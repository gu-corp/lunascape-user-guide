# 機能説明

Lunascape Mobile の機能を、ホーム、ニュース、ブラウザ、設定、ウォレットの 5 つに分けて説明します。

- [ブラウザ](../../browser/i18n/ja/README.md) — ブラウジング、広告ブロック、ページの保存、ダウンロード、共有、Web3 DApp への接続。
- [ホーム](../../home/i18n/ja/README.md) — ホーム画面 — 検索、ツールメニュー、ニュース、ショートカット、ウォレットをひと目で。
- [ニュース](../../news/i18n/ja/README.md) — RSS フィードのニュースを読む、ソースを管理する。
- [設定](../../settings/i18n/ja/README.md) — 設定の各項目と、リセットの方法。
- [ウォレット](../../wallet/i18n/ja/README.md) — 内蔵のセルフカストディ型 Web3 ウォレット — 作成、ダッシュボード、資産と接続の管理、要求の安全な承認。
