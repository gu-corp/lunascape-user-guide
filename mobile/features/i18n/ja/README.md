# 機能説明

Lunascape Mobile の機能を、ホーム、ニュース、ブラウザ、設定、ウォレットの 5 つに分けて説明します。

- [ブラウザ](browser/README.md) — ブラウジング、広告ブロック、ページの保存、ダウンロード、共有、Web3 DApp への接続。
- [ホーム](home/README.md) — ホーム画面 — 検索、ツールメニュー、ニュース、ショートカット、ウォレットをひと目で。
- [ニュース](news/README.md) — RSS フィードのニュースを読む、ソースを管理する。
- [設定](settings/README.md) — 設定の各項目と、リセットの方法。
- [ウォレット](wallet/README.md) — 内蔵のセルフカストディ型 Web3 ウォレット — 作成、ダッシュボード、資産と接続の管理、要求の安全な承認。
