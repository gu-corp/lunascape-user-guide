# Home

The Home screen: search, the tool menu, news, shortcuts and the wallet at a glance.

- [Overview](overview.md) — The Home screen brings search, browser tools, news, shortcuts, and wallet information together in one place.
- [Quick Search](quick-search.md) — Use Quick Search to search with the selected search engine or open information from a QR code.
- [Tool Menu](tool-menu.md) — The Tool Menu provides shortcuts to common browser features, including bookmarks, history, the wallet, downloads, settings, and Private Mode on iOS.
- [News](news.md) — The News widget shows recent articles from the RSS feeds configured in Lunascape.
- [Browser Shortcuts](browser-shortcuts.md) — Browser Shortcuts let you open frequently used websites directly from the Home screen.
- [Wallets](wallets.md) — The Wallet widget provides a quick view of the selected Web3 wallet account, including its balance and assets.
