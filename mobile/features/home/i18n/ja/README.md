# ホーム

ホーム画面 — 検索、ツールメニュー、ニュース、ショートカット、ウォレットをひと目で。

- [概要](overview.md) — ホーム画面には、検索、ブラウザツール、ニュース、ショートカット、ウォレット情報がまとまっています。
- [ブラウザショートカット](browser-shortcuts.md) — ブラウザショートカットを使うと、よく利用するWebサイトをホーム画面から直接開けます。
- [ニュース](news.md) — ニュースウィジェットには、Lunascapeに設定したRSSフィードの新着記事が表示されます。
- [クイック検索](quick-search.md) — クイック検索では、選択中の検索エンジンによる検索と、QRコードからの情報読み取りができます。
- [ツールメニュー](tool-menu.md) — ツールメニューから、ブックマーク、履歴、ウォレット、ダウンロード、設定、iOS版のプライベートモードなど、よく使う機能をすばやく開けます。
- [ウォレット](wallets.md) — ウォレットウィジェットには、選択中のWeb3ウォレットアカウント、残高、資産の概要が表示されます。
