# Wallet

Lunascape Browser includes Lunascape Wallet, a self-custody Web3 wallet for EVM-compatible networks such as Ethereum and Japan Open Chain. Tap **Wallet** on the home screen to open it.

How to set up and use the wallet — creating it, writing down the seed phrase, sending and receiving, connecting to sites and its settings — is covered in the [Lunascape Wallet User Guide](https://help.lunascape.org/wallet/en/).
