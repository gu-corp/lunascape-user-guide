# Features

Lunascape Mobile's features, in five groups: Home, News, Browser, Settings and Wallet.

- [Home](home/README.md) — The Home screen: search, the tool menu, news, shortcuts and the wallet at a glance.
- [News](news/README.md) — Reading news from RSS feeds, and managing the sources.
- [Browser](browser/README.md) — Browsing, blocking ads, keeping pages for later, downloading, sharing, and connecting to Web3 DApps.
- [Settings](settings/README.md) — Every section of Settings, and how to reset.
- [Wallet](wallet/README.md) — The built-in self-custody Web3 wallet: creating it, reading the dashboard, managing assets and connections, and approving requests safely.
