# ニュース

RSS フィードのニュースを読む、ソースを管理する。

- [概要](overview.md) — ニュース機能では、複数のRSSフィードの記事を1か所にまとめて確認できます。
- [デフォルトRSSソース](default-rss-sources.md) — Lunascapeは、アプリの言語と必要に応じて端末の地域を使って初期RSSフィードを選択します。
- [ニュース設定](news-setting.md) — ニュース画面に表示するRSSフィードを管理します。
- [ニュースソース選択](news-sources-selection.md) — アプリの更新によってデフォルトのニュースソースが変わった場合、保存済みリストとの違いを確認する画面が表示されます。
