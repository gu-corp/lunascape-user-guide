# News

Reading news from RSS feeds, and managing the sources.

- [Overview](overview.md) — News collects articles from multiple RSS feeds and displays them in one place.
- [News Setting](news-setting.md) — Manage the RSS feeds shown on the News screen.
- [News Sources Selection](news-sources-selection.md) — After an app update, Lunascape may ask you to review changes to the default news sources.
- [Default RSS Sources](default-rss-sources.md) — Lunascape selects the initial RSS feed list using the app language and, where applicable, the device region.
