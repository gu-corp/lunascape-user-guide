# 設定

設定の各項目と、リセットの方法。

- [概要](overview.md) — ホーム画面から設定を開くと、Lunascapeの表示や動作を変更できます。
- [ブックマーク](bookmarks.md) — 設定 > ブックマークでは、ブックマークの取り込みや整理、開き方の変更ができます。
- [デフォルトブラウザ](default-browser.md) — デフォルトブラウザに設定すると、メールやメッセージなど、ほかのアプリでタップしたリンクがLunascapeで開きます。
- [表示](display.md) — 設定 > 表示では、アプリの画面、Webサイトの見え方、言語、高度な表示動作を変更できます。
- [一般](general.md) — 設定 > 一般では、アプリの基本動作、タブ、ショートカット、広告ブロック、ニュース、ホーム画面を変更できます。
- [履歴](history.md) — 設定 > 履歴では、履歴の開き方を変更したり、閲覧データを削除したりできます。
- [プライバシー](privacy.md) — 設定 > プライバシーでは、アプリへのアクセスを保護したり、閲覧データを自動削除したりできます。
- [デフォルトにリセット](reset-to-default.md) — カスタマイズをすべて元に戻したい場合や、アプリを再起動しても設定に関する問題が続く場合に使用します。
- [検索](search.md) — 設定 > 検索では、検索サービスや候補・検索結果の動作を変更できます。
- [サポート](support.md) — 設定 > サポートでは、ヘルプやインストール済みバージョンの情報を確認できます。
- [ウォレット](wallet.md) — 設定 > ウォレットでは、ブラウザウォレット機能の表示を切り替えたり、詳細設定を開いたりできます。
