# ブラウザ

ブラウジング、広告ブロック、ページの保存、ダウンロード、共有、Web3 DApp への接続。

- [概要](overview.md) — Lunascapeのブラウザでは、通常のWeb閲覧に加えて、広告ブロック、ファイルのダウンロード、プライベートブラウジング、Web3 DAppへの接続ができます。
- [広告ブロック](ad-blocking.md) — 広告ブロックを有効にすると、対応しているWebサイト上の広告を減らせます。この機能は初期状態では無効です。
- [ブックマーク](bookmarks.md) — よく使うWebページをブックマークに保存し、フォルダーで整理できます。
- [ブラウザツールメニュー](browser-tool-menu.md) — ブラウザのツールメニューには、表示中のWebページで使える操作がまとめられています。
- [ブラウジング履歴](browsing-history.md) — 閲覧したWebページは日付ごとに履歴へ保存されます。履歴から以前のページを開き直すことができます。
- [ファイルダウンロード](download-file.md) — Lunascapeでは、音声、動画、画像、文書など、Webサイトが提供する各種ファイルをダウンロードできます。
- [プライベートモード](private-mode.md) — プライベートモードでは、閲覧履歴やCookieを通常のブラウジングデータとは分けて扱えます。この機能はiOS版で利用できます。
- [リーディングリスト](reading-list.md) — あとで読みたいWebページをリーディングリストに保存できます。項目は未読と既読に分けて管理されます。
- [検索](search.md) — アドレスバーにキーワードを入力してWebを検索できます。
- [共有](share.md) — 表示中のWebページを他のアプリへ共有したり、端末に保存したりできます。
- [タブ操作](tab-operations.md) — 複数のWebページをタブで開き、すばやく切り替えられます。
- [Web3 DAppサポート](web3-dapp-support.md) — 対応するWeb3 DAppへウォレットを接続し、アカウントの確認やトランザクションの承認ができます。
