# Lunascape Mobile ユーザガイド

Lunascape Mobile は、従来の Web ブラウジングと最先端の Web3 機能を組み合わせた、強力で機能豊富なモバイルブラウザです。パフォーマンスと革新性を求める現代のユーザー向けに作られ、ブロックチェーン技術、ニュース集約、高度なブラウジング機能を、ひとつの直感的なインターフェースに統合しています。

## Lunascape Mobile をダウンロード

広告ブロック対応の日本製ブラウザアプリです。Web3 ウォレットを内蔵し、Uniswap などの DApp にそのまま接続できるので、暗号通貨や NFT の売買も簡単に行えます。

- **iOS** — [App Store で入手](http://itunes.apple.com/app/ilunascape/id380065805?mt=8)
- **Android** — [Google Play で入手](https://play.google.com/store/apps/details?id=jp.co.lunascape.android.ilunascape)

手順は [ダウンロードとインストール](../../getting-started/i18n/ja/download.md)、うまくいかないときは [トラブルシューティング](../../getting-started/i18n/ja/troubleshooting.md) を参照してください。

## Lunascape Mobile v15 の特長

- **動画広告もブロック** — Web サイトと動画の広告を完全にブロック
- **統合 Web3 ウォレット** — Ethereum、Japan Open Chain に対応する EVM ウォレット
- **統合 RSS ニュースリーダー** — お気に入りの情報をブラウザの中でまとめて閲覧
- **20 年以上の実績** — 2,000 万ダウンロードを超える日本製ブラウザ
- **プライバシー重視** — トラッキングも個人データの収集もしない安全な設計

## 概要

Lunascape Mobile は、基本的な Web ナビゲーションから高度な Web3 の操作、ニュースの閲覧、プライバシー機能まで、モバイルブラウジングのあらゆる場面で優れた体験を提供することを目指しています。一般のユーザーにもブロックチェーン愛好家にも、使いやすさと強力な機能を両立するよう設計されています。

### 1 つのアプリで、複数の機能

Lunascape Mobile は、従来の Web ブラウジングと Web3 ウォレット、ニュース集約、高度なプライバシー機能をシームレスに統合した唯一のモバイルブラウザです。Web を見るときも、暗号資産を管理するときも、最新のニュースを追うときも、すべてがひとつの体験としてつながります。

### パフォーマンスとセキュリティへの注力

効率的なハードウェアアクセラレーション、最適化された Web3 の操作、堅牢なプライバシー保護により、最新のモバイル端末で優れた性能を発揮します。ブラウジングデータと暗号資産は、業界標準の暗号化とセルフカストディ型ウォレット技術で守られます。

### クリーンで直感的、機能豊富なデザイン

あらゆるモバイル端末とプラットフォームで美しく動作するよう設計されています。丁寧に作り込んだ UI 部品、レスポンシブなレイアウト、画面サイズに合わせたテーマにより、上質なブラウジング体験が得られます。

### Web と Web3 に最適化

現代の Web 標準の力と最先端の Web3 機能を組み合わせ、従来のブラウジングと分散アプリケーション、暗号資産の管理、ブロックチェーンの操作をひとつにまとめます。

## 主要機能

### 高度な Web ブラウジング

強力なブラウジング機能と Web3 の統合で、これまでにない Web 体験を。

- 広告ブロックとプライバシー保護
- タブ管理と閲覧履歴
- ダウンロード管理とファイル共有
- プライベートブラウジングモード
- Web3 DApp 対応

### 内蔵 Web3 ウォレット

暗号資産の管理も、分散アプリケーションとのやり取りも、そのまま。

- Ethereum、BSC、Polygon などに対応する EVM 互換ウォレット
- 安全なシードフレーズと秘密鍵の管理
- トークンと資産の管理
- DeFi・NFT マーケットプレイスとの連携
- 外部ウォレット接続のための WalletConnect 対応

### インテリジェントなニュース集約

お気に入りのソースからのパーソナライズされたニュースフィードとリアルタイム更新で、いつでも最新の情報を。

- カスタマイズできるニュースソースと RSS フィード
- リアルタイムのニュース更新
- パーソナライズされたおすすめ
- 多言語対応

### 充実した設定

豊富な設定項目とプライバシーコントロールで、自分好みに。

- プライバシーとセキュリティのコントロール
- 表示とアクセシビリティの設定
- ネットワークとウォレットの設定
- バックアップと復元

## 目標

### クロスプラットフォームの卓越性

Lunascape Mobile は iOS と Android の両方でシームレスに動作し、プラットフォームによらず一貫した体験を提供します。各プラットフォームの特性に最適化しつつ、機能の同等性を保っています。

### Web 標準ベース

現代の Web 技術と標準の上に作られており、現在および将来の Web アプリケーションとの互換性を確保します。最新の Web API に対応しながら、既存の Web サイトとの互換性も維持します。

### ユーザー中心の設計

すべての機能はユーザーを第一に、使いやすさ、性能、セキュリティを優先して設計されています。インターフェースは使い方と好みに合わせて適応し、使うほどブラウジングが効率的になります。

### 革新とセキュリティ

最先端の Web3 技術と堅牢なセキュリティ対策を組み合わせ、分散 Web を探索するあいだも、デジタル資産と個人データを守ります。
