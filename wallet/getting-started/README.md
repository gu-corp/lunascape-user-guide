# はじめに

ウォレットを開き、作成またはインポートして、シードフレーズを控えるまで。

- [インストールしてはじめる](install.md) — パソコン（Chrome 拡張機能 / Lunascape Desktop）とスマートフォンから、使う方法を選んで準備します。
- [ウォレットを作成する](create-wallet.md) — マスターパスワードを決め、利用規約に同意すると、新しいウォレットができます。
- [ウォレットをインポートする](import-wallet.md) — 12 語のシードフレーズで、既存のウォレットを取り込みます。
- [シードフレーズをバックアップする](backup.md) — ウォレットを作成したら、すぐにシードフレーズを控えてください。
- [画面の見かた](screen.md) — ウォレットの画面は、上から順に次の要素で構成されています。
