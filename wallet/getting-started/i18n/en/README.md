# Getting started

From opening the wallet to creating or importing one and writing down the seed phrase.

- [Install and get started](install.md) — Choose how to use the wallet: on a computer (Chrome extension or Lunascape Desktop) or on a smartphone.
- [Create a wallet](create-wallet.md) — Set a master password, accept the terms, and the new wallet is ready.
- [Import a wallet](import-wallet.md) — Bring in an existing wallet with its 12-word seed phrase.
- [Back up your seed phrase](backup.md) — Write down the seed phrase as soon as you create the wallet.
- [The wallet screen](screen.md) — The parts of the wallet screen, from top to bottom.
