# Get and open the wallet

## In Lunascape Desktop

Lunascape Wallet is already part of Lunascape Desktop. There is nothing to install.

Press the Lunascape Wallet button (the wallet shape) in the toolbar, and the wallet opens in a panel on the right of the window. Press the button again, or the **×** at the top right of the panel, to close it.

<img src="img/lock.png" alt="Pressing the wallet button in the toolbar opens the Lunascape Wallet panel on the right, showing the lock screen with a password field and an Unlock button" width="300" />

If you can't find the button, check that Lunascape Wallet is on under **Settings** > **Extensions** > **System Extensions** in Lunascape.

## In Chrome and other browsers

Add Lunascape Wallet from the Chrome Web Store. Then pin it from the extensions button (the puzzle piece) in the toolbar so it's always one click away.

## The first time you open it

The first time, the wallet shows the create screen.

- Starting fresh: [Create a wallet](create-wallet.md)
- Using a wallet from another computer or browser: [Import a wallet](import-wallet.md)

## After that

The wallet opens on the lock screen (**Welcome back!**). Enter the master password you set when you created it and press **Unlock**. The wallet also locks when, for example, you restart the browser.

If you've forgotten the password, see [Forgot your password](../../../troubleshooting/i18n/en/password.md).
