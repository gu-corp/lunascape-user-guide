# Computer (extension)

Lunascape Wallet on Windows / Mac. The extension you add to Google Chrome and the one built into Lunascape Desktop are the same, with the same screens and operations.

The screenshots show the wallet in the Lunascape Desktop side panel. In Chrome, the same screens open from the extension button in the toolbar.

- [Getting started](../../getting-started/i18n/en/README.md) — From installing to creating a wallet and writing down the seed phrase.
- [Using the wallet](../../features/i18n/en/README.md) — Sending, receiving, checking your assets, and switching networks and accounts.
- [Connecting to sites](../../dapps/i18n/en/README.md) — Connecting to Web3 sites and checking signatures and transactions.
- [Settings](../../settings/i18n/en/README.md) — Every item in the wallet's settings.
- [Troubleshooting](../../troubleshooting/i18n/en/README.md) — Problems with passwords, sending and connecting to sites.
