# パソコン版（拡張機能）

Windows / Mac で使う Lunascape Wallet です。Google Chrome に追加する拡張機能と、Lunascape Desktop に最初から入っているものは同じで、画面と操作も同じです。

画面の例は Lunascape Desktop のサイドパネルで表示したものです。Chrome では、ツールバーの拡張機能のボタンから開くと、同じ画面が表示されます。

- [使いかた](../../features/i18n/ja/README.md) — 送金、受け取り、資産の確認、ネットワークとアカウントの切り替え。
- [サイトとつなぐ](../../dapps/i18n/ja/README.md) — Web3 サイトへの接続と、署名や取引の確認。
- [設定](../../settings/i18n/ja/README.md) — ウォレットの設定のすべての項目。
- [困ったときは](../../troubleshooting/i18n/ja/README.md) — パスワード、送金、サイトとの接続のトラブル。
