# Chrome に追加する

**対象：** Windows / Mac の Google Chrome

以下の画面は Mac の Chrome のものです。Windows でも同じ流れで進められます。

## 1. Chrome ウェブストアのページを開く

Google Chrome で [Lunascape Wallet（Chrome ウェブストア）](https://chromewebstore.google.com/detail/lunascape-wallet/nfinomegcaccbhchhgflladpfbajihdf) を開き、**Chrome に追加** を押します。

<img src="img/chrome-store.png" alt="Chrome ウェブストアの Lunascape Wallet のページ。提供元は gu.net。Chrome に追加のボタンがある" width="760" />

## 2. 拡張機能を追加する

「「Lunascape Wallet」を追加しますか？」と、拡張機能ができることが表示されます。**拡張機能を追加** を押します。

<img src="img/chrome-add-dialog.png" alt="「Lunascape Wallet」を追加しますか？ のダイアログ。すべてのウェブサイト上にある自分の全データの読み取りと変更、通知を表示、と書かれ、キャンセルと拡張機能を追加のボタンがある" width="760" />

ウォレットは、Web3 サイトと接続するために、ページの内容を読み取ります。許可なく送金などをすることはありません。

## 3. 追加されたことを確かめる

右上に「「Lunascape Wallet」が Chrome に追加されました」と表示されます。Chrome へのログインは不要です。**×** で閉じてください。

<img src="img/chrome-added.png" alt="ウィンドウの右上に、Lunascape Wallet が Chrome に追加されました、という表示と、Chrome にログインのボタン" width="760" />

**Lunascape Wallet へようこそ** のタブも開き、ツールバーへのピン留めのしかたが表示されます。

<img src="img/chrome-welcome.png" alt="Lunascape Wallet へようこそ のタブ。拡張機能のメニューからピン留めする図と、このタブを閉じるのボタン" width="760" />

## 4. ツールバーにピン留めする

Chrome のツールバーにある拡張機能のボタン（パズルのアイコン）を押し、**Lunascape Wallet** の横のピンを押します。

<img src="img/chrome-pin-menu.png" alt="パズルのアイコンから開いた拡張機能のメニュー。Lunascape Wallet とピンのボタンがある" width="760" />

ツールバーに Lunascape Wallet のアイコン（財布の形）が表示されるようになります。

<img src="img/chrome-pinned.png" alt="Lunascape Wallet をピン留めした状態。パズルのアイコンの横に、ウォレットのアイコンが表示されている" width="760" />

## 5. ウォレットを開く

ツールバーの Lunascape Wallet のアイコンを押すと、右側のサイドパネルにウォレットが開きます。**次** を押して始めます。

<img src="img/chrome-side-panel.png" alt="右側の Lunascape Wallet のサイドパネル。暗号資産を視覚的に簡単に管理、使用できます、という説明と、次のボタン" width="760" />

**次** を押すと、画面に表示されているプライバシーポリシーと利用規約に同意したことになります。

## 6. ウォレットを作成する

1. **新しいウォレットを作成** を選び、**次** を押します。

   <img src="img/create-local-wallet.png" alt="ローカルウォレットの作成画面。新しいウォレットを作成と、ウォレットをインポートの選択肢と、次ボタン" width="300" />

2. マスターパスワード（8 文字以上）を 2 回入力し、**作成** を押します。忘れると、誰にも解除できません。

   <img src="img/create-password.png" alt="マスターパスワードの登録画面。新しいパスワードとパスワードの確認の欄、作成ボタン" width="300" />

3. 3 つの項目を読み、すべてにチェックを入れて **アカウントを作成** を押します。

   <img src="img/create-terms.png" alt="利用規約画面。3 つのチェック項目と、アカウントを作成ボタン" width="300" />

4. ウォレットのメイン画面が表示されたら完了です。

   <img src="img/main-new.png" alt="作成直後のメイン画面。Account 1 の合計残高は 0 ドル（アドレスはぼかしてある）" width="300" />

すでに持っているウォレットを使う場合は、**ウォレットをインポート** を選びます。[ウォレットをインポートする](import-wallet.md) を参照してください。

## 7. シードフレーズを控える

パソコン版では、シードフレーズを控える画面は自動では表示されません。必ずここで控えてください。

1. ウォレットの右上の **⋮** を押し、**設定** を選びます。
2. **セキュリティ** を選び、**シードフレーズをエクスポート** を押します。
3. **シードフレーズを表示** を押し、マスターパスワードを入力して、12 個の英単語を順番どおりに紙に書き写します。

<img src="img/export-seed.png" alt="シードフレーズをエクスポートの画面で、パスワードを入力してくださいというダイアログが開いている" width="560" />

> **重要:** シードフレーズは紙に書いて、誰にも見せずに保管してください。スクリーンショットやクラウドへの保存は避けてください。シードフレーズを知られると、ウォレットの資産をすべて送金されてしまいます。[シードフレーズをバックアップする](backup.md) も参照してください。
