# Lunascape Desktop で使う

**対象：** Windows / Mac

Lunascape Desktop には Lunascape Wallet が最初から入っています。拡張機能を追加する必要はありません。

1. [Lunascape のダウンロードページ](https://www.lunascape.org/ja/download) から、Windows 版または Mac 版をダウンロードします。
2. ダウンロードしたファイルを開き、画面の案内に従ってインストールし、Lunascape を起動します。
3. ツールバーの Lunascape Wallet のアイコン（財布の形）を押します。ウィンドウの右側にウォレットのパネルが開きます。もう一度アイコンを押すか、パネル右上の **×** で閉じます。

   <img src="img/lock.png" alt="ツールバーの財布のアイコンを押すと、ウィンドウの右側に Lunascape Wallet のパネルが開く。ロック画面にパスワード欄とロック解除ボタンがある" width="300" />

   アイコンが見つからないときは、Lunascape の **設定** > **拡張機能** の **システム拡張** で、Lunascape Wallet がオンになっているか確認してください。

4. はじめて開くと、ウォレットの作成画面が表示されます。[ウォレットを作成する](create-wallet.md) の手順で作成してください。
5. 作成が終わったら、[シードフレーズをバックアップする](backup.md) の手順で、必ずシードフレーズを控えてください。パソコン版では、シードフレーズを控える画面は自動では表示されません。

## Lunascape Desktop だけの設定

Lunascape の **設定** > **ウォレット** で、ウォレット拡張機能の **現在のバージョン** を確認し、**拡張機能のソース** を変更できます。通常は既定のまま（**Chrome Web Store（推奨）** で **自動更新を有効にする** がオン）で使います。

<img src="img/desktop-wallet-settings.png" alt="Lunascape の設定のウォレット。現在のバージョンが表示され、拡張機能のソースは Chrome Web Store（推奨）が選ばれ、自動更新を有効にするがオンになっている" width="560" />

Lunascape Wallet を使わないときは、**設定** > **拡張機能** の **システム拡張** でオフにできます。

ウォレットの画面と操作は、Chrome に追加した場合と同じです。
