# The wallet screen

Tap **Wallet** on the Lunascape Browser home screen to open the wallet. The main screen is made up of the following parts.

<img src="img/mobile-main.png" alt="The wallet's main screen: the account name at the top left, the refresh, network and settings icons at the top right, the total balance, the Send and Receive buttons, the assets in possession and the transaction history" width="300" />

| Part | What it does |
| --- | --- |
| Account name | Tap to switch or add accounts. See [Accounts and address book](accounts.md) |
| Refresh icon | Reloads balances |
| Network icon | Switches the network (chain) used when you connect to sites. See [Networks](networks.md) |
| Settings icon (gear) | Opens the wallet's settings. See [Settings](settings.md) |
| Total Balance | The total value of your assets. Tap the currency to change it; the eye icon hides the amount |
| **Send** / **Receive** | See [Send and receive](send-receive.md) |
| Assets in possession | Your tokens and balances. **View all** opens the full asset list. See [Check your assets](assets.md) |
| Transaction History | What this account has sent. **View all** shows the full list |

The toolbar at the bottom is Lunascape Browser's own (back, search, browser, wallet and settings).
