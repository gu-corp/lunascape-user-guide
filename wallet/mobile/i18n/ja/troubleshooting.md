# 困ったときは

## マスターパスワードを忘れた

パスワードを調べる方法はありません。シードフレーズがあれば、シードフレーズでウォレットを入れ直してください。設定の **マスターパスワードを変更する** でも、シードフレーズを入力すれば変更できます。シードフレーズがない場合は、ロックを解除できません。

## 送金できない・「残高が不足しています」と表示される

送るトークンとは別に、手数料のための、そのネットワークの基本の通貨（Ethereum では ETH、Japan Open Chain では JOC）が必要です。少し受け取るか、[購入](assets.md#トークンを購入する) してから、もう一度試してください。

## 受け取ったトークンが表示されない

相手が、ウォレットに入っているネットワークで送ったか確かめてください。資産リストにない場合は、[トークンを追加](assets.md#トークンを追加する) してください。

## Face ID が使えない

入れ直した直後は、パスワードの登録画面に Face ID のスイッチが出ないことがあります。あとでロック画面で、Face ID を登録するか聞かれることがあります。それまでは、マスターパスワードでロックを解除してください。

## サイトがウォレットを見つけない

- サイトを、ほかのブラウザーではなく Lunascape Browser で開いているか確かめてください。
- サイトで MetaMask を選ぶか、設定の **ethereum.isMetaMaskを有効にします** をオンにして、ページを再読み込みしてください。

## 「G.U.Wallet」と表示される

一部の確認画面には、ウォレットの以前の名前が表示されます。同じウォレット（Lunascape Wallet）です。

## お問い合わせの前に

シードフレーズ・秘密鍵・パスワードは、Lunascape のサポートを含め、誰にも伝えないでください。お問い合わせには、アプリのバージョン、端末、ネットワーク、何をしていたかを書いてください。

- [サポート](https://www.lunascape.org/ja/support)
