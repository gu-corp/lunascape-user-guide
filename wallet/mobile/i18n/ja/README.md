# スマホ版（Lunascape Browser）

iPhone / Android の Lunascape Browser アプリに入っている Lunascape Wallet です。パソコン版とは画面が異なります。画面の例は iPhone のものです。Android でも同じ流れで使えます。

- [インストールしてはじめる](install.md) — アプリのインストールから、ウォレットの作成、シードフレーズを控えるまで。
- [画面の見かた](screen.md) — ウォレットのメイン画面の各部分。
- [送金と受け取り](send-receive.md) — アドレスに送金する、自分のアドレスを見せて受け取る。
- [資産を確認する](assets.md) — 資産リスト、トークンの詳細、トークンの追加、NFT、購入。
- [ネットワーク](networks.md) — ネットワークの切り替え、追加、編集、削除。
- [アカウントと連絡先](accounts.md) — アカウントの追加と切り替え、よく送るアドレスの保存。
- [サイトとつなぐ](dapps.md) — Web3 サイト（DApp）への接続と、サイトから届く依頼の確認。
- [WalletConnect](walletconnect.md) — QR コードで、別の端末のサイトと接続する。
- [設定](settings.md) — ウォレット設定のすべての項目。
- [困ったときは](troubleshooting.md) — パスワードを忘れた、送金できないなど。
