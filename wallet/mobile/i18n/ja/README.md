# スマホ版（Lunascape Browser）

iPhone / Android の Lunascape Browser アプリに入っている Lunascape Wallet です。パソコン版とは画面が異なります。

- [インストールしてはじめる](install.md) — アプリのインストールから、ウォレットの作成、シードフレーズを控えるまで。
- [概要](overview.md) — スマホ版のウォレットでできること。
- [ウォレットダッシュボード](wallet-dashboard.md) — アカウント、ネットワーク、残高、資産、取引履歴の確認と、送信・受信。
- [アセット一覧](asset-list.md) — トークンの表示、並べ替え、詳細、編集。
- [ウォレット操作](wallet-operations.md) — サイト（DApp）への接続、トークンとネットワークの追加。
- [WalletConnect](walletconnect.md) — QR コードやディープリンクでサイトと接続する。
- [ウォレット設定](wallet-settings.md) — アカウント、アドレス帳、ネットワーク、表示通貨、セキュリティ。
- [ウォレット作成（旧）](create-wallet.md) — 以前の手順です。今の手順は [インストールしてはじめる](install.md) を参照してください。
