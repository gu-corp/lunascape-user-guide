# G.U. Wallet

G.U. Wallet は標準で入っている Web3 ウォレットの拡張機能です。EVM 互換のチェーンに対応し、Web3 サイト（DApp）と接続できます。

## 使いはじめる

ツールバーの G.U. Wallet のアイコンを押して、画面の案内に従ってウォレットを作成するか、既存のウォレットを復元します。

> **注意:** 復元用のフレーズ（シードフレーズ）は、他人に知られると資産を失います。画面のスクリーンショットやチャットで送ることは避け、安全な場所に保管してください。Lunascape のサポートがフレーズを尋ねることはありません。

## サイトと接続する

Web3 サイトで接続を求められると、ウォレットの確認画面が表示されます。接続してよいサイトかを確認してから許可してください。

## 設定

**設定** > **ウォレット** で、ウォレット拡張機能の取得元などを変更できます。通常は既定のまま（Chrome ウェブストアから自動更新）で使います。
