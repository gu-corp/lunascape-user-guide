# AI sidebar

Lunascape AI Sidebar is bundled with the browser. Ask it about the page you are on, or have it summarise or translate.

## Open it

Press the AI sidebar button in the toolbar. A panel opens beside the page.

## Choose a model

Pick where the sidebar sends your questions in its settings.

| Provider | What you need |
| --- | --- |
| Anthropic (Claude) | An Anthropic API key |
| OpenAI-compatible | The endpoint URL and an API key |
| Claude Code CLI | The Claude Code CLI installed on this computer |
| Local AI | A model running on this computer. Experimental, and not available everywhere |

API keys are kept on your computer and are sent only to the provider you chose.

## What it reads

The sidebar reads the page you are viewing in order to answer. Close it before opening a page you would rather it did not read.
