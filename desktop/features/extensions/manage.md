# 拡張機能を追加・管理する

Lunascape は Chrome 拡張機能に対応しています。Chrome ウェブストアからそのまま追加できます。

## 追加する

1. Chrome ウェブストアで使いたい拡張機能のページを開きます。
2. **Chrome に追加** を押します。
3. 必要な権限が表示されるので、内容を確認してインストールします。

権限には、次のようなものがあります。

| 表示 | 意味 |
| --- | --- |
| 閲覧アクティビティの読み取り | 開いているタブの情報を読み取ります |
| 閲覧履歴の読み取りと変更 | 履歴を読み書きします |
| ブックマークの読み取りと変更 | ブックマークを読み書きします |
| Cookie の読み取りと変更 | サイトのログイン状態などを読み書きします |
| ダウンロードの管理 | ダウンロードを操作します |

> **注意:** 一部の拡張機能は、Lunascape が未対応の API を使うためインストールできないことがあります。その場合はインストール時に理由が表示されます。

## 管理する

**設定** > **拡張機能** で、インストール済みの拡張機能を確認し、有効・無効の切り替えと削除ができます。

拡張機能のボタンはツールバーに並びます。ボタンを押すとポップアップが開きます。

## 標準で入っている拡張機能

| 名前 | 説明 |
| --- | --- |
| Lunascape Password Manager | [パスワードマネージャー](password-manager.md) |
| G.U. Wallet | [G.U. Wallet](wallet.md) |
