# AI サイドバー

Lunascape AI Sidebar は標準で入っている拡張機能です。表示中のページについて質問したり、要約や翻訳を頼んだりできます。

## 開く

ツールバーの AI サイドバーのアイコンを押すと、ウィンドウの横にパネルが開きます。

## 使うモデルを選ぶ

サイドバーの設定から、接続先を選びます。

| 接続先 | 必要なもの |
| --- | --- |
| Anthropic（Claude） | Anthropic の API キー |
| OpenAI 互換 | エンドポイントの URL と API キー |
| Claude Code CLI | 端末にインストール済みの Claude Code CLI |
| ローカル AI | 端末上で動くモデル（実験的な機能で、環境によっては利用できません） |

API キーは端末内に保存され、選んだ接続先以外には送信されません。

## ページを読み取る範囲

AI サイドバーは、表示中のページの内容を読み取って回答します。読み取ってほしくないページでは、サイドバーを閉じてから開いてください。
