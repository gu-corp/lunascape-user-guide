# Features

The features of Lunascape Desktop, in five groups: browsing, windows and profiles, privacy, extensions, and AI.

- [AI](../../ai/i18n/en/README.md) — The AI built into Lunascape, and connecting an outside AI.
- [Browsing](../../browser/i18n/en/README.md) — The everyday browsing tasks.
- [Extensions](../../extensions/i18n/en/README.md) — The extensions bundled with Lunascape, and adding and managing Chrome extensions.
- [Privacy](../../privacy/i18n/en/README.md) — Ad blocking, site permissions, and managing the data sites keep.
- [Windows and profiles](../../windows/i18n/en/README.md) — Private windows, and profiles for keeping uses apart.
