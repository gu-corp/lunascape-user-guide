# プライバシー

広告ブロック、サイトの権限、サイトが保存するデータの管理について説明します。

- [広告ブロック](ad-blocking.md) — 広告とトラッカーをブロックして、表示を軽くし、通信量を減らします。ブロックした数はツールバーのアイコンで確認できます。
- [サイトの権限](permissions.md) — サイトが位置情報・カメラ・マイク・通知を使おうとすると、画面に確認が表示されます。
- [サイトデータと閲覧データ](site-data.md) — アドレスバー左のアイコンから サイトデータを管理 を開くと、そのサイトが保存している Cookie などのデータを確認して削除できます。削除すると、そのサイトからはログアウトさ…
