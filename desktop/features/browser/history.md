# 履歴

## 履歴を見る

メニュー（≡）から **履歴** を選ぶか、`Ctrl+H` / `Cmd+H` を押します。日付ごとに、開いたページが並びます。検索ボックスからタイトルや URL で絞り込めます。

## 履歴を削除する

一覧から個別に削除できます。まとめて消したいときは、**設定** > **プライバシー** の閲覧データの削除を使います。

## 保存期間を変える

**設定** > **プライバシー** の **履歴保存日数** で、履歴を保持する日数を設定できます。期間を過ぎた履歴は自動的に削除されます。

> **注意:** シークレットウィンドウで開いたページは履歴に残りません。
