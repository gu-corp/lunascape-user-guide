# PDF を表示する

PDF へのリンクを開くと、内蔵の PDF ビューアで表示されます。ダウンロードしなくてもそのまま読めます。

## ビューアでできること

- ページの移動と拡大・縮小
- ページ内のテキスト検索
- 印刷
- ファイルとして保存（ダウンロード）

## ログインが必要なサイトの PDF

社内システムなど、ログインが必要なサイトの PDF も、ログインした状態のまま表示できます。

## 表示できないときは

- ページを再読み込みしてください。
- 一度ダウンロードして、PC 上の PDF リーダーで開けるか確認してください。
- それでも表示されない場合は[不具合の報告](../../troubleshooting/README.md)を参照してください。
