# ブラウジング

毎日のブラウジングでよく使う操作をまとめています。

- [ブラウジングの概要](overview.md) — 日常の操作は、次のページにまとめています。
- [タブを操作する](tabs.md) — タブを右クリックすると、次のような操作ができます。
- [タブグループ](tab-groups.md) — 関連するタブをまとめて、色と名前を付けて管理できます。調べ物の単位でタブを分けたいときに使います。
- [検索とアドレスバー](search.md) — アドレスバーは、URL の入力と検索を兼ねています。
- [ブックマーク](bookmarks.md) — よく使うブックマークを、ツールバーの下に並べて表示します。
- [履歴](history.md) — メニュー（≡）から 履歴 を選ぶか、`Ctrl+H` / `Cmd+H` を押します。日付ごとに、開いたページが並びます。検索ボックスからタイトルや URL で絞り込めます。
- [ダウンロード](downloads.md) — ファイルへのリンクを選ぶと、ダウンロードが始まり、画面下部にダウンロードバーが表示されます。バーの すべて表示 を押すと、ダウンロード履歴が開きます。
- [PDF を表示する](pdf.md) — PDF へのリンクを開くと、内蔵の PDF ビューアで表示されます。ダウンロードしなくてもそのまま読めます。
- [ページの操作](page-tools.md)
- [キーボードショートカット](shortcuts.md) — Windows は `Ctrl`、macOS は `Cmd` を使います。異なる場合は両方を記載しています。
