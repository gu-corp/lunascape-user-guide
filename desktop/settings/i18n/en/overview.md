# Settings

Open **Settings** from the menu (≡) or from the sidebar on the left, and pick a section on the left.

| Section | What it covers |
| --- | --- |
| General | The default browser, language, tabs |
| Appearance | Which toolbars and browser elements are shown |
| Search | Manage search engines and choose the default |
| Privacy | Ad blocking, site permissions, browsing data |
| Downloads | Where downloaded files are saved |
| Bookmarks | The bookmarks bar, and managing bookmarks |
| Wallet | The built-in crypto wallet |
| Extensions | Manage installed extensions |
| Theme | Colours, appearance and the dashboard background |
| Profiles | Manage browsing profiles |
| AI integration | The AI sidebar's tools, the MCP server, the audit log |
| About | Version, release notes and the update channel |

## General

- **Default browser**: makes Lunascape the default browser. See [Set as the default browser](../../../getting-started/i18n/en/default-browser.md).
- **Language**: the language of the browser interface.
- **Tabs**: whether what you type in the address bar opens in a new tab, and which page a new tab shows.

## About

- **Version**: the Lunascape version you are running, and its **Release notes**.
- **Update channel**: which kind of build you receive (stable, beta or dev). See [Update](../../../getting-started/i18n/en/update.md).

## Appearance

- Show the bookmarks bar
- Show icons on the bookmarks bar / on tabs
- Show the search bar / the dashboard button in the toolbar

## Reset

**Reset** in the settings offers:

- **Reset all settings**: everything goes back to its default. This cannot be undone.
- **Reset search engines**: the defaults come back and the engines you added are deleted.
