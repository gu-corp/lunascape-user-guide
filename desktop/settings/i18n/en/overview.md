# Settings

Open **Settings** from the menu (≡) and pick a section on the left.

| Section | What it covers |
| --- | --- |
| Profiles | Manage browsing profiles |
| General | Language, what happens at startup, the default browser, the update channel |
| Appearance | Which toolbars and browser elements are shown |
| Search engines | Manage search engines and choose the default |
| Privacy | Ad blocking, site permissions, browsing data |
| Downloads | Where downloaded files are saved |
| Bookmarks | The bookmarks bar, and managing bookmarks |
| Extensions | Manage installed extensions |
| Wallet | The built-in crypto wallet |
| AI integration | The MCP server, what an AI may do, the audit log |
| Theme | Colours, appearance and the dashboard background |
| About | Version and release notes |

## General

- **Language**: the language of the browser interface.
- **On startup**: **Continue where you left off** restores the tabs you had open.
- **Update channel**: which kind of build you receive. See [Update](../../../getting-started/i18n/en/update.md).

## Appearance

- Show the bookmarks bar
- Show icons on the bookmarks bar / on tabs
- Show the search bar / the dashboard button in the toolbar
- Open what you type in the address bar in a new tab

## Reset

**Reset** in the settings offers:

- **Reset all settings**: everything goes back to its default. This cannot be undone.
- **Reset search engines**: the defaults come back and the engines you added are deleted.
