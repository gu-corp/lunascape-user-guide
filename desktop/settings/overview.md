# 設定一覧

メニュー（≡）から **設定** を開きます。左側の一覧から項目を選びます。

| 項目 | 内容 |
| --- | --- |
| プロファイル | ブラウジングプロファイルを管理します |
| 一般 | 言語、起動時の動作、既定のブラウザー、更新チャンネル |
| 外観 | 表示するツールバーやブラウザー要素を選びます |
| 検索エンジン | 検索エンジンの管理と既定の設定 |
| プライバシー | 広告ブロック、サイトの権限、閲覧データ |
| ダウンロード | ダウンロードしたファイルの保存先 |
| ブックマーク | ブックマークバーの表示とブックマークの管理 |
| 拡張機能 | インストール済みの拡張機能を管理します |
| ウォレット | 内蔵暗号資産ウォレットの設定 |
| AI 連携 | MCP サーバー、AI に渡す権限、監査ログ |
| テーマ | ブラウザーの配色と外観、ダッシュボード背景 |
| About | バージョン、リリースノート |

## 一般

- **言語**: ブラウザーの表示言語を選びます。
- **起動時**: **前回終了時の状態を復元** を選ぶと、前回開いていたタブが復元されます。
- **更新チャンネル**: 受け取るバージョンの種類を選びます。詳しくは[アップデート](../getting-started/update.md)を参照してください。

## 外観

- ブックマークバーを表示する
- ブックマークバーにアイコンを表示する / タブにアイコンを表示する
- ツールバーに検索バーを表示する / ダッシュボードボタンを表示する
- アドレスバーから入力した際に新しいタブで開く

## 設定を初期化する

**設定** の **リセット** から、次の操作ができます。

- **すべての設定を初期化**: すべての設定が既定値に戻ります。取り消せません。
- **検索エンジンを既定に戻す**: 追加した検索エンジンは削除されます。
