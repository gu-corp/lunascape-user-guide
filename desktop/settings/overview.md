# 設定一覧

メニュー（≡）か、左のサイドバーの **設定** から開きます。左側の一覧から項目を選びます。

| 項目 | 内容 |
| --- | --- |
| 一般 | 既定のブラウザー、言語、タブ |
| 外観 | 表示するツールバーやブラウザー要素を選びます |
| 検索 | 検索エンジンの管理と既定の設定 |
| プライバシー | 広告ブロック、サイトの権限、閲覧データ |
| ダウンロード | ダウンロードしたファイルの保存先 |
| ブックマーク | ブックマークバーの表示とブックマークの管理 |
| ウォレット | 内蔵暗号資産ウォレットの設定 |
| 拡張機能 | インストール済みの拡張機能を管理します |
| テーマ | ブラウザーの配色と外観、ダッシュボード背景 |
| プロファイル | ブラウジングプロファイルを管理します |
| AI連携 | AI サイドバーのツール、MCP サーバー、監査ログ |
| About | バージョン、リリースノート、更新チャンネル |

## 一般

- **既定のブラウザ**: Lunascape を既定のブラウザーにします。詳しくは[既定のブラウザーに設定する](../getting-started/default-browser.md)を参照してください。
- **言語**: ブラウザーの表示言語を選びます。
- **タブ**: **アドレスバーから入力した際に新しいタブで開く** と、新しいタブで表示するページを選びます。

## About

- **バージョン**: 使っている Lunascape のバージョンと、**リリースノート** を確認できます。
- **更新チャンネル**: 受け取るバージョンの種類（stable・beta・dev）を選びます。詳しくは[アップデート](../getting-started/update.md)を参照してください。

## 外観

- ブックマークバーを表示する
- ブックマークバーにアイコンを表示する / タブにアイコンを表示する
- ツールバーに検索バーを表示する / ダッシュボードボタンを表示する

## 設定を初期化する

**設定** の **リセット** から、次の操作ができます。

- **すべての設定を初期化**: すべての設定が既定値に戻ります。取り消せません。
- **検索エンジンを既定に戻す**: 追加した検索エンジンは削除されます。
