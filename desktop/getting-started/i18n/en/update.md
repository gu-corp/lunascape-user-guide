# Update

Lunascape checks for a new version on its own and tells you when it finds one.

## Check by hand

1. Choose **Check for updates** from the menu (≡).
2. If a newer version exists, a confirmation appears. Choose **Yes** to start the download.
3. When the download finishes, **A new version is available** appears. **Restart now** applies the update immediately; **Later** applies it the next time you start Lunascape.

If you are already up to date, it says so instead.

## Update channel

**Settings** > **General** > **Update channel** decides which kind of build you receive. Leave it on the stable channel unless you have a reason not to.

## What changed

The release notes open on their own after an update. To read them again later, open **Settings** > **About** > **Release notes**.
