# The browser window

The window is made up of these parts, from top to bottom.

| Part | What it does |
| --- | --- |
| Tab bar | Holds the open tabs. Drag to reorder, or drag out of the window to detach |
| Toolbar | Back / forward / reload, the address bar, the search bar and the buttons |
| Address bar | Takes both a URL and a search term |
| Search bar | Searches with a chosen search engine. You can hide it from the settings |
| Bookmarks bar | Your frequently used bookmarks. Can be shown or hidden |
| Side panel | Shows extension panels such as the AI sidebar |
| Page area | Shows the web page |

## Toolbar buttons

- **Dashboard**: opens the new-tab dashboard. Show or hide it in **Settings** > **Appearance**.
- **Password manager**: opens your saved logins.
- **Extensions**: the buttons of the extensions you have installed.
- **Menu (≡)**: bookmarks, history, downloads, profiles and settings.

## The dashboard

Every new tab opens a dashboard: a search box, your most-used sites and a background image. Change the image in **Settings** > **Theme** > **Dashboard background**.
