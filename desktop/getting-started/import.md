# 他のブラウザーからデータを移行する

Chrome などのブラウザーから、ブックマーク・履歴・パスワードを取り込めます。

## 取り込む

1. メニュー（≡）から **ブックマークマネージャ** を開きます。
2. **インポート** を選びます。
3. 取り込み元のブラウザーと、取り込むプロファイルを選びます。
4. 取り込む項目（ブックマーク、履歴、パスワードなど）を選んで実行します。

> **注意:** パスワードはプロファイルごとではなく、すべてのプロファイルで共有されます。

## 取り込めるもの

| 項目 | 説明 |
| --- | --- |
| ブックマーク | フォルダー構成のまま取り込みます |
| 履歴 | 閲覧履歴を取り込みます |
| パスワード | 保存済みのログイン情報を取り込みます。取り込みには元のブラウザー側の許可が必要な場合があります |

## HTML ファイルから取り込む

他のブラウザーで書き出した HTML 形式のブックマークファイルも取り込めます。ブックマークマネージャの **インポート** からファイルを選んでください。
