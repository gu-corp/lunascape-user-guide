# 困ったときは

起動、アップデート、動作の重さ、拡張機能の不調 — 症状ごとの対処をまとめています。

- [起動できない](startup.md) — インストールが途中で終わっている可能性があります。次の手順で入れ直してください。
- [アップデートできない](updates.md) — 設定 > 一般 の 更新チャンネル を確認してください。チャンネルによって配信されるバージョンが異なります。
- [うまく動かない拡張機能がある](extensions.md) — 拡張機能の内部処理が停止している可能性があります。次の順に試してください。
- [動作が重い・応答しなくなる](performance.md) — そのタブを閉じて、症状が収まるか確認してください。ページ側の処理が繰り返し失敗していると、CPU 使用率が上がることがあります。改善しない場合は、Lunascape を再起動し…
