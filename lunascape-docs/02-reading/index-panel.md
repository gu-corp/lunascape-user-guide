# INDEX を使う

画面左の INDEX は、文書ルートにあるフォルダと文書のツリーです。

## 絞り込む

1. INDEX の上の [文書を絞り込み] に言葉を入力します。
2. 文書名が一致する項目だけが表示されます。入力を消すと元に戻ります。

> **ご注意**
>
> 絞り込み中は、ドラッグ＆ドロップによる並び替えはできません。

## フォルダを開閉する

- フォルダ名の左の矢印、または表紙のないフォルダ名を押すと開閉します。
- 表紙（本文のある `README.md` または `index.md`）があるフォルダは、名前を押すと表紙を開きます。開閉だけを行うには、項目メニューの [フォルダを開く] / [フォルダを閉じる] を使います。
- フォルダの開閉状態は利用者ごとに記憶され、Git 管理のファイルには書き込まれません。

## README とフォルダの表紙

`README.md` は、そのフォルダの中身を説明するファイルです。

- README があるフォルダは、フォルダ名を押すとその README が表示されます。
- README がないフォルダは、中の一番上の文書が表示されます。
- README の見出し（H1）は、INDEX に出るそのフォルダの名前になります。

README は必須ではありません。あとから追加するには、フォルダの項目メニューで [READMEを作成] を選びます（README のないフォルダにだけ表示されます）。

## INDEX を表示／非表示にする

- ツールバーのカラム表示にある左側のアイコンで、INDEX を表示／非表示にします。右側のアイコンは「このページ」の表示／非表示です。
- 画面が狭いときは、INDEX は閉じた状態で始まります。[戻る] の左に表示される [INDEXを開く]（三本線）を押すと、INDEX が本文の上に重なって開きます。INDEX 内の [×]、背景のクリック、`Esc`、または文書の移動で閉じます。この一時的な開閉は、広い画面での設定を変えません。
- 表示する文書が 1 件だけの文書ルートでは、初回だけ INDEX が自動的に閉じます。カラム表示のアイコンで開き直せます。この動作は [表示設定] の [文書が1件なら自動的に隠す] でオフにできます。

## 項目メニューを使う

INDEX の項目にマウスを重ねると表示される [⋯]、または項目の右クリックで、その項目のメニューを開きます。項目は次の順に並びます。

| グループ | 項目 |
|---|---|
| よく使う操作 | [フォルダを開く] / [フォルダを閉じる]、[INDEXを開く]（フォルダの表紙を開く）、[編集]、[タイトルを変更]、[VS Codeで開く]、[パスをコピー] |
| 作成・整理 | [READMEを作成]（README のないフォルダのみ）、[新しい文書]、[新しいフォルダ]、[複製]、[ファイル名を変更] / [フォルダ名を変更]、[1つ上へ移動]、[1つ下へ移動] |
| 削除 | [ゴミ箱へ移動] |

- 文書ルート直下に作成するには、INDEX の見出し右端の [⋯]、または INDEX の空白部分を右クリックし、[新しい文書] か [新しいフォルダ] を選びます。同じメニューに [文書名を変更] と、文書ルートに README がなければ [READMEを作成] が並びます。ツールバーに出ている文書名を右クリックしても、同じメニューが開きます。
- メニュー内は `↑` `↓` で移動し、`Home` `End` で先頭・末尾へ移動します。`Esc` で閉じると、開く前の位置にフォーカスが戻ります。

> **ご注意**
>
> 作成・整理・削除の項目は、VS Code でワークスペースを信頼している場合にだけ表示されます。文書の編集中や、別の INDEX 操作を処理している間も使えません。

## 見せかたを変える

[表示設定] から、ファイル名の表示、文書・フォルダのアイコン、フォルダ内の件数、階層ガイド線、表示密度を変更できます。詳しくは [表示設定を変更する](display-settings.md) を参照してください。
