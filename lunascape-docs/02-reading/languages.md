# 別の言語で読む

翻訳版がある文書は、ツールバーの言語メニュー（地球儀）から言語を切り替えて読めます。

## 言語を切り替える

1. ツールバーの言語メニューを押します。
   表示中のページの言語と、その根拠（翻訳版のパス、自動検出、プロジェクトの既定言語）が表示されます。
2. 読みたい言語を選びます。
   同じ文書の翻訳版が開きます。選んだ言語は記憶され、次に開く文書でも、翻訳版があればその言語で表示します。

言語の一覧には、その文書に翻訳版があるかどうかが表示されます。

| 表示 | 意味 |
|---|---|
| 翻訳あり | 翻訳版が存在し、開けます |
| 翻訳なし | プロジェクトの対応言語ですが、この文書の翻訳版はまだありません |
| 更新あり | 翻訳版はありますが、翻訳したあとに元の文書が変更されています |

> **ご注意**
>
> - 言語を選ぶ操作は、既にある翻訳版を開くだけです。翻訳を生成したり、ファイルを作成したりすることはありません。翻訳版を作るには、同じメニューの [翻訳を作成・管理…] を使います。
> - 表示中のページの言語がプロジェクトの既定言語と異なると判定されたときは、警告が表示されます。設定が書き換えられることはありません。

## 最初に表示される言語

文書を開いたとき、最初の表示言語は次の順で決まります。

1. この文書ルートで以前に自分で選んだ言語。選んだ内容は保存されます（既定言語を選んだ場合も、選択として保存されます）。
2. VS Code の表示言語（Web ブラウザ版では、ブラウザの言語設定）。対応言語と一致するものが自動選択されます。地域付きの言語（`en-US` など）は、基本言語（`en`）とも一致します。
3. プロジェクトのフォールバック言語（`lunascape-docs.json` の `fallbackLocale`）。
4. プロジェクトの既定言語。

> **ヒント**
>
> - 自動選択されたときは、言語メニューの現在の言語に「自動選択」と表示されます。バッジにポインターを載せると理由が表示されます。
> - `fallbackLocale` は、閲覧環境の言語が対応言語のどれとも一致しない読者に見せる言語です。日本語が正本で英語版を持つプロジェクトで `"en"` を設定すると、スペイン語などの環境の読者には英語版が開きます。未設定のときは既定言語が使われます。

## 翻訳版の置き場所

既定言語の文書はそのままの場所に置き、翻訳版は**同じフォルダーの `i18n/<言語>/`** に、同じファイル名で置きます。

```text
docs/
  README.md                  ← 既定言語（例: 日本語）
  i18n/en/README.md          ← その英語版
  guide/
    setup.md
    i18n/en/setup.md         ← その英語版
```

> **ご注意**
>
> - フォルダー構造を `i18n/` の下に作り直す形（`i18n/en/guide/setup.md`）では認識されません。`i18n/` は必ず、その文書と同じフォルダーに置きます。
> - 翻訳版の解決先は、この 1 か所だけです。親フォルダー側の `i18n/` に同じ文書の翻訳を置いても「どちらが優先されるか」の競合にはならず、そちらは言語メニューにも台帳にも現れない孤立ファイルになります（自動削除はされません）。同じ翻訳を 2 か所に置かないでください。

## Web ブラウザ版で読む場合

Web ブラウザ版でも、翻訳版があれば同じように切り替えられます。翻訳版がない言語で読みたいときは、ブラウザのページ翻訳機能を使えます。コード、数式、図は翻訳の対象から外れるようになっています。
