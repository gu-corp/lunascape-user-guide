# Промяна на настройките на изгледа

От [Настройки на изгледа] (зъбно колело) в лентата с инструменти всеки потребител може да промени вида на INDEX и показването на бутона за редактиране.

1. Натиснете [Настройки на изгледа] в лентата с инструменти.
2. Превключете елементите, които искате да промените. Промените се прилагат веднага.
3. Натиснете отново [Настройки на изгледа] или щракнете извън панела, за да го затворите.

## Налични настройки

| Раздел | Елемент | Действие |
|---|---|---|
| Език на документа | (текущо състояние) | Показва езика по подразбиране на проекта и текущо показвания език. [Настройване на езиците на проекта…] отваря езиковите настройки на проекта |
| Съдържание | [Имена на файловете] | Показва имената на файловете вместо заглавията на документите |
| | [Икони на документите] | Показва икона до всеки документ |
| | [Икони на папките] | Показва икона до всяка папка |
| | [Брой елементи в папките] | Показва броя на документите във всяка папка |
| | [Насоки за отстъпите] | Показва направляващи линии за нивата на влагане |
| | [Скриване при само един документ] | Затваря INDEX само при първото отваряне в коренна папка на документацията с един-единствен документ |
| | [Свиване на данните за документа] | Свива управляващата таблица в началото на документа в реда „Данни за документа“. Когато е изключено, таблицата се показва както е |
| | [Плътност на изгледа] | Избира разстоянието между редовете на INDEX измежду [Стандартен] / [Компактна] |
| | [Бутон за редактиране] | Показва [Редактиране] в долния десен ъгъл на документа |
| Действия | [Връщане към настройките по подразбиране на проекта] | Премахва всички ваши промени и връща настройките на проекта |
| | [Отваряне на настройките на разширението] | Отваря настройките на Lunascape Docs в екрана с настройки на VS Code |

> **Съвет**
>
> - Настройките на изгледа се запазват за всеки потребител и за всяка коренна папка на документацията и не се записват във файлове, управлявани от Git.
> - Настройките имат следния приоритет: „настройки на изгледа на потребителя → настройки на VS Code → `lunascape-docs.json` → настройки по подразбиране на продукта“. Общите за екипа стойности по подразбиране се задават в `tree` и `editor` в `lunascape-docs.json`.

## Превключване на цветовата схема

Натиснете превключвателя на темата (слънце/луна) в лентата с инструменти, за да превключите между бял фон и цветовата схема на VS Code. Цветовата схема при отваряне се определя от настройката `lunascapeDocEditor.appearance` (`light` или `auto`).
