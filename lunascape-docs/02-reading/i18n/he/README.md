# פעולות בסיסיות

הפעולות הבסיסיות מרגע פתיחת המסמכים ועד המעבר אל הדף שברצונכם לקרוא.

## פתיחת המסמכים

1. פתחו את המאגר ב־VS Code.
2. בלוח הפקודות (`⇧⌘P` / `Ctrl+Shift+P`) הריצו את "Lunascape Docs: פתיחת מציג המפרט".
   שורש התיעוד הקרוב ביותר (כברירת מחדל, תיקיית `docs`) נמצא, ודף הפתיחה מוצג.

> **טיפ**
>
> - לחצו לחיצה ימנית על קובץ Markdown בסייר ובחרו ב־[Lunascape Docs: פתיחה במציג המפרט] כדי לפתוח מאותו קובץ.
> - פתיחת קובץ Markdown שאינו שייך לשורש תיעוד מציגה את התיקייה שלו כשורש תיעוד זמני.

## מעבר בין דפים

| פעולה | אופן הביצוע |
|---|---|
| פתיחה מתוכן העניינים | לחצו על שם מסמך ב־INDEX שמשמאל |
| מעקב אחר קישור | לחצו על קישור בגוף הטקסט. הוא נפתח באותו מסך |
| מעבר בהיסטוריה | [חזרה] ו־[קדימה] בסרגל הכלים, או `Alt`+`←` / `Alt`+`→` |
| חזרה לדף הפתיחה | [דף הבית של המפרט] בסרגל הכלים |
| מעבר לרמה שמעל | [INDEX ההורה] בסרגל הכלים, או פריט בשביל הניווט |
| מעבר בתוך הדף | לחצו על כותרת ב"בדף זה" שמימין |

## חיפוש מסמך

הקלידו מילה ב־[סינון מסמכים] שמעל ה־INDEX, ויוצגו רק הפריטים ששם המסמך שלהם תואם. מחיקת הטקסט מחזירה את התצוגה למצבה הקודם.

## עדכון לתוכן העדכני

כאשר אתם שומרים קובץ Markdown בעורך של VS Code, התצוגה מתעדכנת אוטומטית. לאחר שינוי בכלי חיצוני, לחצו על [טעינה מחדש] בסרגל הכלים.

> **שימו לב**
>
> - קישורים חיצוניים בגוף הטקסט (כגון `https://`) נפתחים בדפדפן ברירת המחדל. קישורים לקבצים שמחוץ לשורש התיעוד אינם נפתחים.
> - המסמך שאתם קוראים מעובד במכשיר שלכם. לצורך הקריאה לא נשלח שום מסמך החוצה.
