# שינוי הגדרות התצוגה

דרך [הגדרות תצוגה] (גלגל השיניים) שבסרגל הכלים אפשר לשנות, לכל משתמש בנפרד, את אופן ההצגה של INDEX ואת הצגתו של לחצן העריכה.

1. לחצו על [הגדרות תצוגה] שבסרגל הכלים.
2. החליפו את מצבם של הפריטים שברצונכם לשנות. השינוי נכנס לתוקף מיד.
3. לחצו שוב על [הגדרות תצוגה], או לחצו מחוץ ללוח, כדי לסגור אותו.

## הפריטים שניתן להגדיר

| קטגוריה | פריט | תפקיד |
|---|---|---|
| שפת המסמך | (המצב הנוכחי) | מציג את שפת ברירת המחדל של הפרויקט ואת השפה המוצגת כעת. [הגדרת שפות הפרויקט…] פותח את הגדרות השפה של הפרויקט |
| תוכן | [שמות קבצים] | מציג את שם הקובץ במקום שם המסמך |
| | [סמלי מסמכים] | מציג סמל בפריטי המסמכים |
| | [סמלי תיקיות] | מציג סמל בפריטי התיקיות |
| | [מספר הפריטים בתיקייה] | מציג את מספר המסמכים שבתיקייה |
| | [קווי היררכיה] | מציג קווי הנחיה המסמנים את ההיררכיה |
| | [הסתרה אוטומטית כשיש מסמך אחד בלבד] | בשורש תיעוד שיש בו מסמך אחד בלבד, סוגר את INDEX אוטומטית בפתיחה הראשונה בלבד |
| | [כיווץ פרטי המסמך] | מכווץ את טבלת הניהול שבראש המסמך לשורת "פרטי המסמך". כשהאפשרות כבויה, הטבלה מוצגת כמות שהיא |
| | [צפיפות התצוגה] | בחירת מרווח השורות ב-INDEX מבין [רגיל] / [מצומצמת] |
| | [לחצן העריכה] | מציג את [עריכה] בפינה הימנית התחתונה של גוף המסמך |
| פעולות | [חזרה לברירות המחדל של הפרויקט] | מוחק את כל שינויי המשתמש ומחזיר את הגדרות הפרויקט |
| | [פתיחת הגדרות ההרחבה] | פותח את הגדרות Lunascape Docs במסך ההגדרות של VS Code |

> **עצה**
>
> - הגדרות התצוגה נשמרות לכל משתמש ולכל שורש תיעוד בנפרד, ואינן נכתבות לקבצים המנוהלים ב-Git.
> - סדר הקדימות של ההגדרות הוא "הגדרות התצוגה של המשתמש ← הגדרות VS Code ← `lunascape-docs.json` ← ברירות המחדל של המוצר". ברירות המחדל המשותפות לצוות נקבעות ב-`tree` וב-`editor` שבתוך `lunascape-docs.json`.

## החלפת ערכת הצבעים

לחיצה על מתג ערכת הנושא (שמש/ירח) שבסרגל הכלים מחליפה בין רקע לבן לבין ערכת הצבעים של VS Code. ערכת הצבעים בעת הפתיחה נקבעת בהגדרה `lunascapeDocEditor.appearance` (`light` או `auto`).
