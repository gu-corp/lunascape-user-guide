# Operasi dasar

Operasi dasar mulai dari membuka dokumen hingga sampai ke halaman yang ingin Anda baca.

## Membuka dokumen

1. Buka repositori di VS Code.
2. Jalankan "Lunascape Docs: Buka Penampil Spesifikasi" melalui Palet Perintah (`⇧⌘P` / `Ctrl+Shift+P`).
   Root dokumentasi terdekat (secara bawaan folder `docs`) akan ditemukan dan halaman awalnya ditampilkan.

> **Tip**
>
> - Klik kanan berkas Markdown di Explorer, lalu pilih [Lunascape Docs: Buka di Penampil Spesifikasi] untuk mulai dari berkas tersebut.
> - Jika Anda membuka berkas Markdown yang tidak termasuk dalam root dokumentasi mana pun, foldernya akan ditampilkan sebagai root dokumentasi sementara.

## Berpindah halaman

| Operasi | Cara |
|---|---|
| Membuka dari daftar isi | Tekan nama dokumen pada INDEX di sebelah kiri |
| Mengikuti tautan | Tekan tautan di dalam teks. Tautan terbuka pada tampilan yang sama |
| Menelusuri riwayat | [Kembali] dan [Maju] pada bilah alat, atau `Alt`+`←` / `Alt`+`→` |
| Kembali ke halaman awal | [Beranda spesifikasi] pada bilah alat |
| Naik satu tingkat | [INDEX induk] pada bilah alat, atau item pada tautan jejak |
| Berpindah di dalam halaman | Tekan judul pada "Di halaman ini" di sebelah kanan |

## Mencari dokumen

Ketik kata pada [Saring dokumen] di atas INDEX untuk menampilkan hanya dokumen yang namanya cocok. Kosongkan isian tersebut untuk menampilkan semuanya kembali.

## Memperbarui ke konten terbaru

Ketika Anda menyimpan berkas Markdown di editor VS Code, tampilan diperbarui secara otomatis. Jika berkas diubah dengan alat lain, tekan [Muat ulang] pada bilah alat.

> **Catatan**
>
> - Tautan eksternal di dalam teks (misalnya `https://`) terbuka di peramban bawaan Anda. Tautan ke berkas di luar root dokumentasi tidak akan terbuka.
> - Dokumen yang Anda baca diproses di dalam perangkat Anda. Tidak ada dokumen yang dikirim ke luar untuk keperluan membaca.
