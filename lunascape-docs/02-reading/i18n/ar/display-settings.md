# تغيير إعدادات العرض

من [إعدادات العرض] (رمز الترس) في شريط الأدوات، يمكن لكل مستخدم تغيير طريقة ظهور INDEX وإظهار زر التحرير.

1. اضغط [إعدادات العرض] في شريط الأدوات.
2. بدّل العناصر التي تريد تغييرها. يُطبَّق التغيير فورًا.
3. اضغط [إعدادات العرض] مرة أخرى، أو اضغط خارج اللوحة لإغلاقها.

## العناصر القابلة للضبط

| القسم | العنصر | الوظيفة |
|---|---|---|
| لغة المستند | (الحالة الراهنة) | تعرض اللغة الافتراضية للمشروع واللغة المعروضة حاليًا. ويفتح [ضبط لغات المشروع…] إعدادات لغات المشروع |
| المحتوى | [أسماء الملفات] | تعرض أسماء الملفات بدلًا من أسماء المستندات |
| | [أيقونات المستندات] | تعرض أيقونة بجانب كل مستند |
| | [أيقونات المجلدات] | تعرض أيقونة بجانب كل مجلد |
| | [عدد العناصر] | يعرض عدد المستندات داخل كل مجلد |
| | [أدلة المستويات] | تعرض خطوط دليل تبيّن مستويات التداخل |
| | [الإخفاء عند وجود مستند واحد فقط] | يغلق INDEX تلقائيًا في المرة الأولى فقط، في جذر توثيق يحتوي على مستند واحد |
| | [طيّ تفاصيل المستند] | يطوي جدول الإدارة الموجود في أعلى المستند إلى سطر «تفاصيل المستند». وعند إيقافه يُعرض الجدول كما هو |
| | [كثافة العرض] | اختر تباعد الأسطر في INDEX من [عادي] / [مضغوط] |
| | [زر التحرير] | يعرض [تحرير] أسفل يسار المتن |
| الإجراءات | [العودة إلى إعدادات المشروع الافتراضية] | يمحو كل تغييرات المستخدم ويعيد إعدادات المشروع |
| | [فتح إعدادات الإضافة] | يفتح إعدادات Lunascape Docs في شاشة إعدادات VS Code |

> **تلميح**
>
> - تُحفظ إعدادات العرض لكل مستخدم ولكل جذر توثيق، ولا تُكتب في ملفات يديرها Git.
> - تُطبَّق الإعدادات بالترتيب التالي: «إعدادات عرض المستخدم ← إعدادات VS Code ← `lunascape-docs.json` ← الإعدادات الافتراضية للمنتج». وتُحدَّد القيم الافتراضية المشتركة للفريق في `tree` و`editor` داخل `lunascape-docs.json`.

## تبديل نسق الألوان

اضغط زر تبديل النسق (الشمس/القمر) في شريط الأدوات للتبديل بين الخلفية البيضاء ونسق ألوان VS Code. ويُحدَّد النسق عند الفتح بالإعداد `lunascapeDocEditor.appearance` (`light` أو `auto`).
