# استخدام INDEX

‏INDEX الموجود على يسار الشاشة هو شجرة المجلدات والمستندات الموجودة في جذر التوثيق.

## التصفية

1. اكتب كلمة في [تصفية المستندات] أعلى INDEX.
2. تظهر العناصر التي يطابق اسمها الكلمة فقط. امسح ما كتبته لتعود القائمة كما كانت.

> **ملاحظة**
>
> لا يمكن إعادة الترتيب بالسحب والإفلات أثناء التصفية.

## فتح المجلدات وإغلاقها

- اضغط السهم الموجود على يسار اسم المجلد، أو اسم مجلد لا غلاف له، لفتحه أو إغلاقه.
- المجلد الذي له غلاف (ملف `README.md` أو `index.md` يحتوي على نص) يفتح غلافه عند الضغط على اسمه. ولفتحه أو إغلاقه فقط، استخدم [فتح المجلد] / [إغلاق المجلد] في قائمة العنصر.
- تُحفظ حالة الفتح والإغلاق لكل مستخدم على حدة، ولا تُكتب في الملفات الخاضعة لإدارة Git.

## ‏README وغلاف المجلد

`README.md` هو الملف الذي يشرح محتوى المجلد.

- المجلد الذي فيه README يعرض ذلك الملف عند الضغط على اسم المجلد.
- المجلد الذي لا README فيه يعرض أول مستند بداخله.
- يصبح عنوان README (H1) هو اسم ذلك المجلد في INDEX.

وجود README ليس إلزاميًا. ولإضافته لاحقًا، اختر [إنشاء README] من قائمة عنصر المجلد (تظهر للمجلدات التي لا README فيها فقط).

## إظهار INDEX أو إخفاؤه

- الأيقونة اليسرى في أزرار الأعمدة بشريط الأدوات تُظهر INDEX أو تُخفيه. والأيقونة اليمنى تُظهر «في هذه الصفحة» أو تُخفيها.
- عندما تكون الشاشة ضيقة، يبدأ INDEX مغلقًا. اضغط [فتح INDEX] (الخطوط الثلاثة) الظاهر على يسار [رجوع]، فينفتح INDEX فوق نص المستند. ويُغلق بالضغط على [×] داخل INDEX، أو بالنقر على الخلفية، أو بمفتاح `Esc`، أو بالانتقال إلى مستند آخر. وهذا الفتح المؤقت لا يغيّر الإعداد الخاص بالشاشات العريضة.
- في جذر التوثيق الذي لا يعرض سوى مستند واحد، يُغلق INDEX تلقائيًا في المرة الأولى فقط. ويمكن فتحه من جديد بأيقونة الأعمدة. ويمكن إيقاف هذا السلوك من [إعدادات العرض] عبر [الإخفاء عند وجود مستند واحد فقط].

## استخدام قائمة العنصر

افتح قائمة العنصر بالضغط على [⋯] الذي يظهر عند تمرير المؤشر فوق عنصر في INDEX، أو بالنقر بالزر الأيمن على العنصر. وتُرتَّب العناصر على النحو التالي.

| المجموعة | العناصر |
|---|---|
| العمليات المتكررة | [فتح المجلد] / [إغلاق المجلد]، [فتح INDEX] (فتح غلاف المجلد)، [تحرير]، [تغيير العنوان]، [فتح في VS Code]، [نسخ المسار] |
| الإنشاء والتنظيم | [إنشاء README] (للمجلدات التي لا README فيها فقط)، [مستند جديد]، [مجلد جديد]، [تكرار]، [تغيير اسم الملف] / [تغيير اسم المجلد]، [نقل لأعلى بمقدار واحد]، [نقل لأسفل بمقدار واحد] |
| الحذف | [نقل إلى سلة المحذوفات] |

- للإنشاء مباشرة تحت جذر التوثيق، اضغط [⋯] في أقصى يمين عنوان INDEX، أو انقر بالزر الأيمن على مساحة فارغة في INDEX، ثم اختر [مستند جديد] أو [مجلد جديد]. وتضم القائمة نفسها [تغيير اسم المستند]، كما تضم [إنشاء README] إن لم يكن في جذر التوثيق ملف README. وتنفتح القائمة نفسها أيضًا بالنقر بالزر الأيمن على اسم المستند الظاهر في شريط الأدوات.
- داخل القائمة، يتنقل `↑` `↓` بين العناصر، وينقل `Home` `End` إلى أولها وآخرها. وعند الإغلاق بمفتاح `Esc` يعود التركيز إلى الموضع الذي كان عليه قبل الفتح.

> **ملاحظة**
>
> لا تظهر عناصر الإنشاء والتنظيم والحذف إلا إذا كانت مساحة العمل موثوقة في VS Code. كما لا يمكن استخدامها أثناء تحرير مستند أو أثناء تنفيذ عملية أخرى في INDEX.

## تغيير طريقة العرض

من [إعدادات العرض] يمكنك تغيير إظهار أسماء الملفات، وأيقونات المستندات والمجلدات، وعدد العناصر داخل المجلد، وخطوط دليل المستويات، وكثافة العرض. للتفاصيل، راجع [تغيير إعدادات العرض](display-settings.md).
