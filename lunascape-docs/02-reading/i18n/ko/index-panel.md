# INDEX 사용하기

화면 왼쪽의 INDEX는 문서 루트에 있는 폴더와 문서의 트리입니다.

## 필터링하기

1. INDEX 위의 [문서 필터링]에 단어를 입력합니다.
2. 문서 이름이 일치하는 항목만 표시됩니다. 입력한 내용을 지우면 원래대로 돌아갑니다.

> **참고**
>
> 필터링 중에는 끌어서 놓기로 정렬 순서를 바꿀 수 없습니다.

## 폴더 펼치기 및 접기

- 폴더 이름 왼쪽의 화살표, 또는 표지가 없는 폴더의 이름을 누르면 펼쳐지거나 접힙니다.
- 표지(본문이 있는 `README.md` 또는 `index.md`)가 있는 폴더는 이름을 누르면 표지가 열립니다. 펼치거나 접기만 하려면 항목 메뉴의 [폴더 펼치기] / [폴더 접기]를 사용합니다.
- 폴더의 펼침 상태는 사용자별로 기억되며 Git으로 관리되는 파일에는 기록되지 않습니다.

## README와 폴더 표지

`README.md`는 해당 폴더의 내용을 설명하는 파일입니다.

- README가 있는 폴더는 폴더 이름을 누르면 그 README가 표시됩니다.
- README가 없는 폴더는 그 안의 맨 위 문서가 표시됩니다.
- README의 제목(H1)은 INDEX에 표시되는 해당 폴더의 이름이 됩니다.

README는 필수가 아닙니다. 나중에 추가하려면 폴더의 항목 메뉴에서 [README 만들기]를 선택합니다(README가 없는 폴더에만 표시됩니다).

## INDEX 표시하기 / 숨기기

- 도구 모음의 칼럼 표시에 있는 왼쪽 아이콘으로 INDEX를 표시하거나 숨깁니다. 오른쪽 아이콘은 "이 페이지"의 표시 및 숨김입니다.
- 화면이 좁을 때는 INDEX가 닫힌 상태로 시작합니다. [뒤로] 왼쪽에 표시되는 [INDEX 열기](세 줄)를 누르면 INDEX가 본문 위에 겹쳐져 열립니다. INDEX 안의 [×], 배경 클릭, `Esc`, 또는 문서 이동으로 닫힙니다. 이 일시적인 열기와 닫기는 넓은 화면에서의 설정을 바꾸지 않습니다.
- 표시할 문서가 1개뿐인 문서 루트에서는 처음 한 번만 INDEX가 자동으로 닫힙니다. 칼럼 표시 아이콘으로 다시 열 수 있습니다. 이 동작은 [표시 설정]의 [문서가 1개뿐이면 자동으로 숨기기]에서 끌 수 있습니다.

## 항목 메뉴 사용하기

INDEX의 항목에 마우스를 올리면 표시되는 [⋯], 또는 항목을 마우스 오른쪽 버튼으로 클릭하면 해당 항목의 메뉴가 열립니다. 항목은 다음 순서로 나열됩니다.

| 그룹 | 항목 |
|---|---|
| 자주 사용하는 조작 | [폴더 펼치기] / [폴더 접기], [INDEX 열기](폴더의 표지 열기), [편집], [제목 변경], [VS Code에서 열기], [경로 복사] |
| 만들기 및 정리 | [README 만들기](README가 없는 폴더만), [새 문서], [새 폴더], [복제], [파일 이름 변경] / [폴더 이름 변경], [위로 이동], [아래로 이동] |
| 삭제 | [휴지통으로 이동] |

- 문서 루트 바로 아래에 만들려면 INDEX 제목 오른쪽 끝의 [⋯], 또는 INDEX의 빈 부분을 마우스 오른쪽 버튼으로 클릭하고 [새 문서] 또는 [새 폴더]를 선택합니다. 같은 메뉴에 [문서 이름 변경]과, 문서 루트에 README가 없으면 [README 만들기]가 함께 표시됩니다. 도구 모음에 표시된 문서 이름을 마우스 오른쪽 버튼으로 클릭해도 같은 메뉴가 열립니다.
- 메뉴 안에서는 `↑` `↓`로 이동하고, `Home` `End`로 처음과 끝으로 이동합니다. `Esc`로 닫으면 열기 전의 위치로 포커스가 돌아갑니다.

> **참고**
>
> 만들기, 정리, 삭제 항목은 VS Code에서 작업 영역을 신뢰하고 있는 경우에만 표시됩니다. 문서를 편집하는 중이거나 다른 INDEX 조작을 처리하는 동안에도 사용할 수 없습니다.

## 보이는 방식 바꾸기

[표시 설정]에서 파일 이름 표시, 문서 및 폴더 아이콘, 폴더 안의 항목 수, 계층 안내선, 표시 밀도를 변경할 수 있습니다. 자세한 내용은 [표시 설정 변경하기](display-settings.md)를 참조하십시오.
