# 다른 언어로 읽기

번역본이 있는 문서는 도구 모음의 언어 메뉴(지구본)에서 언어를 전환하여 읽을 수 있습니다.

## 언어 전환

1. 도구 모음의 언어 메뉴를 누릅니다.
   표시 중인 페이지의 언어와 그 근거(번역본 경로, 자동 감지, 프로젝트 기본 언어)가 표시됩니다.
2. 읽고 싶은 언어를 선택합니다.
   같은 문서의 번역본이 열립니다. 선택한 언어는 기억되며, 다음에 여는 문서에서도 번역본이 있으면 그 언어로 표시합니다.

언어 목록에는 해당 문서에 번역본이 있는지 여부가 표시됩니다.

| 표시 | 의미 |
|---|---|
| 번역 있음 | 번역본이 존재하며 열 수 있습니다 |
| 번역 없음 | 프로젝트가 지원하는 언어이지만, 이 문서의 번역본은 아직 없습니다 |
| 업데이트 있음 | 번역본은 있지만, 번역한 이후에 원본 문서가 변경되었습니다 |

> **참고**
>
> - 언어를 선택하는 조작은 이미 있는 번역본을 열 뿐입니다. 번역을 생성하거나 파일을 만들지 않습니다. 번역본을 만들려면 같은 메뉴의 [번역 생성·관리…]를 사용합니다.
> - 표시 중인 페이지의 언어가 프로젝트 기본 언어와 다르다고 판정되면 경고가 표시됩니다. 설정이 변경되는 일은 없습니다.

## 처음에 표시되는 언어

문서를 열 때, 처음 표시 언어는 다음 순서로 결정됩니다.

1. 이 문서 루트에서 이전에 직접 선택한 언어. 선택한 내용은 저장됩니다(기본 언어를 선택한 경우에도 선택으로 저장됩니다).
2. VS Code의 표시 언어(웹 브라우저 버전에서는 브라우저의 언어 설정). 지원 언어와 일치하는 것이 자동 선택됩니다. 지역이 포함된 언어(`en-US` 등)는 기본 언어(`en`)와도 일치합니다.
3. 프로젝트의 폴백 언어(`lunascape-docs.json`의 `fallbackLocale`).
4. 프로젝트의 기본 언어.

> **팁**
>
> - 자동 선택되었을 때는 언어 메뉴의 현재 언어에 '자동 선택'이라고 표시됩니다. 배지에 포인터를 올리면 이유가 표시됩니다.
> - `fallbackLocale`은 열람 환경의 언어가 지원 언어 중 어느 것과도 일치하지 않는 독자에게 보여줄 언어입니다. 일본어가 정본이고 영어판을 가진 프로젝트에서 `"en"`을 설정하면, 스페인어 등의 환경 독자에게는 영어판이 열립니다. 설정하지 않은 경우에는 기본 언어가 사용됩니다.

## 번역본을 두는 위치

기본 언어 문서는 원래 위치에 두고, 번역본은 **같은 폴더의 `i18n/<언어>/`**에 같은 파일 이름으로 둡니다.

```text
docs/
  README.md                  ← 기본 언어(예: 일본어)
  i18n/en/README.md          ← 그 영어판
  guide/
    setup.md
    i18n/en/setup.md         ← 그 영어판
```

> **참고**
>
> - 폴더 구조를 `i18n/` 아래에 다시 만드는 형태(`i18n/en/guide/setup.md`)는 인식되지 않습니다. `i18n/`는 반드시 해당 문서와 같은 폴더에 둡니다.
> - 번역본이 해석되는 위치는 이 한 곳뿐입니다. 상위 폴더의 `i18n/`에 같은 문서의 번역을 두어도 "어느 쪽이 우선되는가"의 충돌은 발생하지 않으며, 그쪽은 언어 메뉴에도 대장에도 나타나지 않는 고립된 파일이 됩니다(자동으로 삭제되지 않습니다). 같은 번역을 두 곳에 두지 마십시오.

## 웹 브라우저 버전에서 읽는 경우

웹 브라우저 버전에서도 번역본이 있으면 같은 방식으로 전환할 수 있습니다. 번역본이 없는 언어로 읽고 싶을 때는 브라우저의 페이지 번역 기능을 사용할 수 있습니다. 코드, 수식, 다이어그램은 번역 대상에서 제외됩니다.
