# 기본 조작

문서를 열고 나서 읽고 싶은 페이지로 이동하기까지의 기본 조작입니다.

## 문서 열기

1. VS Code에서 리포지토리를 엽니다.
2. 명령 팔레트(`⇧⌘P` / `Ctrl+Shift+P`)에서 "Lunascape Docs: 사양서 뷰어 열기"를 실행합니다.
   가장 가까운 문서 루트(기본값은 `docs` 폴더)를 찾아 시작 페이지를 표시합니다.

> **힌트**
>
> - 탐색기에서 Markdown 파일을 마우스 오른쪽 버튼으로 클릭하고 [Lunascape Docs: 사양서 뷰어로 열기]를 선택하면 해당 파일부터 열 수 있습니다.
> - 문서 루트에 속하지 않는 Markdown 파일을 열면 그 폴더를 임시 문서 루트로 표시합니다.

## 페이지 이동하기

| 조작 | 방법 |
|---|---|
| 목차에서 열기 | 왼쪽 INDEX에서 문서 이름을 누릅니다 |
| 링크 따라가기 | 본문의 링크를 누릅니다. 같은 화면에서 열립니다 |
| 기록 따라가기 | 도구 모음의 [뒤로] [앞으로], 또는 `Alt`+`←` / `Alt`+`→` |
| 시작 페이지로 돌아가기 | 도구 모음의 [사양서 홈] |
| 상위 계층으로 이동 | 도구 모음의 [상위 INDEX], 또는 이동 경로의 항목 |
| 페이지 안에서 이동 | 오른쪽 "이 페이지"에서 제목을 누릅니다 |

## 문서 찾기

INDEX 위의 [문서 필터링]에 단어를 입력하면 문서 이름이 일치하는 항목만 표시됩니다. 입력을 지우면 원래대로 돌아갑니다.

## 최신 내용으로 갱신하기

Markdown 파일을 VS Code 편집기에서 저장하면 표시가 자동으로 갱신됩니다. 외부 도구로 변경했을 때는 도구 모음의 [다시 불러오기]를 누릅니다.

> **참고**
>
> - 본문의 외부 링크(`https://` 등)는 기본 브라우저에서 열립니다. 문서 루트 밖에 있는 파일로의 링크는 열리지 않습니다.
> - 열람 중인 문서는 사용자의 기기 안에서 처리됩니다. 열람을 위해 문서를 외부로 보내지 않습니다.
