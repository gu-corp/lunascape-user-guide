# 표시 설정 변경하기

도구 모음의 [표시 설정] 버튼(톱니바퀴)에서 INDEX의 표시 방식과 편집 버튼 표시 여부를 사용자별로 변경할 수 있습니다.

1. 도구 모음의 [표시 설정]을 누릅니다.
2. 변경할 항목을 전환합니다. 변경 내용은 바로 반영됩니다.
3. [표시 설정]을 다시 누르거나 패널 바깥을 눌러 닫습니다.

## 설정할 수 있는 항목

| 구분 | 항목 | 기능 |
|---|---|---|
| 문서 언어 | (현재 상태) | 프로젝트의 기본 언어와 표시 중인 언어를 표시합니다. [프로젝트 언어 설정…]에서 프로젝트의 언어 설정을 엽니다 |
| 콘텐츠 | [파일 이름] | 문서 이름 대신 파일 이름을 표시합니다 |
| | [문서 아이콘] | 문서 항목에 아이콘을 표시합니다 |
| | [폴더 아이콘] | 폴더 항목에 아이콘을 표시합니다 |
| | [폴더 내 항목 수] | 폴더에 포함된 문서 수를 표시합니다 |
| | [계층 가이드] | 계층을 나타내는 가이드선을 표시합니다 |
| | [문서가 1개뿐이면 자동으로 숨기기] | 문서가 1개뿐인 문서 루트에서 INDEX를 처음 한 번만 자동으로 닫습니다 |
| | [문서 정보 접기] | 문서 첫머리의 관리 표를 "문서 정보" 행으로 접습니다. 끄면 표를 그대로 표시합니다 |
| | [표시 밀도] | INDEX의 행 간격을 [보통] / [컴팩트] 중에서 선택합니다 |
| | [편집 버튼] | 본문 오른쪽 아래에 [편집]을 표시합니다 |
| 조작 | [프로젝트 기본값으로 되돌리기] | 사용자의 변경을 모두 지우고 프로젝트 설정으로 되돌립니다 |
| | [확장 설정 열기] | VS Code의 설정 화면에서 Lunascape Docs 설정을 엽니다 |

> **힌트**
>
> - 표시 설정은 사용자별·문서 루트별로 저장되며, Git으로 관리되는 파일에는 기록하지 않습니다.
> - 설정은 "사용자의 표시 설정 → VS Code 설정 → `lunascape-docs.json` → 제품 기본값" 순으로 우선합니다. 팀 공통 기본값은 `lunascape-docs.json`의 `tree`와 `editor`에서 정합니다.

## 색 구성 전환하기

도구 모음의 테마 전환(해/달)을 누르면 흰 배경과 VS Code의 색 구성을 전환합니다. 열었을 때의 색 구성은 설정 `lunascapeDocEditor.appearance`(`light` 또는 `auto`)로 정해집니다.
