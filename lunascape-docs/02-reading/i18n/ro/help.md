# Afișarea ajutorului

Acest ghid de ajutor este inclus în extensie și se citește în aceeași vizualizare ca documentele obișnuite.

## Deschiderea ajutorului

Folosiți una dintre metodele următoare.

- Apăsați [Ajutor] (?) din capătul din dreapta al barei de instrumente.
- Executați „Lunascape Docs: Deschide ajutorul” din paleta de comenzi.

Cât timp ajutorul este deschis, INDEX, legăturile din text, „Pe această pagină” și [Înapoi] [Înainte] funcționează la fel ca pentru documentele obișnuite. Istoricul de navigare al ajutorului este păstrat separat de documentele proiectului, iar ajutorul nu este adăugat niciodată în lista rădăcinilor documentației.

## Închiderea ajutorului

Apăsați din nou [Ajutor] din bara de instrumente sau apăsați [×] afișat în dreapta acestuia. Reveniți la documentul pe care îl citeați înainte de a deschide ajutorul, în aceeași poziție de derulare.

## Schimbarea limbii ajutorului

Pe lângă japoneză și engleză, ajutorul include limbile pe care VS Code le oferă ca limbi ale interfeței. Puteți schimba limba oricând, fără a părăsi pagina pe care o citiți.

1. Apăsați meniul de limbi (globul) din bara de instrumente.
2. Alegeți limba în care doriți să citiți.
   Aceeași pagină este afișată în limba aleasă, în aceeași poziție de citire.

> **Sfat**
>
> Limba aleasă este memorată și folosită la următoarea deschidere a ajutorului. Dacă nu ați schimbat-o niciodată, limba este aleasă în ordinea: limba documentului afișat, limba interfeței VS Code, apoi japoneza.
>
> Schimbarea limbii ajutorului nu schimbă limba în care sunt citite documentele proiectului.

> **Notă**
>
> Ajutorul este doar pentru citire. Editarea, traducerea, verificările și operațiile similare nu sunt disponibile cât timp este afișat ajutorul.
