# Основні операції

Основні дії від відкриття документів до переходу на сторінку, яку ви хочете прочитати.

## Відкрити документи

1. Відкрийте репозиторій у VS Code.
2. У палітрі команд (`⇧⌘P` / `Ctrl+Shift+P`) виконайте «Lunascape Docs: Відкрити переглядач специфікації».
   Буде знайдено найближчий корінь документації (типово — папка `docs`) і показано його початкову сторінку.

> **Порада**
>
> - Клацніть правою кнопкою миші файл Markdown у провіднику та виберіть [Lunascape Docs: Відкрити в переглядачі специфікації], щоб почати з цього файлу.
> - Якщо відкрити файл Markdown, який не належить до жодного кореня документації, його папка тимчасово показується як корінь документації.

## Переходити між сторінками

| Дія | Спосіб |
|---|---|
| Відкрити зі змісту | Натисніть назву документа в INDEX ліворуч |
| Перейти за посиланням | Натисніть посилання в тексті. Воно відкриється в тому самому вікні |
| Переглянути історію | [Назад] і [Вперед] на панелі інструментів або `Alt`+`←` / `Alt`+`→` |
| Повернутися на початкову сторінку | [Головна специфікації] на панелі інструментів |
| Піднятися на рівень вище | [Батьківський INDEX] на панелі інструментів або елемент навігаційного ланцюжка |
| Переходити в межах сторінки | Натисніть заголовок у «На цій сторінці» праворуч |

## Знайти документ

Введіть слово в поле [Фільтрувати документи] над INDEX, щоб показати лише документи з відповідними назвами. Очистіть поле, щоб повернути початковий вигляд.

## Оновити вміст

Коли ви зберігаєте файл Markdown у редакторі VS Code, вигляд оновлюється автоматично. Якщо файли змінено зовнішнім інструментом, натисніть [Перезавантажити] на панелі інструментів.

> **Примітка**
>
> - Зовнішні посилання в тексті (`https://` тощо) відкриваються у браузері за замовчуванням. Посилання на файли поза коренем документації не відкриваються.
> - Документи, які ви переглядаєте, обробляються на вашому пристрої. Для читання документа нічого нікуди не надсилається.
