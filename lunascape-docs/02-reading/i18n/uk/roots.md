# Перемикання кореня документації

Корінь документації — це верхня папка одного набору документів. INDEX, фільтрування, перевірки та переклад працюють у межах одного кореня документації.

## Як знаходиться корінь документації

Lunascape Docs піднімається вгору від відкритого файлу Markdown і робить коренем документації найближчу папку, яка відповідає одній з таких умов.

- Папка, що містить `lunascape-docs.json` (назва папки будь-яка)
- Папка з назвою `docs` (інші назви можна додати параметром `lunascapeDocEditor.rootDirectoryNames`)

Коли ви виконуєте команду «Lunascape Docs: Відкрити переглядач специфікації», відкривається корінь документації з параметра `lunascapeDocEditor.root` (за замовчуванням `docs`).

## Перемикання на інший корінь документації

Якщо в робочій області кілька коренів документації, назва кореня ліворуч на панелі інструментів стає розкривним списком.

1. Натисніть назву кореня документації ліворуч на панелі інструментів.
2. Виберіть корінь документації зі списку.
   Відкриється його початкова сторінка, і INDEX перемкнеться.

> **Порада**
>
> Назви у списку визначаються в такому порядку. Вони не змінюються при зміні мови інтерфейсу.
>
> 1. `title` у `lunascape-docs.json`
> 2. `navigation.title` файлу `README.md` у корені, інакше його H1
> 3. `navigation.title` файлу `index.md` у корені, інакше його H1
> 4. Назва папки (для стандартної папки `docs` — назва батьківської папки)

## Відкриття файлу Markdown поза коренем документації

Якщо відкрити файл Markdown, який не входить до кореня документації, його папка тимчасово показується як корінь документації. В INDEX перелічуються файли Markdown у цій папці та нижче.

- Натисніть [Вгору на одну папку] на панелі інструментів, щоб розширити область показу до батьківської папки в межах робочої області.
- У цьому режимі мовні параметри проєкту та пакетний переклад недоступні. Помістіть `lunascape-docs.json` у папку, щоб зробити її коренем документації та увімкнути їх.

## Постійне відкриття одного кореня документації

Установіть для параметра `lunascapeDocEditor.rootMode` значення `fixed`, щоб завжди відкривався корінь документації з `lunascapeDocEditor.root`, який би файл Markdown ви не відкрили.
