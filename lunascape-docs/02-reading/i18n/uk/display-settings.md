# Зміна параметрів відображення

За допомогою кнопки [Параметри відображення] (шестірня) на панелі інструментів кожен користувач може змінити вигляд INDEX і показ кнопки редагування.

1. Натисніть [Параметри відображення] на панелі інструментів.
2. Перемкніть потрібні пункти. Зміни застосовуються одразу.
3. Натисніть [Параметри відображення] ще раз або клацніть поза панеллю, щоб закрити її.

## Доступні параметри

| Розділ | Пункт | Дія |
|---|---|---|
| Мова документа | (поточний стан) | Показує мову за замовчуванням проєкту та поточну мову відображення. Пункт [Налаштувати мови проєкту…] відкриває параметри мов проєкту |
| Вміст | [Назви файлів] | Показує назви файлів замість назв документів |
| | [Піктограми документів] | Показує піктограму біля кожного документа |
| | [Піктограми папок] | Показує піктограму біля кожної папки |
| | [Кількість елементів у папці] | Показує кількість документів у папці |
| | [Напрямні ієрархії] | Показує напрямні лінії ієрархії |
| | [Автоматично приховувати, якщо документ лише один] | У корені документації лише з одним документом автоматично закриває INDEX під час першого відкриття |
| | [Згорнути відомості про документ] | Згортає керівну таблицю на початку документа в рядок «Відомості про документ». Якщо вимкнено, таблиця показується як є |
| | [Щільність відображення] | Міжрядковий інтервал INDEX: [Звичайний] / [Компактна] |
| | [Кнопка редагування] | Показує кнопку [Редагувати] у правому нижньому куті тексту |
| Дії | [Повернути типові значення проєкту] | Скасовує всі зміни користувача й повертає параметри проєкту |
| | [Відкрити параметри розширення] | Відкриває параметри Lunascape Docs у вікні параметрів VS Code |

> **Порада**
>
> - Параметри відображення зберігаються окремо для кожного користувача та кожного кореня документації й не записуються у файли, якими керує Git.
> - Параметри мають такий порядок пріоритету: «параметри відображення користувача → параметри VS Code → `lunascape-docs.json` → типові значення продукту». Спільні для команди значення за замовчуванням задаються в розділах `tree` і `editor` файлу `lunascape-docs.json`.

## Перемикання колірної схеми

Натисніть перемикач теми (сонце/місяць) на панелі інструментів, щоб перемкнутися між білим тлом і колірною схемою VS Code. Схему під час відкриття визначає параметр `lunascapeDocEditor.appearance` (`light` або `auto`).
