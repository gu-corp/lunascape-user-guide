# Використання INDEX

INDEX ліворуч — це дерево папок і документів у корені документації.

## Фільтрування

1. Введіть слово в поле [Фільтрувати документи] над INDEX.
2. Відображаються лише елементи, назви яких збігаються. Очистіть поле, щоб повернути початковий вигляд.

> **Примітка**
>
> Під час фільтрування змінювати порядок перетягуванням не можна.

## Розгортання та згортання папок

- Натисніть стрілку ліворуч від назви папки або назву папки без обкладинки, щоб розгорнути чи згорнути її.
- Папка з обкладинкою (файл `README.md` або `index.md` із вмістом) відкриває цю сторінку, коли ви натискаєте її назву. Щоб лише розгорнути або згорнути її, скористайтеся пунктами [Розгорнути папку] / [Згорнути папку] в меню елемента.
- Стан розгортання зберігається окремо для кожного користувача й не записується у файли під керуванням Git.

## README та обкладинка папки

`README.md` — це файл, який описує вміст папки.

- Якщо папка має README, натискання її назви показує цей README.
- Якщо README немає, показується перший документ усередині папки.
- Заголовок README (H1) стає назвою цієї папки в INDEX.

README не є обов'язковим. Щоб додати його пізніше, виберіть [Створити README] в меню елемента папки (цей пункт з'являється лише для папок без README).

## Показ і приховування INDEX

- Ліва піктограма в елементах керування колонками на панелі інструментів показує або приховує INDEX. Права піктограма показує або приховує «На цій сторінці».
- На вузьких екранах INDEX спочатку закритий. Натисніть [Відкрити INDEX] (три лінії) ліворуч від [Назад], і INDEX відкриється поверх документа. Закрийте його за допомогою [×] усередині INDEX, клацання на тлі, клавіші `Esc` або переходом до іншого документа. Це тимчасове відкриття не змінює налаштування для широкого екрана.
- У корені документації, де відображається лише один документ, INDEX автоматично закривається лише першого разу. Його можна знову відкрити піктограмою колонок. Цю поведінку можна вимкнути пунктом [Автоматично приховувати, якщо документ лише один] у [Параметри відображення].

## Використання меню елемента

Наведіть вказівник на елемент INDEX, щоб з'явилася кнопка [⋯], або клацніть елемент правою кнопкою миші, щоб відкрити його меню. Пункти розташовані в такому порядку.

| Група | Пункти |
|---|---|
| Часті дії | [Розгорнути папку] / [Згорнути папку], [Відкрити INDEX] (відкриває обкладинку папки), [Редагувати], [Змінити заголовок], [Відкрити у VS Code], [Копіювати шлях] |
| Створення та впорядкування | [Створити README] (лише для папок без README), [Новий документ], [Нова папка], [Дублювати], [Змінити назву файлу] / [Змінити назву папки], [Перемістити вище], [Перемістити нижче] |
| Видалення | [Перемістити до кошика] |

- Щоб створити елемент безпосередньо в корені документації, натисніть [⋯] біля правого краю заголовка INDEX або клацніть правою кнопкою миші порожню ділянку INDEX, а потім виберіть [Новий документ] чи [Нова папка]. У тому самому меню є пункт [Змінити назву документа], а якщо в корені документації немає README — і пункт [Створити README]. Це саме меню відкривається й тоді, коли клацнути правою кнопкою миші назву документа на панелі інструментів.
- У меню клавіші `↑` `↓` переміщують між пунктами, а `Home` `End` — до першого та останнього. Клавіша `Esc` закриває меню й повертає фокус туди, де він був до відкриття.

> **Примітка**
>
> Пункти створення, впорядкування та видалення відображаються лише тоді, коли робоча область у VS Code є надійною. Вони також недоступні під час редагування документа або поки обробляється інша дія в INDEX.

## Зміна вигляду

У розділі [Параметри відображення] можна змінити показ імен файлів, піктограми документів і папок, кількість елементів у папках, напрямні лінії ієрархії та щільність відображення. Докладніше див. [Зміна параметрів відображення](display-settings.md).
