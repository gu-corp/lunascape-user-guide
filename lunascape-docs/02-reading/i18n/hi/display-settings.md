# प्रदर्शन सेटिंग्स बदलना

टूलबार के [प्रदर्शन सेटिंग्स] (गियर) से, INDEX की दिखावट और संपादन बटन का प्रदर्शन हर उपयोगकर्ता अपने लिए बदल सकता है।

1. टूलबार में [प्रदर्शन सेटिंग्स] दबाएँ।
2. जिन वस्तुओं को बदलना है उन्हें टॉगल करें। बदलाव तुरंत लागू होते हैं।
3. बंद करने के लिए [प्रदर्शन सेटिंग्स] दोबारा दबाएँ या पैनल के बाहर क्लिक करें।

## सेट की जा सकने वाली वस्तुएँ

| वर्ग | वस्तु | कार्य |
|---|---|---|
| दस्तावेज़ की भाषा | (वर्तमान स्थिति) | प्रोजेक्ट की डिफ़ॉल्ट भाषा और वर्तमान प्रदर्शन भाषा दिखाता है। [प्रोजेक्ट की भाषाएँ सेट करें…] से प्रोजेक्ट की भाषा सेटिंग्स खुलती हैं |
| सामग्री | [फ़ाइल नाम] | दस्तावेज़ के नाम के बजाय फ़ाइल नाम दिखाता है |
| | [दस्तावेज़ आइकन] | दस्तावेज़ वस्तुओं पर आइकन दिखाता है |
| | [फ़ोल्डर आइकन] | फ़ोल्डर वस्तुओं पर आइकन दिखाता है |
| | [फ़ोल्डर में वस्तुओं की संख्या] | फ़ोल्डर में मौजूद दस्तावेज़ों की संख्या दिखाता है |
| | [स्तर गाइड] | स्तर दर्शाने वाली गाइड रेखाएँ दिखाता है |
| | [दस्तावेज़ केवल एक हो तो छिपाएँ] | जिस दस्तावेज़ रूट में केवल एक दस्तावेज़ हो, वहाँ पहली बार INDEX अपने आप बंद कर देता है |
| | [दस्तावेज़ की जानकारी समेटें] | दस्तावेज़ के शीर्ष की प्रबंधन तालिका को "दस्तावेज़ की जानकारी" पंक्ति में समेट देता है। बंद करने पर तालिका जैसी है वैसी दिखती है |
| | [प्रदर्शन घनत्व] | INDEX की पंक्तियों का अंतराल [मानक] / [संक्षिप्त] में से चुनता है |
| | [संपादन बटन] | मुख्य पाठ के नीचे दाईं ओर [संपादित करें] दिखाता है |
| कार्य | [प्रोजेक्ट डिफ़ॉल्ट पर लौटाएँ] | उपयोगकर्ता के सभी बदलाव मिटाकर प्रोजेक्ट की सेटिंग्स पर लौटाता है |
| | [एक्सटेंशन सेटिंग्स खोलें] | VS Code की सेटिंग्स स्क्रीन में Lunascape Docs की सेटिंग्स खोलता है |

> **संकेत**
>
> - प्रदर्शन सेटिंग्स हर उपयोगकर्ता और हर दस्तावेज़ रूट के लिए अलग सहेजी जाती हैं, और Git से प्रबंधित फ़ाइलों में नहीं लिखी जातीं।
> - सेटिंग्स की प्राथमिकता का क्रम है: "उपयोगकर्ता की प्रदर्शन सेटिंग्स → VS Code सेटिंग्स → `lunascape-docs.json` → उत्पाद के डिफ़ॉल्ट"। टीम के साझा डिफ़ॉल्ट `lunascape-docs.json` के `tree` और `editor` में तय होते हैं।

## रंग-योजना बदलना

टूलबार का थीम टॉगल (सूरज/चाँद) दबाने पर सफ़ेद पृष्ठभूमि और VS Code की रंग-योजना के बीच अदला-बदली होती है। खुलते समय की रंग-योजना `lunascapeDocEditor.appearance` सेटिंग (`light` या `auto`) से तय होती है।
