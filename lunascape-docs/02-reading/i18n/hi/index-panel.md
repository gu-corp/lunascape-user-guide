# INDEX का उपयोग करना

स्क्रीन के बाईं ओर का INDEX, दस्तावेज़ रूट में मौजूद फ़ोल्डरों और दस्तावेज़ों का ट्री है।

## फ़िल्टर करना

1. INDEX के ऊपर [दस्तावेज़ फ़िल्टर करें] में कोई शब्द लिखें।
2. केवल वही आइटम दिखते हैं जिनके दस्तावेज़ नाम मेल खाते हैं। लिखा हुआ मिटाने पर सब कुछ फिर से दिखने लगता है।

> **ध्यान दें**
>
> फ़िल्टर लगे होने पर ड्रैग और ड्रॉप से क्रम नहीं बदला जा सकता।

## फ़ोल्डर खोलना और बंद करना

- फ़ोल्डर के नाम के बाईं ओर बने तीर को, या बिना कवर पृष्ठ वाले फ़ोल्डर के नाम को दबाने पर वह खुलता या बंद होता है।
- जिस फ़ोल्डर में कवर पृष्ठ (मुख्य सामग्री वाली `README.md` या `index.md`) है, उसका नाम दबाने पर वह कवर पृष्ठ खुलता है। केवल खोलने या बंद करने के लिए आइटम मेनू का [फ़ोल्डर खोलें] / [फ़ोल्डर बंद करें] उपयोग करें।
- फ़ोल्डर के खुले या बंद होने की स्थिति प्रत्येक उपयोगकर्ता के लिए याद रखी जाती है और Git में प्रबंधित फ़ाइलों में नहीं लिखी जाती।

## README और फ़ोल्डर का कवर पृष्ठ

`README.md` वह फ़ाइल है जो उस फ़ोल्डर की सामग्री का विवरण देती है।

- जिस फ़ोल्डर में README है, उसका नाम दबाने पर वही README दिखता है।
- जिस फ़ोल्डर में README नहीं है, उसमें सबसे ऊपर का दस्तावेज़ दिखता है।
- README का शीर्षक (H1) ही INDEX में उस फ़ोल्डर का नाम बनता है।

README अनिवार्य नहीं है। बाद में जोड़ने के लिए फ़ोल्डर के आइटम मेनू में [README बनाएँ] चुनें (यह केवल उन फ़ोल्डरों के लिए दिखता है जिनमें README नहीं है)।

## INDEX दिखाना / छिपाना

- टूलबार के कॉलम नियंत्रणों में बाईं ओर के आइकन से INDEX दिखाया या छिपाया जाता है। दाईं ओर का आइकन «इस पृष्ठ पर» को दिखाता या छिपाता है।
- स्क्रीन संकरी होने पर INDEX बंद स्थिति में शुरू होता है। [वापस] के बाईं ओर दिखने वाले [INDEX खोलें] (तीन रेखाएँ) को दबाने पर INDEX मुख्य सामग्री के ऊपर आकर खुलता है। इसे INDEX के अंदर के [×], पृष्ठभूमि पर क्लिक, `Esc`, या किसी दूसरे दस्तावेज़ पर जाने से बंद किया जा सकता है। यह अस्थायी स्थिति चौड़ी स्क्रीन की सेटिंग नहीं बदलती।
- जिस दस्तावेज़ रूट में दिखाने के लिए केवल एक ही दस्तावेज़ है, वहाँ पहली बार INDEX अपने आप बंद हो जाता है। कॉलम आइकन से उसे फिर से खोला जा सकता है। यह व्यवहार [प्रदर्शन सेटिंग्स] के [दस्तावेज़ केवल एक हो तो छिपाएँ] से बंद किया जा सकता है।

## आइटम मेनू का उपयोग करना

INDEX के किसी आइटम पर माउस ले जाने पर दिखने वाले [⋯] से, या आइटम पर राइट-क्लिक करके उस आइटम का मेनू खुलता है। आइटम इस क्रम में होते हैं।

| समूह | आइटम |
|---|---|
| अक्सर उपयोग होने वाले कार्य | [फ़ोल्डर खोलें] / [फ़ोल्डर बंद करें], [INDEX खोलें] (फ़ोल्डर का कवर पृष्ठ खोलें), [संपादित करें], [शीर्षक बदलें], [VS Code में खोलें], [पथ कॉपी करें] |
| बनाना और व्यवस्थित करना | [README बनाएँ] (केवल उन फ़ोल्डरों के लिए जिनमें README नहीं है), [नया दस्तावेज़], [नया फ़ोल्डर], [प्रतिलिपि बनाएँ], [फ़ाइल का नाम बदलें] / [फ़ोल्डर का नाम बदलें], [एक ऊपर ले जाएँ], [एक नीचे ले जाएँ] |
| हटाना | [रद्दी में ले जाएँ] |

- दस्तावेज़ रूट के ठीक नीचे कुछ बनाने के लिए, INDEX के शीर्षक के दाएँ छोर पर बने [⋯] को दबाएँ या INDEX के खाली हिस्से पर राइट-क्लिक करें, फिर [नया दस्तावेज़] या [नया फ़ोल्डर] चुनें। उसी मेनू में [दस्तावेज़ का नाम बदलें] और, यदि दस्तावेज़ रूट में README न हो तो [README बनाएँ] भी होता है। टूलबार में दिख रहे दस्तावेज़ के नाम पर राइट-क्लिक करने पर भी यही मेनू खुलता है।
- मेनू के अंदर `↑` `↓` से आइटम बदले जाते हैं और `Home` `End` से पहले और अंतिम आइटम पर जाया जाता है। `Esc` से बंद करने पर फ़ोकस वहीं लौट आता है जहाँ से मेनू खोला गया था।

> **ध्यान दें**
>
> बनाने, व्यवस्थित करने और हटाने वाले आइटम केवल तभी दिखते हैं जब VS Code में कार्यस्थान विश्वसनीय हो। दस्तावेज़ के संपादन के दौरान, और जब INDEX का कोई दूसरा कार्य चल रहा हो, तब भी ये उपलब्ध नहीं होते।

## दिखने का तरीका बदलना

[प्रदर्शन सेटिंग्स] से फ़ाइल नामों का प्रदर्शन, दस्तावेज़ और फ़ोल्डर के आइकन, फ़ोल्डर के भीतर की संख्या, श्रेणी-क्रम की मार्गदर्शक रेखाएँ और प्रदर्शन घनत्व बदले जा सकते हैं। विस्तार के लिए [प्रदर्शन सेटिंग्स बदलना](display-settings.md) देखें।
