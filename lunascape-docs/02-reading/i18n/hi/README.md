# बुनियादी संचालन

दस्तावेज़ खोलने से लेकर जिस पृष्ठ को आप पढ़ना चाहते हैं वहाँ पहुँचने तक के बुनियादी संचालन।

## दस्तावेज़ खोलें

1. VS Code में रिपॉज़िटरी खोलें।
2. कमांड पैलेट (`⇧⌘P` / `Ctrl+Shift+P`) से "Lunascape Docs: विनिर्देश व्यूअर खोलें" चलाएँ।
   निकटतम दस्तावेज़ रूट (डिफ़ॉल्ट रूप से `docs` फ़ोल्डर) मिल जाता है और उसका आरंभिक पृष्ठ दिखाया जाता है।

> **संकेत**
>
> - एक्सप्लोरर में किसी Markdown फ़ाइल पर दायाँ-क्लिक करें और [Lunascape Docs: विनिर्देश व्यूअर में खोलें] चुनें, तो उस फ़ाइल से शुरू कर सकते हैं।
> - ऐसी Markdown फ़ाइल खोलने पर जो किसी दस्तावेज़ रूट से संबंधित नहीं है, उसका फ़ोल्डर एक अस्थायी दस्तावेज़ रूट के रूप में दिखाया जाता है।

## पृष्ठों के बीच जाएँ

| संचालन | तरीका |
|---|---|
| विषय-सूची से खोलें | बाईं ओर INDEX में दस्तावेज़ का नाम दबाएँ |
| लिंक पर जाएँ | मुख्य पाठ में लिंक दबाएँ। वह उसी दृश्य में खुलता है |
| इतिहास में आगे-पीछे जाएँ | टूलबार में [वापस] [आगे], या `Alt`+`←` / `Alt`+`→` |
| आरंभिक पृष्ठ पर लौटें | टूलबार में [विनिर्देश का मुख्य पृष्ठ] |
| एक स्तर ऊपर जाएँ | टूलबार में [मूल INDEX], या ब्रेडक्रंब का कोई मद |
| पृष्ठ के भीतर जाएँ | दाईं ओर "इस पृष्ठ पर" में शीर्षक दबाएँ |

## दस्तावेज़ ढूँढें

INDEX के ऊपर [दस्तावेज़ फ़िल्टर करें] में कोई शब्द लिखें, तो केवल वही मद दिखते हैं जिनके दस्तावेज़ नाम मेल खाते हैं। लिखा हुआ मिटाने पर सब पहले जैसा हो जाता है।

## सामग्री को नवीनतम करें

VS Code के संपादक में Markdown फ़ाइल सहेजने पर दृश्य अपने आप अद्यतन हो जाता है। बाहरी टूल से बदलाव करने पर टूलबार में [पुनः लोड करें] दबाएँ।

> **ध्यान दें**
>
> - मुख्य पाठ में बाहरी लिंक (`https://` आदि) आपके डिफ़ॉल्ट ब्राउज़र में खुलते हैं। दस्तावेज़ रूट के बाहर की फ़ाइलों के लिंक नहीं खुलते।
> - जिन दस्तावेज़ों को आप देख रहे हैं, उनका प्रसंस्करण आपके ही उपकरण पर होता है। पढ़ने के लिए दस्तावेज़ कहीं बाहर नहीं भेजे जाते।
