# Basishandelingen

De basishandelingen vanaf het openen van de documenten tot het bereiken van de pagina die u wilt lezen.

## De documenten openen

1. Open de repository in VS Code.
2. Voer in het opdrachtenpalet (`⇧⌘P` / `Ctrl+Shift+P`) "Lunascape Docs: Specificatieviewer openen" uit.
   De dichtstbijzijnde documentatiehoofdmap (standaard de map `docs`) wordt gevonden en de startpagina wordt weergegeven.

> **Tip**
>
> - Klik in de Verkenner met de rechtermuisknop op een Markdown-bestand en kies [Lunascape Docs: Openen in specificatieviewer] om vanaf dat bestand te beginnen.
> - Als u een Markdown-bestand opent dat tot geen enkele documentatiehoofdmap behoort, wordt de map ervan als tijdelijke documentatiehoofdmap weergegeven.

## Tussen pagina's navigeren

| Handeling | Werkwijze |
|---|---|
| Openen vanuit de inhoudsopgave | Druk op een documentnaam in de INDEX links |
| Een koppeling volgen | Druk op een koppeling in de tekst. Deze wordt in hetzelfde scherm geopend |
| Door de geschiedenis gaan | [Terug] en [Vooruit] op de werkbalk, of `Alt`+`←` / `Alt`+`→` |
| Terug naar de startpagina | [Startpagina van de specificatie] op de werkbalk |
| Eén niveau omhoog | [Bovenliggende INDEX] op de werkbalk, of een item in de broodkruimels |
| Binnen de pagina navigeren | Druk op een kop in "Op deze pagina" rechts |

## Een document zoeken

Typ een woord in [Documenten filteren] boven de INDEX om alleen de documenten weer te geven waarvan de naam overeenkomt. Wis de invoer om weer alles te tonen.

## De inhoud bijwerken

Wanneer u een Markdown-bestand in de editor van VS Code opslaat, wordt de weergave automatisch bijgewerkt. Als u bestanden met een extern hulpmiddel hebt gewijzigd, drukt u op [Opnieuw laden] op de werkbalk.

> **Let op**
>
> - Externe koppelingen in de tekst (`https://` en dergelijke) worden in uw standaardbrowser geopend. Koppelingen naar bestanden buiten de documentatiehoofdmap worden niet geopend.
> - Het document dat u leest, wordt op uw apparaat verwerkt. Er wordt niets naar buiten verzonden om een document te lezen.
