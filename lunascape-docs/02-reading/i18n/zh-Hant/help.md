# 顯示說明

本說明指南隨附於擴充功能，可在與一般文件相同的畫面中閱讀。

## 開啟說明

請使用下列任一方式。

- 按下工具列最右端的 [說明]（?）。
- 在命令選擇區執行「Lunascape Docs: 開啟說明」。

說明開啟期間，INDEX、內文連結、「本頁內容」以及 [返回] [前進] 的用法與一般文件相同。說明的瀏覽記錄與專案文件分開保存，說明也不會加入文件根目錄的清單中。

## 關閉說明

再次按下工具列的 [說明]，或按下其右側顯示的 [×]。畫面會回到開啟說明前正在閱讀的文件，並停留在相同的捲動位置。

## 切換說明的語言

說明除了日文與英文之外，也隨附 VS Code 提供作為顯示語言的各種語言。您可以停留在正在閱讀的頁面，隨時切換。

1. 按下工具列的語言選單（地球儀）。
2. 選擇想閱讀的語言。
   相同頁面會以所選語言顯示，閱讀位置也維持不變。

> **提示**
>
> 系統會記住您選擇的語言，下次開啟說明時也會以同一語言顯示。若您從未切換過，則依照顯示中文件的語言、VS Code 的顯示語言、日文的順序選用。
>
> 切換說明的語言，並不會變更閱讀專案文件時使用的語言。

> **注意**
>
> 說明為唯讀。顯示說明期間無法進行編輯、翻譯、檢查等操作。
