# 以其他語言閱讀

有翻譯版的文件，可以從工具列的語言選單（地球儀）切換語言閱讀。

## 切換語言

1. 按工具列的語言選單。
   會顯示目前頁面的語言，以及判定依據（翻譯版的路徑、自動偵測、專案的預設語言）。
2. 選擇想閱讀的語言。
   會開啟同一文件的翻譯版。所選語言會被記住，下次開啟文件時，若有翻譯版也會以該語言顯示。

語言清單中會顯示該文件是否有翻譯版。

| 顯示 | 意義 |
|---|---|
| 已翻譯 | 翻譯版存在，可以開啟 |
| 未翻譯 | 是專案的支援語言，但此文件尚無翻譯版 |
| 待更新 | 有翻譯版，但翻譯之後原始文件已變更 |

> **ご注意**
>
> - 選擇語言的操作只會開啟既有的翻譯版，不會生成翻譯或建立檔案。若要建立翻譯版，請使用同一選單中的 [建立或管理翻譯…]。
> - 當判定目前頁面的語言與專案的預設語言不同時，會顯示警告。設定不會被改寫。

## 最初顯示的語言

開啟文件時，最初的顯示語言依下列順序決定。

1. 你先前在此文件根目錄選過的語言。所選內容會被儲存（即使選的是預設語言，也會作為選擇被儲存）。
2. VS Code 的顯示語言（在網頁瀏覽器版中為瀏覽器的語言設定）。會自動選取與支援語言相符者。帶地區的語言（如 `en-US`）也會與基本語言（`en`）相符。
3. 專案的後備語言（`lunascape-docs.json` 的 `fallbackLocale`）。
4. 專案的預設語言。

> **ヒント**
>
> - 自動選取時，語言選單中目前的語言會顯示「自動選取」。將指標移到徽章上會顯示原因。
> - `fallbackLocale` 是向閱讀環境語言與任何支援語言都不相符的讀者顯示的語言。在正本為日文並具有英文版的專案中設定 `"en"`，則使用西班牙文等環境的讀者會開啟英文版。未設定時會使用預設語言。

## 翻譯版的存放位置

預設語言的文件放在原本的位置，翻譯版則以相同的檔名放在**同一資料夾的 `i18n/<語言>/`** 中。

```text
docs/
  README.md                  ← 預設語言（例如：日文）
  i18n/en/README.md          ← 其英文版
  guide/
    setup.md
    i18n/en/setup.md         ← 其英文版
```

> **ご注意**
>
> - 在 `i18n/` 之下重建資料夾結構（`i18n/en/guide/setup.md`）的方式不會被識別。`i18n/` 一定要放在與該文件相同的資料夾中。
> - 翻譯版的解析來源只有這一個位置。即使將同一文件的翻譯放到父資料夾的 `i18n/`，也不會造成「以何者為優先」的衝突，該處會成為語言選單與台帳都看不到的孤立檔案（且不會被自動刪除）。請勿將同一份翻譯放在兩個位置。

## 在網頁瀏覽器版閱讀時

網頁瀏覽器版中，只要有翻譯版也能以同樣方式切換。想以沒有翻譯版的語言閱讀時，可以使用瀏覽器的頁面翻譯功能。程式碼、數學式與圖表已設定為排除在翻譯對象之外。
