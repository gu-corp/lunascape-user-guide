# 基本操作

從開啟文件到移至想閱讀的頁面，這些是基本的操作。

## 開啟文件

1. 在 VS Code 中開啟存放庫。
2. 在命令選擇區（`⇧⌘P` / `Ctrl+Shift+P`）中執行「Lunascape Docs: 開啟規格書檢視器」。
   系統會找出最接近的文件根目錄（預設為 `docs` 資料夾），並顯示其開始頁面。

> **提示**
>
> - 在檔案總管中以滑鼠右鍵按一下 Markdown 檔案，選擇 [Lunascape Docs: 以規格書檢視器開啟]，即可從該檔案開始閱讀。
> - 開啟不屬於任何文件根目錄的 Markdown 檔案時，會將該檔案所在的資料夾當作暫時的文件根目錄來顯示。

## 在頁面之間移動

| 操作 | 方法 |
|---|---|
| 從目錄開啟 | 在左側的 INDEX 中按一下文件名稱 |
| 跟隨連結 | 按一下內文中的連結。會在同一個畫面中開啟 |
| 依瀏覽紀錄移動 | 工具列的 [返回] [前進]，或 `Alt`+`←` / `Alt`+`→` |
| 回到開始頁面 | 工具列的 [規格書首頁] |
| 移至上一層 | 工具列的 [上層 INDEX]，或導覽路徑中的項目 |
| 在頁面內移動 | 在右側的「本頁內容」中按一下標題 |

## 尋找文件

在 INDEX 上方的 [篩選文件] 中輸入文字，就只會顯示名稱相符的文件。清除輸入的文字即可恢復原本的顯示。

## 更新為最新內容

在 VS Code 的編輯器中儲存 Markdown 檔案後，畫面會自動更新。以外部工具變更檔案時，請按一下工具列的 [重新載入]。

> **注意**
>
> - 內文中的外部連結（例如 `https://`）會在預設瀏覽器中開啟。指向文件根目錄之外檔案的連結則不會開啟。
> - 您所閱讀的文件會在裝置內處理。不會為了閱讀文件而將文件傳送至外部。
