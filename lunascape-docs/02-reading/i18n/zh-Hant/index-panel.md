# 使用 INDEX

畫面左側的 INDEX 是文件根目錄中資料夾與文件的樹狀結構。

## 篩選

1. 在 INDEX 上方的 [篩選文件] 中輸入文字。
2. 只會顯示名稱相符的項目。清除輸入內容即可恢復原狀。

> **注意**
>
> 篩選期間無法以拖放方式調整排序。

## 展開與收合資料夾

- 按下資料夾名稱左側的箭頭，或沒有封面頁的資料夾名稱，即可展開或收合。
- 有封面頁（具有內文的 `README.md` 或 `index.md`）的資料夾，按下名稱會開啟封面頁。若只要展開或收合，請使用項目選單中的 [展開資料夾] / [收合資料夾]。
- 資料夾的展開與收合狀態會依使用者個別記住，不會寫入 Git 管理的檔案。

## README 與資料夾的封面頁

`README.md` 是說明該資料夾內容的檔案。

- 有 README 的資料夾，按下資料夾名稱時會顯示該 README。
- 沒有 README 的資料夾，則會顯示其中最上方的文件。
- README 的標題（H1）會成為該資料夾在 INDEX 中顯示的名稱。

README 並非必要。若要日後新增，請在資料夾的項目選單中選擇 [建立 README]（僅會在沒有 README 的資料夾中顯示）。

## 顯示／隱藏 INDEX

- 使用工具列欄位顯示中左側的圖示，可顯示或隱藏 INDEX。右側的圖示則用於顯示或隱藏「本頁內容」。
- 畫面較窄時，INDEX 會以收合狀態啟動。按下顯示在 [返回] 左側的 [開啟 INDEX]（三條線）後，INDEX 會重疊顯示在內文上方。可透過 INDEX 內的 [×]、點擊背景、`Esc`，或切換文件來關閉。這種暫時的開闔不會變更寬畫面時的設定。
- 在只顯示 1 份文件的文件根目錄中，INDEX 只會在第一次自動收合。可用欄位顯示的圖示重新開啟。此行為可在 [顯示設定] 的 [只有一份文件時自動隱藏] 中關閉。

## 使用項目選單

將滑鼠移到 INDEX 的項目上時會顯示 [⋯]，按下該圖示或在項目上按一下滑鼠右鍵，即可開啟該項目的選單。項目依下列順序排列。

| 群組 | 項目 |
|---|---|
| 常用操作 | [展開資料夾] / [收合資料夾]、[開啟 INDEX]（開啟資料夾的封面頁）、[編輯]、[變更標題]、[以 VS Code 開啟]、[複製路徑] |
| 建立與整理 | [建立 README]（僅限沒有 README 的資料夾）、[新文件]、[新增資料夾]、[建立複本]、[變更檔案名稱] / [變更資料夾名稱]、[上移一項]、[下移一項] |
| 刪除 | [移至資源回收筒] |

- 若要直接建立在文件根目錄下，請按 INDEX 標題右端的 [⋯]，或在 INDEX 的空白處按一下滑鼠右鍵，然後選擇 [新文件] 或 [新增資料夾]。同一個選單中還有 [變更文件名稱]，若文件根目錄沒有 README，也會顯示 [建立 README]。在工具列上顯示的文件名稱按一下滑鼠右鍵，也會開啟相同的選單。
- 在選單中可用 `↑` `↓` 移動，並以 `Home` `End` 移至開頭與結尾。以 `Esc` 關閉時，焦點會回到開啟前的位置。

> **注意**
>
> 建立、整理與刪除的項目，只有在 VS Code 中信任工作區時才會顯示。在編輯文件中，或正在處理其他 INDEX 操作期間，也無法使用。

## 變更顯示方式

在 [顯示設定] 中，可變更檔案名稱的顯示、文件與資料夾的圖示、資料夾內的項目數、階層引導線與顯示密度。詳情請參閱[變更顯示設定](display-settings.md)。
