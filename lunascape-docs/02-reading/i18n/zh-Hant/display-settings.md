# 變更顯示設定

從工具列的 [顯示設定]（齒輪）可以依使用者變更 INDEX 的呈現方式和編輯按鈕的顯示。

1. 按下工具列的 [顯示設定]。
2. 切換要變更的項目。變更會立即生效。
3. 再按一次 [顯示設定]，或按面板以外的地方即可關閉。

## 可設定的項目

| 區分 | 項目 | 作用 |
|---|---|---|
| 文件語言 | （目前狀態） | 顯示專案的預設語言與目前顯示中的語言。從 [設定專案語言…] 可開啟專案的語言設定 |
| 內容 | [檔案名稱] | 以檔案名稱取代文件名稱顯示 |
| | [文件圖示] | 在文件項目上顯示圖示 |
| | [資料夾圖示] | 在資料夾項目上顯示圖示 |
| | [資料夾內件數] | 顯示資料夾內含的文件數 |
| | [階層指引線] | 顯示標示階層的指引線 |
| | [只有一份文件時自動隱藏] | 在只有 1 份文件的文件根目錄中，僅第一次自動關閉 INDEX |
| | [摺疊文件資訊] | 將文件開頭的管理表格摺疊成「文件資訊」這一列。關閉時則直接顯示表格 |
| | [顯示密度] | 從 [標準] / [精簡] 選擇 INDEX 的行距 |
| | [編輯按鈕] | 在內文右下顯示 [編輯] |
| 操作 | [還原為專案預設值] | 清除使用者的所有變更，回到專案的設定 |
| | [開啟擴充功能設定] | 在 VS Code 的設定畫面開啟 Lunascape Docs 的設定 |

> **提示**
>
> - 顯示設定會依使用者、依文件根目錄分別儲存，不會寫入由 Git 管理的檔案。
> - 設定的優先順序為「使用者的顯示設定 → VS Code 設定 → `lunascape-docs.json` → 產品預設值」。團隊共用的預設值請以 `lunascape-docs.json` 的 `tree` 和 `editor` 決定。

## 切換配色

按下工具列的主題切換（太陽／月亮），即可在白色背景與 VS Code 的配色之間切換。開啟時的配色由設定 `lunascapeDocEditor.appearance`（`light` 或 `auto`）決定。
