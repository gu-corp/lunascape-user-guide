# عملیات پایه

عملیات پایه از باز کردن اسناد تا رسیدن به صفحه‌ای که می‌خواهید بخوانید.

## باز کردن اسناد

1. مخزن را در VS Code باز کنید.
2. در پنجرهٔ فرمان (`⇧⌘P` / `Ctrl+Shift+P`) فرمان «Lunascape Docs: باز کردن نمایشگر مشخصات فنی» را اجرا کنید.
   نزدیک‌ترین ریشهٔ مستندات (به‌طور پیش‌فرض پوشهٔ `docs`) پیدا می‌شود و صفحهٔ آغازین آن نمایش داده می‌شود.

> **نکته**
>
> - در کاوشگر روی یک فایل Markdown کلیک راست کنید و [Lunascape Docs: باز کردن در نمایشگر مشخصات فنی] را انتخاب کنید تا از همان فایل شروع شود.
> - اگر فایل Markdown‌ای را باز کنید که به هیچ ریشهٔ مستنداتی تعلق ندارد، پوشهٔ آن به‌عنوان ریشهٔ مستندات موقت نمایش داده می‌شود.

## جابه‌جایی میان صفحه‌ها

| عمل | روش |
|---|---|
| باز کردن از فهرست مطالب | در INDEX سمت چپ روی نام سند بزنید |
| دنبال کردن پیوند | روی پیوندی در متن بزنید. در همان نما باز می‌شود |
| مرور تاریخچه | [بازگشت] و [جلو] در نوار ابزار، یا `Alt`+`←` / `Alt`+`→` |
| بازگشت به صفحهٔ آغازین | [صفحهٔ اصلی مشخصات فنی] در نوار ابزار |
| رفتن به یک سطح بالاتر | [INDEX والد] در نوار ابزار، یا یکی از موارد مسیر راهنما |
| جابه‌جایی درون صفحه | در «در این صفحه» سمت راست روی یک عنوان بزنید |

## یافتن سند

در [محدود کردن اسناد] بالای INDEX واژه‌ای را وارد کنید تا فقط اسنادی نمایش داده شوند که نامشان مطابقت دارد. با پاک کردن ورودی، همه‌چیز دوباره نمایش داده می‌شود.

## به‌روزرسانی به تازه‌ترین محتوا

وقتی فایل Markdown را در ویرایشگر VS Code ذخیره می‌کنید، نمایش به‌طور خودکار به‌روز می‌شود. اگر با ابزاری بیرونی تغییری داده‌اید، در نوار ابزار [بارگذاری مجدد] را بزنید.

> **توجه**
>
> - پیوندهای بیرونی در متن (مانند `https://`) در مرورگر پیش‌فرض شما باز می‌شوند. پیوند به فایل‌های بیرون از ریشهٔ مستندات باز نمی‌شود.
> - سندی که می‌خوانید روی دستگاه شما پردازش می‌شود. برای خواندن سند، چیزی به بیرون فرستاده نمی‌شود.
