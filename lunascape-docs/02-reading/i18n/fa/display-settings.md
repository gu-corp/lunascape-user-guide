# تغییر تنظیمات نمایش

از [تنظیمات نمایش] (چرخ‌دنده) در نوار ابزار، هر کاربر می‌تواند شکل نمایش INDEX و نمایش دکمهٔ ویرایش را تغییر دهد.

۱. در نوار ابزار [تنظیمات نمایش] را بزنید.
۲. موردی را که می‌خواهید تغییر دهید، جابه‌جا کنید. تغییر بی‌درنگ اعمال می‌شود.
۳. برای بستن، دوباره [تنظیمات نمایش] را بزنید یا بیرون از پنل را بزنید.

## موردهای قابل تنظیم

| بخش | مورد | کارکرد |
|---|---|---|
| زبان سند | (وضعیت کنونی) | زبان پیش‌فرض پروژه و زبان در حال نمایش را نشان می‌دهد. با [تنظیم زبان‌های پروژه…] تنظیمات زبان پروژه باز می‌شود |
| محتوا | [نام پرونده‌ها] | به‌جای نام سند، نام پرونده را نشان می‌دهد |
| | [نقشک‌های سند] | کنار موردهای سند نقشک نشان می‌دهد |
| | [نقشک‌های پوشه] | کنار موردهای پوشه نقشک نشان می‌دهد |
| | [تعداد موارد درون پوشه] | شمار سندهای درون هر پوشه را نشان می‌دهد |
| | [راهنماهای سطح‌بندی] | خط‌های راهنمای سطح‌بندی را نشان می‌دهد |
| | [اگر تنها یک سند هست، خودکار پنهان شود] | در ریشهٔ مستنداتی که تنها یک سند دارد، INDEX را فقط بار نخست به‌طور خودکار می‌بندد |
| | [جمع کردن اطلاعات سند] | جدول مدیریتی بالای سند را در سطر «اطلاعات سند» جمع می‌کند. اگر خاموش باشد، جدول همان‌گونه نشان داده می‌شود |
| | [تراکم نمایش] | فاصلهٔ سطرهای INDEX را از [استاندارد] / [فشرده] برمی‌گزیند |
| | [دکمهٔ ویرایش] | [ویرایش] را در پایین‌ سمت راست متن نشان می‌دهد |
| عملیات | [بازگشت به پیش‌فرض‌های پروژه] | همهٔ تغییرهای کاربر را پاک می‌کند و به تنظیمات پروژه بازمی‌گردد |
| | [باز کردن تنظیمات افزونه] | تنظیمات Lunascape Docs را در صفحهٔ تنظیمات VS Code باز می‌کند |

> **نکته**
>
> - تنظیمات نمایش برای هر کاربر و هر ریشهٔ مستندات جداگانه ذخیره می‌شود و در پرونده‌هایی که با Git مدیریت می‌شوند نوشته نمی‌شود.
> - ترتیب اولویت تنظیمات چنین است: «تنظیمات نمایش کاربر ← تنظیمات VS Code ← ‏`lunascape-docs.json` ← پیش‌فرض محصول». پیش‌فرض‌های مشترک تیم در `tree` و `editor` در `lunascape-docs.json` تعیین می‌شود.

## تغییر رنگ‌بندی

با زدن کلید تغییر زمینه (خورشید/ماه) در نوار ابزار، میان زمینهٔ سفید و رنگ‌بندی VS Code جابه‌جا می‌شوید. رنگ‌بندی هنگام باز شدن با تنظیم `lunascapeDocEditor.appearance` (‏`light` یا `auto`) تعیین می‌شود.
