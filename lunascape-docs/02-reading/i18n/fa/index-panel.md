# استفاده از INDEX

INDEX در سمت چپ صفحه، درخت پوشه‌ها و اسناد موجود در ریشهٔ مستندات است.

## محدود کردن

1. در [محدود کردن اسناد] بالای INDEX یک واژه بنویسید.
2. تنها مواردی که نام سندشان مطابقت دارد نمایش داده می‌شوند. با پاک کردن نوشته، حالت نخست بازمی‌گردد.

> **توجه**
>
> هنگام محدود کردن، تغییر ترتیب با کشیدن و رها کردن ممکن نیست.

## باز و بسته کردن پوشه‌ها

- با فشردن پیکان سمت چپ نام پوشه، یا نام پوشه‌ای که صفحهٔ معرفی ندارد، پوشه باز یا بسته می‌شود.
- پوشه‌ای که صفحهٔ معرفی دارد (یک `README.md` یا `index.md` دارای متن)، با فشردن نامش صفحهٔ معرفی را باز می‌کند. برای باز و بسته کردن تنها، از [باز کردن پوشه] / [بستن پوشه] در منوی مورد استفاده کنید.
- وضعیت باز یا بستهٔ پوشه‌ها برای هر کاربر به خاطر سپرده می‌شود و در فایل‌های تحت مدیریت Git نوشته نمی‌شود.

## README و صفحهٔ معرفی پوشه

`README.md` فایلی است که محتوای آن پوشه را توضیح می‌دهد.

- در پوشه‌ای که README دارد، با فشردن نام پوشه همان README نمایش داده می‌شود.
- در پوشه‌ای که README ندارد، بالاترین سند درون آن نمایش داده می‌شود.
- عنوان (H1) موجود در README، نام آن پوشه در INDEX می‌شود.

README الزامی نیست. برای افزودن آن در آینده، در منوی مورد مربوط به پوشه [ساخت README] را انتخاب کنید (تنها برای پوشه‌های بدون README نمایش داده می‌شود).

## نمایش یا پنهان کردن INDEX

- با نماد سمت چپ در بخش نمایش ستونی نوار ابزار، INDEX را نمایش می‌دهید یا پنهان می‌کنید. نماد سمت راست، نمایش یا پنهان کردن «در این صفحه» است.
- وقتی صفحه باریک است، INDEX در حالت بسته آغاز می‌شود. با فشردن [باز کردن INDEX] (سه خط) که در سمت چپ [بازگشت] نمایش داده می‌شود، INDEX روی متن باز می‌شود. با [×] درون INDEX، کلیک روی زمینه، `Esc`، یا جابه‌جایی به سند دیگر بسته می‌شود. این باز و بسته شدن موقتی، تنظیم صفحه‌های پهن را تغییر نمی‌دهد.
- در ریشهٔ مستنداتی که تنها یک سند برای نمایش دارد، INDEX فقط بار نخست خودکار بسته می‌شود. با نماد نمایش ستونی می‌توانید دوباره آن را باز کنید. این رفتار را می‌توانید در [تنظیمات نمایش] با [اگر تنها یک سند هست، خودکار پنهان شود] خاموش کنید.

## استفاده از منوی مورد

با بردن نشانگر روی یکی از موارد INDEX، [⋯] نمایان می‌شود؛ با فشردن آن یا با راست‌کلیک روی مورد، منوی آن مورد باز می‌شود. موارد به این ترتیب چیده می‌شوند.

| گروه | موارد |
|---|---|
| عملیات پرکاربرد | [باز کردن پوشه] / [بستن پوشه]، [باز کردن INDEX] (باز کردن صفحهٔ معرفی پوشه)، [ویرایش]، [تغییر عنوان]، [باز کردن در VS Code]، [رونوشت از مسیر] |
| ساخت و سازمان‌دهی | [ساخت README] (تنها برای پوشه‌های بدون README)، [سند جدید]، [پوشهٔ جدید]، [تکثیر]، [تغییر نام فایل] / [تغییر نام پوشه]، [انتقال به یکی بالاتر]، [انتقال به یکی پایین‌تر] |
| حذف | [انتقال به سطل زباله] |

- برای ساختن مستقیم زیر ریشهٔ مستندات، [⋯] را در انتهای سمت راست عنوان INDEX بفشارید یا روی بخش خالی INDEX راست‌کلیک کنید و [سند جدید] یا [پوشهٔ جدید] را انتخاب کنید. در همان منو [تغییر نام سند] و، اگر ریشهٔ مستندات README نداشته باشد، [ساخت README] نیز قرار دارد. با راست‌کلیک روی نام سندی که در نوار ابزار دیده می‌شود نیز همین منو باز می‌شود.
- درون منو با `↑` `↓` جابه‌جا می‌شوید و با `Home` `End` به ابتدا و انتها می‌روید. با بستن منو به کمک `Esc`، تمرکز به جایگاه پیش از باز شدن بازمی‌گردد.

> **توجه**
>
> موارد ساخت، سازمان‌دهی و حذف تنها زمانی نمایش داده می‌شوند که فضای کاری در VS Code مورد اعتماد باشد. هنگام ویرایش سند، و نیز در حین پردازش عملیات دیگری در INDEX، در دسترس نیستند.
