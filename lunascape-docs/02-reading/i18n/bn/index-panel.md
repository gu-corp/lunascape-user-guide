# INDEX ব্যবহার করা

পর্দার বাঁ দিকের INDEX হলো ডকুমেন্টেশন রুটে থাকা ফোল্ডার ও নথির ট্রি।

## ফিল্টার করা

1. INDEX-এর উপরে থাকা [নথি ফিল্টার করুন]-এ একটি শব্দ লিখুন।
2. যেসব নথির নাম মিলে যায় কেবল সেগুলোই দেখানো হয়। লেখাটি মুছে ফেললে আগের অবস্থা ফিরে আসে।

> **দ্রষ্টব্য**
>
> ফিল্টার চালু থাকা অবস্থায় ড্র্যাগ অ্যান্ড ড্রপ দিয়ে ক্রম পরিবর্তন করা যায় না।

## ফোল্ডার খোলা ও বন্ধ করা

- ফোল্ডারের নামের বাঁ পাশের তির চিহ্নে, অথবা প্রচ্ছদবিহীন ফোল্ডারের নামে চাপ দিলে সেটি খোলে বা বন্ধ হয়।
- যে ফোল্ডারে প্রচ্ছদ আছে (বিষয়বস্তুসহ `README.md` বা `index.md`), তার নামে চাপ দিলে প্রচ্ছদটি খোলে। শুধু খোলা বা বন্ধ করতে চাইলে আইটেম মেনুর [ফোল্ডার খুলুন] / [ফোল্ডার বন্ধ করুন] ব্যবহার করুন।
- ফোল্ডার খোলা বা বন্ধ থাকার অবস্থা প্রতিটি ব্যবহারকারীর জন্য আলাদাভাবে মনে রাখা হয় এবং Git-এ পরিচালিত ফাইলে লেখা হয় না।

## README ও ফোল্ডারের প্রচ্ছদ

`README.md` হলো সেই ফাইল যা ওই ফোল্ডারের ভেতরে কী আছে তা বর্ণনা করে।

- যে ফোল্ডারে README আছে, তার নামে চাপ দিলে সেই README দেখানো হয়।
- যে ফোল্ডারে README নেই, সেখানে ভেতরের সবচেয়ে উপরের নথিটি দেখানো হয়।
- README-এর শিরোনাম (H1) INDEX-এ ওই ফোল্ডারের নাম হিসেবে দেখা যায়।

README রাখা আবশ্যক নয়। পরে যোগ করতে চাইলে ফোল্ডারের আইটেম মেনু থেকে [README তৈরি করুন] বেছে নিন (এটি কেবল README নেই এমন ফোল্ডারেই দেখা যায়)।

## INDEX দেখানো / লুকানো

- টুলবারের কলাম প্রদর্শনের বাঁ দিকের আইকন দিয়ে INDEX দেখানো বা লুকানো যায়। ডান দিকের আইকনটি "এই পৃষ্ঠায়" দেখানো বা লুকানোর জন্য।
- পর্দা সরু হলে INDEX বন্ধ অবস্থায় শুরু হয়। [পিছনে]-এর বাঁ পাশে দেখানো [INDEX খুলুন] (তিনটি রেখা) চাপ দিলে INDEX মূল লেখার উপরে ভেসে খোলে। INDEX-এর ভেতরের [×], পটভূমিতে ক্লিক, `Esc`, অথবা অন্য নথিতে গেলে এটি বন্ধ হয়। এই সাময়িক খোলা-বন্ধ প্রশস্ত পর্দার সেটিংস বদলায় না।
- যে ডকুমেন্টেশন রুটে দেখানোর মতো নথি মাত্র একটি, সেখানে প্রথমবার INDEX স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যায়। কলাম প্রদর্শনের আইকন দিয়ে আবার খোলা যায়। [প্রদর্শন সেটিংস]-এর [নথি একটি হলে স্বয়ংক্রিয়ভাবে লুকান] দিয়ে এই আচরণ বন্ধ করা যায়।

## আইটেম মেনু ব্যবহার করা

INDEX-এর কোনো আইটেমের উপর মাউস রাখলে যে [⋯] দেখা যায় তাতে চাপ দিয়ে, অথবা আইটেমটিতে ডান ক্লিক করে সেই আইটেমের মেনু খুলুন। আইটেমগুলো নিচের ক্রমে সাজানো থাকে।

| গ্রুপ | আইটেম |
|---|---|
| প্রায়ই ব্যবহৃত কাজ | [ফোল্ডার খুলুন] / [ফোল্ডার বন্ধ করুন]、[INDEX খুলুন] (ফোল্ডারের প্রচ্ছদ খোলে)、[সম্পাদনা]、[শিরোনাম পরিবর্তন করুন]、[VS Code-এ খুলুন]、[পাথ কপি করুন] |
| তৈরি ও গোছানো | [README তৈরি করুন] (কেবল README নেই এমন ফোল্ডারে)、[নতুন নথি]、[নতুন ফোল্ডার]、[প্রতিলিপি]、[ফাইলের নাম পরিবর্তন করুন] / [ফোল্ডারের নাম পরিবর্তন করুন]、[এক ধাপ উপরে সরান]、[এক ধাপ নিচে সরান] |
| মুছে ফেলা | [ট্র্যাশে সরান] |

- ডকুমেন্টেশন রুটের ঠিক নিচে কিছু তৈরি করতে হলে INDEX-এর শিরোনামের ডান প্রান্তের [⋯] চাপুন, অথবা INDEX-এর ফাঁকা অংশে ডান ক্লিক করে [নতুন নথি] বা [নতুন ফোল্ডার] বেছে নিন। একই মেনুতে [নথির নাম পরিবর্তন করুন] থাকে, আর ডকুমেন্টেশন রুটে README না থাকলে [README তৈরি করুন]-ও থাকে। টুলবারে দেখানো নথির নামে ডান ক্লিক করলেও একই মেনু খোলে।
- মেনুর ভেতরে `↑` `↓` দিয়ে এক আইটেম থেকে আরেক আইটেমে যাওয়া যায় এবং `Home` `End` দিয়ে প্রথম ও শেষ আইটেমে যাওয়া যায়। `Esc` দিয়ে বন্ধ করলে মেনু খোলার আগে যেখানে ফোকাস ছিল সেখানেই ফিরে যায়।

> **দ্রষ্টব্য**
>
> তৈরি, গোছানো ও মুছে ফেলার আইটেমগুলো কেবল তখনই দেখা যায় যখন VS Code-এ ওয়ার্কস্পেসটি বিশ্বস্ত ওয়ার্কস্পেস হিসেবে চিহ্নিত থাকে। নথি সম্পাদনার সময়, কিংবা INDEX-এর অন্য কোনো কাজ চলাকালীনও এগুলো ব্যবহার করা যায় না।

## দেখার ধরন পরিবর্তন করা

[প্রদর্শন সেটিংস] থেকে ফাইলের নাম দেখানো, নথি ও ফোল্ডারের আইকন, ফোল্ডারের ভেতরের সংখ্যা, স্তরের নির্দেশক রেখা এবং প্রদর্শনের ঘনত্ব পরিবর্তন করা যায়। বিস্তারিত জানতে [প্রদর্শন সেটিংস পরিবর্তন করা](display-settings.md) দেখুন।
