# মৌলিক ব্যবহার

নথি খোলা থেকে শুরু করে আপনি যে পৃষ্ঠাটি পড়তে চান সেখানে পৌঁছানো পর্যন্ত মৌলিক ব্যবহারবিধি।

## নথি খুলুন

1. VS Code-এ রিপোজিটরি খুলুন।
2. কমান্ড প্যালেট (`⇧⌘P` / `Ctrl+Shift+P`) থেকে "Lunascape Docs: স্পেসিফিকেশন ভিউয়ার খুলুন" চালান।
   নিকটতম ডকুমেন্টেশন রুট (ডিফল্টভাবে `docs` ফোল্ডার) খুঁজে নেওয়া হয় এবং তার শুরুর পৃষ্ঠা দেখানো হয়।

> **ইঙ্গিত**
>
> - এক্সপ্লোরারে কোনো Markdown ফাইলে ডান-ক্লিক করে [Lunascape Docs: স্পেসিফিকেশন ভিউয়ারে খুলুন] বেছে নিলে সেই ফাইল থেকে শুরু করা যায়।
> - কোনো ডকুমেন্টেশন রুটের অন্তর্ভুক্ত নয় এমন Markdown ফাইল খুললে তার ফোল্ডারটিকে সাময়িক ডকুমেন্টেশন রুট হিসেবে দেখানো হয়।

## পৃষ্ঠার মধ্যে চলাচল করুন

| কাজ | পদ্ধতি |
|---|---|
| সূচিপত্র থেকে খোলা | বাঁ দিকের INDEX-এ নথির নাম চাপুন |
| লিঙ্ক অনুসরণ করা | লেখার মধ্যের লিঙ্ক চাপুন। একই পর্দাতেই খোলে |
| ইতিহাস ধরে চলা | টুলবারের [পিছনে] [সামনে], অথবা `Alt`+`←` / `Alt`+`→` |
| শুরুর পৃষ্ঠায় ফেরা | টুলবারের [স্পেসিফিকেশনের শীর্ষপাতা] |
| এক স্তর উপরে যাওয়া | টুলবারের [প্যারেন্ট INDEX], অথবা ব্রেডক্রাম্বের কোনো আইটেম |
| পৃষ্ঠার ভিতরে চলাচল | ডান দিকের "এই পৃষ্ঠায়"-এ শিরোনাম চাপুন |

## নথি খুঁজুন

INDEX-এর উপরের [নথি ফিল্টার করুন]-এ কোনো শব্দ লিখলে কেবল নাম মিলে যাওয়া নথিগুলিই দেখানো হয়। লেখা মুছে দিলে আবার আগের অবস্থায় ফিরে আসে।

## সর্বশেষ বিষয়বস্তুতে হালনাগাদ করুন

VS Code-এর এডিটরে Markdown ফাইল সংরক্ষণ করলে প্রদর্শন আপনাআপনি হালনাগাদ হয়। বাইরের কোনো সরঞ্জাম দিয়ে পরিবর্তন করলে টুলবারের [পুনরায় লোড] চাপুন।

> **বিশেষ দ্রষ্টব্য**
>
> - লেখার মধ্যের বাইরের লিঙ্ক (যেমন `https://`) আপনার ডিফল্ট ব্রাউজারে খোলে। ডকুমেন্টেশন রুটের বাইরের ফাইলের লিঙ্ক খোলে না।
> - আপনি যে নথি দেখছেন তা আপনার যন্ত্রের ভিতরেই প্রক্রিয়াজাত হয়। পড়ার জন্য নথি বাইরে পাঠানো হয় না।
