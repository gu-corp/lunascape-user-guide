# প্রদর্শন সেটিংস পরিবর্তন করা

টুলবারের [প্রদর্শন সেটিংস] (গিয়ার) থেকে INDEX-এর চেহারা ও সম্পাদনা বোতামের প্রদর্শন প্রতিটি ব্যবহারকারী আলাদাভাবে পরিবর্তন করতে পারেন।

1. টুলবারের [প্রদর্শন সেটিংস] চাপুন।
2. যে অংশগুলো পরিবর্তন করতে চান সেগুলো বদলান। পরিবর্তন সঙ্গে সঙ্গেই কার্যকর হয়।
3. আবার [প্রদর্শন সেটিংস] চাপুন, বা প্যানেলের বাইরে চাপ দিয়ে বন্ধ করুন।

## যেসব সেটিংস পাওয়া যায়

| বিভাগ | অংশ | কাজ |
|---|---|---|
| নথির ভাষা | (বর্তমান অবস্থা) | প্রকল্পের ডিফল্ট ভাষা এবং বর্তমানে প্রদর্শিত ভাষা দেখায়। [প্রকল্পের ভাষা সেট করুন…] থেকে প্রকল্পের ভাষা সেটিংস খোলে |
| কনটেন্ট | [ফাইলের নাম] | নথির নামের বদলে ফাইলের নাম দেখায় |
| | [নথির আইকন] | নথির অংশে আইকন দেখায় |
| | [ফোল্ডারের আইকন] | ফোল্ডারের অংশে আইকন দেখায় |
| | [ফোল্ডারের ভেতরের সংখ্যা] | ফোল্ডারে থাকা নথির সংখ্যা দেখায় |
| | [স্তরের গাইড] | স্তর বোঝানোর গাইড রেখা দেখায় |
| | [নথি একটি হলে স্বয়ংক্রিয়ভাবে লুকান] | যে ডকুমেন্টেশন রুটে কেবল ১টি নথি আছে, সেখানে INDEX প্রথমবার স্বয়ংক্রিয়ভাবে বন্ধ করে |
| | [নথির তথ্য ভাঁজ করুন] | নথির শুরুর ব্যবস্থাপনা টেবিলটিকে "নথির তথ্য" সারিতে ভাঁজ করে। বন্ধ থাকলে টেবিলটি যেমন আছে তেমনই দেখায় |
| | [প্রদর্শন ঘনত্ব] | INDEX-এর সারির ব্যবধান [সাধারণ] / [কম্প্যাক্ট] থেকে বেছে নেয় |
| | [সম্পাদনা বোতাম] | মূল লেখার নিচে ডান দিকে [সম্পাদনা] দেখায় |
| ক্রিয়া | [প্রকল্পের ডিফল্টে ফিরে যান] | ব্যবহারকারীর সব পরিবর্তন মুছে প্রকল্পের সেটিংসে ফিরিয়ে নেয় |
| | [এক্সটেনশনের সেটিংস খুলুন] | VS Code-এর সেটিংস পর্দায় Lunascape Docs-এর সেটিংস খোলে |

> **ইঙ্গিত**
>
> - প্রদর্শন সেটিংস প্রতিটি ব্যবহারকারী ও প্রতিটি ডকুমেন্টেশন রুট অনুযায়ী সংরক্ষিত হয় এবং Git-এ পরিচালিত ফাইলে লেখা হয় না।
> - সেটিংসের অগ্রাধিকারের ক্রম হলো "ব্যবহারকারীর প্রদর্শন সেটিংস → VS Code সেটিংস → `lunascape-docs.json` → পণ্যের ডিফল্ট"। দলের সবার জন্য অভিন্ন ডিফল্ট মান `lunascape-docs.json`-এর `tree` ও `editor`-এ ঠিক করা হয়।

## রঙের বিন্যাস বদলানো

টুলবারের থিম পরিবর্তন (সূর্য/চাঁদ) চাপলে সাদা পটভূমি ও VS Code-এর রঙের বিন্যাসের মধ্যে বদল হয়। খোলার সময়ের রঙের বিন্যাস `lunascapeDocEditor.appearance` সেটিং (`light` বা `auto`) দিয়ে ঠিক হয়।
