# การใช้งานพื้นฐาน

การใช้งานพื้นฐานตั้งแต่การเปิดเอกสารไปจนถึงการย้ายไปยังหน้าที่ต้องการอ่าน

## เปิดเอกสาร

1. เปิดที่เก็บใน VS Code
2. เรียกใช้ "Lunascape Docs: เปิดโปรแกรมดูข้อกำหนด" จากแผงคำสั่ง (`⇧⌘P` / `Ctrl+Shift+P`)
   ระบบจะค้นหารากเอกสารที่ใกล้ที่สุด (ตามค่าเริ่มต้นคือโฟลเดอร์ `docs`) และแสดงหน้าเริ่มต้น

> **คำแนะนำ**
>
> - คลิกขวาที่ไฟล์ Markdown ในตัวสำรวจไฟล์ แล้วเลือก [Lunascape Docs: เปิดในโปรแกรมดูข้อกำหนด] เพื่อเริ่มจากไฟล์นั้น
> - เมื่อเปิดไฟล์ Markdown ที่ไม่ได้อยู่ในรากเอกสารใด ระบบจะแสดงโฟลเดอร์ของไฟล์นั้นเป็นรากเอกสารชั่วคราว

## ย้ายไปยังหน้าอื่น

| การทำงาน | วิธีการ |
|---|---|
| เปิดจากสารบัญ | กดชื่อเอกสารใน INDEX ทางด้านซ้าย |
| ตามลิงก์ | กดลิงก์ในเนื้อหา ลิงก์จะเปิดในหน้าจอเดียวกัน |
| ย้อนดูประวัติ | [ย้อนกลับ] [ไปข้างหน้า] บนแถบเครื่องมือ หรือ `Alt`+`←` / `Alt`+`→` |
| กลับไปยังหน้าเริ่มต้น | [หน้าแรกของข้อกำหนด] บนแถบเครื่องมือ |
| ขึ้นไปยังระดับบน | [INDEX ระดับบน] บนแถบเครื่องมือ หรือรายการในเส้นทางนำทาง |
| ย้ายภายในหน้า | กดหัวข้อใน "ในหน้านี้" ทางด้านขวา |

## ค้นหาเอกสาร

พิมพ์คำลงใน [กรองเอกสาร] ที่อยู่เหนือ INDEX แล้วระบบจะแสดงเฉพาะรายการที่ชื่อเอกสารตรงกัน เมื่อลบข้อความที่พิมพ์ออก ระบบจะกลับสู่สภาพเดิม

## อัปเดตให้เป็นเนื้อหาล่าสุด

เมื่อบันทึกไฟล์ Markdown ในตัวแก้ไขของ VS Code การแสดงผลจะอัปเดตโดยอัตโนมัติ หากแก้ไขด้วยเครื่องมือภายนอก ให้กด [โหลดใหม่] บนแถบเครื่องมือ

> **ข้อควรทราบ**
>
> - ลิงก์ภายนอกในเนื้อหา (เช่น `https://`) จะเปิดในเบราว์เซอร์เริ่มต้น ส่วนลิงก์ไปยังไฟล์ที่อยู่นอกรากเอกสารจะไม่เปิด
> - เอกสารที่กำลังอ่านจะถูกประมวลผลภายในเครื่อง ระบบจะไม่ส่งเอกสารออกไปภายนอกเพื่อการอ่าน
