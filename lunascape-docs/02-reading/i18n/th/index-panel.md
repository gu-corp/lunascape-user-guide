# การใช้ INDEX

INDEX ทางด้านซ้ายของหน้าจอคือแผนผังของโฟลเดอร์และเอกสารที่อยู่ในรากเอกสาร

## กรอง

1. พิมพ์คำลงใน [กรองเอกสาร] เหนือ INDEX
2. ระบบจะแสดงเฉพาะรายการที่ชื่อเอกสารตรงกัน ลบข้อความที่พิมพ์ออกเพื่อกลับไปแสดงทั้งหมด

> **ข้อควรทราบ**
>
> ระหว่างที่กรองอยู่ จะไม่สามารถจัดลำดับใหม่ด้วยการลากและวางได้

## เปิดและปิดโฟลเดอร์

- กดลูกศรทางซ้ายของชื่อโฟลเดอร์ หรือกดชื่อโฟลเดอร์ที่ไม่มีหน้าปก เพื่อเปิดหรือปิดโฟลเดอร์
- โฟลเดอร์ที่มีหน้าปก (`README.md` หรือ `index.md` ที่มีเนื้อหา) จะเปิดหน้าปกนั้นเมื่อกดที่ชื่อ หากต้องการเพียงเปิดหรือปิดโฟลเดอร์ ให้ใช้ [เปิดโฟลเดอร์] / [ปิดโฟลเดอร์] ในเมนูของรายการ
- สถานะการเปิดปิดโฟลเดอร์จะถูกจดจำไว้เป็นรายผู้ใช้ และจะไม่ถูกเขียนลงในไฟล์ที่อยู่ภายใต้การจัดการของ Git

## README และหน้าปกของโฟลเดอร์

`README.md` คือไฟล์ที่อธิบายสิ่งที่อยู่ในโฟลเดอร์นั้น

- โฟลเดอร์ที่มี README เมื่อกดชื่อโฟลเดอร์จะแสดง README นั้น
- โฟลเดอร์ที่ไม่มี README จะแสดงเอกสารรายการบนสุดที่อยู่ภายใน
- หัวเรื่อง (H1) ของ README จะกลายเป็นชื่อของโฟลเดอร์นั้นใน INDEX

README ไม่จำเป็นต้องมี หากต้องการเพิ่มภายหลัง ให้เลือก [สร้าง README] จากเมนูของรายการโฟลเดอร์ (จะแสดงเฉพาะโฟลเดอร์ที่ยังไม่มี README)

## แสดงหรือซ่อน INDEX

- ไอคอนด้านซ้ายในส่วนควบคุมคอลัมน์บนแถบเครื่องมือใช้แสดงหรือซ่อน INDEX ส่วนไอคอนด้านขวาใช้แสดงหรือซ่อน "ในหน้านี้"
- เมื่อหน้าจอแคบ INDEX จะเริ่มต้นในสถานะปิด กด [เปิด INDEX] (ขีดสามเส้น) ที่แสดงอยู่ทางซ้ายของ [ย้อนกลับ] แล้ว INDEX จะเปิดซ้อนทับอยู่เหนือเนื้อหา ปิดได้ด้วย [×] ใน INDEX การคลิกพื้นหลัง `Esc` หรือการย้ายไปยังเอกสารอื่น การเปิดปิดชั่วคราวนี้จะไม่เปลี่ยนการตั้งค่าของหน้าจอกว้าง
- ในรากเอกสารที่มีเอกสารให้แสดงเพียงรายการเดียว INDEX จะปิดเองโดยอัตโนมัติเฉพาะครั้งแรก เปิดใหม่ได้ด้วยไอคอนควบคุมคอลัมน์ ปิดการทำงานนี้ได้ที่ [ซ่อนอัตโนมัติเมื่อมีเอกสารเพียงรายการเดียว] ใน [การตั้งค่าการแสดงผล]

## การใช้เมนูของรายการ

เปิดเมนูของรายการได้จาก [⋯] ที่ปรากฏเมื่อวางเมาส์บนรายการใน INDEX หรือคลิกขวาที่รายการนั้น รายการในเมนูจะเรียงตามลำดับต่อไปนี้

| กลุ่ม | รายการ |
|---|---|
| การใช้งานที่ใช้บ่อย | [เปิดโฟลเดอร์] / [ปิดโฟลเดอร์], [เปิด INDEX] (เปิดหน้าปกของโฟลเดอร์), [แก้ไข], [เปลี่ยนชื่อเรื่อง], [เปิดใน VS Code], [คัดลอกเส้นทาง] |
| การสร้างและจัดระเบียบ | [สร้าง README] (เฉพาะโฟลเดอร์ที่ยังไม่มี README), [เอกสารใหม่], [โฟลเดอร์ใหม่], [ทำสำเนา], [เปลี่ยนชื่อไฟล์] / [เปลี่ยนชื่อโฟลเดอร์], [เลื่อนขึ้นหนึ่งลำดับ], [เลื่อนลงหนึ่งลำดับ] |
| การลบ | [ย้ายไปถังขยะ] |

- หากต้องการสร้างไว้ใต้รากเอกสารโดยตรง ให้กด [⋯] ที่ปลายขวาของหัวเรื่อง INDEX หรือคลิกขวาที่พื้นที่ว่างของ INDEX แล้วเลือก [เอกสารใหม่] หรือ [โฟลเดอร์ใหม่] ในเมนูเดียวกันจะมี [เปลี่ยนชื่อเอกสาร] และหากรากเอกสารยังไม่มี README ก็จะมี [สร้าง README] อยู่ด้วย การคลิกขวาที่ชื่อเอกสารบนแถบเครื่องมือก็เปิดเมนูเดียวกันนี้ได้
- ภายในเมนู ใช้ `↑` `↓` เพื่อเลื่อนไปมา และใช้ `Home` `End` เพื่อไปยังรายการแรกและรายการสุดท้าย เมื่อปิดด้วย `Esc` โฟกัสจะกลับไปยังตำแหน่งก่อนเปิดเมนู

> **ข้อควรทราบ**
>
> รายการสำหรับการสร้าง จัดระเบียบ และลบ จะแสดงเฉพาะเมื่อพื้นที่ทำงานนั้นเชื่อถือได้ใน VS Code เท่านั้น และจะใช้ไม่ได้ระหว่างที่กำลังแก้ไขเอกสารหรือระหว่างที่กำลังประมวลผลการทำงานอื่นของ INDEX

## การเปลี่ยนรูปแบบการแสดงผล

จาก [การตั้งค่าการแสดงผล] คุณสามารถเปลี่ยนการแสดงชื่อไฟล์ ไอคอนของเอกสารและโฟลเดอร์ จำนวนรายการในโฟลเดอร์ เส้นนำระดับชั้น และความหนาแน่นของการแสดงผลได้ รายละเอียดดูที่ [การเปลี่ยนการตั้งค่าการแสดงผล](display-settings.md)
