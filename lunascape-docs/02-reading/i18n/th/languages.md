# อ่านในภาษาอื่น

เอกสารที่มีคำแปลสามารถสลับภาษาเพื่ออ่านได้จากเมนูภาษา (รูปลูกโลก) บนแถบเครื่องมือ

## สลับภาษา

1. กดเมนูภาษาบนแถบเครื่องมือ
   ระบบจะแสดงภาษาของหน้าที่กำลังเปิดอยู่ พร้อมเหตุผลที่กำหนดภาษานั้น (เส้นทางของคำแปล การตรวจหาอัตโนมัติ หรือภาษาเริ่มต้นของโครงการ)
2. เลือกภาษาที่ต้องการอ่าน
   คำแปลของเอกสารเดียวกันจะเปิดขึ้น ภาษาที่เลือกจะถูกจดจำไว้ และเอกสารที่เปิดครั้งต่อไปจะแสดงด้วยภาษานั้นหากมีคำแปล

รายการภาษาจะแสดงว่าเอกสารนี้มีคำแปลในแต่ละภาษาหรือไม่

| การแสดงผล | ความหมาย |
|---|---|
| มีคำแปล | มีคำแปลอยู่และเปิดได้ |
| ไม่มีคำแปล | เป็นภาษาที่โครงการรองรับ แต่เอกสารนี้ยังไม่มีคำแปล |
| มีการอัปเดต | มีคำแปลอยู่ แต่เอกสารต้นทางถูกแก้ไขหลังจากที่แปลไว้ |

> **ข้อควรระวัง**
>
> - การเลือกภาษาเป็นเพียงการเปิดคำแปลที่มีอยู่แล้วเท่านั้น ไม่ได้สร้างคำแปลหรือสร้างไฟล์ขึ้นมา หากต้องการสร้างคำแปล ให้ใช้ [สร้างและจัดการคำแปล…] ในเมนูเดียวกัน
> - เมื่อระบบตัดสินว่าภาษาของหน้าที่กำลังเปิดอยู่ต่างจากภาษาเริ่มต้นของโครงการ จะมีคำเตือนปรากฏขึ้น การตั้งค่าจะไม่ถูกเขียนทับ

## ภาษาที่แสดงเป็นอันดับแรก

เมื่อเปิดเอกสาร ภาษาที่แสดงเป็นอันดับแรกจะถูกกำหนดตามลำดับต่อไปนี้

1. ภาษาที่คุณเคยเลือกไว้เองในรากเอกสารนี้ สิ่งที่เลือกไว้จะถูกบันทึก (แม้เลือกภาษาเริ่มต้น ก็ถูกบันทึกเป็นการเลือกเช่นกัน)
2. ภาษาที่แสดงของ VS Code (ในเวอร์ชันเว็บเบราว์เซอร์ คือการตั้งค่าภาษาของเบราว์เซอร์) ระบบจะเลือกภาษาที่ตรงกับภาษาที่รองรับโดยอัตโนมัติ ภาษาที่มีรหัสภูมิภาค (เช่น `en-US`) จะตรงกับภาษาพื้นฐาน (`en`) ด้วย
3. ภาษาสำรองของโครงการ (`fallbackLocale` ใน `lunascape-docs.json`)
4. ภาษาเริ่มต้นของโครงการ

> **คำแนะนำ**
>
> - เมื่อระบบเลือกให้โดยอัตโนมัติ ภาษาปัจจุบันในเมนูภาษาจะแสดงคำว่า "เลือกอัตโนมัติ" เมื่อวางตัวชี้เมาส์บนป้ายกำกับ จะแสดงเหตุผล
> - `fallbackLocale` คือภาษาที่จะแสดงแก่ผู้อ่านซึ่งภาษาของสภาพแวดล้อมการอ่านไม่ตรงกับภาษาที่รองรับใดเลย ในโครงการที่มีภาษาญี่ปุ่นเป็นเอกสารต้นฉบับและมีฉบับภาษาอังกฤษ หากตั้งค่าเป็น `"en"` ผู้อ่านที่ใช้สภาพแวดล้อมภาษาสเปนหรือภาษาอื่นก็จะเปิดฉบับภาษาอังกฤษ หากไม่ได้ตั้งค่าไว้ จะใช้ภาษาเริ่มต้น

## ที่เก็บคำแปล

เอกสารภาษาเริ่มต้นให้วางไว้ที่เดิม ส่วนคำแปลให้วางไว้ใน **`i18n/<ภาษา>/` ของโฟลเดอร์เดียวกัน** โดยใช้ชื่อไฟล์เดียวกัน

```text
docs/
  README.md                  ← ภาษาเริ่มต้น (ตัวอย่าง: ภาษาญี่ปุ่น)
  i18n/en/README.md          ← ฉบับภาษาอังกฤษของไฟล์นั้น
  guide/
    setup.md
    i18n/en/setup.md         ← ฉบับภาษาอังกฤษของไฟล์นั้น
```

> **ข้อควรระวัง**
>
> - การสร้างโครงสร้างโฟลเดอร์ขึ้นใหม่ภายใต้ `i18n/` (`i18n/en/guide/setup.md`) จะไม่ถูกรับรู้ ต้องวาง `i18n/` ไว้ในโฟลเดอร์เดียวกับเอกสารนั้นเสมอ
> - ตำแหน่งที่ใช้ค้นหาคำแปลมีเพียงแห่งเดียวนี้เท่านั้น แม้จะวางคำแปลของเอกสารเดียวกันไว้ใน `i18n/` ของโฟลเดอร์แม่ด้วย ก็ไม่เกิดการแย่งกันว่า "ฝ่ายใดมีลำดับความสำคัญกว่า" แต่ไฟล์ฝั่งนั้นจะกลายเป็นไฟล์โดดเดี่ยวที่ไม่ปรากฏทั้งในเมนูภาษาและในทะเบียน (และจะไม่ถูกลบโดยอัตโนมัติ) กรุณาอย่าวางคำแปลเดียวกันไว้ 2 แห่ง

## กรณีอ่านด้วยเวอร์ชันเว็บเบราว์เซอร์

ในเวอร์ชันเว็บเบราว์เซอร์ก็สลับภาษาได้เช่นเดียวกันหากมีคำแปล หากต้องการอ่านในภาษาที่ไม่มีคำแปล สามารถใช้ฟังก์ชันแปลหน้าเว็บของเบราว์เซอร์ได้ โค้ด สูตรคณิตศาสตร์ และแผนภาพจะถูกยกเว้นจากการแปล
