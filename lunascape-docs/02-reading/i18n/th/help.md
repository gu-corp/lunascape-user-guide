# การแสดงวิธีใช้

คู่มือวิธีใช้นี้มาพร้อมกับส่วนขยาย และอ่านได้ในหน้าจอเดียวกับเอกสารทั่วไป

## เปิดวิธีใช้

เปิดได้ด้วยวิธีใดวิธีหนึ่งต่อไปนี้

- กด [วิธีใช้] (?) ที่ปลายขวาของแถบเครื่องมือ
- เรียกใช้ "Lunascape Docs: เปิดวิธีใช้" จากแถบคำสั่ง

ขณะที่วิธีใช้เปิดอยู่ คุณใช้ INDEX ลิงก์ในเนื้อหา "ในหน้านี้" และ [ย้อนกลับ] [ไปข้างหน้า] ได้เหมือนกับเอกสารทั่วไป ประวัติการอ่านของวิธีใช้จะถูกเก็บแยกจากเอกสารของโครงการ และวิธีใช้จะไม่ถูกเพิ่มเข้าในรายการรากเอกสาร

## ปิดวิธีใช้

กด [วิธีใช้] บนแถบเครื่องมืออีกครั้ง หรือกด [×] ที่แสดงอยู่ทางขวาของปุ่มนั้น คุณจะกลับไปยังเอกสารที่อ่านอยู่ก่อนเปิดวิธีใช้ ที่ตำแหน่งการเลื่อนเดิม

## สลับภาษาของวิธีใช้

วิธีใช้มาพร้อมภาษาญี่ปุ่นและภาษาอังกฤษ รวมถึงภาษาอื่นที่ VS Code มีให้เป็นภาษาที่แสดง คุณสลับได้ทุกเมื่อโดยยังอยู่ที่หน้าที่อ่านอยู่

1. กดเมนูภาษา (รูปลูกโลก) บนแถบเครื่องมือ
2. เลือกภาษาที่ต้องการอ่าน
   หน้าเดียวกันจะแสดงในภาษาที่เลือก และตำแหน่งที่อ่านอยู่ยังคงเดิม

> **คำแนะนำ**
>
> ภาษาที่เลือกจะถูกจดจำไว้ และใช้แสดงในครั้งถัดไปที่เปิดวิธีใช้ หากยังไม่เคยสลับเลย ระบบจะเลือกตามลำดับ คือ ภาษาของเอกสารที่แสดงอยู่ ภาษาที่แสดงของ VS Code แล้วจึงเป็นภาษาญี่ปุ่น
>
> การสลับภาษาของวิธีใช้ไม่ทำให้ภาษาที่ใช้อ่านเอกสารของโครงการเปลี่ยนไป

> **ข้อควรระวัง**
>
> วิธีใช้เป็นแบบอ่านอย่างเดียว การแก้ไข การแปล การตรวจสอบ และการดำเนินการอื่นทำนองนี้ ไม่สามารถทำได้ขณะที่วิธีใช้แสดงอยู่
