# การสลับรากเอกสาร

รากเอกสารคือโฟลเดอร์บนสุดของเอกสารหนึ่งชุด INDEX การกรอง การตรวจสอบ และคำแปล ทั้งหมดทำงานแยกตามรากเอกสาร

## วิธีค้นหารากเอกสาร

Lunascape Docs จะไล่ขึ้นไปจากไฟล์ Markdown ที่เปิดอยู่ แล้วใช้โฟลเดอร์ที่ใกล้ที่สุดซึ่งตรงกับข้อใดข้อหนึ่งต่อไปนี้เป็นรากเอกสาร

- โฟลเดอร์ที่มี `lunascape-docs.json` (ชื่อโฟลเดอร์เป็นอะไรก็ได้)
- โฟลเดอร์ชื่อ `docs` (เพิ่มชื่ออื่นได้ด้วยการตั้งค่า `lunascapeDocEditor.rootDirectoryNames`)

เมื่อคุณเรียกใช้ "Lunascape Docs: เปิดตัวแสดงข้อกำหนด" ระบบจะเปิดรากเอกสารจากการตั้งค่า `lunascapeDocEditor.root` (ค่าเริ่มต้นคือ `docs`)

## สลับไปยังรากเอกสารอื่น

เมื่อพื้นที่ทำงานมีรากเอกสารหลายราก ชื่อรากเอกสารที่ริมซ้ายสุดของแถบเครื่องมือจะกลายเป็นเมนูแบบเลื่อนลง

1. กดชื่อรากเอกสารที่ริมซ้ายสุดของแถบเครื่องมือ
2. เลือกรากเอกสารจากรายการ
   หน้าเริ่มต้นของรากเอกสารนั้นจะแสดงขึ้น และ INDEX จะสลับตาม

> **เคล็ดลับ**
>
> ชื่อที่แสดงในรายการกำหนดตามลำดับต่อไปนี้ และจะไม่เปลี่ยนแม้คุณสลับภาษาที่แสดง
>
> 1. `title` ใน `lunascape-docs.json`
> 2. `navigation.title` ของ `README.md` ที่ราก หากไม่มีให้ใช้ H1 ของไฟล์นั้น
> 3. `navigation.title` ของ `index.md` ที่ราก หากไม่มีให้ใช้ H1 ของไฟล์นั้น
> 4. ชื่อโฟลเดอร์ (สำหรับโฟลเดอร์ `docs` มาตรฐาน จะใช้ชื่อโฟลเดอร์แม่)

## เปิด Markdown ที่ไม่อยู่ในรากเอกสารใด

เมื่อคุณเปิดไฟล์ Markdown ที่ไม่ได้อยู่ในรากเอกสาร ระบบจะแสดงโฟลเดอร์ของไฟล์นั้นเป็นรากเอกสารชั่วคราว INDEX จะแสดงรายการไฟล์ Markdown ในโฟลเดอร์เดียวกันและที่อยู่ใต้ลงไป

- กด [ขึ้นไปโฟลเดอร์บน] ในแถบเครื่องมือ เพื่อขยายขอบเขตการแสดงผลไปยังโฟลเดอร์แม่ภายในพื้นที่ทำงาน
- ในมุมมองนี้ จะใช้การตั้งค่าภาษาของโปรเจกต์และการแปลทั้งชุดไม่ได้ หากวาง `lunascape-docs.json` ไว้ในโฟลเดอร์นั้นเพื่อทำให้เป็นรากเอกสาร ก็จะใช้ได้

## เปิดรากเอกสารที่กำหนดไว้เสมอ

หากตั้งค่า `lunascapeDocEditor.rootMode` เป็น `fixed` ไม่ว่าคุณจะเปิดไฟล์ Markdown ใด ระบบจะเปิดรากเอกสารที่ `lunascapeDocEditor.root` เสมอ
