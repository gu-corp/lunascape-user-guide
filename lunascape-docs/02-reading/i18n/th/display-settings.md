# เปลี่ยนการตั้งค่าการแสดงผล

จาก [การตั้งค่าการแสดงผล] (รูปเฟือง) บนแถบเครื่องมือ ผู้ใช้แต่ละคนสามารถเปลี่ยนลักษณะการแสดงผลของ INDEX และการแสดงปุ่มแก้ไขได้

1. กด [การตั้งค่าการแสดงผล] บนแถบเครื่องมือ
2. สลับรายการที่ต้องการเปลี่ยน การเปลี่ยนแปลงจะมีผลทันที
3. กด [การตั้งค่าการแสดงผล] อีกครั้ง หรือกดนอกแผงเพื่อปิด

## รายการที่ตั้งค่าได้

| ประเภท | รายการ | การทำงาน |
|---|---|---|
| ภาษาของเอกสาร | (สถานะปัจจุบัน) | แสดงภาษาเริ่มต้นของโครงการและภาษาที่กำลังแสดงอยู่ [ตั้งค่าภาษาของโครงการ…] จะเปิดการตั้งค่าภาษาของโครงการ |
| เนื้อหา | [ชื่อไฟล์] | แสดงชื่อไฟล์แทนชื่อเอกสาร |
| | [ไอคอนเอกสาร] | แสดงไอคอนที่รายการเอกสาร |
| | [ไอคอนโฟลเดอร์] | แสดงไอคอนที่รายการโฟลเดอร์ |
| | [จำนวนรายการในโฟลเดอร์] | แสดงจำนวนเอกสารที่อยู่ในโฟลเดอร์ |
| | [เส้นนำระดับชั้น] | แสดงเส้นนำที่บอกระดับชั้น |
| | [ซ่อนอัตโนมัติเมื่อมีเอกสารเพียงรายการเดียว] | ในรากเอกสารที่มีเอกสารเพียง 1 รายการ จะปิด INDEX อัตโนมัติเฉพาะครั้งแรก |
| | [ย่อข้อมูลเอกสาร] | ย่อตารางจัดการที่อยู่ต้นเอกสารให้เหลือบรรทัด "ข้อมูลเอกสาร" เมื่อปิดไว้จะแสดงตารางตามเดิม |
| | [ความหนาแน่นการแสดงผล] | เลือกระยะห่างระหว่างบรรทัดของ INDEX จาก [มาตรฐาน] / [กระชับ] |
| | [ปุ่มแก้ไข] | แสดง [แก้ไข] ที่มุมขวาล่างของเนื้อหา |
| การดำเนินการ | [กลับไปใช้ค่าเริ่มต้นของโครงการ] | ลบการเปลี่ยนแปลงของผู้ใช้ทั้งหมด และกลับไปใช้การตั้งค่าของโครงการ |
| | [เปิดการตั้งค่าส่วนขยาย] | เปิดการตั้งค่าของ Lunascape Docs ในหน้าจอการตั้งค่าของ VS Code |

> **คำแนะนำ**
>
> - การตั้งค่าการแสดงผลจะถูกบันทึกแยกตามผู้ใช้และตามรากเอกสาร และจะไม่เขียนลงในไฟล์ที่จัดการด้วย Git
> - การตั้งค่ามีลำดับความสำคัญดังนี้ "การตั้งค่าการแสดงผลของผู้ใช้ → การตั้งค่า VS Code → `lunascape-docs.json` → ค่าเริ่มต้นของผลิตภัณฑ์" ค่าเริ่มต้นที่ใช้ร่วมกันทั้งทีมกำหนดได้ที่ `tree` และ `editor` ใน `lunascape-docs.json`

## สลับชุดสี

กดปุ่มสลับธีม (ดวงอาทิตย์／ดวงจันทร์) บนแถบเครื่องมือ เพื่อสลับระหว่างพื้นหลังสีขาวกับชุดสีของ VS Code ชุดสีเมื่อเปิดขึ้นมาครั้งแรกกำหนดด้วยการตั้งค่า `lunascapeDocEditor.appearance` (`light` หรือ `auto`)
