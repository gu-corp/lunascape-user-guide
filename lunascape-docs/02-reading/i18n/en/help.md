# Showing this help

This help guide is bundled with the extension and is read in the same view as ordinary documents.

## Open the help

Use either of the following.

- Press [ヘルプ] (Help, ?) at the right end of the toolbar.
- Run "Lunascape Docs: ヘルプを開く" (Open Help) from the Command Palette.

While the help is open, the INDEX, in-text links, "This page" and [戻る] (Back) / [進む] (Forward) work exactly as for ordinary documents. The help's browsing history is kept separately from the project documents, and the help is never added to the list of documentation roots.

## Close the help

Press [ヘルプ] (Help) in the toolbar again, or the [×] shown next to it. You return to the document you were reading, at the same scroll position.

## Switch the help language

The help ships in Japanese and English. You can switch at any time without leaving the page you are reading.

1. Press the language menu (globe) in the toolbar.
2. Choose [日本語] (Japanese) or [English].
   The same page appears in that language, at the same reading position.

> **Hint**
>
> Your choice is remembered and used the next time you open the help. Until you switch once, the language is chosen from the current document language, then the VS Code display language, then Japanese.
>
> Switching the help language never changes the language your project documents are read in.

> **Note**
>
> The help is read-only. Editing, translation, checks and similar actions are unavailable while the help is shown.
