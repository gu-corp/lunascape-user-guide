# 更改显示设置

在工具栏的 [显示设置]（齿轮）中，每位用户都可以更改 INDEX 的显示方式以及编辑按钮是否显示。

1. 按工具栏的 [显示设置]。
2. 切换要更改的项目。更改会立即生效。
3. 再次按 [显示设置]，或点击面板以外的位置将其关闭。

## 可设置的项目

| 分类 | 项目 | 作用 |
|---|---|---|
| 文档语言 | （当前状态） | 显示项目的默认语言和当前显示的语言。通过 [设置项目语言…] 打开项目的语言设置 |
| 内容 | [文件名] | 显示文件名，而不是文档名 |
| | [文档图标] | 在文档条目上显示图标 |
| | [文件夹图标] | 在文件夹条目上显示图标 |
| | [文件夹内条目数] | 显示文件夹中包含的文档数 |
| | [层级参考线] | 显示表示层级的参考线 |
| | [只有一个文档时自动隐藏] | 在只有 1 个文档的文档根目录中，仅首次自动关闭 INDEX |
| | [折叠文档信息] | 将文档开头的管理表格折叠为“文档信息”一行。关闭后则按原样显示表格 |
| | [显示密度] | 从 [标准] / [紧凑] 中选择 INDEX 的行间距 |
| | [编辑按钮] | 在正文右下角显示 [编辑] |
| 操作 | [恢复为项目默认值] | 清除用户的全部更改，恢复为项目的设置 |
| | [打开扩展设置] | 在 VS Code 的设置界面中打开 Lunascape Docs 的设置 |

> **提示**
>
> - 显示设置按用户、按文档根目录分别保存，不会写入由 Git 管理的文件。
> - 设置按“用户的显示设置 → VS Code 设置 → `lunascape-docs.json` → 产品默认值”的顺序优先。团队通用的默认值由 `lunascape-docs.json` 的 `tree` 和 `editor` 决定。

## 切换配色

按工具栏的主题切换按钮（太阳／月亮），可在白色背景和 VS Code 的配色之间切换。打开时的配色由设置 `lunascapeDocEditor.appearance`（`light` 或 `auto`）决定。
