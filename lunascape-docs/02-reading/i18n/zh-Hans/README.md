# 基本操作

从打开文档到跳转至想阅读的页面，这些是基本操作。

## 打开文档

1. 在 VS Code 中打开仓库。
2. 在命令面板（`⇧⌘P` / `Ctrl+Shift+P`）中执行“Lunascape Docs: 打开规格说明书查看器”。
   系统会找到最近的文档根目录（默认为 `docs` 文件夹），并显示其起始页。

> **提示**
>
> - 在资源管理器中右键单击 Markdown 文件，选择 [Lunascape Docs: 在规格说明书查看器中打开]，即可从该文件开始浏览。
> - 打开不属于任何文档根目录的 Markdown 文件时，会将其所在文件夹作为临时文档根目录显示。

## 在页面间跳转

| 操作 | 方法 |
|---|---|
| 从目录打开 | 在左侧 INDEX 中按文档名 |
| 跟随链接 | 按正文中的链接。会在同一画面内打开 |
| 浏览历史记录 | 工具栏的 [返回] [前进]，或 `Alt`+`←` / `Alt`+`→` |
| 返回起始页 | 工具栏的 [规格说明书首页] |
| 前往上一层级 | 工具栏的 [上级INDEX]，或导航路径中的项目 |
| 在页面内跳转 | 在右侧“本页目录”中按标题 |

## 查找文档

在 INDEX 上方的 [筛选文档] 中输入词语，只会显示文档名匹配的项目。清除输入即可恢复原状。

## 更新为最新内容

在 VS Code 编辑器中保存 Markdown 文件后，显示内容会自动更新。使用外部工具修改时，请按工具栏的 [重新加载]。

> **注意**
>
> - 正文中的外部链接（如 `https://`）将在默认浏览器中打开。指向文档根目录之外文件的链接不会打开。
> - 所浏览的文档在本机设备内处理。不会为了阅读而将文档发送到外部。
