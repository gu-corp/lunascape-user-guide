# 以其他语言阅读

对于有翻译版本的文档，可以从工具栏的语言菜单（地球仪）切换语言阅读。

## 切换语言

1. 按下工具栏的语言菜单。
   此处会显示当前页面的语言及其判定依据（翻译版本的路径、自动检测或项目的默认语言）。
2. 选择想要阅读的语言。
   会打开同一文档的翻译版本。所选语言会被记住，下次打开文档时，只要存在翻译版本就会以该语言显示。

语言列表会显示该文档是否有翻译版本。

| 显示 | 含义 |
|---|---|
| 有翻译 | 存在翻译版本，可以打开 |
| 无翻译 | 是项目支持的语言，但此文档尚无翻译版本 |
| 有更新 | 存在翻译版本，但翻译之后原文档已被修改 |

> **注意**
>
> - 选择语言只会打开已有的翻译版本，不会生成翻译，也不会创建文件。要创建翻译版本，请使用同一菜单中的 [创建/管理翻译…]。
> - 当判定当前页面的语言与项目的默认语言不同时，会显示警告。配置不会被改写。

## 最先显示的语言

打开文档时，最先显示的语言按以下顺序决定。

1. 你之前在此文档根目录中选择过的语言。所选内容会被保存（即使选择的是默认语言，也会作为选择保存）。
2. VS Code 的显示语言（在 Web 浏览器版中为浏览器的语言设置）。会自动选择与之匹配的支持语言。带地区的语言（如 `en-US`）也会与基础语言（`en`）匹配。
3. 项目的回退语言（`lunascape-docs.json` 中的 `fallbackLocale`）。
4. 项目的默认语言。

> **提示**
>
> - 自动选择时，语言菜单中的当前语言会显示“自动选择”。将指针悬停在徽标上即可看到原因。
> - `fallbackLocale` 是向阅读环境语言与任何支持语言都不匹配的读者显示的语言。在以日语为正本并拥有英语版本的项目中设置 `"en"`，则西班牙语等环境的读者会打开英语版本。未设置时使用默认语言。

## 翻译版本的存放位置

默认语言的文档保持在原位置，翻译版本则以相同的文件名放在**同一文件夹下的 `i18n/<语言>/`** 中。

```text
docs/
  README.md                  ← 默认语言（例如：日语）
  i18n/en/README.md          ← 其英语版本
  guide/
    setup.md
    i18n/en/setup.md         ← 其英语版本
```

> **注意**
>
> - 在 `i18n/` 下重建文件夹结构的形式（`i18n/en/guide/setup.md`）不会被识别。`i18n/` 必须放在与该文档相同的文件夹中。
> - 翻译版本的解析位置只有这一处。即使把同一文档的翻译放到父文件夹的 `i18n/` 中，也不会产生“哪一个优先”的冲突，那份文件会成为既不出现在语言菜单、也不出现在台账中的孤立文件（不会被自动删除）。请勿将同一份翻译放在两个地方。

## 在 Web 浏览器版中阅读

在 Web 浏览器版中，只要存在翻译版本，同样可以这样切换。想以没有翻译版本的语言阅读时，可以使用浏览器的页面翻译功能。代码、数学公式和图表已被排除在翻译对象之外。
