# 使用 INDEX

画面左侧的 INDEX 是文档根目录中文件夹和文档的树状列表。

## 筛选

1. 在 INDEX 上方的 [筛选文档] 中输入文字。
2. 只显示名称匹配的项目。清空输入框即可恢复原状。

> **注意**
>
> 筛选期间无法通过拖放调整排序。

## 展开和折叠文件夹

- 按文件夹名称左侧的箭头，或按没有封面页的文件夹名称，即可展开或折叠。
- 有封面页（含正文的 `README.md` 或 `index.md`）的文件夹，按名称会打开封面页。若只想展开或折叠，请使用项目菜单中的 [展开文件夹] / [折叠文件夹]。
- 文件夹的展开状态按用户分别记住，不会写入 Git 管理的文件。

## README 与文件夹封面

`README.md` 是说明该文件夹内容的文件。

- 对于有 README 的文件夹，按文件夹名称即可显示该 README。
- 没有 README 的文件夹则显示其中最上方的文档。
- README 的标题（H1）会成为 INDEX 中该文件夹的名称。

README 不是必需的。若要稍后添加，请在文件夹的项目菜单中选择 [创建 README]（仅对没有 README 的文件夹显示）。

## 显示／隐藏 INDEX

- 使用工具栏分栏显示中左侧的图标，可显示或隐藏 INDEX。右侧的图标用于显示或隐藏"本页目录"。
- 屏幕较窄时，INDEX 以折叠状态开始。按 [返回] 左侧显示的 [打开 INDEX]（三条横线），INDEX 会叠加在正文之上打开。按 INDEX 中的 [×]、点击背景、按 `Esc` 或切换文档即可关闭。这种临时的开合不会更改宽屏幕下的设置。
- 在只显示一个文档的文档根目录中，仅首次会自动折叠 INDEX。可用分栏显示的图标重新打开。此行为可在 [显示设置] 的 [只有一个文档时自动隐藏] 中关闭。

## 使用项目菜单

将鼠标移到 INDEX 的项目上会显示 [⋯]，按它或右键单击该项目，即可打开该项目的菜单。项目按以下顺序排列。

| 分组 | 项目 |
|---|---|
| 常用操作 | [展开文件夹] / [折叠文件夹]、[打开 INDEX]（打开文件夹的封面页）、[编辑]、[修改标题]、[在 VS Code 中打开]、[复制路径] |
| 创建与整理 | [创建 README]（仅限没有 README 的文件夹）、[新建文档]、[新建文件夹]、[创建副本]、[修改文件名] / [修改文件夹名]、[上移一项]、[下移一项] |
| 删除 | [移至回收站] |

- 若要在文档根目录下直接创建，请按 INDEX 标题右端的 [⋯]，或右键单击 INDEX 的空白部分，然后选择 [新建文档] 或 [新建文件夹]。同一菜单中还有 [修改文档名]，若文档根目录没有 README，则还会显示 [创建 README]。右键单击工具栏上显示的文档名，也会打开同样的菜单。
- 在菜单中用 `↑` `↓` 移动，用 `Home` `End` 移到开头和末尾。按 `Esc` 关闭后，焦点会回到打开菜单前的位置。

> **注意**
>
> 创建、整理和删除类项目只在 VS Code 中信任工作区时才会显示。在编辑文档期间，或正在处理其他 INDEX 操作期间，也无法使用。

## 更改外观

在 [显示设置] 中可以更改文件名的显示、文档和文件夹的图标、文件夹内的项目数、层级引导线以及显示密度。详情请参阅 [更改显示设置](display-settings.md)。
