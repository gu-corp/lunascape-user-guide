# 显示帮助

本帮助指南随扩展一同提供，可在与普通文档相同的界面中阅读。

## 打开帮助

用以下任一方法打开。

- 按工具栏最右端的 [帮助]（?）。
- 在命令面板中执行"Lunascape Docs: 打开帮助"。

帮助打开期间，INDEX、正文链接、"本页目录"、[返回] [前进] 的用法与普通文档完全相同。帮助的浏览历史与项目文档分开保存，文档根目录的列表中不会加入帮助。

## 关闭帮助

再次按工具栏的 [帮助]，或按其右侧显示的 [×]。即可返回打开帮助前正在阅读的文档，滚动位置保持不变。

## 切换帮助的语言

帮助除日语和英语外，还附带 VS Code 可作为界面语言使用的其他语言。可以随时切换，无需离开正在阅读的页面。

1. 按工具栏的语言菜单（地球仪）。
2. 选择想阅读的语言。
   同一页面会以所选语言显示，阅读位置也保持不变。

> **提示**
>
> 所选语言会被记住，下次打开帮助时仍以该语言显示。若一次也没有切换过，则按当前显示文档的语言、VS Code 的界面语言、日语的顺序选择。
>
> 切换帮助的语言，不会改变阅读项目文档所用的语言。

> **注意**
>
> 帮助为只读。显示帮助期间无法进行编辑、翻译、检查等操作。
