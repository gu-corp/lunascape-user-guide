# Operasi asas

Operasi asas dari membuka dokumen sehingga sampai ke halaman yang ingin anda baca.

## Membuka dokumen

1. Buka repositori dalam VS Code.
2. Jalankan "Lunascape Docs: Buka pemapar spesifikasi" daripada Palet Perintah (`⇧⌘P` / `Ctrl+Shift+P`).
   Akar dokumentasi yang terdekat (folder `docs` secara lalai) ditemui dan halaman mulanya dipaparkan.

> **Petua**
>
> - Klik kanan fail Markdown dalam Penjelajah dan pilih [Lunascape Docs: Buka dalam pemapar spesifikasi] untuk bermula daripada fail itu.
> - Apabila anda membuka fail Markdown yang tidak tergolong dalam mana-mana akar dokumentasi, folder fail itu dipaparkan sebagai akar dokumentasi sementara.

## Berpindah antara halaman

| Tindakan | Cara |
|---|---|
| Buka daripada isi kandungan | Tekan nama dokumen dalam INDEX di sebelah kiri |
| Ikut pautan | Tekan pautan dalam teks. Pautan itu dibuka dalam paparan yang sama |
| Susuri sejarah | [Kembali] dan [Ke hadapan] pada bar alat, atau `Alt`+`←` / `Alt`+`→` |
| Kembali ke halaman mula | [Laman utama spesifikasi] pada bar alat |
| Naik satu peringkat | [INDEX induk] pada bar alat, atau item pada jejak laluan |
| Bergerak dalam halaman | Tekan tajuk dalam "Pada halaman ini" di sebelah kanan |

## Mencari dokumen

Taipkan perkataan dalam [Tapis dokumen] di atas INDEX untuk memaparkan hanya dokumen yang namanya sepadan. Kosongkan medan itu untuk memaparkan semula semuanya.

## Mengemas kini kepada kandungan terbaharu

Apabila anda menyimpan fail Markdown dalam editor VS Code, paparan dikemas kini secara automatik. Setelah membuat perubahan dengan alat luaran, tekan [Muat semula] pada bar alat.

> **Perhatian**
>
> - Pautan luaran dalam teks (`https://` dan sebagainya) dibuka dalam pelayar lalai anda. Pautan ke fail di luar akar dokumentasi tidak dibuka.
> - Dokumen yang anda baca diproses dalam peranti anda. Tiada dokumen dihantar ke luar untuk tujuan pembacaan.
