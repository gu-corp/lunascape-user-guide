# Основные операции

Основные действия: от открытия документов до перехода на нужную страницу.

## Открытие документов

1. Откройте репозиторий в VS Code.
2. В палитре команд (`⇧⌘P` / `Ctrl+Shift+P`) выполните команду «Lunascape Docs: Открыть просмотр спецификации».
   Будет найден ближайший корень документации (по умолчанию папка `docs`) и показана его начальная страница.

> **Совет**
>
> - Щелкните правой кнопкой мыши файл Markdown в проводнике и выберите [Lunascape Docs: Открыть в просмотре спецификации], чтобы начать с этого файла.
> - Если открыть файл Markdown, не относящийся ни к одному корню документации, его папка будет показана как временный корень документации.

## Переход между страницами

| Действие | Способ |
|---|---|
| Открыть из оглавления | Нажмите название документа в INDEX слева |
| Перейти по ссылке | Нажмите ссылку в тексте. Она откроется в том же окне |
| Перемещаться по истории | Кнопки [Назад] и [Вперед] на панели инструментов либо `Alt`+`←` / `Alt`+`→` |
| Вернуться на начальную страницу | [Главная страница спецификации] на панели инструментов |
| Подняться на уровень выше | [Родительский INDEX] на панели инструментов или элемент цепочки навигации |
| Перемещаться внутри страницы | Нажмите заголовок в панели «На этой странице» справа |

## Поиск документа

Введите слово в поле [Фильтр документов] над INDEX — останутся только документы, названия которых совпадают. Очистите поле, чтобы вернуть прежний список.

## Обновление содержимого

При сохранении файла Markdown в редакторе VS Code представление обновляется автоматически. Если файлы изменены внешним средством, нажмите [Обновить] на панели инструментов.

> **Примечание**
>
> - Внешние ссылки (`https://` и подобные) открываются в браузере по умолчанию. Ссылки на файлы за пределами корня документации не открываются.
> - Документы обрабатываются на вашем устройстве. Для чтения документа никакие данные никуда не передаются.
