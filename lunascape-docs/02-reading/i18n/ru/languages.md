# Чтение на другом языке

Если у документа есть переводы, язык можно переключить в языковом меню (глобус) на панели инструментов.

## Переключение языка

1. Нажмите языковое меню на панели инструментов.
   Отображаются язык текущей страницы и то, как он был определен (путь к переводу, автоматическое определение, язык проекта по умолчанию).
2. Выберите язык, на котором хотите читать.
   Откроется перевод того же документа. Выбранный язык запоминается, и следующий открытый документ будет показан на этом языке, если перевод существует.

В списке языков указано, есть ли у этого документа перевод.

| Отображение | Значение |
|---|---|
| Есть перевод | Перевод существует, его можно открыть |
| Нет перевода | Язык поддерживается проектом, но у этого документа перевода пока нет |
| Устарел | Перевод есть, но исходный документ изменился после перевода |

> **Примечание**
>
> - Выбор языка лишь открывает уже существующий перевод. Он не создает перевод и не создает файлов. Чтобы создать перевод, используйте [Создать и управлять переводами…] в том же меню.
> - Если определено, что язык текущей страницы отличается от языка проекта по умолчанию, выводится предупреждение. Настройки при этом не изменяются.

## Язык, на котором документ открывается первым

При открытии документа язык отображения определяется в следующем порядке.

1. Язык, который вы ранее выбрали сами в этом корне документации. Выбор сохраняется (выбор языка по умолчанию тоже сохраняется как выбор).
2. Язык интерфейса VS Code (в веб-версии — языковые настройки браузера). Автоматически выбирается совпадающий поддерживаемый язык. Язык с указанием региона (например, `en-US`) совпадает и с базовым языком (`en`).
3. Резервный язык проекта (`fallbackLocale` в `lunascape-docs.json`).
4. Язык проекта по умолчанию.

> **Совет**
>
> - Если язык был выбран автоматически, рядом с текущим языком в языковом меню отображается «Выбрано автоматически». Наведите указатель на значок, чтобы увидеть причину.
> - `fallbackLocale` — это язык, который показывается читателям, чей язык среды не совпадает ни с одним из поддерживаемых языков. Если в проекте с японским исходным документом и английской версией задать `"en"`, читателю, например, с испаноязычной средой откроется английская версия. Если параметр не задан, используется язык по умолчанию.

## Где хранятся переводы

Документы на языке по умолчанию остаются на своем месте, а переводы помещаются в **папку `i18n/<язык>/` рядом с документом** под тем же именем файла.

```text
docs/
  README.md                  ← default language (for example Japanese)
  i18n/en/README.md          ← its English translation
  guide/
    setup.md
    i18n/en/setup.md         ← its English translation
```

> **Примечание**
>
> - Воссоздание структуры папок внутри `i18n/` (`i18n/en/guide/setup.md`) не распознается. Папка `i18n/` всегда располагается рядом с документом, который она переводит.
> - Перевод разрешается только из этого единственного места. Если поместить перевод того же документа еще и в `i18n/` родительской папки, конфликта приоритетов не возникнет: такой файл станет изолированным и не появится ни в языковом меню, ни в реестре (и не будет удален автоматически). Не размещайте один и тот же перевод в двух местах.

## Чтение в веб-версии

В веб-версии язык переключается точно так же, если перевод существует. Чтобы прочитать документ на языке, для которого перевода нет, можно воспользоваться функцией перевода страницы в браузере. Код, формулы и схемы исключены из перевода.
