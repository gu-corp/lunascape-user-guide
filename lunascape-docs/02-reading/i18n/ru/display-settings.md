# Изменение параметров отображения

С помощью кнопки [Параметры отображения] (шестерёнка) на панели инструментов каждый пользователь может изменить вид панели INDEX и отображение кнопки редактирования.

1. Нажмите [Параметры отображения] на панели инструментов.
2. Переключите нужные пункты. Изменения применяются сразу.
3. Нажмите [Параметры отображения] ещё раз или щёлкните вне панели, чтобы закрыть её.

## Доступные параметры

| Раздел | Пункт | Назначение |
|---|---|---|
| Язык документа | (текущее состояние) | Показывает язык проекта по умолчанию и текущий язык отображения. Пункт [Настроить языки проекта…] открывает языковые параметры проекта |
| Содержимое | [Имена файлов] | Показывает имена файлов вместо названий документов |
| | [Значки документов] | Показывает значок у каждого документа |
| | [Значки папок] | Показывает значок у каждой папки |
| | [Число элементов в папке] | Показывает количество документов в папке |
| | [Направляющие отступов] | Показывает линии, обозначающие уровни вложенности |
| | [Скрывать, если документ только один] | В корне документации с единственным документом закрывает INDEX один раз, при первом открытии |
| | [Свернуть сведения о документе] | Сворачивает служебную таблицу в начале документа в строку «Сведения о документе». Если параметр выключен, таблица показывается как есть |
| | [Плотность отображения] | Межстрочный интервал в INDEX: [Обычный] или [Компактная] |
| | [Кнопка редактирования] | Показывает кнопку [Редактировать] в правом нижнем углу документа |
| Действия | [Вернуть настройки проекта по умолчанию] | Удаляет все изменения пользователя и возвращает параметры проекта |
| | [Открыть параметры расширения] | Открывает параметры Lunascape Docs в окне настроек VS Code |

> **Совет**
>
> - Параметры отображения сохраняются отдельно для каждого пользователя и каждого корня документации и не записываются в файлы под управлением Git.
> - Параметры применяются в следующем порядке: параметры отображения пользователя → параметры VS Code → `lunascape-docs.json` → значения продукта по умолчанию. Общие для команды значения задаются в разделах `tree` и `editor` файла `lunascape-docs.json`.

## Переключение цветовой схемы

Нажмите переключатель темы (солнце/луна) на панели инструментов, чтобы переключиться между белым фоном и цветовой схемой VS Code. Схема при открытии определяется параметром `lunascapeDocEditor.appearance` (`light` или `auto`).
