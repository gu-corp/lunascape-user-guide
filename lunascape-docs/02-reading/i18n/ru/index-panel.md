# Работа с INDEX

INDEX в левой части экрана — это дерево папок и документов в корне документации.

## Фильтрация

1. Введите слово в поле [Фильтр документов] над INDEX.
2. Отображаются только документы с совпадающими именами. Очистите поле — список вернется к прежнему виду.

> **Примечание**
>
> Во время фильтрации изменить порядок перетаскиванием нельзя.

## Развертывание и свертывание папок

- Нажмите стрелку слева от имени папки или имя папки без титульной страницы, чтобы развернуть или свернуть ее.
- Папка с титульной страницей (`README.md` или `index.md` с содержимым) при нажатии на имя открывает эту страницу. Чтобы только развернуть или свернуть ее, используйте [Развернуть папку] / [Свернуть папку] в меню элемента.
- Состояние развертывания сохраняется для каждого пользователя и не записывается в файлы под управлением Git.

## README и титульная страница папки

`README.md` — это файл, который описывает содержимое папки.

- Если в папке есть README, нажатие на имя папки открывает его.
- Если README нет, открывается первый документ внутри папки.
- Заголовок README (H1) становится именем этой папки в INDEX.

README не обязателен. Чтобы добавить его позже, выберите [Создать README] в меню элемента папки (пункт отображается только для папок без README).

## Показ и скрытие INDEX

- Левый значок в настройках колонок на панели инструментов показывает или скрывает INDEX. Правый значок показывает или скрывает «На этой странице».
- На узком экране INDEX открывается свернутым. Нажмите [Открыть INDEX] (три полоски) слева от [Назад] — INDEX откроется поверх текста документа. Закрыть его можно кнопкой [×] внутри INDEX, щелчком по фону, клавишей `Esc` или переходом к другому документу. Это временное состояние не изменяет настройку для широкого экрана.
- В корне документации, где отображается только один документ, INDEX автоматически сворачивается при первом открытии. Снова открыть его можно значком колонок. Это поведение отключается параметром [Скрывать, если документ только один] в [Параметры отображения].

## Работа с меню элемента

Наведите указатель на элемент INDEX и нажмите появившийся [⋯] или щелкните элемент правой кнопкой мыши, чтобы открыть его меню. Пункты расположены в следующем порядке.

| Группа | Пункты |
|---|---|
| Частые действия | [Развернуть папку] / [Свернуть папку], [Открыть INDEX] (открыть титульную страницу папки), [Редактировать], [Изменить заголовок], [Открыть в VS Code], [Копировать путь] |
| Создание и упорядочивание | [Создать README] (только для папок без README), [Новый документ], [Новая папка], [Дублировать], [Изменить имя файла] / [Изменить имя папки], [Переместить выше], [Переместить ниже] |
| Удаление | [Переместить в корзину] |

- Чтобы создать элемент непосредственно в корне документации, нажмите [⋯] у правого края заголовка INDEX или щелкните правой кнопкой мыши по пустому месту INDEX, затем выберите [Новый документ] или [Новая папка]. В том же меню есть пункт [Изменить имя документа], а если в корне документации нет README — то и [Создать README]. То же меню открывается при щелчке правой кнопкой мыши по имени документа на панели инструментов.
- Внутри меню используйте `↑` `↓` для перемещения между пунктами, `Home` `End` — для перехода к первому и последнему. Клавиша `Esc` закрывает меню и возвращает фокус туда, где он был до открытия.

> **Примечание**
>
> Пункты создания, упорядочивания и удаления отображаются только тогда, когда рабочая область в VS Code является надежной. Они также недоступны во время редактирования документа или пока выполняется другая операция в INDEX.

## Изменение внешнего вида

В разделе [Параметры отображения] можно включить показ имен файлов, значков документов и папок, количества элементов в папке, направляющих линий уровней, а также изменить плотность отображения. Подробнее см. [Изменение параметров отображения](display-settings.md).
