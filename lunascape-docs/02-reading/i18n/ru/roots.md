# Переключение корней документации

Корень документации — это верхняя папка одного набора документов. INDEX, фильтрация, проверки и перевод работают в пределах одного корня документации.

## Как определяется корень документации

Lunascape Docs поднимается вверх по родительским папкам от открытого файла Markdown и делает корнем документации ближайшую папку, отвечающую одному из следующих условий.

- Папка, в которой есть `lunascape-docs.json` (имя папки не важно)
- Папка с именем `docs` (другие имена можно добавить в параметре `lunascapeDocEditor.rootDirectoryNames`)

При выполнении команды «Lunascape Docs: Открыть просмотр спецификаций» открывается корень документации, заданный параметром `lunascapeDocEditor.root` (по умолчанию `docs`).

## Переключение на другой корень документации

Если в рабочей области несколько корней документации, имя корня в левом краю панели инструментов становится раскрывающимся списком.

1. Нажмите имя корня документации в левом краю панели инструментов.
2. Выберите корень документации из списка.
   Откроется начальная страница выбранного корня, и INDEX переключится.

> **Совет**
>
> Имена в списке определяются в следующем порядке. При смене языка интерфейса они не меняются.
>
> 1. `title` в `lunascape-docs.json`
> 2. `navigation.title` файла `README.md` в корне, иначе его заголовок H1
> 3. `navigation.title` файла `index.md` в корне, иначе его заголовок H1
> 4. Имя папки (для стандартной папки `docs` — имя её родительской папки)

## Открытие файла Markdown вне корня документации

Если открыть файл Markdown, не входящий ни в один корень документации, его папка отображается как временный корень документации. В INDEX перечисляются файлы Markdown в этой папке и во вложенных папках.

- Нажмите [На папку вверх] на панели инструментов, чтобы расширить область просмотра до родительской папки в пределах рабочей области.
- В этом режиме языковые параметры проекта и пакетный перевод недоступны. Поместите в папку файл `lunascape-docs.json`, чтобы сделать её корнем документации, и они станут доступны.

## Всегда открывать один и тот же корень документации

Задайте параметру `lunascapeDocEditor.rootMode` значение `fixed`, и тогда при открытии любого файла Markdown всегда будет открываться корень документации, указанный в `lunascapeDocEditor.root`.
