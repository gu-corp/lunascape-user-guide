# ヘルプを表示する

このヘルプガイドは拡張機能に同梱されており、通常の文書と同じ画面で読めます。

## ヘルプを開く

次のいずれかの方法で開きます。

- ツールバー右端の [ヘルプ]（?）を押します。
- コマンドパレットで「Lunascape Docs: ヘルプを開く」を実行します。

ヘルプが開いている間は、INDEX、本文リンク、「このページ」、[戻る] [進む] を、通常の文書と同じように使えます。ヘルプの閲覧履歴はプロジェクトの文書とは別に保持され、文書ルートの一覧にヘルプが加わることはありません。

## ヘルプを閉じる

ツールバーの [ヘルプ] をもう一度押すか、その右に表示される [×] を押します。ヘルプを開く前に読んでいた文書に、同じスクロール位置で戻ります。

## ヘルプの言語を切り替える

ヘルプは日本語と英語を同梱しています。読んでいるページのまま、いつでも切り替えられます。

1. ツールバーの言語メニュー（地球儀）を押します。
2. [日本語] または [English] を選びます。
   同じページが選んだ言語で表示され、読んでいた位置もそのままです。

> **ヒント**
>
> 選んだ言語は記憶され、次にヘルプを開いたときも同じ言語で表示します。一度も切り替えていない場合は、表示中の文書の言語、VS Code の表示言語、日本語の順に選ばれます。
>
> ヘルプの言語を切り替えても、プロジェクトの文書を読む言語は変わりません。

> **ご注意**
>
> ヘルプは読み取り専用です。編集、翻訳、チェックなどの操作は、ヘルプの表示中には行えません。
