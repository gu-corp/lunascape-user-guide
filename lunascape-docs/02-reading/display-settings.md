# 表示設定を変更する

ツールバーの [表示設定]（歯車）から、INDEX の見せかたや編集ボタンの表示を、利用者ごとに変更できます。

1. ツールバーの [表示設定] を押します。
2. 変更したい項目を切り替えます。変更はすぐに反映されます。
3. もう一度 [表示設定] を押すか、パネルの外を押して閉じます。

## 設定できる項目

| 区分 | 項目 | 働き |
|---|---|---|
| 文書言語 | （現在の状態） | プロジェクトの既定言語と表示中の言語を表示します。[プロジェクト言語を設定…] からプロジェクトの言語設定を開きます |
| コンテンツ | [ファイル名] | 文書名の代わりにファイル名を表示します |
| | [文書アイコン] | 文書項目にアイコンを表示します |
| | [フォルダアイコン] | フォルダ項目にアイコンを表示します |
| | [フォルダ内件数] | フォルダに含まれる文書数を表示します |
| | [階層ガイド] | 階層を示すガイド線を表示します |
| | [文書が1件なら自動的に隠す] | 文書が 1 件だけの文書ルートで、INDEX を初回だけ自動的に閉じます |
| | [文書情報を折りたたむ] | 文書先頭の管理表を「文書情報」の行に折りたたみます。オフにすると表をそのまま表示します |
| | [表示密度] | INDEX の行間を [標準] / [コンパクト] から選びます |
| | [編集ボタン] | 本文右下の [編集] を表示します |
| 操作 | [プロジェクト既定に戻す] | 利用者の変更をすべて消し、プロジェクトの設定に戻します |
| | [拡張機能設定を開く] | VS Code の設定画面で Lunascape Docs の設定を開きます |

> **ヒント**
>
> - 表示設定は利用者ごと・文書ルートごとに保存され、Git で管理されるファイルには書き込みません。
> - 設定は「利用者の表示設定 → VS Code 設定 → `lunascape-docs.json` → 製品既定」の順に優先されます。チーム共通の既定値は `lunascape-docs.json` の `tree` と `editor` で決めます。

## 配色を切り替える

ツールバーのテーマ切替（太陽／月）を押すと、白背景と VS Code の配色を切り替えます。開いたときの配色は、設定 `lunascapeDocEditor.appearance`（`light` または `auto`）で決まります。
