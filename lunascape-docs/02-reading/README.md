# 基本操作

文書を開いてから、読みたいページへ移動するまでの基本の操作です。

## 文書を開く

1. VS Code でリポジトリを開きます。
2. コマンドパレット（`⇧⌘P` / `Ctrl+Shift+P`）で「Lunascape Docs: 仕様書ビューアーを開く」を実行します。
   最も近い文書ルート（既定では `docs` フォルダ）が見つかり、開始ページが表示されます。

> **ヒント**
>
> - エクスプローラーで Markdown ファイルを右クリックし、[Lunascape Docs: 仕様書ビューアーで開く] を選ぶと、そのファイルから開けます。
> - 文書ルートに属さない Markdown ファイルを開くと、そのフォルダを一時的な文書ルートとして表示します。

## ページを移動する

| 操作 | 方法 |
|---|---|
| 目次から開く | 左の INDEX で文書名を押します |
| リンクをたどる | 本文中のリンクを押します。同じ画面内で開きます |
| 履歴をたどる | ツールバーの [戻る] [進む]、または `Alt`+`←` / `Alt`+`→` |
| 開始ページへ戻る | ツールバーの [仕様書トップ] |
| 上の階層へ | ツールバーの [親INDEX]、またはパンくずの項目 |
| ページ内を移動する | 右の「このページ」で見出しを押します |

## 文書を探す

INDEX の上の [文書を絞り込み] に言葉を入力すると、文書名が一致する項目だけが表示されます。入力を消すと元に戻ります。

## 最新の内容に更新する

Markdown ファイルを VS Code のエディターで保存すると、表示は自動的に更新されます。外部のツールで変更したときは、ツールバーの [再読み込み] を押します。

> **ご注意**
>
> - 本文中の外部リンク（`https://` など）は既定のブラウザで開きます。文書ルートの外にあるファイルへのリンクは開きません。
> - 閲覧している文書は端末内で処理されます。閲覧のために文書を外部へ送ることはありません。
