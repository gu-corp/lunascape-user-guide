# Lista poleceń

Wpisz „Lunascape Docs” w palecie poleceń (`⇧⌘P` / `Ctrl+Shift+P`), aby uruchomić następujące polecenia.

| Polecenie | Działanie |
|---|---|
| Lunascape Docs: Otwórz przeglądarkę specyfikacji | Otwiera najbliższy katalog główny dokumentacji w przeglądarce. Czytanie, edytowanie, sprawdzanie i tłumaczenie odbywa się w tym widoku |
| Lunascape Docs: Otwórz w przeglądarce specyfikacji | Wyświetla w przeglądarce plik Markdown otwarty w edytorze |
| Lunascape Docs: Utwórz dokument z szablonu | Tworzy pierwszy zestaw dokumentów w projekcie, który nie ma folderu dokumentów |
| Lunascape Docs: Sprawdź katalog główny dokumentacji | Sprawdza cały katalog główny dokumentacji za pomocą docs-lint i pokazuje wyniki w Narzędziach dokumentów oraz w panelu „Problemy” |
| Lunascape Docs: Otwórz pomoc | Otwiera ten przewodnik pomocy |

## Obsługa z Eksploratora

Kliknij prawym przyciskiem myszy plik `.md`, `.markdown` lub `.mdx` w Eksploratorze i wybierz [Lunascape Docs: Otwórz w przeglądarce specyfikacji].

> **Wskazówka**
>
> Aby pliki Markdown otwierały się w Lunascape Docs również przy zwykłym otwieraniu, dodaj powiązanie edytora w ustawieniach obszaru roboczego.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Przewodnik wprowadzający

Przewodnik „Rozpocznij pracę z Lunascape Docs”, dostępny w menu [Pomoc] → „Zapraszamy” w VS Code, pozwala wypróbować pierwsze czynności po kolei.
