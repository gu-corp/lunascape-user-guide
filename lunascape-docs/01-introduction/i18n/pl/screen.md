# Nazwy i funkcje elementów ekranu

Ekran Lunascape Docs składa się z paska narzędzi na górze, panelu INDEX po lewej, treści dokumentu pośrodku oraz panelu „Na tej stronie" po prawej.

## Pasek narzędzi

Opis od lewej do prawej.

| Nazwa | Działanie |
|---|---|
| Nazwa katalogu głównego dokumentacji | Nazwa wyświetlanego zestawu dokumentów. Gdy obszar roboczy zawiera kilka katalogów głównych dokumentacji, staje się listą rozwijaną umożliwiającą przełączanie |
| [Otwórz INDEX] (trzy linie) | Widoczne tylko przy wąskim ekranie. Otwiera INDEX nałożony na treść dokumentu |
| [Wstecz] [Dalej] | Poruszanie się po historii przeglądania |
| [Strona główna specyfikacji] (domek) | Otwiera stronę początkową katalogu głównego dokumentacji (zwykle `README.md`) |
| [Nadrzędny INDEX] (↑) | Otwiera stronę tytułową folderu, w którym znajduje się wyświetlany dokument. Przy tymczasowym otwarciu folderu zmienia się w [Do folderu nadrzędnego] |
| [Załaduj ponownie] | Ponownie wczytuje dokument i INDEX |
| Ścieżka nawigacji | Położenie wyświetlanego dokumentu. Naciśnięcie elementu przenosi na dany poziom |
| Menu języka (globus) | Pokazuje język wyświetlanej strony oraz języki, na które można przełączyć. Znajduje się tu również [Utwórz lub zarządzaj tłumaczeniami…] |
| Przełącznik motywu (słońce/księżyc) | Przełącza między białym tłem a kolorystyką VS Code |
| Wyświetlanie kolumn | Niezależnie pokazuje lub ukrywa INDEX po lewej i „Na tej stronie" po prawej |
| [Narzędzia dokumentów] (znacznik wyboru) | Otwiera panel sprawdzania dokumentów, tworzenia z szablonu i tłumaczenia. Tutaj wyświetlana jest także liczba wyników sprawdzania |
| [Ustawienia widoku] (koło zębate) | Zmienia ustawienia poszczególnych użytkowników, takie jak wygląd panelu INDEX czy wyświetlanie przycisku edycji |
| [Pomoc] (?) | Otwiera ten przewodnik pomocy. Gdy pomoc jest wyświetlana, obok pojawia się [×] |

## INDEX (po lewej)

- Wpisanie tekstu w polu [Filtruj dokumenty] pod nagłówkiem wyświetla tylko pasujące dokumenty.
- Naciśnięcie folderu rozwija go lub zwija. W przypadku folderu ze stroną tytułową (`README.md`) naciśnięcie nazwy otwiera tę stronę.
- Menu operacji dla danego elementu otwiera się przez [⋯] pojawiające się po najechaniu myszą lub przez kliknięcie prawym przyciskiem.
- Przycisk [⋯] przy prawej krawędzi nagłówka pozwala utworzyć nowy dokument lub folder bezpośrednio w katalogu głównym dokumentacji.

## Treść dokumentu (pośrodku)

- Jeśli na początku dokumentu znajduje się tabela zarządzania dokumentem, jest ona zebrana w niewielkim wierszu „Informacje o dokumencie".
- Edycję dokumentu rozpoczyna się przyciskiem [⋯] (więcej operacji) w prawym górnym rogu lub [Edytuj] w prawym dolnym rogu.
- Odnośniki w treści otwierają się w tym samym widoku. Zewnętrzne adresy URL otwierają się w domyślnej przeglądarce.

## Na tej stronie (po prawej)

Lista nagłówków wyświetlanego dokumentu. Naciśnięcie przewija do danego nagłówka.
