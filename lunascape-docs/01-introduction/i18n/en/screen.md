# Parts of the screen

The Lunascape Docs screen consists of the toolbar at the top, the INDEX on the left, the document in the center, and "このページ" (This page) on the right.

## Toolbar

From left to right:

| Item | Function |
|---|---|
| Documentation root name | The name of the current document set. When the workspace has several documentation roots it becomes a drop-down for switching |
| [INDEXを開く] (Open INDEX, three lines) | Shown only on narrow screens. Opens the INDEX as an overlay on top of the document |
| [戻る] (Back) [進む] (Forward) | Move through the browsing history |
| [仕様書トップ] (Home, house icon) | Opens the start page of the documentation root (normally `README.md`) |
| [親INDEX] (Parent INDEX, ↑) | Opens the landing page of the folder that contains the current document. While browsing a folder temporarily it becomes [上のフォルダへ] (Up one folder) |
| [再読み込み] (Reload) | Re-reads the document and the INDEX |
| Breadcrumbs | The location of the current document. Press an item to go to that level |
| Language menu (globe) | Shows the language of the current page and the languages you can switch to. [翻訳を作成・管理…] (Create or manage translations…) is here too |
| Theme toggle (sun/moon) | Switches between a white background and the VS Code color theme |
| Column controls | Show or hide the INDEX on the left and "This page" on the right independently |
| [文書ツール] (Document Tools, check mark) | Opens the panel for document checks, template creation and translation. The check status is shown here as well |
| [表示設定] (Display settings, gear) | Per-user settings such as how the INDEX looks and whether the Edit button is shown |
| [ヘルプ] (Help, ?) | Opens this help guide. While help is shown, a [×] appears next to it |

## INDEX (left)

- Type into [文書を絞り込み] (Filter documents) under the heading to show only matching documents.
- Press a folder to expand or collapse it. A folder with a landing page (`README.md`) opens that page when you press its name.
- Hover an item to reveal [⋯], or right-click it, to open the item's action menu.
- [⋯] at the right end of the heading creates a new document or folder directly under the documentation root.

## Document (center)

- A document-control table at the top of a document is summarized into a compact "文書情報" (Document information) row.
- [⋯] (More actions) at the top right and [編集] (Edit) at the bottom right start editing.
- Links in the text open in the same view. External URLs open in your default browser.

## This page (right)

A list of the headings in the current document. Press one to scroll to it.
