# Lunascape Docs কী

Lunascape Docs এমন একটি সরঞ্জাম, যা Git রিপোজিটরিতে রাখা Markdown নথিগুলোকে যেমন আছে তেমনই একটি “স্পেসিফিকেশন সাইট” হিসেবে ব্যবহার করতে দেয়। আগে থেকে বিল্ড করা, নথি সার্ভার বা আলাদা ডেটাবেসের প্রয়োজন নেই।

## যা করা যায়

| উদ্দেশ্য | প্রধান বৈশিষ্ট্য |
|---|---|
| পড়া | INDEX (সূচিপত্র), মূল লেখার ভেতরের লিংক, ব্রেডক্রাম্ব, পেছনে ও সামনে যাওয়া, পৃষ্ঠার ভেতরের সূচি, ফিল্টার করে অনুসন্ধান |
| দেখা | টেবিল, কোড ব্লক, ছবির স্বয়ংক্রিয় মাপ মেলানো, KaTeX গাণিতিক সূত্র, Mermaid, Vega-Lite, Markmap, WaveDrom ও Svgbob-এর চিত্র, নথি নিয়ন্ত্রণ সারণি ভাঁজ করে দেখানো |
| লেখা | ভিজ্যুয়াল সম্পাদনা ও Markdown সোর্স সম্পাদনার মধ্যে পরিবর্তন, INDEX থেকে তৈরি, অনুলিপি, নাম পরিবর্তন ও ক্রম পরিবর্তন |
| যাচাই করা | docs-lint দিয়ে নথি পরীক্ষা, Standard Pack অনুযায়ী আবশ্যক নথি, অধ্যায় ও পরিভাষা যাচাই, টেমপ্লেট থেকে তৈরি |
| অনুবাদ করা | এক পৃষ্ঠা করে বা একসঙ্গে অনুবাদের প্রস্তাব তৈরি। যাচাই করার পর সংরক্ষণ <!-- ai-only --> |
| AI থেকে ব্যবহার | VS Code-এর এজেন্ট দেখে নিতে পারে এমন কেবল-পঠনযোগ্য স্পেসিফিকেশন সরঞ্জাম <!-- ai-only --> |

## যেখানে ব্যবহার করা যায়

| পরিবেশ | ব্যবহার |
|---|---|
| VS Code এক্সটেনশন | নিজের কম্পিউটারের রিপোজিটরি দেখা, সম্পাদনা, পরীক্ষা ও অনুবাদ। এই সহায়তার মূল বিষয় এটিই |
| ওয়েব ব্রাউজার সংস্করণ | GitHub-এ থাকা নথি (সর্বজনীন ও ব্যক্তিগত) দেখা, ডিভাইসে খসড়া রাখা, স্থানীয় ফোল্ডার দেখা |
| Chromium এক্সটেনশন | ওয়েব ব্রাউজার সংস্করণটি ব্রাউজারের ট্যাবে খোলে |

## মূল ধারণা

- **Markdown-ই মূল নথি।** নথিগুলো Git দিয়ে পরিচালিত Markdown ফাইল হিসেবেই থাকে। Lunascape Docs সেগুলোকে অন্য কোনো বিন্যাসে রূপান্তর করে রাখে না।
- **সংরক্ষণ করেন আপনি নিজেই।** সম্পাদনা করা বিষয়বস্তু ফাইলে লেখা হয় কেবল তখনই, যখন আপনি [সংরক্ষণ] চাপেন। Git-এর স্টেজিং বা কমিট স্বয়ংক্রিয়ভাবে করা হয় না।
- **নথি ডিভাইসের ভেতরেই প্রক্রিয়া করা হয়।** দেখা বা সম্পাদনার জন্য নথি বাইরে কোথাও পাঠানো হয় না। কেবল অনুবাদের সময় কোথায় ও কী পাঠানো হবে তা আগে দেখানো হয়, এবং আপনার অনুমোদনের পরেই পাঠানো হয়।
- **অনূদিত সংস্করণ `i18n/<ভাষা>/`-এর নিচে রাখা হয়।** ডিফল্ট ভাষার নথি যেখানে আছে সেখানেই থাকে; অনূদিত সংস্করণ একই আপেক্ষিক পাথে `i18n/en/` ইত্যাদির নিচে রাখা হয়।
- **AI কেবল প্রস্তাব দেয়।** অনুবাদের প্রস্তাব পার্থক্য যাচাই করার পরেই সংরক্ষণ করা হয়। আপনাকে না জানিয়ে নথি বদলে ফেলা হয় না। <!-- ai-only -->
