# Lunascape Docs কী

Lunascape Docs হলো এমন একটি সরঞ্জাম, যা Git রিপোজিটরিতে রাখা Markdown নথিগুলোকে যেমন আছে তেমনই "স্পেসিফিকেশন সাইট" হিসেবে ব্যবহার করতে দেয়। আগে থেকে বিল্ড করা, নথি সার্ভার বা আলাদা ডেটাবেস কিছুই লাগে না।

## যা করা যায়

| উদ্দেশ্য | প্রধান বৈশিষ্ট্য |
|---|---|
| পড়া | INDEX (সূচিপত্র), লেখার ভেতরের লিঙ্ক, ব্রেডক্রাম্ব, পিছনে ও সামনে যাওয়া, পৃষ্ঠার ভেতরের সূচি, ছেঁকে নেওয়া অনুসন্ধান |
| দেখা | সারণি, কোড ব্লক, ছবির স্বয়ংক্রিয় মাপ মেলানো, KaTeX গাণিতিক সূত্র, Mermaid, Vega-Lite, Markmap, WaveDrom ও Svgbob চিত্র, নথি ব্যবস্থাপনা সারণির ভাঁজ করা প্রদর্শন |
| লেখা | ভিজ্যুয়াল সম্পাদনা ও Markdown উৎস সম্পাদনার মধ্যে অদলবদল, INDEX থেকে তৈরি, অনুলিপি, নাম বদল ও ক্রম বদল |
| যাচাই করা | docs-lint দিয়ে নথি পরীক্ষা, Standard Pack অনুযায়ী আবশ্যক নথি, অধ্যায় ও পরিভাষার যাচাই, টেমপ্লেট থেকে তৈরি |
| অনুবাদ করা | এক পৃষ্ঠা ধরে ধরে অথবা একসঙ্গে অনুবাদের খসড়া তৈরি। যাচাই করার পর সংরক্ষণ <!-- ai-only --> |
| AI থেকে ব্যবহার | VS Code-এর এজেন্ট যে স্পেসিফিকেশন সরঞ্জাম দেখতে পারে, কেবল পড়ার জন্য <!-- ai-only --> |

## যেসব পরিবেশে ব্যবহার করা যায়

| পরিবেশ | ব্যবহার |
|---|---|
| VS Code এক্সটেনশন | নিজের কম্পিউটারের রিপোজিটরি পড়া, সম্পাদনা, পরীক্ষা ও অনুবাদ। এই সহায়তা মূলত এটি নিয়েই |
| ওয়েব ব্রাউজার সংস্করণ | GitHub-এ থাকা নথি (প্রকাশ্য ও ব্যক্তিগত) পড়া, ডিভাইসের ভেতরের খসড়া, স্থানীয় ফোল্ডার পড়া |
| Chromium এক্সটেনশন | ওয়েব ব্রাউজার সংস্করণ ব্রাউজারের ট্যাবে খোলে |
| Lunascape ব্রাউজার | একই নথি মডেল যুক্ত করার পরিকল্পনা রয়েছে |

## মূল ভাবনা

- **Markdown-ই মূল নথি।** নথিগুলো Git-এ ব্যবস্থাপিত Markdown ফাইল হিসেবেই থাকে। Lunascape Docs সেগুলোকে অন্য কোনো রূপে বদলে জমা রাখে না।
- **সংরক্ষণ ব্যবহারকারী নিজে করেন।** সম্পাদনা করা বিষয়বস্তু কেবল [সংরক্ষণ] চাপলেই ফাইলে লেখা হয়। Git-এর স্টেজিং বা কমিট নিজে থেকে হয় না।
- **নথি ডিভাইসের ভেতরেই প্রক্রিয়াজাত হয়।** পড়া বা সম্পাদনার জন্য নথি বাইরে পাঠানো হয় না। কেবল অনুবাদের সময়ই, কোথায় ও কী পাঠানো হবে তা আগে দেখিয়ে, অনুমোদনের পর পাঠানো হয়।
- **অনূদিত সংস্করণ `i18n/<言語>/`-এ রাখা হয়।** ডিফল্ট ভাষার নথি যেখানে আছে সেখানেই থাকে, আর অনূদিত সংস্করণ একই আপেক্ষিক পথে `i18n/en/` প্রভৃতিতে রাখা হয়।
- **AI কেবল প্রস্তাব দেয়।** অনুবাদের খসড়া পার্থক্য দেখে নেওয়ার পর সংরক্ষণ করা হয়। নথি নীরবে বদলে দেওয়া হয় না। <!-- ai-only -->
