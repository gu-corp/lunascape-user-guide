# কমান্ডের তালিকা

কমান্ড প্যালেটে (`⇧⌘P` / `Ctrl+Shift+P`) "Lunascape Docs" লিখলে নিচের কমান্ডগুলো চালানো যায়।

| কমান্ড | কাজ |
|---|---|
| Lunascape Docs: স্পেসিফিকেশন ভিউয়ার খুলুন | নিকটতম ডকুমেন্টেশন রুট ভিউয়ারে খোলে। পড়া, সম্পাদনা, পরীক্ষা ও অনুবাদ এই পর্দাতেই করা হয় |
| Lunascape Docs: স্পেসিফিকেশন ভিউয়ারে খুলুন | এডিটরে খোলা Markdown ফাইলটি ভিউয়ারে দেখায় |
| Lunascape Docs: টেমপ্লেট থেকে নথি তৈরি করুন | নথির ফোল্ডার নেই এমন প্রকল্পে প্রথম নথির সেট তৈরি করে |
| Lunascape Docs: ডকুমেন্টেশন রুট যাচাই করুন | পুরো ডকুমেন্টেশন রুট docs-lint দিয়ে পরীক্ষা করে এবং ফলাফল নথি সরঞ্জাম ও "সমস্যা" প্যানেলে দেখায় |
| Lunascape Docs: সহায়তা খুলুন | এই সহায়তা নির্দেশিকা খোলে |

## এক্সপ্লোরার থেকে পরিচালনা

এক্সপ্লোরারে `.md`, `.markdown` বা `.mdx` ফাইলে ডান-ক্লিক করলে [Lunascape Docs: স্পেসিফিকেশন ভিউয়ারে খুলুন] বেছে নেওয়া যায়।

> **ইঙ্গিত**
>
> Markdown ফাইল সাধারণভাবে খুললেও যাতে Lunascape Docs-এ দেখানো হয়, তার জন্য ওয়ার্কস্পেসের সেটিংসে এডিটরের সংযুক্তি যোগ করুন।
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## ওয়াকথ্রু

VS Code-এর [সহায়তা] মেনু → "স্বাগতম"-এ থাকা "Lunascape Docs শুরু করুন" ওয়াকথ্রু থেকে প্রথম ধাপগুলো পরপর চেষ্টা করা যায়।
