# এক্সটেনশন ইনস্টল করা

VS Code এক্সটেনশন "Lunascape Docs Pro" একটি VSIX ফাইল হিসেবে বিতরণ করা হয়। এটি বিনামূল্যে; "Pro" সেই সংস্করণকে বোঝায় যা AI-কে কাজ হস্তান্তর করে এবং নিজে নিজে হালনাগাদ হয়।

## চালানোর পরিবেশ

- VS Code 1.90 বা তার পরের সংস্করণ
- নথি তৈরি করা, INDEX থেকে সাজানো, পরীক্ষার সেটিংস সংরক্ষণ, অনুবাদ — এমন লেখা জড়িত বৈশিষ্ট্যগুলো কেবল সেই ওয়ার্কস্পেসে কাজ করে যেটিকে আপনি VS Code-এ "বিশ্বস্ত" হিসেবে চিহ্নিত করেছেন।

## ইনস্টল করা

1. VSIX ফাইলটি সংগ্রহ করুন। এই লিংক সবসময় সর্বশেষ সংস্করণের দিকে নির্দেশ করে।

   [lunascape-docs-pro.vsix ডাউনলোড করুন](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. VS Code-এর এক্সটেনশন ভিউ (`⇧⌘X` / `Ctrl+Shift+X`) খুলুন।
3. উপরের ডানদিকের `…` মেনু থেকে [VSIX থেকে ইনস্টল করুন...] বেছে নিন এবং সংগ্রহ করা ফাইলটি নির্দিষ্ট করুন।

### কমান্ড দিয়ে ইনস্টল করা

টার্মিনাল থেকে এক লাইনেই সেরে ফেলা যায়। সংগ্রহ ও ইনস্টল পরপর সম্পন্ন হয়।

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **নোট**
> `code` খুঁজে না পাওয়া গেলে, কমান্ড প্যালেট (`⇧⌘P` / `Ctrl+Shift+P`) থেকে [শেল কমান্ড: PATH-এ 'code' কমান্ড ইনস্টল করুন] চালান।

## হালনাগাদ করা

নতুন সংস্করণ প্রকাশিত হলে, এক্সটেনশন নিজেই সেটি সংগ্রহ করে ইনস্টল করে। VS Code যখন উইন্ডো পুনরায় লোড করার পরামর্শ দেয়, তখনই তা কার্যকর হয়। আপনার সেটিংস ও নথি অপরিবর্তিত থাকে।

পরীক্ষা দিনে একবার হয়। এখনই যাচাই করতে চাইলে, কমান্ড প্যালেট (`⇧⌘P` / `Ctrl+Shift+P`) থেকে [Lunascape Docs: হালনাগাদ পরীক্ষা করুন] চালান।

আচরণ `lunascapeDocEditor.update.check` সেটিং দিয়ে পরিবর্তন করা যায়।

| সেটিং | আচরণ |
|---|---|
| নতুন সংস্করণ প্রকাশিত হলে ইনস্টল করে | ডিফল্ট |
| জানায়; ইনস্টল করা হবে কিনা তা প্রতিবার সিদ্ধান্ত নিন | একটি বিজ্ঞপ্তি দেখা যায়, এবং [হালনাগাদ] চাপলেই কেবল বদলায় |
| পরীক্ষা করে না | কিছুই করে না |

### যখন হালনাগাদ করা যায় না

"হালনাগাদ সংগ্রহ করা যায়নি: No Servers" দেখা গেলে, ইনস্টল করা সংস্করণটি 0.22.18 বা তার আগের। সেই সংস্করণের হালনাগাদ পথ সংগ্রহের পরের ধাপে প্রতিবার ব্যর্থ হয়, তাই এটি নিজে নতুন সংস্করণে যেতে পারে না। উপরের পদ্ধতি অনুযায়ী একবার হাতে ইনস্টল করে নিন; এরপর থেকে এটি নিজেই হালনাগাদ হবে।

## সংস্করণ যাচাই করা

এক্সটেনশন ভিউতে "Lunascape Docs Pro" খুললে ইনস্টল করা সংস্করণটি দেখা যায়। কোনো সমস্যা রিপোর্ট করার সময় এটি প্রয়োজন হয়।
