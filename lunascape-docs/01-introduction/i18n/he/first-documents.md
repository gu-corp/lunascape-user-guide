# יצירת המסמכים הראשונים

בפרויקט שאין בו עדיין תיקיית מסמכים, אפשר ליצור מלוח הפקודות ערכה ראשונה של מסמכים.

1. פתחו ב‑VS Code את תיקיית הפרויקט וסמנו את סביבת העבודה כמהימנה.
2. בלוח הפקודות (`⇧⌘P` / `Ctrl+Shift+P`) הריצו את "Lunascape Docs: יצירת תיעוד מתבנית".
   אם בסביבת העבודה יש כמה תיקיות, בחרו את סביבת העבודה שבה ייווצרו המסמכים.
3. בחרו את המבנה שייווצר.
   - [מסמך בעמוד אחד]: מבנה מינימלי הכולל רק `README.md`. מתאים למפרט קצר, להערות ולמסמך הסבר יחיד.
   - [ערכת תיעוד]: יוצר עמוד ראשי ואת דפי הכניסה אל `specification/` (מפרט), `manual/` (מדריך) ו‑`help/` (עזרה).
4. הזינו את כותרת התיעוד. היא משמשת ל‑README ולכותרת של כל מסמך.
5. הזינו את תיקיית המסמכים שתיווצר. הנתיב יחסי לסביבת העבודה, וברירת המחדל היא `docs`.
6. בדקו את רשימת הקבצים שייווצרו ולחצו על [יצירה].
   בתום היצירה נפתח `README.md` החדש במציג.

> **שימו לב**
>
> - קבצים קיימים אינם נדרסים. אם אפילו אחד מהקבצים שאמורים להיווצר כבר קיים, לא נוצר דבר והפעולה נעצרת.
> - אי אפשר ליצור מסמכים בסביבת עבודה שאינה מהימנה.

> **טיפ**
>
> - אם כבר יש לכם תיקיית מסמכים, השלבים האלה מיותרים. עברו אל [פעולות בסיסיות](../02-reading/README.md).
> - כשכמות המסמכים גדלה, אפשר לבחור תבנית ולהוסיף מסמכים אחד‑אחד מלשונית [יצירה] שבכלי מסמכים.
