# שמות חלקי המסך ותפקידיהם

מסך Lunascape Docs מורכב מסרגל הכלים שבחלק העליון, מ‑INDEX שמשמאל, מגוף המסמך שבמרכז ומ"בדף זה" שמימין.

## סרגל הכלים

ההסבר מתקדם משמאל לימין.

| שם | תפקיד |
|---|---|
| שם שורש התיעוד | שמה של ערכת המסמכים המוצגת. כאשר בסביבת העבודה יש כמה שורשי תיעוד, הוא הופך לתפריט נפתח שמאפשר מעבר ביניהם |
| [פתיחת INDEX] (שלושה קווים) | מוצג רק כאשר המסך צר. פותח את INDEX מעל גוף המסמך |
| [חזרה] [קדימה] | מנווטים בהיסטוריית העיון |
| [דף הבית של המפרט] (בית) | פותח את עמוד הפתיחה של שורש התיעוד (בדרך כלל `README.md`) |
| [INDEX ההורה] (↑) | פותח את עמוד השער של התיקייה שבה נמצא המסמך המוצג. כאשר תיקייה פתוחה באופן זמני, הכפתור הופך ל[לתיקייה שמעל] |
| [טעינה מחדש] | קורא מחדש את המסמך ואת INDEX |
| שביל ניווט | מיקומו של המסמך המוצג. לחיצה על פריט מעבירה לרמה שלו |
| תפריט השפות (גלובוס) | מציג את שפת הדף המוצג ואת השפות שאפשר לעבור אליהן. גם [יצירה וניהול של תרגומים…] נמצא כאן |
| החלפת ערכת נושא (שמש/ירח) | מחליף בין רקע לבן לבין ערכת הצבעים של VS Code |
| תצוגת עמודות | מציג או מסתיר את INDEX שמשמאל ואת "בדף זה" שמימין, כל אחד בנפרד |
| [כלי מסמכים] (סימן וי) | פותח את הלוח של בדיקת המסמך, היצירה מתבנית והתרגום. גם מספר תוצאות הבדיקה מוצג כאן |
| [הגדרות תצוגה] (גלגל שיניים) | משנה הגדרות של כל משתמש, כגון אופן ההצגה של INDEX והצגת כפתור העריכה |
| [עזרה] (?) | פותח את מדריך העזרה הזה. בזמן שהעזרה מוצגת, מופיע [×] מימינו |

## INDEX (שמאל)

- הקלדה ב[סינון מסמכים] שמתחת לכותרת מציגה רק את המסמכים התואמים.
- לחיצה על תיקייה פותחת וסוגרת אותה. בתיקייה שיש בה עמוד שער (`README.md`), לחיצה על השם פותחת את עמוד השער.
- לחיצה על [⋯], שמופיע בהעברת העכבר מעל פריט, או לחיצה ימנית, פותחת את תפריט הפעולות של אותו פריט.
- מ[⋯] שבקצה הימני של הכותרת אפשר ליצור מסמך חדש או תיקייה חדשה ישירות תחת שורש התיעוד.

## גוף המסמך (מרכז)

- כאשר בראש המסמך יש טבלת ניהול מסמך, היא מוצגת מקובצת בשורה קטנה של "פרטי המסמך".
- עריכת המסמך מתחילה מ[⋯] (פעולות נוספות) שבפינה הימנית העליונה ומ[עריכה] שבפינה הימנית התחתונה.
- קישורים שבגוף המסמך נפתחים באותו מסך. כתובות URL חיצוניות נפתחות בדפדפן ברירת המחדל.

## בדף זה (ימין)

רשימת הכותרות של המסמך המוצג. לחיצה גוללת אל אותה כותרת.
