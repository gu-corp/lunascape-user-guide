# מהו Lunascape Docs

‏Lunascape Docs הוא כלי שמאפשר להשתמש במסמכי Markdown שבמאגר Git כאתר מפרטים, כמות שהם. אין צורך בבנייה מוקדמת, בשרת תיעוד או במסד נתונים ייעודי.

## מה אפשר לעשות

| מטרה | תכונות עיקריות |
|---|---|
| לקרוא | ‏INDEX (תוכן העניינים), קישורים בגוף הטקסט, שביל ניווט, חזרה וקדימה, תוכן העניינים של הדף, חיפוש מסנן |
| לראות | טבלאות, גושי קוד, התאמה אוטומטית של תמונות, נוסחאות KaTeX, תרשימי Mermaid, Vega-Lite, Markmap, WaveDrom ו-Svgbob, תצוגה מקופלת של טבלת ניהול המסמך |
| לכתוב | מעבר בין עריכה חזותית לעריכת מקור Markdown, יצירה, שכפול, שינוי שם וסידור מתוך ה-INDEX |
| לבדוק | בדיקת מסמכים באמצעות docs-lint, אימות המסמכים, הפרקים והמונחים הנדרשים לפי Standard Pack, יצירה מתוך תבנית |
| לתרגם | יצירת הצעת תרגום לדף אחד או לכמה דפים בבת אחת. שמירה לאחר בדיקה <!-- ai-only --> |
| להשתמש מתוך AI | כלי מפרט לקריאה בלבד שסוכני VS Code יכולים לפנות אליו <!-- ai-only --> |

## סביבות שבהן אפשר להשתמש

| סביבה | שימוש |
|---|---|
| תוסף VS Code | עיון, עריכה, בדיקה ותרגום של המאגר שבמחשב שלך. עזרה זו מתמקדת בו |
| גרסת דפדפן האינטרנט | עיון במסמכים שב-GitHub (ציבוריים ופרטיים), טיוטות בתוך המכשיר, עיון בתיקייה מקומית |
| תוסף Chromium | פותח את גרסת דפדפן האינטרנט בלשונית של הדפדפן |
| דפדפן Lunascape | בכוונתנו לשלב בו את אותו מודל מסמכים |

## עקרונות יסוד

- **‏Markdown הוא המקור.** המסמכים נשארים כקובצי ה-Markdown המנוהלים ב-Git. ‏Lunascape Docs אינו ממיר אותם לתבנית אחרת ואינו שומר עותק כזה.
- **השמירה נעשית בידי המשתמש.** התוכן שנערך נכתב לקובץ רק בלחיצה על [שמירה]. פעולות staging ו-commit ב-Git אינן מתבצעות אוטומטית.
- **המסמכים מעובדים בתוך המכשיר.** לצורך עיון או עריכה אין שליחה של מסמכים אל מחוץ למכשיר. רק בתרגום נשלח מסמך, ורק לאחר הצגת היעד והתוכן מראש וקבלת אישורך.
- **גרסאות התרגום נמצאות ב-`i18n/<שפה>/`.** מסמכי שפת ברירת המחדל נשארים במקומם, וגרסאות התרגום נמצאות באותו נתיב יחסי תחת `i18n/en/` וכדומה.
- **ה-AI רק מציע.** את הצעת התרגום שומרים לאחר בדיקת ההפרש. המסמכים אינם משוכתבים בשקט. <!-- ai-only -->
