# מהו Lunascape Docs

Lunascape Docs הוא כלי שמציג את מסמכי ה-Markdown שבמאגר Git כ"אתר מפרטים", כפי שהם. אין צורך בבנייה מוקדמת, בשרת תיעוד או במסד נתונים ייעודי.

## מה אפשר לעשות

| מטרה | תכונות עיקריות |
|---|---|
| קריאה | INDEX (תוכן העניינים), קישורים בגוף הטקסט, שביל ניווט, אחורה וקדימה, תוכן עניינים של הדף, חיפוש עם סינון |
| תצוגה | טבלאות, בלוקי קוד, התאמה אוטומטית של תמונות, נוסחאות KaTeX, תרשימי Mermaid,‏ Vega-Lite,‏ Markmap,‏ WaveDrom ו-Svgbob, תצוגה מקופלת של טבלאות ניהול מסמכים |
| כתיבה | מעבר בין עריכה חזותית לעריכת מקור ה-Markdown, יצירה, שכפול, שינוי שם ושינוי סדר מתוך ה-INDEX |
| בדיקה | בדיקת מסמכים באמצעות docs-lint, אימות מסמכים, פרקים ומונחים נדרשים לפי Standard Pack, יצירה מתבנית |
| תרגום | יצירת הצעות תרגום לדף בודד או לכמה דפים יחד. השמירה מתבצעת לאחר סקירה <!-- ai-only --> |
| שימוש מתוך AI | כלי מפרטים לקריאה בלבד שהסוכנים של VS Code יכולים להיעזר בו <!-- ai-only --> |

## סביבות שימוש

| סביבה | שימוש |
|---|---|
| הרחבה ל-VS Code | עיון, עריכה, בדיקה ותרגום של מאגר מקומי. זהו הנושא המרכזי של עזרה זו |
| גרסת דפדפן | עיון במסמכים ב-GitHub (ציבוריים ופרטיים), טיוטות השמורות במכשיר, עיון בתיקייה מקומית |
| הרחבה ל-Chromium | פותחת את גרסת הדפדפן בכרטיסייה של הדפדפן |

## עקרונות בסיסיים

- **Markdown הוא מסמך המקור.** המסמכים נשארים קובצי Markdown המנוהלים ב-Git. Lunascape Docs אינו ממיר אותם לפורמט אחר לצורך שמירה.
- **השמירה בידי המשתמש.** תוכן שנערך נכתב לקובץ רק כשלוחצים על [שמירה]. פעולות ה-staging וה-commit ב-Git אינן מתבצעות באופן אוטומטי.
- **המסמכים מעובדים במכשיר.** מסמכים אינם נשלחים החוצה לצורך עיון או עריכה. רק בעת תרגום מוצגים מראש היעד והתוכן שיישלחו, והשליחה מתבצעת לאחר אישור.
- **גרסאות מתורגמות נמצאות תחת `i18n/<locale>/`.** מסמכים בשפת ברירת המחדל נשארים במקומם, וגרסאות מתורגמות נשמרות באותו נתיב יחסי תחת `i18n/en/` וכדומה.
- **תפקיד ה-AI מסתכם בהצעות.** הצעות התרגום נשמרות לאחר סקירת ההבדלים. מסמכים אינם משתנים ללא ידיעת המשתמש. <!-- ai-only -->
