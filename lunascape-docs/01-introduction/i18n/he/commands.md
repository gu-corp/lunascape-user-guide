# רשימת הפקודות

בלוח הפקודות (`⇧⌘P` / `Ctrl+Shift+P`) הקלידו "Lunascape Docs" כדי להריץ את הפקודות הבאות.

| פקודה | תפקיד |
|---|---|
| Lunascape Docs: פתיחת מציג המפרטים | פותחת במציג את שורש התיעוד הקרוב ביותר. הקריאה, העריכה, הבדיקה והתרגום נעשים כולם במסך הזה |
| Lunascape Docs: פתיחה במציג המפרטים | מציגה במציג את קובץ ה-Markdown הפתוח בעורך |
| Lunascape Docs: יצירת מסמכים מתבנית | יוצרת ערכת מסמכים ראשונה בפרויקט שאין בו תיקיית מסמכים |
| Lunascape Docs: אימות שורש התיעוד | בודקת את שורש התיעוד כולו באמצעות docs-lint ומציגה את התוצאות בכלי מסמכים ובלוח "בעיות" |
| Lunascape Docs: פתיחת העזרה | פותחת את מדריך העזרה הזה |

## פעולות מתוך סייר הקבצים

בסייר הקבצים, לחצו לחיצה ימנית על קובץ `.md`, ‏`.markdown` או `.mdx` ובחרו [Lunascape Docs: פתיחה במציג המפרטים].

> **טיפ**
>
> כדי שקובצי Markdown יוצגו ב-Lunascape Docs גם כשפותחים אותם כרגיל, הוסיפו שיוך עורך להגדרות סביבת העבודה.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## סיור מודרך

הסיור המודרך "תחילת העבודה עם Lunascape Docs", שנמצא בתפריט [עזרה] ← "ברוכים הבאים" של VS Code, מאפשר לנסות את הפעולות הראשונות לפי הסדר.
