# एक्सटेंशन इंस्टॉल करना

VS Code एक्सटेंशन "Lunascape Docs Pro" को VSIX फ़ाइल के रूप में वितरित किया जाता है। यह निःशुल्क है; "Pro" उस संस्करण को दर्शाता है जो AI को काम सौंपता है और स्वयं को अपडेट करता है।

## आवश्यकताएँ

- VS Code 1.90 या उसके बाद का
- फ़ाइलें लिखने वाली सुविधाएँ — दस्तावेज़ बनाना, INDEX को व्यवस्थित करना, जाँच सेटिंग्स सहेजना, अनुवाद करना — केवल उसी कार्यस्थान में काम करती हैं जिसे आपने VS Code में विश्वसनीय के रूप में चिह्नित किया है।

## इंस्टॉल करना

1. VSIX फ़ाइल प्राप्त करें। यह लिंक हमेशा वर्तमान संस्करण की ओर इंगित करता है।

   [lunascape-docs-pro.vsix डाउनलोड करें](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. VS Code का एक्सटेंशन दृश्य (`⇧⌘X` / `Ctrl+Shift+X`) खोलें।
3. ऊपर दाईं ओर `…` मेनू से [VSIX से इंस्टॉल करें...] चुनें और प्राप्त की गई फ़ाइल निर्दिष्ट करें।

### कमांड से इंस्टॉल करना

आप इसे टर्मिनल से एक ही पंक्ति में पूरा कर सकते हैं। यह प्राप्त करना और इंस्टॉल करना एक साथ करता है।

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **ध्यान दें**
> यदि `code` नहीं मिलता, तो कमांड पैलेट (`⇧⌘P` / `Ctrl+Shift+P`) से [शेल कमांड: PATH में 'code' कमांड इंस्टॉल करें] चलाएँ।

## अपडेट करना

जब कोई नया संस्करण प्रकाशित होता है, तो एक्सटेंशन उसे स्वयं प्राप्त करके इंस्टॉल कर देता है। VS Code विंडो को पुनः लोड करने का सुझाव देता है, और तभी वह बदल जाता है। आपकी सेटिंग्स और दस्तावेज़ जैसे थे वैसे ही बने रहते हैं।

जाँच दिन में एक बार होती है। अभी जाँचना चाहें, तो कमांड पैलेट (`⇧⌘P` / `Ctrl+Shift+P`) से [Lunascape Docs: नए संस्करण की जाँच करें] चलाएँ।

व्यवहार सेटिंग `lunascapeDocEditor.update.check` से बदला जा सकता है।

| सेटिंग | व्यवहार |
|---|---|
| नया संस्करण प्रकाशित होने पर इंस्टॉल करें | डिफ़ॉल्ट |
| मुझे सूचित करें, और हर बार मैं तय करूँ | एक सूचना दिखती है, और [अपडेट] दबाने पर ही बदलाव होता है |
| जाँच न करें | कुछ नहीं होता |

### जब अपडेट न हो सके

यदि "अपडेट प्राप्त नहीं किया जा सका: No Servers" दिखता है, तो इंस्टॉल किया गया संस्करण 0.22.18 या उससे पुराना है। उस संस्करण की अपडेट सुविधा प्राप्त करने के बाद के अंतिम चरण में हर बार विफल हो जाती है, इसलिए वह स्वयं नया नहीं हो सकता। ऊपर दिए गए चरणों से एक बार हाथ से फिर इंस्टॉल करें। इसके बाद यह स्वयं अपडेट होता रहेगा।

## संस्करण की जाँच करना

एक्सटेंशन दृश्य में "Lunascape Docs Pro" खोलने पर इंस्टॉल किया गया संस्करण दिखता है। किसी समस्या की रिपोर्ट करते समय इसकी आवश्यकता होती है।
