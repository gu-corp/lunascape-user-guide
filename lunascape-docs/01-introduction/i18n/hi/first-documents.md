# पहली बार दस्तावेज़ बनाना

जिस प्रोजेक्ट में अभी तक दस्तावेज़ फ़ोल्डर नहीं है, वहाँ आप कमांड पैलेट से दस्तावेज़ों का पहला समूह बना सकते हैं।

1. VS Code में प्रोजेक्ट का फ़ोल्डर खोलें और कार्यस्थान को विश्वसनीय बनाएँ।
2. कमांड पैलेट (`⇧⌘P` / `Ctrl+Shift+P`) में "Lunascape Docs: टेम्पलेट से दस्तावेज़ बनाएँ" चलाएँ।
   कार्यस्थान में एक से अधिक फ़ोल्डर होने पर, वह कार्यस्थान चुनें जिसमें दस्तावेज़ बनाने हैं।
3. बनाई जाने वाली संरचना चुनें।
   - [एक-पृष्ठ दस्तावेज़]: केवल `README.md` वाली सबसे छोटी संरचना। छोटे विनिर्देश, नोट्स या किसी एकल विवरण-दस्तावेज़ के लिए उपयुक्त है।
   - [दस्तावेज़ सेट]: एक शीर्ष पृष्ठ, तथा `specification/` (विनिर्देश), `manual/` (मैनुअल) और `help/` (सहायता) के प्रवेश पृष्ठ बनाता है।
4. दस्तावेज़ का शीर्षक दर्ज करें। इसका उपयोग README और हर दस्तावेज़ के शीर्षक में होता है।
5. बनाया जाने वाला दस्तावेज़ फ़ोल्डर दर्ज करें। यह कार्यस्थान से सापेक्ष पथ होता है और डिफ़ॉल्ट रूप से `docs` है।
6. बनाई जाने वाली फ़ाइलों की सूची देखें और [बनाएँ] दबाएँ।
   बनने के बाद नई `README.md` व्यूअर में खुल जाती है।

> **ध्यान दें**
>
> - मौजूदा फ़ाइलों को अधिलेखित नहीं किया जाता। बनाई जाने वाली फ़ाइलों में से एक भी पहले से मौजूद हो, तो कुछ भी बनाए बिना काम रोक दिया जाता है।
> - अविश्वसनीय कार्यस्थान में दस्तावेज़ नहीं बनाए जा सकते।

> **सुझाव**
>
> - यदि दस्तावेज़ फ़ोल्डर पहले से मौजूद है, तो यह प्रक्रिया आवश्यक नहीं है। [बुनियादी संचालन](../02-reading/README.md) पर जाएँ।
> - दस्तावेज़ बढ़ने पर, दस्तावेज़ टूल के [बनाएँ] टैब से टेम्पलेट चुनकर एक-एक दस्तावेज़ जोड़ा जा सकता है।
