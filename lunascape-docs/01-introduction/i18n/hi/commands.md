# कमांड सूची

कमांड पैलेट (`⇧⌘P` / `Ctrl+Shift+P`) में "Lunascape Docs" लिखने पर निम्न कमांड चलाई जा सकती हैं।

| कमांड | काम |
|---|---|
| Lunascape Docs: विनिर्देश व्यूअर खोलें | निकटतम दस्तावेज़ रूट को व्यूअर में खोलता है। पढ़ना, संपादन, जाँच और अनुवाद इसी स्क्रीन पर होते हैं |
| Lunascape Docs: विनिर्देश व्यूअर में खोलें | एडिटर में खुली Markdown फ़ाइल को व्यूअर में दिखाता है |
| Lunascape Docs: टेम्पलेट से दस्तावेज़ बनाएँ | जिस प्रोजेक्ट में दस्तावेज़ फ़ोल्डर नहीं है, उसमें दस्तावेज़ों का पहला सेट बनाता है |
| Lunascape Docs: दस्तावेज़ रूट की जाँच करें | पूरे दस्तावेज़ रूट की docs-lint से जाँच करता है और परिणाम दस्तावेज़ टूल तथा "समस्याएँ" पैनल में दिखाता है |
| Lunascape Docs: सहायता खोलें | यह सहायता गाइड खोलता है |

## एक्सप्लोरर से संचालन

एक्सप्लोरर में `.md`, `.markdown` या `.mdx` फ़ाइल पर दायाँ-क्लिक करने पर [Lunascape Docs: विनिर्देश व्यूअर में खोलें] चुना जा सकता है।

> **संकेत**
>
> Markdown फ़ाइल को सामान्य रूप से खोलने पर भी उसे Lunascape Docs में दिखाने के लिए, कार्यस्थान की सेटिंग्स में एडिटर एसोसिएशन जोड़ें।
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## वॉकथ्रू

VS Code के [सहायता] मेनू → "स्वागत है" में मौजूद वॉकथ्रू "Lunascape Docs से शुरू करें" से पहले चरण क्रम से आज़माए जा सकते हैं।
