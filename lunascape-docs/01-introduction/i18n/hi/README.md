# Lunascape Docs क्या है

Lunascape Docs एक ऐसा टूल है जो Git रिपॉज़िटरी में रखे Markdown दस्तावेज़ों को, जैसे हैं वैसे ही, "विनिर्देश साइट" के रूप में प्रस्तुत करता है। इसके लिए पहले से किसी बिल्ड, दस्तावेज़ सर्वर या विशेष डेटाबेस की आवश्यकता नहीं है।

## आप क्या कर सकते हैं

| उद्देश्य | मुख्य सुविधाएँ |
|---|---|
| पढ़ना | INDEX (विषय-सूची), मूल पाठ के लिंक, ब्रेडक्रंब, पीछे/आगे, पृष्ठ की विषय-सूची, छाँटकर खोज |
| देखना | तालिकाएँ, कोड ब्लॉक, चित्रों का स्वतः फ़िट होना, KaTeX गणितीय सूत्र, Mermaid・Vega-Lite・Markmap・WaveDrom・Svgbob के आरेख, दस्तावेज़ प्रबंधन तालिकाओं का संक्षिप्त प्रदर्शन |
| लिखना | विज़ुअल संपादन और Markdown स्रोत संपादन के बीच अदला-बदली, INDEX से निर्माण・प्रतिलिपि・नाम बदलना・क्रम बदलना |
| जाँचना | docs-lint द्वारा दस्तावेज़ की जाँच, Standard Pack के आधार पर आवश्यक दस्तावेज़・अध्याय・शब्दावली की पुष्टि, टेम्पलेट से निर्माण |
| अनुवाद करना | एक पृष्ठ के लिए या एक साथ कई पृष्ठों के लिए अनुवाद प्रस्ताव तैयार करना। पुष्टि करने के बाद सहेजें <!-- ai-only --> |
| AI से उपयोग करना | VS Code का एजेंट जिसे देख सके, ऐसा केवल-पठन विनिर्देश टूल <!-- ai-only --> |

## उपलब्ध परिवेश

| परिवेश | उपयोग |
|---|---|
| VS Code एक्सटेंशन | अपने कंप्यूटर की रिपॉज़िटरी को पढ़ना, संपादित करना, जाँचना और अनुवाद करना। यह सहायता इसी पर केंद्रित है |
| वेब ब्राउज़र संस्करण | GitHub पर रखे दस्तावेज़ों (सार्वजनिक・निजी) को पढ़ना, डिवाइस में मसौदे रखना, स्थानीय फ़ोल्डर को पढ़ना |
| Chromium एक्सटेंशन | वेब ब्राउज़र संस्करण को ब्राउज़र के टैब में खोलता है |
| Lunascape ब्राउज़र | इसी दस्तावेज़ मॉडल को इसमें शामिल करने की योजना है |

## मूल विचार

- **Markdown ही प्रामाणिक दस्तावेज़ है।** दस्तावेज़ Git द्वारा प्रबंधित Markdown फ़ाइलों के रूप में ही रहते हैं। Lunascape Docs उन्हें किसी अन्य प्रारूप में बदलकर नहीं रखता।
- **सहेजना उपयोगकर्ता के हाथ में है।** संपादित सामग्री फ़ाइल में केवल तभी लिखी जाती है जब आप [सहेजें] दबाते हैं। Git की स्टेजिंग या कमिट स्वतः नहीं होती।
- **दस्तावेज़ डिवाइस के भीतर ही संसाधित होते हैं।** पढ़ने या संपादित करने के लिए दस्तावेज़ बाहर नहीं भेजे जाते। केवल अनुवाद के समय, गंतव्य और सामग्री पहले दिखाई जाती है और आपकी स्वीकृति के बाद ही भेजी जाती है।
- **अनुवादित संस्करण `i18n/<भाषा>/` में रखे जाते हैं।** डिफ़ॉल्ट भाषा के दस्तावेज़ अपने स्थान पर ही रहते हैं, और अनुवादित संस्करण उसी सापेक्ष पथ के साथ `i18n/en/` आदि में रखे जाते हैं।
- **AI केवल सुझाव देता है।** अनुवाद प्रस्ताव को अंतर देखकर पुष्टि करने के बाद सहेजा जाता है। दस्तावेज़ चुपचाप बदले नहीं जाते। <!-- ai-only -->
