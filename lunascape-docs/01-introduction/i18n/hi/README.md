# Lunascape Docs क्या है

Lunascape Docs, Git रिपॉज़िटरी में रखे Markdown दस्तावेज़ों को जैसे हैं वैसे ही “विनिर्देश साइट” के रूप में उपयोग करने का टूल है। इसके लिए पहले से बिल्ड, दस्तावेज़ सर्वर या अलग डेटाबेस की आवश्यकता नहीं होती।

## आप क्या कर सकते हैं

| उद्देश्य | मुख्य सुविधाएँ |
|---|---|
| पढ़ना | INDEX (विषय-सूची), मुख्य पाठ में लिंक, ब्रेडक्रंब, पीछे/आगे, पृष्ठ के भीतर विषय-सूची, फ़िल्टर खोज |
| देखना | तालिकाएँ, कोड ब्लॉक, चित्रों का स्वचालित समायोजन, KaTeX गणितीय सूत्र, Mermaid/Vega-Lite/Markmap/WaveDrom/Svgbob आरेख, दस्तावेज़ प्रबंधन तालिका का संकुचित प्रदर्शन |
| लिखना | विज़ुअल संपादन और Markdown स्रोत संपादन के बीच बदलना, INDEX से बनाना, प्रतिलिपि बनाना, नाम बदलना और क्रम बदलना |
| जाँचना | docs-lint द्वारा दस्तावेज़ों की जाँच, Standard Pack के आधार पर आवश्यक दस्तावेज़ों, अध्यायों और शब्दों की पुष्टि, टेम्पलेट से बनाना |
| अनुवाद करना | एक-एक पृष्ठ या एक साथ कई पृष्ठों के अनुवाद प्रस्ताव बनाना। पुष्टि करने के बाद सहेजना <!-- ai-only --> |
| AI से उपयोग करना | VS Code के एजेंट द्वारा उपयोग किया जा सकने वाला, केवल पढ़ने योग्य विनिर्देश टूल <!-- ai-only --> |

## उपलब्ध परिवेश

| परिवेश | उपयोग |
|---|---|
| VS Code एक्सटेंशन | अपने कंप्यूटर की रिपॉज़िटरी को देखना, संपादित करना, जाँचना और अनुवाद करना। यह सहायता मुख्य रूप से इसी के बारे में है |
| वेब ब्राउज़र संस्करण | GitHub पर दस्तावेज़ों (सार्वजनिक और निजी) को देखना, डिवाइस में मसौदे रखना, स्थानीय फ़ोल्डर देखना |
| Chromium एक्सटेंशन | वेब ब्राउज़र संस्करण को ब्राउज़र के टैब में खोलता है |

## मूल सिद्धांत

- **Markdown ही प्रामाणिक दस्तावेज़ है।** दस्तावेज़ Git में प्रबंधित Markdown फ़ाइलों के रूप में ही रहते हैं। Lunascape Docs उन्हें किसी अन्य प्रारूप में बदलकर नहीं रखता।
- **सहेजने का निर्णय आप लेते हैं।** संपादित सामग्री केवल तभी फ़ाइल में लिखी जाती है, जब आप [सहेजें] दबाते हैं। Git स्टेजिंग और कमिट अपने-आप नहीं होते।
- **दस्तावेज़ आपके डिवाइस पर ही संसाधित होते हैं।** देखने या संपादित करने के लिए दस्तावेज़ बाहर नहीं भेजे जाते। केवल अनुवाद के समय, गंतव्य और सामग्री पहले दिखाई जाती है, और आपकी स्वीकृति के बाद ही भेजी जाती है।
- **अनुवादित संस्करण `i18n/<locale>/` में रखे जाते हैं।** डिफ़ॉल्ट भाषा के दस्तावेज़ अपने मूल स्थान पर ही रहते हैं, और अनुवादित संस्करण उसी सापेक्ष पथ के साथ `i18n/en/` आदि में रखे जाते हैं।
- **AI केवल प्रस्ताव देता है।** अनुवाद प्रस्तावों को अंतर की पुष्टि करने के बाद सहेजा जाता है। दस्तावेज़ों को कभी भी चुपचाप दोबारा नहीं लिखा जाता। <!-- ai-only -->
