# Λίστα εντολών

Πληκτρολογήστε «Lunascape Docs» στην παλέτα εντολών (`⇧⌘P` / `Ctrl+Shift+P`) για να εκτελέσετε τις παρακάτω εντολές.

| Εντολή | Λειτουργία |
|---|---|
| Lunascape Docs: Άνοιγμα προβολής προδιαγραφών | Ανοίγει την πλησιέστερη ρίζα τεκμηρίωσης στην προβολή. Η ανάγνωση, η επεξεργασία, ο έλεγχος και η μετάφραση γίνονται σε αυτήν την οθόνη |
| Lunascape Docs: Άνοιγμα στην προβολή προδιαγραφών | Εμφανίζει στην προβολή το αρχείο Markdown που είναι ανοιχτό στον επεξεργαστή |
| Lunascape Docs: Δημιουργία εγγράφων από πρότυπο | Δημιουργεί ένα πρώτο σύνολο εγγράφων σε ένα έργο που δεν έχει φάκελο εγγράφων |
| Lunascape Docs: Έλεγχος ρίζας τεκμηρίωσης | Ελέγχει ολόκληρη τη ρίζα τεκμηρίωσης με το docs-lint και εμφανίζει τα αποτελέσματα στα Εργαλεία εγγράφου και στον πίνακα «Προβλήματα» |
| Lunascape Docs: Άνοιγμα βοήθειας | Ανοίγει αυτόν τον οδηγό βοήθειας |

## Από την Εξερεύνηση

Κάντε δεξί κλικ σε ένα αρχείο `.md`, `.markdown` ή `.mdx` στην Εξερεύνηση και επιλέξτε [Lunascape Docs: Άνοιγμα στην προβολή προδιαγραφών].

> **Συμβουλή**
>
> Για να εμφανίζονται τα αρχεία Markdown στο Lunascape Docs και όταν τα ανοίγετε κανονικά, προσθέστε μια συσχέτιση επεξεργαστή στις ρυθμίσεις του χώρου εργασίας.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Καθοδηγούμενη παρουσίαση

Από την καθοδηγούμενη παρουσίαση «Ξεκινήστε με το Lunascape Docs», στο μενού [Βοήθεια] → «Καλώς ορίσατε» του VS Code, μπορείτε να δοκιμάσετε με τη σειρά τα πρώτα βήματα.
