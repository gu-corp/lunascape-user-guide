# Δημιουργία των πρώτων σας εγγράφων

Σε ένα έργο που δεν έχει ακόμη φάκελο τεκμηρίωσης, μπορείτε να δημιουργήσετε ένα αρχικό σύνολο εγγράφων από την παλέτα εντολών.

1. Ανοίξτε τον φάκελο του έργου στο VS Code και ορίστε τον χώρο εργασίας ως αξιόπιστο.
2. Εκτελέστε την εντολή «Lunascape Docs: Δημιουργία τεκμηρίωσης από πρότυπο» από την παλέτα εντολών (`⇧⌘P` / `Ctrl+Shift+P`).
   Αν ο χώρος εργασίας περιέχει περισσότερους από έναν φακέλους, επιλέξτε εκείνον στον οποίο θα δημιουργηθούν τα έγγραφα.
3. Επιλέξτε τη δομή που θα δημιουργηθεί.
   - [Έγγραφο μίας σελίδας]: μόνο ένα `README.md`. Κατάλληλο για σύντομες προδιαγραφές, σημειώσεις ή ένα αυτοτελές επεξηγηματικό έγγραφο.
   - [Σύνολο τεκμηρίωσης]: μια αρχική σελίδα και οι σελίδες εισόδου για τα `specification/` (προδιαγραφές), `manual/` (εγχειρίδιο) και `help/` (βοήθεια).
4. Πληκτρολογήστε τον τίτλο της τεκμηρίωσης. Χρησιμοποιείται στο README και στις επικεφαλίδες κάθε εγγράφου.
5. Πληκτρολογήστε τον φάκελο τεκμηρίωσης που θα δημιουργηθεί, ως διαδρομή σχετική με τον χώρο εργασίας. Η προεπιλογή είναι `docs`.
6. Ελέγξτε τη λίστα των αρχείων που θα δημιουργηθούν και πατήστε [Δημιουργία].
   Μόλις ολοκληρωθεί η δημιουργία, το νέο `README.md` ανοίγει στο πρόγραμμα προβολής.

> **Σημείωση**
>
> - Τα υπάρχοντα αρχεία δεν αντικαθίστανται ποτέ. Αν έστω και ένα από τα αρχεία που πρόκειται να δημιουργηθούν υπάρχει ήδη, δεν δημιουργείται τίποτα και η ενέργεια ματαιώνεται.
> - Η δημιουργία δεν είναι δυνατή σε χώρο εργασίας που δεν είναι αξιόπιστος.

> **Συμβουλή**
>
> - Αν έχετε ήδη φάκελο τεκμηρίωσης, παραλείψτε αυτά τα βήματα και προχωρήστε στις [Βασικές λειτουργίες](../02-reading/README.md).
> - Καθώς αυξάνονται τα έγγραφα, μπορείτε να προσθέτετε ένα-ένα έγγραφα επιλέγοντας πρότυπο από την καρτέλα [Δημιουργία] των Εργαλείων εγγράφου.
