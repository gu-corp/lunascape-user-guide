# Τι είναι το Lunascape Docs

Το Lunascape Docs είναι ένα εργαλείο που σας επιτρέπει να χρησιμοποιείτε τα έγγραφα Markdown ενός αποθετηρίου Git, όπως είναι, ως «ιστότοπο προδιαγραφών». Δεν χρειάζονται προηγούμενη δόμηση, διακομιστής εγγράφων ούτε ειδική βάση δεδομένων.

## Τι μπορείτε να κάνετε

| Σκοπός | Κύριες λειτουργίες |
|---|---|
| Ανάγνωση | INDEX (πίνακας περιεχομένων), σύνδεσμοι μέσα στο κείμενο, διαδρομή πλοήγησης, Πίσω/Εμπρός, περιεχόμενα σελίδας, αναζήτηση με φιλτράρισμα |
| Προβολή | Πίνακες, μπλοκ κώδικα, αυτόματη προσαρμογή εικόνων, μαθηματικά KaTeX, διαγράμματα Mermaid/Vega-Lite/Markmap/WaveDrom/Svgbob, συμπτυγμένη εμφάνιση πινάκων διαχείρισης εγγράφων |
| Σύνταξη | Εναλλαγή ανάμεσα σε οπτική επεξεργασία και επεξεργασία του κώδικα Markdown· δημιουργία, αντιγραφή, μετονομασία και αλλαγή σειράς από το INDEX |
| Έλεγχος | Έλεγχος εγγράφων με το docs-lint, επαλήθευση απαιτούμενων εγγράφων, ενοτήτων και όρων βάσει του Standard Pack, δημιουργία από πρότυπα |
| Μετάφραση | Δημιουργία προτάσεων μετάφρασης ανά σελίδα ή μαζικά. Αποθήκευση μετά από έλεγχο <!-- ai-only --> |
| Χρήση μέσω AI | Εργαλείο προδιαγραφών μόνο για ανάγνωση, στο οποίο έχουν πρόσβαση οι πράκτορες του VS Code <!-- ai-only --> |

## Πού μπορείτε να το χρησιμοποιήσετε

| Περιβάλλον | Χρήση |
|---|---|
| Επέκταση για το VS Code | Ανάγνωση, επεξεργασία, έλεγχος και μετάφραση του αποθετηρίου στον υπολογιστή σας. Σε αυτήν εστιάζει η παρούσα βοήθεια |
| Έκδοση για πρόγραμμα περιήγησης | Ανάγνωση εγγράφων στο GitHub (δημόσιων και ιδιωτικών), πρόχειρα στη συσκευή σας, ανάγνωση τοπικού φακέλου |
| Επέκταση Chromium | Ανοίγει την έκδοση για πρόγραμμα περιήγησης σε καρτέλα του προγράμματος περιήγησης |

## Βασικές αρχές

- **Το Markdown είναι το πρωτότυπο.** Τα έγγραφα παραμένουν αρχεία Markdown που διαχειρίζεται το Git. Το Lunascape Docs δεν τα μετατρέπει ούτε τα διατηρεί σε άλλη μορφή.
- **Εσείς αποφασίζετε πότε θα γίνει αποθήκευση.** Οι αλλαγές γράφονται στο αρχείο μόνο όταν πατάτε [Αποθήκευση]. Το staging και το commit στο Git δεν γίνονται αυτόματα.
- **Τα έγγραφα επεξεργάζονται στη συσκευή σας.** Για την ανάγνωση ή την επεξεργασία, κανένα έγγραφο δεν αποστέλλεται εκτός συσκευής. Μόνο για τη μετάφραση εμφανίζονται πρώτα ο προορισμός και το περιεχόμενο, και η αποστολή γίνεται μετά την έγκρισή σας.
- **Οι μεταφράσεις βρίσκονται στο `i18n/<γλώσσα>/`.** Τα έγγραφα της προεπιλεγμένης γλώσσας μένουν στη θέση τους· οι μεταφράσεις τοποθετούνται με την ίδια σχετική διαδρομή στο `i18n/en/` κ.λπ.
- **Η AI μόνο προτείνει.** Οι προτάσεις μετάφρασης αποθηκεύονται αφού ελέγξετε τις διαφορές. Τα έγγραφα δεν τροποποιούνται ποτέ χωρίς να το γνωρίζετε. <!-- ai-only -->
