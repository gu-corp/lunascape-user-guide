# Τι είναι το Lunascape Docs

Το Lunascape Docs μετατρέπει τα έγγραφα Markdown που βρίσκονται σε ένα αποθετήριο Git σε «ιστότοπο προδιαγραφών», ως έχουν. Δεν χρειάζεται προηγούμενη διαδικασία δόμησης, διακομιστής τεκμηρίωσης ή ειδική βάση δεδομένων.

## Τι μπορείτε να κάνετε

| Σκοπός | Κύριες λειτουργίες |
|---|---|
| Ανάγνωση | INDEX (πίνακας περιεχομένων), σύνδεσμοι στο κείμενο, διαδρομή πλοήγησης, πίσω/εμπρός, περιεχόμενα της σελίδας, αναζήτηση με φιλτράρισμα |
| Προβολή | Πίνακες, μπλοκ κώδικα, αυτόματη προσαρμογή εικόνων, μαθηματικά KaTeX, διαγράμματα Mermaid, Vega-Lite, Markmap, WaveDrom και Svgbob, συμπτυγμένη προβολή των πινάκων διαχείρισης εγγράφου |
| Σύνταξη | Εναλλαγή μεταξύ οπτικής επεξεργασίας και επεξεργασίας πηγαίου Markdown· δημιουργία, αντιγραφή, μετονομασία και αναδιάταξη από το INDEX |
| Επαλήθευση | Έλεγχος εγγράφων με το docs-lint, επιβεβαίωση των υποχρεωτικών εγγράφων, κεφαλαίων και όρων βάσει του Standard Pack, δημιουργία από πρότυπο |
| Μετάφραση | Δημιουργία προτάσεων μετάφρασης ανά σελίδα ή μαζικά. Αποθήκευση μετά από έλεγχο <!-- ai-only --> |
| Χρήση από AI | Εργαλείο προδιαγραφών μόνο για ανάγνωση, το οποίο μπορούν να συμβουλεύονται οι πράκτορες του VS Code <!-- ai-only --> |

## Διαθέσιμα περιβάλλοντα

| Περιβάλλον | Χρήση |
|---|---|
| Επέκταση VS Code | Ανάγνωση, επεξεργασία, έλεγχος και μετάφραση του αποθετηρίου στον υπολογιστή σας. Αυτή η βοήθεια επικεντρώνεται σε αυτό |
| Έκδοση για πρόγραμμα περιήγησης | Ανάγνωση εγγράφων στο GitHub (δημόσιων ή ιδιωτικών), πρόχειρα στη συσκευή σας, ανάγνωση τοπικού φακέλου |
| Επέκταση Chromium | Ανοίγει την έκδοση για πρόγραμμα περιήγησης σε καρτέλα του προγράμματος περιήγησης |
| Πρόγραμμα περιήγησης Lunascape | Πρόκειται να ενσωματώσει το ίδιο μοντέλο εγγράφων |

## Βασικές αρχές

- **Το Markdown είναι το πρωτότυπο.** Τα έγγραφα παραμένουν αρχεία Markdown υπό τη διαχείριση του Git. Το Lunascape Docs δεν τα μετατρέπει σε άλλη μορφή για να τα διατηρήσει.
- **Η αποθήκευση γίνεται από εσάς.** Το περιεχόμενο που επεξεργαστήκατε γράφεται στο αρχείο μόνο όταν πατήσετε [Αποθήκευση]. Η προετοιμασία (staging) και η υποβολή (commit) στο Git δεν γίνονται αυτόματα.
- **Τα έγγραφα επεξεργάζονται στη συσκευή σας.** Κανένα έγγραφο δεν αποστέλλεται προς τα έξω για ανάγνωση ή επεξεργασία. Μόνο κατά τη μετάφραση εμφανίζονται εκ των προτέρων ο παραλήπτης και το περιεχόμενο, και η αποστολή γίνεται μετά την έγκρισή σας.
- **Οι μεταφράσεις τοποθετούνται στο `i18n/<γλώσσα>/`.** Τα έγγραφα της προεπιλεγμένης γλώσσας παραμένουν στη θέση τους, ενώ οι μεταφράσεις τοποθετούνται με την ίδια σχετική διαδρομή στο `i18n/en/` και ούτω καθεξής.
- **Η AI περιορίζεται σε προτάσεις.** Οι προτάσεις μετάφρασης αποθηκεύονται αφού ελέγξετε τις διαφορές. Κανένα έγγραφο δεν τροποποιείται σιωπηλά. <!-- ai-only -->
