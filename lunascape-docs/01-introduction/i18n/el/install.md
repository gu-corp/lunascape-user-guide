# Εγκατάσταση της επέκτασης

Η επέκταση του VS Code «Lunascape Docs Pro» διανέμεται ως αρχείο VSIX. Είναι δωρεάν· το «Pro» δηλώνει την έκδοση που αναθέτει εργασίες σε AI και ενημερώνεται μόνη της.

## Απαιτήσεις

- VS Code 1.90 ή νεότερο
- Οι λειτουργίες που γράφουν αρχεία — δημιουργία εγγράφων, οργάνωση του INDEX, αποθήκευση ρυθμίσεων ελέγχου, μετάφραση — λειτουργούν μόνο σε έναν χώρο εργασίας που έχετε ορίσει ως αξιόπιστο στο VS Code.

## Εγκατάσταση

1. Αποκτήστε το αρχείο VSIX. Αυτός ο σύνδεσμος δείχνει πάντα στην τρέχουσα έκδοση.

   [Λήψη του lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. Ανοίξτε την προβολή Επεκτάσεων (`⇧⌘X` / `Ctrl+Shift+X`).
3. Επιλέξτε [Εγκατάσταση από VSIX...] από το μενού `…` επάνω δεξιά και υποδείξτε το αρχείο που κατεβάσατε.

### Από τη γραμμή εντολών

Μία γραμμή, αν προτιμάτε να μην φύγετε από το τερματικό. Κάνει λήψη και εγκατάσταση διαδοχικά.

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **Σημείωση**
> Αν δεν βρεθεί το `code`, εκτελέστε [Shell Command: Install 'code' command in PATH] από την Παλέτα εντολών (`⇧⌘P` / `Ctrl+Shift+P`).

## Ενημέρωση

Όταν δημοσιευτεί μια νεότερη έκδοση, η επέκταση την ανακτά και την εγκαθιστά μόνη της. Το VS Code σάς προτρέπει να επαναφορτώσετε το παράθυρο, και τότε γίνεται η εναλλαγή. Οι ρυθμίσεις και τα έγγραφά σας παραμένουν ως έχουν.

Ο έλεγχος γίνεται μία φορά την ημέρα. Αν θέλετε να ελέγξετε αμέσως, εκτελέστε [Lunascape Docs: Έλεγχος για νεότερη έκδοση] από την Παλέτα εντολών (`⇧⌘P` / `Ctrl+Shift+P`).

Η συμπεριφορά αλλάζει με τη ρύθμιση `lunascapeDocEditor.update.check`.

| Ρύθμιση | Συμπεριφορά |
|---|---|
| Εγκατάσταση νεότερης έκδοσης όταν δημοσιευτεί | Προεπιλογή |
| Ειδοποίηση, με απόφαση κάθε φορά | Εμφανίζεται μια ειδοποίηση και η εναλλαγή γίνεται μόνο όταν πατήσετε [Ενημέρωση] |
| Χωρίς έλεγχο | Δεν γίνεται τίποτα |

### Όταν η ενημέρωση δεν είναι δυνατή

Αν εμφανιστεί «Δεν ήταν δυνατή η ανάκτηση της ενημέρωσης: No Servers», η εγκατεστημένη έκδοση είναι η 0.22.18 ή παλαιότερη. Η λειτουργία ενημέρωσης εκείνης της έκδοσης αποτυγχάνει πάντα στο τελευταίο βήμα μετά την ανάκτηση, οπότε δεν μπορεί να ενημερωθεί μόνη της. Εγκαταστήστε την μία φορά με το χέρι, όπως παραπάνω· από εκεί και πέρα ενημερώνεται μόνη της.

## Έλεγχος της έκδοσης

Αν ανοίξετε το «Lunascape Docs Pro» στην προβολή Επεκτάσεων, εμφανίζεται η εγκατεστημένη έκδοση. Θα τη χρειαστείτε όταν αναφέρετε ένα πρόβλημα.
