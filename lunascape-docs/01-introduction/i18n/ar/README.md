# ما هو Lunascape Docs

يتيح Lunascape Docs التعامل مع مستندات Markdown الموجودة في مستودع Git كما هي بوصفها «موقع مواصفات». لا حاجة إلى خطوة بناء مسبقة ولا إلى خادم توثيق ولا إلى قاعدة بيانات مخصصة.

## ما يمكنك فعله

| الغرض | الميزات الرئيسية |
|---|---|
| القراءة | INDEX (فهرس المحتويات)، روابط داخل النص، مسار التنقل، رجوع وتقدّم، فهرس داخل الصفحة، بحث بالتصفية |
| العرض | الجداول، كتل التعليمات البرمجية، ملاءمة الصور تلقائيًا، معادلات KaTeX، الرسوم التخطيطية بصيغ Mermaid وVega-Lite وMarkmap وWaveDrom وSvgbob، وطيّ جداول إدارة المستندات |
| الكتابة | التبديل بين التحرير المرئي وتحرير مصدر Markdown، والإنشاء والنسخ وإعادة التسمية وإعادة الترتيب من INDEX |
| التحقق | فحص المستندات بواسطة docs-lint، والتأكد من المستندات والفصول والمصطلحات المطلوبة وفق Standard Pack، والإنشاء من قالب |
| الترجمة | توليد مقترحات ترجمة لصفحة واحدة أو دفعةً واحدة، مع الحفظ بعد المراجعة <!-- ai-only -->|
| الاستخدام من الذكاء الاصطناعي | أداة مواصفات للقراءة فقط يمكن لوكلاء VS Code الرجوع إليها <!-- ai-only -->|

## البيئات المتاحة

| البيئة | الاستخدام |
|---|---|
| امتداد VS Code | قراءة المستودع الموجود على جهازك وتحريره وفحصه وترجمته. وهو محور هذه المساعدة |
| إصدار متصفح الويب | قراءة المستندات الموجودة على GitHub (العامة والخاصة)، والمسودات داخل الجهاز، وقراءة مجلد محلي |
| امتداد Chromium | يفتح إصدار متصفح الويب في علامة تبويب في المتصفح |
| متصفح Lunascape | من المقرر أن يضمّ نموذج المستندات نفسه |

## المبادئ الأساسية

- **‏Markdown هو المستند الأصلي.** تبقى المستندات ملفات Markdown كما هي تحت إدارة Git. ولا يحتفظ Lunascape Docs بنسخة محوّلة إلى صيغة أخرى.
- **الحفظ بيد المستخدم.** لا تُكتب التعديلات في الملف إلا عند الضغط على [حفظ]. ولا تتم التهيئة للإيداع في Git ولا الإيداع نفسه تلقائيًا.
- **تُعالَج المستندات داخل الجهاز.** لا تُرسل المستندات إلى الخارج لأجل القراءة أو التحرير. وعند الترجمة فقط، تُعرض الجهة المستقبِلة والمحتوى مسبقًا، ولا يتم الإرسال إلا بعد الموافقة.
- **توضع النسخ المترجمة في `i18n/<اللغة>/`.** تبقى مستندات اللغة الافتراضية في مكانها، وتوضع النسخ المترجمة بالمسار النسبي نفسه في `i18n/en/` وما شابهها.
- **الذكاء الاصطناعي يقترح فقط.** تُحفظ مقترحات الترجمة بعد مراجعة الفروق. ولا يُعاد كتابة المستندات في صمت. <!-- ai-only -->
