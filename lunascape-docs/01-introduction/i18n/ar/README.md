# ما هو Lunascape Docs

Lunascape Docs أداة تتيح التعامل مع مستندات Markdown الموجودة في مستودع Git كما هي بوصفها «موقع مواصفات». لا حاجة إلى بناء مسبق ولا إلى خادم للمستندات ولا إلى قاعدة بيانات مخصصة.

## ما يمكنك فعله

| الغرض | الميزات الرئيسية |
|---|---|
| القراءة | INDEX (جدول المحتويات)، والروابط داخل النص، ومسار التنقل، والرجوع والتقدّم، وجدول المحتويات داخل الصفحة، والبحث بالتصفية |
| العرض | الجداول، وكتل التعليمات البرمجية، والملاءمة التلقائية لحجم الصور، ومعادلات KaTeX، والرسوم التخطيطية بـ Mermaid وVega-Lite وMarkmap وWaveDrom وSvgbob، وعرض جداول إدارة المستندات مطويةً |
| الكتابة | التبديل بين التحرير المرئي وتحرير مصدر Markdown، والإنشاء والتكرار وإعادة التسمية وإعادة الترتيب من INDEX |
| التحقق | فحص المستندات باستخدام docs-lint، والتحقق من المستندات والأقسام والمصطلحات المطلوبة وفق Standard Pack، والإنشاء من قالب |
| الترجمة | إنشاء مقترحات الترجمة صفحةً صفحة أو دفعةً واحدة، ثم الحفظ بعد المراجعة <!-- ai-only --> |
| الاستخدام عبر الذكاء الاصطناعي | أداة مواصفات للقراءة فقط يمكن لوكلاء VS Code الرجوع إليها <!-- ai-only --> |

## البيئات المتاحة

| البيئة | الاستخدام |
|---|---|
| ملحق VS Code | تصفح المستودع الموجود على جهازك وتحريره وفحصه وترجمته. وهو محور هذه المساعدة |
| إصدار متصفح الويب | تصفح المستندات على GitHub (العامة والخاصة)، والمسودات المحفوظة على الجهاز، وتصفح المجلدات المحلية |
| ملحق Chromium | يفتح إصدار متصفح الويب في علامة تبويب في المتصفح |

## المبادئ الأساسية

- **ملفات Markdown هي النسخة الأصلية.** تبقى المستندات ملفات Markdown تُدار باستخدام Git. لا يحوّلها Lunascape Docs إلى تنسيق آخر ليحتفظ بها.
- **الحفظ يتولاه المستخدم.** لا يُكتب المحتوى المحرَّر في الملف إلا عند الضغط على [حفظ]. لا تُضاف التغييرات إلى منطقة التجهيز في Git ولا تُودَع تلقائيًا.
- **تُعالَج المستندات على جهازك.** لا تُرسَل المستندات إلى أي جهة خارجية لعرضها أو تحريرها. في الترجمة وحدها تُعرض الجهة المرسَل إليها والمحتوى مسبقًا، ولا يُرسَل شيء إلا بعد موافقتك.
- **توضع الترجمات في `i18n/<locale>/`.** تبقى مستندات اللغة الافتراضية في مكانها، وتوضع الترجمات بالمسار النسبي نفسه تحت `i18n/en/` وما شابه.
- **يقتصر دور الذكاء الاصطناعي على الاقتراح.** تُحفظ مقترحات الترجمة بعد مراجعة الفروق. لا يُعاد كتابة أي مستند دون علمك. <!-- ai-only -->
