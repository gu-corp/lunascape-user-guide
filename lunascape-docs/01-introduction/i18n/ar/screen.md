# أسماء أجزاء الشاشة ووظائفها

تتكوّن شاشة Lunascape Docs من شريط الأدوات في الأعلى، وINDEX على اليسار، والمستند في الوسط، و«في هذه الصفحة» على اليمين.

## شريط الأدوات

فيما يلي شرح العناصر من اليسار إلى اليمين.

| الاسم | الوظيفة |
|---|---|
| اسم جذر التوثيق | اسم مجموعة المستندات المعروضة. عندما تحتوي مساحة العمل على أكثر من جذر توثيق، يتحوّل إلى قائمة منسدلة للتبديل بينها |
| [فتح INDEX] (ثلاثة خطوط) | يظهر فقط عندما تكون الشاشة ضيّقة. يفتح INDEX فوق المستند |
| [رجوع] [تقدّم] | للتنقّل في سجلّ التصفّح |
| [صفحة التوثيق الرئيسية] (منزل) | يفتح صفحة بداية جذر التوثيق (عادةً `README.md`) |
| [INDEX الأصل] (↑) | يفتح صفحة غلاف المجلد الذي يحتوي المستند المعروض. وعند فتح مجلد بصفة مؤقتة يصبح [إلى المجلد الأعلى] |
| [إعادة تحميل] | يعيد قراءة المستند وINDEX |
| مسار التنقل | موضع المستند المعروض. اضغط أي عنصر للانتقال إلى ذلك المستوى |
| قائمة اللغات (كرة أرضية) | تعرض لغة الصفحة الحالية واللغات التي يمكن التبديل إليها. ويوجد هنا أيضًا [إنشاء الترجمات وإدارتها…] |
| تبديل السمة (شمس/قمر) | يبدّل بين الخلفية البيضاء وألوان VS Code |
| عرض الأعمدة | يُظهر أو يُخفي INDEX على اليسار و«في هذه الصفحة» على اليمين، كلًّا على حدة |
| [أدوات المستندات] (علامة صح) | يفتح لوحة فحص المستندات والإنشاء من قالب والترجمة. ويظهر هنا أيضًا عدد نتائج الفحص |
| [إعدادات العرض] (ترس) | لتغيير الإعدادات الخاصة بكل مستخدم، مثل طريقة عرض INDEX وإظهار زر التحرير |
| [مساعدة] (؟) | يفتح دليل المساعدة هذا. وأثناء عرض المساعدة يظهر [×] بجانبه |

## INDEX (على اليسار)

- عند الكتابة في [تصفية المستندات] أسفل العنوان، تُعرض المستندات المطابقة فقط.
- اضغط المجلد لفتحه أو طيّه. أما المجلد الذي له صفحة غلاف (`README.md`)، فيفتح غلافه عند الضغط على اسمه.
- افتح قائمة إجراءات العنصر من [⋯] التي تظهر عند تمرير المؤشر فوقه، أو بالضغط بزر الفأرة الأيمن.
- من [⋯] في أقصى يمين العنوان، يمكنك إنشاء مستند أو مجلد جديد مباشرةً تحت جذر التوثيق.

## المستند (في الوسط)

- إذا كان في أعلى المستند جدول لإدارة المستند، فإنه يُعرض مجمّعًا في سطر صغير باسم «معلومات المستند».
- ابدأ تحرير المستند من [⋯] (إجراءات أخرى) أعلى اليمين أو من [تحرير] أسفل اليمين.
- تُفتح الروابط الموجودة في النص داخل الشاشة نفسها. أما عناوين URL الخارجية فتُفتح في المتصفح الافتراضي.

## في هذه الصفحة (على اليمين)

قائمة بعناوين المستند المعروض. اضغط أحدها للتمرير إليه.
