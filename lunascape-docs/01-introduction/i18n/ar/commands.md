# قائمة الأوامر

اكتب «Lunascape Docs» في لوحة الأوامر (`⇧⌘P` / `Ctrl+Shift+P`) لتنفيذ الأوامر التالية.

| الأمر | الوظيفة |
|---|---|
| Lunascape Docs: فتح عارض المواصفات | يفتح أقرب جذر توثيق في العارض. تتم القراءة والتحرير والفحص والترجمة في هذه الشاشة |
| Lunascape Docs: الفتح في عارض المواصفات | يعرض ملف Markdown المفتوح في المحرّر داخل العارض |
| Lunascape Docs: إنشاء مستندات من قالب | ينشئ مجموعة المستندات الأولى في مشروع لا يحتوي على مجلد مستندات |
| Lunascape Docs: التحقّق من جذر التوثيق | يفحص جذر التوثيق بالكامل باستخدام docs-lint ويعرض النتائج في أدوات المستندات وفي لوحة «المشكلات» |
| Lunascape Docs: فتح المساعدة | يفتح دليل المساعدة هذا |

## من المستكشف

انقر بزر الفأرة الأيمن على ملف `.md` أو `.markdown` أو `.mdx` في المستكشف، ثم اختر [Lunascape Docs: الفتح في عارض المواصفات].

> **تلميح**
>
> لعرض ملفات Markdown في Lunascape Docs عند فتحها بالطريقة المعتادة، أضف ارتباط المحرّر إلى إعدادات مساحة العمل.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## الجولة التعريفية

من قائمة [مساعدة] في VS Code ← «مرحبًا»، تتيح لك الجولة التعريفية «البدء مع Lunascape Docs» تجربة الخطوات الأولى بالترتيب.
