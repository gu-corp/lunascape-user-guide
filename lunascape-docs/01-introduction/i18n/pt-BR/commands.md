# Lista de comandos

Digite "Lunascape Docs" na Paleta de Comandos (`⇧⌘P` / `Ctrl+Shift+P`) para executar os comandos a seguir.

| Comando | Função |
|---|---|
| Lunascape Docs: Abrir o visualizador de especificações | Abre no visualizador a raiz da documentação mais próxima. A leitura, a edição, a verificação e a tradução são feitas nessa tela |
| Lunascape Docs: Abrir no visualizador de especificações | Mostra no visualizador o arquivo Markdown aberto no editor |
| Lunascape Docs: Criar documentação a partir de um modelo | Cria o primeiro conjunto de documentos em um projeto que não tem pasta de documentação |
| Lunascape Docs: Validar a raiz da documentação | Verifica toda a raiz da documentação com o docs-lint e mostra os resultados nas Ferramentas de documento e no painel "Problemas" |
| Lunascape Docs: Abrir a Ajuda | Abre este guia de ajuda |

## A partir do Explorador

Clique com o botão direito em um arquivo `.md`, `.markdown` ou `.mdx` no Explorador e escolha [Lunascape Docs: Abrir no visualizador de especificações].

> **Dica**
>
> Para que os arquivos Markdown sejam exibidos no Lunascape Docs também ao abri-los normalmente, adicione uma associação de editor às configurações do espaço de trabalho.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Passo a passo

No menu [Ajuda] → "Bem-vindo" do VS Code, o passo a passo "Introdução ao Lunascape Docs" permite experimentar as primeiras operações na ordem.
