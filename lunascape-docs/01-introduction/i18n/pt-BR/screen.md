# Nomes e funções das partes da tela

A tela do Lunascape Docs é composta pela barra de ferramentas na parte superior, pelo INDEX à esquerda, pelo documento no centro e por "Nesta página" à direita.

## Barra de ferramentas

Da esquerda para a direita:

| Nome | Função |
|---|---|
| Nome da raiz da documentação | É o nome do conjunto de documentos exibido. Quando o espaço de trabalho tem várias raízes da documentação, vira uma lista suspensa e permite alternar entre elas |
| [Abrir o INDEX] (três linhas) | Aparece apenas quando a tela é estreita. Abre o INDEX sobreposto ao documento |
| [Voltar] [Avançar] | Percorrem o histórico de navegação |
| [Início da documentação] (casa) | Abre a página inicial da raiz da documentação (normalmente `README.md`) |
| [INDEX pai] (↑) | Abre a página de capa da pasta que contém o documento exibido. Quando uma pasta está aberta temporariamente, passa a ser [Ir para a pasta acima] |
| [Recarregar] | Relê o documento e o INDEX |
| Trilha de navegação | É a localização do documento exibido. Pressione cada item para ir até aquele nível |
| Menu de idiomas (globo) | Mostra o idioma da página exibida e os idiomas para os quais é possível alternar. [Criar e gerenciar traduções…] também fica aqui |
| Alternância de tema (sol/lua) | Alterna entre o fundo branco e as cores do VS Code |
| Exibição de colunas | Mostra ou oculta, separadamente, o INDEX à esquerda e "Nesta página" à direita |
| [Ferramentas de documento] (marca de verificação) | Abre os painéis de verificação de documentos, de criação a partir de modelos e de tradução. O número de resultados da verificação também aparece aqui |
| [Configurações de exibição] (engrenagem) | Altera as configurações de cada usuário, como a aparência do INDEX e a exibição do botão de edição |
| [Ajuda] (?) | Abre este guia de ajuda. Enquanto a ajuda está aberta, um [×] aparece ao lado direito |

## INDEX (à esquerda)

- Digite em [Filtrar documentos], abaixo do título, para exibir apenas os documentos correspondentes.
- Pressione uma pasta para abri-la ou fechá-la. Nas pastas que têm uma capa (`README.md`), pressionar o nome abre a capa.
- Passe o mouse sobre um item para exibir [⋯], ou clique com o botão direito, para abrir o menu de ações do item.
- Pelo [⋯] na extremidade direita do título, é possível criar um novo documento ou pasta diretamente na raiz da documentação.

## Documento (ao centro)

- Quando há uma tabela de controle do documento no início dele, ela é resumida em uma pequena linha "Informações do documento".
- Comece a editar o documento pelo [⋯] (Outras ações), no canto superior direito, ou por [Editar], no canto inferior direito.
- Os links do texto abrem na mesma tela. URLs externas abrem no navegador padrão.

## Nesta página (à direita)

É a lista dos títulos do documento exibido. Pressione um deles para rolar até ele.
