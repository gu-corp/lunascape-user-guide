# Popis naredbi

Upišite „Lunascape Docs” u paletu naredbi (`⇧⌘P` / `Ctrl+Shift+P`) kako biste pokrenuli sljedeće naredbe.

| Naredba | Funkcija |
|---|---|
| Lunascape Docs: Otvori preglednik specifikacija | Otvara najbliži korijen dokumentacije u pregledniku. Čitanje, uređivanje, provjera i prijevod obavljaju se u tom prikazu |
| Lunascape Docs: Otvori u pregledniku specifikacija | Prikazuje Markdown datoteku otvorenu u uređivaču u pregledniku |
| Lunascape Docs: Stvori dokumentaciju iz predloška | Stvara početni skup dokumenata u projektu koji nema mapu s dokumentacijom |
| Lunascape Docs: Provjeri korijen dokumentacije | Provjerava cijeli korijen dokumentacije alatom docs-lint i prikazuje rezultate u Alatima za dokumente i na ploči „Problemi” |
| Lunascape Docs: Otvori pomoć | Otvara ovaj vodič za pomoć |

## Iz Eksploratora

Desnom tipkom miša kliknite datoteku `.md`, `.markdown` ili `.mdx` u Eksploratoru i odaberite [Lunascape Docs: Otvori u pregledniku specifikacija].

> **Savjet**
>
> Da bi se Markdown datoteke prikazivale u Lunascape Docs i kada ih otvarate na uobičajen način, dodajte pridruživanje uređivača u postavke radnog prostora.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Vodič kroz korake

Vodič kroz korake „Započnite s Lunascape Docs”, koji se nalazi u izborniku [Pomoć] → „Dobro došli” u VS Code, omogućuje vam da redom isprobate prve korake.
