# Nazivi i funkcije dijelova zaslona

Zaslon aplikacije Lunascape Docs sastoji se od alatne trake na vrhu, INDEX-a s lijeve strane, teksta dokumenta u sredini i odjeljka „Na ovoj stranici” s desne strane.

## Alatna traka

Opis slijeva nadesno.

| Naziv | Funkcija |
|---|---|
| Naziv korijena dokumentacije | Naziv prikazanog skupa dokumenata. Kada radni prostor sadrži više korijena dokumentacije, postaje padajući izbornik za prebacivanje |
| [Otvori INDEX] (tri crte) | Prikazuje se samo kada je zaslon uzak. Otvara INDEX preko teksta dokumenta |
| [Natrag] [Naprijed] | Kreću se kroz povijest pregledavanja |
| [Početna stranica specifikacije] (kućica) | Otvara početnu stranicu korijena dokumentacije (obično `README.md`) |
| [Nadređeni INDEX] (↑) | Otvara naslovnicu mape u kojoj se nalazi prikazani dokument. Kada je mapa privremeno otvorena, postaje [U nadređenu mapu] |
| [Ponovno učitaj] | Ponovno učitava dokument i INDEX |
| Navigacijski trag | Mjesto prikazanog dokumenta. Pritisnite pojedinu stavku za prelazak na tu razinu |
| Jezični izbornik (globus) | Prikazuje jezik trenutačne stranice i jezike na koje se može prebaciti. Ovdje se nalazi i [Izradi i upravljaj prijevodima…] |
| Promjena teme (sunce/mjesec) | Prebacuje između bijele pozadine i VS Code shema boja |
| Prikaz stupaca | Zasebno prikazuje ili skriva INDEX s lijeve strane i „Na ovoj stranici” s desne strane |
| [Alati za dokumente] (kvačica) | Otvara ploču za provjeru dokumenta, izradu iz predloška i prijevod. Ovdje se prikazuje i broj rezultata provjere |
| [Postavke prikaza] (zupčanik) | Mijenja postavke za svakog korisnika, kao što su izgled INDEX-a i prikaz gumba za uređivanje |
| [Pomoć] (?) | Otvara ovaj vodič za pomoć. Dok je pomoć prikazana, desno se prikazuje [×] |

## INDEX (lijevo)

- Kada upišete tekst u [Suzi popis dokumenata] ispod naslova, prikazuju se samo odgovarajući dokumenti.
- Pritiskom na mapu ona se otvara ili zatvara. Mapa koja ima naslovnicu (`README.md`) otvara naslovnicu kada pritisnete njezin naziv.
- Izbornik radnji za pojedinu stavku otvorite pomoću [⋯], koji se pojavi kada mišem prijeđete preko stavke, ili desnim klikom.
- Pomoću [⋯] na desnom kraju naslova možete izraditi novi dokument ili mapu neposredno u korijenu dokumentacije.

## Tekst dokumenta (sredina)

- Kada se na početku dokumenta nalazi tablica za upravljanje dokumentom, prikazuje se sažeto u malom retku „Podaci o dokumentu”.
- Uređivanje dokumenta započinjete pomoću [⋯] (ostale radnje) gore desno i [Uredi] dolje desno.
- Poveznice u tekstu otvaraju se u istom prikazu. Vanjski URL-ovi otvaraju se u zadanom pregledniku.

## Na ovoj stranici (desno)

Popis naslova u prikazanom dokumentu. Pritiskom se pomiče do tog naslova.
