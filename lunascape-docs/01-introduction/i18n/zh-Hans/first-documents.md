# 首次创建文档

在还没有文档文件夹的项目中，可以通过命令面板创建最初的一套文档。

1. 在 VS Code 中打开项目文件夹，并信任该工作区。
2. 在命令面板（`⇧⌘P` / `Ctrl+Shift+P`）中执行“Lunascape Docs: 从模板创建文档”。
   如果工作区中有多个文件夹，请选择要在其中创建的工作区。
3. 选择要创建的结构。
   - [单页文档]：仅包含 `README.md` 的最小结构。适合简短的规格书、笔记或独立的说明文档。
   - [整套文档]：创建首页，以及 `specification/`（规格书）、`manual/`（手册）、`help/`（帮助）的入口页。
4. 输入文档标题。它用于 README 和各文档的标题。
5. 输入要创建的文档文件夹。使用相对于工作区的路径，默认值为 `docs`。
6. 确认将要创建的文件列表，然后按 [创建]。
   创建完成后，新的 `README.md` 会在查看器中打开。

> **注意**
>
> - 不会覆盖已有的文件。如果要创建的文件中哪怕只有一个已经存在，则不创建任何文件并中止操作。
> - 在未信任的工作区中无法创建。

> **提示**
>
> - 如果已经有文档文件夹，则无需执行本步骤。请继续阅读[基本操作](../02-reading/README.md)。
> - 文档增多后，可以在文档工具的 [创建] 选项卡中选择模板，逐个添加文档。
