# 画面各部分的名称与功能

Lunascape Docs 的画面由顶部的工具栏、左侧的 INDEX、中间的正文和右侧的"本页目录"构成。

## 工具栏

按从左到右的顺序说明。

| 名称 | 功能 |
|---|---|
| 文档根目录名称 | 当前显示的文档集的名称。当工作区中有多个文档根目录时，会变为下拉菜单，可以切换 |
| [打开 INDEX]（三条横线） | 仅在画面较窄时显示。将 INDEX 叠加在正文之上打开 |
| [返回] [前进] | 沿浏览历史移动 |
| [规格说明书首页]（房子） | 打开文档根目录的起始页（通常是 `README.md`） |
| [上级INDEX]（↑） | 打开当前文档所在文件夹的封面页。临时打开某个文件夹时，会变为 [转到上级文件夹] |
| [重新加载] | 重新读取文档和 INDEX |
| 导航路径 | 当前文档的位置。按下各个项目可移动到该层级 |
| 语言菜单（地球仪） | 显示当前页面的语言，以及可切换的语言。[创建和管理翻译…] 也在这里 |
| 主题切换（太阳／月亮） | 在白色背景和 VS Code 配色之间切换 |
| 栏位显示 | 分别显示／隐藏左侧的 INDEX 和右侧的"本页目录" |
| [文档工具]（对勾） | 打开文档检查、从模板创建、翻译的面板。检查结果的数量也显示在这里 |
| [显示设置]（齿轮） | 更改 INDEX 的显示方式、编辑按钮的显示等各用户的设置 |
| [帮助]（?） | 打开本帮助指南。显示帮助时，其右侧会出现 [×] |

## INDEX（左侧）

- 在标题下方的 [筛选文档] 中输入内容，即可只显示匹配的文档。
- 按下文件夹可展开或折叠。带有封面页（`README.md`）的文件夹，按下名称即可打开封面页。
- 将鼠标悬停在项目上时会出现 [⋯]，或者右键单击，即可打开该项目的操作菜单。
- 通过标题右端的 [⋯]，可以在文档根目录下直接创建新的文档或文件夹。

## 正文（中间）

- 文档开头有文档管理表时，会汇总显示为一行小的"文档信息"。
- 从右上角的 [⋯]（其他操作）和右下角的 [编辑] 开始编辑文档。
- 正文中的链接在同一画面内打开。外部 URL 则在默认浏览器中打开。

## 本页目录（右侧）

当前文档的标题一览。按下后会滚动到该标题处。
