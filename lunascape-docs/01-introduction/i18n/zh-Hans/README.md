# 什么是 Lunascape Docs

Lunascape Docs 是一款工具，可将 Git 仓库中的 Markdown 文档直接作为“规格说明书网站”使用。无需事先构建，也无需文档服务器或专用数据库。

## 能做什么

| 目的 | 主要功能 |
|---|---|
| 阅读 | INDEX（目录）、正文链接、面包屑导航、后退/前进、页内目录、筛选搜索 |
| 查看 | 表格、代码块、图片自动适配、KaTeX 数学公式、Mermaid/Vega-Lite/Markmap/WaveDrom/Svgbob 图表、文档管理表的折叠显示 |
| 编写 | 在可视化编辑与 Markdown 源码编辑之间切换、在 INDEX 中新建/复制/重命名/调整排序 |
| 核查 | 使用 docs-lint 检查文档、依据 Standard Pack 确认必备的文档/章节/术语、从模板新建 |
| 翻译 | 逐页或批量生成翻译建议，确认后再保存 <!-- ai-only --> |
| 供 AI 使用 | 可供 VS Code 智能体查阅的只读规格说明工具 <!-- ai-only --> |

## 可用环境

| 环境 | 用途 |
|---|---|
| VS Code 扩展 | 浏览、编辑、检查和翻译本地仓库。本帮助主要介绍此环境 |
| Web 浏览器版 | 浏览 GitHub 上的文档（公开或私有）、在设备中保存草稿、浏览本地文件夹 |
| Chromium 扩展 | 在浏览器标签页中打开 Web 浏览器版 |

## 基本理念

- **Markdown 即为正本。** 文档始终是由 Git 管理的 Markdown 文件。Lunascape Docs 不会将其转换为其他格式另行保存。
- **保存由用户执行。** 编辑的内容仅在按下 [保存] 时才写入文件。Git 的暂存和提交不会自动进行。
- **文档在设备内处理。** 浏览或编辑时不会将文档发送到外部。仅在翻译时，会事先显示发送目标和内容，经批准后再发送。
- **翻译版本放在 `i18n/<语言>/` 中。** 默认语言的文档保留在原位置，翻译版本以相同的相对路径放在 `i18n/en/` 等文件夹中。
- **AI 只负责提出建议。** 翻译建议需在确认差异后再保存。不会擅自改写文档。 <!-- ai-only -->
