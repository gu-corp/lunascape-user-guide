# 什么是 Lunascape Docs

Lunascape Docs 可以把放在 Git 仓库中的 Markdown 文档直接当作"规格书网站"来使用。无需事先构建、无需文档服务器，也无需专用的数据库。

## 可以做什么

| 目的 | 主要功能 |
|---|---|
| 阅读 | INDEX（目录）、正文链接、导航路径、后退与前进、本页目录、筛选搜索 |
| 查看 | 表格、代码块、图片自动适应、KaTeX 公式，Mermaid、Vega-Lite、Markmap、WaveDrom、Svgbob 图，文档管理表的折叠显示 |
| 编写 | 在可视化编辑与 Markdown 源码编辑之间切换，从 INDEX 创建、复制、重命名和调整排序 |
| 检查 | 使用 docs-lint 进行文档检查，依据 Standard Pack 确认必备文档、章节和术语，从模板创建 |
| 翻译 | 按单页或批量生成翻译草案。确认后再保存 <!-- ai-only --> |
| 从 AI 使用 | 供 VS Code 的代理参考的只读规格工具 <!-- ai-only --> |

## 可用的环境

| 环境 | 用途 |
|---|---|
| VS Code 扩展 | 阅读、编辑、检查和翻译本机仓库中的文档。本帮助以此为中心 |
| Web 浏览器版 | 阅读 GitHub 上的文档（公开或非公开）、在设备内保存草稿、浏览本地文件夹 |
| Chromium 扩展 | 在浏览器标签页中打开 Web 浏览器版 |
| Lunascape 浏览器 | 计划内置相同的文档模型 |

## 基本理念

- **Markdown 就是正本。** 文档始终保持为由 Git 管理的 Markdown 文件。Lunascape Docs 不会将其转换为其他格式后另行保存。
- **由使用者决定何时保存。** 编辑的内容只在按下 [保存] 时才写入文件。不会自动执行 Git 的暂存或提交。
- **文档在设备内处理。** 不会为了阅读或编辑而把文档发送到外部。只有翻译时才会发送，并且会事先显示发送目标和内容，得到您的批准后再发送。
- **翻译版放在 `i18n/<语言>/` 下。** 默认语言的文档保持在原位置，翻译版则以相同的相对路径放在 `i18n/en/` 等目录下。
- **AI 只做提案。** 翻译草案在确认差异后再保存。不会在您不知情的情况下改写文档。 <!-- ai-only -->
