# 畫面各部分的名稱與功能

Lunascape Docs 的畫面由上方的工具列、左側的 INDEX、中央的內文，以及右側的「本頁內容」組成。

## 工具列

依照由左至右的順序說明。

| 名稱 | 功能 |
|---|---|
| 文件根目錄名稱 | 目前顯示的文件集名稱。工作區中有多個文件根目錄時會變成下拉選單，可以切換 |
| [開啟 INDEX]（三條線） | 僅在畫面較窄時顯示。將 INDEX 覆蓋在內文上方開啟 |
| [返回] [前進] | 依瀏覽記錄前後移動 |
| [規格書首頁]（房屋） | 開啟文件根目錄的起始頁（通常是 `README.md`） |
| [上層 INDEX]（↑） | 開啟目前文件所在資料夾的封面頁。暫時開啟資料夾時會變成 [前往上層資料夾] |
| [重新載入] | 重新讀取文件與 INDEX |
| 導覽路徑 | 目前文件的位置。按下各項目即可移動到該層級 |
| 語言選單（地球儀） | 顯示目前頁面的語言，以及可切換的語言。[建立與管理翻譯…] 也在這裡 |
| 主題切換（太陽／月亮） | 在白色背景與 VS Code 配色之間切換 |
| 欄位顯示 | 分別顯示／隱藏左側的 INDEX 與右側的「本頁內容」 |
| [文件工具]（勾號） | 開啟文件檢查、從範本建立、翻譯的面板。檢查結果的件數也顯示在這裡 |
| [顯示設定]（齒輪） | 變更 INDEX 的呈現方式、編輯按鈕的顯示與否等各使用者的設定 |
| [說明]（?） | 開啟本說明指南。顯示說明時，右側會出現 [×] |

## INDEX（左側）

- 在標題下方的 [篩選文件] 輸入文字，只會顯示符合的文件。
- 按下資料夾即可展開或收合。有封面頁（`README.md`）的資料夾，按下名稱會開啟封面頁。
- 將滑鼠移到項目上時會顯示 [⋯]，按下它或以滑鼠右鍵點選，即可開啟該項目的操作選單。
- 從標題最右端的 [⋯]，可以在文件根目錄下直接建立新的文件或資料夾。

## 內文（中央）

- 文件開頭有文件管理表時，會彙整顯示為一行小巧的「文件資訊」。
- 從右上的 [⋯]（其他操作）與右下的 [編輯] 開始編輯文件。
- 內文中的連結會在同一畫面內開啟。外部 URL 則以預設瀏覽器開啟。

## 本頁內容（右側）

目前文件的標題一覽。按下後會捲動到該標題。
