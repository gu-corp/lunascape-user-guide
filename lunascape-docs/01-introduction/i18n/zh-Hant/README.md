# 什麼是 Lunascape Docs

Lunascape Docs 是一套工具，能將放在 Git 存放庫中的 Markdown 文件，直接當作「規格書網站」來使用。不需要事先建置、不需要文件伺服器，也不需要專用的資料庫。

## 可以做什麼

| 目的 | 主要功能 |
|---|---|
| 閱讀 | INDEX（目錄）、內文連結、導覽路徑、上一頁與下一頁、本頁內容、篩選搜尋 |
| 檢視 | 表格、程式碼區塊、圖片自動縮放、KaTeX 數學式，Mermaid、Vega-Lite、Markmap、WaveDrom、Svgbob 的圖表，文件管理表格的摺疊顯示 |
| 撰寫 | 在視覺化編輯與 Markdown 原始碼編輯之間切換，從 INDEX 建立、複製、重新命名與調整排序 |
| 檢查 | 以 docs-lint 檢查文件，依 Standard Pack 確認必要文件、章節與用語，從範本建立 |
| 翻譯 | 以單頁或批次方式產生翻譯草案。確認後再儲存 <!-- ai-only --> |
| 從 AI 使用 | 供 VS Code 的代理程式參照的唯讀規格工具 <!-- ai-only --> |

## 可使用的環境

| 環境 | 用途 |
|---|---|
| VS Code 擴充功能 | 閱讀、編輯、檢查與翻譯本機的存放庫。本說明以此為主 |
| 網頁瀏覽器版 | 閱讀 GitHub 上的文件（公開與非公開）、裝置內的草稿、本機資料夾的閱讀 |
| Chromium 擴充功能 | 在瀏覽器分頁中開啟網頁瀏覽器版 |
| Lunascape 瀏覽器 | 預定內建相同的文件模型 |

## 基本觀念

- **Markdown 就是正本。** 文件維持為 Git 所管理的 Markdown 檔案。Lunascape Docs 不會轉換成其他格式另行保存。
- **儲存由使用者執行。** 編輯的內容只有在按下 [儲存] 時才會寫入檔案。不會自動進行 Git 的暫存或提交。
- **文件在裝置內處理。** 不會為了閱讀或編輯而將文件傳送到外部。只有在翻譯時，才會事先顯示傳送對象與內容，並在您同意後傳送。
- **翻譯版放在 `i18n/<語言>/`。** 預設語言的文件留在原處，翻譯版則以相同的相對路徑放在 `i18n/en/` 等位置。
- **AI 僅提供建議。** 翻譯草案會在確認差異後才儲存。不會在未告知的情況下改寫文件。 <!-- ai-only -->
