# 什麼是 Lunascape Docs

Lunascape Docs 是一套工具，可將放在 Git 儲存庫中的 Markdown 文件，直接當作「規格書網站」使用。不需要事先建置，也不需要文件伺服器或專用資料庫。

## 可以做的事

| 目的 | 主要功能 |
|---|---|
| 閱讀 | INDEX（目錄）、內文連結、導覽路徑、上一頁／下一頁、頁內目錄、篩選搜尋 |
| 檢視 | 表格、程式碼區塊、圖片自動調整大小、KaTeX 數學式、Mermaid／Vega-Lite／Markmap／WaveDrom／Svgbob 圖表、文件管理表的摺疊顯示 |
| 撰寫 | 切換視覺化編輯與 Markdown 原始碼編輯、從 INDEX 建立／複製／重新命名／調整排序 |
| 確認 | 以 docs-lint 檢查文件、依 Standard Pack 確認必要的文件／章節／用語、從範本建立 |
| 翻譯 | 以單頁或批次方式產生翻譯建議，確認後再儲存 <!-- ai-only --> |
| 供 AI 使用 | 可供 VS Code 代理程式參照的唯讀規格工具 <!-- ai-only --> |

## 可使用的環境

| 環境 | 用途 |
|---|---|
| VS Code 延伸模組 | 瀏覽、編輯、檢查與翻譯本機的儲存庫。本說明以此為主 |
| 網頁瀏覽器版 | 瀏覽 GitHub 上的文件（公開、私人皆可）、在裝置內保存草稿、瀏覽本機資料夾 |
| Chromium 擴充功能 | 在瀏覽器分頁中開啟網頁瀏覽器版 |

## 基本概念

- **Markdown 就是正本。** 文件始終是以 Git 管理的 Markdown 檔案。Lunascape Docs 不會將文件轉換成其他格式另行保存。
- **由使用者自行儲存。** 編輯的內容只會在按下 [儲存] 時寫入檔案。不會自動進行 Git 的暫存或提交。
- **文件在裝置內處理。** 不會為了瀏覽或編輯而將文件傳送到外部。只有翻譯時，會事先顯示傳送目的地與內容，經您同意後才傳送。
- **翻譯版放在 `i18n/<言語>/` 中。** 預設語言的文件維持原本的位置，翻譯版則以相同的相對路徑放在 `i18n/en/` 等資料夾中。
- **AI 只負責提出建議。** 翻譯建議需確認差異後才儲存。不會在未告知的情況下改寫文件。 <!-- ai-only -->
