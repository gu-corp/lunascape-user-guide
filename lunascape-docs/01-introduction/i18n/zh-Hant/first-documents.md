# 初次建立文件

在尚未有文件資料夾的專案中，可以從命令選擇區建立第一套文件。

1. 在 VS Code 中開啟專案的資料夾，並信任該工作區。
2. 在命令選擇區（`⇧⌘P` / `Ctrl+Shift+P`）中執行「Lunascape Docs: 從範本建立文件」。
   若工作區中有多個資料夾，請選擇要建立文件的工作區。
3. 選擇要建立的結構。
   - [單頁文件]：只有 `README.md` 的最小結構。適合簡短的規格書、筆記或單獨的說明文件。
   - [整套文件]：建立首頁，以及 `specification/`（規格書）、`manual/`（手冊）、`help/`（說明）的入口頁。
4. 輸入文件標題。標題會用於 README 與各份文件的標題。
5. 輸入要建立的文件資料夾。路徑為相對於工作區的路徑，預設為 `docs`。
6. 確認即將建立的檔案清單，然後按 [建立]。
   建立完成後，新的 `README.md` 會在檢視器中開啟。

> **注意**
>
> - 不會覆寫既有的檔案。即將建立的檔案中只要有一個已經存在，就不會建立任何檔案並中止作業。
> - 在未受信任的工作區中無法建立。

> **提示**
>
> - 若已經有文件資料夾，則不需要這個步驟。請前往[基本操作](../02-reading/README.md)。
> - 文件變多之後，可以從文件工具的 [建立] 索引標籤選擇範本，逐一新增文件。
