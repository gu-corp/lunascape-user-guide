# Bildschirmelemente und ihre Funktion

Der Bildschirm von Lunascape Docs besteht aus der Symbolleiste oben, dem INDEX links, dem Dokument in der Mitte und „Auf dieser Seite" rechts.

## Symbolleiste

Die Beschreibung folgt von links nach rechts.

| Bezeichnung | Funktion |
|---|---|
| Name der Dokumentwurzel | Der Name des angezeigten Dokumentsatzes. Enthält der Arbeitsbereich mehrere Dokumentwurzeln, wird daraus ein Auswahlmenü zum Umschalten |
| [INDEX öffnen] (drei Linien) | Wird nur bei schmalem Bildschirm angezeigt. Öffnet den INDEX über dem Dokument |
| [Zurück] [Vor] | Folgen dem Verlauf |
| [Startseite der Spezifikation] (Haus) | Öffnet die Startseite der Dokumentwurzel (in der Regel `README.md`) |
| [Übergeordneter INDEX] (↑) | Öffnet die Titelseite des Ordners, in dem das angezeigte Dokument liegt. Wenn ein Ordner vorübergehend geöffnet ist, wird daraus [Zum übergeordneten Ordner] |
| [Neu laden] | Liest das Dokument und den INDEX erneut ein |
| Navigationspfad | Der Ort des angezeigten Dokuments. Ein Druck auf einen Eintrag wechselt zu dieser Ebene |
| Sprachmenü (Globus) | Zeigt die Sprache der angezeigten Seite und die Sprachen, zu denen Sie wechseln können. Auch [Übersetzungen erstellen und verwalten…] finden Sie hier |
| Designumschaltung (Sonne/Mond) | Wechselt zwischen weißem Hintergrund und den Farben von VS Code |
| Spaltenanzeige | Blendet den INDEX links und „Auf dieser Seite" rechts jeweils ein oder aus |
| [Dokumentwerkzeuge] (Häkchen) | Öffnet die Bereiche für die Dokumentprüfung, das Erstellen aus einer Vorlage und die Übersetzung. Auch die Anzahl der Prüfergebnisse wird hier angezeigt |
| [Anzeigeeinstellungen] (Zahnrad) | Ändert die Einstellungen der einzelnen Benutzer, etwa das Aussehen des INDEX oder die Anzeige der Schaltfläche zum Bearbeiten |
| [Hilfe] (?) | Öffnet diese Hilfe. Während die Hilfe angezeigt wird, erscheint rechts daneben ein [×] |

## INDEX (links)

- Eine Eingabe in [Dokumente filtern] unterhalb der Überschrift zeigt nur die übereinstimmenden Dokumente an.
- Ein Druck auf einen Ordner öffnet oder schließt ihn. Bei Ordnern mit einer Titelseite (`README.md`) öffnet ein Druck auf den Namen die Titelseite.
- Das [⋯], das beim Zeigen mit der Maus auf einen Eintrag erscheint, oder ein Rechtsklick öffnet das Menü mit den Aktionen für diesen Eintrag.
- Über das [⋯] am rechten Rand der Überschrift erstellen Sie ein neues Dokument oder einen neuen Ordner unmittelbar unter der Dokumentwurzel.

## Dokument (Mitte)

- Steht am Anfang eines Dokuments eine Dokumentverwaltungstabelle, wird sie in einer kleinen Zeile „Dokumentinformationen" zusammengefasst.
- Über das [⋯] (Weitere Aktionen) oben rechts und [Bearbeiten] unten rechts beginnen Sie die Bearbeitung des Dokuments.
- Links im Text öffnen sich im selben Bildschirm. Externe URLs öffnen sich im Standardbrowser.

## Auf dieser Seite (rechts)

Eine Liste der Überschriften des angezeigten Dokuments. Ein Druck darauf scrollt zur jeweiligen Überschrift.
