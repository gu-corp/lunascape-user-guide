# Senarai perintah

Taip "Lunascape Docs" dalam Palet Perintah (`⇧⌘P` / `Ctrl+Shift+P`) untuk menjalankan perintah berikut.

| Perintah | Fungsi |
|---|---|
| Lunascape Docs: Buka Pemapar Spesifikasi | Membuka akar dokumentasi yang terdekat dalam pemapar. Bacaan, penyuntingan, semakan dan terjemahan dilakukan dalam skrin ini |
| Lunascape Docs: Buka dalam Pemapar Spesifikasi | Memaparkan fail Markdown yang dibuka dalam editor di dalam pemapar |
| Lunascape Docs: Cipta dokumen daripada templat | Mencipta set dokumen yang pertama dalam projek yang tiada folder dokumen |
| Lunascape Docs: Sahkan akar dokumentasi | Menyemak keseluruhan akar dokumentasi dengan docs-lint dan memaparkan hasilnya dalam Alat Dokumen serta panel "Masalah" |
| Lunascape Docs: Buka Bantuan | Membuka panduan bantuan ini |

## Operasi daripada Explorer

Klik kanan fail `.md`, `.markdown` atau `.mdx` dalam Explorer, dan anda boleh memilih [Lunascape Docs: Buka dalam Pemapar Spesifikasi].

> **Petua**
>
> Untuk memaparkan fail Markdown dengan Lunascape Docs walaupun ketika dibuka secara biasa, tambahkan perkaitan editor pada tetapan ruang kerja.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Panduan langkah demi langkah

Melalui panduan langkah demi langkah "Bermula dengan Lunascape Docs" dalam menu [Bantuan] VS Code → "Selamat Datang", anda boleh mencuba operasi pertama satu demi satu.
