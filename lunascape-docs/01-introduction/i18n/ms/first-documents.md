# Mencipta dokumen buat kali pertama

Dalam projek yang belum mempunyai folder dokumentasi, anda boleh mencipta satu set dokumen awal daripada Palet Perintah.

1. Buka folder projek dalam VS Code dan percayai ruang kerja tersebut.
2. Jalankan "Lunascape Docs: Cipta dokumentasi daripada templat" daripada Palet Perintah (`⇧⌘P` / `Ctrl+Shift+P`).
   Jika ruang kerja mempunyai beberapa folder, pilih ruang kerja tempat dokumen akan dicipta.
3. Pilih struktur yang hendak dicipta.
   - [Dokumen satu halaman]: hanya `README.md` sahaja, iaitu struktur paling ringkas. Sesuai untuk spesifikasi pendek, nota atau dokumen penerangan tunggal.
   - [Set dokumentasi]: mencipta halaman utama serta halaman masuk untuk `specification/` (spesifikasi), `manual/` (manual) dan `help/` (bantuan).
4. Masukkan tajuk dokumentasi. Tajuk ini digunakan untuk README dan untuk tajuk setiap dokumen.
5. Masukkan folder dokumentasi yang hendak dicipta. Laluannya relatif kepada ruang kerja, dan lalainya ialah `docs`.
6. Semak senarai fail yang akan dicipta, kemudian tekan [Cipta].
   Setelah penciptaan selesai, `README.md` yang baharu akan dibuka dalam pemapar.

> **Nota**
>
> - Fail sedia ada tidak akan ditulis ganti. Jika salah satu daripada fail yang hendak dicipta sudah wujud, tiada apa-apa yang dicipta dan operasi dihentikan.
> - Penciptaan tidak boleh dilakukan dalam ruang kerja yang tidak dipercayai.

> **Petua**
>
> - Jika anda sudah mempunyai folder dokumentasi, langkah ini tidak diperlukan. Teruskan ke [Operasi asas](../02-reading/README.md).
> - Apabila dokumen semakin bertambah, anda boleh menambah dokumen satu demi satu dengan memilih templat daripada tab [Cipta] dalam Alat Dokumen.
