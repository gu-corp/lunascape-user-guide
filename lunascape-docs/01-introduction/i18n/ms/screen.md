# Nama dan fungsi bahagian skrin

Skrin Lunascape Docs terdiri daripada bar alat di bahagian atas, INDEX di sebelah kiri, teks dokumen di tengah, dan "Pada halaman ini" di sebelah kanan.

## Bar alat

Diterangkan dari kiri ke kanan.

| Nama | Fungsi |
|---|---|
| Nama akar dokumentasi | Nama set dokumen yang sedang dipaparkan. Apabila ruang kerja mempunyai beberapa akar dokumentasi, ia menjadi menu lungsur untuk bertukar |
| [Buka INDEX] (tiga garis) | Dipaparkan hanya apabila skrin sempit. Membuka INDEX bertindan di atas teks dokumen |
| [Kembali] [Ke hadapan] | Menyusuri sejarah pelayaran |
| [Laman utama spesifikasi] (rumah) | Membuka halaman permulaan akar dokumentasi (biasanya `README.md`) |
| [INDEX induk] (↑) | Membuka halaman muka folder yang mengandungi dokumen yang sedang dipaparkan. Semasa folder dibuka secara sementara, ia menjadi [Ke folder atas] |
| [Muat semula] | Membaca semula dokumen dan INDEX |
| Jejak laluan | Lokasi dokumen yang sedang dipaparkan. Tekan setiap item untuk pergi ke aras tersebut |
| Menu bahasa (glob) | Memaparkan bahasa halaman semasa dan bahasa yang boleh ditukar. [Buat dan urus terjemahan…] juga ada di sini |
| Penukar tema (matahari/bulan) | Bertukar antara latar putih dan skema warna VS Code |
| Paparan lajur | Menunjukkan atau menyembunyikan INDEX di sebelah kiri dan "Pada halaman ini" di sebelah kanan secara berasingan |
| [Alat Dokumen] (tanda semak) | Membuka panel semakan dokumen, penciptaan daripada templat, dan terjemahan. Bilangan hasil semakan juga dipaparkan di sini |
| [Tetapan paparan] (gear) | Menukar tetapan bagi setiap pengguna, seperti rupa INDEX dan paparan butang edit |
| [Bantuan] (?) | Membuka panduan bantuan ini. Semasa bantuan dipaparkan, [×] muncul di sebelah kanannya |

## INDEX (kiri)

- Taip dalam [Tapis dokumen] di bawah tajuk untuk memaparkan hanya dokumen yang sepadan.
- Tekan folder untuk membuka atau menutupnya. Bagi folder yang mempunyai halaman muka (`README.md`), tekan namanya untuk membuka halaman muka itu.
- Tuding tetikus pada sesuatu item untuk memaparkan [⋯], atau klik kanan padanya, untuk membuka menu tindakan item tersebut.
- Melalui [⋯] di hujung kanan tajuk, anda boleh mencipta dokumen atau folder baharu terus di bawah akar dokumentasi.

## Teks dokumen (tengah)

- Apabila terdapat jadual pengurusan dokumen di bahagian atas dokumen, ia diringkaskan menjadi satu baris kecil "Maklumat dokumen".
- Mulakan penyuntingan dokumen melalui [⋯] (tindakan lain) di kanan atas dan [Edit] di kanan bawah.
- Pautan di dalam teks dibuka dalam skrin yang sama. URL luaran dibuka dalam pelayar lalai anda.

## Pada halaman ini (kanan)

Senarai tajuk dalam dokumen yang sedang dipaparkan. Tekan satu untuk menatal ke tajuk tersebut.
