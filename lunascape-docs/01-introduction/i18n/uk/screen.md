# Назви та призначення елементів екрана

Екран Lunascape Docs складається з панелі інструментів угорі, INDEX ліворуч, основного тексту в центрі та панелі «На цій сторінці» праворуч.

## Панель інструментів

Опис зліва направо.

| Назва | Призначення |
|---|---|
| Назва кореня документації | Назва набору документів, що відображається. Якщо в робочій області кілька коренів документації, елемент стає розкривним списком для перемикання |
| [Відкрити INDEX] (три смуги) | Відображається лише на вузькому екрані. Відкриває INDEX поверх основного тексту |
| [Назад] [Вперед] | Переміщення історією перегляду |
| [Головна специфікації] (будиночок) | Відкриває початкову сторінку кореня документації (зазвичай `README.md`) |
| [Батьківський INDEX] (↑) | Відкриває титульну сторінку папки, у якій міститься поточний документ. Якщо папку відкрито тимчасово, кнопка стає [На папку вище] |
| [Перезавантажити] | Повторно зчитує документ та INDEX |
| Навігаційний ланцюжок | Розташування поточного документа. Натисніть елемент, щоб перейти на відповідний рівень |
| Меню мов (глобус) | Показує мову поточної сторінки та мови, на які можна перемкнутися. Тут же розташовано [Створити та керувати перекладами…] |
| Перемикач теми (сонце/місяць) | Перемикає між білим тлом і колірною схемою VS Code |
| Керування колонками | Окремо показує або приховує INDEX ліворуч і «На цій сторінці» праворуч |
| [Інструменти документа] (галочка) | Відкриває панель перевірки документів, створення із шаблону та перекладу. Тут також показано кількість результатів перевірки |
| [Параметри відображення] (шестірня) | Змінює налаштування окремого користувача, як-от вигляд INDEX або показ кнопки редагування |
| [Довідка] (?) | Відкриває цей довідковий посібник. Поки довідку показано, праворуч від кнопки з’являється [×] |

## INDEX (ліворуч)

- Введіть текст у поле [Фільтрувати документи] під заголовком, щоб показати лише відповідні документи.
- Натисніть папку, щоб розгорнути або згорнути її. Якщо папка має титульну сторінку (`README.md`), натискання її назви відкриває цю сторінку.
- Наведіть вказівник на елемент і натисніть [⋯], що з’явиться, або клацніть елемент правою кнопкою миші, щоб відкрити меню дій для нього.
- За допомогою [⋯] у правому краї заголовка можна створити новий документ або папку безпосередньо в корені документації.

## Основний текст (у центрі)

- Якщо на початку документа є таблиця керування документом, вона зводиться до невеликого рядка «Відомості про документ».
- Редагування документа починається з [⋯] (інші дії) угорі праворуч або [Редагувати] внизу праворуч.
- Посилання в тексті відкриваються в тому самому вікні. Зовнішні URL відкриваються у браузері за замовчуванням.

## На цій сторінці (праворуч)

Перелік заголовків поточного документа. Натисніть заголовок, щоб прокрутити до нього.
