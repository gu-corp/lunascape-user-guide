# Створення перших документів

У проєкті, де ще немає папки документації, можна створити початковий набір документів через палітру команд.

1. Відкрийте папку проєкту у VS Code та позначте робочу область як надійну.
2. У палітрі команд (`⇧⌘P` / `Ctrl+Shift+P`) виконайте «Lunascape Docs: Створити документацію з шаблону».
   Якщо робоча область містить кілька папок, виберіть ту, у якій створити документи.
3. Виберіть структуру для створення.
   - [Односторінковий документ] — мінімальний склад, лише `README.md`. Підходить для короткої специфікації, нотаток або окремого пояснювального документа.
   - [Комплект документації] — головна сторінка та вхідні сторінки для `specification/` (специфікації), `manual/` (посібник) і `help/` (довідка).
4. Введіть назву документації. Її буде використано для README та заголовків кожного документа.
5. Введіть папку документації, яку потрібно створити. Шлях вказується відносно робочої області, за замовчуванням — `docs`.
6. Перегляньте список файлів, які буде створено, і натисніть [Створити].
   Після завершення створення новий `README.md` відкриється у переглядачі.

> **Примітка**
>
> - Наявні файли ніколи не перезаписуються. Якщо хоча б один із файлів, які потрібно створити, уже існує, нічого не створюється і операція припиняється.
> - У ненадійній робочій області створення недоступне.

> **Порада**
>
> - Якщо папка документації вже є, цей розділ можна пропустити та перейти до [Основних операцій](../02-reading/README.md).
> - Коли документів побільшає, їх можна додавати по одному, вибираючи шаблон на вкладці [Створити] Інструментів документа.
