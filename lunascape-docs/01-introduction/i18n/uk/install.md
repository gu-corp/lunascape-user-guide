# Встановлення розширення

Розширення VS Code «Lunascape Docs Pro» розповсюджується у вигляді файлу VSIX. Воно безкоштовне; «Pro» позначає версію, яка передає роботу штучному інтелекту та оновлюється сама.

## Вимоги

- VS Code 1.90 або новіша версія
- Функції, що записують файли — створення документів, упорядкування INDEX, збереження параметрів перевірки, переклад — працюють лише в робочій області, яку ви позначили як надійну у VS Code.

## Встановлення

1. Отримайте файл VSIX. Це посилання завжди вказує на поточну версію.

   [Завантажити lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. Відкрийте подання розширень (`⇧⌘X` / `Ctrl+Shift+X`).
3. Виберіть [Встановити з VSIX…] у меню `…` вгорі праворуч і вкажіть завантажений файл.

### З командного рядка

Один рядок, якщо ви не хочете залишати термінал. Він завантажує та встановлює.

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **Примітка**
> Якщо `code` не знайдено, виконайте [Shell Command: Install 'code' command in PATH] з палітри команд (`⇧⌘P` / `Ctrl+Shift+P`).

## Оновлення

Коли публікується новіша версія, розширення завантажує та встановлює її. VS Code пропонує перезавантажити вікно — саме тоді ви починаєте нею користуватися. Ваші параметри й документи залишаються без змін.

Перевірка відбувається раз на день. Щоб перевірити просто зараз, виконайте [Lunascape Docs: Перевірити наявність новішої версії] з палітри команд (`⇧⌘P` / `Ctrl+Shift+P`).

Параметр `lunascapeDocEditor.update.check` змінює те, що відбувається.

| Параметр | Що відбувається |
|---|---|
| Встановлювати новішу версію, коли вона опублікована | За замовчуванням |
| Повідомляти, а рішення приймати щоразу | З'являється сповіщення, і нічого не змінюється, доки ви не натиснете [Оновити] |
| Не перевіряти | Нічого не відбувається |

### Коли оновлення неможливе

Повідомлення «Не вдалося отримати оновлення: No Servers» означає, що встановлена версія 0.22.18 або старіша. Її механізм оновлення щоразу зазнає невдачі на останньому кроці, тож вона не може оновитися сама. Встановіть один раз вручну, як описано вище; після цього вона оновлюватиметься сама.

## Перевірка версії

Відкрийте «Lunascape Docs Pro» у поданні розширень, щоб побачити встановлену версію. Вона знадобиться вам, коли ви повідомлятимете про проблему.
