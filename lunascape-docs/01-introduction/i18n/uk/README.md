# Що таке Lunascape Docs

Lunascape Docs — це інструмент, який дає змогу використовувати документи Markdown із репозиторію Git як «сайт специфікацій» без жодних перетворень. Попередня збірка, сервер документації чи окрема база даних не потрібні.

## Можливості

| Мета | Основні функції |
|---|---|
| Читати | INDEX (зміст), посилання в тексті, навігаційний ланцюжок, переходи назад і вперед, зміст сторінки, пошук із фільтрацією |
| Переглядати | Таблиці, блоки коду, автоматичне припасування зображень, формули KaTeX, діаграми Mermaid, Vega-Lite, Markmap, WaveDrom і Svgbob, згорнуте відображення таблиць керування документами |
| Писати | Перемикання між візуальним редагуванням і редагуванням вихідного коду Markdown; створення, дублювання, перейменування та зміна порядку з INDEX |
| Перевіряти | Перевірка документів за допомогою docs-lint, перевірка обов’язкових документів, розділів і термінів на основі Standard Pack, створення з шаблонів |
| Перекладати | Створення пропозицій перекладу для однієї сторінки або пакетно. Збереження після перегляду <!-- ai-only --> |
| Використовувати зі ШІ | Інструмент специфікацій лише для читання, до якого можуть звертатися агенти VS Code <!-- ai-only --> |

## Середовища використання

| Середовище | Призначення |
|---|---|
| Розширення VS Code | Перегляд, редагування, перевірка та переклад репозиторію на вашому комп’ютері. Ця довідка присвячена переважно йому |
| Веб-версія для браузера | Перегляд документів на GitHub (публічних і приватних), чернетки на пристрої, перегляд локальної папки |
| Розширення Chromium | Відкриває веб-версію у вкладці браузера |

## Основні принципи

- **Оригінал — це Markdown.** Документи залишаються файлами Markdown, якими керує Git. Lunascape Docs не зберігає їх у перетвореному вигляді в іншому форматі.
- **Зберігаєте ви самі.** Зміни записуються у файл лише тоді, коли ви натискаєте [Зберегти]. Додавання змін до індексу Git і коміти не виконуються автоматично.
- **Документи обробляються на вашому пристрої.** Для перегляду чи редагування документи нікуди не надсилаються. Лише під час перекладу адресат і вміст спершу показуються вам, а надсилання відбувається тільки після вашого схвалення.
- **Переклади розміщуються в `i18n/<locale>/`.** Документи мовою за замовчуванням залишаються на своєму місці, а переклади розміщуються за тим самим відносним шляхом у `i18n/en/` тощо.
- **ШІ лише пропонує.** Пропозиції перекладу зберігаються після перегляду відмінностей. Документи ніколи не переписуються без вашого відома. <!-- ai-only -->
