# Що таке Lunascape Docs

Lunascape Docs — це інструмент, який дає змогу працювати з документами Markdown, розміщеними в репозиторії Git, безпосередньо як із «сайтом специфікацій». Не потрібні ані попередня збірка, ані сервер документації, ані окрема база даних.

## Можливості

| Мета | Основні функції |
|---|---|
| Читати | INDEX (зміст), посилання в тексті, навігаційний ланцюжок, назад і вперед, зміст сторінки, пошук з фільтруванням |
| Переглядати | Таблиці, блоки коду, автоматичне припасування зображень, формули KaTeX, діаграми Mermaid, Vega-Lite, Markmap, WaveDrom і Svgbob, згорнутий показ таблиць керування документом |
| Писати | Перемикання між візуальним редагуванням і редагуванням джерела Markdown, створення, дублювання, перейменування та зміна порядку з INDEX |
| Перевіряти | Перевірка документа за допомогою docs-lint, звірка обов'язкових документів, розділів і термінів за Standard Pack, створення з шаблону |
| Перекладати | Створення варіантів перекладу посторінково або пакетно. Збереження після перевірки <!-- ai-only --> |
| Використовувати з AI | Специфікаційний інструмент лише для читання, до якого може звертатися агент VS Code <!-- ai-only --> |

## Доступні середовища

| Середовище | Призначення |
|---|---|
| Розширення VS Code | Перегляд, редагування, перевірка та переклад репозиторію на вашому комп'ютері. Це основа цієї довідки |
| Версія для веббраузера | Перегляд документів на GitHub (відкритих і закритих), чернетки на пристрої, перегляд локальної папки |
| Розширення Chromium | Відкриває версію для веббраузера у вкладці браузера |
| Браузер Lunascape | Планується вбудувати ту саму модель документів |

## Основні засади

- **Оригіналом є Markdown.** Документи залишаються файлами Markdown, якими керує Git. Lunascape Docs не перетворює їх на інший формат і не зберігає такої копії.
- **Збереження виконує користувач.** Відредаговане записується у файл лише тоді, коли ви натискаєте [Зберегти]. Індексування та фіксація в Git не виконуються автоматично.
- **Документи обробляються на вашому пристрої.** Для перегляду або редагування документи назовні не надсилаються. Лише під час перекладу заздалегідь показуються адресат і вміст, а надсилання відбувається після вашого схвалення.
- **Переклади розміщуються в `i18n/<мова>/`.** Документи мовою за замовчуванням залишаються на своєму місці, а переклади розміщуються за тим самим відносним шляхом у `i18n/en/` тощо.
- **AI лише пропонує.** Варіанти перекладу зберігаються після перегляду відмінностей. Документи ніколи не переписуються мовчки. <!-- ai-only -->
