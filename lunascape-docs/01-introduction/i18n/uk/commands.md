# Список команд

Введіть «Lunascape Docs» у палітрі команд (`⇧⌘P` / `Ctrl+Shift+P`), щоб виконати такі команди.

| Команда | Дія |
|---|---|
| Lunascape Docs: Відкрити переглядач специфікацій | Відкриває найближчий корінь документації у переглядачі. Перегляд, редагування, перевірка та переклад виконуються в цьому вікні |
| Lunascape Docs: Відкрити в переглядачі специфікацій | Показує у переглядачі файл Markdown, відкритий у редакторі |
| Lunascape Docs: Створити документ із шаблону | Створює перший комплект документів у проєкті, де немає папки з документами |
| Lunascape Docs: Перевірити корінь документації | Перевіряє весь корінь документації за допомогою docs-lint і показує результати в інструментах документа та на панелі «Проблеми» |
| Lunascape Docs: Відкрити довідку | Відкриває цю довідку |

## Дії з панелі «Провідник»

Клацніть правою кнопкою миші файл `.md`, `.markdown` або `.mdx` на панелі «Провідник» і виберіть [Lunascape Docs: Відкрити в переглядачі специфікацій].

> **Підказка**
>
> Щоб файли Markdown відкривалися в Lunascape Docs і під час звичайного відкриття, додайте зіставлення редактора до параметрів робочої області.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```
