# A képernyő részeinek neve és szerepe

A Lunascape Docs képernyője a felül lévő eszköztárból, a bal oldali INDEX-ből, a középen lévő szövegtörzsből és a jobb oldali „Ezen az oldalon” panelből áll.

## Eszköztár

Balról jobbra haladva:

| Név | Szerep |
|---|---|
| Dokumentumgyökér neve | A megjelenített dokumentumkészlet neve. Ha a munkaterületen több Dokumentumgyökér van, legördülő listává válik, és válthat közöttük |
| [INDEX megnyitása] (három vonal) | Csak akkor jelenik meg, ha a képernyő keskeny. Az INDEX-et a szövegtörzs fölé nyitja |
| [Vissza] [Előre] | Végiglépked a böngészési előzményeken |
| [A specifikáció kezdőlapja] (ház) | Megnyitja a Dokumentumgyökér kezdőoldalát (általában `README.md`) |
| [Szülő INDEX] (↑) | Megnyitja annak a mappának a címlapját, amelyben a megjelenített dokumentum van. Ha ideiglenesen nyitott meg egy mappát, [Egy mappával feljebb] lesz belőle |
| [Újratöltés] | Újraolvassa a dokumentumot és az INDEX-et |
| Morzsamenü | A megjelenített dokumentum helye. Az egyes elemeket megnyomva az adott szintre lép |
| Nyelvi menü (földgömb) | A megjelenített oldal nyelvét és a választható nyelveket mutatja. A [Fordítások létrehozása és kezelése…] is itt található |
| Témaváltás (nap/hold) | A fehér háttér és a VS Code színösszeállítása között vált |
| Oszlopok megjelenítése | Külön-külön megjeleníti vagy elrejti a bal oldali INDEX-et és a jobb oldali „Ezen az oldalon” panelt |
| [Dokumentumeszközök] (pipa) | Megnyitja a dokumentum-ellenőrzés, a sablonból való létrehozás és a fordítás panelét. Az ellenőrzés találatainak száma is itt látható |
| [Megjelenítési beállítások] (fogaskerék) | Felhasználónként módosítja a beállításokat, például az INDEX megjelenését vagy a szerkesztés gomb megjelenítését |
| [Súgó] (?) | Megnyitja ezt a súgóútmutatót. A súgó megjelenítése közben tőle jobbra [×] látható |

## INDEX (bal oldalt)

- Ha a fejléc alatti [Dokumentumok szűrése] mezőbe ír, csak az egyező dokumentumok jelennek meg.
- A mappát megnyomva az kinyílik, illetve becsukódik. Ha a mappának van címlapja (`README.md`), a nevét megnyomva a címlap nyílik meg.
- Az elem fölé húzva az egeret megjelenik a [⋯], amellyel – vagy jobb gombos kattintással – megnyithatja az elem műveleti menüjét.
- A fejléc jobb szélén lévő [⋯] menüből közvetlenül a Dokumentumgyökér alatt hozhat létre új dokumentumot vagy mappát.

## Szövegtörzs (középen)

- Ha a dokumentum elején dokumentumkezelési táblázat áll, azt egyetlen kis „Dokumentuminformációk” sorba vonja össze.
- A jobb felső [⋯] (további műveletek) és a jobb alsó [Szerkesztés] gombbal kezdheti el a dokumentum szerkesztését.
- A szövegtörzsben lévő hivatkozások ugyanabban a nézetben nyílnak meg. A külső URL-eket az alapértelmezett böngésző nyitja meg.

## Ezen az oldalon (jobb oldalt)

A megjelenített dokumentum címsorainak listája. Megnyomva az adott címsorhoz görget.
