# Daftar perintah

Ketik "Lunascape Docs" di Command Palette (`⇧⌘P` / `Ctrl+Shift+P`) untuk menjalankan perintah berikut.

| Perintah | Fungsi |
|---|---|
| Lunascape Docs: Buka Penampil Spesifikasi | Membuka root dokumentasi terdekat di penampil. Membaca, mengedit, memeriksa, dan menerjemahkan dilakukan di layar ini |
| Lunascape Docs: Buka di Penampil Spesifikasi | Menampilkan berkas Markdown yang terbuka di editor ke dalam penampil |
| Lunascape Docs: Buat dokumen dari templat | Membuat satu set dokumen awal pada proyek yang belum memiliki folder dokumen |
| Lunascape Docs: Validasi root dokumentasi | Memeriksa seluruh root dokumentasi dengan docs-lint dan menampilkan hasilnya di Alat Dokumen serta panel "Masalah" |
| Lunascape Docs: Buka Bantuan | Membuka panduan bantuan ini |

## Operasi dari Explorer

Klik kanan berkas `.md`, `.markdown`, atau `.mdx` di Explorer, lalu pilih [Lunascape Docs: Buka di Penampil Spesifikasi].

> **Tips**
>
> Agar berkas Markdown ditampilkan di Lunascape Docs saat dibuka secara biasa, tambahkan asosiasi editor pada pengaturan ruang kerja.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Panduan langkah demi langkah

Dari panduan langkah demi langkah "Memulai Lunascape Docs" pada menu [Bantuan] → "Selamat Datang" di VS Code, Anda dapat mencoba operasi pertama secara berurutan.
