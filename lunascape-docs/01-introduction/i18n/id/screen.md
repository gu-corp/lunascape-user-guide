# Nama dan fungsi setiap bagian layar

Layar Lunascape Docs terdiri dari bilah alat di bagian atas, INDEX di sebelah kiri, isi dokumen di tengah, dan "Di halaman ini" di sebelah kanan.

## Bilah alat

Dijelaskan berurutan dari kiri.

| Nama | Fungsi |
|---|---|
| Nama root dokumentasi | Nama kumpulan dokumen yang sedang ditampilkan. Bila ruang kerja memiliki beberapa root dokumentasi, bagian ini menjadi menu tarik-turun untuk berpindah |
| [Buka INDEX] (tiga garis) | Hanya muncul bila layar sempit. Membuka INDEX sebagai lapisan di atas isi dokumen |
| [Kembali] [Maju] | Menelusuri riwayat penjelajahan |
| [Beranda spesifikasi] (rumah) | Membuka halaman awal root dokumentasi (biasanya `README.md`) |
| [INDEX induk] (↑) | Membuka halaman sampul folder yang memuat dokumen yang sedang ditampilkan. Saat folder dibuka sementara, tombol ini menjadi [Ke folder atas] |
| [Muat ulang] | Membaca ulang dokumen dan INDEX |
| Tautan jejak | Lokasi dokumen yang sedang ditampilkan. Tekan tiap bagian untuk berpindah ke tingkat tersebut |
| Menu bahasa (bola dunia) | Menampilkan bahasa halaman yang sedang dibuka dan bahasa lain yang dapat dipilih. [Buat dan kelola terjemahan…] juga ada di sini |
| Pengalih tema (matahari/bulan) | Berganti antara latar putih dan skema warna VS Code |
| Tampilan kolom | Menampilkan atau menyembunyikan INDEX di kiri dan "Di halaman ini" di kanan, masing-masing secara terpisah |
| [Alat Dokumen] (tanda centang) | Membuka panel pemeriksaan dokumen, pembuatan dari templat, dan terjemahan. Jumlah hasil pemeriksaan juga ditampilkan di sini |
| [Pengaturan tampilan] (roda gigi) | Mengubah pengaturan per pengguna, seperti cara INDEX ditampilkan dan tampil tidaknya tombol edit |
| [Bantuan] (?) | Membuka panduan bantuan ini. Selagi bantuan ditampilkan, tombol [×] muncul di sebelah kanannya |

## INDEX (kiri)

- Ketik pada [Saring dokumen] di bawah judul untuk menampilkan hanya dokumen yang cocok.
- Tekan folder untuk membuka atau menutupnya. Folder yang memiliki halaman sampul (`README.md`) akan membuka halaman sampul itu bila namanya ditekan.
- Arahkan penunjuk ke sebuah item lalu tekan [⋯] yang muncul, atau klik kanan item tersebut, untuk membuka menu tindakannya.
- Melalui [⋯] di ujung kanan judul, Anda dapat membuat dokumen atau folder baru tepat di bawah root dokumentasi.

## Isi dokumen (tengah)

- Bila ada tabel pengelolaan dokumen di awal dokumen, tabel itu dirangkum menjadi satu baris kecil "Informasi dokumen".
- Mulai mengedit dokumen melalui [⋯] (tindakan lainnya) di kanan atas dan [Edit] di kanan bawah.
- Tautan di dalam isi dokumen terbuka pada layar yang sama. URL eksternal terbuka di peramban bawaan.

## Di halaman ini (kanan)

Daftar judul dari dokumen yang sedang ditampilkan. Tekan salah satunya untuk menggulir ke judul tersebut.
