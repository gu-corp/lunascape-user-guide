# نصب افزونه

افزونهٔ VS Code با نام «Lunascape Docs Pro» به‌صورت یک فایل VSIX توزیع می‌شود. رایگان است؛ «Pro» نشان‌دهندهٔ نسخه‌ای است که کار را به یک هوش مصنوعی می‌سپارد و خودش را به‌روزرسانی می‌کند.

## الزامات

- VS Code نسخهٔ 1.90 یا جدیدتر
- قابلیت‌هایی که فایل می‌نویسند — ساختن سند، سازمان‌دهی INDEX، ذخیرهٔ تنظیمات بررسی، ترجمه — فقط در فضای کاری‌ای کار می‌کنند که آن را در VS Code به‌عنوان مورد اعتماد علامت زده باشید.

## نصب

1. فایل VSIX را دریافت کنید. این پیوند همیشه به نسخهٔ فعلی اشاره می‌کند.

   [دانلود lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. نمای افزونه‌ها (`⇧⌘X` / `Ctrl+Shift+X`) را باز کنید.
3. از منوی `…` در گوشهٔ بالا-راست، گزینهٔ [نصب از VSIX…] را انتخاب کنید و فایلی را که دریافت کرده‌اید مشخص کنید.

### از خط فرمان

اگر ترجیح می‌دهید ترمینال را ترک نکنید، تنها با یک خط انجام می‌شود. دریافت و نصب پشت سر هم انجام می‌شوند.

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **توجه**
> اگر `code` پیدا نشد، از پالت فرمان (`⇧⌘P` / `Ctrl+Shift+P`) دستور [دستور پوسته: نصب فرمان 'code' در PATH] را اجرا کنید.

## به‌روزرسانی

وقتی نسخهٔ جدیدتری منتشر شود، افزونه خودش آن را دریافت و نصب می‌کند. VS Code پیشنهاد بارگذاری مجدد پنجره را می‌دهد و از همان لحظه استفاده از نسخهٔ جدید آغاز می‌شود. تنظیمات و اسناد شما همان‌طور که هستند باقی می‌مانند.

بررسی روزی یک‌بار انجام می‌شود. برای بررسی فوری، از پالت فرمان (`⇧⌘P` / `Ctrl+Shift+P`) دستور [Lunascape Docs: بررسی نسخهٔ جدیدتر] را اجرا کنید.

رفتار آن را می‌توانید با تنظیم `lunascapeDocEditor.update.check` تغییر دهید.

| تنظیم | رفتار |
|---|---|
| نسخهٔ جدیدتر را پس از انتشار نصب کن | پیش‌فرض |
| اطلاع بده و نصب را هر بار خودم تصمیم می‌گیرم | یک اعلان نمایش داده می‌شود و تا زمانی که [به‌روزرسانی] را نزنید چیزی تغییر نمی‌کند |
| هرگز بررسی نکن | کاری انجام نمی‌شود |

### وقتی نمی‌تواند به‌روزرسانی شود

اگر پیام «به‌روزرسانی دریافت نشد: No Servers» ظاهر شود، نسخهٔ نصب‌شده 0.22.18 یا قدیمی‌تر است. مسیر به‌روزرسانی آن نسخه در آخرین گام همیشه شکست می‌خورد، بنابراین نمی‌تواند خودش را به نسخه‌ای جدیدتر برساند. یک‌بار به‌صورت دستی و طبق مراحل بالا آن را دوباره نصب کنید؛ از آن پس خودش را به‌روزرسانی می‌کند.

## بررسی نسخه

با باز کردن «Lunascape Docs Pro» در نمای افزونه‌ها، نسخهٔ نصب‌شده نمایش داده می‌شود. هنگام گزارش یک مشکل به آن نیاز خواهید داشت.
