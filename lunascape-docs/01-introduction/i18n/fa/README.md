# Lunascape Docs چیست

Lunascape Docs ابزاری است که سندهای Markdown موجود در یک مخزن Git را همان‌گونه که هستند، به‌عنوان «سایت مشخصات فنی» به‌کار می‌گیرد. به هیچ مرحلهٔ ساخت، سرور مستندات یا پایگاه دادهٔ اختصاصی نیاز نیست.

## کارهایی که می‌توانید انجام دهید

| هدف | قابلیت‌های اصلی |
|---|---|
| خواندن | INDEX (فهرست مطالب)، پیوندهای درون متن، مسیر راهنما، بازگشت و پیشروی، فهرست درون‌صفحه، جست‌وجوی فیلتری |
| دیدن | جدول‌ها، بلوک‌های کد، جا شدن خودکار تصویرها، فرمول ریاضی KaTeX، نمودارهای Mermaid، Vega-Lite، Markmap، WaveDrom و Svgbob، نمایش جمع‌شدهٔ جدول‌های مدیریت سند |
| نوشتن | جابه‌جایی میان ویرایش دیداری و ویرایش منبع Markdown؛ ساخت، تکثیر، تغییر نام و تغییر ترتیب از INDEX |
| بررسی کردن | بررسی سند با docs-lint، وارسی سندها، فصل‌ها و اصطلاحات لازم بر پایهٔ Standard Pack، ساخت از الگو |
| ترجمه کردن | ساخت پیشنهاد ترجمه برای یک صفحه یا به‌صورت یکجا. پس از بررسی ذخیره می‌شود <!-- ai-only --> |
| استفاده از سوی AI | ابزار مشخصات فنی فقط‌خواندنی که عامل‌های VS Code می‌توانند به آن مراجعه کنند <!-- ai-only --> |

## محیط‌های قابل استفاده

| محیط | کاربرد |
|---|---|
| افزونهٔ VS Code | خواندن، ویرایش، بررسی و ترجمهٔ مخزن روی دستگاه شما. محور این راهنما همین است |
| نسخهٔ مرورگر وب | خواندن سندهای روی GitHub (عمومی یا خصوصی)، پیش‌نویس‌های درون دستگاه، خواندن پوشهٔ محلی |
| افزونهٔ Chromium | نسخهٔ مرورگر وب را در یک زبانهٔ مرورگر باز می‌کند |
| مرورگر Lunascape | قرار است همین مدل سند را در خود جای دهد |

## اندیشهٔ پایه

- **Markdown سند مرجع است.** سندها همان فایل‌های Markdown تحت مدیریت Git باقی می‌مانند. Lunascape Docs آن‌ها را به قالبی دیگر تبدیل و نگهداری نمی‌کند.
- **ذخیره را کاربر انجام می‌دهد.** محتوای ویرایش‌شده تنها هنگامی در فایل نوشته می‌شود که [ذخیره] را بفشارید. مرحله‌بندی و ثبت در Git به‌صورت خودکار انجام نمی‌شود.
- **سندها درون دستگاه پردازش می‌شوند.** برای خواندن یا ویرایش، هیچ سندی به بیرون فرستاده نمی‌شود. تنها هنگام ترجمه، مقصد و محتوا از پیش نمایش داده می‌شود و پس از تأیید ارسال می‌گردد.
- **نسخه‌های ترجمه در `i18n/<زبان>/` قرار می‌گیرند.** سندهای زبان پیش‌فرض در جای خود می‌مانند و نسخه‌های ترجمه با همان مسیر نسبی در `i18n/en/` و مانند آن قرار می‌گیرند.
- **AI تنها پیشنهاد می‌دهد.** پیشنهاد ترجمه پس از بررسی تفاوت‌ها ذخیره می‌شود. سند بی‌خبر بازنویسی نمی‌شود. <!-- ai-only -->
