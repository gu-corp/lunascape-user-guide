# Lunascape Docs چیست

Lunascape Docs ابزاری است برای اینکه اسناد Markdown موجود در یک مخزن Git را همان‌طور که هستند، به‌صورت یک «سایت مشخصات فنی» به کار ببرید. نه به ساخت پیشاپیش نیاز است، نه به سرور اسناد و نه به پایگاه دادهٔ اختصاصی.

## کارهایی که می‌توانید انجام دهید

| هدف | قابلیت‌های اصلی |
|---|---|
| خواندن | INDEX (فهرست مطالب)، پیوندهای درون متن، مسیر راهنما، بازگشت و جلو رفتن، فهرست مطالب درون صفحه، جست‌وجوی پالایشی |
| دیدن | جدول، بلوک کد، تنظیم خودکار اندازهٔ تصویر، فرمول ریاضی KaTeX، نمودارهای Mermaid/Vega-Lite/Markmap/WaveDrom/Svgbob، نمایش تاشوی جدول‌های کنترل سند |
| نوشتن | جابه‌جایی میان ویرایش دیداری و ویرایش منبع Markdown؛ ایجاد، تکثیر، تغییر نام و تغییر ترتیب از INDEX |
| بررسی | بررسی سند با docs-lint؛ وارسی اسناد، فصل‌ها و اصطلاحات الزامی بر پایهٔ Standard Pack؛ ایجاد از روی الگو |
| ترجمه | تولید پیشنهاد ترجمه برای یک صفحه یا به‌صورت یکجا؛ ذخیره پس از بازبینی <!-- ai-only --> |
| استفاده از طریق هوش مصنوعی | ابزار مشخصات فنی فقط‌خواندنی که عامل‌های VS Code می‌توانند به آن مراجعه کنند <!-- ai-only --> |

## محیط‌های قابل استفاده

| محیط | کاربرد |
|---|---|
| افزونهٔ VS Code | مشاهده، ویرایش، بررسی و ترجمهٔ مخزن روی رایانهٔ خودتان. محور اصلی این راهنما همین است |
| نسخهٔ مرورگر وب | مشاهدهٔ اسناد روی GitHub (عمومی و خصوصی)، پیش‌نویس روی دستگاه، مشاهدهٔ پوشهٔ محلی |
| افزونهٔ Chromium | نسخهٔ مرورگر وب را در یک زبانهٔ مرورگر باز می‌کند |

## اصول پایه

- **Markdown سند مرجع است.** اسناد همان فایل‌های Markdown تحت مدیریت Git باقی می‌مانند. Lunascape Docs آن‌ها را به قالب دیگری تبدیل و نگهداری نمی‌کند.
- **ذخیره کردن با کاربر است.** محتوای ویرایش‌شده فقط وقتی [ذخیره] را فشار دهید در فایل نوشته می‌شود. استیج کردن و کامیت در Git به‌طور خودکار انجام نمی‌شود.
- **اسناد روی دستگاه شما پردازش می‌شوند.** برای مشاهده یا ویرایش، هیچ سندی به بیرون فرستاده نمی‌شود. فقط هنگام ترجمه، مقصد و محتوای ارسالی از پیش نمایش داده می‌شود و پس از تأیید شما ارسال می‌شود.
- **نسخه‌های ترجمه‌شده در `i18n/<locale>/` قرار می‌گیرند.** اسناد زبان پیش‌فرض در همان جای خود می‌مانند و نسخه‌های ترجمه‌شده با همان مسیر نسبی در `i18n/en/` و مانند آن قرار می‌گیرند.
- **هوش مصنوعی فقط پیشنهاد می‌دهد.** پیشنهاد ترجمه پس از بازبینی تفاوت‌ها ذخیره می‌شود. هیچ سندی بی‌خبر بازنویسی نمی‌شود. <!-- ai-only -->
