# فهرست فرمان‌ها

در پالت فرمان (`⇧⌘P` / `Ctrl+Shift+P`) عبارت «Lunascape Docs» را تایپ کنید تا بتوانید فرمان‌های زیر را اجرا کنید.

| فرمان | کارکرد |
|---|---|
| Lunascape Docs: باز کردن نمایشگر مشخصات فنی | نزدیک‌ترین ریشهٔ مستندات را در نمایشگر باز می‌کند. خواندن، ویرایش، بررسی و ترجمه همه در این صفحه انجام می‌شود |
| Lunascape Docs: باز کردن در نمایشگر مشخصات فنی | فایل Markdown باز در ویرایشگر را در نمایشگر نشان می‌دهد |
| Lunascape Docs: ساخت سند از الگو | در پروژه‌ای که پوشهٔ سند ندارد، نخستین مجموعهٔ اسناد را می‌سازد |
| Lunascape Docs: اعتبارسنجی ریشهٔ مستندات | کل ریشهٔ مستندات را با docs-lint بررسی می‌کند و نتیجه را در ابزارهای سند و پنل «مشکلات» نشان می‌دهد |
| Lunascape Docs: باز کردن راهنما | همین راهنما را باز می‌کند |

## کار از کاوشگر

در کاوشگر روی فایل `.md`، `.markdown` یا `.mdx` راست‌کلیک کنید تا بتوانید [Lunascape Docs: باز کردن در نمایشگر مشخصات فنی] را انتخاب کنید.

> **نکته**
>
> اگر می‌خواهید فایل‌های Markdown هنگام باز شدن به‌صورت معمولی هم در Lunascape Docs نمایش داده شوند، پیوند ویرایشگر را به تنظیمات فضای کاری اضافه کنید.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## راهنمای گام‌به‌گام

از راهنمای گام‌به‌گام «شروع کار با Lunascape Docs» که در منوی [راهنما] ← «خوش‌آمدگویی» در VS Code قرار دارد، می‌توانید نخستین کارها را به‌ترتیب امتحان کنید.
