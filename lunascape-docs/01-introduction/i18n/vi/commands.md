# Danh sách lệnh

Nhập "Lunascape Docs" vào bảng lệnh (`⇧⌘P` / `Ctrl+Shift+P`) để chạy các lệnh sau.

| Lệnh | Chức năng |
|---|---|
| Lunascape Docs: Mở trình xem bản đặc tả | Mở thư mục gốc tài liệu gần nhất trong trình xem. Việc đọc, chỉnh sửa, kiểm tra và dịch đều được thực hiện trên màn hình này |
| Lunascape Docs: Mở bằng trình xem bản đặc tả | Hiển thị tệp Markdown đang mở trong trình soạn thảo bằng trình xem |
| Lunascape Docs: Tạo tài liệu từ mẫu | Tạo bộ tài liệu đầu tiên cho dự án chưa có thư mục tài liệu |
| Lunascape Docs: Kiểm tra thư mục gốc tài liệu | Kiểm tra toàn bộ thư mục gốc tài liệu bằng docs-lint và hiển thị kết quả trong Công cụ tài liệu và bảng "Sự cố" |
| Lunascape Docs: Mở Trợ giúp | Mở hướng dẫn trợ giúp này |

## Thao tác từ Explorer

Nhấp chuột phải vào tệp `.md`, `.markdown` hoặc `.mdx` trong Explorer, bạn có thể chọn [Lunascape Docs: Mở bằng trình xem bản đặc tả].

> **Mẹo**
>
> Để hiển thị tệp Markdown bằng Lunascape Docs ngay cả khi mở theo cách thông thường, hãy thêm liên kết trình soạn thảo vào cài đặt của không gian làm việc.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Hướng dẫn từng bước

Từ hướng dẫn từng bước "Bắt đầu với Lunascape Docs" trong menu [Trợ giúp] → "Chào mừng" của VS Code, bạn có thể thử lần lượt các thao tác đầu tiên.
