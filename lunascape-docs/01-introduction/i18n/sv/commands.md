# Kommandolista

Skriv "Lunascape Docs" i kommandopaletten (`⇧⌘P` / `Ctrl+Shift+P`) för att köra följande kommandon.

| Kommando | Funktion |
|---|---|
| Lunascape Docs: Öppna specifikationsvisaren | Öppnar närmaste dokumentrot i visaren. Läsning, redigering, kontroll och översättning sker i den här vyn |
| Lunascape Docs: Öppna i specifikationsvisaren | Visar den Markdown-fil som är öppen i redigeraren i visaren |
| Lunascape Docs: Skapa dokument från mall | Skapar en första uppsättning dokument i ett projekt som saknar dokumentmapp |
| Lunascape Docs: Validera dokumentroten | Kontrollerar hela dokumentroten med docs-lint och visar resultatet i Dokumentverktyg och i panelen Problem |
| Lunascape Docs: Öppna hjälpen | Öppnar den här hjälpguiden |

## Från Utforskaren

Högerklicka på en `.md`-, `.markdown`- eller `.mdx`-fil i Utforskaren och välj [Lunascape Docs: Öppna i specifikationsvisaren].

> **Tips**
>
> Lägg till en redigerarkoppling i arbetsytans inställningar om du vill att Markdown-filer ska visas i Lunascape Docs även när du öppnar dem på vanligt sätt.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Genomgång

Genomgången "Kom igång med Lunascape Docs", som finns under menyn [Hjälp] → "Välkommen" i VS Code, låter dig prova de första stegen i tur och ordning.
