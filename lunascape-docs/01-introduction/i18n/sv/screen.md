# Skärmens delar och deras funktion

Skärmen i Lunascape Docs består av verktygsfältet högst upp, INDEX till vänster, dokumentet i mitten och "På den här sidan" till höger.

## Verktygsfältet

Från vänster till höger:

| Namn | Funktion |
|---|---|
| Dokumentrotens namn | Namnet på den dokumentuppsättning som visas. När arbetsytan har flera dokumentrötter blir det en listruta där du kan växla mellan dem |
| [Öppna INDEX] (tre streck) | Visas bara när skärmen är smal. Öppnar INDEX ovanpå dokumentet |
| [Tillbaka] [Framåt] | Följer visningshistoriken |
| [Specifikationens startsida] (hus) | Öppnar dokumentrotens startsida (normalt `README.md`) |
| [Överordnat INDEX] (↑) | Öppnar omslagssidan för den mapp som innehåller det visade dokumentet. När du tillfälligt har öppnat en mapp blir knappen [Till överordnad mapp] |
| [Läs in på nytt] | Läser in dokumentet och INDEX på nytt |
| Sökväg | Platsen för det visade dokumentet. Tryck på ett objekt för att gå till den nivån |
| Språkmenyn (jordglob) | Visar språket för den aktuella sidan och de språk du kan växla till. [Skapa och hantera översättningar…] finns också här |
| Temaväxling (sol/måne) | Växlar mellan vit bakgrund och färgerna i VS Code |
| Kolumnvisning | Visar eller döljer INDEX till vänster respektive "På den här sidan" till höger |
| [Dokumentverktyg] (bockmarkering) | Öppnar panelen för dokumentkontroll, skapande från mallar och översättning. Antalet kontrollresultat visas också här |
| [Visningsinställningar] (kugghjul) | Ändrar inställningar per användare, till exempel hur INDEX visas och om redigeringsknappen visas |
| [Hjälp] (?) | Öppnar den här hjälpguiden. När hjälpen visas finns ett [×] till höger om knappen |

## INDEX (till vänster)

- Skriv i [Filtrera dokument] under rubriken för att bara visa dokument som stämmer.
- Tryck på en mapp för att öppna eller stänga den. I en mapp som har en omslagssida (`README.md`) öppnas omslagssidan när du trycker på namnet.
- Öppna objektets åtgärdsmeny med [⋯], som visas när du för pekaren över objektet, eller med högerklick.
- Med [⋯] längst till höger i rubriken skapar du ett nytt dokument eller en ny mapp direkt under dokumentroten.

## Dokumentet (i mitten)

- När det finns en dokumenthanteringstabell överst i dokumentet visas den sammanfattad på en liten rad med "Dokumentinformation".
- Du börjar redigera dokumentet med [⋯] (Fler åtgärder) uppe till höger eller [Redigera] nere till höger.
- Länkar i texten öppnas i samma vy. Externa URL:er öppnas i din standardwebbläsare.

## På den här sidan (till höger)

En lista över rubrikerna i det visade dokumentet. Tryck på en rubrik för att rulla till den.
