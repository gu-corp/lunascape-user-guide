# ชื่อและหน้าที่ของแต่ละส่วนบนหน้าจอ

หน้าจอของ Lunascape Docs ประกอบด้วยแถบเครื่องมือด้านบน INDEX ทางซ้าย เนื้อหาตรงกลาง และ "ในหน้านี้" ทางขวา

## แถบเครื่องมือ

อธิบายเรียงจากซ้ายไปขวา

| ชื่อ | หน้าที่ |
|---|---|
| ชื่อรากเอกสาร | ชื่อของชุดเอกสารที่กำลังแสดงอยู่ เมื่อพื้นที่ทำงานมีรากเอกสารหลายชุด ช่องนี้จะกลายเป็นเมนูแบบเลื่อนลงสำหรับสลับไปมา |
| [เปิด INDEX] (สามขีด) | แสดงเฉพาะเมื่อหน้าจอแคบ จะเปิด INDEX ซ้อนทับบนเนื้อหา |
| [ย้อนกลับ] [ไปข้างหน้า] | ย้อนดูตามประวัติการเปิดอ่าน |
| [หน้าแรกของข้อกำหนด] (รูปบ้าน) | เปิดหน้าเริ่มต้นของรากเอกสาร (ตามปกติคือ `README.md`) |
| [INDEX ระดับบน] (↑) | เปิดหน้าปกของโฟลเดอร์ที่เก็บเอกสารซึ่งกำลังแสดงอยู่ เมื่อเปิดโฟลเดอร์ไว้ชั่วคราว ปุ่มนี้จะเปลี่ยนเป็น [ไปยังโฟลเดอร์ระดับบน] |
| [โหลดใหม่] | อ่านเอกสารและ INDEX ใหม่อีกครั้ง |
| เส้นทางนำทาง | ตำแหน่งของเอกสารที่กำลังแสดงอยู่ กดที่แต่ละรายการเพื่อย้ายไปยังลำดับชั้นนั้น |
| เมนูภาษา (ลูกโลก) | แสดงภาษาของหน้าที่กำลังเปิดอยู่ และภาษาที่สลับไปได้ [สร้างและจัดการคำแปล…] อยู่ที่นี่ด้วย |
| สลับธีม (ดวงอาทิตย์／ดวงจันทร์) | สลับระหว่างพื้นหลังสีขาวกับชุดสีของ VS Code |
| การแสดงคอลัมน์ | แสดงหรือซ่อน INDEX ทางซ้ายและ "ในหน้านี้" ทางขวา แยกจากกัน |
| [เครื่องมือเอกสาร] (เครื่องหมายถูก) | เปิดแผงสำหรับการตรวจสอบเอกสาร การสร้างจากเทมเพลต และคำแปล จำนวนผลการตรวจสอบก็แสดงที่นี่ด้วย |
| [การตั้งค่าการแสดงผล] (ฟันเฟือง) | เปลี่ยนการตั้งค่าเฉพาะผู้ใช้ เช่น รูปแบบการแสดง INDEX และการแสดงปุ่มแก้ไข |
| [วิธีใช้] (?) | เปิดคู่มือวิธีใช้นี้ ขณะที่วิธีใช้แสดงอยู่ จะมี [×] ปรากฏทางขวาของปุ่มนี้ |

## INDEX (ซ้าย)

- พิมพ์ลงใน [กรองเอกสาร] ที่อยู่ใต้หัวข้อ เพื่อแสดงเฉพาะเอกสารที่ตรงกัน
- กดที่โฟลเดอร์เพื่อเปิดหรือปิด โฟลเดอร์ที่มีหน้าปก (`README.md`) จะเปิดหน้าปกเมื่อกดที่ชื่อ
- วางเมาส์บนรายการเพื่อให้ [⋯] ปรากฏ หรือคลิกขวาที่รายการ เพื่อเปิดเมนูการทำงานของรายการนั้น
- [⋯] ที่ริมขวาของหัวข้อ ใช้สร้างเอกสารหรือโฟลเดอร์ใหม่ใต้รากเอกสารโดยตรง

## เนื้อหา (ตรงกลาง)

- เมื่อมีตารางควบคุมเอกสารอยู่ที่ต้นเอกสาร ระบบจะสรุปไว้ในแถว "ข้อมูลเอกสาร" ขนาดเล็ก
- เริ่มแก้ไขเอกสารได้จาก [⋯] (การทำงานอื่น ๆ) ที่มุมขวาบน และ [แก้ไข] ที่มุมขวาล่าง
- ลิงก์ในเนื้อหาจะเปิดในหน้าจอเดียวกัน ส่วน URL ภายนอกจะเปิดในเบราว์เซอร์เริ่มต้น

## ในหน้านี้ (ขวา)

รายการหัวข้อของเอกสารที่กำลังแสดงอยู่ กดแล้วจะเลื่อนไปยังหัวข้อนั้น
