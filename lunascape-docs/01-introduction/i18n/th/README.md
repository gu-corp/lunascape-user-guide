# Lunascape Docs คืออะไร

Lunascape Docs เป็นเครื่องมือที่ใช้จัดการเอกสาร Markdown ในที่เก็บ Git ให้เป็น "เว็บไซต์ข้อกำหนด" ได้ตามที่เป็นอยู่ ไม่จำเป็นต้องมีการบิลด์ล่วงหน้า เซิร์ฟเวอร์เอกสาร หรือฐานข้อมูลเฉพาะ

## สิ่งที่ทำได้

| วัตถุประสงค์ | ความสามารถหลัก |
|---|---|
| อ่าน | INDEX (สารบัญ) ลิงก์ในเนื้อหา เส้นทางนำทาง ย้อนกลับ・ไปข้างหน้า สารบัญในหน้า การค้นหาแบบกรอง |
| ดู | ตาราง บล็อกโค้ด การปรับขนาดรูปภาพอัตโนมัติ สูตรคณิตศาสตร์ KaTeX แผนภาพ Mermaid・Vega-Lite・Markmap・WaveDrom・Svgbob การแสดงตารางควบคุมเอกสารแบบพับเก็บ |
| เขียน | สลับระหว่างการแก้ไขแบบเห็นภาพกับการแก้ไขซอร์ส Markdown การสร้าง ทำสำเนา เปลี่ยนชื่อ และจัดลำดับจาก INDEX |
| ตรวจสอบ | การตรวจสอบเอกสารด้วย docs-lint การตรวจสอบเอกสาร บท และคำศัพท์ที่จำเป็นตาม Standard Pack การสร้างจากเทมเพลต |
| แปล | การสร้างคำแปลที่เสนอทีละหน้าหรือครั้งละหลายหน้า บันทึกหลังจากตรวจสอบแล้ว <!-- ai-only --> |
| ใช้จาก AI | เครื่องมือข้อกำหนดแบบอ่านอย่างเดียวที่เอเจนต์ของ VS Code อ้างอิงได้ <!-- ai-only --> |

## สภาพแวดล้อมที่ใช้ได้

| สภาพแวดล้อม | การใช้งาน |
|---|---|
| ส่วนขยาย VS Code | การอ่าน แก้ไข ตรวจสอบ และแปลที่เก็บบนเครื่องของคุณ วิธีใช้นี้เน้นที่สภาพแวดล้อมนี้ |
| เว็บเบราว์เซอร์ | การอ่านเอกสารบน GitHub (ทั้งแบบสาธารณะและไม่สาธารณะ) ฉบับร่างในเครื่อง การอ่านโฟลเดอร์ในเครื่อง |
| ส่วนขยาย Chromium | เปิดรุ่นเว็บเบราว์เซอร์ในแท็บของเบราว์เซอร์ |
| เบราว์เซอร์ Lunascape | มีแผนจะฝังโมเดลเอกสารเดียวกันนี้ |

## แนวคิดพื้นฐาน

- **Markdown คือต้นฉบับ** เอกสารยังคงเป็นไฟล์ Markdown ที่จัดการด้วย Git ตามเดิม Lunascape Docs ไม่ได้แปลงเป็นรูปแบบอื่นแล้วเก็บไว้
- **การบันทึกทำโดยผู้ใช้** เนื้อหาที่แก้ไขจะถูกเขียนลงไฟล์เมื่อคุณกด [บันทึก] เท่านั้น การจัดเตรียม (staging) และการคอมมิตของ Git ไม่ได้ทำโดยอัตโนมัติ
- **เอกสารประมวลผลภายในเครื่อง** การอ่านหรือแก้ไขจะไม่ส่งเอกสารออกไปภายนอก เฉพาะเมื่อแปลเท่านั้นที่จะแสดงปลายทางและเนื้อหาให้ดูก่อน แล้วจึงส่งหลังจากได้รับการอนุมัติ
- **คำแปลวางไว้ใน `i18n/<ภาษา>/`** เอกสารภาษาเริ่มต้นอยู่ที่เดิม ส่วนคำแปลวางไว้ใน `i18n/en/` เป็นต้น โดยใช้เส้นทางสัมพัทธ์เดียวกัน
- **AI ทำได้แค่เสนอ** คำแปลที่เสนอจะบันทึกหลังจากตรวจสอบส่วนต่างแล้ว จะไม่มีการเขียนทับเอกสารโดยไม่บอกกล่าว <!-- ai-only -->
