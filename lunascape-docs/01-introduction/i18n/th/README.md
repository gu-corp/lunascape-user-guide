# Lunascape Docs คืออะไร

Lunascape Docs เป็นเครื่องมือที่ใช้เอกสาร Markdown ที่วางไว้ในที่เก็บ Git เป็น “เว็บไซต์ข้อกำหนด” ได้ทันทีโดยไม่ต้องแปลงไฟล์ ไม่ต้องบิลด์ล่วงหน้า และไม่ต้องใช้เซิร์ฟเวอร์เอกสารหรือฐานข้อมูลเฉพาะ

## สิ่งที่ทำได้

| วัตถุประสงค์ | ฟังก์ชันหลัก |
|---|---|
| อ่าน | INDEX (สารบัญ), ลิงก์ในเนื้อหา, เส้นทางนำทาง, ย้อนกลับ/ไปข้างหน้า, สารบัญภายในหน้า, การค้นหาแบบกรอง |
| ดู | ตาราง, บล็อกโค้ด, การปรับรูปภาพให้พอดีโดยอัตโนมัติ, สูตรคณิตศาสตร์ KaTeX, แผนภาพ Mermaid/Vega-Lite/Markmap/WaveDrom/Svgbob, การแสดงตารางควบคุมเอกสารแบบยุบ |
| เขียน | การสลับระหว่างการแก้ไขแบบภาพกับการแก้ไขซอร์ส Markdown, การสร้าง ทำสำเนา เปลี่ยนชื่อ และจัดลำดับใหม่จาก INDEX |
| ตรวจสอบ | การตรวจสอบเอกสารด้วย docs-lint, การตรวจเอกสาร บท และคำศัพท์ที่จำเป็นตาม Standard Pack, การสร้างจากเทมเพลต |
| แปล | สร้างคำแปลที่เสนอทีละหน้าหรือหลายหน้าพร้อมกัน แล้วตรวจทานก่อนบันทึก <!-- ai-only --> |
| ใช้จาก AI | เครื่องมือข้อกำหนดแบบอ่านอย่างเดียวที่เอเจนต์ของ VS Code ใช้อ้างอิงได้ <!-- ai-only --> |

## สภาพแวดล้อมที่ใช้งานได้

| สภาพแวดล้อม | การใช้งาน |
|---|---|
| ส่วนขยาย VS Code | ดู แก้ไข ตรวจสอบ และแปลที่เก็บในเครื่องของคุณ วิธีใช้นี้เน้นที่ส่วนขยายนี้เป็นหลัก |
| เวอร์ชันเว็บเบราว์เซอร์ | ดูเอกสารบน GitHub (ทั้งแบบสาธารณะและแบบส่วนตัว), ฉบับร่างที่เก็บไว้ในอุปกรณ์, ดูโฟลเดอร์ในเครื่อง |
| ส่วนขยาย Chromium | เปิดเวอร์ชันเว็บเบราว์เซอร์ในแท็บของเบราว์เซอร์ |

## แนวคิดพื้นฐาน

- **Markdown คือต้นฉบับ** เอกสารยังคงเป็นไฟล์ Markdown ที่จัดการด้วย Git ตามเดิม Lunascape Docs จะไม่แปลงเอกสารเป็นรูปแบบอื่นแล้วเก็บไว้
- **ผู้ใช้เป็นผู้บันทึกเอง** เนื้อหาที่แก้ไขจะถูกเขียนลงไฟล์เฉพาะเมื่อกด [บันทึก] เท่านั้น จะไม่มีการ stage หรือคอมมิตใน Git โดยอัตโนมัติ
- **เอกสารได้รับการประมวลผลภายในอุปกรณ์** จะไม่มีการส่งเอกสารออกไปภายนอกเพื่อการดูหรือแก้ไข เฉพาะตอนแปลเท่านั้นที่จะแสดงปลายทางและเนื้อหาที่จะส่งให้ทราบก่อน แล้วจึงส่งหลังจากได้รับการอนุมัติ
- **คำแปลจะอยู่ใน `i18n/<locale>/`** เอกสารของภาษาเริ่มต้นจะอยู่ที่เดิม ส่วนคำแปลจะวางไว้ใน `i18n/en/` เป็นต้น โดยใช้เส้นทางสัมพัทธ์เดียวกัน
- **AI ทำได้เพียงเสนอ** คำแปลที่เสนอจะบันทึกหลังจากตรวจสอบความแตกต่างแล้ว จะไม่มีการเขียนทับเอกสารโดยไม่แจ้งให้ทราบ <!-- ai-only -->
