# รายการคำสั่ง

พิมพ์ "Lunascape Docs" ในแผงคำสั่ง (`⇧⌘P` / `Ctrl+Shift+P`) เพื่อเรียกใช้คำสั่งต่อไปนี้

| คำสั่ง | การทำงาน |
|---|---|
| Lunascape Docs: เปิดโปรแกรมดูข้อกำหนด | เปิดรากเอกสารที่ใกล้ที่สุดในโปรแกรมดู การอ่าน การแก้ไข การตรวจสอบ และการแปล ทำได้ในหน้าจอนี้ |
| Lunascape Docs: เปิดในโปรแกรมดูข้อกำหนด | แสดงไฟล์ Markdown ที่เปิดอยู่ในตัวแก้ไขด้วยโปรแกรมดู |
| Lunascape Docs: สร้างเอกสารจากเทมเพลต | สร้างชุดเอกสารชุดแรกในโปรเจกต์ที่ยังไม่มีโฟลเดอร์เอกสาร |
| Lunascape Docs: ตรวจสอบรากเอกสาร | ตรวจสอบรากเอกสารทั้งหมดด้วย docs-lint แล้วแสดงผลลัพธ์ในเครื่องมือเอกสารและแผง "ปัญหา" |
| Lunascape Docs: เปิดวิธีใช้ | เปิดคู่มือวิธีใช้นี้ |

## การใช้งานจากตัวสำรวจ

คลิกขวาที่ไฟล์ `.md`, `.markdown` หรือ `.mdx` ในตัวสำรวจ แล้วเลือก [Lunascape Docs: เปิดในโปรแกรมดูข้อกำหนด]

> **เคล็ดลับ**
>
> หากต้องการให้ไฟล์ Markdown แสดงด้วย Lunascape Docs เมื่อเปิดตามปกติ ให้เพิ่มการเชื่อมโยงตัวแก้ไขในการตั้งค่าของพื้นที่ทำงาน
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## บทแนะนำการใช้งาน

จากเมนู [วิธีใช้] → "ยินดีต้อนรับ" ของ VS Code เลือกบทแนะนำการใช้งาน "เริ่มต้นใช้งาน Lunascape Docs" เพื่อทดลองการใช้งานขั้นแรกไปตามลำดับ
