# สร้างเอกสารครั้งแรก

ในโปรเจกต์ที่ยังไม่มีโฟลเดอร์เอกสาร คุณสามารถสร้างชุดเอกสารชุดแรกได้จาก Command Palette

1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code แล้วตั้งให้พื้นที่ทำงานเชื่อถือได้
2. เรียกใช้ "Lunascape Docs: สร้างเอกสารจากเทมเพลต" จาก Command Palette (`⇧⌘P` / `Ctrl+Shift+P`)
   หากพื้นที่ทำงานมีหลายโฟลเดอร์ ให้เลือกโฟลเดอร์ที่จะสร้างเอกสาร
3. เลือกโครงสร้างที่จะสร้าง
   - [เอกสารหน้าเดียว]: โครงสร้างขั้นต่ำที่มีเพียง `README.md` เหมาะกับข้อกำหนดสั้น ๆ บันทึกย่อ หรือเอกสารอธิบายเดี่ยว ๆ
   - [ชุดเอกสาร]: สร้างหน้าแรก พร้อมหน้าทางเข้าของ `specification/` (ข้อกำหนด), `manual/` (คู่มือ) และ `help/` (วิธีใช้)
4. ป้อนชื่อเอกสาร ชื่อนี้จะใช้กับ README และหัวข้อของเอกสารแต่ละฉบับ
5. ป้อนโฟลเดอร์เอกสารที่จะสร้าง โดยเป็นเส้นทางสัมพัทธ์จากพื้นที่ทำงาน ค่าเริ่มต้นคือ `docs`
6. ตรวจสอบรายการไฟล์ที่จะสร้าง แล้วกด [สร้าง]
   เมื่อสร้างเสร็จ `README.md` ไฟล์ใหม่จะเปิดขึ้นในโปรแกรมดูเอกสาร

> **ข้อควรทราบ**
>
> - ไฟล์ที่มีอยู่แล้วจะไม่ถูกเขียนทับ หากไฟล์ที่จะสร้างมีอยู่แล้วแม้เพียงไฟล์เดียว ระบบจะยกเลิกโดยไม่สร้างสิ่งใดเลย
> - ไม่สามารถสร้างได้ในพื้นที่ทำงานที่ไม่เชื่อถือได้

> **เคล็ดลับ**
>
> - หากมีโฟลเดอร์เอกสารอยู่แล้ว ไม่จำเป็นต้องทำตามขั้นตอนนี้ ให้ไปที่ [การใช้งานพื้นฐาน](../02-reading/README.md) ได้เลย
> - เมื่อเอกสารเพิ่มมากขึ้น คุณสามารถเลือกเทมเพลตเพื่อเพิ่มเอกสารทีละฉบับได้จากแท็บ [สร้าง] ของเครื่องมือเอกสาร
