# การติดตั้งส่วนขยาย

ส่วนขยาย VS Code "Lunascape Docs Pro" เผยแพร่เป็นไฟล์ VSIX ใช้งานได้ฟรี "Pro" หมายถึงรุ่นที่มีความสามารถในการส่งงานให้ AI และอัปเดตตัวเอง

## ความต้องการของระบบ

- VS Code 1.90 ขึ้นไป
- ความสามารถที่มีการเขียนไฟล์ เช่น การสร้างเอกสาร การจัดระเบียบจาก INDEX การบันทึกการตั้งค่าการตรวจสอบ และการแปล ใช้ได้เฉพาะในพื้นที่ทำงานที่คุณตั้งให้เป็น "เชื่อถือได้" ใน VS Code เท่านั้น

## การติดตั้ง

1. รับไฟล์ VSIX ลิงก์นี้ชี้ไปที่เวอร์ชันล่าสุดเสมอ

   [ดาวน์โหลด lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. เปิดมุมมองส่วนขยายของ VS Code (`⇧⌘X` / `Ctrl+Shift+X`)
3. เลือก [ติดตั้งจาก VSIX...] จากเมนู `…` ที่มุมขวาบน แล้วระบุไฟล์ที่รับมา

### ติดตั้งด้วยคำสั่ง

คุณสามารถทำให้เสร็จได้ด้วยคำสั่งบรรทัดเดียวจากเทอร์มินัล โดยรับไฟล์และติดตั้งต่อเนื่องกัน

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **หมายเหตุ**
> หากไม่พบ `code` ให้เรียกใช้ [Shell Command: Install 'code' command in PATH] จาก Command Palette (`⇧⌘P` / `Ctrl+Shift+P`)

## การอัปเดต

เมื่อมีการเผยแพร่เวอร์ชันใหม่ ส่วนขยายจะรับและติดตั้งด้วยตัวเอง เมื่อ VS Code แนะนำให้โหลดหน้าต่างใหม่ การเปลี่ยนจะเกิดขึ้นตรงนั้น การตั้งค่าและเอกสารของคุณจะยังคงอยู่ตามเดิม

การตรวจสอบเกิดขึ้นวันละครั้ง หากต้องการตรวจสอบทันที ให้เรียกใช้ [Lunascape Docs: ตรวจสอบการอัปเดต] จาก Command Palette (`⇧⌘P` / `Ctrl+Shift+P`)

คุณสามารถเปลี่ยนพฤติกรรมได้ที่การตั้งค่า `lunascapeDocEditor.update.check`

| การตั้งค่า | พฤติกรรม |
|---|---|
| ติดตั้งเมื่อมีการเผยแพร่เวอร์ชันใหม่ | ค่าเริ่มต้น |
| แจ้งให้ทราบ แล้วตัดสินใจแต่ละครั้งว่าจะติดตั้งหรือไม่ | จะมีการแจ้งเตือนปรากฏขึ้น และจะเปลี่ยนก็ต่อเมื่อกด [อัปเดต] เท่านั้น |
| ไม่ตรวจสอบ | ไม่ทำอะไร |

### เมื่ออัปเดตไม่ได้

หากปรากฏข้อความ "ไม่สามารถรับการอัปเดตได้: No Servers" แสดงว่าเวอร์ชันที่ติดตั้งอยู่เป็น 0.22.18 หรือก่อนหน้านั้น ความสามารถในการอัปเดตของเวอร์ชันนั้นจะล้มเหลวในขั้นตอนสุดท้ายหลังจากรับไฟล์มาแล้วเสมอ จึงไม่สามารถอัปเดตตัวเองได้ กรุณาติดตั้งใหม่ด้วยมือเพียงครั้งเดียวตามขั้นตอนข้างต้น หลังจากนั้นมันจะอัปเดตด้วยตัวเอง

## การตรวจสอบเวอร์ชัน

เมื่อเปิด "Lunascape Docs Pro" ในมุมมองส่วนขยาย จะแสดงเวอร์ชันที่ติดตั้งอยู่ ซึ่งจำเป็นเมื่อคุณรายงานปัญหา
