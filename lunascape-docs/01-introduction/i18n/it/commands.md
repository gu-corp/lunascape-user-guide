# Elenco dei comandi

Digita «Lunascape Docs» nel riquadro comandi (`⇧⌘P` / `Ctrl+Shift+P`) per eseguire i comandi seguenti.

| Comando | Funzione |
|---|---|
| Lunascape Docs: Apri il visualizzatore di specifiche | Apre nel visualizzatore la radice della documentazione più vicina. La lettura, la modifica, il controllo e la traduzione avvengono tutti in questa schermata |
| Lunascape Docs: Apri nel visualizzatore di specifiche | Mostra nel visualizzatore il file Markdown aperto nell'editor |
| Lunascape Docs: Crea documentazione da modello | Crea un primo insieme di documenti in un progetto privo di cartella della documentazione |
| Lunascape Docs: Verifica la radice della documentazione | Controlla l'intera radice della documentazione con docs-lint e mostra i risultati negli Strumenti documento e nel pannello «Problemi» |
| Lunascape Docs: Apri la Guida | Apre questa guida |

## Da Esplora risorse

In Esplora risorse fai clic con il pulsante destro su un file `.md`, `.markdown` o `.mdx` e scegli [Lunascape Docs: Apri nel visualizzatore di specifiche].

> **Suggerimento**
>
> Per mostrare i file Markdown in Lunascape Docs anche quando li apri normalmente, aggiungi un'associazione dell'editor alle impostazioni dell'area di lavoro.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```
