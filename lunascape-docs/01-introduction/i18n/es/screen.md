# Nombres y funciones de las partes de la pantalla

La pantalla de Lunascape Docs se compone de la barra de herramientas superior, el INDEX a la izquierda, el documento en el centro y «En esta página» a la derecha.

## Barra de herramientas

Se describe de izquierda a derecha.

| Nombre | Función |
|---|---|
| Nombre de la raíz de documentación | Nombre del conjunto de documentos que se muestra. Cuando el área de trabajo tiene varias raíces de documentación, se convierte en una lista desplegable que permite cambiar entre ellas |
| [Abrir INDEX] (tres líneas) | Solo aparece cuando la pantalla es estrecha. Abre el INDEX superpuesto sobre el documento |
| [Atrás] [Adelante] | Recorren el historial de navegación |
| [Inicio de la especificación] (casa) | Abre la página inicial de la raíz de documentación (normalmente `README.md`) |
| [INDEX superior] (↑) | Abre la portada de la carpeta que contiene el documento mostrado. Cuando se está viendo una carpeta de forma temporal, cambia a [Subir a la carpeta superior] |
| [Recargar] | Vuelve a leer el documento y el INDEX |
| Ruta de navegación | Ubicación del documento mostrado. Al pulsar cada elemento se accede a ese nivel |
| Menú de idiomas (globo terráqueo) | Muestra el idioma de la página actual y los idiomas a los que puede cambiar. [Crear y gestionar traducciones…] también está aquí |
| Cambio de tema (sol/luna) | Alterna entre el fondo blanco y los colores de VS Code |
| Visualización de columnas | Muestra u oculta el INDEX de la izquierda y «En esta página» de la derecha, cada uno por separado |
| [Herramientas de documentos] (marca de verificación) | Abre los paneles de comprobación de documentos, creación a partir de plantillas y traducción. El número de resultados de la comprobación también se muestra aquí |
| [Configuración de visualización] (engranaje) | Cambia los ajustes de cada usuario, como el aspecto del INDEX o la visibilidad del botón de edición |
| [Ayuda] (?) | Abre esta guía de ayuda. Mientras se muestra la ayuda, aparece [×] a su derecha |

## INDEX (izquierda)

- Si escribe en [Filtrar documentos], debajo del encabezado, solo se muestran los documentos que coinciden.
- Al pulsar una carpeta, esta se abre o se cierra. En las carpetas que tienen portada (`README.md`), al pulsar el nombre se abre la portada.
- Coloque el puntero sobre un elemento para que aparezca [⋯], o haga clic con el botón derecho, para abrir el menú de acciones de ese elemento.
- Desde [⋯], en el extremo derecho del encabezado, puede crear documentos y carpetas directamente en la raíz de documentación.

## Documento (centro)

- Cuando el documento tiene una tabla de gestión al principio, se resume en una pequeña fila «Información del documento».
- Para empezar a editar el documento, use [⋯] (Más acciones) en la parte superior derecha o [Editar] en la parte inferior derecha.
- Los enlaces del texto se abren en la misma pantalla. Las URL externas se abren en el navegador predeterminado.

## En esta página (derecha)

Lista de los encabezados del documento mostrado. Al pulsar uno, la página se desplaza hasta ese encabezado.
