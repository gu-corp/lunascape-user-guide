# Lista de comandos

Escriba «Lunascape Docs» en la paleta de comandos (`⇧⌘P` / `Ctrl+Shift+P`) para ejecutar los comandos siguientes.

| Comando | Función |
|---|---|
| Lunascape Docs: Abrir el visor de especificaciones | Abre en el visor la raíz de documentación más cercana. La lectura, la edición, la comprobación y la traducción se realizan en esta pantalla |
| Lunascape Docs: Abrir en el visor de especificaciones | Muestra en el visor el archivo Markdown abierto en el editor |
| Lunascape Docs: Crear documentación a partir de una plantilla | Crea un primer conjunto de documentos en un proyecto que no tiene carpeta de documentos |
| Lunascape Docs: Validar la raíz de documentación | Comprueba toda la raíz de documentación con docs-lint y muestra los resultados en Herramientas de documentos y en el panel «Problemas» |
| Lunascape Docs: Abrir la ayuda | Abre esta guía de ayuda |

## Desde el Explorador

Haga clic con el botón derecho en un archivo `.md`, `.markdown` o `.mdx` en el Explorador y elija [Lunascape Docs: Abrir en el visor de especificaciones].

> **Sugerencia**
>
> Para mostrar los archivos Markdown en Lunascape Docs también cuando los abra de la manera habitual, añada una asociación de editor a la configuración del área de trabajo.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```
