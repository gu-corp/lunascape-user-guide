# Lista de comenzi

Tastați „Lunascape Docs” în paleta de comenzi (`⇧⌘P` / `Ctrl+Shift+P`) pentru a executa comenzile următoare.

| Comandă | Funcție |
|---|---|
| Lunascape Docs: Deschide vizualizatorul de specificații | Deschide în vizualizator cea mai apropiată rădăcină a documentației. Citirea, editarea, verificarea și traducerea se fac în acest ecran |
| Lunascape Docs: Deschide în vizualizatorul de specificații | Afișează în vizualizator fișierul Markdown deschis în editor |
| Lunascape Docs: Creează documente dintr-un șablon | Creează un prim set de documente într-un proiect care nu are un folder de documente |
| Lunascape Docs: Validează rădăcina documentației | Verifică întreaga rădăcină a documentației cu docs-lint și afișează rezultatele în Instrumente pentru documente și în panoul „Probleme” |
| Lunascape Docs: Deschide ajutorul | Deschide acest ghid de ajutor |

## Operațiuni din Explorator

Faceți clic dreapta pe un fișier `.md`, `.markdown` sau `.mdx` în Explorator și alegeți [Lunascape Docs: Deschide în vizualizatorul de specificații].

> **Sfat**
>
> Pentru ca fișierele Markdown să fie afișate în Lunascape Docs și atunci când le deschideți în mod obișnuit, adăugați o asociere de editor în setările spațiului de lucru.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Prezentare ghidată

Din prezentarea ghidată „Începeți cu Lunascape Docs”, aflată în meniul [Ajutor] → „Bun venit” din VS Code, puteți încerca pe rând primele operațiuni.
