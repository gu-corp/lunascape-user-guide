# Denumirea și rolul fiecărei părți a ecranului

Ecranul Lunascape Docs este alcătuit din bara de instrumente din partea de sus, INDEX în stânga, documentul în centru și „Pe această pagină” în dreapta.

## Bara de instrumente

Elementele sunt prezentate de la stânga la dreapta.

| Denumire | Rol |
|---|---|
| Numele rădăcinii documentației | Numele setului de documente afișat. Când spațiul de lucru are mai multe rădăcini ale documentației, devine o listă derulantă și puteți comuta între ele |
| [Deschide INDEX] (trei linii) | Apare doar când ecranul este îngust. Deschide INDEX suprapus peste document |
| [Înapoi] [Înainte] | Parcurg istoricul de navigare |
| [Pagina principală a documentației] (casă) | Deschide pagina de început a rădăcinii documentației (de obicei `README.md`) |
| [INDEX părinte] (↑) | Deschide pagina de întâmpinare a folderului care conține documentul afișat. Când folderul este deschis temporar, devine [La folderul superior] |
| [Reîncarcă] | Reîncarcă documentul și INDEX |
| Firul de navigare | Locul documentului afișat. Apăsați un element pentru a trece la nivelul respectiv |
| Meniul de limbă (glob) | Arată limba paginii afișate și limbile către care puteți comuta. Tot aici se află [Creează și gestionează traduceri…] |
| Comutator de temă (soare/lună) | Comută între fundalul alb și paleta de culori VS Code |
| Afișarea coloanelor | Afișează sau ascunde separat INDEX din stânga și „Pe această pagină” din dreapta |
| [Instrumente pentru documente] (bifă) | Deschide panoul pentru verificarea documentelor, crearea din șabloane și traducere. Tot aici se afișează numărul rezultatelor verificării |
| [Setări de afișare] (rotiță) | Modifică setările fiecărui utilizator, precum modul de afișare a INDEX sau afișarea butonului de editare |
| [Ajutor] (?) | Deschide acest ghid de ajutor. Cât timp este afișat ajutorul, în dreapta apare [×] |

## INDEX (stânga)

- Dacă scrieți în [Filtrează documentele], sub titlu, se afișează doar documentele care se potrivesc.
- Apăsați un folder pentru a-l deschide sau a-l închide. La folderele care au o pagină de întâmpinare (`README.md`), apăsarea numelui deschide acea pagină.
- Deschideți meniul de acțiuni al unui element cu [⋯], care apare când treceți cu mausul peste el, sau cu clic dreapta.
- Din [⋯] aflat la capătul din dreapta al titlului puteți crea un document sau un folder nou direct în rădăcina documentației.

## Documentul (centru)

- Când documentul are la început un tabel de gestionare, acesta este afișat concentrat într-un rând mic, „Informații despre document”.
- Editarea documentului începe din [⋯] (Alte acțiuni), în dreapta sus, și din [Editează], în dreapta jos.
- Legăturile din text se deschid în același ecran. Adresele URL externe se deschid în browserul implicit.

## Pe această pagină (dreapta)

Lista titlurilor din documentul afișat. Apăsați unul pentru a derula până la el.
