# Lunascape Docs란

Lunascape Docs는 Git 리포지토리에 둔 Markdown 문서를 그대로 "사양서 사이트"로 다루기 위한 도구입니다. 사전 빌드, 문서 서버, 전용 데이터베이스는 필요하지 않습니다.

## 할 수 있는 일

| 목적 | 주요 기능 |
|---|---|
| 읽기 | INDEX(목차), 본문 링크, 탐색 경로, 뒤로·앞으로, 페이지 내 목차, 필터 검색 |
| 보기 | 표, 코드 블록, 이미지 자동 맞춤, KaTeX 수식, Mermaid·Vega-Lite·Markmap·WaveDrom·Svgbob 다이어그램, 문서 관리표 접어서 표시 |
| 쓰기 | 비주얼 편집과 Markdown 소스 편집 전환, INDEX에서 만들기·복제·이름 바꾸기·순서 변경 |
| 확인하기 | docs-lint를 이용한 문서 검사, Standard Pack에 따른 필수 문서·장·용어 확인, 템플릿으로 만들기 |
| 번역하기 | 페이지 단위 또는 일괄로 번역안 생성. 확인한 뒤 저장 <!-- ai-only --> |
| AI에서 사용하기 | VS Code의 에이전트가 참조할 수 있는 읽기 전용 사양 도구 <!-- ai-only --> |

## 사용할 수 있는 환경

| 환경 | 용도 |
|---|---|
| VS Code 확장 프로그램 | 로컬 리포지토리의 열람, 편집, 검사, 번역. 이 도움말은 주로 이 환경을 다룹니다 |
| 웹 브라우저 버전 | GitHub에 있는 문서(공개·비공개) 열람, 기기에 저장되는 초안, 로컬 폴더 열람 |
| Chromium 확장 프로그램 | 웹 브라우저 버전을 브라우저 탭에서 엽니다 |

## 기본 개념

- **Markdown이 정본입니다.** 문서는 Git으로 관리되는 Markdown 파일 그대로입니다. Lunascape Docs가 문서를 다른 형식으로 변환해 보관하지 않습니다.
- **저장은 사용자가 합니다.** 편집한 내용은 [저장]을 눌렀을 때만 파일에 기록됩니다. Git의 스테이징이나 커밋은 자동으로 하지 않습니다.
- **문서는 기기 안에서 처리합니다.** 열람이나 편집을 위해 문서를 외부로 보내지 않습니다. 번역할 때만 전송 대상과 내용을 미리 표시하고, 승인을 받은 뒤에 전송합니다.
- **번역본은 `i18n/<locale>/`에 둡니다.** 기본 언어 문서는 원래 위치에 두고, 번역본은 같은 상대 경로로 `i18n/en/` 등에 둡니다.
- **AI는 제안까지만 합니다.** 번역안은 변경 사항을 확인한 뒤 저장합니다. 사용자 모르게 문서를 고쳐 쓰지 않습니다. <!-- ai-only -->
