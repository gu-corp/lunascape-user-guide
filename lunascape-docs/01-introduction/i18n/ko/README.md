# Lunascape Docs란

Lunascape Docs는 Git 리포지토리에 있는 Markdown 문서를 그대로 "사양서 사이트"로 다루기 위한 도구입니다. 사전 빌드, 문서 서버, 전용 데이터베이스가 필요하지 않습니다.

## 할 수 있는 일

| 목적 | 주요 기능 |
|---|---|
| 읽기 | INDEX(목차), 본문 링크, 이동 경로, 뒤로·앞으로, 이 페이지, 필터 검색 |
| 보기 | 표, 코드 블록, 이미지 자동 맞춤, KaTeX 수식, Mermaid·Vega-Lite·Markmap·WaveDrom·Svgbob 다이어그램, 문서 관리표 접어 표시 |
| 쓰기 | 비주얼 편집과 Markdown 소스 편집 전환, INDEX에서 만들기·복제·이름 바꾸기·정렬 순서 변경 |
| 확인하기 | docs-lint를 통한 문서 검사, Standard Pack에 따른 필수 문서·장·용어 확인, 템플릿에서 만들기 |
| 번역하기 | 한 페이지 단위 또는 일괄 번역안 생성. 확인한 후 저장 <!-- ai-only --> |
| AI에서 사용하기 | VS Code 에이전트가 참조할 수 있는 읽기 전용 사양 도구 <!-- ai-only --> |

## 사용할 수 있는 환경

| 환경 | 용도 |
|---|---|
| VS Code 확장 기능 | 로컬 리포지토리의 열람, 편집, 검사, 번역. 이 도움말의 중심입니다 |
| 웹 브라우저 버전 | GitHub상의 문서(공개·비공개) 열람, 단말 내 초안, 로컬 폴더 열람 |
| Chromium 확장 기능 | 웹 브라우저 버전을 브라우저 탭에서 엽니다 |
| Lunascape 브라우저 | 동일한 문서 모델을 탑재할 예정입니다 |

## 기본 개념

- **Markdown이 정본입니다.** 문서는 Git으로 관리되는 Markdown 파일 그대로입니다. Lunascape Docs가 다른 형식으로 변환하여 보관하지 않습니다.
- **저장은 사용자가 합니다.** 편집한 내용은 [저장]을 눌렀을 때만 파일에 기록합니다. Git 스테이징이나 커밋은 자동으로 하지 않습니다.
- **문서는 단말 내에서 처리합니다.** 열람이나 편집을 위해 문서를 외부로 보내지 않습니다. 번역할 때만 보내는 곳과 내용을 미리 표시하고, 승인 후에 전송합니다.
- **번역본은 `i18n/<언어>/`에 둡니다.** 기본 언어 문서는 원래 위치에 그대로 두고, 번역본은 동일한 상대 경로로 `i18n/en/` 등에 둡니다.
- **AI는 제안까지만 합니다.** 번역안은 차이를 확인한 후 저장합니다. 문서를 말없이 고쳐 쓰지 않습니다. <!-- ai-only -->
