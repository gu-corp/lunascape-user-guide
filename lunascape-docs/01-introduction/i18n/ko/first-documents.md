# 처음으로 문서 작성하기

문서 폴더가 아직 없는 프로젝트에서는 명령 팔레트에서 최초의 문서 일체를 작성할 수 있습니다.

1. VS Code에서 프로젝트 폴더를 열고 작업 영역을 신뢰합니다.
2. 명령 팔레트(`⇧⌘P` / `Ctrl+Shift+P`)에서 "Lunascape Docs: 템플릿에서 문서 작성"을 실행합니다.
   작업 영역에 폴더가 여러 개 있을 때는 작성할 작업 영역을 선택합니다.
3. 작성할 구성을 선택합니다.
   - [1페이지 문서]: `README.md`만 있는 최소 구성입니다. 짧은 사양서, 메모, 단독 설명 문서에 적합합니다.
   - [문서 일체]: 첫 페이지와 함께 `specification/`(사양서), `manual/`(매뉴얼), `help/`(도움말)의 입구를 작성합니다.
4. 문서 제목을 입력합니다. README와 각 문서의 제목에 사용됩니다.
5. 작성할 문서 폴더를 입력합니다. 작업 영역 기준의 상대 경로이며, 기본값은 `docs`입니다.
6. 작성될 파일 목록을 확인하고 [작성]을 누릅니다.
   작성이 끝나면 새 `README.md`가 뷰어에서 열립니다.

> **참고**
>
> - 기존 파일은 덮어쓰지 않습니다. 작성할 파일 중 하나라도 이미 존재하면 아무것도 작성하지 않고 중단합니다.
> - 신뢰하지 않는 작업 영역에서는 작성할 수 없습니다.

> **팁**
>
> - 이미 문서 폴더가 있는 경우에는 이 절차가 필요하지 않습니다. [기본 조작](../02-reading/README.md)으로 진행하세요.
> - 문서가 늘어나면 문서 도구의 [작성] 탭에서 템플릿을 선택해 문서를 하나씩 추가할 수 있습니다.
