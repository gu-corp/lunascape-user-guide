# 화면 각 부분의 이름과 기능

Lunascape Docs 화면은 위쪽의 도구 모음, 왼쪽의 INDEX, 가운데의 본문, 오른쪽의 "이 페이지"로 구성되어 있습니다.

## 도구 모음

왼쪽부터 순서대로 설명합니다.

| 이름 | 기능 |
|---|---|
| 문서 루트 이름 | 표시 중인 문서 세트의 이름입니다. 작업 영역에 문서 루트가 여러 개 있을 때는 드롭다운이 되어 전환할 수 있습니다 |
| [INDEX 열기] （세 줄 아이콘） | 화면이 좁을 때만 표시됩니다. INDEX를 본문 위에 겹쳐서 엽니다 |
| [뒤로] [앞으로] | 열람 기록을 따라 이동합니다 |
| [사양서 홈] （집 아이콘） | 문서 루트의 시작 페이지（보통은 `README.md`）를 엽니다 |
| [상위 INDEX] （↑） | 표시 중인 문서가 들어 있는 폴더의 표지를 엽니다. 폴더를 일시적으로 열어 둔 상태에서는 [상위 폴더로]가 됩니다 |
| [다시 불러오기] | 문서와 INDEX를 다시 읽어 들입니다 |
| 이동 경로 | 표시 중인 문서의 위치입니다. 각 항목을 누르면 해당 계층으로 이동합니다 |
| 언어 메뉴 （지구본 아이콘） | 표시 중인 페이지의 언어와 전환할 수 있는 언어를 표시합니다. [번역 만들기·관리…]도 여기에 있습니다 |
| 테마 전환 （해／달 아이콘） | 흰색 배경과 VS Code의 배색을 전환합니다 |
| 칼럼 표시 | 왼쪽의 INDEX와 오른쪽의 "이 페이지"를 각각 표시／숨김으로 전환합니다 |
| [문서 도구] （체크 표시 아이콘） | 문서 검사, 템플릿에서 만들기, 번역 패널을 엽니다. 검사 결과의 건수도 여기에 표시됩니다 |
| [표시 설정] （톱니바퀴 아이콘） | INDEX의 표시 방식이나 편집 버튼의 표시 여부 등 사용자별 설정을 변경합니다 |
| [도움말] （? 아이콘） | 이 도움말 가이드를 엽니다. 도움말이 표시되어 있는 동안에는 오른쪽 옆에 [×]가 표시됩니다 |

## INDEX（왼쪽）

- 제목 아래의 [문서 필터링]에 입력하면 일치하는 문서만 표시합니다.
- 폴더를 누르면 열리고 닫힙니다. 표지（`README.md`）가 있는 폴더는 이름을 누르면 표지를 엽니다.
- 항목에 마우스를 올리면 표시되는 [⋯] 또는 마우스 오른쪽 버튼으로 해당 항목의 작업 메뉴를 엽니다.
- 제목 오른쪽 끝의 [⋯]에서는 문서 루트 바로 아래에 새 문서나 폴더를 만들 수 있습니다.

## 본문（가운데）

- 문서 맨 앞에 문서 관리표가 있을 때는 작은 "문서 정보" 행으로 묶어서 표시합니다.
- 오른쪽 위의 [⋯]（기타 작업）와 오른쪽 아래의 [편집]에서 문서 편집을 시작합니다.
- 본문 안의 링크는 같은 화면에서 열립니다. 외부 URL은 기본 브라우저에서 열립니다.

## 이 페이지（오른쪽）

표시 중인 문서의 제목 목록입니다. 누르면 해당 제목까지 스크롤합니다.
