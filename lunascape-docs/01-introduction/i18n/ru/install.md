# Установка расширения

Расширение VS Code «Lunascape Docs Pro» распространяется в виде файла VSIX. Оно бесплатно; «Pro» обозначает редакцию, которая передает работу ИИ и обновляет себя сама.

## Требования

- VS Code 1.90 или новее
- Функции, которые записывают файлы, — создание документов, упорядочивание INDEX, сохранение настроек проверки, перевод — работают только в рабочей области, отмеченной в VS Code как надежная.

## Установка

1. Получите файл VSIX. Эта ссылка всегда указывает на текущую версию.

   [Скачать lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. Откройте представление расширений (`⇧⌘X` / `Ctrl+Shift+X`).
3. В меню `…` в правом верхнем углу выберите [Установить из VSIX…] и укажите скачанный файл.

### Из командной строки

Одна строка, если вы предпочитаете не покидать терминал. Она скачивает и устанавливает.

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **Примечание**
> Если `code` не найден, выполните [Оболочка: установить команду «code» в PATH] из палитры команд (`⇧⌘P` / `Ctrl+Shift+P`).

## Обновление

Когда публикуется более новая версия, расширение само скачивает и устанавливает ее. VS Code предложит перезагрузить окно — с этого момента вы работаете в новой версии. Ваши настройки и документы остаются как есть.

Проверка выполняется один раз в день. Чтобы проверить прямо сейчас, выполните [Lunascape Docs: Проверить наличие новой версии] из палитры команд (`⇧⌘P` / `Ctrl+Shift+P`).

Поведение меняется настройкой `lunascapeDocEditor.update.check`.

| Настройка | Что происходит |
|---|---|
| Устанавливать более новую версию, когда она опубликована | По умолчанию |
| Сообщать и давать решать каждый раз | Появляется уведомление, и ничего не меняется, пока вы не нажмете [Обновить] |
| Не проверять | Ничего не происходит |

### Когда обновление не удается

Сообщение «Не удалось получить обновление: No Servers» означает, что установлена версия 0.22.18 или более ранняя. Ее механизм обновления всегда дает сбой на последнем шаге после скачивания, поэтому сама она обновиться не может. Установите ее один раз вручную, как описано выше; далее она будет обновляться сама.

## Проверка версии

Откройте «Lunascape Docs Pro» в представлении расширений, чтобы увидеть установленную версию. Она понадобится при сообщении о неполадке.
