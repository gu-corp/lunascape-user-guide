# Что такое Lunascape Docs

Lunascape Docs — это инструмент, который позволяет работать с документами Markdown, размещенными в репозитории Git, как с готовым «сайтом спецификаций». Предварительная сборка, сервер документации и отдельная база данных не нужны.

## Возможности

| Цель | Основные функции |
|---|---|
| Чтение | INDEX (оглавление), ссылки в тексте, цепочка навигации, переходы назад и вперед, оглавление страницы, поиск с фильтром |
| Просмотр | Таблицы, блоки кода, автоматическая подгонка изображений, формулы KaTeX, схемы Mermaid, Vega-Lite, Markmap, WaveDrom и Svgbob, свернутое отображение таблиц управления документом |
| Запись | Переключение между визуальным редактированием и правкой исходного текста Markdown; создание, копирование, переименование и изменение порядка из INDEX |
| Проверка | Проверка документов с помощью docs-lint, контроль обязательных документов, разделов и терминов по Standard Pack, создание из шаблонов |
| Перевод | Создание вариантов перевода для одной страницы или сразу для нескольких. Сохранение после проверки <!-- ai-only --> |
| Работа из AI | Инструмент спецификаций только для чтения, доступный агентам VS Code <!-- ai-only --> |

## Где можно использовать

| Среда | Назначение |
|---|---|
| Расширение VS Code | Просмотр, редактирование, проверка и перевод репозитория на вашем компьютере. Этой справке посвящена основная часть |
| Веб-версия | Просмотр документов на GitHub (открытых и закрытых), черновики на устройстве, просмотр локальной папки |
| Расширение Chromium | Открывает веб-версию во вкладке браузера |
| Браузер Lunascape | Планируется встроить ту же модель документов |

## Основные принципы

- **Исходником является Markdown.** Документы остаются файлами Markdown под управлением Git. Lunascape Docs не хранит их в преобразованном виде в другом формате.
- **Сохраняет пользователь.** Изменения записываются в файл только при нажатии [Сохранить]. Индексация и фиксация в Git автоматически не выполняются.
- **Документы обрабатываются на устройстве.** Для просмотра и редактирования документы никуда не передаются. Только при переводе заранее показываются адресат и содержимое, и отправка происходит после подтверждения.
- **Переводы размещаются в `i18n/<язык>/`.** Документы на языке по умолчанию остаются на своем месте, а переводы располагаются по тому же относительному пути в `i18n/en/` и подобных папках.
- **AI только предлагает.** Варианты перевода сохраняются после проверки различий. Документы никогда не изменяются без ведома пользователя. <!-- ai-only -->
