# Что такое Lunascape Docs

Lunascape Docs — это инструмент, который позволяет использовать документы Markdown из репозитория Git как «сайт спецификаций» без каких-либо преобразований. Предварительная сборка, сервер документации и отдельная база данных не нужны.

## Возможности

| Цель | Основные функции |
|---|---|
| Чтение | INDEX (оглавление), ссылки в тексте, цепочка навигации, переходы назад и вперед, оглавление страницы, поиск с фильтрацией |
| Просмотр | Таблицы, блоки кода, автоматическое масштабирование изображений, формулы KaTeX, схемы Mermaid, Vega-Lite, Markmap, WaveDrom и Svgbob, свернутое отображение таблиц управления документом |
| Написание | Переключение между визуальным редактированием и редактированием исходного кода Markdown; создание, копирование, переименование и изменение порядка из INDEX |
| Проверка | Проверка документов с помощью docs-lint, контроль обязательных документов, разделов и терминов на основе Standard Pack, создание из шаблонов |
| Перевод | Создание вариантов перевода для одной страницы или пакетно. Сохранение после проверки <!-- ai-only --> |
| Использование из ИИ | Инструмент спецификаций только для чтения, к которому могут обращаться агенты VS Code <!-- ai-only --> |

## Где можно использовать

| Среда | Назначение |
|---|---|
| Расширение VS Code | Просмотр, редактирование, проверка и перевод локального репозитория. Эта справка посвящена в основном ему |
| Веб-версия | Просмотр документов на GitHub (общедоступных и закрытых), черновики на устройстве, просмотр локальной папки |
| Расширение для Chromium | Открывает веб-версию во вкладке браузера |

## Основные принципы

- **Исходный документ — это Markdown.** Документы остаются файлами Markdown под управлением Git. Lunascape Docs не преобразует их в другой формат для хранения.
- **Сохраняете вы сами.** Изменения записываются в файл только тогда, когда вы нажимаете [Сохранить]. Добавление в индекс и коммиты Git автоматически не выполняются.
- **Документы обрабатываются на устройстве.** Для просмотра и редактирования документы никуда не отправляются. Только при переводе заранее показываются получатель и содержимое, а отправка выполняется после вашего подтверждения.
- **Переводы размещаются в `i18n/<язык>/`.** Документы на языке по умолчанию остаются на своих местах, а переводы размещаются по тому же относительному пути в `i18n/en/` и т. д.
- **ИИ только предлагает.** Варианты перевода сохраняются после проверки различий. Документы никогда не переписываются без вашего ведома. <!-- ai-only -->
