# Список команд

Введите «Lunascape Docs» в палитре команд (`⇧⌘P` / `Ctrl+Shift+P`), чтобы выполнить следующие команды.

| Команда | Назначение |
|---|---|
| Lunascape Docs: Открыть средство просмотра спецификаций | Открывает ближайший корень документации в средстве просмотра. Чтение, редактирование, проверка и перевод выполняются в этом окне |
| Lunascape Docs: Открыть в средстве просмотра спецификаций | Показывает в средстве просмотра файл Markdown, открытый в редакторе |
| Lunascape Docs: Создать документы из шаблона | Создаёт первый комплект документов в проекте, где нет папки с документами |
| Lunascape Docs: Проверить корень документации | Проверяет весь корень документации с помощью docs-lint и показывает результаты в разделе «Инструменты документа» и на панели «Проблемы» |
| Lunascape Docs: Открыть справку | Открывает это руководство |

## Действия в проводнике

Щёлкните правой кнопкой мыши файл `.md`, `.markdown` или `.mdx` в проводнике и выберите [Lunascape Docs: Открыть в средстве просмотра спецификаций].

> **Совет**
>
> Чтобы файлы Markdown открывались в Lunascape Docs и при обычном открытии, добавьте сопоставление редактора в параметры рабочей области.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Пошаговое руководство

Пошаговое руководство «Начало работы с Lunascape Docs» в меню [Справка] → «Добро пожаловать» в VS Code позволяет по порядку выполнить первые действия.
