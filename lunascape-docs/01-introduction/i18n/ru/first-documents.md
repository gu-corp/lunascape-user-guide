# Создание первых документов

В проекте, где еще нет папки с документацией, начальный комплект документов можно создать из палитры команд.

1. Откройте папку проекта в VS Code и сделайте рабочую область надежной.
2. В палитре команд (`⇧⌘P` / `Ctrl+Shift+P`) выполните команду «Lunascape Docs: Создать документацию из шаблона».
   Если в рабочей области несколько папок, выберите ту, в которой нужно создать документы.
3. Выберите структуру для создания.
   - [Одностраничный документ]: минимальный вариант — только `README.md`. Подходит для короткой спецификации, заметок или отдельного пояснительного документа.
   - [Комплект документации]: главная страница и входные страницы для `specification/` (спецификации), `manual/` (руководство) и `help/` (справка).
4. Введите заголовок документации. Он используется в README и в заголовках каждого документа.
5. Введите папку документации, которую нужно создать. Путь указывается относительно рабочей области, по умолчанию — `docs`.
6. Проверьте список создаваемых файлов и нажмите [Создать].
   После создания новый файл `README.md` откроется в средстве просмотра.

> **Примечание**
>
> - Существующие файлы не перезаписываются. Если хотя бы один из создаваемых файлов уже существует, ничего не создается и операция прерывается.
> - В ненадежной рабочей области создание недоступно.

> **Совет**
>
> - Если папка документации уже есть, этот порядок действий не нужен — перейдите к разделу [Основные операции](../02-reading/README.md).
> - Когда документов станет больше, добавляйте их по одному, выбирая шаблон на вкладке [Создать] в инструментах документа.
