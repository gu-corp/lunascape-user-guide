# Названия и назначение частей экрана

Экран Lunascape Docs состоит из панели инструментов сверху, INDEX слева, основного текста в центре и панели «На этой странице» справа.

## Панель инструментов

Описание слева направо.

| Название | Назначение |
|---|---|
| Имя корня документации | Имя отображаемого набора документов. Если в рабочей области несколько корней документации, становится раскрывающимся списком для переключения |
| [Открыть INDEX] (три полосы) | Отображается только при узком экране. Открывает INDEX поверх основного текста |
| [Назад] [Вперед] | Перемещение по истории просмотра |
| [Главная страница спецификации] (домик) | Открывает начальную страницу корня документации (обычно `README.md`) |
| [Родительский INDEX] (↑) | Открывает титульную страницу папки, в которой находится отображаемый документ. При временном просмотре папки становится [На папку выше] |
| [Обновить] | Перечитывает документ и INDEX |
| Цепочка навигации | Расположение отображаемого документа. Нажатие на элемент переводит на соответствующий уровень |
| Меню языков (глобус) | Показывает язык отображаемой страницы и языки, на которые можно переключиться. Здесь же находится пункт [Создать и управлять переводами…] |
| Переключение темы (солнце/луна) | Переключает между белым фоном и цветовой схемой VS Code |
| Управление колонками | По отдельности показывает или скрывает INDEX слева и «На этой странице» справа |
| [Инструменты документа] (галочка) | Открывает панели проверки документа, создания из шаблона и перевода. Здесь же отображается число результатов проверки |
| [Параметры отображения] (шестеренка) | Изменение пользовательских настроек: вид INDEX, отображение кнопки редактирования и т. п. |
| [Справка] (?) | Открывает это руководство. Пока справка открыта, справа от кнопки отображается [×] |

## INDEX (слева)

- Введите текст в поле [Фильтр документов] под заголовком, чтобы показать только совпадающие документы.
- Нажатие на папку раскрывает или закрывает ее. Если у папки есть титульная страница (`README.md`), нажатие на имя открывает эту страницу.
- Наведите указатель на элемент и нажмите появившуюся кнопку [⋯] либо щелкните правой кнопкой мыши, чтобы открыть меню действий для этого элемента.
- Кнопка [⋯] у правого края заголовка позволяет создать новый документ или папку непосредственно в корне документации.

## Основной текст (в центре)

- Если в начале документа есть таблица управления документом, она сводится в небольшую строку «Сведения о документе».
- Редактирование документа начинается с кнопки [⋯] (Другие действия) вверху справа или кнопки [Редактировать] внизу справа.
- Ссылки в тексте открываются в том же окне. Внешние URL открываются в браузере по умолчанию.

## На этой странице (справа)

Список заголовков отображаемого документа. При нажатии выполняется прокрутка к этому заголовку.
