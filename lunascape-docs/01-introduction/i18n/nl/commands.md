# Overzicht van opdrachten

Typ "Lunascape Docs" in het opdrachtenpalet (`⇧⌘P` / `Ctrl+Shift+P`) om de volgende opdrachten uit te voeren.

| Opdracht | Functie |
|---|---|
| Lunascape Docs: Specificatieviewer openen | Opent de dichtstbijzijnde documentatiehoofdmap in de viewer. Lezen, bewerken, controleren en vertalen gebeurt allemaal in dit scherm |
| Lunascape Docs: Openen in specificatieviewer | Toont het Markdown-bestand dat in de editor geopend is, in de viewer |
| Lunascape Docs: Document maken op basis van een sjabloon | Maakt een eerste set documenten in een project zonder documentenmap |
| Lunascape Docs: Documentatiehoofdmap valideren | Controleert de volledige documentatiehoofdmap met docs-lint en toont de resultaten in Documenthulpmiddelen en in het paneel "Problemen" |
| Lunascape Docs: Help openen | Opent deze helpgids |

## Vanuit de Verkenner

Klik in de Verkenner met de rechtermuisknop op een `.md`-, `.markdown`- of `.mdx`-bestand en kies [Lunascape Docs: Openen in specificatieviewer].

> **Tip**
>
> Wilt u Markdown-bestanden ook bij het gewoon openen in Lunascape Docs weergeven, voeg dan een editorkoppeling toe aan de werkruimte-instellingen.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Rondleiding

Via de rondleiding "Aan de slag met Lunascape Docs" onder het menu [Help] → "Welkom" in VS Code kunt u de eerste handelingen stap voor stap uitproberen.
