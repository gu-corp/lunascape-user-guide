# Navn og funksjoner for skjermens deler

Skjermen i Lunascape Docs består av verktøylinjen øverst, INDEX til venstre, brødteksten i midten og «På denne siden» til høyre.

## Verktøylinjen

Beskrevet fra venstre mot høyre.

| Navn | Funksjon |
|---|---|
| Dokumentrotnavn | Navnet på dokumentsettet som vises. Når arbeidsområdet har flere dokumentrøtter, blir dette en nedtrekksliste for å bytte |
| [Åpne INDEX] (tre streker) | Vises bare når skjermen er smal. Åpner INDEX som et overlegg over brødteksten |
| [Tilbake] [Fram] | Følger lesehistorikken |
| [Spesifikasjonens forside] (hus) | Åpner startsiden for dokumentroten (vanligvis `README.md`) |
| [Overordnet INDEX] (↑) | Åpner forsiden til mappen som inneholder dokumentet som vises. Når du åpner en mappe midlertidig, blir dette [Til mappen over] |
| [Last inn på nytt] | Leser inn dokumentet og INDEX på nytt |
| Brødsmuler | Plasseringen til dokumentet som vises. Trykk på et element for å gå til det nivået |
| Språkmeny (globus) | Viser språket til siden som vises, og språkene du kan bytte til. [Opprett og administrer oversettelser …] finnes også her |
| Temabytte (sol/måne) | Bytter mellom hvit bakgrunn og fargeoppsettet i VS Code |
| Kolonnevisning | Viser eller skjuler INDEX til venstre og «På denne siden» til høyre hver for seg |
| [Dokumentverktøy] (avkrysning) | Åpner panelet for dokumentkontroll, oppretting fra mal og oversettelse. Antallet kontrollresultater vises også her |
| [Visningsinnstillinger] (tannhjul) | Endrer innstillinger per bruker, som hvordan INDEX vises og om redigeringsknappen vises |
| [Hjelp] (?) | Åpner denne hjelpeveiledningen. Mens hjelpen vises, står det en [×] til høyre for den |

## INDEX (venstre)

- Skriv inn i [Filtrer dokumenter] under overskriften for bare å vise dokumenter som samsvarer.
- Trykk på en mappe for å åpne eller lukke den. En mappe med forside (`README.md`) åpner forsiden når du trykker på navnet.
- Hold musepekeren over et element for å vise [⋯], eller høyreklikk, for å åpne handlingsmenyen for elementet.
- Fra [⋯] helt til høyre i overskriften kan du opprette et nytt dokument eller en ny mappe rett under dokumentroten.

## Brødteksten (midten)

- Når det står en dokumentkontrolltabell øverst i dokumentet, samles den i en liten «Dokumentinformasjon»-rad.
- Start redigeringen fra [⋯] (flere handlinger) øverst til høyre og [Rediger] nederst til høyre.
- Lenker i brødteksten åpnes i samme visning. Eksterne URL-er åpnes i standardnettleseren din.

## På denne siden (høyre)

En liste over overskriftene i dokumentet som vises. Trykk på en for å bla til den overskriften.
