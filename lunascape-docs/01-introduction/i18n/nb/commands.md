# Kommandoliste

Skriv «Lunascape Docs» i kommandopaletten (`⇧⌘P` / `Ctrl+Shift+P`) for å kjøre følgende kommandoer.

| Kommando | Funksjon |
|---|---|
| Lunascape Docs: Åpne spesifikasjonsviser | Åpner den nærmeste dokumentroten i viseren. Lesing, redigering, kontroll og oversettelse skjer i denne visningen |
| Lunascape Docs: Åpne i spesifikasjonsviser | Viser Markdown-filen som er åpen i editoren, i viseren |
| Lunascape Docs: Opprett dokumentasjon fra mal | Oppretter et første sett med dokumenter i et prosjekt som ikke har en dokumentmappe |
| Lunascape Docs: Valider dokumentrot | Kontrollerer hele dokumentroten med docs-lint og viser resultatene i Dokumentverktøy og «Problemer»-panelet |
| Lunascape Docs: Åpne hjelp | Åpner denne hjelpeveiledningen |

## Fra utforskeren

Høyreklikk en `.md`-, `.markdown`- eller `.mdx`-fil i utforskeren, så kan du velge [Lunascape Docs: Åpne i spesifikasjonsviser].

> **Tips**
>
> For å vise Markdown-filer i Lunascape Docs også når du åpner dem på vanlig måte, legger du til en editortilknytning i arbeidsområdeinnstillingene.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Gjennomgang

I VS Code kan du prøve de første trinnene i rekkefølge fra gjennomgangen «Kom i gang med Lunascape Docs», som du finner under menyen [Hjelp] → «Velkommen».
