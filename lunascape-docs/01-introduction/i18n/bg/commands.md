# Списък с команди

Въведете „Lunascape Docs“ в палитрата с команди (`⇧⌘P` / `Ctrl+Shift+P`), за да изпълните следните команди.

| Команда | Действие |
|---|---|
| Lunascape Docs: Отваряне на визуализатора на спецификации | Отваря най-близката коренна папка на документацията във визуализатора. Четенето, редактирането, проверката и преводът се извършват в този изглед |
| Lunascape Docs: Отваряне във визуализатора на спецификации | Показва във визуализатора файла на Markdown, отворен в редактора |
| Lunascape Docs: Създаване на документ от шаблон | Създава първоначален набор от документи в проект без папка с документация |
| Lunascape Docs: Проверка на коренната папка на документацията | Проверява цялата коренна папка на документацията с docs-lint и показва резултатите в „Инструменти за документи“ и в панела „Проблеми“ |
| Lunascape Docs: Отваряне на помощта | Отваря това ръководство за помощ |

## Действия от Explorer

Щракнете с десния бутон върху файл `.md`, `.markdown` или `.mdx` в Explorer и изберете [Lunascape Docs: Отваряне във визуализатора на спецификации].

> **Съвет**
>
> За да се показват файловете на Markdown в Lunascape Docs и когато ги отваряте по обичайния начин, добавете свързване на редактора в настройките на работното пространство.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Въведение стъпка по стъпка

От въведението „Първи стъпки с Lunascape Docs“ в менюто [Помощ] → „Добре дошли“ на VS Code можете да изпробвате първите действия едно по едно.
