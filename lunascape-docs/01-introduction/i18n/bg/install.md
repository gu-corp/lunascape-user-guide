# Инсталиране на разширението

Разширението за VS Code „Lunascape Docs Pro“ се разпространява като VSIX файл. То е безплатно; „Pro“ обозначава изданието, което предава работа на AI и се обновява самó.

## Изисквания

- VS Code 1.90 или по-нова версия
- Функциите, които записват файлове — създаване на документи, подреждане на INDEX, запазване на настройки за проверка, превод — работят само в работно пространство, което сте отбелязали като надеждно във VS Code.

## Инсталиране

1. Вземете VSIX файла. Тази връзка винаги сочи към текущата версия.

   [Изтегляне на lunascape-docs-pro.vsix](https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix)

2. Отворете изгледа с разширения (`⇧⌘X` / `Ctrl+Shift+X`).
3. От менюто `…` горе вдясно изберете [Инсталиране от VSIX…] и посочете файла, който изтеглихте.

### От командния ред

Един ред, ако предпочитате да не напускате терминала. Изтегля и инсталира.

macOS / Linux:

```sh
curl -L -o /tmp/lunascape-docs-pro.vsix https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix && code --install-extension /tmp/lunascape-docs-pro.vsix
```

Windows (PowerShell):

```powershell
curl.exe -L -o "$env:TEMP\lunascape-docs-pro.vsix" https://github.com/gu-corp/lunascape-user-guide/releases/latest/download/lunascape-docs-pro.vsix; code --install-extension "$env:TEMP\lunascape-docs-pro.vsix"
```

> **Бележка**
> Ако `code` не бъде намерен, изпълнете [Команда на обвивката: Инсталиране на командата 'code' в PATH] от палитрата с команди (`⇧⌘P` / `Ctrl+Shift+P`).

## Обновяване

Когато бъде публикувана по-нова версия, разширението я изтегля и инсталира. VS Code предлага да презаредите прозореца и точно тогава започвате да я използвате. Настройките и документите ви остават непроменени.

Проверката е веднъж на ден. За да проверите веднага, изпълнете [Lunascape Docs: Проверка за по-нова версия] от палитрата с команди (`⇧⌘P` / `Ctrl+Shift+P`).

Настройката `lunascapeDocEditor.update.check` променя поведението.

| Настройка | Поведение |
|---|---|
| Инсталиране на по-нова версия, когато бъде публикувана | По подразбиране |
| Уведомяване, като решавате всеки път | Появява се известие и нищо не се променя, докато не натиснете [Обновяване] |
| Без проверка | Не се случва нищо |

### Когато обновяването е невъзможно

Съобщението „Обновяването не можа да бъде изтеглено: No Servers“ означава, че инсталираната версия е 0.22.18 или по-стара. Нейният път за обновяване се проваля на последната стъпка всеки път, така че не може сама да премине към по-нова версия. Инсталирайте я веднъж на ръка, както е описано по-горе; оттам нататък тя се обновява сама.

## Проверка на версията

Отворете „Lunascape Docs Pro“ в изгледа с разширения, за да видите инсталираната версия. Ще ви е необходима, когато докладвате проблем.
