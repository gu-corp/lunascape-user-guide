# Какво представлява Lunascape Docs

Lunascape Docs превръща Markdown документите в дадено Git хранилище в „сайт със спецификации“ такива, каквито са. Не са необходими предварително компилиране, сървър за документация или специална база данни.

## Какво можете да правите

| Цел | Основни функции |
|---|---|
| Четене | INDEX (съдържание), връзки в текста, навигационна пътека, назад и напред, съдържание на страницата, търсене с филтриране |
| Преглед | Таблици, блокове с код, автоматично побиране на изображенията, формули с KaTeX, диаграми с Mermaid, Vega-Lite, Markmap, WaveDrom и Svgbob, свито показване на таблиците за управление на документа |
| Писане | Превключване между визуално редактиране и редактиране на Markdown източника; създаване, дублиране, преименуване и пренареждане от INDEX |
| Проверка | Проверка на документа с docs-lint, проверка на задължителните документи, раздели и термини по Standard Pack, създаване от шаблон |
| Превод | Създаване на предложения за превод по една страница или наведнъж. Запазват се след преглед <!-- ai-only --> |
| Използване от AI | Инструмент за спецификации само за четене, до който агентите на VS Code имат достъп <!-- ai-only --> |

## Среди, в които може да се използва

| Среда | Предназначение |
|---|---|
| Разширение за VS Code | Разглеждане, редактиране, проверка и превод на хранилището на вашия компютър. Тази помощ е насочена към него |
| Версия за уеб браузър | Разглеждане на документи в GitHub (публични и частни), чернови на устройството, разглеждане на локална папка |
| Разширение за Chromium | Отваря версията за уеб браузър в раздел на браузъра |
| Браузър Lunascape | Предстои да вгради същия модел на документите |

## Основни принципи

- **Markdown е изходният документ.** Документите си остават Markdown файлове, управлявани с Git. Lunascape Docs не ги преобразува и не съхранява копие в друг формат.
- **Запазването се извършва от потребителя.** Редакциите се записват във файла само когато натиснете [Запазване]. Добавянето в Git и подаването никога не стават автоматично.
- **Документите се обработват на устройството.** За разглеждане и редактиране документите не се изпращат навън. Само при превод съдържанието се изпраща, след като предварително се покажат получателят и съдържанието и вие дадете съгласие.
- **Преводите се поставят в `i18n/<език>/`.** Документите на езика по подразбиране остават на мястото си, а преводите се поставят със същия относителен път в `i18n/en/` и подобни.
- **AI само предлага.** Предложенията за превод се запазват, след като прегледате разликите. Документите не се променят без ваше знание. <!-- ai-only -->
