# Какво е Lunascape Docs

Lunascape Docs е инструмент, с който Markdown документите в Git хранилище се използват направо като „сайт със спецификации“. Не са необходими предварително изграждане, сървър за документи или специална база данни.

## Какво можете да правите

| Цел | Основни функции |
|---|---|
| Четене | INDEX (съдържание), връзки в текста, навигационна пътека, назад и напред, съдържание на страницата, търсене с филтриране |
| Преглед | Таблици, кодови блокове, автоматично напасване на изображенията, формули KaTeX, диаграми Mermaid, Vega-Lite, Markmap, WaveDrom и Svgbob, сгънат изглед на таблиците за контрол на документите |
| Писане | Превключване между визуално редактиране и редактиране на изходния код в Markdown, създаване, дублиране, преименуване и пренареждане от INDEX |
| Проверка | Проверка на документите с docs-lint, проверка на задължителните документи, глави и термини по Standard Pack, създаване от шаблон |
| Превод | Генериране на предложения за превод за една страница или групово. Запазване след преглед <!-- ai-only --> |
| Използване чрез ИИ | Инструмент за спецификации само за четене, който агентите във VS Code могат да ползват <!-- ai-only --> |

## Къде може да се използва

| Среда | Предназначение |
|---|---|
| Разширение за VS Code | Преглед, редактиране, проверка и превод на хранилище на вашия компютър. Тази помощ се отнася основно за него |
| Уеб версия | Преглед на документи в GitHub (публични и частни), чернови на устройството, преглед на локална папка |
| Разширение за Chromium | Отваря уеб версията в раздел на браузъра |

## Основни принципи

- **Изходният документ е Markdown.** Документите остават Markdown файлове, управлявани в Git. Lunascape Docs не ги преобразува и не ги съхранява в друг формат.
- **Запазването го правите вие.** Промените се записват във файла само когато натиснете [Запазване]. Добавянето в индекса и създаването на къмит в Git не стават автоматично.
- **Документите се обработват на вашето устройство.** За преглед и редактиране документите не се изпращат навън. Само при превод предварително се показват получателят и съдържанието, а изпращането става след вашето одобрение.
- **Преводите се поставят в `i18n/<locale>/`.** Документите на езика по подразбиране остават на мястото си, а преводите се поставят със същия относителен път в `i18n/en/` и други подобни папки.
- **ИИ само предлага.** Предложенията за превод се запазват, след като прегледате разликите. Документите никога не се променят без ваше знание. <!-- ai-only -->
