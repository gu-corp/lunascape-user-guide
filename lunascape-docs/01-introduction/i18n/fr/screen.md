# Nom et rôle des différentes parties de l'écran

L'écran de Lunascape Docs se compose de la barre d'outils en haut, de l'INDEX à gauche, du document au centre et de « Sur cette page » à droite.

## Barre d'outils

Description de gauche à droite.

| Nom | Rôle |
|---|---|
| Nom de la racine de documentation | Nom du jeu de documents affiché. Lorsque l'espace de travail comporte plusieurs racines de documentation, il devient une liste déroulante permettant de changer de racine |
| [Ouvrir l'INDEX] (trois traits) | Affiché uniquement lorsque l'écran est étroit. Ouvre l'INDEX en surimpression sur le document |
| [Précédent] [Suivant] | Parcourent l'historique de consultation |
| [Accueil des spécifications] (maison) | Ouvre la page de démarrage de la racine de documentation (généralement `README.md`) |
| [INDEX parent] (↑) | Ouvre la page d'accueil du dossier qui contient le document affiché. Lorsqu'un dossier est ouvert temporairement, ce bouton devient [Dossier parent] |
| [Recharger] | Relit le document et l'INDEX |
| Fil d'Ariane | Emplacement du document affiché. Appuyez sur un élément pour accéder à ce niveau |
| Menu des langues (globe) | Affiche la langue de la page en cours et les langues vers lesquelles vous pouvez basculer. [Créer et gérer les traductions…] se trouve également ici |
| Changement de thème (soleil/lune) | Bascule entre le fond blanc et les couleurs de VS Code |
| Affichage des colonnes | Affiche ou masque, séparément, l'INDEX à gauche et « Sur cette page » à droite |
| [Outils de document] (coche) | Ouvre le panneau de vérification des documents, de création à partir d'un modèle et de traduction. Le nombre de résultats de vérification s'affiche également ici |
| [Paramètres d'affichage] (roue dentée) | Modifie les réglages propres à chaque utilisateur, comme l'apparence de l'INDEX ou l'affichage du bouton de modification |
| [Aide] (?) | Ouvre ce guide d'aide. Pendant l'affichage de l'aide, un [×] apparaît à sa droite |

## INDEX (à gauche)

- Saisissez du texte dans [Filtrer les documents], sous le titre, pour n'afficher que les documents correspondants.
- Appuyez sur un dossier pour l'ouvrir ou le fermer. Pour un dossier doté d'une page d'accueil (`README.md`), appuyer sur son nom ouvre cette page.
- Le [⋯] qui apparaît au survol d'un élément, ou un clic droit, ouvre le menu des actions de cet élément.
- Le [⋯] situé à l'extrémité droite du titre permet de créer un document ou un dossier directement sous la racine de documentation.

## Document (au centre)

- Lorsqu'un tableau de gestion du document figure en tête du document, il est regroupé dans une petite ligne « Informations du document ».
- Le [⋯] (autres actions) en haut à droite et le [Modifier] en bas à droite permettent de commencer à modifier le document.
- Les liens du corps du texte s'ouvrent dans le même écran. Les URL externes s'ouvrent dans le navigateur par défaut.

## Sur cette page (à droite)

Liste des titres du document affiché. Appuyez sur l'un d'eux pour faire défiler la page jusqu'à ce titre.
