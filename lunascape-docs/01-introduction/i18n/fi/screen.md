# Näytön osat ja niiden toiminnot

Lunascape Docsin näyttö koostuu ylälaidan työkalurivistä, vasemman reunan INDEX-paneelista, keskellä olevasta leipätekstistä ja oikean reunan ”Tällä sivulla” -palstasta.

## Työkalurivi

Osat vasemmalta oikealle:

| Osa | Toiminto |
|---|---|
| Dokumenttijuuren nimi | Näytettävän dokumenttijoukon nimi. Kun työtilassa on useita dokumenttijuuria, tästä tulee pudotusvalikko, josta voit vaihtaa juurta |
| [Avaa INDEX] (kolme viivaa) | Näkyy vain, kun näyttö on kapea. Avaa INDEX-paneelin leipätekstin päälle |
| [Takaisin] [Eteenpäin] | Siirtyvät selaushistoriassa |
| [Määrittelyn etusivu] (talo) | Avaa dokumenttijuuren aloitussivun (yleensä `README.md`) |
| [Ylätason INDEX] (↑) | Avaa sen kansion etusivun, jossa näytettävä dokumentti on. Kun kansio on avattu tilapäisesti, painike on [Ylempään kansioon] |
| [Lataa uudelleen] | Lukee dokumentin ja INDEX-paneelin uudelleen |
| Navigointipolku | Näytettävän dokumentin sijainti. Kun painat jotakin kohtaa, siirryt kyseiselle tasolle |
| Kielivalikko (maapallo) | Näyttää näytettävän sivun kielen ja kielet, joihin voit vaihtaa. Myös [Luo ja hallitse käännöksiä…] on täällä |
| Teeman vaihto (aurinko/kuu) | Vaihtaa valkoisen taustan ja VS Coden väriteeman välillä |
| Palstojen näyttö | Näyttää tai piilottaa erikseen vasemman INDEX-paneelin ja oikean ”Tällä sivulla” -palstan |
| [Dokumenttityökalut] (valintamerkki) | Avaa paneelin, jossa ovat dokumenttitarkistus, mallista luominen ja käännös. Myös tarkistustulosten määrä näkyy tässä |
| [Näyttöasetukset] (ratas) | Muuttaa käyttäjäkohtaisia asetuksia, kuten INDEX-paneelin ulkoasua ja muokkauspainikkeen näkymistä |
| [Ohje] (?) | Avaa tämän ohjeoppaan. Kun ohje on näkyvissä, sen oikealla puolella näkyy [×] |

## INDEX (vasemmalla)

- Kun kirjoitat otsikon alla olevaan kenttään [Rajaa dokumentteja], näkyviin jäävät vain vastaavat dokumentit.
- Kansio avautuu ja sulkeutuu painamalla sitä. Jos kansiolla on etusivu (`README.md`), sen nimen painaminen avaa etusivun.
- Kohteen toimintovalikon avaat [⋯]-painikkeesta, joka tulee näkyviin, kun viet hiiren kohteen päälle, tai napsauttamalla kohdetta hiiren oikealla painikkeella.
- Otsikon oikeassa reunassa olevasta [⋯]-painikkeesta voit luoda uuden dokumentin tai kansion suoraan dokumenttijuureen.

## Leipäteksti (keskellä)

- Kun dokumentin alussa on dokumentinhallintataulukko, se näytetään koottuna pienelle ”Dokumentin tiedot” -riville.
- Dokumentin muokkaus alkaa oikean yläkulman [⋯]-painikkeesta (muut toiminnot) ja oikean alakulman [Muokkaa]-painikkeesta.
- Leipätekstin linkit avautuvat samassa näkymässä. Ulkoiset URL-osoitteet avautuvat oletusselaimessa.

## Tällä sivulla (oikealla)

Luettelo näytettävän dokumentin otsikoista. Kun painat otsikkoa, sivu vierittyy kyseiseen kohtaan.
