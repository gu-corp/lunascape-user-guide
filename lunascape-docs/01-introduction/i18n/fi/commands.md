# Komentoluettelo

Kirjoita komentopalettiin (`⇧⌘P` / `Ctrl+Shift+P`) teksti "Lunascape Docs", niin voit suorittaa seuraavat komennot.

| Komento | Toiminto |
|---|---|
| Lunascape Docs: Avaa määrittelykatselin | Avaa lähimmän dokumenttijuuren katselimeen. Luku, muokkaus, tarkistus ja käännös tapahtuvat tässä näkymässä |
| Lunascape Docs: Avaa määrittelykatselimessa | Näyttää katselimessa sen Markdown-tiedoston, joka on auki editorissa |
| Lunascape Docs: Luo dokumentti mallista | Luo ensimmäisen dokumenttikokonaisuuden projektiin, jossa ei ole dokumenttikansiota |
| Lunascape Docs: Tarkista dokumenttijuuri | Tarkistaa koko dokumenttijuuren docs-lint-työkalulla ja näyttää tulokset Dokumenttityökaluissa ja Ongelmat-paneelissa |
| Lunascape Docs: Avaa ohje | Avaa tämän ohjeen |

## Toiminnot Resurssienhallinnasta

Napsauta Resurssienhallinnassa `.md`-, `.markdown`- tai `.mdx`-tiedostoa hiiren kakkospainikkeella, niin voit valita [Lunascape Docs: Avaa määrittelykatselimessa].

> **Vihje**
>
> Jos haluat näyttää Markdown-tiedostot Lunascape Docsissa myös silloin, kun avaat ne tavalliseen tapaan, lisää työtilan asetuksiin editorin liitos.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Esittelykierros

VS Coden [Ohje]-valikon kohdasta "Tervetuloa" löytyvän esittelykierroksen "Aloita Lunascape Docsin käyttö" avulla voit kokeilla ensimmäisiä toimintoja järjestyksessä.
