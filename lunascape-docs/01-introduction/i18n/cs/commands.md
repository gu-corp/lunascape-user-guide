# Seznam příkazů

Zadejte do palety příkazů (`⇧⌘P` / `Ctrl+Shift+P`) text „Lunascape Docs“ a můžete spustit následující příkazy.

| Příkaz | Funkce |
|---|---|
| Lunascape Docs: Otevřít prohlížeč specifikací | Otevře nejbližší kořen dokumentace v prohlížeči. Čtení, úpravy, kontrola i překlad probíhají v tomto zobrazení |
| Lunascape Docs: Otevřít v prohlížeči specifikací | Zobrazí v prohlížeči soubor Markdown otevřený v editoru |
| Lunascape Docs: Vytvořit dokument ze šablony | Vytvoří první sadu dokumentů v projektu, který nemá složku s dokumenty |
| Lunascape Docs: Ověřit kořen dokumentace | Zkontroluje celý kořen dokumentace pomocí docs-lint a zobrazí výsledky v Nástrojích dokumentu a v panelu Problémy |
| Lunascape Docs: Otevřít nápovědu | Otevře tuto příručku nápovědy |

## Ovládání z Průzkumníka

Klikněte v Průzkumníku pravým tlačítkem na soubor `.md`, `.markdown` nebo `.mdx` a zvolte [Lunascape Docs: Otevřít v prohlížeči specifikací].

> **Tip**
>
> Chcete-li soubory Markdown zobrazovat v Lunascape Docs i při běžném otevření, přidejte do nastavení pracovního prostoru přiřazení editoru.
>
> ```json
> {
>   "workbench.editorAssociations": {
>     "*.md": "lunascapeDocEditor.markdownPortal"
>   }
> }
> ```

## Průvodce

V nabídce [Nápověda] → „Vítejte“ ve VS Code najdete průvodce „Začínáme s Lunascape Docs“, s nímž si můžete postupně vyzkoušet první kroky.
