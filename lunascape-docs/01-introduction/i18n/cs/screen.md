# Názvy a funkce částí obrazovky

Obrazovka Lunascape Docs se skládá z panelu nástrojů nahoře, INDEXU vlevo, textu dokumentu uprostřed a části „Na této stránce“ vpravo.

## Panel nástrojů

Popis zleva doprava.

| Název | Funkce |
|---|---|
| Název kořene dokumentace | Název zobrazené sady dokumentů. Pokud je v pracovním prostoru více kořenů dokumentace, změní se na rozbalovací nabídku pro přepínání |
| [Otevřít INDEX] (tři čáry) | Zobrazuje se jen na úzké obrazovce. Otevře INDEX přes text dokumentu |
| [Zpět] [Vpřed] | Procházejí historii prohlížení |
| [Úvodní stránka specifikace] (domeček) | Otevře úvodní stránku kořene dokumentace (obvykle `README.md`) |
| [Nadřazený INDEX] (↑) | Otevře titulní stránku složky, v níž je zobrazený dokument. Při dočasně otevřené složce se změní na [O složku výš] |
| [Znovu načíst] | Znovu načte dokument a INDEX |
| Popis cesty | Umístění zobrazeného dokumentu. Stisknutím položky přejdete na danou úroveň |
| Nabídka jazyků (glóbus) | Zobrazuje jazyk aktuální stránky a jazyky, na které lze přepnout. Je zde i [Vytvořit a spravovat překlady…] |
| Přepínač motivu (slunce/měsíc) | Přepíná mezi bílým pozadím a barvami VS Code |
| Zobrazení sloupců | Samostatně zobrazí či skryje INDEX vlevo a „Na této stránce“ vpravo |
| [Nástroje dokumentů] (zaškrtnutí) | Otevře panel pro kontrolu dokumentů, vytváření ze šablony a překlad. Zobrazuje se zde i počet výsledků kontroly |
| [Nastavení zobrazení] (ozubené kolo) | Mění nastavení jednotlivého uživatele, například vzhled INDEXU nebo zobrazení tlačítka úprav |
| [Nápověda] (?) | Otevře tuto příručku nápovědy. Při zobrazené nápovědě se vpravo vedle ní objeví [×] |

## INDEX (vlevo)

- Když zadáte text do pole [Filtrovat dokumenty] pod nadpisem, zobrazí se jen odpovídající dokumenty.
- Stisknutím složky ji rozbalíte nebo sbalíte. U složky s titulní stránkou (`README.md`) otevře stisknutí názvu tuto titulní stránku.
- Nabídku akcí položky otevřete pomocí [⋯], které se objeví po najetí myší, nebo klepnutím pravým tlačítkem.
- Pomocí [⋯] na pravém okraji nadpisu vytvoříte nový dokument nebo složku přímo v kořeni dokumentace.

## Text dokumentu (uprostřed)

- Pokud je na začátku dokumentu tabulka správy dokumentu, zobrazí se souhrnně v malém řádku „Informace o dokumentu“.
- Úpravy dokumentu zahájíte pomocí [⋯] (další akce) vpravo nahoře nebo [Upravit] vpravo dole.
- Odkazy v textu se otevírají ve stejném zobrazení. Externí adresy URL se otevřou ve výchozím prohlížeči.

## Na této stránce (vpravo)

Seznam nadpisů zobrazeného dokumentu. Po stisknutí se posunete k danému nadpisu.
