# 画面各部の名称と働き

Lunascape Docs の画面は、上部のツールバー、左の INDEX、中央の本文、右の「このページ」で構成されています。

## ツールバー

左から順に説明します。

| 名称 | 働き |
|---|---|
| 文書ルート名 | 表示中の文書セットの名前です。ワークスペースに文書ルートが複数あるときはプルダウンになり、切り替えられます |
| [INDEXを開く]（三本線） | 画面が狭いときだけ表示されます。INDEX を本文の上に重ねて開きます |
| [戻る] [進む] | 閲覧履歴をたどります |
| [仕様書トップ]（家） | 文書ルートの開始ページ（通常は `README.md`）を開きます |
| [親INDEX]（↑） | 表示中の文書が入っているフォルダの表紙を開きます。フォルダを一時的に開いているときは [上のフォルダへ] になります |
| [再読み込み] | 文書と INDEX を読み直します |
| パンくず | 表示中の文書の場所です。各項目を押すとその階層へ移動します |
| 言語メニュー（地球儀） | 表示中のページの言語と、切り替えられる言語を表示します。[翻訳を作成・管理…] もここにあります |
| テーマ切替（太陽／月） | 白背景と VS Code の配色を切り替えます |
| カラム表示 | 左の INDEX と右の「このページ」を、それぞれ表示／非表示にします |
| [文書ツール]（チェックマーク） | 文書チェック、テンプレートからの作成、翻訳のパネルを開きます。チェック結果の件数もここに表示されます |
| [表示設定]（歯車） | INDEX の見せかたや編集ボタンの表示など、利用者ごとの設定を変更します |
| [ヘルプ]（?） | このヘルプガイドを開きます。ヘルプの表示中は右隣に [×] が表示されます |

## INDEX（左）

- 見出しの下の [文書を絞り込み] に入力すると、一致する文書だけを表示します。
- フォルダを押すと開閉します。表紙（`README.md`）のあるフォルダは、名前を押すと表紙を開きます。
- 項目にマウスを重ねると表示される [⋯]、または右クリックで、その項目の操作メニューを開きます。
- 見出しの右端の [⋯] からは、文書ルート直下に新しい文書やフォルダを作成できます。

## 本文（中央）

- 文書の先頭に文書管理表があるときは、小さな「文書情報」の行にまとめて表示します。
- 右上の [⋯]（その他の操作）と右下の [編集] から、文書の編集を始めます。
- 本文中のリンクは同じ画面内で開きます。外部の URL は既定のブラウザで開きます。

## このページ（右）

表示中の文書の見出しの一覧です。押すと、その見出しまでスクロールします。
