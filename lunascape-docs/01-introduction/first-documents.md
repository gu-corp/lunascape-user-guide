# 文書をはじめて作成する

文書フォルダがまだないプロジェクトでは、コマンドパレットから最初の文書一式を作成できます。

1. VS Code でプロジェクトのフォルダを開き、ワークスペースを信頼します。
2. コマンドパレット（`⇧⌘P` / `Ctrl+Shift+P`）で「Lunascape Docs: テンプレートからドキュメントを作成」を実行します。
   ワークスペースにフォルダが複数あるときは、作成先のワークスペースを選びます。
3. 作成する構成を選びます。
   - [1ページ文書]：`README.md` だけの最小構成です。短い仕様、メモ、単独の説明文書に向いています。
   - [ドキュメント一式]：トップページと、`specification/`（仕様書）、`manual/`（マニュアル）、`help/`（ヘルプ）の入口を作成します。
4. ドキュメントのタイトルを入力します。README と各文書の見出しに使います。
5. 作成する文書フォルダを入力します。ワークスペースからの相対パスで、既定は `docs` です。
6. 作成されるファイルの一覧を確認し、[作成] を押します。
   作成が終わると、新しい `README.md` がビューアーで開きます。

> **ご注意**
>
> - 既存のファイルは上書きしません。作成するファイルのうち 1 つでも既に存在する場合は、何も作成せずに中止します。
> - 信頼していないワークスペースでは作成できません。

> **ヒント**
>
> - 既に文書フォルダがある場合は、この手順は不要です。[基本操作](../02-reading/README.md) に進んでください。
> - 文書が増えてきたら、文書ツールの [作成] タブから、テンプレートを選んで文書を 1 つずつ追加できます。
