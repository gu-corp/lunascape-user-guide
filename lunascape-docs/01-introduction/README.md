# Lunascape Docs とは

Lunascape Docs は、Git リポジトリに置いた Markdown 文書を、そのまま「仕様書サイト」として扱うためのツールです。事前のビルド、文書サーバー、専用のデータベースは必要ありません。

## できること

| 目的 | 主な機能 |
|---|---|
| 読む | INDEX（目次）、本文リンク、パンくず、戻る・進む、ページ内目次、絞り込み検索 |
| 見る | 表、コードブロック、画像の自動フィット、KaTeX 数式、Mermaid・Vega-Lite・Markmap・WaveDrom・Svgbob の図、文書管理表の折りたたみ表示 |
| 書く | ビジュアル編集と Markdown ソース編集の切り替え、INDEX からの作成・複製・名前変更・並び替え |
| 確かめる | docs-lint による文書チェック、Standard Pack に基づく必須文書・章・用語の確認、テンプレートからの作成 |
| 翻訳する | 1 ページ単位または一括での翻訳案の生成。確認してから保存 |
| AI から使う | VS Code のエージェントが参照できる、読み取り専用の仕様ツール |

## 利用できる環境

| 環境 | 用途 |
|---|---|
| VS Code 拡張機能 | 手元のリポジトリの閲覧、編集、チェック、翻訳。このヘルプの中心です |
| Web ブラウザ版 | GitHub 上の文書（公開・非公開）の閲覧、端末内の下書き、ローカルフォルダの閲覧 |
| Chromium 拡張機能 | Web ブラウザ版をブラウザのタブで開きます |
| Lunascape ブラウザ | 同じ文書モデルを組み込む予定です |

## 基本の考えかた

- **Markdown が正本です。** 文書は Git で管理されている Markdown ファイルのままです。Lunascape Docs が別の形式に変換して保持することはありません。
- **保存は利用者が行います。** 編集した内容は、[保存] を押したときにだけファイルへ書き込みます。Git のステージングやコミットは自動では行いません。
- **文書は端末内で処理します。** 閲覧や編集のために文書を外部へ送ることはありません。翻訳のときだけ、送信先と内容を事前に表示し、承認後に送信します。
- **翻訳版は `i18n/<言語>/` に置きます。** 既定言語の文書はそのままの場所に、翻訳版は同じ相対パスで `i18n/en/` などに置きます。
- **AI は提案までです。** 翻訳案は差分を確認してから保存します。文書を黙って書き換えることはありません。
