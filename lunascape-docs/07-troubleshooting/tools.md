# チェック・作成・翻訳がうまくいかない

## チェック

### 「docs-lintを利用できません」と表示される

- 拡張機能に docs-lint の実行環境が含まれていないか、設定に問題があります。拡張機能を再インストールしてください。
- 「ローカルPackと設定を安全に読み込むには、VS Codeでこのワークスペースを信頼してください」: ローカルの Standard Pack を使うには、信頼済みワークスペースが必要です。

### 結果が「再検証が必要」のまま

文書や設定を変更すると、前回の結果は無効になります。[文書ルートを検証] をもう一度押します。保存していない変更は反映されません。

### 指摘を押しても開かない

「文書ルート全体」の項目は特定の文書に紐づかないため、位置を持ちません。指摘の内容に従って、該当する文書を確認してください。

### ルールを保存できない

- 信頼済みワークスペースが必要です。
- 「Lint設定が別の操作で変更されました」: `docs-lint.config.json` が外部で変更されています。最新の状態を読み込んでからやり直します。
- シンボリックリンクや、文書ルート外の設定ファイルは編集できません。

## テンプレートからの作成

- 「テンプレートのプレビューが期限切れです」「入力内容が変更されました」: もう一度 [プレビュー] を押してから作成します。
- 「保存先の文書は既に存在します」: 既存ファイルは上書きしません。別の保存先を指定します。
- 保存先には、文書ルートからの相対パスと `.md` / `.mdx` の拡張子が必要です。`i18n` の下には作成できません。
- 「文書を作成するにはワークスペースを信頼してください」: VS Code でワークスペースを信頼します。

## 翻訳

### 翻訳のボタンが押せない

- 「この文書ルートではAI翻訳が有効になっていません」: `lunascape-docs.json` の `translation.enabled` を `true` にします。
- 「プロジェクト既定言語が未設定です」: [表示設定を変更する](../02-reading/display-settings.md) で既定言語を保存します。
- 「対応言語に翻訳先を追加してください」: 翻訳先の言語を `locales` に加えます。
- 「翻訳する正本文書が見つかりません」: 翻訳版のページを開いています。既定言語のページに切り替えます。
- 一時的なフォルダ表示では一括翻訳を使えません。そのフォルダに `lunascape-docs.json` を置いて文書ルートにします。

### 翻訳案が拒否される・作り直しを求められる

- 「正本文書が変更されました。翻訳案を作り直してください」: 翻訳案を作ったあとに、正本または翻訳先が変わりました。もう一度翻訳します。
- 言語モデルの応答に、保護すべき識別子やコードが欠けていた場合は受理されません。応答の内容は、出力パネルの「Lunascape Docs 翻訳」で確認できます。
- 「一括翻訳は1回1000文書までです」: フォルダや明示選択で範囲を分けます。
