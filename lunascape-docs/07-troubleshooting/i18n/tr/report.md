# Bir sorunu bildirme

Çözemediğiniz bir sorunu aşağıdaki bilgilerle birlikte bildirin. Belge içeriğini veya gizli bilgileri yalnızca gerekli olduğu ölçüde paylaşın.

## Bildirime eklenecek bilgiler

| Öğe | Nasıl bulunur |
|---|---|
| Lunascape Docs sürümü | Uzantılar görünümünde "Lunascape Docs" açıldığında görünür |
| VS Code sürümü | Menüde [Yardım] → [Hakkında] |
| İşletim sistemi | macOS, Windows veya Linux ve sürümü |
| Belge kökünün yapısı | `lunascape-docs.json` içeriği, klasör yapısının özeti, Standard Pack kullanılıp kullanılmadığı |
| Yeniden oluşturma adımları | Neyi hangi sırayla yaptığınız |
| Beklenen ve gerçekleşen sonuç | Görünen iletiyi olduğu gibi, tam olarak kopyalayın |
| Çeviri sorunlarında | Çıktı panelindeki "Lunascape Docs 翻訳" içeriği |

> **İpucu**
>
> - Görüntüleme sorunlarında, Komut Paleti'ndeki "Developer: Open Webview Developer Tools" ile konsolda hata olup olmadığını görebilirsiniz.
> - Web sürümündeki sorunlarda, tarayıcının türünü ve sürümünü, ayrıca açmaya çalıştığınız URL'yi de ekleyin.
