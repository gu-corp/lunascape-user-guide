# Sorun giderme

Belirtinize uygun sayfayı bulun. Önce aşağıdaki temel adımları denemek sorunu çözebilir.

## Önce bunları deneyin

1. Araç çubuğunda [Yeniden yükle] düğmesine basın.
2. Düzenlenmekte olan bir Markdown dosyası varsa, VS Code'da kaydedin.
3. Komut paletinden "Developer: Reload Window" komutunu çalıştırın.
4. Uzantılar görünümünde Lunascape Docs'un güncel olup olmadığını denetleyin ([Uzantıyı yükleme](../01-introduction/install.md)).

| Diyagramlar, matematik veya görseller görüntülenmiyor ya da hata veriyor | [Diyagram, matematik veya görseller görüntülenmiyor](rendering.md) |

| Web sürümünde depo açılamıyor veya oturum açılamıyor | [Web sürümünde açılamıyor veya oturum açılamıyor](web.md) |
