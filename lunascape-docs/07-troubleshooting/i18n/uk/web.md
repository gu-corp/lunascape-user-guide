# Не вдається відкрити вебверсію або увійти

## Після входу репозиторій не з'являється у списку

Для цього облікового запису не встановлено GitHub App «Lunascape Docs», або потрібний репозиторій не входить до переліку. Попросіть власника репозиторію чи адміністратора організації встановити його за інструкцією [Перегляд закритого репозиторію](../06-web/private-repository.md).

## Не вдається пройти далі екрана входу

- У вас немає прав на читання цього репозиторію. Попросіть власника репозиторію надати доступ.
- «Для цього сайту не налаштовано вхід через GitHub»: у самостійно розгорнутому переглядачі не налаштовано службу входу. Її має налаштувати адміністратор.

## Не відкривається спливаюче вікно входу

Браузер блокує спливаючі вікна. Дозвольте спливаючі вікна для цього сайту та спробуйте ще раз.

## З'являється повідомлення «Сеанс входу завершено»

Термін дії входу минув. Натисніть [Увійти через GitHub] ще раз.

## Під час відкриття відкритого репозиторію виникає помилка 404

- Перевірте запис `owner/repo@ref/dir`.
- Назви гілок, що містять `/`, вказати не можна.

## Через деякий час завантаження припиняється

Без входу діє обмеження на використання GitHub API (60 звернень на годину). Якщо з'явилося повідомлення «Досягнуто обмеження кількості звернень», зачекайте деякий час або скористайтеся кнопкою [Увійти через GitHub].

## З'являється повідомлення «Цей сайт не може показати цей репозиторій»

Щоб відкривати репозиторій із самостійно розгорнутого переглядача, URL цього сайту потрібно додати до `viewer.origins` у файлі `lunascape-docs.json` у репозиторії.

## Після відкриття `index.html` нічого не відображається

Пряме відкриття через `file://` не працює. Відкрийте сторінку через HTTP-сервер або скористайтеся версією для VS Code.

## На експортованому сайті з'являється повідомлення «Не знайдено lunascape-docs-manifest.json»

Розмістіть повний набір файлів, отриманий командою `npm run export:web` (разом із маніфестом), без змін.

## Не вдається зберегти чернетку

- «Не вдається відкрити IndexedDB», «Використовується в іншій вкладці»: причина — приватний режим браузера або інша вкладка з тим самим сайтом. Відкрийте сторінку у звичайному вікні та закрийте інші вкладки.
- Чернетки зберігаються окремо для кожного пристрою та браузера. На інший пристрій вони не переносяться.
