# Документ не відображається

## З’являється повідомлення «Не знайдено Markdown або папку docs, які можна відкрити»

- У робочій області немає папки `docs`, або використовується назва, відмінна від `docs`.
  - Якщо покласти в цю папку `lunascape-docs.json`, вона розпізнаватиметься як корінь документації незалежно від назви.
  - Або додайте назву папки до параметра `lunascapeDocEditor.rootDirectoryNames`.
- Якщо документів ще немає, створіть їх командою «Lunascape Docs: Створити документ із шаблону».
- Також можна відкрити файл Markdown у редакторі та виконати команду «Lunascape Docs: Відкрити у переглядачі специфікацій».

## Документ не відображається в INDEX

- Переконайтеся, що розширення файлу — `.md`, `.markdown` або `.mdx`.
- Такі папки не відображаються: папки, назва яких починається з `.`, `node_modules`, а також папки, указані в `ignoredDirectories` (за замовчуванням `99-archive`).
- Переклади, розташовані в `i18n/`, не відображаються в INDEX окремо. Перемикайтеся на них у мовному меню.
- Якщо щойно доданий файл не відображається, натисніть [Перезавантажити].
- Можливо, ви переглядаєте інший корінь документації. Перевірте назву кореня документації ліворуч на панелі інструментів.

## Після натискання папки нічого не відображається

Файл `README.md` цієї папки — «дескриптор лише з параметрами»: у ньому є тільки front matter і немає основного тексту. Розгорніть папку в INDEX і виберіть документ усередині неї.

## Відкривається не той корінь документації

- Якщо для параметра `lunascapeDocEditor.rootMode` задано значення `fixed`, завжди відкривається `lunascapeDocEditor.root`.
- Зі значенням `auto` вибирається корінь документації, найближчий до відкритого файлу Markdown. Перемкнути його можна в розкривному списку ліворуч на панелі інструментів.

## Назва кореня документації відрізняється від очікуваної

Назва визначається в такому порядку: `title` у `lunascape-docs.json` → `navigation.title` кореневого `README.md` → його заголовок H1 → `index.md` → назва папки. Щоб зафіксувати назву, задайте `title`.

## INDEX зник

- У корені документації лише з одним документом INDEX автоматично закривається під час першого відкриття. Його можна відкрити значком стовпців на панелі інструментів. Вимкнути цю поведінку можна параметром [Автоматично приховувати, якщо документ лише один] у розділі [Параметри відображення].
- Якщо екран вузький, відкрийте його кнопкою [Відкрити INDEX] (три смуги) ліворуч від [Назад].

## Посилання не відкривається

- «Ціль посилання не знайдено»: файл, на який указує посилання, не існує. Внутрішні посилання можна перевірити командою [Перевірка] в Інструментах документа.
- «Небезпечне або непідтримуване посилання не відкрито»: посилання за межі кореня документації, а також посилання зі схемою, відмінною від `https://` чи `mailto:`, не відкриваються.

## Відображається не та мова

- У мовному меню перевірте мову поточної сторінки та підставу для її вибору.
- Раніше вибрана мова інтерфейсу запам’ятовується. Виберіть мову за замовчуванням у мовному меню ще раз.
- Якщо задано особистий параметр `lunascapeDocEditor.locale`, перевага надається перекладу цією мовою.
