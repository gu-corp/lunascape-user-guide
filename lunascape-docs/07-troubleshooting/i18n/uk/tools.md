# Перевірка, створення або переклад не працюють

## Перевірка

### Показується повідомлення «docs-lint недоступний»

- До розширення не входить середовище виконання docs-lint, або в налаштуваннях є проблема. Перевстановіть розширення.
- «Щоб безпечно завантажити локальний Pack і налаштування, позначте цю робочу область у VS Code як надійну»: щоб користуватися локальним Standard Pack, потрібна надійна робоча область.

### Результат залишається у стані «Потрібна повторна перевірка»

Після зміни документа або налаштувань попередній результат стає недійсним. Натисніть [Перевірити корінь документації] ще раз. Незбережені зміни не враховуються.

### Натискання зауваження нічого не відкриває

Пункти «Увесь корінь документації» не прив’язані до конкретного документа, тому не мають позиції. Перевірте відповідні документи згідно зі змістом зауваження.

### Не вдається зберегти правила

- Потрібна надійна робоча область.
- «Налаштування Lint змінено іншою дією»: файл `docs-lint.config.json` змінено ззовні. Завантажте найновіший стан і повторіть спробу.
- Символічні посилання та файли налаштувань за межами кореня документації редагувати не можна.

## Створення з шаблону

- «Термін дії попереднього перегляду шаблону минув», «Введені дані змінено»: натисніть [Попередній перегляд] ще раз, а потім створіть документ.
- «Документ у місці збереження вже існує»: наявні файли не перезаписуються. Укажіть інше місце збереження.
- Для місця збереження потрібні відносний шлях від кореня документації та розширення `.md` / `.mdx`. У папці `i18n` створювати документи не можна.
- «Щоб створювати документи, позначте робочу область як надійну»: позначте робочу область у VS Code як надійну.

## Переклад

### Кнопки перекладу неактивні

- «Для цього кореня документації AI-переклад не ввімкнено»: встановіть для `translation.enabled` у `lunascape-docs.json` значення `true`.
- «Мову проєкту за замовчуванням не встановлено»: збережіть мову за замовчуванням, як описано в розділі [Змінення параметрів відображення](../02-reading/display-settings.md).
- «Додайте мову перекладу до підтримуваних мов»: додайте цільову мову до `locales`.
- «Не знайдено оригіналу документа для перекладу»: відкрито сторінку перекладу. Перейдіть на сторінку мовою за замовчуванням.
- Під час тимчасового відображення папки пакетний переклад недоступний. Помістіть у цю папку `lunascape-docs.json`, щоб зробити її коренем документації.

### Пропозицію перекладу відхилено або потрібно створити її заново

- «Оригінал документа змінено. Створіть пропозицію перекладу заново»: після створення пропозиції змінився оригінал або документ перекладу. Перекладіть ще раз.
- Якщо у відповіді мовної моделі бракує ідентифікаторів або коду, які потрібно зберігати, її не буде прийнято. Вміст відповіді можна переглянути на панелі виводу «Lunascape Docs Переклад».
- «За один раз пакетний переклад обробляє не більше ніж 1000 документів»: розділіть діапазон за папками або явним вибором.
