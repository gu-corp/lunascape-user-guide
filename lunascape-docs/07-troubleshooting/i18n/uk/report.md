# Повідомлення про проблему

Якщо проблему не вдається усунути, повідомте про неї, додавши наведені нижче відомості. Вміст документів і конфіденційну інформацію надавайте лише в тому обсязі, який потрібен.

## Які відомості додати

| Пункт | Як дізнатися |
|---|---|
| Версія Lunascape Docs | Відкрийте «Lunascape Docs» у поданні розширень |
| Версія VS Code | [Довідка] → [Про програму] в меню |
| ОС | macOS, Windows або Linux та її версія |
| Будова кореня документації | Вміст `lunascape-docs.json`, загальний опис структури папок, наявність Standard Pack |
| Кроки відтворення | Що і в якому порядку ви робили |
| Очікуваний і фактичний результат | Повідомлення, яке з’явилося, наведіть повністю, як є |
| Якщо проблема з перекладом | Вміст панелі виводу «Lunascape Docs 翻訳» |

> **Порада**
>
> - Якщо проблема з відображенням, виконайте «Developer: Open Webview Developer Tools» у палітрі команд і перевірте, чи немає помилок у консолі.
> - Якщо проблема у веб-версії, додайте також назву та версію браузера й URL-адресу, яку ви намагалися відкрити.

## Куди повідомляти

Повідомте про проблему в [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
