# Діаграми, формули або зображення не відображаються

## Діаграма TikZ показується як згорнутий вихідний код

- Розповсюджувана версія розширення не містить рушія промальовування TikZ. Це нормальне відображення.
- Для розробки та оцінювання встановіть `node-tikzjax` 1.0.5 безпосередньо в корені надійної робочої області та задайте для параметра `lunascapeDocEditor.tikz.runtime` значення `workspace` — тоді діаграма промальовується.
- У версії для веббраузера TikZ не промальовується.

## Формули показуються як звичайний текст

- Перевірте роздільники. Для вбудованих формул — `$...$` або `\(...\)`, для окремих формул — `$$...$$` або `\[...\]`.
- Символ `$` усередині вбудованого коду або блоку коду формулою не стає.
- Записи, схожі на грошові суми, як-от `$5 and $10`, формулами не вважаються.
- Дуже великі формули або формули з великою кількістю розгортань макросів не промальовуються, якщо перевищують обмеження (`maxSize: 50`, `maxExpand: 1000`). Розділіть їх.

## Діаграма показує «Не вдається промалювати»

- Повідомлення про помилку від Mermaid, Vega-Lite, WaveDrom та інших вказує на проблему із синтаксисом. Перевірте вихідний код в екрані редагування за допомогою [Markdown].
- Vega-Lite: дані вбудовуйте в `data.values` або `datasets`. Дані за зовнішньою URL-адресою та позначки із зображеннями використовувати не можна.
- WaveDrom: пишіть у строгому форматі JSON. Форма JavaScript (ключі без лапок тощо) не підтримується.
- Penrose: використовуйте лише `@preset set-theory` на початку та дозволені інструкції (`Set`, `Subset`, `Disjoint`, `Intersecting`, `AutoLabel All`).
- «Створений SVG містить небезпечні посилання», «Створений SVG перевищує обмеження»: діаграми з посиланнями на зовнішні ресурси та надто великі діаграми не відображаються. Зменште вміст або приберіть посилання.

## Зображення не відображається

- Шлях до зображення задається відносно документа. Зображення за межами кореня документації не відображаються.
- Для `width` в `<img>` указуйте лише число (`width="360"`).

## На експортованому вебсайті не відображаються діаграми

Бібліотеки промальовування для TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob і Penrose завантажуються під час відображення. Розмістіть папку `vendor/` разом з експортованим сайтом.
