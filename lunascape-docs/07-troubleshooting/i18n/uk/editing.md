# Не вдається редагувати, зберегти або змінити порядок

## Немає кнопки [Редагувати]

- Параметр [Кнопка редагування] у розділі [Параметри відображення] вимкнено. Увімкніть його або скористайтеся [⋯] → [Редагувати] угорі праворуч від тексту чи меню елемента в INDEX → [Редагувати].
- Те саме стосується випадку, коли `editor.showEditButton` у `lunascape-docs.json` має значення `false`.
- Під час показу довідки редагування недоступне. Закрийте довідку.

## Не вдається перемкнутися на візуальний вигляд

«Цей документ містить синтаксис MDX, тому перемкнутися на звичайний екран редагування неможливо»: документи із синтаксисом, властивим MDX (компоненти, `import` тощо), редагуються лише у вигляді Markdown, щоб зберегти цей синтаксис.

## Не вдається редагувати формули чи діаграму безпосередньо

У візуальному вигляді показано результат відтворення. Натисніть [Markdown] на екрані редагування та відредагуйте вихідний текст.

## Не вдається змінити порядок або перетягнути

- Під час фільтрування, під час редагування документа та поки триває інша дія в INDEX, змінювати порядок не можна.
- Якщо робоча область не є надійною, дії створення, впорядкування та видалення недоступні. Зробіть робочу область надійною у VS Code.
- «INDEX оновлено. Перетягніть ще раз»: щойно застосовано іншу зміну. Повторіть дію.
- Початкову сторінку (кореневий `README.md`) перемістити не можна.

## З’являється повідомлення «Є незбережені зміни»

Потрібний файл зараз редагується в редакторі VS Code. Спершу збережіть або скасуйте зміни, а потім повторіть спробу.

## Не вдається змінити назву

Такі назви використовувати не можна.

- Назви, що починаються з `.`, `i18n`, а також зарезервовані назви Windows (`CON` тощо)
- Назви, що закінчуються крапкою або пробілом, і назви з керуючими символами чи символами, недопустимими в іменах файлів
- Назви, які вже є в тій самій папці (зокрема назви, що відрізняються лише регістром літер)
- Назви документів без розширення Markdown

## Зміни збережено, але в Git їх немає або вони не зафіксовані

Lunascape Docs лише записує файл і не виконує індексування чи фіксацію в Git. Перевірте подання системи керування версіями у VS Code та за потреби зафіксуйте зміни.
