# Якщо виникли проблеми

Знайдіть сторінку, яка відповідає вашій ситуації. Спершу спробуйте наведені нижче基本 дії — часто цього достатньо.

## Що спробувати спочатку

1. Натисніть [Перезавантажити] на панелі інструментів.
2. Якщо ви редагуєте файл Markdown, збережіть його у VS Code.
3. Виконайте «Developer: Reload Window» у палітрі команд.
4. У поданні розширень перевірте, чи Lunascape Docs оновлено до останньої версії ([Встановлення розширення](../01-introduction/install.md)).

## Пошук за симптомом

| Симптом | Сторінка |
|---|---|
| Корінь документації не знайдено, документів немає в INDEX, INDEX зник, посилання не відкриваються | [Документи не відображаються](viewer.md) |
| Діаграми, формули або зображення не відображаються чи видають помилку | [Діаграми, формули або зображення не відображаються](rendering.md) |
| Немає кнопки [Редагувати], не вдається зберегти, змінити порядок або перейменувати | [Не вдається редагувати, зберегти чи змінити порядок](editing.md) |
| Перевірка не виконується, правила не зберігаються, помилки в шаблонах або перекладі | [Перевірка, створення або переклад не працюють](tools.md) |
| У веб-версії не вдається відкрити репозиторій або увійти | [У веб-версії не вдається відкрити чи увійти](web.md) |
| Проблема не зникла | [Повідомити про помилку](report.md) |
