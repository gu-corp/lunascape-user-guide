# Segnalare un problema

Se un problema non si risolve, segnalalo allegando le informazioni seguenti. Condividi il contenuto dei documenti o le informazioni riservate solo nella misura necessaria.

## Informazioni da includere nella segnalazione

| Voce | Come verificarla |
|---|---|
| Versione di Lunascape Docs | Viene indicata aprendo «Lunascape Docs» nella vista Estensioni |
| Versione di VS Code | [Guida] → [Informazioni su] nel menu |
| Sistema operativo | macOS, Windows o Linux e la relativa versione |
| Struttura della radice della documentazione | Il contenuto di `lunascape-docs.json`, una descrizione sommaria della struttura delle cartelle, la presenza o meno di uno Standard Pack |
| Procedura per riprodurre il problema | Che cosa hai fatto e in quale ordine |
| Risultato atteso e risultato effettivo | Riporta per intero i messaggi visualizzati, così come appaiono |
| In caso di problemi di traduzione | Il contenuto del canale di output «Lunascape Docs 翻訳» |

> **Suggerimento**
>
> - Per i problemi di visualizzazione, con «Developer: Open Webview Developer Tools» nel riquadro comandi puoi verificare se la console segnala errori.
> - Per i problemi della versione Web, indica anche il browser e la sua versione e l'URL che hai provato ad aprire.

## Dove segnalare

Effettua la segnalazione in [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
