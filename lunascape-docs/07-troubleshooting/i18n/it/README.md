# Risoluzione dei problemi

Cerca la pagina corrispondente al sintomo. Prova prima le soluzioni di base indicate di seguito: spesso risolvono il problema.

## Prime cose da provare

1. Premi [Ricarica] nella barra degli strumenti.
2. Se stai modificando un file Markdown, salvalo in VS Code.
3. Nella palette dei comandi, esegui «Developer: Reload Window».
4. Nella vista delle estensioni, verifica che Lunascape Docs sia aggiornato ([Installare l'estensione](../01-introduction/install.md)).
