# समस्या की रिपोर्ट करना

जो समस्या हल न हो, उसकी रिपोर्ट निम्नलिखित जानकारी के साथ करें। दस्तावेज़ की सामग्री या गोपनीय जानकारी केवल आवश्यक सीमा तक ही साझा करें।

## रिपोर्ट में शामिल की जाने वाली जानकारी

| मद | पता करने का तरीका |
|---|---|
| Lunascape Docs का संस्करण | एक्सटेंशन व्यू में "Lunascape Docs" खोलने पर दिखाई देता है |
| VS Code का संस्करण | मेनू में [सहायता] → [के बारे में] |
| OS | macOS, Windows या Linux, और उसका संस्करण |
| दस्तावेज़ रूट की संरचना | `lunascape-docs.json` की सामग्री, फ़ोल्डर संरचना की रूपरेखा, Standard Pack है या नहीं |
| पुनरुत्पादन के चरण | आपने क्या, किस क्रम में किया |
| अपेक्षित परिणाम और वास्तविक परिणाम | दिखाई गई संदेश को पूरा, जैसा है वैसा ही |
| अनुवाद की समस्या होने पर | आउटपुट पैनल में "Lunascape Docs 翻訳" की सामग्री |

> **संकेत**
>
> - प्रदर्शन की समस्याओं में, कमांड पैलेट के "Developer: Open Webview Developer Tools" से यह देखा जा सकता है कि कंसोल में कोई त्रुटि आ रही है या नहीं।
> - Web संस्करण की समस्याओं में, ब्राउज़र का प्रकार और संस्करण तथा जिस URL को खोलने का प्रयास किया, वह भी साथ दें।
