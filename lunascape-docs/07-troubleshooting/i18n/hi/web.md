# Web संस्करण में खुल नहीं रहा · साइन इन नहीं हो रहा

## साइन इन करने पर भी रिपॉज़िटरी सूची में नहीं दिखती

उस खाते पर GitHub App «Lunascape Docs» इंस्टॉल नहीं है, या लक्षित रिपॉज़िटरी उसमें शामिल नहीं है। रिपॉज़िटरी के मालिक या संगठन के व्यवस्थापक से [निजी रिपॉज़िटरी देखें](../06-web/private-repository.md) की प्रक्रिया के अनुसार इंस्टॉल करने का अनुरोध करें।

## साइन इन स्क्रीन से आगे नहीं बढ़ पाते

- लक्षित रिपॉज़िटरी के लिए पढ़ने की अनुमति नहीं है। रिपॉज़िटरी के मालिक से अनुमति देने का अनुरोध करें।
- «इस साइट पर GitHub साइन इन कॉन्फ़िगर नहीं है»: स्वयं तैनात किए गए व्यूअर में साइन इन सेवा कॉन्फ़िगर नहीं है। व्यवस्थापक को साइन इन सेवा कॉन्फ़िगर करनी होगी।

## साइन इन के लिए पॉप-अप नहीं खुलता

ब्राउज़र पॉप-अप को रोक रहा है। इस साइट के लिए पॉप-अप की अनुमति दें और फिर से प्रयास करें।

## «आपका साइन इन समाप्त हो गया है» दिखाई देता है

साइन इन की अवधि समाप्त हो गई है। [GitHub से साइन इन करें] को फिर से दबाएँ।

## सार्वजनिक रिपॉज़िटरी खोलने पर 404 आता है

- `owner/repo@ref/dir` लेखन-रूप की जाँच करें।
- `/` वाले ब्रांच नाम निर्दिष्ट नहीं किए जा सकते।

## कुछ समय बाद लोड होना बंद हो जाता है

साइन इन किए बिना GitHub API की उपयोग सीमा (प्रति घंटा 60 बार) लागू होती है। «सीमा तक पहुँच गए» दिखाई दे, तो कुछ देर प्रतीक्षा करें या [GitHub से साइन इन करें]।

## «इस साइट से यह रिपॉज़िटरी नहीं दिखाई जा सकती» दिखाई देता है

स्वयं तैनात किए गए व्यूअर से खोलने के लिए, रिपॉज़िटरी के `lunascape-docs.json` में `viewer.origins` के अंतर्गत उस साइट का URL जोड़ना आवश्यक है।

## `index.html` खोलने पर कुछ भी नहीं दिखता

`file://` से सीधे खोलने पर यह काम नहीं करता। HTTP सर्वर के माध्यम से खोलें, या VS Code संस्करण का उपयोग करें।

## निर्यात की गई साइट पर «lunascape-docs-manifest.json नहीं मिला» दिखाई देता है

`npm run export:web` से निकली सभी फ़ाइलें (मैनिफ़ेस्ट सहित) ज्यों की त्यों तैनात करें।

## मसौदा सहेजा नहीं जा सकता

- «IndexedDB नहीं खोला जा सकता» · «दूसरे टैब में उपयोग में है»: इसका कारण ब्राउज़र का निजी मोड, या वही साइट खोले हुए कोई दूसरा टैब है। सामान्य विंडो में खोलें और अन्य टैब बंद करें।
- मसौदे प्रत्येक डिवाइस और ब्राउज़र के लिए अलग-अलग सहेजे जाते हैं। वे दूसरे डिवाइस पर नहीं जाते।
