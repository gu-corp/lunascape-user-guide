# समस्या होने पर

अपने लक्षण के अनुसार संबंधित पृष्ठ ढूँढ़ें। पहले नीचे दिए बुनियादी उपाय आज़माने से समस्या हल हो सकती है।

## सबसे पहले यह आज़माएँ

1. टूलबार में [पुनः लोड करें] दबाएँ।
2. यदि कोई Markdown फ़ाइल संपादित की जा रही है, तो उसे VS Code में सहेजें।
3. कमांड पैलेट से "Developer: Reload Window" चलाएँ।
4. एक्सटेंशन दृश्य में जाँचें कि Lunascape Docs नवीनतम संस्करण है या नहीं ([एक्सटेंशन इंस्टॉल करना](../01-introduction/install.md))।
