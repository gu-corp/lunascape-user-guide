# संपादन, सहेजना या क्रम बदलना नहीं हो पा रहा

## [संपादित करें] बटन नहीं है

- [प्रदर्शन सेटिंग्स] में [संपादन बटन] बंद है। इसे चालू करें, या दस्तावेज़ के ऊपर दाईं ओर [⋯] → [संपादित करें], अथवा INDEX के आइटम मेनू → [संपादित करें] का उपयोग करें।
- `lunascape-docs.json` में `editor.showEditButton` के `false` होने पर भी यही होता है।
- सहायता दिखाई देते समय संपादन नहीं किया जा सकता। सहायता बंद करें।

## दृश्य प्रदर्शन पर स्विच नहीं कर पा रहे

«इस दस्तावेज़ में MDX सिंटैक्स होने के कारण सामान्य संपादन स्क्रीन पर स्विच नहीं किया जा सकता»: MDX-विशिष्ट सिंटैक्स (कॉम्पोनेंट, `import` आदि) वाले दस्तावेज़ों को, उस सिंटैक्स को बनाए रखने के लिए, केवल Markdown प्रदर्शन में ही संपादित किया जाता है।

## गणितीय सूत्र या आरेख को सीधे संपादित नहीं कर पा रहे

दृश्य प्रदर्शन में रेंडर किया गया परिणाम दिखता है। संपादन स्क्रीन में [Markdown] दबाएँ और स्रोत संपादित करें।

## क्रम बदलना या खींचना नहीं हो पा रहा

- छँटाई करते समय, दस्तावेज़ का संपादन करते समय, तथा INDEX की कोई अन्य क्रिया चल रही हो, तब क्रम नहीं बदला जा सकता।
- कार्यस्थान विश्वसनीय न होने पर बनाने, व्यवस्थित करने और हटाने की क्रियाएँ उपलब्ध नहीं होतीं। VS Code में कार्यस्थान को विश्वसनीय बनाएँ।
- «INDEX अद्यतन हो गया है। कृपया फिर से खींचें»: अभी-अभी कोई अन्य परिवर्तन लागू हुआ है। क्रिया दोबारा करें।
- आरंभिक पृष्ठ (रूट का `README.md`) को स्थानांतरित नहीं किया जा सकता।

## «असहेजे गए परिवर्तन हैं» दिखाई देता है

संबंधित फ़ाइल VS Code के संपादक में संपादित की जा रही है। पहले सहेजें या परिवर्तन रद्द करें, फिर दोबारा प्रयास करें।

## नाम नहीं बदल पा रहे

निम्नलिखित नाम उपयोग नहीं किए जा सकते।

- `.` से शुरू होने वाले नाम, `i18n`, तथा Windows के आरक्षित नाम (जैसे `CON`)
- अंत में बिंदु या रिक्त स्थान वाले नाम, तथा नियंत्रण वर्ण या फ़ाइल नाम में अमान्य वर्ण वाले नाम
- उसी फ़ोल्डर में पहले से मौजूद नाम (केवल अक्षरों के छोटे-बड़े होने में भिन्न नाम भी शामिल)
- Markdown एक्सटेंशन रहित दस्तावेज़ नाम

## सहेजने के बाद भी Git में परिवर्तन नहीं दिखते या कमिट नहीं होते

Lunascape Docs केवल फ़ाइल में लिखता है; Git में स्टेजिंग या कमिट नहीं करता। VS Code के स्रोत नियंत्रण दृश्य में जाँचें और आवश्यकतानुसार कमिट करें।
