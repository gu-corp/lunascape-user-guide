# Informar de un problema

Si un problema no se resuelve, infórmelo con la siguiente información. Comparta el contenido del documento o información confidencial solo en la medida necesaria.

## Información que debe incluir

| Elemento | Cómo obtenerlo |
|---|---|
| Versión de Lunascape Docs | Se muestra al abrir «Lunascape Docs» en la vista de extensiones |
| Versión de VS Code | [Ayuda] → [Acerca de] en el menú |
| Sistema operativo | macOS, Windows o Linux, y su versión |
| Estructura de la raíz de documentación | El contenido de `lunascape-docs.json`, un resumen de la estructura de carpetas y si se usa un Standard Pack |
| Pasos para reproducirlo | Qué hizo y en qué orden |
| Resultado esperado y resultado real | Copie cualquier mensaje que aparezca, completo y tal cual |
| En caso de problemas de traducción | El contenido del canal de salida «Lunascape Docs 翻訳» |

> **Sugerencia**
>
> - Para los problemas de visualización, «Developer: Open Webview Developer Tools» en la paleta de comandos permite comprobar si la consola muestra errores.
> - Para los problemas del visor web, incluya también el navegador y su versión, y la URL que intentó abrir.

## Dónde informar

Informe en [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
