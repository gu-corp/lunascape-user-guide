# Solución de problemas

Busque la página que corresponda al síntoma. Pruebe primero las soluciones básicas siguientes; a menudo bastan para resolver el problema.

## Qué probar primero

1. Pulse [Recargar] en la barra de herramientas.
2. Si hay un archivo Markdown en edición, guárdelo en VS Code.
3. Ejecute «Developer: Reload Window» desde la paleta de comandos.
4. Compruebe en la vista de extensiones que Lunascape Docs está actualizado ([Instalar la extensión](../01-introduction/install.md)).

## Buscar por síntoma

| Síntoma | Página |
|---|---|
| No se encuentra la raíz de documentación, los documentos no aparecen en el INDEX, el INDEX desapareció, los enlaces no se abren | [Los documentos no aparecen](viewer.md) |
| Los diagramas, las fórmulas o las imágenes no se muestran o dan error | [Los diagramas, las fórmulas o las imágenes no se muestran](rendering.md) |

| El problema continúa | [Informar de un problema](report.md) |
