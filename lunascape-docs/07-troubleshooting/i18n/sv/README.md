# Om något går fel

Leta upp sidan som motsvarar ditt symtom. Prova först de grundläggande åtgärderna nedan – ofta löser det problemet.

## Prova detta först

1. Tryck på [Läs in på nytt] i verktygsfältet.
2. Om du redigerar en Markdown-fil, spara den i VS Code.
3. Kör ”Developer: Reload Window” från kommandopaletten.
4. Kontrollera i vyn Tillägg att Lunascape Docs är den senaste versionen ([Installera tillägget](../01-introduction/install.md)).

## Sök efter symtom

| Symtom | Sida |
|---|---|
| Ingen dokumentrot hittas, dokument visas inte i INDEX, INDEX har försvunnit, länkar öppnas inte | [Dokument visas inte](viewer.md) |
| Diagram, matematik eller bilder visas inte eller ger ett fel | [Diagram, matematik eller bilder visas inte](rendering.md) |
| [Redigera] saknas, det går inte att spara, sortera om eller byta namn | [Det går inte att redigera, spara eller sortera om](editing.md) |
| Kontroller kan inte köras, regler kan inte sparas, mallar eller översättning ger fel | [Kontroll, skapande eller översättning fungerar inte](tools.md) |
| Webbversionen kan inte öppna en lagringsplats eller logga in | [Det går inte att öppna eller logga in i webbversionen](web.md) |
| Problemet kvarstår | [Rapportera ett fel](report.md) |
