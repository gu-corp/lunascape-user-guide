# Rapportera ett problem

Om ett problem inte går att lösa, rapportera det tillsammans med följande information. Dela endast så mycket av dokumentens innehåll eller känsliga uppgifter som är nödvändigt.

## Information att ta med i rapporten

| Post | Så tar du reda på det |
|---|---|
| Version av Lunascape Docs | Visas när du öppnar ”Lunascape Docs” i vyn Tillägg |
| Version av VS Code | [Hjälp] → [Om] på menyn |
| Operativsystem | macOS, Windows eller Linux, och dess version |
| Dokumentrotens uppbyggnad | Innehållet i `lunascape-docs.json`, en översikt över mappstrukturen, om Standard Pack används |
| Steg för att återskapa | Vad du gjorde, och i vilken ordning |
| Förväntat och faktiskt resultat | Kopiera eventuella meddelanden i sin helhet, precis som de visas |
| Vid problem med översättning | Innehållet i utdatapanelen ”Lunascape Docs 翻訳” |

> **Tips**
>
> - Vid visningsproblem kan du med ”Developer: Open Webview Developer Tools” i kommandopaletten se om konsolen visar några fel.
> - Vid problem med webbversionen bifogar du även webbläsaren och dess version samt den URL du försökte öppna.

## Var du rapporterar

Rapportera i [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
