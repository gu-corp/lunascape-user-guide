# عند مواجهة مشكلة

ابحث عن الصفحة المناسبة انطلاقًا من العَرَض. جرّب أولًا الإجراءات الأساسية التالية، فقد تحل المشكلة.

## ما يُجرَّب أولًا

1. اضغط [إعادة تحميل] في شريط الأدوات.
2. إذا كان هناك ملف Markdown قيد التحرير، فاحفظه في VS Code.
3. نفّذ «Developer: Reload Window» من لوحة الأوامر.
4. تحقّق في عرض الإضافات من أن Lunascape Docs بأحدث إصدار ([تثبيت الإضافة](../01-introduction/install.md)).

## البحث حسب العَرَض

| العَرَض | الصفحة المرجعية |
|---|---|
| لا يُعثر على جذر التوثيق، أو لا تظهر المستندات في INDEX، أو اختفى INDEX، أو لا تُفتح الروابط | [المستندات لا تظهر](viewer.md) |
| الرسوم التخطيطية أو المعادلات أو الصور لا تظهر أو يظهر خطأ | [الرسوم التخطيطية أو المعادلات أو الصور لا تظهر](rendering.md) |
| لا يوجد زر [تحرير]، أو تعذّر الحفظ، أو تعذّرت إعادة الترتيب أو إعادة التسمية | [تعذّر التحرير أو الحفظ أو إعادة الترتيب](editing.md) |
| تعذّر تنفيذ الفحص، أو تعذّر حفظ القواعد، أو حدث خطأ في القوالب أو الترجمة | [الفحص أو الإنشاء أو الترجمة لا يعمل كما ينبغي](tools.md) |
| تعذّر فتح مستودع في نسخة الويب أو تسجيل الدخول | [تعذّر الفتح أو تسجيل الدخول في نسخة الويب](web.md) |
| المشكلة لم تُحل | [الإبلاغ عن عطل](report.md) |
