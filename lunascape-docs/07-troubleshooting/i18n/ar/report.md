# الإبلاغ عن مشكلة

إذا واجهت مشكلة لم تتمكن من حلّها، فأبلغ عنها مرفقةً بالمعلومات التالية. ولا تشارك محتوى المستندات أو المعلومات السرّية إلا بالقدر اللازم.

## المعلومات التي تُرفق بالبلاغ

| العنصر | طريقة معرفته |
|---|---|
| إصدار Lunascape Docs | يظهر عند فتح «Lunascape Docs» في عرض الامتدادات |
| إصدار VS Code | [مساعدة] ← [حول] من القائمة |
| نظام التشغيل | macOS أو Windows أو Linux، وإصداره |
| بنية جذر التوثيق | محتوى `lunascape-docs.json`، ونبذة عن بنية المجلدات، ووجود Standard Pack من عدمه |
| خطوات إعادة إظهار المشكلة | ما الذي فعلته، وبأي ترتيب |
| النتيجة المتوقَّعة والنتيجة الفعلية | انسخ أي رسالة ظهرت بنصّها الكامل كما هي |
| في حال كانت المشكلة في الترجمة | محتوى لوحة الإخراج «Lunascape Docs ترجمة» |

> **تلميح**
>
> - في مشكلات العرض، يمكنك التحقق مما إذا كانت وحدة التحكّم تُظهر أخطاءً عبر «Developer: Open Webview Developer Tools» في لوحة الأوامر.
> - في مشكلات نسخة الويب، أرفق أيضًا نوع المتصفح وإصداره وعنوان URL الذي حاولت فتحه.
