# تعذّر الفتح أو تسجيل الدخول في نسخة الويب

## سجّلتُ الدخول، لكن المستودع لا يظهر في القائمة

تطبيق GitHub App باسم «Lunascape Docs» غير مثبَّت على هذا الحساب، أو أن المستودع غير مُدرَج ضمنه. اطلب من مالك المستودع أو من مدير المؤسسة تثبيته وفق الخطوات الواردة في [قراءة مستودع خاص](../06-web/private-repository.md).

## لا يمكن تجاوز شاشة تسجيل الدخول

- ليست لديك صلاحية القراءة على المستودع المطلوب. اطلب من مالك المستودع منحك الصلاحية.
- «لم يُضبَط تسجيل الدخول عبر GitHub لهذا الموقع»: العارض الذي نشرتَه بنفسك لا تتوفّر فيه خدمة تسجيل دخول مضبوطة. يجب على المدير ضبط خدمة تسجيل الدخول.

## نافذة تسجيل الدخول المنبثقة لا تُفتح

المتصفّح يحجب النوافذ المنبثقة. اسمح بالنوافذ المنبثقة لهذا الموقع ثم أعد المحاولة.

## تظهر رسالة «انتهت صلاحية تسجيل الدخول»

انتهت مدّة صلاحية تسجيل الدخول. اضغط [تسجيل الدخول عبر GitHub] مرّة أخرى.

## يظهر الخطأ 404 عند فتح مستودع عام

- تحقّق من صيغة `owner/repo@ref/dir`.
- لا يمكن تحديد أسماء فروع تحتوي على `/`.

## يتوقّف التحميل بعد مدّة

من دون تسجيل الدخول، يسري حدّ استخدام واجهة GitHub API (‏60 طلبًا في الساعة). إذا ظهرت رسالة «بلغتَ حدّ عدد الطلبات»، فانتظر قليلًا أو [تسجيل الدخول عبر GitHub].

## تظهر رسالة «لا يمكن عرض هذا المستودع من هذا الموقع»

لفتح المستودع من عارض نشرتَه بنفسك، يجب إضافة عنوان URL الخاص بذلك الموقع إلى `viewer.origins` في ملف `lunascape-docs.json` داخل المستودع.

## لا يظهر أي شيء عند فتح `index.html`

لا يعمل الملف عند فتحه مباشرةً عبر `file://`. افتحه عبر خادم HTTP، أو استخدم نسخة VS Code.

## تظهر في الموقع المُصدَّر رسالة «تعذّر العثور على lunascape-docs-manifest.json»

انشر مجموعة الملفات الناتجة عن `npm run export:web` كاملةً (بما فيها ملف البيان) كما هي.

## تعذّر حفظ المسودة

- «تعذّر فتح IndexedDB» أو «قيد الاستخدام في علامة تبويب أخرى»: السبب هو الوضع الخاص في المتصفّح، أو وجود علامة تبويب أخرى تعرض الموقع نفسه. افتح الموقع في نافذة عادية وأغلق علامات التبويب الأخرى.
- تُحفظ المسودات لكل جهاز ومتصفّح على حدة. ولا تُنقل إلى جهاز آخر.
