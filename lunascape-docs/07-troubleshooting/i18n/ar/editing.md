# تعذّر التحرير أو الحفظ أو إعادة الترتيب

## لا يوجد زر [تحرير]

- الخيار [زر التحرير] في [إعدادات العرض] مُعطَّل. فعِّله، أو استخدم [⋯] ← [تحرير] أعلى يمين المستند، أو قائمة العنصر في INDEX ← [تحرير].
- ينطبق الأمر نفسه عندما تكون قيمة `editor.showEditButton` في `lunascape-docs.json` هي `false`.
- لا يمكن التحرير أثناء عرض المساعدة. أغلق المساعدة.

## تعذّر التبديل إلى العرض المرئي

«هذا المستند يحتوي على صياغة MDX، لذا لا يمكن التبديل إلى شاشة التحرير العادية»: المستندات التي تحتوي على صياغة خاصة بـ MDX (مكوّنات، `import` وما شابه) تُحرَّر في عرض Markdown فقط، حفاظًا على تلك الصياغة.

## تعذّر تحرير المعادلات أو الرسوم التخطيطية مباشرةً

يعرض العرض المرئي نتيجة الرسم. اضغط [Markdown] في شاشة التحرير وحرِّر المصدر.

## تعذّرت إعادة الترتيب أو السحب

- لا يمكن إعادة الترتيب أثناء التصفية، أو أثناء تحرير مستند، أو أثناء تنفيذ عملية أخرى في INDEX.
- عندما تكون مساحة العمل غير موثوقة، لا تتوفر عمليات الإنشاء والتنظيم والحذف. امنح الثقة لمساحة العمل في VS Code.
- «تم تحديث INDEX. اسحب مرة أخرى»: طُبِّق تغيير آخر للتو. كرِّر العملية.
- لا يمكن نقل صفحة البداية (ملف `README.md` في الجذر).

## تظهر رسالة «توجد تغييرات غير محفوظة»

الملف المعني قيد التحرير في محرِّر VS Code. احفظ التغييرات أو تجاهلها أولًا، ثم أعد المحاولة.

## تعذّر تغيير الاسم

لا يمكن استخدام الأسماء التالية.

- الأسماء التي تبدأ بـ `.`، والاسم `i18n`، والأسماء المحجوزة في Windows (مثل `CON`)
- الأسماء المنتهية بنقطة أو مسافة، والأسماء المحتوية على أحرف تحكم أو أحرف غير مسموح بها في أسماء الملفات
- الأسماء الموجودة بالفعل في المجلد نفسه (بما في ذلك الأسماء التي تختلف في حالة الأحرف فقط)
- أسماء المستندات التي لا تحمل امتداد Markdown

## حفظتُ التغييرات لكنها لا تظهر في Git أو لا يجري إيداعها

يكتفي Lunascape Docs بالكتابة في الملف، ولا يقوم بالتحضير (staging) أو الإيداع (commit) في Git. تحقّق من عرض التحكم بالمصدر في VS Code وأودِع التغييرات عند الحاجة.
