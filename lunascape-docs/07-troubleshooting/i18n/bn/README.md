# সমস্যা হলে

উপসর্গ দেখে সংশ্লিষ্ট পৃষ্ঠাটি খুঁজে নিন। প্রথমে নিচের প্রাথমিক পদক্ষেপগুলি চেষ্টা করলে সমস্যা মিটে যেতে পারে।

## প্রথমে যা করবেন

1. টুলবারের [পুনরায় লোড] চাপুন।
2. সম্পাদনা চলছে এমন কোনো Markdown ফাইল থাকলে VS Code-এ সেটি সংরক্ষণ করুন।
3. কমান্ড প্যালেট থেকে "Developer: Reload Window" চালান।
4. এক্সটেনশন ভিউতে দেখে নিন Lunascape Docs সর্বশেষ সংস্করণ কি না ([এক্সটেনশন ইনস্টল করা](../01-introduction/install.md))।
