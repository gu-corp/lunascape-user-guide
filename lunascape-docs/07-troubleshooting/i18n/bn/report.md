# সমস্যা প্রতিবেদন করা

যে সমস্যার সমাধান হচ্ছে না, তা নিচের তথ্যসহ জানান। নথির মূল লেখা বা গোপনীয় তথ্য কেবল প্রয়োজনীয় পরিমাণেই শেয়ার করুন।

## প্রতিবেদনে যা অন্তর্ভুক্ত করবেন

| বিষয় | যেভাবে দেখবেন |
|---|---|
| Lunascape Docs-এর সংস্করণ | এক্সটেনশন ভিউতে "Lunascape Docs" খুললে দেখা যায় |
| VS Code-এর সংস্করণ | মেনুতে [সহায়তা] → [সম্পর্কে] |
| OS | macOS, Windows বা Linux এবং তার সংস্করণ |
| ডকুমেন্টেশন রুটের গঠন | `lunascape-docs.json`-এর বিষয়বস্তু, ফোল্ডার গঠনের সারসংক্ষেপ, Standard Pack আছে কি না |
| পুনরায় ঘটানোর ধাপ | কী কাজ কোন ক্রমে করেছেন |
| প্রত্যাশিত ফল ও প্রকৃত ফল | যে বার্তা দেখা গেছে, তার পূর্ণ পাঠ হুবহু |
| অনুবাদের সমস্যা হলে | আউটপুট প্যানেলের "Lunascape Docs 翻訳"-এর বিষয়বস্তু |

> **ইঙ্গিত**
>
> - প্রদর্শনের সমস্যায় কমান্ড প্যালেটের "Developer: Open Webview Developer Tools" দিয়ে কনসোলে কোনো ত্রুটি দেখা যাচ্ছে কি না তা দেখতে পারেন।
> - ওয়েব সংস্করণের সমস্যায় ব্রাউজারের ধরন ও সংস্করণ এবং যে URL খুলতে চেয়েছিলেন তাও জানান।
