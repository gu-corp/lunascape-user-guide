# ওয়েব সংস্করণে খোলা বা সাইন ইন করা যাচ্ছে না

## সাইন ইন করার পরেও রিপোজিটরি তালিকায় দেখা যাচ্ছে না

সেই অ্যাকাউন্টে GitHub App “Lunascape Docs” ইনস্টল করা নেই, অথবা কাঙ্ক্ষিত রিপোজিটরিটি তার অন্তর্ভুক্ত নয়। রিপোজিটরির মালিক বা সংস্থার প্রশাসককে [ব্যক্তিগত রিপোজিটরি পড়া](../06-web/private-repository.md) অনুযায়ী ইনস্টল করে দিতে বলুন।

## সাইন ইন স্ক্রিন থেকে এগোনো যাচ্ছে না

- কাঙ্ক্ষিত রিপোজিটরির পড়ার অনুমতি আপনার নেই। রিপোজিটরির মালিককে অনুমতি দিতে বলুন।
- “এই সাইটে GitHub সাইন ইন কনফিগার করা নেই”: নিজে স্থাপন করা ভিউয়ারে সাইন ইন পরিষেবা কনফিগার করা নেই। প্রশাসককে সাইন ইন পরিষেবা কনফিগার করতে হবে।

## সাইন ইনের পপ-আপ খুলছে না

ব্রাউজার পপ-আপ আটকে দিচ্ছে। এই সাইটের পপ-আপ অনুমোদন করে আবার চেষ্টা করুন।

## “সাইন ইনের মেয়াদ শেষ হয়েছে” দেখাচ্ছে

সাইন ইনের মেয়াদ ফুরিয়ে গেছে। আবার [GitHub দিয়ে সাইন ইন] চাপুন।

## প্রকাশ্য রিপোজিটরি খুললে 404 আসে

- `owner/repo@ref/dir` লেখার ধরনটি যাচাই করুন।
- যে ব্রাঞ্চের নামে `/` আছে, তা উল্লেখ করা যায় না।

## কিছুক্ষণ পরে আর লোড হয় না

সাইন ইন না করা অবস্থায় GitHub API-এর ব্যবহারের সীমা (ঘণ্টায় ৬০ বার) প্রযোজ্য। “ব্যবহারের সীমা পূর্ণ হয়েছে” দেখালে কিছুক্ষণ অপেক্ষা করুন, অথবা [GitHub দিয়ে সাইন ইন] করুন।

## “এই সাইট থেকে এই রিপোজিটরি দেখানো যাবে না” দেখাচ্ছে

নিজে স্থাপন করা ভিউয়ার থেকে খুলতে হলে, রিপোজিটরির `lunascape-docs.json`-এর `viewer.origins`-এ সেই সাইটের URL যোগ করতে হবে।

## `index.html` খুললেও কিছু দেখা যাচ্ছে না

`file://` দিয়ে সরাসরি খুললে এটি কাজ করে না। HTTP সার্ভারের মাধ্যমে খুলুন, অথবা VS Code সংস্করণ ব্যবহার করুন।

## রপ্তানি করা সাইটে “lunascape-docs-manifest.json খুঁজে পাওয়া যায়নি” দেখাচ্ছে

`npm run export:web` দিয়ে তৈরি হওয়া সম্পূর্ণ ফাইলগুলো (ম্যানিফেস্টসহ) যেমন আছে তেমনই স্থাপন করুন।

## খসড়া সংরক্ষণ করা যাচ্ছে না

- “IndexedDB খোলা যাচ্ছে না”, “অন্য ট্যাবে ব্যবহৃত হচ্ছে”: এর কারণ ব্রাউজারের প্রাইভেট মোড, অথবা একই সাইট খোলা আছে এমন অন্য কোনো ট্যাব। সাধারণ উইন্ডোতে খুলুন এবং অন্য ট্যাবগুলো বন্ধ করুন।
- খসড়া প্রতিটি ডিভাইস ও ব্রাউজার অনুযায়ী সংরক্ষিত হয়। অন্য ডিভাইসে তা স্থানান্তরিত হয় না।
