# เมื่อพบปัญหา

ค้นหาหน้าที่ตรงกับอาการที่พบ ลองวิธีแก้ไขพื้นฐานต่อไปนี้ก่อน อาจแก้ปัญหาได้

## สิ่งที่ควรลองก่อน

1. กด [โหลดใหม่] ในแถบเครื่องมือ
2. หากมีไฟล์ Markdown ที่กำลังแก้ไขอยู่ ให้บันทึกไฟล์นั้นใน VS Code
3. เรียกใช้ "Developer: Reload Window" จาก Command Palette
4. ตรวจสอบในมุมมองส่วนขยายว่า Lunascape Docs เป็นเวอร์ชันล่าสุดหรือไม่ ([การติดตั้งส่วนขยาย](../01-introduction/install.md))
