# เปิดเวอร์ชันเว็บไม่ได้ หรือลงชื่อเข้าใช้ไม่ได้

## ลงชื่อเข้าใช้แล้ว แต่ไม่มีที่เก็บแสดงในรายการ

บัญชีนั้นยังไม่ได้ติดตั้ง GitHub App "Lunascape Docs" หรือที่เก็บนั้นไม่ได้รวมอยู่ในการติดตั้ง ขอให้เจ้าของที่เก็บหรือผู้ดูแลขององค์กรติดตั้งให้ ตามขั้นตอนใน [ดูที่เก็บส่วนตัว](../06-web/private-repository.md)

## ไปต่อจากหน้าลงชื่อเข้าใช้ไม่ได้

- คุณไม่มีสิทธิ์อ่านที่เก็บนั้น ขอให้เจ้าของที่เก็บให้สิทธิ์แก่คุณ
- “ไซต์นี้ยังไม่ได้ตั้งค่าการลงชื่อเข้าใช้ด้วย GitHub”: ตัวแสดงผลที่คุณติดตั้งเองยังไม่ได้ตั้งค่าบริการลงชื่อเข้าใช้ ผู้ดูแลระบบต้องตั้งค่าบริการลงชื่อเข้าใช้ก่อน

## หน้าต่างป๊อปอัปสำหรับลงชื่อเข้าใช้ไม่เปิดขึ้นมา

เบราว์เซอร์กำลังบล็อกป๊อปอัป อนุญาตป๊อปอัปของไซต์นี้ แล้วลองอีกครั้ง

## แสดงข้อความ “การลงชื่อเข้าใช้หมดอายุแล้ว”

การลงชื่อเข้าใช้หมดอายุแล้ว กด [ลงชื่อเข้าใช้ด้วย GitHub] อีกครั้ง

## เปิดที่เก็บสาธารณะแล้วได้ 404

- ตรวจสอบรูปแบบ `owner/repo@ref/dir`
- ชื่อสาขาที่มี `/` ไม่สามารถระบุได้

## ผ่านไปสักพักแล้วโหลดไม่ได้

เมื่อยังไม่ได้ลงชื่อเข้าใช้ จะมีขีดจำกัดการใช้งาน GitHub API (60 ครั้งต่อชั่วโมง) หากแสดงข้อความ “ถึงขีดจำกัดจำนวนครั้งแล้ว” ให้รอสักครู่ หรือกด [ลงชื่อเข้าใช้ด้วย GitHub]

## แสดงข้อความ “ไซต์นี้ไม่สามารถแสดงที่เก็บนี้ได้”

หากต้องการเปิดจากตัวแสดงผลที่คุณติดตั้งเอง ต้องเพิ่ม URL ของไซต์นั้นลงใน `viewer.origins` ของ `lunascape-docs.json` ในที่เก็บ

## เปิด `index.html` แล้วไม่แสดงอะไรเลย

การเปิดโดยตรงด้วย `file://` จะใช้งานไม่ได้ ให้เปิดผ่านเซิร์ฟเวอร์ HTTP หรือใช้เวอร์ชัน VS Code

## ไซต์ที่ส่งออกแสดงข้อความ “ไม่พบ lunascape-docs-manifest.json”

ให้นำไฟล์ทั้งชุดที่ได้จาก `npm run export:web` (รวมถึงไฟล์ manifest) ไปวางตามเดิมทั้งหมด

## บันทึกฉบับร่างไม่ได้

- “เปิด IndexedDB ไม่ได้” “กำลังใช้งานอยู่ในแท็บอื่น”: เกิดจากโหมดส่วนตัวของเบราว์เซอร์ หรือมีแท็บอื่นที่เปิดไซต์เดียวกันอยู่ ให้เปิดในหน้าต่างปกติ และปิดแท็บอื่น
- ฉบับร่างจะถูกบันทึกแยกตามเครื่องและตามเบราว์เซอร์ จะไม่ถูกโอนไปยังเครื่องอื่น
