# ไม่แสดงแผนภาพ สูตรคณิตศาสตร์ หรือรูปภาพ

## แผนภาพ TikZ แสดงเป็นซอร์สที่ถูกยุบไว้

- ส่วนขยายรุ่นที่แจกจ่ายไม่ได้รวมเอนจินการวาด TikZ มาด้วย นี่เป็นการแสดงผลตามปกติ
- สำหรับการพัฒนาและการประเมิน ให้ติดตั้ง `node-tikzjax` 1.0.5 ไว้ใต้รากของพื้นที่ทำงานที่เชื่อถือได้โดยตรง แล้วตั้งค่า `lunascapeDocEditor.tikz.runtime` เป็น `workspace` จึงจะวาดได้
- เว็บเบราว์เซอร์จะไม่วาด TikZ

## สูตรคณิตศาสตร์แสดงเป็นตัวอักษรธรรมดา

- ตรวจสอบเครื่องหมายคั่น แบบในบรรทัดใช้ `$...$` หรือ `\(...\)` ส่วนสูตรที่แยกบรรทัดใช้ `$$...$$` หรือ `\[...\]`
- `$` ที่อยู่ในโค้ดในบรรทัดหรือในบล็อกโค้ดจะไม่กลายเป็นสูตรคณิตศาสตร์
- ข้อความที่ดูเหมือนจำนวนเงิน เช่น `$5 and $10` จะไม่ถูกทำเป็นสูตรคณิตศาสตร์
- สูตรที่ใหญ่มากหรือมีการขยายแมโครจำนวนมาก หากเกินขีดจำกัด (`maxSize: 50`, `maxExpand: 1000`) จะไม่ถูกวาด ให้แบ่งออกเป็นส่วน ๆ

## แผนภาพขึ้นว่า "วาดไม่ได้"

- ข้อความแสดงข้อผิดพลาดของ Mermaid, Vega-Lite, WaveDrom และอื่น ๆ จะชี้ถึงปัญหาของไวยากรณ์ ให้ตรวจสอบซอร์สในหน้าจอแก้ไขด้วย [Markdown]
- Vega-Lite: ฝังข้อมูลไว้ใน `data.values` หรือ `datasets` ใช้ข้อมูลจาก URL ภายนอกและมาร์กรูปภาพไม่ได้
- WaveDrom: เขียนเป็น JSON แบบเข้มงวด ใช้รูปแบบ JavaScript (เช่น คีย์ที่ไม่มีเครื่องหมายคำพูด) ไม่ได้
- Penrose: ใช้ `@preset set-theory` ที่บรรทัดแรก และใช้เฉพาะประโยคที่อนุญาต (`Set`, `Subset`, `Disjoint`, `Intersecting`, `AutoLabel All`) เท่านั้น
- "SVG ที่สร้างขึ้นมีการอ้างอิงที่ไม่ปลอดภัย" "SVG ที่สร้างขึ้นเกินขีดจำกัด": แผนภาพที่มีการอ้างอิงทรัพยากรภายนอก หรือแผนภาพที่ใหญ่เกินไป จะไม่แสดง ให้ลดเนื้อหาลงหรือนำการอ้างอิงออก

## ไม่แสดงรูปภาพ

- ระบุเส้นทางของรูปภาพเป็นเส้นทางสัมพัทธ์จากเอกสาร รูปภาพที่อยู่นอกรากเอกสารจะไม่แสดง
- `width` ของ `<img>` ให้ระบุเป็นตัวเลขเท่านั้น (`width="360"`)

## ไม่แสดงแผนภาพในเว็บไซต์ที่ส่งออก

ไลบรารีสำหรับวาด TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob และ Penrose จะถูกโหลดเมื่อแสดงผล ให้วางโฟลเดอร์ `vendor/` ไว้พร้อมกับเว็บไซต์ที่ส่งออกด้วย
