# การรายงานปัญหา

หากพบปัญหาที่แก้ไขไม่ได้ กรุณารายงานพร้อมข้อมูลต่อไปนี้ แบ่งปันเนื้อหาของเอกสารหรือข้อมูลที่เป็นความลับเท่าที่จำเป็นเท่านั้น

## ข้อมูลที่ต้องระบุในรายงาน

| รายการ | วิธีตรวจสอบ |
|---|---|
| เวอร์ชันของ Lunascape Docs | แสดงขึ้นเมื่อเปิด "Lunascape Docs" ในมุมมองส่วนขยาย |
| เวอร์ชันของ VS Code | [วิธีใช้] → [เกี่ยวกับ] ในเมนู |
| ระบบปฏิบัติการ | macOS, Windows หรือ Linux พร้อมเวอร์ชัน |
| โครงสร้างของรากเอกสาร | เนื้อหาของ `lunascape-docs.json` ภาพรวมของโครงสร้างโฟลเดอร์ และมีการใช้ Standard Pack หรือไม่ |
| ขั้นตอนการทำซ้ำ | คุณทำอะไรบ้างตามลำดับ |
| ผลลัพธ์ที่คาดหวังและผลลัพธ์จริง | คัดลอกข้อความที่ปรากฏมาทั้งหมดตามที่แสดง |
| กรณีเป็นปัญหาเกี่ยวกับคำแปล | เนื้อหาของแผงผลลัพธ์ "Lunascape Docs 翻訳" |

> **คำแนะนำ**
>
> - สำหรับปัญหาการแสดงผล คุณสามารถใช้ "Developer: Open Webview Developer Tools" ในคอมมานด์พาเลตต์เพื่อตรวจสอบว่ามีข้อผิดพลาดในคอนโซลหรือไม่
> - สำหรับปัญหาของเวอร์ชันเว็บ กรุณาระบุชนิดและเวอร์ชันของเบราว์เซอร์ รวมทั้ง URL ที่พยายามเปิดด้วย
