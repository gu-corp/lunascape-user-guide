# การตรวจสอบ การสร้าง หรือการแปลทำงานไม่สำเร็จ

## การตรวจสอบ

### แสดงข้อความ "ไม่สามารถใช้ docs-lint ได้"

- ส่วนขยายไม่มีสภาพแวดล้อมสำหรับรัน docs-lint หรือการตั้งค่ามีปัญหา ให้ติดตั้งส่วนขยายใหม่
- "หากต้องการโหลดแพ็กในเครื่องและการตั้งค่าอย่างปลอดภัย โปรดเชื่อถือพื้นที่ทำงานนี้ใน VS Code": การใช้ Standard Pack ในเครื่องต้องใช้พื้นที่ทำงานที่เชื่อถือได้

### ผลลัพธ์ยังคงเป็น "ต้องตรวจสอบใหม่"

เมื่อแก้ไขเอกสารหรือการตั้งค่า ผลลัพธ์ครั้งก่อนจะใช้ไม่ได้ ให้กด [ตรวจสอบรากเอกสาร] อีกครั้ง การเปลี่ยนแปลงที่ยังไม่ได้บันทึกจะไม่ถูกนำมารวม

### กดที่ข้อทักท้วงแล้วไม่เปิดอะไรขึ้นมา

รายการของ "รากเอกสารทั้งหมด" ไม่ได้ผูกกับเอกสารใดเอกสารหนึ่ง จึงไม่มีตำแหน่ง ให้ตรวจสอบเอกสารที่เกี่ยวข้องตามเนื้อหาของข้อทักท้วงนั้น

### บันทึกกฎไม่ได้

- ต้องใช้พื้นที่ทำงานที่เชื่อถือได้
- "การตั้งค่า Lint ถูกเปลี่ยนโดยการดำเนินการอื่น": `docs-lint.config.json` ถูกเปลี่ยนจากภายนอก ให้โหลดสถานะล่าสุดแล้วลองใหม่
- ไฟล์การตั้งค่าที่เป็นลิงก์สัญลักษณ์ หรืออยู่นอกรากเอกสาร ไม่สามารถแก้ไขได้

## การสร้างจากเทมเพลต

- "ตัวอย่างของเทมเพลตหมดอายุแล้ว" "เนื้อหาที่กรอกถูกเปลี่ยนแปลง": ให้กด [ตัวอย่าง] อีกครั้งก่อนสร้าง
- "มีเอกสารอยู่ที่ปลายทางบันทึกแล้ว": ไฟล์ที่มีอยู่จะไม่ถูกเขียนทับ ให้ระบุปลายทางบันทึกอื่น
- ปลายทางบันทึกต้องเป็นเส้นทางสัมพัทธ์จากรากเอกสาร และมีนามสกุล `.md` / `.mdx` ไม่สามารถสร้างไว้ใต้ `i18n` ได้
- "หากต้องการสร้างเอกสาร โปรดเชื่อถือพื้นที่ทำงาน": ให้เชื่อถือพื้นที่ทำงานใน VS Code

## คำแปล

### กดปุ่มคำแปลไม่ได้

- "รากเอกสารนี้ยังไม่ได้เปิดใช้งานการแปลด้วย AI": ให้ตั้งค่า `translation.enabled` ใน `lunascape-docs.json` เป็น `true`
- "ยังไม่ได้ตั้งค่าภาษาเริ่มต้นของโปรเจกต์": ให้บันทึกภาษาเริ่มต้นตาม [การเปลี่ยนการตั้งค่าการแสดงผล](../02-reading/display-settings.md)
- "โปรดเพิ่มภาษาปลายทางลงในภาษาที่รองรับ": ให้เพิ่มภาษาปลายทางของคำแปลลงใน `locales`
- "ไม่พบเอกสารต้นฉบับที่จะแปล": ขณะนี้เปิดหน้าที่เป็นฉบับแปลอยู่ ให้สลับไปที่หน้าของภาษาเริ่มต้น
- ไม่สามารถใช้การแปลเป็นชุดขณะที่แสดงโฟลเดอร์แบบชั่วคราว ให้วาง `lunascape-docs.json` ไว้ในโฟลเดอร์นั้นเพื่อทำให้เป็นรากเอกสาร

### ข้อเสนอคำแปลถูกปฏิเสธ หรือถูกขอให้สร้างใหม่

- "เอกสารต้นฉบับถูกเปลี่ยนแปลง โปรดสร้างข้อเสนอคำแปลใหม่": ต้นฉบับหรือปลายทางเปลี่ยนไปหลังจากสร้างข้อเสนอคำแปลแล้ว ให้แปลอีกครั้ง
- หากคำตอบของโมเดลภาษาขาดตัวระบุหรือโค้ดที่ต้องคงไว้ คำตอบนั้นจะไม่ถูกยอมรับ ตรวจดูเนื้อหาของคำตอบได้ที่แผงผลลัพธ์ "Lunascape Docs 翻訳"
- "การแปลเป็นชุดรองรับได้ครั้งละไม่เกิน 1000 เอกสาร": ให้แบ่งขอบเขตตามโฟลเดอร์หรือโดยการเลือกอย่างชัดเจน
