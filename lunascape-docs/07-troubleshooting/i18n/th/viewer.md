# เอกสารไม่แสดง

## แสดงข้อความ "ไม่พบ Markdown หรือโฟลเดอร์ docs ที่เปิดได้"

- พื้นที่ทำงานไม่มีโฟลเดอร์ `docs` หรือใช้ชื่ออื่นที่ไม่ใช่ `docs`
  - หากวางไฟล์ `lunascape-docs.json` ไว้ในโฟลเดอร์นั้น ระบบจะรู้จักโฟลเดอร์นั้นเป็นรากเอกสารโดยไม่คำนึงถึงชื่อ
  - หรือเพิ่มชื่อโฟลเดอร์ลงในการตั้งค่า `lunascapeDocEditor.rootDirectoryNames`
- หากยังไม่มีเอกสาร ให้สร้างด้วย "Lunascape Docs: สร้างเอกสารจากเทมเพลต"
- อีกวิธีหนึ่งคือเปิดไฟล์ Markdown ในตัวแก้ไข แล้วเรียกใช้ "Lunascape Docs: เปิดในโปรแกรมดูข้อกำหนด"

## เอกสารไม่แสดงใน INDEX

- ตรวจสอบว่านามสกุลไฟล์เป็น `.md`, `.markdown` หรือ `.mdx`
- โฟลเดอร์ต่อไปนี้จะไม่แสดง: โฟลเดอร์ที่ขึ้นต้นด้วย `.`, `node_modules` และโฟลเดอร์ที่ระบุไว้ใน `ignoredDirectories` (ค่าเริ่มต้นคือ `99-archive`)
- คำแปลที่อยู่ใต้ `i18n/` จะไม่แสดงแยกรายการใน INDEX ให้สลับจากเมนูภาษา
- หากไฟล์ที่เพิ่งเพิ่มเข้ามาไม่แสดง ให้กด [โหลดใหม่]
- คุณอาจกำลังดูรากเอกสารอื่นอยู่ ให้ตรวจสอบชื่อรากเอกสารที่ด้านซ้ายสุดของแถบเครื่องมือ

## กดโฟลเดอร์แล้วไม่แสดงอะไรเลย

ไฟล์ `README.md` ของโฟลเดอร์นั้นเป็น "ตัวอธิบายเฉพาะการตั้งค่า" ที่มีเพียง front matter โดยไม่มีเนื้อหา ให้เปิดโฟลเดอร์ใน INDEX แล้วเลือกเอกสารที่อยู่ภายใน

## เปิดรากเอกสารที่ไม่ได้ตั้งใจ

- หากการตั้งค่า `lunascapeDocEditor.rootMode` เป็น `fixed` ระบบจะเปิด `lunascapeDocEditor.root` เสมอ
- เมื่อเป็น `auto` ระบบจะเลือกรากเอกสารที่ใกล้กับไฟล์ Markdown ที่เปิดที่สุด สลับได้จากเมนูแบบเลื่อนลงที่ด้านซ้ายสุดของแถบเครื่องมือ

## ชื่อรากเอกสารไม่ตรงกับที่คาดไว้

ชื่อจะถูกกำหนดตามลำดับ `title` ใน `lunascape-docs.json` → `navigation.title` ของ `README.md` ที่ราก → H1 ของไฟล์นั้น → `index.md` → ชื่อโฟลเดอร์ หากต้องการกำหนดตายตัว ให้ตั้งค่า `title`

## INDEX หายไป

- ในรากเอกสารที่มีเอกสารเพียงรายการเดียว INDEX จะปิดอัตโนมัติเฉพาะครั้งแรก เปิดได้จากไอคอนแสดงคอลัมน์บนแถบเครื่องมือ และปิดการทำงานนี้ได้ที่ [ซ่อนอัตโนมัติเมื่อมีเอกสารเพียงรายการเดียว] ใน [การตั้งค่าการแสดงผล]
- เมื่อหน้าจอแคบ ให้เปิดจาก [เปิด INDEX] (ขีดสามเส้น) ที่อยู่ทางซ้ายของ [ย้อนกลับ]

## กดลิงก์แล้วไม่เปิด

- "ไม่พบปลายทางของลิงก์": ไฟล์ปลายทางไม่มีอยู่ ตรวจสอบลิงก์ภายในได้ด้วย [ตรวจสอบ] ในเครื่องมือเอกสาร
- "ไม่ได้เปิดลิงก์ที่ไม่ปลอดภัยหรือไม่รองรับ": ลิงก์ที่อยู่นอกรากเอกสาร หรือลิงก์ที่ใช้สกีมอื่นนอกเหนือจาก `https://` และ `mailto:` จะไม่เปิด

## ภาษาที่แสดงไม่ตรงกับที่ตั้งใจ

- ตรวจสอบภาษาของหน้าที่กำลังแสดงและเหตุผลที่เลือกภาษานั้นได้จากเมนูภาษา
- ระบบจะจดจำภาษาที่แสดงที่คุณเลือกไว้ครั้งก่อน ให้เลือกภาษาเริ่มต้นใหม่จากเมนูภาษา
- หากตั้งค่าส่วนบุคคล `lunascapeDocEditor.locale` ไว้ ระบบจะให้ความสำคัญกับคำแปลของภาษานั้นก่อน
