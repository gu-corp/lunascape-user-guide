# แก้ไข บันทึก หรือจัดลำดับใหม่ไม่ได้

## ไม่มีปุ่ม [แก้ไข]

- [ปุ่มแก้ไข] ใน [การตั้งค่าการแสดงผล] ปิดอยู่ ให้เปิดใช้งาน หรือใช้ [⋯] → [แก้ไข] ที่มุมขวาบนของเนื้อหา หรือเมนูรายการใน INDEX → [แก้ไข]
- กรณีที่ `editor.showEditButton` ใน `lunascape-docs.json` เป็น `false` ก็เช่นเดียวกัน
- ขณะที่แสดงวิธีใช้อยู่จะแก้ไขไม่ได้ ให้ปิดวิธีใช้ก่อน

## สลับไปยังมุมมองภาพไม่ได้

「この文書にはMDX構文があるため通常の編集画面へ切り替えられません」 (เอกสารนี้มีไวยากรณ์ MDX จึงสลับไปยังหน้าจอแก้ไขปกติไม่ได้): เอกสารที่มีไวยากรณ์เฉพาะของ MDX (คอมโพเนนต์, `import` เป็นต้น) จะแก้ไขได้เฉพาะในมุมมอง Markdown เท่านั้น เพื่อรักษาไวยากรณ์นั้นไว้

## แก้ไขสูตรคณิตศาสตร์หรือแผนภาพโดยตรงไม่ได้

มุมมองภาพจะแสดงผลลัพธ์ที่วาดแล้ว ให้กด [Markdown] ในหน้าจอแก้ไข แล้วแก้ไขที่ต้นฉบับ

## จัดลำดับใหม่หรือลากไม่ได้

- ขณะกรองรายการ ขณะแก้ไขเอกสาร และขณะที่การดำเนินการอื่นของ INDEX กำลังทำงานอยู่ จะจัดลำดับใหม่ไม่ได้
- เมื่อไม่ได้เชื่อถือพื้นที่ทำงาน จะใช้การสร้าง การจัดระเบียบ และการลบไม่ได้ ให้เชื่อถือพื้นที่ทำงานใน VS Code
- 「INDEXが更新されています。もう一度ドラッグしてください」 (INDEX ได้รับการอัปเดตแล้ว กรุณาลากอีกครั้ง): เป็นช่วงที่เพิ่งมีการเปลี่ยนแปลงอื่นถูกนำมาใช้ ให้ทำอีกครั้ง
- หน้าเริ่มต้น (`README.md` ที่ราก) ย้ายไม่ได้

## มีข้อความ 「未保存の変更があります」 (มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก) แสดงขึ้น

ไฟล์ที่ต้องการกำลังถูกแก้ไขอยู่ในตัวแก้ไขของ VS Code ให้บันทึกหรือละทิ้งการเปลี่ยนแปลงก่อน แล้วลองใหม่อีกครั้ง

## เปลี่ยนชื่อไม่ได้

ชื่อต่อไปนี้ใช้ไม่ได้

- ชื่อที่ขึ้นต้นด้วย `.`, `i18n` และชื่อสงวนของ Windows (เช่น `CON`)
- ชื่อที่ลงท้ายด้วยจุดหรือช่องว่าง และชื่อที่มีอักขระควบคุมหรืออักขระที่ใช้ในชื่อไฟล์ไม่ได้
- ชื่อที่มีอยู่แล้วในโฟลเดอร์เดียวกัน (รวมถึงชื่อที่ต่างกันเพียงตัวพิมพ์ใหญ่เล็ก)
- ชื่อเอกสารที่ไม่มีนามสกุลของ Markdown

## บันทึกแล้วแต่ไม่มีการเปลี่ยนแปลงใน Git หรือไม่ถูกคอมมิต

Lunascape Docs เพียงเขียนลงไฟล์เท่านั้น ไม่ได้ทำการ stage หรือคอมมิตใน Git ให้ตรวจสอบที่มุมมอง Source Control ของ VS Code แล้วคอมมิตตามที่ต้องการ
