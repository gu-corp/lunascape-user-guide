# Signaler un problème

Si un problème persiste, signalez-le en joignant les informations suivantes. Ne partagez le contenu des documents ou des informations confidentielles que dans la mesure nécessaire.

## Informations à inclure

| Élément | Comment le trouver |
|---|---|
| Version de Lunascape Docs | Ouvrez « Lunascape Docs » dans la vue Extensions |
| Version de VS Code | [Aide] → [À propos] dans le menu |
| Système d'exploitation | macOS, Windows ou Linux, et sa version |
| Structure de la racine de documentation | Le contenu de `lunascape-docs.json`, un aperçu de l'arborescence des dossiers, la présence ou non d'un Standard Pack |
| Étapes de reproduction | Ce que vous avez fait, dans l'ordre |
| Résultat attendu et résultat obtenu | Recopiez tout message intégralement, tel qu'il s'affiche |
| En cas de problème de traduction | Le contenu du canal de sortie « Lunascape Docs 翻訳 » |

> **Conseil**
>
> - Pour les problèmes d'affichage, la commande « Developer: Open Webview Developer Tools » de la palette de commandes permet de vérifier si la console signale des erreurs.
> - Pour les problèmes de la version Web, joignez également le navigateur et sa version, ainsi que l'URL que vous tentiez d'ouvrir.

## Où signaler

Signalez le problème dans les [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
