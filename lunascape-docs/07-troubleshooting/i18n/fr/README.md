# En cas de problème

Recherchez la page correspondant à votre symptôme. Essayez d'abord les solutions de base ci-dessous : elles suffisent souvent à résoudre le problème.

## À essayer en premier

1. Appuyez sur [Recharger] dans la barre d'outils.
2. Si un fichier Markdown est en cours de modification, enregistrez-le dans VS Code.
3. Exécutez « Developer: Reload Window » depuis la palette de commandes.
4. Dans la vue Extensions, vérifiez que Lunascape Docs est à jour ([Installer l'extension](../01-introduction/install.md)).
