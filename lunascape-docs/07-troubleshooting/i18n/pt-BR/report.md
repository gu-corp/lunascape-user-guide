# Relatar um problema

Para um problema que você não consegue resolver, faça o relato com as informações a seguir. Compartilhe o conteúdo do documento ou informações confidenciais apenas na medida do necessário.

## Informações a incluir no relato

| Item | Como verificar |
|---|---|
| Versão do Lunascape Docs | Abra "Lunascape Docs" na visualização de extensões |
| Versão do VS Code | [Ajuda] → [Sobre] no menu |
| Sistema operacional | macOS, Windows ou Linux, e sua versão |
| Estrutura da raiz da documentação | O conteúdo de `lunascape-docs.json`, um resumo da estrutura de pastas, se há um Standard Pack |
| Etapas para reproduzir | O que você fez e em que ordem |
| Resultado esperado e resultado obtido | Copie qualquer mensagem exibida na íntegra, como aparece |
| No caso de problemas de tradução | O conteúdo do canal de saída "Lunascape Docs 翻訳" |

> **Dica**
>
> - Em problemas de exibição, "Developer: Open Webview Developer Tools" na paleta de comandos mostra se há erros no console.
> - Em problemas da versão Web, informe também o navegador e sua versão e a URL que você tentou abrir.

## Onde relatar

Relate em [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
