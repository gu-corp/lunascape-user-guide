# Solução de problemas

Procure a página correspondente ao sintoma. Experimente primeiro as medidas básicas a seguir; às vezes isso já resolve.

## O que tentar primeiro

1. Pressione [Recarregar] na barra de ferramentas.
2. Se houver um arquivo Markdown em edição, salve-o no VS Code.
3. Execute "Developer: Reload Window" na paleta de comandos.
4. Na visão de extensões, verifique se o Lunascape Docs está na versão mais recente ([Instalar a extensão](../01-introduction/install.md)).

## Procurar pelo sintoma

| Sintoma | Página de referência |
|---|---|
| A raiz da documentação não é encontrada, os documentos não aparecem no INDEX, o INDEX desapareceu, os links não abrem | [Os documentos não aparecem](viewer.md) |
| Diagramas, fórmulas matemáticas ou imagens não aparecem ou apresentam erro | [Diagramas, fórmulas matemáticas ou imagens não aparecem](rendering.md) |
| Não há [Editar], não é possível salvar, reordenar ou renomear | [Não é possível editar, salvar ou reordenar](editing.md) |
| As verificações não são executadas, não é possível salvar regras, os modelos ou a tradução apresentam erro | [A verificação, a criação ou a tradução não funcionam](tools.md) |
| Não é possível abrir um repositório nem entrar na versão Web | [Não é possível abrir nem entrar na versão Web](web.md) |
| O problema continua | [Relatar um problema](report.md) |
