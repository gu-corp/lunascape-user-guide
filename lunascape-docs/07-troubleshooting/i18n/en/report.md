# Reporting a problem

For a problem you cannot resolve, report it with the following information. Share document content or confidential information only as far as necessary.

## What to include

| Item | How to find it |
|---|---|
| Lunascape Docs version | Open "Lunascape Docs" in the Extensions view |
| VS Code version | [Help] → [About] in the menu |
| OS | macOS, Windows or Linux, and its version |
| Layout of the documentation root | The content of `lunascape-docs.json`, an outline of the folder structure, whether a Standard Pack is used |
| Steps to reproduce | What you did, in order |
| Expected and actual results | Copy any message in full, as shown |
| For translation problems | The content of the "Lunascape Docs 翻訳" output channel |

> **Hint**
>
> - For display problems, "Developer: Open Webview Developer Tools" in the Command Palette shows whether the console reports errors.
> - For Web viewer problems, include the browser and its version and the URL you tried to open.

## Where to report

Open an issue in the [issue tracker](https://github.com/gu-corp/lunascape-user-guide/issues).
