# Troubleshooting

Find the page for your symptom. Trying the basic steps below first often resolves the problem.

## Try these first

1. Press [再読み込み] (Reload) in the toolbar.
2. If a Markdown file is being edited, save it in VS Code.
3. Run "Developer: Reload Window" from the Command Palette.
4. Check in the Extensions view that Lunascape Docs is up to date (see [Installing the extension](../01-introduction/install.md)).
