# Ongelman ilmoittaminen

Jos ongelma ei ratkea, ilmoita siitä ja liitä mukaan seuraavat tiedot. Jaa dokumentin sisältöä tai luottamuksellisia tietoja vain siinä laajuudessa kuin on tarpeen.

## Ilmoitukseen liitettävät tiedot

| Kohta | Mistä sen löytää |
|---|---|
| Lunascape Docsin versio | Avaa Laajennukset-näkymässä ”Lunascape Docs” |
| VS Coden versio | Valikosta [Ohje] → [Tietoja] |
| Käyttöjärjestelmä | macOS, Windows tai Linux ja sen versio |
| Dokumenttijuuren rakenne | Tiedoston `lunascape-docs.json` sisältö, yleiskuva kansiorakenteesta, käytetäänkö Standard Packia |
| Toistamisvaiheet | Mitä teit ja missä järjestyksessä |
| Odotettu ja todellinen tulos | Kopioi näytetty viesti kokonaisuudessaan sellaisenaan |
| Käännösongelmissa | Tulostepaneelin kanavan ”Lunascape Docs 翻訳” sisältö |

> **Vinkki**
>
> - Näyttöön liittyvissä ongelmissa komentopaletin ”Developer: Open Webview Developer Tools” näyttää, ilmoittaako konsoli virheitä.
> - Web-katselimen ongelmissa liitä mukaan myös selain ja sen versio sekä URL-osoite, jonka yritit avata.
