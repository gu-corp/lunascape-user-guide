# Ongelmatilanteet

Etsi oireeseesi sopiva sivu. Kokeile ensin seuraavia perustoimia — usein ne ratkaisevat ongelman.

## Kokeile ensin näitä

1. Paina työkalurivin [Lataa uudelleen] -painiketta.
2. Jos jokin Markdown-tiedosto on muokattavana, tallenna se VS Codessa.
3. Suorita komentopaletista ”Developer: Reload Window”.
4. Tarkista laajennusnäkymästä, että Lunascape Docs on ajan tasalla ([Laajennuksen asentaminen](../01-introduction/install.md)).

## Etsi oireen mukaan

| Oire | Sivu |
|---|---|
| Dokumenttijuurta ei löydy, dokumentit eivät näy INDEX-paneelissa, INDEX katosi, linkit eivät avaudu | [Dokumentit eivät näy](viewer.md) |
| Kaaviot, matematiikka tai kuvat eivät näy tai antavat virheen | [Kaaviot, matematiikka tai kuvat eivät näy](rendering.md) |
| [Muokkaa]-painiketta ei ole, tallentaminen ei onnistu, järjestäminen tai uudelleennimeäminen ei onnistu | [Muokkaaminen, tallentaminen tai järjestäminen ei onnistu](editing.md) |
| Tarkistukset eivät käynnisty, sääntöjä ei voi tallentaa, mallit tai käännös antavat virheen | [Tarkistus, luonti tai käännös ei onnistu](tools.md) |
| Web-katselin ei avaa säilöä tai kirjautuminen ei onnistu | [Web-katselin ei avaudu tai kirjautuminen ei onnistu](web.md) |
| Ongelma ei ratkea | [Vian ilmoittaminen](report.md) |
