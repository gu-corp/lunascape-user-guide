# Když si nevíte rady

Najděte stránku odpovídající vašemu problému. Nejprve vyzkoušejte základní kroky níže — často problém vyřeší.

## Co zkusit nejdříve

1. Na panelu nástrojů stiskněte [Znovu načíst].
2. Pokud upravujete soubor Markdown, uložte jej ve VS Code.
3. V paletě příkazů spusťte „Developer: Reload Window“.
4. V zobrazení rozšíření ověřte, že je Lunascape Docs aktuální ([Instalace rozšíření](../01-introduction/install.md)).
