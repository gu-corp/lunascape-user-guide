# Nahlášení problému

Pokud problém nedokážete vyřešit, nahlaste jej s následujícími informacemi. Obsah dokumentů nebo důvěrné informace sdílejte jen v nezbytném rozsahu.

## Co uvést v hlášení

| Položka | Jak ji zjistíte |
|---|---|
| Verze Lunascape Docs | Otevřete „Lunascape Docs“ v zobrazení rozšíření |
| Verze VS Code | [Nápověda] → [O aplikaci] v nabídce |
| Operační systém | macOS, Windows nebo Linux a jeho verze |
| Uspořádání kořene dokumentace | Obsah souboru `lunascape-docs.json`, přehled struktury složek, zda se používá Standard Pack |
| Postup pro zopakování | Co jste dělali a v jakém pořadí |
| Očekávaný a skutečný výsledek | Zobrazenou zprávu uveďte celou a přesně |
| U problémů s překladem | Obsah výstupního kanálu „Lunascape Docs 翻訳“ |

> **Tip**
>
> - U problémů se zobrazením můžete pomocí příkazu „Developer: Open Webview Developer Tools“ v paletě příkazů ověřit, zda konzole hlásí chyby.
> - U problémů s webovým prohlížečem dokumentů přiložte také typ a verzi prohlížeče a URL, kterou jste chtěli otevřít.

## Kam problém nahlásit

Nahlaste jej v [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
