# Αντιμετώπιση προβλημάτων

Βρείτε τη σελίδα που αντιστοιχεί στο σύμπτωμά σας. Δοκιμάστε πρώτα τα παρακάτω βασικά βήματα — συχνά λύνουν το πρόβλημα.

## Δοκιμάστε πρώτα αυτά

1. Πατήστε [Επαναφόρτωση] στη γραμμή εργαλείων.
2. Αν επεξεργάζεστε κάποιο αρχείο Markdown, αποθηκεύστε το στο VS Code.
3. Εκτελέστε την εντολή «Developer: Reload Window» από την παλέτα εντολών.
4. Ελέγξτε στην προβολή επεκτάσεων ότι το Lunascape Docs είναι ενημερωμένο ([Εγκατάσταση της επέκτασης](../01-introduction/install.md)).

## Αναζήτηση με βάση το σύμπτωμα

| Σύμπτωμα | Σελίδα |
|---|---|
| Δεν βρίσκεται ρίζα τεκμηρίωσης, τα έγγραφα δεν εμφανίζονται στο INDEX, το INDEX εξαφανίστηκε, οι σύνδεσμοι δεν ανοίγουν | [Τα έγγραφα δεν εμφανίζονται](viewer.md) |
| Διαγράμματα, μαθηματικά ή εικόνες δεν εμφανίζονται ή παρουσιάζουν σφάλμα | [Διαγράμματα, μαθηματικά ή εικόνες δεν εμφανίζονται](rendering.md) |
| Δεν υπάρχει το [Επεξεργασία], δεν γίνεται αποθήκευση, δεν γίνεται αλλαγή σειράς ή μετονομασία | [Δεν γίνεται επεξεργασία, αποθήκευση ή αλλαγή σειράς](editing.md) |
| Ο έλεγχος δεν εκτελείται, οι κανόνες δεν αποθηκεύονται, τα πρότυπα ή η μετάφραση παρουσιάζουν σφάλμα | [Ο έλεγχος, η δημιουργία ή η μετάφραση δεν λειτουργεί](tools.md) |
| Η έκδοση Web δεν ανοίγει αποθετήριο ή δεν γίνεται σύνδεση | [Η έκδοση Web δεν ανοίγει ή δεν γίνεται σύνδεση](web.md) |
| Το πρόβλημα παραμένει | [Αναφορά προβλήματος](report.md) |
