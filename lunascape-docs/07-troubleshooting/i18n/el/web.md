# Η έκδοση Web δεν ανοίγει ή δεν γίνεται σύνδεση

## Συνδεθήκατε, αλλά το αποθετήριο δεν εμφανίζεται στη λίστα

Το GitHub App «Lunascape Docs» δεν είναι εγκατεστημένο σε αυτόν τον λογαριασμό ή το αποθετήριο δεν περιλαμβάνεται σε αυτό. Ζητήστε από τον κάτοχο του αποθετηρίου ή από τον διαχειριστή του οργανισμού να το εγκαταστήσει, σύμφωνα με τα βήματα στο [Ανάγνωση ιδιωτικού αποθετηρίου](../06-web/private-repository.md).

## Δεν γίνεται μετάβαση πέρα από την οθόνη σύνδεσης

- Δεν έχετε δικαίωμα ανάγνωσης στο συγκεκριμένο αποθετήριο. Ζητήστε από τον κάτοχο του αποθετηρίου να σας το παραχωρήσει.
- «Δεν έχει ρυθμιστεί σύνδεση με GitHub για αυτόν τον ιστότοπο»: σε πρόγραμμα προβολής που έχετε εγκαταστήσει μόνοι σας δεν έχει ρυθμιστεί υπηρεσία σύνδεσης. Ο διαχειριστής πρέπει να ρυθμίσει την υπηρεσία σύνδεσης.

## Δεν ανοίγει το αναδυόμενο παράθυρο σύνδεσης

Το πρόγραμμα περιήγησης αποκλείει τα αναδυόμενα παράθυρα. Επιτρέψτε τα αναδυόμενα παράθυρα για αυτόν τον ιστότοπο και δοκιμάστε ξανά.

## Εμφανίζεται «Η σύνδεσή σας έληξε»

Η διάρκεια ισχύος της σύνδεσης έληξε. Πατήστε ξανά [Σύνδεση με GitHub].

## Ένα δημόσιο αποθετήριο επιστρέφει 404

- Ελέγξτε τη γραφή `owner/repo@ref/dir`.
- Δεν μπορείτε να ορίσετε ονόματα κλάδων που περιέχουν `/`.

## Μετά από λίγο σταματά η φόρτωση

Χωρίς σύνδεση ισχύει το όριο χρήσης του GitHub API (60 φορές ανά ώρα). Όταν εμφανιστεί «Συμπληρώθηκε το όριο κλήσεων», περιμένετε λίγο ή πατήστε [Σύνδεση με GitHub].

## Εμφανίζεται «Αυτός ο ιστότοπος δεν μπορεί να εμφανίσει αυτό το αποθετήριο»

Για να το ανοίξετε από πρόγραμμα προβολής που έχετε εγκαταστήσει μόνοι σας, πρέπει να προσθέσετε τη διεύθυνση URL του ιστότοπου στο `viewer.origins` του `lunascape-docs.json` του αποθετηρίου.

## Ανοίγετε το `index.html`, αλλά δεν εμφανίζεται τίποτα

Δεν λειτουργεί αν το ανοίξετε απευθείας με `file://`. Ανοίξτε το μέσω διακομιστή HTTP ή χρησιμοποιήστε την έκδοση για VS Code.

## Στον ιστότοπο που εξαγάγατε εμφανίζεται «Δεν βρέθηκε το lunascape-docs-manifest.json»

Τοποθετήστε ως έχει όλο το σύνολο των αρχείων που παράγει η `npm run export:web`, μαζί με το manifest.

## Δεν αποθηκεύεται το πρόχειρο

- «Δεν είναι δυνατό το άνοιγμα της IndexedDB», «Χρησιμοποιείται από άλλη καρτέλα»: η αιτία είναι η ιδιωτική περιήγηση του προγράμματος περιήγησης ή μια άλλη καρτέλα με τον ίδιο ιστότοπο ανοιχτό. Ανοίξτε τον σε κανονικό παράθυρο και κλείστε τις άλλες καρτέλες.
- Τα πρόχειρα αποθηκεύονται ανά συσκευή και ανά πρόγραμμα περιήγησης. Δεν μεταφέρονται σε άλλη συσκευή.
