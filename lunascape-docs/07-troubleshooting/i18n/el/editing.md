# Δεν είναι δυνατή η επεξεργασία, η αποθήκευση ή η αλλαγή σειράς

## Δεν υπάρχει το κουμπί [Επεξεργασία]

- Το [Κουμπί επεξεργασίας] στις [Ρυθμίσεις προβολής] είναι απενεργοποιημένο. Ενεργοποιήστε το ή χρησιμοποιήστε το [⋯] → [Επεξεργασία] επάνω δεξιά στο κείμενο ή το μενού στοιχείου του INDEX → [Επεξεργασία].
- Το ίδιο ισχύει όταν η ρύθμιση `editor.showEditButton` στο `lunascape-docs.json` έχει την τιμή `false`.
- Όσο εμφανίζεται η Βοήθεια, δεν είναι δυνατή η επεξεργασία. Κλείστε τη Βοήθεια.

## Δεν είναι δυνατή η εναλλαγή στην οπτική προβολή

«Αυτό το έγγραφο περιέχει σύνταξη MDX, επομένως δεν είναι δυνατή η εναλλαγή στην κανονική οθόνη επεξεργασίας»: τα έγγραφα που περιέχουν σύνταξη ειδική για MDX (στοιχεία, `import` και άλλα) υποβάλλονται σε επεξεργασία μόνο στην προβολή Markdown, ώστε να διατηρηθεί η σύνταξη.

## Δεν είναι δυνατή η απευθείας επεξεργασία μαθηματικών ή διαγράμματος

Η οπτική προβολή εμφανίζει το αποτέλεσμα της απόδοσης. Πατήστε [Markdown] στην οθόνη επεξεργασίας και επεξεργαστείτε τον πηγαίο κώδικα.

## Δεν είναι δυνατή η αλλαγή σειράς ή η μεταφορά με σύρσιμο

- Η αλλαγή σειράς δεν είναι δυνατή κατά το φιλτράρισμα, κατά την επεξεργασία εγγράφου και όσο εκτελείται άλλη ενέργεια του INDEX.
- Όταν ο χώρος εργασίας δεν είναι αξιόπιστος, οι ενέργειες δημιουργίας, οργάνωσης και διαγραφής δεν είναι διαθέσιμες. Ορίστε τον χώρο εργασίας ως αξιόπιστο στο VS Code.
- «Το INDEX έχει ενημερωθεί. Σύρετε ξανά»: μόλις εφαρμόστηκε μια άλλη αλλαγή. Επαναλάβετε την ενέργεια.
- Η αρχική σελίδα (το `README.md` της ρίζας) δεν μπορεί να μετακινηθεί.

## Εμφανίζεται το μήνυμα «Υπάρχουν μη αποθηκευμένες αλλαγές»

Το συγκεκριμένο αρχείο βρίσκεται υπό επεξεργασία στο πρόγραμμα επεξεργασίας του VS Code. Αποθηκεύστε πρώτα ή απορρίψτε τις αλλαγές και δοκιμάστε ξανά.

## Δεν είναι δυνατή η αλλαγή ονόματος

Τα παρακάτω ονόματα δεν μπορούν να χρησιμοποιηθούν.

- Ονόματα που αρχίζουν με `.`, το `i18n` και τα δεσμευμένα ονόματα των Windows (`CON` και άλλα)
- Ονόματα που τελειώνουν σε τελεία ή κενό διάστημα και ονόματα που περιέχουν χαρακτήρες ελέγχου ή χαρακτήρες που δεν επιτρέπονται σε ονόματα αρχείων
- Ονόματα που υπάρχουν ήδη στον ίδιο φάκελο (συμπεριλαμβανομένων ονομάτων που διαφέρουν μόνο σε πεζά και κεφαλαία)
- Ονόματα εγγράφων χωρίς επέκταση Markdown

## Αποθήκευσα, αλλά οι αλλαγές δεν εμφανίζονται στο Git ή δεν υποβάλλονται

Το Lunascape Docs απλώς γράφει στο αρχείο· δεν εκτελεί staging ούτε υποβολή στο Git. Ελέγξτε την προβολή ελέγχου πηγαίου κώδικα στο VS Code και υποβάλετε τις αλλαγές, εφόσον χρειάζεται.
