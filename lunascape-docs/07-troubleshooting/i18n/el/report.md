# Αναφορά προβλήματος

Για ένα πρόβλημα που δεν μπορείτε να λύσετε, στείλτε μια αναφορά με τις παρακάτω πληροφορίες. Κοινοποιήστε το περιεχόμενο των εγγράφων ή εμπιστευτικές πληροφορίες μόνο στον βαθμό που είναι απαραίτητο.

## Τι να περιλάβετε στην αναφορά

| Στοιχείο | Πώς το βρίσκετε |
|---|---|
| Έκδοση του Lunascape Docs | Εμφανίζεται όταν ανοίξετε το «Lunascape Docs» στην προβολή επεκτάσεων |
| Έκδοση του VS Code | [Βοήθεια] → [Σχετικά] στο μενού |
| Λειτουργικό σύστημα | macOS, Windows ή Linux και η έκδοσή του |
| Δομή της ρίζας τεκμηρίωσης | Το περιεχόμενο του `lunascape-docs.json`, μια περίληψη της δομής των φακέλων, αν χρησιμοποιείται Standard Pack |
| Βήματα αναπαραγωγής | Τι κάνατε και με ποια σειρά |
| Αναμενόμενο και πραγματικό αποτέλεσμα | Αντιγράψτε ολόκληρο το μήνυμα που εμφανίστηκε, όπως ακριβώς είναι |
| Για προβλήματα μετάφρασης | Το περιεχόμενο του καναλιού εξόδου «Lunascape Docs 翻訳» |

> **Συμβουλή**
>
> - Για προβλήματα εμφάνισης, με την εντολή «Developer: Open Webview Developer Tools» στην παλέτα εντολών μπορείτε να δείτε αν η κονσόλα αναφέρει σφάλματα.
> - Για προβλήματα της έκδοσης Web, αναφέρετε επίσης το πρόγραμμα περιήγησης και την έκδοσή του, καθώς και τη διεύθυνση URL που προσπαθήσατε να ανοίξετε.
