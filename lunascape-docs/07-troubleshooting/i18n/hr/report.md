# Prijava problema

Problem koji ne možete riješiti prijavite uz sljedeće informacije. Sadržaj dokumenta i povjerljive informacije dijelite samo u nužnom opsegu.

## Informacije koje treba priložiti

| Stavka | Kako je provjeriti |
|---|---|
| Verzija programa Lunascape Docs | Prikazuje se kada u prikazu proširenja otvorite „Lunascape Docs” |
| Verzija programa VS Code | [Pomoć] → [O programu] u izborniku |
| Operacijski sustav | macOS, Windows ili Linux i njegova verzija |
| Sastav korijena dokumentacije | Sadržaj datoteke `lunascape-docs.json`, pregled strukture mapa, koristi li se Standard Pack |
| Koraci za ponavljanje problema | Što ste učinili i kojim redoslijedom |
| Očekivani i stvarni rezultat | Poruku koja se pojavila prenesite u cijelosti, onako kako je prikazana |
| Kod problema s prijevodom | Sadržaj kanala „Lunascape Docs 翻訳” na ploči izlaza |

> **Savjet**
>
> - Kod problema s prikazom naredbom „Developer: Open Webview Developer Tools” u paleti naredbi možete provjeriti javlja li konzola pogreške.
> - Kod problema s web-preglednikom dokumenata priložite i vrstu i verziju preglednika te URL koji ste pokušali otvoriti.

## Kamo prijaviti

Prijavite problem u [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
