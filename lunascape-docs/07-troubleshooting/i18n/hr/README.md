# Ako naiđete na problem

Pronađite stranicu koja odgovara vašem simptomu. Najprije isprobajte osnovne korake u nastavku — često riješe problem.

## Što prvo isprobati

1. Na alatnoj traci pritisnite [Ponovno učitaj].
2. Ako uređujete Markdown datoteku, spremite je u VS Code.
3. U paleti naredbi pokrenite „Developer: Reload Window".
4. U prikazu proširenja provjerite je li Lunascape Docs najnovije verzije ([Instaliranje proširenja](../01-introduction/install.md)).

## Traženje prema simptomu

| Simptom | Stranica |
|---|---|
| Korijen dokumentacije nije pronađen, dokumenti se ne pojavljuju u INDEX-u, INDEX je nestao, poveznice se ne otvaraju | [Dokumenti se ne prikazuju](viewer.md) |
| Dijagrami, matematički izrazi ili slike se ne prikazuju ili javljaju pogrešku | [Dijagrami, matematički izrazi ili slike se ne prikazuju](rendering.md) |
| Nema gumba [Uredi], spremanje nije moguće, promjena redoslijeda ili naziva nije moguća | [Uređivanje, spremanje ili promjena redoslijeda nije moguća](editing.md) |
| Provjera se ne pokreće, pravila se ne mogu spremiti, predložak ili prijevod javljaju pogrešku | [Provjera, izrada ili prijevod ne uspijevaju](tools.md) |
| Web-preglednik ne može otvoriti repozitorij ili se prijaviti | [Web-preglednik se ne otvara ili prijava ne uspijeva](web.md) |
| Problem i dalje postoji | [Prijava problema](report.md) |
