# Depanare

Căutați pagina care corespunde simptomului. Încercați mai întâi pașii de bază de mai jos; adesea problema se rezolvă astfel.

## Ce să încercați mai întâi

1. Apăsați [Reîncarcă] din bara de instrumente.
2. Dacă editați un fișier Markdown, salvați-l în VS Code.
3. Executați „Developer: Reload Window” din paleta de comenzi.
4. Verificați în vizualizarea Extensii dacă Lunascape Docs este la zi ([Instalarea extensiei](../01-introduction/install.md)).

## Căutare după simptom

| Simptom | Pagina de referință |
|---|---|
| Nu se găsește nicio rădăcină a documentației, documentele nu apar în INDEX, INDEX a dispărut, legăturile nu se deschid | [Documentele nu apar](viewer.md) |
| Diagramele, formulele matematice sau imaginile nu se afișează ori generează o eroare | [Diagramele, formulele matematice sau imaginile nu se afișează](rendering.md) |
| Lipsește [Editează], nu se poate salva, nu se poate reordona sau redenumi | [Nu se poate edita, salva sau reordona](editing.md) |
| Verificările nu se execută, regulile nu pot fi salvate, șabloanele sau traducerea dau eroare | [Verificarea, crearea sau traducerea nu funcționează](tools.md) |
| Versiunea Web nu poate deschide depozitul sau nu permite conectarea | [Versiunea Web nu se deschide sau nu permite conectarea](web.md) |
