# Raportarea unei probleme

Pentru o problemă pe care nu o puteți rezolva, raportați-o împreună cu următoarele informații. Partajați conținutul documentelor sau informațiile confidențiale doar în măsura în care este necesar.

## Informații de inclus în raport

| Element | Cum se verifică |
|---|---|
| Versiunea Lunascape Docs | Se afișează când deschideți „Lunascape Docs” în vizualizarea Extensii |
| Versiunea VS Code | [Ajutor] → [Despre] din meniu |
| Sistemul de operare | macOS, Windows sau Linux și versiunea acestuia |
| Structura rădăcinii documentației | Conținutul fișierului `lunascape-docs.json`, o prezentare a structurii de foldere, dacă se folosește un Standard Pack |
| Pașii de reproducere | Ce ați făcut și în ce ordine |
| Rezultatul așteptat și cel obținut | Copiați integral orice mesaj afișat, așa cum apare |
| În cazul problemelor de traducere | Conținutul canalului de ieșire „Lunascape Docs 翻訳” |

> **Sfat**
>
> - Pentru problemele de afișare, comanda „Developer: Open Webview Developer Tools” din paleta de comenzi arată dacă în consolă apar erori.
> - Pentru problemele versiunii Web, adăugați și browserul cu versiunea sa, precum și adresa URL pe care ați încercat să o deschideți.

## Unde se raportează

Deschideți o problemă în [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
