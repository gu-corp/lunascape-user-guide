# Saat mengalami masalah

Cari halaman yang sesuai dengan gejala yang Anda alami. Cobalah penanganan dasar berikut terlebih dahulu, karena sering kali masalah langsung teratasi.

## Yang perlu dicoba lebih dahulu

1. Tekan [Muat ulang] pada bilah alat.
2. Jika ada berkas Markdown yang sedang diedit, simpan di VS Code.
3. Jalankan "Developer: Reload Window" dari Command Palette.
4. Pada tampilan Extensions, periksa apakah Lunascape Docs sudah versi terbaru ([Memasang ekstensi](../01-introduction/install.md)).

## Cari berdasarkan gejala

| Gejala | Halaman rujukan |
|---|---|
| Root dokumentasi tidak ditemukan, dokumen tidak muncul di INDEX, INDEX hilang, tautan tidak terbuka | [Dokumen tidak tampil](viewer.md) |
| Diagram, rumus, atau gambar tidak tampil atau menimbulkan galat | [Diagram, rumus, atau gambar tidak tampil](rendering.md) |
| Tidak ada [Edit], tidak bisa menyimpan, tidak bisa mengubah urutan atau nama | [Tidak bisa mengedit, menyimpan, atau mengubah urutan](editing.md) |
| Pemeriksaan tidak bisa dijalankan, aturan tidak bisa disimpan, templat atau terjemahan menimbulkan galat | [Pemeriksaan, pembuatan, atau terjemahan tidak berjalan baik](tools.md) |
| Tidak bisa membuka repositori atau masuk di versi Web | [Tidak bisa membuka atau masuk di versi Web](web.md) |
| Masalah belum teratasi | [Melaporkan masalah](report.md) |
