# Melaporkan masalah

Untuk masalah yang tidak dapat Anda selesaikan, laporkan dengan menyertakan informasi berikut. Bagikan isi dokumen atau informasi rahasia hanya seperlunya.

## Informasi yang disertakan dalam laporan

| Item | Cara memeriksa |
|---|---|
| Versi Lunascape Docs | Ditampilkan saat Anda membuka "Lunascape Docs" di tampilan Extensions |
| Versi VS Code | [Bantuan] → [Tentang] pada menu |
| OS | macOS, Windows, atau Linux, beserta versinya |
| Susunan root dokumentasi | Isi `lunascape-docs.json`, ringkasan struktur folder, ada atau tidaknya Standard Pack |
| Langkah reproduksi | Apa yang Anda lakukan dan dalam urutan apa |
| Hasil yang diharapkan dan hasil sebenarnya | Salin pesan yang muncul secara utuh, apa adanya |
| Untuk masalah terjemahan | Isi panel keluaran "Lunascape Docs 翻訳" |

> **Petunjuk**
>
> - Untuk masalah tampilan, "Developer: Open Webview Developer Tools" di Command Palette memperlihatkan apakah ada kesalahan di konsol.
> - Untuk masalah pada versi Web, sertakan juga jenis dan versi peramban serta URL yang ingin Anda buka.

## Tempat melapor

Laporkan di [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
