# לא ניתן לפתוח בגרסת הדפדפן או להתחבר

## התחברתי, אבל המאגר אינו מופיע ברשימה

אפליקציית GitHub בשם "Lunascape Docs" אינה מותקנת בחשבון הזה, או שהמאגר אינו נכלל בה. בקשו מבעל המאגר או ממנהל הארגון להתקין אותה לפי ההוראות שב[עיון במאגר פרטי](../06-web/private-repository.md).

## לא ניתן להתקדם ממסך ההתחברות

- אין לכם הרשאת קריאה למאגר. בקשו מבעל המאגר להעניק לכם הרשאה.
- "התחברות עם GitHub אינה מוגדרת באתר הזה": במציג שהצבתם בעצמכם לא הוגדר שירות התחברות. מנהל המערכת צריך להגדיר שירות התחברות.

## חלון ההתחברות הקופץ אינו נפתח

הדפדפן חוסם את החלון הקופץ. אפשרו חלונות קופצים באתר הזה ונסו שוב.

## מוצגת ההודעה "ההתחברות פגה"

תוקף ההתחברות פג. לחצו שוב על [כניסה עם GitHub].

## פתיחת מאגר ציבורי מחזירה 404

- בדקו את הכתיב `owner/repo@ref/dir`.
- לא ניתן לציין שם ענף שמכיל `/`.

## אחרי זמן מה הטעינה מפסיקה לפעול

כשאינכם מחוברים חלה מגבלת שימוש ב‑API של GitHub (60 קריאות בשעה). אם מוצגת ההודעה "הגעתם למגבלת מספר הפעמים", המתינו מעט או התחברו באמצעות [כניסה עם GitHub].

## מוצגת ההודעה "לא ניתן להציג את המאגר הזה מהאתר הזה"

כדי לפתוח את המאגר ממציג שהצבתם בעצמכם, יש להוסיף את כתובת ה‑URL של האתר אל `viewer.origins` בקובץ `lunascape-docs.json` שבמאגר.

## פתיחת `index.html` אינה מציגה דבר

פתיחה ישירה דרך `file://` אינה פועלת. פתחו את הקובץ דרך שרת HTTP, או השתמשו בגרסת VS Code.

## באתר שייצאתם מוצגת ההודעה "lunascape-docs-manifest.json לא נמצא"

הציבו כמות שהוא את מערך הקבצים המלא שהופק באמצעות `npm run export:web`, כולל קובץ המניפסט.

## לא ניתן לשמור טיוטה

- "לא ניתן לפתוח את IndexedDB", "בשימוש בלשונית אחרת": הסיבה היא מצב פרטי בדפדפן, או לשונית אחרת שפתוחה באותו אתר. פתחו חלון רגיל וסגרו את הלשוניות האחרות.
- הטיוטות נשמרות בנפרד לכל מכשיר ולכל דפדפן. הן אינן עוברות למכשיר אחר.
