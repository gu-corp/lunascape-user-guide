# מסמכים אינם מוצגים

## מוצגת ההודעה "לא נמצאו קובץ Markdown או תיקיית docs לפתיחה"

- בסביבת העבודה אין תיקיית `docs`, או שנעשה שימוש בשם אחר מלבד `docs`.
  - הנחת `lunascape-docs.json` באותה תיקייה גורמת לזיהויה כשורש התיעוד, ללא תלות בשמה.
  - לחלופין, הוסיפו את שם התיקייה להגדרה `lunascapeDocEditor.rootDirectoryNames`.
- אם עדיין אין מסמכים, צרו אותם באמצעות "Lunascape Docs: יצירת תיעוד מתבנית".
- אפשר גם לפתוח קובץ Markdown בעורך ואז להריץ את "Lunascape Docs: פתיחה במציג המפרטים".

## מסמך אינו מופיע ב-INDEX

- ודאו שהסיומת היא `.md`, `.markdown` או `.mdx`.
- התיקיות הבאות אינן מוצגות: תיקיות ששמן מתחיל ב-`.`, `node_modules`, ותיקיות שצוינו ב-`ignoredDirectories` (ברירת המחדל היא `99-archive`).
- גרסאות התרגום שמתחת ל-`i18n/` אינן מוצגות ב-INDEX בנפרד. המעבר אליהן נעשה מתפריט השפות.
- אם קובץ שהוספתם זה עתה אינו מוצג, לחצו על [טעינה מחדש].
- ייתכן שאתם צופים בשורש תיעוד אחר. בדקו את שם שורש התיעוד בקצה השמאלי של סרגל הכלים.

## לחיצה על תיקייה אינה מציגה דבר

קובץ ה-`README.md` של אותה תיקייה הוא "מתאר להגדרות בלבד", שיש בו front matter בלבד וללא גוף. פתחו את התיקייה ב-INDEX ובחרו מסמך שבתוכה.

## נפתח שורש תיעוד לא מכוון

- כאשר ההגדרה `lunascapeDocEditor.rootMode` היא `fixed`, נפתח תמיד השורש שצוין ב-`lunascapeDocEditor.root`.
- במצב `auto` נבחר שורש התיעוד הקרוב ביותר לקובץ ה-Markdown שנפתח. אפשר להחליף בעזרת התפריט הנפתח שבקצה השמאלי של סרגל הכלים.

## שם שורש התיעוד שונה מהמצופה

השם נקבע לפי הסדר הזה: `title` שב-`lunascape-docs.json` → `navigation.title` של `README.md` שבשורש → כותרת ה-H1 שלו → `index.md` → שם התיקייה. כדי לקבע את השם, הגדירו את `title`.

## INDEX נעלם

- בשורש תיעוד שיש בו מסמך אחד בלבד, INDEX נסגר אוטומטית בפעם הראשונה בלבד. אפשר לפתוח אותו באמצעות סמל תצוגת העמודות שבסרגל הכלים. אפשר לכבות זאת באמצעות [הסתרה אוטומטית כשיש מסמך אחד בלבד] שב-[הגדרות תצוגה].
- כשהמסך צר, פתחו אותו באמצעות [פתיחת INDEX] (שלושה קווים) שמשמאל ל-[חזרה].

## לחיצה על קישור אינה פותחת אותו

- "יעד הקישור לא נמצא": הקובץ שאליו מפנה הקישור אינו קיים. אפשר לבדוק קישורים פנימיים באמצעות [בדיקה] שבכלי מסמכים.
- "קישור לא בטוח או שאינו נתמך לא נפתח": קישורים אל מחוץ לשורש התיעוד, או לסכמות שאינן `https://` או `mailto:`, אינם נפתחים.

## השפה המוצגת שונה מהמכוון

- בתפריט השפות אפשר לבדוק את שפת הדף המוצג ואת הסיבה לבחירתה.
- שפת התצוגה שנבחרה בפעם הקודמת נשמרת. בחרו מחדש את שפת ברירת המחדל בתפריט השפות.
- אם ההגדרה האישית `lunascapeDocEditor.locale` מוגדרת, גרסת התרגום באותה שפה מקבלת עדיפות.
