# דיווח על תקלה

אם לא הצלחתם לפתור בעיה, דווחו עליה בצירוף המידע הבא. שתפו מתוכן המסמך או ממידע סודי רק את הנדרש.

## המידע שיש לכלול בדיווח

| פריט | כיצד לאתר אותו |
|---|---|
| גרסת Lunascape Docs | פתחו את "Lunascape Docs" בתצוגת התוספים |
| גרסת VS Code | [עזרה] ← [אודות] בתפריט |
| מערכת ההפעלה | macOS, Windows או Linux, והגרסה שלה |
| מבנה שורש התיעוד | תוכן הקובץ `lunascape-docs.json`, תיאור כללי של מבנה התיקיות, והאם נעשה שימוש ב-Standard Pack |
| שלבים לשחזור | מה עשיתם, ובאיזה סדר |
| התוצאה הצפויה והתוצאה בפועל | העתיקו כל הודעה שהוצגה במלואה, כפי שהיא |
| בבעיות תרגום | תוכן ערוץ הפלט "Lunascape Docs 翻訳" |

> **עצה**
>
> - בבעיות תצוגה, הפקודה "Developer: Open Webview Developer Tools" בלוח הפקודות מראה אם המסוף מדווח על שגיאות.
> - בבעיות בגרסת הווב, צרפו גם את סוג הדפדפן והגרסה שלו, ואת כתובת ה-URL שניסיתם לפתוח.
