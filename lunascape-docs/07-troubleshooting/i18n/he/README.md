# פתרון בעיות

אתרו את הדף המתאים לתקלה שנתקלתם בה. לעיתים קרובות ניסיון הפעולות הבסיסיות שלהלן פותר את הבעיה.

## מה לנסות תחילה

1. לחצו על [טעינה מחדש] בסרגל הכלים.
2. אם קובץ Markdown נמצא בעריכה, שמרו אותו ב‑VS Code.
3. הריצו "Developer: Reload Window" מלוח הפקודות.
4. בדקו בתצוגת התוספים ש‑Lunascape Docs מעודכן לגרסה האחרונה ([התקנת התוסף](../01-introduction/install.md)).

## איתור לפי תקלה

| תקלה | דף עזר |
|---|---|
| שורש התיעוד אינו נמצא, מסמכים אינם מופיעים ב‑INDEX, ה‑INDEX נעלם, קישורים אינם נפתחים | [מסמכים אינם מוצגים](viewer.md) |
| תרשימים, נוסחאות או תמונות אינם מוצגים או מציגים שגיאה | [תרשימים, נוסחאות או תמונות אינם מוצגים](rendering.md) |
| אין כפתור [עריכה], לא ניתן לשמור, לא ניתן לשנות סדר או לשנות שם | [לא ניתן לערוך, לשמור או לשנות סדר](editing.md) |
| בדיקות אינן פועלות, לא ניתן לשמור כללים, תבניות או תרגום נכשלים | [בדיקה, יצירה או תרגום אינם מצליחים](tools.md) |
| גרסת ה‑Web אינה פותחת מאגר או אינה מאפשרת התחברות | [גרסת ה‑Web אינה נפתחת או שההתחברות נכשלת](web.md) |
| הבעיה לא נפתרה | [דיווח על תקלה](report.md) |
