# תרשימים, נוסחאות או תמונות אינם מוצגים

## תרשים TikZ מוצג כקוד מקור מקופל

- הגרסה המופצת של ההרחבה אינה כוללת מנוע ציור של TikZ. זו התצוגה הרגילה.
- לצורכי פיתוח והערכה, התקינו את `node-tikzjax` בגרסה 1.0.5 ישירות תחת סביבת עבודה מהימנה, והגדירו את ההגדרה `lunascapeDocEditor.tikz.runtime` לערך `workspace`.
- בגרסת דפדפן האינטרנט TikZ אינו מצויר.

## הנוסחאות מוצגות כטקסט רגיל

- בדקו את תווי התיחום. לנוסחה בתוך שורה `$...$` או `\(...\)`, ולנוסחה עצמאית `$$...$$` או `\[...\]`.
- `$` בתוך קוד בתוך שורה או בתוך גוש קוד אינו הופך לנוסחה.
- כתיב שנראה כמו סכום כסף, כגון `$5 and $10`, אינו נחשב לנוסחה.
- נוסחאות גדולות מאוד או נוסחאות עם פריסת מאקרו רבה אינן מצוירות כאשר הן חורגות מהמגבלות (`maxSize: 50`, `maxExpand: 1000`). פצלו אותן.

## תרשים מוצג עם ההודעה "לא ניתן לצייר"

- הודעות השגיאה של Mermaid, Vega-Lite, WaveDrom ואחרים מצביעות על בעיית התחביר. בדקו את המקור במסך העריכה באמצעות [Markdown].
- Vega-Lite: הטמיעו את הנתונים ב-`data.values` או ב-`datasets`. לא ניתן להשתמש בנתונים מכתובת URL חיצונית ובסימוני תמונה.
- WaveDrom: כתבו JSON קפדני. לא ניתן להשתמש בכתיב של JavaScript (מפתחות ללא מרכאות וכדומה).
- Penrose: השתמשו רק ב-`@preset set-theory` בראש הקובץ ובמשפטים המותרים (`Set`, `Subset`, `Disjoint`, `Intersecting`, `AutoLabel All`).
- "ב-SVG שנוצר יש הפניות שאינן בטוחות", "ה-SVG שנוצר חורג מהמגבלה": תרשימים המכילים הפניות למשאבים חיצוניים, או תרשימים גדולים מדי, אינם מוצגים. צמצמו את התוכן או הסירו את ההפניות.

## תמונה אינה מוצגת

- את נתיב התמונה יש לציין כנתיב יחסי למסמך. תמונות הנמצאות מחוץ לשורש התיעוד אינן מוצגות.
- ב-`width` של `<img>` יש לציין מספר בלבד (`width="360"`).

## תרשימים אינם מוצגים באתר האינטרנט שיוצא

ספריות הציור של TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob ו-Penrose נטענות בעת התצוגה. הציבו את התיקייה `vendor/` יחד עם האתר שיוצא.
