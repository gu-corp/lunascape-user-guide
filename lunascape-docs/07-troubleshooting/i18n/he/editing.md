# לא ניתן לערוך, לשמור או לשנות סדר

## אין לחצן [עריכה]

- [לחצן העריכה] ב[הגדרות תצוגה] כבוי. הפעילו אותו, או השתמשו ב־[⋯] ← [עריכה] בפינה הימנית העליונה של גוף המסמך, או בתפריט הפריט ב־INDEX ← [עריכה].
- הדבר נכון גם כאשר `editor.showEditButton` בקובץ `lunascape-docs.json` מוגדר כ־`false`.
- בזמן שהעזרה מוצגת לא ניתן לערוך. סגרו את העזרה.

## לא ניתן לעבור לתצוגה החזותית

«המסמך הזה מכיל תחביר MDX ולכן לא ניתן לעבור למסך העריכה הרגיל»: מסמכים הכוללים תחביר ייחודי ל־MDX (רכיבים, `import` וכדומה) נערכים בתצוגת Markdown בלבד, כדי לשמור על התחביר.

## לא ניתן לערוך נוסחאות או תרשים ישירות

התצוגה החזותית מציגה את תוצאת הרינדור. לחצו על [Markdown] במסך העריכה וערכו את המקור.

## לא ניתן לשנות סדר או לגרור

- בזמן סינון, בזמן עריכת מסמך ובזמן שפעולה אחרת ב־INDEX מתבצעת, לא ניתן לשנות סדר.
- כאשר סביבת העבודה אינה מהימנה, פעולות היצירה, הארגון והמחיקה אינן זמינות. סמנו את סביבת העבודה כמהימנה ב־VS Code.
- «ה־INDEX עודכן. גררו שוב»: שינוי אחר הוחל זה עתה. בצעו את הפעולה שוב.
- את דף הפתיחה (`README.md` שבשורש) לא ניתן להעביר.

## מוצגת ההודעה «יש שינויים שלא נשמרו»

הקובץ הנדון נמצא בעריכה בעורך של VS Code. שמרו את השינויים או בטלו אותם, ואז נסו שוב.

## לא ניתן לשנות את השם

לא ניתן להשתמש בשמות הבאים.

- שמות המתחילים ב־`.`, השם `i18n`, ושמות שמורים של Windows (כגון `CON`)
- שמות המסתיימים בנקודה או ברווח, ושמות הכוללים תווי בקרה או תווים שאינם מותרים בשמות קבצים
- שמות הקיימים כבר באותה תיקייה (כולל שמות הנבדלים רק באותיות גדולות וקטנות)
- שמות מסמכים ללא סיומת של Markdown

## שמרתי, אך השינוי אינו מופיע ב־Git או אינו נשלח כ־commit

Lunascape Docs רק כותב לקובץ, ואינו מבצע staging או commit ב־Git. בדקו בתצוגת ניהול המקור (Source Control) של VS Code ובצעו commit לפי הצורך.
