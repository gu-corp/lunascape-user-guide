# 網頁版無法開啟或無法登入

## 已登入，但存放庫沒有出現在清單中

該帳號未安裝 GitHub App「Lunascape Docs」，或是目標存放庫未包含在內。請依照 [閱覽非公開存放庫](../06-web/private-repository.md) 的步驟，向存放庫擁有者或組織的管理員提出安裝申請。

## 停在登入畫面無法繼續

- 沒有目標存放庫的讀取權限。請向存放庫擁有者申請授予權限。
- 顯示「本網站未設定 GitHub 登入」：自行部署的檢視器未設定登入服務。需要由管理員設定登入服務。

## 登入用的快顯視窗沒有開啟

瀏覽器封鎖了快顯視窗。請允許本網站的快顯視窗後再試一次。

## 顯示「登入已過期」

登入的有效期限已過。請再按一次 [使用 GitHub 登入]。

## 開啟公開存放庫時出現 404

- 確認 `owner/repo@ref/dir` 的寫法。
- 無法指定包含 `/` 的分支名稱。

## 過一段時間後就無法載入

在未登入的狀態下，會受到 GitHub API 的使用限制（每小時 60 次）。顯示「已達次數上限」時，請稍候片刻，或是進行 [使用 GitHub 登入]。

## 顯示「無法從本網站顯示這個存放庫」

若要從自行部署的檢視器開啟，必須在存放庫端 `lunascape-docs.json` 的 `viewer.origins` 中，加入該網站的 URL。

## 開啟 `index.html` 後沒有顯示任何內容

以 `file://` 直接開啟時無法運作。請透過 HTTP 伺服器開啟，或使用 VS Code 版。

## 匯出的網站顯示「找不到 lunascape-docs-manifest.json」

請將 `npm run export:web` 輸出的整組檔案（含資訊清單）原樣部署。

## 無法儲存草稿

- 顯示「無法開啟 IndexedDB」「其他分頁正在使用中」：原因是瀏覽器的無痕模式，或是有其他分頁開著同一個網站。請以一般視窗開啟，並關閉其他分頁。
- 草稿會依裝置與瀏覽器分別儲存，不會延續到其他裝置。
