# 檢查、建立或翻譯無法順利進行

## 檢查

### 顯示「無法使用 docs-lint」

- 擴充功能未包含 docs-lint 的執行環境，或設定有問題。請重新安裝擴充功能。
- 「若要安全載入本機 Pack 與設定，請在 VS Code 中信任此工作區」：若要使用本機的 Standard Pack，必須是受信任的工作區。

### 結果一直停在「需要重新驗證」

變更文件或設定後，前次的結果即失效。請再次按下 [驗證文件根目錄]。未儲存的變更不會反映。

### 按下指摘項目後沒有開啟任何內容

「整個文件根目錄」的項目不與特定文件相關聯，因此沒有位置資訊。請依照指摘的內容，確認相對應的文件。

### 無法儲存規則

- 必須是受信任的工作區。
- 「Lint 設定已被其他操作變更」：`docs-lint.config.json` 已在外部被變更。請載入最新狀態後再重試。
- 符號連結，或位於文件根目錄之外的設定檔無法編輯。

## 從範本建立

- 「範本的預覽已過期」「輸入內容已變更」：請再次按下 [預覽] 後再建立。
- 「儲存位置的文件已存在」：不會覆寫既有檔案。請指定其他儲存位置。
- 儲存位置需要相對於文件根目錄的路徑，以及 `.md` / `.mdx` 副檔名。無法在 `i18n` 之下建立。
- 「若要建立文件，請信任工作區」：請在 VS Code 中信任此工作區。

## 翻譯

### 無法按下翻譯的按鈕

- 「此文件根目錄未啟用 AI 翻譯」：請將 `lunascape-docs.json` 的 `translation.enabled` 設為 `true`。
- 「尚未設定專案預設語言」：請依[變更顯示設定](../02-reading/display-settings.md)儲存預設語言。
- 「請將翻譯目標加入支援語言」：請將翻譯目標語言加入 `locales`。
- 「找不到要翻譯的正本文件」：目前開啟的是翻譯版頁面。請切換至預設語言的頁面。
- 以暫時方式顯示資料夾時無法使用批次翻譯。請在該資料夾放置 `lunascape-docs.json`，使其成為文件根目錄。

### 翻譯提案被拒絕，或被要求重新產生

- 「正本文件已變更。請重新產生翻譯提案」：產生翻譯提案之後，正本或翻譯目標有所變更。請重新翻譯。
- 若語言模型的回應缺少應保護的識別碼或程式碼，則不予接受。回應的內容可在輸出面板的「Lunascape Docs 翻譯」中確認。
- 「批次翻譯每次上限為 1000 份文件」：請依資料夾或明確選取來分割範圍。
