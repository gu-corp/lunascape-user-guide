# 無法編輯、儲存或重新排序

## 沒有 [編輯] 按鈕

- [顯示設定] 的 [編輯按鈕] 已關閉。請將其開啟，或使用內文右上角的 [⋯] → [編輯]，或是 INDEX 項目選單 → [編輯]。
- `lunascape-docs.json` 的 `editor.showEditButton` 為 `false` 時亦同。
- 顯示說明時無法編輯。請關閉說明。

## 無法切換到視覺化顯示

「此文件含有 MDX 語法，因此無法切換到一般編輯畫面」：含有 MDX 專屬語法（元件、`import` 等）的文件，為保留該語法，僅能在 Markdown 顯示下編輯。

## 無法直接編輯數學式或圖表

視覺化顯示呈現的是繪製結果。請在編輯畫面按 [Markdown]，編輯原始碼。

## 無法重新排序或拖曳

- 篩選期間、編輯文件期間，以及其他 INDEX 操作處理期間無法重新排序。
- 未信任工作區時，無法使用建立、整理、刪除等操作。請在 VS Code 中信任該工作區。
- 「INDEX 已更新，請重新拖曳」：這是其他變更剛套用完成的狀態。請再操作一次。
- 起始頁面（根目錄的 `README.md`）無法移動。

## 顯示「有未儲存的變更」

目標檔案正在 VS Code 的編輯器中編輯。請先儲存或捨棄變更，然後重試。

## 無法變更名稱

下列名稱無法使用。

- 以 `.` 開頭的名稱、`i18n`、Windows 的保留名稱（如 `CON`）
- 結尾為句點或空白的名稱、含有控制字元或檔案名稱不可使用字元的名稱
- 同一資料夾中已存在的名稱（包含僅大小寫不同的名稱）
- 不具 Markdown 副檔名的文件名稱

## 已儲存卻未出現 Git 變更或未提交

Lunascape Docs 只會寫入檔案，不會執行 Git 的暫存或提交。請在 VS Code 的原始檔控制檢視中確認，並視需要提交。
