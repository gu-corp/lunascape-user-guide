# 回報問題

無法解決的問題，請附上下列資訊回報。文件內容或機密資訊，請只分享必要的範圍。

## 回報應包含的資訊

| 項目 | 確認方式 |
|---|---|
| Lunascape Docs 的版本 | 在擴充功能檢視中開啟「Lunascape Docs」即可看到 |
| VS Code 的版本 | 功能表的 [說明] → [關於] |
| 作業系統 | macOS、Windows、Linux 及其版本 |
| 文件根目錄的結構 | `lunascape-docs.json` 的內容、資料夾結構概要、是否使用 Standard Pack |
| 重現步驟 | 依序做了哪些操作 |
| 預期結果與實際結果 | 顯示的訊息請原樣附上全文 |
| 翻譯問題時 | 輸出面板中「Lunascape Docs 翻訳」的內容 |

> **提示**
>
> - 顯示方面的問題，可在命令選擇區執行「Developer: Open Webview Developer Tools」，確認主控台是否出現錯誤。
> - Web 版的問題，請一併附上瀏覽器的種類與版本，以及您嘗試開啟的 URL。

## 回報處

請至 [Issues](https://github.com/gu-corp/lunascape-user-guide/issues) 回報。
