# 疑難排解

請依症狀尋找對應的頁面。先試試下列基本處理方式，往往就能解決問題。

## 首先請嘗試

1. 按下工具列的 [重新載入]。
2. 如果有正在編輯的 Markdown 檔案，請在 VS Code 中儲存。
3. 在命令選擇區執行「Developer: Reload Window」。
4. 在擴充功能檢視中，確認 Lunascape Docs 是否為最新版本（[安裝擴充功能](../01-introduction/install.md)）。

## 依症狀尋找

| 症狀 | 參照頁面 |
|---|---|
| 找不到文件根目錄、文件未出現在 INDEX 中、INDEX 消失、連結無法開啟 | [文件無法顯示](viewer.md) |
| 圖表、數學式、圖片無法顯示或發生錯誤 | [圖表、數學式、圖片無法顯示](rendering.md) |
| 沒有 [編輯]、無法儲存、無法排序或重新命名 | [無法編輯、儲存、排序](editing.md) |
| 無法執行檢查、無法儲存規則、範本或翻譯發生錯誤 | [檢查、建立、翻譯無法順利進行](tools.md) |
| Web 版無法開啟存放庫、無法登入 | [Web 版無法開啟、無法登入](web.md) |
| 仍未解決 | [回報問題](report.md) |
