# Bei Problemen

Suchen Sie die Seite, die zu Ihrem Symptom passt. Oft lässt sich das Problem bereits mit den folgenden grundlegenden Schritten beheben.

## Das sollten Sie zuerst versuchen

1. Drücken Sie in der Symbolleiste auf [Neu laden].
2. Wenn Sie gerade eine Markdown-Datei bearbeiten, speichern Sie sie in VS Code.
3. Führen Sie in der Befehlspalette „Developer: Reload Window“ aus.
4. Prüfen Sie in der Erweiterungsansicht, ob Lunascape Docs auf dem neuesten Stand ist ([Erweiterung installieren](../01-introduction/install.md)).

## Nach Symptom suchen

| Symptom | Seite |
|---|---|
| Es wird keine Dokumentwurzel gefunden, Dokumente erscheinen nicht im INDEX, der INDEX ist verschwunden, Links lassen sich nicht öffnen | [Dokumente werden nicht angezeigt](viewer.md) |
| Diagramme, Formeln oder Bilder werden nicht angezeigt oder es erscheint ein Fehler | [Diagramme, Formeln oder Bilder werden nicht angezeigt](rendering.md) |
| [Bearbeiten] fehlt, Speichern ist nicht möglich, Umsortieren oder Umbenennen ist nicht möglich | [Bearbeiten, Speichern oder Umsortieren nicht möglich](editing.md) |
| Prüfungen lassen sich nicht ausführen, Regeln lassen sich nicht speichern, Vorlagen oder Übersetzung schlagen fehl | [Prüfung, Erstellung oder Übersetzung schlägt fehl](tools.md) |
| In der Web-Version lässt sich kein Repository öffnen oder die Anmeldung schlägt fehl | [Web-Version lässt sich nicht öffnen, Anmeldung nicht möglich](web.md) |
| Das Problem bleibt bestehen | [Fehler melden](report.md) |
