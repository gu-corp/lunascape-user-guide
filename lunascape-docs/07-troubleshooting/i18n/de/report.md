# Ein Problem melden

Wenn sich ein Problem nicht lösen lässt, melden Sie es mit den folgenden Angaben. Teilen Sie Dokumentinhalte oder vertrauliche Informationen nur, soweit es nötig ist.

## Angaben zur Meldung

| Angabe | So finden Sie sie |
|---|---|
| Version von Lunascape Docs | Wird angezeigt, wenn Sie „Lunascape Docs“ in der Erweiterungsansicht öffnen |
| Version von VS Code | Menü [Hilfe] → [Info] |
| Betriebssystem | macOS, Windows oder Linux und dessen Version |
| Aufbau der Dokumentwurzel | Inhalt von `lunascape-docs.json`, Überblick über die Ordnerstruktur, ob ein Standard Pack verwendet wird |
| Schritte zum Nachvollziehen | Was Sie in welcher Reihenfolge getan haben |
| Erwartetes und tatsächliches Ergebnis | Angezeigte Meldungen vollständig und unverändert |
| Bei Übersetzungsproblemen | Inhalt des Ausgabekanals „Lunascape Docs 翻訳“ |

> **Hinweis**
>
> - Bei Anzeigeproblemen können Sie mit „Developer: Open Webview Developer Tools“ in der Befehlspalette prüfen, ob die Konsole Fehler meldet.
> - Bei Problemen mit der Web-Version geben Sie zusätzlich den Browser und dessen Version sowie die aufgerufene URL an.

## Wohin melden

Melden Sie das Problem unter [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
