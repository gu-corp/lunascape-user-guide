# Документы не отображаются

## Появляется сообщение «Не найдена папка Markdown или docs, которую можно открыть»

- В рабочей области нет папки `docs` либо она называется иначе.
  - Поместите в эту папку файл `lunascape-docs.json` — тогда она будет распознана как корень документации независимо от имени.
  - Либо добавьте имя папки в параметр `lunascapeDocEditor.rootDirectoryNames`.
- Если документов еще нет, создайте их командой «Lunascape Docs: создать документ из шаблона».
- Можно также открыть файл Markdown в редакторе и выполнить команду «Lunascape Docs: открыть в просмотрщике спецификаций».

## Документ не отображается в INDEX

- Проверьте, что расширение файла — `.md`, `.markdown` или `.mdx`.
- Следующие папки не отображаются: папки, имя которых начинается с `.`, `node_modules`, а также папки, указанные в `ignoredDirectories` (по умолчанию `99-archive`).
- Переводы, находящиеся в `i18n/`, не показываются в INDEX отдельно. Переключайтесь на них через меню языка.
- Если только что добавленный файл не отображается, нажмите [Обновить].
- Возможно, открыт другой корень документации. Проверьте имя корня документации у левого края панели инструментов.

## При нажатии на папку ничего не отображается

Файл `README.md` этой папки — «описатель только с настройками»: в нем есть front matter, но нет основного текста. Раскройте папку в INDEX и выберите документ внутри нее.

## Открывается не тот корень документации

- Если параметр `lunascapeDocEditor.rootMode` имеет значение `fixed`, всегда открывается корень, указанный в `lunascapeDocEditor.root`.
- При значении `auto` выбирается корень документации, ближайший к открытому файлу Markdown. Переключить его можно в раскрывающемся списке у левого края панели инструментов.

## Имя корня документации отличается от ожидаемого

Имя определяется в следующем порядке: `title` в `lunascape-docs.json` → `navigation.title` в корневом `README.md` → его заголовок H1 → `index.md` → имя папки. Чтобы задать имя однозначно, укажите `title`.

## INDEX исчез

- В корне документации, где есть только один документ, INDEX автоматически закрывается при первом открытии. Его можно открыть значком отображения столбцов на панели инструментов. Отключить это поведение можно параметром [Скрывать, если документ только один] в разделе [Параметры отображения].
- На узком экране открывайте его кнопкой [Открыть INDEX] (три полосы) слева от кнопки [Назад].

## Ссылка не открывается при нажатии

- «Цель ссылки не найдена»: файл, на который указывает ссылка, не существует. Проверить внутренние ссылки можно кнопкой [Проверка] в инструментах документа.
- «Небезопасная или неподдерживаемая ссылка не была открыта»: ссылки за пределы корня документации, а также ссылки со схемой, отличной от `https://` и `mailto:`, не открываются.

## Отображается не тот язык

- В меню языка проверьте язык открытой страницы и основание, по которому он выбран.
- Выбранный ранее язык интерфейса запоминается. Выберите язык по умолчанию в меню языка заново.
- Если задан личный параметр `lunascapeDocEditor.locale`, приоритет имеет перевод на этот язык.
