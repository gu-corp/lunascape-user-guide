# Сообщение о проблеме

Если проблему решить не удалось, сообщите о ней, приложив следующие сведения. Содержимое документов и конфиденциальные данные передавайте только в необходимом объеме.

## Что включить в сообщение

| Пункт | Как узнать |
|---|---|
| Версия Lunascape Docs | Откройте «Lunascape Docs» в представлении расширений |
| Версия VS Code | В меню [Справка] → [О программе] |
| ОС | macOS, Windows или Linux и версия системы |
| Устройство корня документации | Содержимое `lunascape-docs.json`, краткое описание структуры папок, используется ли Standard Pack |
| Шаги воспроизведения | Что и в каком порядке вы делали |
| Ожидаемый и фактический результат | Появившееся сообщение приведите полностью, как есть |
| Для проблем с переводом | Содержимое канала вывода «Lunascape Docs 翻訳» |

> **Совет**
>
> - При проблемах с отображением команда «Developer: Open Webview Developer Tools» в палитре команд покажет, есть ли ошибки в консоли.
> - При проблемах с веб-версией укажите также браузер и его версию и URL, который вы пытались открыть.

## Куда сообщать

Сообщите о проблеме в [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
