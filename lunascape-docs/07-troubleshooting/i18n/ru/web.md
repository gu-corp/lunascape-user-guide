# Веб-версия не открывается или не удается войти

## Вход выполнен, но репозитория нет в списке

В этой учетной записи не установлено приложение GitHub App «Lunascape Docs» либо нужный репозиторий не включен в него. Попросите владельца репозитория или администратора организации установить его по инструкции [Просмотр закрытого репозитория](../06-web/private-repository.md).

## Не удается пройти дальше экрана входа

- У вас нет прав на чтение этого репозитория. Попросите владельца репозитория предоставить доступ.
- «Для этого сайта не настроен вход через GitHub»: в самостоятельно размещенной программе просмотра не настроена служба входа. Ее должен настроить администратор.

## Всплывающее окно входа не открывается

Браузер блокирует всплывающие окна. Разрешите их для этого сайта и повторите попытку.

## Показано сообщение «Сеанс входа истек»

Срок действия входа истек. Нажмите [Войти через GitHub] еще раз.

## При открытии открытого репозитория возникает ошибка 404

- Проверьте запись вида `owner/repo@ref/dir`.
- Имена веток, содержащие `/`, указать нельзя.

## Через некоторое время загрузка перестает работать

Без входа действует ограничение на обращения к GitHub API (60 раз в час). Если показано сообщение «Достигнут предел числа обращений», подождите некоторое время или нажмите [Войти через GitHub].

## Показано сообщение «С этого сайта нельзя показать этот репозиторий»

Чтобы открыть репозиторий из самостоятельно размещенной программы просмотра, URL-адрес этого сайта нужно добавить в `viewer.origins` в файле `lunascape-docs.json` репозитория.

## При открытии `index.html` ничего не отображается

При открытии напрямую через `file://` страница не работает. Откройте ее через HTTP-сервер или используйте версию для VS Code.

## На выгруженном сайте показано сообщение «Файл lunascape-docs-manifest.json не найден»

Разместите весь набор файлов, созданных командой `npm run export:web` (включая манифест), без изменений.

## Не удается сохранить черновик

- «Не удается открыть IndexedDB», «Используется в другой вкладке»: причина — приватный режим браузера или другая вкладка с тем же сайтом. Откройте сайт в обычном окне и закройте остальные вкладки.
- Черновики сохраняются отдельно для каждого устройства и браузера. На другое устройство они не переносятся.
