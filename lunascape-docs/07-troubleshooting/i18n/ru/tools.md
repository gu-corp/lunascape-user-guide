# Не удается выполнить проверку, создание или перевод

## Проверка

### Отображается сообщение «docs-lint недоступен»

- В расширении нет среды выполнения docs-lint, либо есть проблема в настройках. Переустановите расширение.
- «Чтобы безопасно загрузить локальный Pack и настройки, пометьте эту рабочую область в VS Code как надежную»: для использования локального Standard Pack требуется надежная рабочая область.

### Результат остается в состоянии «требуется повторная проверка»

При изменении документа или настроек прежний результат становится недействительным. Нажмите [Проверить корень документации] еще раз. Несохраненные изменения не учитываются.

### Замечание не открывается при нажатии

Пункты категории «весь корень документации» не связаны с конкретным документом и не имеют позиции. Проверьте соответствующие документы согласно содержанию замечания.

### Не удается сохранить правила

- Требуется надежная рабочая область.
- «Настройки Lint изменены другой операцией»: файл `docs-lint.config.json` был изменен извне. Загрузите актуальное состояние и повторите попытку.
- Символические ссылки и файлы настроек за пределами корня документации редактировать нельзя.

## Создание из шаблона

- «Срок действия предпросмотра шаблона истек», «Введенные данные изменены»: нажмите [Предпросмотр] еще раз, а затем создайте документ.
- «Документ по указанному пути уже существует»: существующие файлы не перезаписываются. Укажите другой путь сохранения.
- Для пути сохранения нужны относительный путь от корня документации и расширение `.md` или `.mdx`. Внутри `i18n` создавать документы нельзя.
- «Чтобы создать документ, пометьте рабочую область как надежную»: пометьте рабочую область в VS Code как надежную.

## Перевод

### Кнопки перевода недоступны

- «В этом корне документации не включен перевод с помощью ИИ»: установите для параметра `translation.enabled` в `lunascape-docs.json` значение `true`.
- «Язык проекта по умолчанию не задан»: сохраните язык по умолчанию на странице [Изменение параметров отображения](../02-reading/display-settings.md).
- «Добавьте язык перевода в список поддерживаемых»: добавьте язык перевода в `locales`.
- «Исходный документ для перевода не найден»: открыта переведенная страница. Переключитесь на страницу на языке по умолчанию.
- При временном отображении папки пакетный перевод недоступен. Поместите в эту папку файл `lunascape-docs.json`, чтобы она стала корнем документации.

### Вариант перевода отклонен или требуется создать его заново

- «Исходный документ изменен. Создайте вариант перевода заново»: после создания варианта перевода изменился исходный документ или перевод. Выполните перевод еще раз.
- Если в ответе языковой модели отсутствуют защищаемые идентификаторы или код, ответ не принимается. Содержимое ответа можно посмотреть в панели вывода «Lunascape Docs 翻訳».
- «За один раз пакетный перевод обрабатывает не более 1000 документов»: разделите объем по папкам или явным выбором.
