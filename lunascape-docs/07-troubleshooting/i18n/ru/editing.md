# Не удается редактировать, сохранять или менять порядок

## Нет кнопки [Редактировать]

- В разделе [Параметры отображения] выключен параметр [Кнопка редактирования]. Включите его либо используйте [⋯] → [Редактировать] в правом верхнем углу документа или меню элемента в INDEX → [Редактировать].
- То же самое происходит, если в `lunascape-docs.json` параметр `editor.showEditButton` имеет значение `false`.
- Во время показа справки редактирование недоступно. Закройте справку.

## Не удается переключиться на визуальный режим

«Этот документ содержит синтаксис MDX, поэтому переключиться на обычный экран редактирования нельзя»: документы с синтаксисом, свойственным MDX (компоненты, `import` и т. п.), редактируются только в режиме Markdown, чтобы сохранить этот синтаксис.

## Не удается напрямую редактировать формулы или схемы

В визуальном режиме показывается результат отрисовки. Нажмите [Markdown] на экране редактирования и измените исходный текст.

## Не удается изменить порядок или перетащить элемент

- Изменение порядка недоступно во время фильтрации, во время редактирования документа и во время выполнения другой операции в INDEX.
- Если рабочая область не является надежной, операции создания, упорядочивания и удаления недоступны. Сделайте рабочую область надежной в VS Code.
- «INDEX обновлен. Перетащите еще раз»: только что применено другое изменение. Повторите операцию.
- Начальную страницу (файл `README.md` в корне) переместить нельзя.

## Появляется сообщение «Есть несохраненные изменения»

Нужный файл редактируется в редакторе VS Code. Сначала сохраните или отмените изменения, затем повторите попытку.

## Не удается изменить имя

Следующие имена использовать нельзя.

- Имена, начинающиеся с `.`, имя `i18n`, зарезервированные имена Windows (например, `CON`)
- Имена, оканчивающиеся точкой или пробелом, а также имена с управляющими символами или символами, недопустимыми в именах файлов
- Имена, которые уже есть в той же папке (включая имена, отличающиеся только регистром букв)
- Имена документов без расширения Markdown

## Изменения сохранены, но не отображаются в Git или не фиксируются

Lunascape Docs только записывает файл и не выполняет в Git ни индексирование, ни фиксацию. Проверьте представление системы управления версиями в VS Code и при необходимости зафиксируйте изменения.
