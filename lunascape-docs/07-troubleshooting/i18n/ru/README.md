# Устранение неполадок

Найдите страницу, которая соответствует вашей проблеме. Часто помогают базовые действия, описанные ниже.

## Что попробовать в первую очередь

1. Нажмите [Обновить] на панели инструментов.
2. Если открыт редактируемый файл Markdown, сохраните его в VS Code.
3. Выполните команду «Developer: Reload Window» в палитре команд.
4. В разделе расширений проверьте, установлена ли последняя версия Lunascape Docs ([Установка расширения](../01-introduction/install.md)).

## Поиск по признаку

| Признак | Страница |
|---|---|
| Корень документации не найден, документы не отображаются в INDEX, INDEX исчез, ссылки не открываются | [Документы не отображаются](viewer.md) |
| Схемы, формулы или изображения не отображаются либо выдают ошибку | [Схемы, формулы и изображения не отображаются](rendering.md) |
| Нет кнопки [Редактировать], не удается сохранить, изменить порядок или переименовать | [Не удается редактировать, сохранить или изменить порядок](editing.md) |
| Проверки не запускаются, правила не сохраняются, шаблоны или перевод завершаются с ошибкой | [Проблемы с проверкой, созданием и переводом](tools.md) |
| В веб-версии не удается открыть репозиторий или войти | [В веб-версии не удается открыть документы или войти](web.md) |
| Проблема сохраняется | [Сообщить о неполадке](report.md) |
