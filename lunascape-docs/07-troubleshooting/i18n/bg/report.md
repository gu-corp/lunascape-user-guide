# Докладване на проблем

Ако даден проблем не се решава, докладвайте го със следната информация. Споделяйте съдържание на документи или поверителна информация само дотолкова, доколкото е необходимо.

## Какво да включите в доклада

| Елемент | Как да го намерите |
|---|---|
| Версия на Lunascape Docs | Показва се, когато отворите „Lunascape Docs“ в изгледа с разширенията |
| Версия на VS Code | [Помощ] → [Относно] в менюто |
| Операционна система | macOS, Windows или Linux и нейната версия |
| Устройство на коренната папка на документацията | Съдържанието на `lunascape-docs.json`, обща схема на папките, дали се използва Standard Pack |
| Стъпки за възпроизвеждане | Какво сте направили и в какъв ред |
| Очакван и действителен резултат | Копирайте всяко съобщение изцяло, както е показано |
| При проблем с превода | Съдържанието на канала „Lunascape Docs 翻訳“ в панела с изхода |

> **Съвет**
>
> - При проблеми с изобразяването с „Developer: Open Webview Developer Tools“ от палитрата с команди можете да проверите дали в конзолата има грешки.
> - При проблеми с уеб версията добавете и браузъра и неговата версия, както и URL адреса, който сте опитали да отворите.

## Къде да докладвате

Докладвайте в [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
