# Apabila menghadapi masalah

Cari halaman yang sepadan dengan gejala anda. Cuba langkah asas berikut dahulu; selalunya masalah itu selesai.

## Perkara yang perlu dicuba dahulu

1. Tekan [Muat semula] pada bar alat.
2. Jika ada fail Markdown yang sedang diedit, simpan fail itu dalam VS Code.
3. Jalankan "Developer: Reload Window" daripada Palet Perintah.
4. Dalam paparan Sambungan, pastikan Lunascape Docs ialah versi terkini ([Memasang sambungan](../01-introduction/install.md)).

## Cari mengikut gejala

| Gejala | Halaman rujukan |
|---|---|
| Akar dokumentasi tidak dijumpai, dokumen tidak muncul dalam INDEX, INDEX hilang, pautan tidak terbuka | [Dokumen tidak dipaparkan](viewer.md) |
| Rajah, rumus matematik atau imej tidak dipaparkan atau menunjukkan ralat | [Rajah, rumus matematik atau imej tidak dipaparkan](rendering.md) |
| Tiada butang [Edit], tidak boleh menyimpan, tidak boleh menyusun semula atau menamakan semula | [Tidak boleh mengedit, menyimpan atau menyusun semula](editing.md) |
| Semakan tidak boleh dijalankan, peraturan tidak boleh disimpan, templat atau terjemahan menunjukkan ralat | [Semakan, penciptaan atau terjemahan tidak berjaya](tools.md) |
| Versi Web tidak dapat membuka repositori atau log masuk | [Versi Web tidak boleh dibuka atau log masuk](web.md) |
| Masih tidak selesai | [Melaporkan masalah](report.md) |
