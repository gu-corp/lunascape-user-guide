# Melaporkan masalah

Bagi masalah yang tidak dapat anda selesaikan, laporkannya bersama maklumat berikut. Kongsikan kandungan dokumen atau maklumat sulit setakat yang perlu sahaja.

## Maklumat yang perlu disertakan

| Perkara | Cara menyemaknya |
|---|---|
| Versi Lunascape Docs | Buka "Lunascape Docs" dalam paparan Sambungan |
| Versi VS Code | [Bantuan] → [Perihal] dalam menu |
| OS | macOS, Windows atau Linux, dan versinya |
| Susunan akar dokumentasi | Kandungan `lunascape-docs.json`, gambaran ringkas struktur folder, sama ada Standard Pack digunakan |
| Langkah untuk menghasilkan semula | Apa yang anda lakukan, mengikut urutan |
| Hasil yang dijangka dan hasil sebenar | Salin mana-mana mesej sepenuhnya, seperti yang dipaparkan |
| Bagi masalah terjemahan | Kandungan saluran output "Lunascape Docs 翻訳" |

> **Petua**
>
> - Bagi masalah paparan, "Developer: Open Webview Developer Tools" dalam Palet Perintah menunjukkan sama ada konsol melaporkan ralat.
> - Bagi masalah pemapar Web, sertakan jenis pelayar dan versinya serta URL yang anda cuba buka.
