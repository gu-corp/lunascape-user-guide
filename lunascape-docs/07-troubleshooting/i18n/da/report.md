# Rapportering af et problem

Rapportér et problem, du ikke kan løse, med følgende oplysninger. Del kun dokumentindhold eller fortrolige oplysninger i det omfang, det er nødvendigt.

## Oplysninger, du skal tage med

| Element | Sådan finder du det |
|---|---|
| Versionen af Lunascape Docs | Vises, når du åbner "Lunascape Docs" i visningen Udvidelser |
| Versionen af VS Code | [Hjælp] → [Om] i menuen |
| OS | macOS, Windows eller Linux og versionen |
| Dokumentrodens opbygning | Indholdet af `lunascape-docs.json`, en oversigt over mappestrukturen, om der bruges en Standard Pack |
| Trin til at gengive problemet | Hvad du gjorde, og i hvilken rækkefølge |
| Forventet og faktisk resultat | Kopiér eventuelle meddelelser i fuld længde, præcis som de vises |
| Ved oversættelsesproblemer | Indholdet af outputkanalen "Lunascape Docs 翻訳" |

> **Tip**
>
> - Ved visningsproblemer kan du med "Developer: Open Webview Developer Tools" i kommandopaletten se, om der er fejl i konsollen.
> - Ved problemer med webviseren skal du også oplyse browseren og dens version samt den URL, du forsøgte at åbne.

## Hvor du rapporterer

Rapportér problemet under [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
