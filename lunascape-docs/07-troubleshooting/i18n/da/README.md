# Fejlfinding

Find den side, der passer til dit symptom. Prøv først de grundlæggende trin nedenfor — det løser ofte problemet.

## Prøv dette først

1. Tryk på [Genindlæs] på værktøjslinjen.
2. Hvis du er ved at redigere en Markdown-fil, så gem den i VS Code.
3. Kør "Developer: Reload Window" fra kommandopaletten.
4. Kontrollér i visningen over udvidelser, at Lunascape Docs er den nyeste version (se [Installer udvidelsen](../01-introduction/install.md)).

## Find efter symptom

| Symptom | Side |
|---|---|
| Der findes ingen dokumentrod, dokumenter dukker ikke op i INDEX, INDEX er forsvundet, links åbner ikke | [Dokumenter vises ikke](viewer.md) |
| Diagrammer, matematik eller billeder vises ikke eller giver en fejl | [Diagrammer, matematik eller billeder vises ikke](rendering.md) |
| Ingen [Rediger], kan ikke gemme, kan ikke ændre rækkefølge eller omdøbe | [Kan ikke redigere, gemme eller ændre rækkefølge](editing.md) |
| Kontrol kan ikke køres, regler kan ikke gemmes, skabeloner eller oversættelse giver fejl | [Kontrol, oprettelse eller oversættelse mislykkes](tools.md) |
| Web-udgaven kan ikke åbne et lager eller logge ind | [Web-udgaven kan ikke åbne eller logge ind](web.md) |
| Løses ikke | [Rapportér en fejl](report.md) |
