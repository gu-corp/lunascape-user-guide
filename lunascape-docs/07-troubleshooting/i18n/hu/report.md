# Hiba jelentése

Ha egy problémát nem sikerül megoldania, jelentse a következő információkkal. A dokumentumok szövegét és a bizalmas információkat csak a szükséges mértékben ossza meg.

## Mit tartalmazzon a jelentés

| Elem | Hogyan derítheti ki |
|---|---|
| A Lunascape Docs verziója | Nyissa meg a „Lunascape Docs” elemet a Bővítmények nézetben |
| A VS Code verziója | A menüben [Súgó] → [Névjegy] |
| Operációs rendszer | macOS, Windows vagy Linux, és annak verziója |
| A dokumentumgyökér felépítése | A `lunascape-docs.json` tartalma, a mappaszerkezet áttekintése, használ-e Standard Pack csomagot |
| A hiba előidézésének lépései | Mit tett, és milyen sorrendben |
| A várt és a tényleges eredmény | A megjelent üzenetet teljes egészében, szó szerint |
| Fordítási hiba esetén | A kimeneti panel „Lunascape Docs 翻訳” csatornájának tartalma |

> **Tipp**
>
> - Megjelenítési hiba esetén a parancskatalógus „Developer: Open Webview Developer Tools” parancsával ellenőrizheti, hogy a konzol jelez-e hibát.
> - A webes nézegető hibáinál adja meg a böngésző típusát és verzióját, valamint a megnyitni kívánt URL-t is.

## Hová jelentse
