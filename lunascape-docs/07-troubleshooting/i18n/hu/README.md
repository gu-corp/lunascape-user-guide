# Hibaelhárítás

Keresse meg a tünetnek megfelelő oldalt. Gyakran megoldja a problémát, ha először az alábbi alapvető lépéseket próbálja ki.

## Először ezeket próbálja

1. Nyomja meg az eszköztáron az [Újratöltés] gombot.
2. Ha éppen szerkeszt egy Markdown fájlt, mentse el a VS Code-ban.
3. Futtassa a „Developer: Reload Window” parancsot a parancskatalógusból.
4. Ellenőrizze a bővítmények nézetben, hogy a Lunascape Docs a legújabb verziójú-e ([A bővítmény telepítése](../01-introduction/install.md)).

## Keresés tünet alapján

| Tünet | Hivatkozott oldal |
|---|---|
| Nem található dokumentumgyökér, a dokumentumok nem jelennek meg az INDEX panelen, az INDEX eltűnt, a hivatkozások nem nyílnak meg | [A dokumentumok nem jelennek meg](viewer.md) |
| Az ábrák, képletek vagy képek nem jelennek meg, vagy hibát adnak | [Az ábrák, képletek vagy képek nem jelennek meg](rendering.md) |
| Nincs [Szerkesztés] gomb, nem lehet menteni, nem lehet átrendezni vagy átnevezni | [Nem lehet szerkeszteni, menteni vagy átrendezni](editing.md) |
| Az ellenőrzés nem fut le, a szabályokat nem lehet menteni, a sablon vagy a fordítás hibát ad | [Az ellenőrzés, a létrehozás vagy a fordítás nem működik](tools.md) |
| A webes változatban nem lehet megnyitni az adattárat vagy bejelentkezni | [A webes változatban nem lehet megnyitni vagy bejelentkezni](web.md) |
| Nem oldódott meg | [Hiba bejelentése](report.md) |
