# W razie problemów

Znajdź stronę odpowiadającą objawowi. Najpierw wypróbuj poniższe podstawowe czynności — często rozwiązują problem.

## Co zrobić najpierw

1. Naciśnij [Załaduj ponownie] na pasku narzędzi.
2. Jeśli edytujesz plik Markdown, zapisz go w VS Code.
3. W palecie poleceń uruchom „Developer: Reload Window”.
4. W widoku rozszerzeń sprawdź, czy Lunascape Docs jest w najnowszej wersji ([Instalowanie rozszerzenia](../01-introduction/install.md)).

## Wyszukiwanie według objawu

| Objaw | Strona |
|---|---|
| Nie znaleziono katalogu głównego dokumentacji, dokumenty nie pojawiają się w INDEX, INDEX zniknął, linki nie otwierają się | [Dokumenty nie są wyświetlane](viewer.md) |
| Diagramy, wzory matematyczne lub obrazy nie są wyświetlane albo pojawia się błąd | [Diagramy, wzory matematyczne lub obrazy nie są wyświetlane](rendering.md) |
| Brak przycisku [Edytuj], nie można zapisać, nie można zmienić kolejności ani nazwy | [Nie można edytować, zapisać ani zmienić kolejności](editing.md) |
| Sprawdzanie nie działa, nie można zapisać reguł, szablony lub tłumaczenie kończą się błędem | [Sprawdzanie, tworzenie lub tłumaczenie nie działa](tools.md) |
| W wersji Web nie można otworzyć repozytorium ani się zalogować | [W wersji Web nie można otworzyć repozytorium ani się zalogować](web.md) |
| Problem nadal występuje | [Zgłaszanie błędu](report.md) |
