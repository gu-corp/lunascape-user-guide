# Zgłaszanie problemu

Problem, którego nie udaje się rozwiązać, zgłoś wraz z poniższymi informacjami. Treść dokumentów i informacje poufne udostępniaj tylko w niezbędnym zakresie.

## Co dołączyć do zgłoszenia

| Element | Jak sprawdzić |
|---|---|
| Wersja Lunascape Docs | Otwórz „Lunascape Docs” w widoku rozszerzeń |
| Wersja VS Code | [Pomoc] → [Informacje] w menu |
| System operacyjny | macOS, Windows lub Linux wraz z wersją |
| Budowa katalogu głównego dokumentacji | Zawartość pliku `lunascape-docs.json`, zarys struktury folderów, obecność Standard Pack |
| Kroki prowadzące do problemu | Co i w jakiej kolejności zostało zrobione |
| Oczekiwany i rzeczywisty wynik | Wyświetlone komunikaty przepisz w całości, bez zmian |
| W przypadku problemów z tłumaczeniem | Zawartość kanału „Lunascape Docs 翻訳” w panelu danych wyjściowych |

> **Wskazówka**
>
> - Przy problemach z wyświetlaniem polecenie „Developer: Open Webview Developer Tools” w palecie poleceń pokazuje, czy w konsoli pojawiają się błędy.
> - Przy problemach z przeglądarką internetową dołącz także rodzaj i wersję przeglądarki oraz adres URL, który próbowano otworzyć.

## Gdzie zgłaszać

Zgłoszenie dodaj w [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
