# Problemen oplossen

Zoek de pagina die bij uw symptoom hoort. Probeer eerst de onderstaande basisstappen; vaak is het probleem daarmee al opgelost.

## Probeer dit eerst

1. Druk op [Opnieuw laden] in de werkbalk.
2. Als u een Markdown-bestand aan het bewerken bent, slaat u dit op in VS Code.
3. Voer "Developer: Reload Window" uit in het opdrachtenpalet.
4. Controleer in de weergave Extensies of Lunascape Docs de nieuwste versie is (zie [De extensie installeren](../01-introduction/install.md)).

## Zoeken op symptoom

| Symptoom | Pagina |
|---|---|
| De documentatiehoofdmap wordt niet gevonden, documenten verschijnen niet in de INDEX, de INDEX is verdwenen, koppelingen gaan niet open | [Documenten worden niet weergegeven](viewer.md) |
| Diagrammen, formules of afbeeldingen worden niet weergegeven of geven een fout | [Diagrammen, formules of afbeeldingen worden niet weergegeven](rendering.md) |
| [Bewerken] ontbreekt, opslaan lukt niet, volgorde wijzigen of hernoemen lukt niet | [Bewerken, opslaan of volgorde wijzigen lukt niet](editing.md) |
| Controles kunnen niet worden uitgevoerd, regels kunnen niet worden opgeslagen, sjablonen of vertaling geven een fout | [Controle, aanmaken of vertaling lukt niet](tools.md) |
| In de webversie kan geen repository worden geopend of kunt u zich niet aanmelden | [Openen of aanmelden lukt niet in de webversie](web.md) |
| Niet opgelost | [Een probleem melden](report.md) |
