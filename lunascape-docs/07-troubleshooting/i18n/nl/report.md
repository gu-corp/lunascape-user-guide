# Een probleem melden

Meld een probleem dat u niet kunt oplossen met de volgende gegevens. Deel de inhoud van documenten of vertrouwelijke informatie alleen voor zover dat nodig is.

## Wat u moet vermelden

| Onderdeel | Zo vindt u het |
|---|---|
| Versie van Lunascape Docs | Open "Lunascape Docs" in de weergave Extensies |
| Versie van VS Code | [Help] → [Info] in het menu |
| Besturingssysteem | macOS, Windows of Linux, en de versie ervan |
| Indeling van de documentatiehoofdmap | De inhoud van `lunascape-docs.json`, een overzicht van de mappenstructuur, of er een Standard Pack wordt gebruikt |
| Stappen om het te reproduceren | Wat u hebt gedaan, in welke volgorde |
| Verwacht en werkelijk resultaat | Neem elk bericht volledig over, precies zoals het wordt weergegeven |
| Bij vertaalproblemen | De inhoud van het uitvoerkanaal "Lunascape Docs 翻訳" |

> **Tip**
>
> - Bij weergaveproblemen laat "Developer: Open Webview Developer Tools" in het opdrachtenpalet zien of de console fouten meldt.
> - Bij problemen met de webviewer vermeldt u ook de browser en de versie ervan en de URL die u wilde openen.

## Waar u kunt melden

Meld het in [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
