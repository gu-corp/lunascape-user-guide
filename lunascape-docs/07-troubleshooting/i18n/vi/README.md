# Khi gặp sự cố

Hãy tìm trang tương ứng với hiện tượng bạn gặp phải. Trước tiên, thử các cách xử lý cơ bản sau đây, đôi khi sự cố sẽ được giải quyết.

## Những điều cần thử trước

1. Nhấn [Tải lại] trên thanh công cụ.
2. Nếu đang chỉnh sửa tệp Markdown, hãy lưu tệp đó trong VS Code.
3. Chạy "Developer: Reload Window" từ bảng lệnh.
4. Trong khung xem tiện ích mở rộng, kiểm tra xem Lunascape Docs đã ở phiên bản mới nhất chưa ([Cài đặt tiện ích mở rộng](../01-introduction/install.md)).

| Sơ đồ, công thức toán, hình ảnh không hiển thị hoặc báo lỗi | [Sơ đồ, công thức toán, hình ảnh không hiển thị](rendering.md) |
