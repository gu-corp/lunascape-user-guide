# 无法编辑、保存或排序

## 没有 [编辑] 按钮

- [显示设置] 中的 [编辑按钮] 已关闭。请将其打开，或使用正文右上角的 [⋯] → [编辑]，或 INDEX 项目菜单 → [编辑]。
- `lunascape-docs.json` 中的 `editor.showEditButton` 为 `false` 时同样如此。
- 显示帮助时无法编辑。请关闭帮助。

## 无法切换到可视化显示

"此文档含有 MDX 语法，无法切换到普通编辑界面"：含有 MDX 专有语法（组件、`import` 等）的文档，为保持语法只能在 Markdown 显示下编辑。

## 无法直接编辑公式或图

可视化显示中呈现的是绘制结果。请在编辑界面中按 [Markdown]，编辑源代码。

## 无法排序或拖动

- 筛选过程中、文档编辑过程中、其他 INDEX 操作处理过程中无法排序。
- 未信任工作区时，无法使用创建、整理、删除操作。请在 VS Code 中信任该工作区。
- "INDEX 已更新，请重新拖动"：这是刚刚应用了其他更改。请再操作一次。
- 起始页（根目录的 `README.md`）无法移动。

## 显示"有未保存的更改"

目标文件正在 VS Code 的编辑器中编辑。请先保存或放弃更改，然后重试。

## 无法重命名

以下名称不可使用。

- 以 `.` 开头的名称、`i18n`、Windows 的保留名称（如 `CON`）
- 以句点或空格结尾的名称，含有控制字符或文件名中不可使用字符的名称
- 同一文件夹中已存在的名称（包括仅大小写不同的名称）
- 不带 Markdown 扩展名的文档名

## 已保存但 Git 中没有出现更改，或未被提交

Lunascape Docs 只写入文件，不进行 Git 的暂存或提交。请在 VS Code 的源代码管理视图中确认，并根据需要提交。
