# 报告问题

无法解决的问题，请附上以下信息进行报告。文档正文和机密信息只在必要范围内共享。

## 报告中应包含的信息

| 项目 | 确认方法 |
|---|---|
| Lunascape Docs 的版本 | 在扩展视图中打开"Lunascape Docs"即可看到 |
| VS Code 的版本 | 菜单中的 [帮助] → [关于] |
| 操作系统 | macOS、Windows、Linux 及其版本 |
| 文档根目录的构成 | `lunascape-docs.json` 的内容、文件夹结构的概要、是否使用 Standard Pack |
| 重现步骤 | 按什么顺序做了哪些操作 |
| 预期结果与实际结果 | 显示的消息请原样附上全文 |
| 翻译问题时 | 输出面板中"Lunascape Docs 翻訳"的内容 |

> **提示**
>
> - 显示方面的问题，可在命令面板中执行"Developer: Open Webview Developer Tools"，确认控制台是否有错误。
> - Web 版的问题，请一并附上浏览器的种类和版本，以及试图打开的 URL。

## 报告地址

请在 [Issues](https://github.com/gu-corp/lunascape-user-guide/issues) 中报告。
