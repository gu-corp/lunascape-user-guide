# 遇到问题时

请根据症状查找对应的页面。先尝试下面的基本处理，有时问题即可解决。

## 首先尝试

1. 按工具栏中的 [重新加载]。
2. 如果有正在编辑的 Markdown 文件，在 VS Code 中保存。
3. 在命令面板中执行“Developer: Reload Window”。
4. 在扩展视图中确认 Lunascape Docs 是否为最新版本（[安装扩展](../01-introduction/install.md)）。

## 按症状查找

| 症状 | 参考页面 |
|---|---|
| 找不到文档根目录、文档未出现在 INDEX 中、INDEX 消失、链接无法打开 | [文档不显示](viewer.md) |
| 图、公式、图片不显示或出现错误 | [图・公式・图片不显示](rendering.md) |
| 没有 [编辑]、无法保存、无法排序或重命名 | [无法编辑・保存・排序](editing.md) |
| 无法执行检查、无法保存规则、模板或翻译出现错误 | [检查・创建・翻译不顺利](tools.md) |
| Web 版无法打开仓库、无法登录 | [Web 版无法打开・无法登录](web.md) |
| 仍未解决 | [报告故障](report.md) |
