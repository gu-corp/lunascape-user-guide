# 检查、创建或翻译失败

## 检查

### 显示"无法使用 docs-lint"

- 扩展中不包含 docs-lint 的运行环境，或者设置有问题。请重新安装扩展。
- "若要安全加载本地 Pack 和设置，请在 VS Code 中信任此工作区"：使用本地的 Standard Pack 需要受信任的工作区。

### 结果一直显示"需要重新检查"

修改文档或设置后，上次的结果即失效。请再次按 [检查文档根目录]。未保存的修改不会反映。

### 按了提示项却打不开

"整个文档根目录"的项目不与特定文档关联，因此没有位置信息。请按照提示内容确认相应的文档。

### 无法保存规则

- 需要受信任的工作区。
- "Lint 设置已被其他操作修改"：`docs-lint.config.json` 在外部被修改。请加载最新状态后重试。
- 无法编辑符号链接，以及文档根目录以外的设置文件。

## 从模板创建

- "模板的预览已过期""输入内容已更改"：请再次按 [预览] 后创建。
- "保存位置的文档已存在"：不会覆盖已有文件。请指定其他保存位置。
- 保存位置需要相对于文档根目录的路径，以及 `.md` / `.mdx` 扩展名。无法在 `i18n` 下创建。
- "若要创建文档，请信任工作区"：请在 VS Code 中信任工作区。

## 翻译

### 翻译按钮无法按下

- "此文档根目录未启用 AI 翻译"：请将 `lunascape-docs.json` 的 `translation.enabled` 设为 `true`。
- "未设置项目默认语言"：请在[更改显示设置](../02-reading/display-settings.md)中保存默认语言。
- "请将翻译目标添加到支持的语言中"：请将目标语言加入 `locales`。
- "找不到要翻译的正本文档"：当前打开的是翻译版页面。请切换到默认语言的页面。
- 临时的文件夹显示状态下无法使用批量翻译。请在该文件夹中放置 `lunascape-docs.json`，使其成为文档根目录。

### 翻译方案被拒绝，或被要求重新生成

- "正本文档已更改。请重新生成翻译方案"：生成翻译方案后，正本或翻译目标发生了变更。请重新翻译。
- 如果语言模型的响应中缺少应受保护的标识符或代码，则不会被接受。响应的内容可在输出面板的"Lunascape Docs 翻訳"中确认。
- "批量翻译每次最多 1000 个文档"：请按文件夹或明确选择来划分范围。
