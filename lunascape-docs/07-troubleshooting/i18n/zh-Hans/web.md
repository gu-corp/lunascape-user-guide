# Web 版无法打开或无法登录

## 已登录，但仓库未出现在列表中

该账户未安装 GitHub App「Lunascape Docs」，或者目标仓库不在安装范围内。请按照[浏览私有仓库](../06-web/private-repository.md)中的步骤，请仓库所有者或组织管理员安装。

## 无法通过登录界面

- 您没有目标仓库的读取权限。请向仓库所有者申请授予权限。
- 「本站点未配置 GitHub 登录」：您自行部署的查看器未配置登录服务。需要由管理员配置登录服务。

## 登录用的弹出窗口无法打开

浏览器拦截了弹出窗口。请允许本站点弹出窗口后重试。

## 显示「登录已过期」

登录已过期。请再次点击 [使用 GitHub 登录]。

## 打开公开仓库时出现 404

- 请确认 `owner/repo@ref/dir` 的写法。
- 无法指定包含 `/` 的分支名。

## 过一段时间后无法加载

在未登录的状态下，会受到 GitHub API 的使用限制（每小时 60 次）。如果显示「已达到次数限制」，请稍候片刻，或使用 [使用 GitHub 登录]。

## 显示「本站点无法显示该仓库」

要从您自行部署的查看器中打开，需要在仓库端 `lunascape-docs.json` 的 `viewer.origins` 中添加该站点的 URL。

## 打开 `index.html` 后什么都不显示

通过 `file://` 直接打开时无法运行。请通过 HTTP 服务器打开，或使用 VS Code 版。

## 导出的站点显示「找不到 lunascape-docs-manifest.json」

请将 `npm run export:web` 输出的整套文件（包含清单文件）原样部署。

## 无法保存草稿

- 「无法打开 IndexedDB」「正在其他标签页中使用」：原因是浏览器的隐私模式，或有其他标签页打开了同一站点。请在普通窗口中打开，并关闭其他标签页。
- 草稿按设备和浏览器分别保存，不会同步到其他设备。
