# Feilsøking

Finn siden som passer til symptomet ditt. Ofte løses problemet ved å prøve de grunnleggende trinnene nedenfor først.

## Prøv dette først

1. Trykk på [Last inn på nytt] på verktøylinjen.
2. Hvis du redigerer en Markdown-fil, lagrer du den i VS Code.
3. Kjør «Developer: Reload Window» fra kommandopaletten.
4. Kontroller i utvidelsesvisningen at Lunascape Docs er oppdatert (se [Installere utvidelsen](../01-introduction/install.md)).

## Finn etter symptom

| Symptom | Side |
|---|---|
| Ingen dokumentrot blir funnet, dokumenter mangler i INDEX, INDEX er forsvunnet, lenker åpnes ikke | [Dokumenter vises ikke](viewer.md) |
| Diagrammer, matematikk eller bilder vises ikke eller gir feil | [Diagrammer, matematikk eller bilder vises ikke](rendering.md) |
| Ingen [Rediger]-knapp, kan ikke lagre, kan ikke endre rekkefølge eller gi nytt navn | [Kan ikke redigere, lagre eller endre rekkefølge](editing.md) |
| Kontroller kjører ikke, regler kan ikke lagres, maler eller oversettelse gir feil | [Kontroll, oppretting eller oversettelse mislykkes](tools.md) |
| Web-visningen kan ikke åpne et repositorium eller logge på | [Web-visningen kan ikke åpne eller logge på](web.md) |
| Fortsatt ikke løst | [Rapportere et problem](report.md) |
