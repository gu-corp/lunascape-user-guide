# Rapportere en feil

Hvis du ikke får løst et problem, meld fra om det med følgende informasjon. Del innholdet i dokumenter og konfidensiell informasjon bare i den grad det er nødvendig.

## Hva du skal ta med

| Element | Slik finner du det |
|---|---|
| Versjon av Lunascape Docs | Åpne «Lunascape Docs» i utvidelsesvisningen |
| Versjon av VS Code | [Hjelp] → [Om] i menyen |
| OS | macOS, Windows eller Linux, og versjonen |
| Oppbygningen av dokumentroten | Innholdet i `lunascape-docs.json`, en oversikt over mappestrukturen, om en Standard Pack brukes |
| Fremgangsmåte for å gjenskape feilen | Hva du gjorde, i rekkefølge |
| Forventet og faktisk resultat | Gjengi eventuelle meldinger i sin helhet, slik de vises |
| Ved oversettelsesproblemer | Innholdet i utdatakanalen «Lunascape Docs 翻訳» |

> **Tips**
>
> - Ved visningsproblemer kan «Developer: Open Webview Developer Tools» i kommandopaletten vise om konsollen rapporterer feil.
> - Ved problemer med webviseren, ta også med nettleseren og versjonen og URL-en du forsøkte å åpne.

## Hvor du melder fra

Meld fra i [Issues](https://github.com/gu-corp/lunascape-user-guide/issues).
