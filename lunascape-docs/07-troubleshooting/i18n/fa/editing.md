# ویرایش، ذخیره یا تغییر ترتیب ممکن نیست

## دکمهٔ [ویرایش] وجود ندارد

- [دکمهٔ ویرایش] در [تنظیمات نمایش] خاموش است. آن را روشن کنید، یا از [⋯] ← [ویرایش] در بالا سمت راست متن، یا از منوی مورد در INDEX ← [ویرایش] استفاده کنید.
- اگر `editor.showEditButton` در `lunascape-docs.json` برابر `false` باشد نیز همین وضعیت پیش می‌آید.
- هنگام نمایش راهنما ویرایش ممکن نیست. راهنما را ببندید.

## تغییر به نمای دیداری ممکن نیست

«این سند دارای نحو MDX است، بنابراین نمی‌توان به صفحهٔ ویرایش معمولی تغییر داد»: سندهایی که نحو ویژهٔ MDX (مؤلفه‌ها، `import` و مانند آن) دارند، برای حفظ این نحو فقط در نمای Markdown ویرایش می‌شوند.

## ویرایش مستقیم فرمول ریاضی یا نمودار ممکن نیست

نمای دیداری نتیجهٔ ترسیم را نشان می‌دهد. در صفحهٔ ویرایش [Markdown] را فشار دهید و کد منبع را ویرایش کنید.

## تغییر ترتیب یا کشیدن ممکن نیست

- هنگام فیلتر کردن، هنگام ویرایش سند و هنگام اجرای عملیات دیگری در INDEX، تغییر ترتیب ممکن نیست.
- وقتی فضای کاری مورد اعتماد نباشد، عملیات ایجاد، سازمان‌دهی و حذف در دسترس نیست. فضای کاری را در VS Code مورد اعتماد کنید.
- «INDEX به‌روزرسانی شده است. دوباره بکشید»: تغییر دیگری همین حالا اعمال شده است. عملیات را دوباره انجام دهید.
- صفحهٔ آغازین (`README.md` ریشه) جابه‌جا نمی‌شود.

## پیام «تغییرات ذخیره‌نشده وجود دارد» نمایش داده می‌شود

پروندهٔ موردنظر در ویرایشگر VS Code در حال ویرایش است. ابتدا آن را ذخیره کنید یا تغییرات را دور بیندازید، سپس دوباره تلاش کنید.

## تغییر نام ممکن نیست

نام‌های زیر قابل استفاده نیستند.

- نام‌هایی که با `.` آغاز می‌شوند، `i18n` و نام‌های رزرو‌شدهٔ Windows (مانند `CON`)
- نام‌هایی که به نقطه یا فاصله ختم می‌شوند، و نام‌هایی که نویسه‌های کنترلی یا نویسه‌های غیرمجاز در نام پرونده دارند
- نام‌هایی که از پیش در همان پوشه وجود دارند (از جمله نام‌هایی که فقط در بزرگی و کوچکی حروف تفاوت دارند)
- نام سندهایی که پسوند Markdown ندارند

## با وجود ذخیره کردن، تغییری در Git دیده نمی‌شود یا کامیت نمی‌شود

Lunascape Docs فقط در پرونده می‌نویسد و مرحله‌بندی (staging) یا کامیت در Git انجام نمی‌دهد. در نمای کنترل منبع VS Code بررسی کنید و در صورت نیاز کامیت کنید.
