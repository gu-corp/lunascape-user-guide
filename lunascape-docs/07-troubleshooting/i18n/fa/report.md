# گزارش یک مشکل

برای مشکلی که نمی‌توانید برطرف کنید، آن را همراه با اطلاعات زیر گزارش دهید. محتوای سند یا اطلاعات محرمانه را فقط تا حدی که لازم است به اشتراک بگذارید.

## اطلاعاتی که باید در گزارش بیاید

| مورد | روش بررسی |
|---|---|
| نسخهٔ Lunascape Docs | با باز کردن «Lunascape Docs» در نمای افزونه‌ها نمایش داده می‌شود |
| نسخهٔ VS Code | [راهنما] ← [درباره] در منو |
| سیستم‌عامل | macOS، Windows یا Linux و نسخهٔ آن |
| ساختار ریشهٔ مستندات | محتوای `lunascape-docs.json`، طرح کلی ساختار پوشه‌ها، وجود یا نبود Standard Pack |
| مراحل بازتولید | چه کاری را به چه ترتیبی انجام دادید |
| نتیجهٔ مورد انتظار و نتیجهٔ واقعی | پیامی که نمایش داده شد، به‌طور کامل و عیناً |
| در صورت وجود مشکل در ترجمه | محتوای «Lunascape Docs 翻訳» در پنل خروجی |

> **نکته**
>
> - در مشکلات مربوط به نمایش، با «Developer: Open Webview Developer Tools» در پنل فرمان می‌توانید بررسی کنید که آیا خطایی در کنسول گزارش شده است یا نه.
> - در مشکلات نسخهٔ وب، نوع و نسخهٔ مرورگر و نشانی اینترنتی‌ای را که می‌خواستید باز کنید نیز اضافه کنید.
