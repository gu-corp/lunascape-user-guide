# رفع مشکل

صفحهٔ مربوط به نشانه‌ای که می‌بینید را پیدا کنید. اغلب با انجام کارهای پایه‌ای زیر مشکل برطرف می‌شود.

## ابتدا این‌ها را امتحان کنید

1. در نوار ابزار [بارگذاری مجدد] را بزنید.
2. اگر فایل Markdown در حال ویرایش دارید، آن را در VS Code ذخیره کنید.
3. در پنجرهٔ فرمان «Developer: Reload Window» را اجرا کنید.
4. در نمای افزونه‌ها بررسی کنید که Lunascape Docs به‌روز باشد ([نصب افزونه](../01-introduction/install.md)).

## جست‌وجو بر اساس نشانه

| نشانه | صفحهٔ مرجع |

| نمودار، فرمول ریاضی یا تصویر نمایش داده نمی‌شود یا خطا می‌دهد | [نمودار، فرمول ریاضی یا تصویر نمایش داده نمی‌شود](rendering.md) |
