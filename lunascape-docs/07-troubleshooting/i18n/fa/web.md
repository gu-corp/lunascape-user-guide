# نسخهٔ وب باز نمی‌شود یا ورود ممکن نیست

## وارد شده‌اید، اما مخزن در فهرست نیست

GitHub App «Lunascape Docs» روی آن حساب نصب نشده است، یا آن مخزن در فهرست نصب گنجانده نشده است. از مالک مخزن یا مدیر سازمان بخواهید طبق مراحل [خواندن مخزن خصوصی](../06-web/private-repository.md) آن را نصب کند.

## از صفحهٔ ورود جلوتر نمی‌روید

- دسترسی خواندن به آن مخزن را ندارید. از مالک مخزن بخواهید دسترسی بدهد.
- «ورود با GitHub برای این سایت پیکربندی نشده است»: در نمایشگری که خودتان مستقر کرده‌اید، سرویس ورود پیکربندی نشده است. مدیر باید سرویس ورود را تنظیم کند.

## پنجرهٔ بازشوی ورود باز نمی‌شود

مرورگر پنجرهٔ بازشو را مسدود کرده است. پنجره‌های بازشوی این سایت را مجاز کنید و دوباره تلاش کنید.

## پیام «ورود شما منقضی شده است» نمایش داده می‌شود

اعتبار ورود به پایان رسیده است. دوباره [ورود با GitHub] را فشار دهید.

## باز کردن مخزن عمومی به خطای ۴۰۴ می‌انجامد

- نگارش `owner/repo@ref/dir` را بررسی کنید.
- نام شاخه‌ای که شامل `/` باشد قابل تعیین نیست.

## پس از مدتی بارگذاری انجام نمی‌شود

بدون ورود، محدودیت استفاده از GitHub API (۶۰ بار در ساعت) اعمال می‌شود. اگر پیام «به محدودیت تعداد دفعات رسیدید» نمایش داده شد، مدتی صبر کنید یا با [ورود با GitHub] وارد شوید.

## پیام «این سایت نمی‌تواند این مخزن را نمایش دهد» نمایش داده می‌شود

برای باز کردن از نمایشگری که خودتان مستقر کرده‌اید، باید نشانی آن سایت را به `viewer.origins` در `lunascape-docs.json` سمت مخزن اضافه کنید.

## با باز کردن `index.html` چیزی نمایش داده نمی‌شود

اگر مستقیماً با `file://` باز شود کار نمی‌کند. آن را از طریق یک کارساز HTTP باز کنید یا از نسخهٔ VS Code استفاده کنید.

## در سایت برون‌بری‌شده پیام «lunascape-docs-manifest.json یافت نشد» نمایش داده می‌شود

مجموعهٔ کامل فایل‌هایی را که `npm run export:web` تولید می‌کند (شامل مانیفست) همان‌گونه که هست مستقر کنید.

## پیش‌نویس ذخیره نمی‌شود

- «IndexedDB باز نمی‌شود» / «در زبانهٔ دیگری در حال استفاده است»: علت آن حالت خصوصی مرورگر یا زبانهٔ دیگری است که همان سایت را باز کرده است. در پنجرهٔ عادی باز کنید و زبانه‌های دیگر را ببندید.
- پیش‌نویس‌ها برای هر دستگاه و هر مرورگر جداگانه ذخیره می‌شوند. به دستگاه دیگری منتقل نمی‌شوند.
