# 문서가 표시되지 않음

## "열 수 있는 Markdown 또는 docs 폴더를 찾을 수 없습니다"라고 표시됨

- 작업 영역에 `docs` 폴더가 없거나, `docs` 이외의 이름을 사용하고 있습니다.
  - `lunascape-docs.json` 을 해당 폴더에 두면 이름과 관계없이 문서 루트로 인식됩니다.
  - 또는 설정 `lunascapeDocEditor.rootDirectoryNames` 에 폴더 이름을 추가합니다.
- 문서가 아직 없는 경우에는 "Lunascape Docs: 템플릿에서 문서 만들기"로 작성합니다.
- Markdown 파일을 편집기에서 연 다음 "Lunascape Docs: 사양서 뷰어에서 열기"를 실행하는 방법도 있습니다.

## 문서가 INDEX에 표시되지 않음

- 확장자가 `.md`, `.markdown`, `.mdx` 인지 확인합니다.
- 다음 폴더는 표시되지 않습니다: `.` 으로 시작하는 폴더, `node_modules`, `ignoredDirectories` 에 지정한 폴더(기본값은 `99-archive`).
- `i18n/` 아래에 있는 번역본은 INDEX에 따로 표시되지 않습니다. 언어 메뉴에서 전환합니다.
- 방금 추가한 파일이 표시되지 않을 때는 [다시 불러오기]를 누릅니다.
- 다른 문서 루트를 보고 있을 수 있습니다. 도구 모음 왼쪽 끝의 문서 루트 이름을 확인합니다.

## 폴더를 눌러도 아무것도 표시되지 않음

해당 폴더의 `README.md` 가 front matter만 있고 본문이 없는 "설정 전용 기술자"입니다. INDEX에서 폴더를 열고 안에 있는 문서를 선택하세요.

## 의도하지 않은 문서 루트가 열림

- 설정 `lunascapeDocEditor.rootMode` 가 `fixed` 로 되어 있으면 항상 `lunascapeDocEditor.root` 가 열립니다.
- `auto` 에서는 연 Markdown 파일에 가장 가까운 문서 루트가 선택됩니다. 도구 모음 왼쪽 끝의 풀다운 메뉴에서 전환할 수 있습니다.

## 문서 루트의 이름이 예상과 다름

이름은 `lunascape-docs.json` 의 `title` → 루트 `README.md` 의 `navigation.title` → 그 H1 → `index.md` → 폴더 이름 순으로 결정됩니다. 고정하려면 `title` 을 설정합니다.

## INDEX가 사라짐

- 문서가 1개뿐인 문서 루트에서는 INDEX가 처음 한 번만 자동으로 닫힙니다. 도구 모음의 열 표시 아이콘으로 열 수 있습니다. [표시 설정]의 [문서가 1개뿐이면 자동으로 숨기기]에서 끌 수 있습니다.
- 화면이 좁을 때는 [뒤로] 왼쪽의 [INDEX 열기](세 줄)에서 엽니다.

## 링크를 눌러도 열리지 않음

- "링크 대상을 찾을 수 없습니다": 링크 대상 파일이 존재하지 않습니다. 문서 도구의 [검사]에서 내부 링크를 확인할 수 있습니다.
- "안전하지 않거나 지원되지 않는 링크를 열지 않았습니다": 문서 루트 밖이나 `https://` `mailto:` 이외의 스킴으로 연결된 링크는 열리지 않습니다.

## 표시되는 언어가 의도와 다름

- 언어 메뉴에서 표시 중인 페이지의 언어와 그 근거를 확인합니다.
- 지난번에 선택한 표시 언어가 기억되어 있습니다. 언어 메뉴에서 기본 언어를 다시 선택합니다.
- 개인 설정 `lunascapeDocEditor.locale` 이 설정되어 있으면 해당 언어의 번역본이 우선됩니다.
