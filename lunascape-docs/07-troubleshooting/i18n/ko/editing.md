# 편집·저장·정렬 순서 변경이 안 될 때

## [편집] 버튼이 없다

- [표시 설정]의 [편집 버튼]이 꺼져 있습니다. 켜거나, 본문 오른쪽 위의 [⋯] → [편집], 또는 INDEX 항목 메뉴 → [편집]을 사용합니다.
- `lunascape-docs.json`의 `editor.showEditButton`이 `false`인 경우에도 마찬가지입니다.
- 도움말을 표시하는 동안에는 편집할 수 없습니다. 도움말을 닫으십시오.

## 비주얼 표시로 전환할 수 없다

"이 문서에는 MDX 구문이 있어 일반 편집 화면으로 전환할 수 없습니다": MDX 고유의 구문(컴포넌트, `import` 등)이 포함된 문서는 구문을 유지하기 위해 Markdown 표시에서만 편집합니다.

## 수식이나 다이어그램을 직접 편집할 수 없다

비주얼 표시에서는 그려진 결과를 표시합니다. 편집 화면에서 [Markdown]을 누르고 소스를 편집하십시오.

## 정렬 순서 변경이나 드래그가 안 된다

- 필터링 중, 문서 편집 중, 다른 INDEX 조작을 처리하는 중에는 정렬 순서를 바꿀 수 없습니다.
- 작업 영역을 신뢰하지 않은 상태에서는 만들기·정리·삭제 조작을 사용할 수 없습니다. VS Code에서 작업 영역을 신뢰하십시오.
- "INDEX가 업데이트되었습니다. 다시 드래그하십시오": 다른 변경이 방금 반영되었습니다. 조작을 다시 수행합니다.
- 시작 페이지(루트의 `README.md`)는 이동할 수 없습니다.

## "저장하지 않은 변경 내용이 있습니다"라고 표시된다

대상 파일을 VS Code 편집기에서 편집하는 중입니다. 먼저 저장하거나 변경 내용을 취소한 다음 다시 시도하십시오.

## 이름을 변경할 수 없다

다음 이름은 사용할 수 없습니다.

- `.`으로 시작하는 이름, `i18n`, Windows의 예약된 이름(`CON` 등)
- 끝이 마침표 또는 공백인 이름, 제어 문자나 파일 이름에 사용할 수 없는 문자가 포함된 이름
- 같은 폴더에 이미 있는 이름(대문자와 소문자만 다른 이름을 포함합니다)
- Markdown 확장자가 없는 문서 이름

## 저장했는데 Git에 변경이 나타나지 않거나 커밋되지 않는다

Lunascape Docs는 파일에 쓰기만 하며, Git의 스테이징이나 커밋은 하지 않습니다. VS Code의 소스 제어 보기에서 확인하고 필요에 따라 커밋하십시오.
