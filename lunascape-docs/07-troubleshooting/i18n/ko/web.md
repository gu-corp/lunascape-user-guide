# 웹 버전에서 열리지 않거나 로그인할 수 없음

## 로그인해도 리포지토리가 목록에 표시되지 않음

해당 계정에 GitHub App "Lunascape Docs"가 설치되어 있지 않거나, 대상 리포지토리가 포함되어 있지 않습니다. 리포지토리 소유자 또는 조직 관리자에게 [비공개 리포지토리 열람하기](../06-web/private-repository.md)의 절차대로 설치를 요청하세요.

## 로그인 화면에서 더 진행할 수 없음

- 대상 리포지토리의 읽기 권한이 없습니다. 리포지토리 소유자에게 권한 부여를 요청하세요.
- "이 사이트에는 GitHub 로그인이 설정되어 있지 않습니다": 직접 배치한 뷰어에 로그인 서비스가 설정되어 있지 않습니다. 관리자가 로그인 서비스를 설정해야 합니다.

## 로그인용 팝업이 열리지 않음

브라우저가 팝업을 차단하고 있습니다. 이 사이트의 팝업을 허용한 다음 다시 시도하세요.

## "로그인이 만료되었습니다"라고 표시됨

로그인 유효 기간이 만료되었습니다. [GitHub으로 로그인]을 다시 누릅니다.

## 공개 리포지토리를 열면 404가 됨

- `owner/repo@ref/dir` 표기를 확인합니다.
- `/`가 포함된 브랜치 이름은 지정할 수 없습니다.

## 얼마 지나면 읽어 들이지 못하게 됨

로그인하지 않은 상태에서는 GitHub API 이용 제한(시간당 60회)이 있습니다. "횟수 제한에 도달했습니다"라고 표시되면 잠시 기다리거나 [GitHub으로 로그인]하세요.

## "이 사이트에서는 이 리포지토리를 표시할 수 없습니다"라고 표시됨

직접 배치한 뷰어에서 열려면, 리포지토리 쪽 `lunascape-docs.json`의 `viewer.origins`에 해당 사이트의 URL을 추가해야 합니다.

## `index.html`을 열어도 아무것도 표시되지 않음

`file://`로 직접 열면 동작하지 않습니다. HTTP 서버를 통해 열거나 VS Code 버전을 사용하세요.

## 내보낸 사이트에서 "lunascape-docs-manifest.json을 찾을 수 없습니다"라고 표시됨

`npm run export:web`으로 출력한 파일 일체(매니페스트 포함)를 그대로 배치하세요.

## 초안을 저장할 수 없음

- "IndexedDB를 열 수 없습니다", "다른 탭에서 사용 중입니다": 브라우저의 시크릿 모드나, 같은 사이트를 열어 둔 다른 탭이 원인입니다. 일반 창에서 열고 다른 탭을 닫으세요.
- 초안은 단말과 브라우저마다 저장됩니다. 다른 단말로는 이어지지 않습니다.
