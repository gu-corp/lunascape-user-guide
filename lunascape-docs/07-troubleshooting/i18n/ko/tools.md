# 검사·작성·번역이 잘 되지 않을 때

## 검사

### "docs-lint를 사용할 수 없습니다"라고 표시된다

- 확장 기능에 docs-lint 실행 환경이 포함되어 있지 않거나, 설정에 문제가 있습니다. 확장 기능을 다시 설치하십시오.
- "로컬 Pack과 설정을 안전하게 불러오려면 VS Code에서 이 작업 영역을 신뢰하십시오": 로컬 Standard Pack을 사용하려면 신뢰할 수 있는 작업 영역이 필요합니다.

### 결과가 "재검사 필요" 상태에서 바뀌지 않는다

문서나 설정을 변경하면 이전 결과는 무효가 됩니다. [문서 루트 검사]를 다시 누르십시오. 저장하지 않은 변경 내용은 반영되지 않습니다.

### 지적 사항을 눌러도 열리지 않는다

"문서 루트 전체" 항목은 특정 문서에 연결되어 있지 않으므로 위치를 가지지 않습니다. 지적 사항의 내용에 따라 해당하는 문서를 확인하십시오.

### 규칙을 저장할 수 없다

- 신뢰할 수 있는 작업 영역이 필요합니다.
- "Lint 설정이 다른 작업으로 변경되었습니다": `docs-lint.config.json`이 외부에서 변경되었습니다. 최신 상태를 불러온 후 다시 시도하십시오.
- 심볼릭 링크이거나 문서 루트 밖에 있는 설정 파일은 편집할 수 없습니다.

## 템플릿으로 작성

- "템플릿 미리 보기가 만료되었습니다", "입력 내용이 변경되었습니다": [미리 보기]를 다시 누른 후 작성하십시오.
- "저장할 위치에 문서가 이미 있습니다": 기존 파일은 덮어쓰지 않습니다. 다른 저장 위치를 지정하십시오.
- 저장 위치에는 문서 루트에서의 상대 경로와 `.md` / `.mdx` 확장자가 필요합니다. `i18n` 아래에는 작성할 수 없습니다.
- "문서를 작성하려면 작업 영역을 신뢰하십시오": VS Code에서 작업 영역을 신뢰하십시오.

## 번역

### 번역 버튼을 누를 수 없다

- "이 문서 루트에서는 AI 번역이 활성화되어 있지 않습니다": `lunascape-docs.json`의 `translation.enabled`를 `true`로 설정하십시오.
- "프로젝트 기본 언어가 설정되어 있지 않습니다": [표시 설정 변경하기](../02-reading/display-settings.md)에서 기본 언어를 저장하십시오.
- "지원 언어에 번역 대상을 추가하십시오": 번역 대상 언어를 `locales`에 추가하십시오.
- "번역할 정본 문서를 찾을 수 없습니다": 번역판 페이지를 열고 있습니다. 기본 언어 페이지로 전환하십시오.
- 일시적인 폴더 표시에서는 일괄 번역을 사용할 수 없습니다. 해당 폴더에 `lunascape-docs.json`을 두어 문서 루트로 만드십시오.

### 번역안이 거부되거나 다시 만들라는 요청이 나온다

- "정본 문서가 변경되었습니다. 번역안을 다시 만드십시오": 번역안을 만든 후에 정본 또는 번역 대상이 변경되었습니다. 다시 번역하십시오.
- 언어 모델의 응답에 보호해야 할 식별자나 코드가 빠져 있으면 받아들여지지 않습니다. 응답 내용은 출력 패널의 "Lunascape Docs 번역"에서 확인할 수 있습니다.
- "일괄 번역은 한 번에 1000개 문서까지입니다": 폴더나 직접 선택으로 범위를 나누십시오.
