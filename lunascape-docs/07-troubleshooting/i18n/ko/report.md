# 문제 신고하기

해결되지 않는 문제는 다음 정보와 함께 신고해 주세요. 문서 본문이나 기밀 정보는 필요한 범위만 공유해 주세요.

## 신고에 포함할 정보

| 항목 | 확인 방법 |
|---|---|
| Lunascape Docs 버전 | 확장 보기에서 "Lunascape Docs"를 열면 표시됩니다 |
| VS Code 버전 | 메뉴의 [도움말] → [정보] |
| OS | macOS, Windows, Linux와 그 버전 |
| 문서 루트의 구성 | `lunascape-docs.json`의 내용, 폴더 구성의 개요, Standard Pack 사용 여부 |
| 재현 절차 | 무엇을 어떤 순서로 조작했는지 |
| 예상한 결과와 실제 결과 | 표시된 메시지는 전문을 그대로 |
| 번역 문제인 경우 | 출력 패널의 "Lunascape Docs 翻訳" 내용 |

> **힌트**
>
> - 표시 문제에서는 명령 팔레트의 "Developer: Open Webview Developer Tools"로 콘솔에 오류가 나오는지 확인할 수 있습니다.
> - Web 뷰어 문제에서는 브라우저의 종류와 버전, 열려고 한 URL도 함께 알려 주세요.
