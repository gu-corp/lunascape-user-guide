# 문제가 생겼을 때

증상에 해당하는 페이지를 찾아보세요. 먼저 다음 기본적인 대처를 시도하면 해결되는 경우가 있습니다.

## 먼저 시도할 것

1. 도구 모음의 [다시 불러오기]를 누릅니다.
2. 편집 중인 Markdown 파일이 있으면 VS Code에서 저장합니다.
3. 명령 팔레트에서 "Developer: Reload Window"를 실행합니다.
4. 확장 보기에서 Lunascape Docs가 최신 버전인지 확인합니다([확장 설치하기](../01-introduction/install.md)).

## 증상으로 찾기

| 증상 | 참조 페이지 |
|---|---|
| 문서 루트를 찾을 수 없음, 문서가 INDEX에 표시되지 않음, INDEX가 사라짐, 링크가 열리지 않음 | [문서가 표시되지 않는다](viewer.md) |
| 다이어그램, 수식, 이미지가 표시되지 않거나 오류가 남 | [다이어그램·수식·이미지가 표시되지 않는다](rendering.md) |
| [편집]이 없음, 저장할 수 없음, 정렬 순서 변경이나 이름 바꾸기를 할 수 없음 | [편집·저장·정렬 순서 변경을 할 수 없다](editing.md) |
| 검사를 실행할 수 없음, 규칙을 저장할 수 없음, 템플릿이나 번역에서 오류가 남 | [검사·작성·번역이 잘 되지 않는다](tools.md) |
| 웹 버전에서 리포지토리를 열 수 없음, 로그인할 수 없음 | [웹 버전에서 열 수 없다·로그인할 수 없다](web.md) |
| 해결되지 않음 | [문제를 보고한다](report.md) |
