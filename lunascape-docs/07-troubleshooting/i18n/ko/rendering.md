# 다이어그램·수식·이미지가 표시되지 않음

## TikZ 다이어그램이 접힌 소스로 표시됨

- 배포판 확장 기능에는 TikZ 렌더링 엔진이 포함되어 있지 않습니다. 정상적인 표시입니다.
- 개발·평가 목적이라면 신뢰할 수 있는 작업 영역 바로 아래에 `node-tikzjax` 1.0.5를 설치하고, 설정 `lunascapeDocEditor.tikz.runtime`을 `workspace`로 지정하면 렌더링됩니다.
- 웹 브라우저 버전에서는 TikZ가 렌더링되지 않습니다.

## 수식이 문자 그대로 표시됨

- 구분 기호를 확인합니다. 인라인은 `$...$` 또는 `\(...\)`, 독립된 수식은 `$$...$$` 또는 `\[...\]`입니다.
- 인라인 코드나 코드 블록 안의 `$`는 수식이 되지 않습니다.
- `$5 and $10`처럼 금액으로 보이는 표기는 수식으로 처리하지 않습니다.
- 매우 큰 수식이나 매크로 확장이 많은 수식은 상한(`maxSize: 50`, `maxExpand: 1000`)을 넘으면 렌더링되지 않습니다. 나누어 주세요.

## 다이어그램에 “렌더링할 수 없습니다”라고 표시됨

- Mermaid, Vega-Lite, WaveDrom 등의 오류 메시지에 구문 문제가 표시됩니다. 편집 화면의 [Markdown]에서 소스를 확인합니다.
- Vega-Lite: 데이터는 `data.values` 또는 `datasets`에 포함시킵니다. 외부 URL의 데이터나 이미지 마크는 사용할 수 없습니다.
- WaveDrom: 엄격한 JSON으로 작성합니다. JavaScript 형식(따옴표 없는 키 등)은 사용할 수 없습니다.
- Penrose: 맨 앞의 `@preset set-theory`와 허용된 문(`Set`, `Subset`, `Disjoint`, `Intersecting`, `AutoLabel All`)만 사용합니다.
- “생성된 SVG에 안전하지 않은 참조가 있습니다”, “생성된 SVG가 상한을 초과했습니다”: 외부 리소스를 참조하는 다이어그램이나 너무 큰 다이어그램은 표시되지 않습니다. 내용을 줄이거나 참조를 제거합니다.

## 이미지가 표시되지 않음

- 이미지 경로는 문서를 기준으로 한 상대 경로로 지정합니다. 문서 루트 바깥에 있는 이미지는 표시되지 않습니다.
- `<img>`의 `width`에는 숫자만 지정합니다(`width="360"`).

## 내보낸 웹사이트에서 다이어그램이 표시되지 않음

TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose의 렌더링 라이브러리는 표시할 때 불러옵니다. 내보낸 사이트에는 `vendor/` 폴더도 함께 배치해 주세요.
