# 図・数式・画像が表示されない

## TikZ 図が折りたたまれたソースになる

- 配布版の拡張機能には TikZ の描画エンジンが同梱されていません。これは正常な表示です。
- 開発・評価目的では、信頼済みワークスペースの直下に `node-tikzjax` 1.0.5 をインストールし、設定 `lunascapeDocEditor.tikz.runtime` を `workspace` にすると描画できます。
- Web ブラウザ版では TikZ は描画されません。

## 数式が文字のまま表示される

- 区切り記号を確認します。インラインは `$...$` または `\(...\)`、独立した数式は `$$...$$` または `\[...\]` です。
- インラインコードやコードブロックの中の `$` は数式になりません。
- `$5 and $10` のような金額らしい書きかたは数式にしません。
- 非常に大きい数式やマクロ展開の多い数式は、上限（`maxSize: 50`、`maxExpand: 1000`）を超えると描画されません。分割してください。

## 図が「描画できません」になる

- Mermaid、Vega-Lite、WaveDrom などのエラーメッセージに、構文の問題が示されます。編集画面の [Markdown] でソースを確認します。
- Vega-Lite: データは `data.values` または `datasets` に埋め込みます。外部 URL のデータや画像マークは使えません。
- WaveDrom: 厳密な JSON で記述します。JavaScript 形式（引用符なしのキーなど）は使えません。
- Penrose: 先頭の `@preset set-theory` と、許可された文（`Set`、`Subset`、`Disjoint`、`Intersecting`、`AutoLabel All`）だけを使います。
- 「生成SVGに安全でない参照があります」「生成されたSVGが上限を超えています」: 外部リソースへの参照を含む図や、大きすぎる図は表示されません。内容を減らすか、参照を取り除きます。

## 画像が表示されない

- 画像のパスは、文書からの相対パスで指定します。文書ルートの外にある画像は表示されません。
- `<img>` の `width` は数値だけを指定します（`width="360"`）。

## 書き出した Web サイトで図が表示されない

TikZ、Vega-Lite、Markmap、WaveDrom、Svgbob、Penrose の描画ライブラリは表示時に読み込まれます。書き出したサイトには `vendor/` フォルダも一緒に配置してください。
