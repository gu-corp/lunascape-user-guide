# 文書が表示されない

## 「開けるMarkdownまたはdocsフォルダが見つかりません」と表示される

- ワークスペースに `docs` フォルダがないか、`docs` 以外の名前を使っています。
  - `lunascape-docs.json` をそのフォルダに置くと、名前に関係なく文書ルートとして認識されます。
  - または、設定 `lunascapeDocEditor.rootDirectoryNames` にフォルダ名を追加します。
- 文書がまだない場合は、「Lunascape Docs: テンプレートからドキュメントを作成」で作成します。
- Markdown ファイルをエディターで開いてから、「Lunascape Docs: 仕様書ビューアーで開く」を実行する方法もあります。

## 文書が INDEX に表示されない

- 拡張子が `.md`、`.markdown`、`.mdx` であることを確認します。
- 次のフォルダは表示されません: `.` で始まるフォルダ、`node_modules`、`ignoredDirectories` に指定したフォルダ（既定は `99-archive`）。
- `i18n/` の下にある翻訳版は、INDEX に個別には表示されません。言語メニューから切り替えます。
- 追加したばかりのファイルが表示されないときは、[再読み込み] を押します。
- 別の文書ルートを見ている可能性があります。ツールバー左端の文書ルート名を確認します。

## フォルダを押しても何も表示されない

そのフォルダの `README.md` が、front matter だけで本文がない「設定専用の記述子」です。INDEX でフォルダを開き、中の文書を選んでください。

## 意図しない文書ルートが開く

- 設定 `lunascapeDocEditor.rootMode` が `fixed` になっていると、常に `lunascapeDocEditor.root` が開きます。
- `auto` では、開いた Markdown ファイルに最も近い文書ルートが選ばれます。ツールバー左端のプルダウンで切り替えられます。

## 文書ルートの名前が期待と違う

名前は、`lunascape-docs.json` の `title` → ルート `README.md` の `navigation.title` → その H1 → `index.md` → フォルダ名の順で決まります。固定したい場合は `title` を設定します。

## INDEX が消えた

- 文書が 1 件だけの文書ルートでは、INDEX が初回だけ自動的に閉じます。ツールバーのカラム表示アイコンで開けます。[表示設定] の [文書が1件なら自動的に隠す] でオフにできます。
- 画面が狭いときは、[戻る] の左の [INDEXを開く]（三本線）から開きます。

## リンクを押しても開かない

- 「リンク先が見つかりません」: リンク先のファイルが存在しません。文書ツールの [チェック] で内部リンクを確認できます。
- 「安全でない、または未対応のリンクを開きませんでした」: 文書ルートの外や、`https://` `mailto:` 以外のスキームへのリンクは開きません。

## 表示される言語が意図と違う

- 言語メニューで、表示中のページの言語と根拠を確認します。
- 前回選んだ表示言語は記憶されています。言語メニューで既定言語を選び直します。
- 個人設定 `lunascapeDocEditor.locale` が設定されていると、その言語の翻訳版が優先されます。
