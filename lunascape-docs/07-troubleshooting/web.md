# Web 版で開けない・ログインできない

## ログインしてもリポジトリが一覧に表示されない

そのアカウントに GitHub App「Lunascape Docs」がインストールされていないか、対象リポジトリに含まれていません。リポジトリのオーナーまたは組織の管理者に、[非公開リポジトリを閲覧する](../06-web/private-repository.md) の手順でインストールを依頼してください。

## サインイン画面から先に進めない

- 対象リポジトリの読み取り権限がありません。リポジトリのオーナーに権限の付与を依頼してください。
- 「このサイトには GitHub ログインが設定されていません」: 自分で配置したビューアーに、ログインサービスが設定されていません。管理者がログインサービスを設定する必要があります。

## ログイン用のポップアップが開かない

ブラウザがポップアップをブロックしています。このサイトのポップアップを許可してから、もう一度お試しください。

## 「ログインが切れています」と表示される

ログインの有効期限が切れました。もう一度 [GitHub でログイン] を押します。

## 公開リポジトリを開くと 404 になる

- `owner/repo@ref/dir` の表記を確認します。
- `/` を含むブランチ名は指定できません。

## しばらくすると読み込めなくなる

ログインしていない状態では、GitHub API の利用制限（1 時間あたり 60 回）があります。「回数制限に達しました」と表示されたら、しばらく待つか、[GitHub でログイン] してください。

## 「このサイトからは、このリポジトリを表示できません」と表示される

自分で配置したビューアーから開くには、リポジトリ側の `lunascape-docs.json` の `viewer.origins` に、そのサイトの URL を追加する必要があります。

## `index.html` を開いても何も表示されない

`file://` で直接開いた場合は動作しません。HTTP サーバー経由で開くか、VS Code 版を使ってください。

## 書き出したサイトで「lunascape-docs-manifest.json が見つかりません」と表示される

`npm run export:web` で出力したファイル一式（マニフェストを含む）を、そのまま配置してください。

## 下書きが保存できない

- 「IndexedDB を開けません」「他のタブで使用中です」: ブラウザのプライベートモードや、同じサイトを開いている別のタブが原因です。通常のウィンドウで開き、他のタブを閉じてください。
- 下書きは端末とブラウザごとに保存されます。別の端末には引き継がれません。
