# 不具合を報告する

解決しない問題は、次の情報を添えて報告してください。文書の本文や機密情報は、必要な範囲だけを共有してください。

## 報告に含める情報

| 項目 | 確認方法 |
|---|---|
| Lunascape Docs のバージョン | 拡張機能ビューで「Lunascape Docs」を開くと表示されます |
| VS Code のバージョン | メニューの [ヘルプ] → [バージョン情報] |
| OS | macOS、Windows、Linux とそのバージョン |
| 文書ルートの構成 | `lunascape-docs.json` の内容、フォルダ構成の概要、Standard Pack の有無 |
| 再現手順 | 何をどの順で操作したか |
| 期待した結果と実際の結果 | 表示されたメッセージは、全文をそのまま |
| 翻訳の問題の場合 | 出力パネルの「Lunascape Docs 翻訳」の内容 |

> **ヒント**
>
> - 表示の問題では、コマンドパレットの「Developer: Open Webview Developer Tools」で、コンソールにエラーが出ていないか確認できます。
> - Web 版の問題では、ブラウザの種類とバージョン、開こうとした URL（`?source=` の値）も添えてください。

## 報告先

[Issues](https://github.com/gu-corp/lunascape-user-guide/issues) に報告してください。
