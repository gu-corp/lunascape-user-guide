# 編集・保存・並び替えができない

## [編集] ボタンがない

- [表示設定] の [編集ボタン] がオフになっています。オンにするか、本文右上の [⋯] → [編集]、または INDEX の項目メニュー → [編集] を使います。
- `lunascape-docs.json` の `editor.showEditButton` が `false` の場合も同様です。
- ヘルプの表示中は編集できません。ヘルプを閉じてください。

## ビジュアル表示に切り替えられない

「この文書にはMDX構文があるため通常の編集画面へ切り替えられません」: MDX 固有の構文（コンポーネント、`import` など）を含む文書は、構文を保つために Markdown 表示だけで編集します。

## 数式や図を直接編集できない

ビジュアル表示では描画結果を表示します。編集画面で [Markdown] を押して、ソースを編集してください。

## 並び替えやドラッグができない

- 絞り込み中、文書の編集中、別の INDEX 操作の処理中は並び替えできません。
- ワークスペースを信頼していないときは、作成・整理・削除の操作が使えません。VS Code でワークスペースを信頼してください。
- 「INDEXが更新されています。もう一度ドラッグしてください」: 別の変更が反映された直後です。もう一度操作します。
- 開始ページ（ルートの `README.md`）は移動できません。

## 「未保存の変更があります」と表示される

対象のファイルが VS Code のエディターで編集中です。先に保存するか、変更を破棄してからやり直してください。

## 名前を変更できない

次の名前は使えません。

- `.` で始まる名前、`i18n`、Windows の予約名（`CON` など）
- 末尾がピリオドまたは空白の名前、制御文字やファイル名に使えない文字を含む名前
- 同じフォルダに既にある名前（大文字小文字だけが異なる名前を含みます）
- Markdown の拡張子を持たない文書名

## 保存したのに Git に変更が出ない・コミットされない

Lunascape Docs はファイルに書き込むだけで、Git のステージングやコミットは行いません。VS Code のソース管理ビューで確認し、必要に応じてコミットしてください。
