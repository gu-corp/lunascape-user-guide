# 困ったときは

症状から該当するページを探してください。まず次の基本的な対処を試すと、解決することがあります。

## 最初に試すこと

1. ツールバーの [再読み込み] を押します。
2. 編集中の Markdown ファイルがあれば、VS Code で保存します。
3. コマンドパレットで「Developer: Reload Window」を実行します。
4. 拡張機能ビューで、Lunascape Docs が最新版か確認します（[拡張機能をインストールする](../01-introduction/install.md)）。

## 症状から探す

| 症状 | 参照ページ |
|---|---|
| 文書ルートが見つからない、文書が INDEX に出てこない、INDEX が消えた、リンクが開かない | [文書が表示されない](viewer.md) |
| 図、数式、画像が表示されない、エラーになる | [図・数式・画像が表示されない](rendering.md) |
| [編集] がない、保存できない、並び替えや名前変更ができない | [編集・保存・並び替えができない](editing.md) |
| チェックが実行できない、ルールを保存できない、テンプレートや翻訳でエラーになる | [チェック・作成・翻訳がうまくいかない](tools.md) |
| Web 版でリポジトリを開けない、ログインできない | [Web 版で開けない・ログインできない](web.md) |
| 解決しない | [不具合を報告する](report.md) |
