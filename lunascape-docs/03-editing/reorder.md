# 文書の並び順を変更する

INDEX に表示される順番は、ドラッグ＆ドロップまたはキーボードで変更できます。変更した順番は、文書の front matter に `navigation.order` として保存されます。

## ドラッグ＆ドロップで並び替える

1. INDEX で文書またはフォルダをドラッグします。
2. 同じ階層の前後、またはフォルダの上でドロップします。
   同じ階層内では順番が変わります。別のフォルダにドロップすると、そのフォルダへ移動します。

## キーボードやメニューで並び替える

- INDEX の項目にフォーカスを置き、`Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` を押します。
- 項目メニューの [1つ上へ移動] / [1つ下へ移動] を選びます。

## 保存される内容

- 同じ階層で並び替えたときは、正本の文書の front matter にある `navigation.order` を更新します。フォルダの場合は、そのフォルダの `README.md` に書き込みます。`README.md` がないフォルダでは、front matter だけの `README.md` を作成します。
- 別のフォルダへ移動したときは、正本と対応する翻訳版をまとめて移動します。移動の前に、相対リンクへの影響について確認が表示されます。
- Git のステージングやコミットは行いません。

> **ご注意**
>
> - 絞り込み中、文書の編集中、信頼していないワークスペースでは並び替えできません。
> - 「INDEXが更新されています」と表示されたときは、別の変更が反映された直後です。もう一度操作してください。
> - 開始ページは別のフォルダへ移動できません。

> **ヒント**
>
> `navigation.order` は 100、200、300 のように 100 刻みで付けると、あとから間に差し込みやすくなります。詳しくは [ナビゲーション情報を設定する](../04-document-tools/navigation-metadata.md) を参照してください。
