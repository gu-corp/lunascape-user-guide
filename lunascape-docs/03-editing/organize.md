# 文書やフォルダを作成・整理する

INDEX の項目メニューから、文書やフォルダの作成、複製、名前の変更、削除を行えます。入力はビューアー内の小さなダイアログで行い、閲覧を中断しません。

> **ご注意**
>
> これらの操作は、VS Code でワークスペースを信頼している場合にだけ使えます。文書の編集中、別の操作の処理中、対象に未保存の変更があるときは実行できません。

## 文書やフォルダを作成する

1. 作成先のフォルダの項目メニュー（[⋯] または右クリック）を開きます。
   文書ルート直下に作成するときは、INDEX の見出し右端の [⋯] か、INDEX の空白部分を右クリックします。
2. [新しい文書] または [新しいフォルダ] を選びます。
3. 名前を入力し、[作成] を押します。
   文書名には Markdown の拡張子（`.md`、`.markdown`、`.mdx` など）が必要です。

新しい文書は、既定言語の文書（正本）として作成されます。

## 文書を複製する

1. 文書の項目メニューを開き、[複製] を選びます。
2. 新しい名前を入力し、[作成] を押します。

複製されるのは正本だけです。翻訳版は複製されません。

## タイトルを変更する

文書の見出し（H1）を変更します。ファイル名は変わりません。

1. 文書またはフォルダの項目メニューを開き、[タイトルを変更] を選びます。
2. 新しいタイトルを 1 行で入力し、[変更] を押します。

フォルダの場合は、そのフォルダの `README.md` の見出しを変更します。表示中の言語が翻訳版のときは、その言語の文書のタイトルが変わります。

## 文書名を変更する

ツールバーに出ている文書名（文書ルートの名前）を変えます。

1. ツールバーの文書名を右クリックします。INDEX 見出し右端の [⋯] からでも開けます。
2. [文書名を変更] を選び、新しい名前を入力します。

設定していないときは、フォルダ名がそのまま表示されます。

変更した名前は、**いま文書名として使われている場所**に書き込みます。表示に使われていない場所へ書いて、見えている見出しが無視される状態にはしません。

| いまの状態 | 書き込む先 |
|---|---|
| `lunascape-docs.json` に名前がある | `lunascape-docs.json` を更新します |
| 名前はないが、文書ルートに README がある | README の見出し（H1）を書き換えます |
| どちらもない | `lunascape-docs.json` を作成して保存します |

どちらに書き込んだかは、変更後のメッセージに表示されます。

> **ヒント**
>
> 文書名は、`lunascape-docs.json` の名前 → 文書ルート README の見出し → フォルダ名 の順に決まります。

## ファイル名やフォルダ名を変更する

1. 項目メニューを開き、[ファイル名を変更] または [フォルダ名を変更] を選びます。
2. 新しい名前を入力し、[変更] を押します。

対応する翻訳版（`i18n/<言語>/` の下の同じパス）も一緒に変更されます。

## 削除する

1. 項目メニューを開き、[ゴミ箱へ移動] を選びます。
2. 確認メッセージの内容を確かめて、移動を承認します。

対象は OS のゴミ箱へ移動するため、必要なら復元できます。翻訳版は削除されず、そのまま残ります。

## 名前に使えないもの

- `.` で始まる名前（INDEX に表示されないため）
- `i18n`（翻訳ファイル用に予約）
- Windows で予約されている名前（`CON`、`PRN` など）
- 末尾がピリオドまたは空白になる名前
- 制御文字や、ファイル名に使用できない文字
- 同じフォルダに既にある名前（大文字小文字だけが異なる名前を含みます）

> **ご注意**
>
> 開始ページ（通常はルートの `README.md`）の名前変更や移動はできません。先に `lunascape-docs.json` の `startPage` を変更してください。
