# 文書を編集する

文書はビューアーの中でそのまま編集できます。編集画面には、見たまま編集する「ビジュアル表示」と「Markdown ソース表示」があり、1 つのボタンで切り替えます。

## 編集を始める

次のいずれかを押します。どれも同じ編集画面が開きます。

- 本文右下の [編集]
- 本文右上の [⋯]（その他の操作）→ [編集]
- INDEX の項目メニュー → [編集]

## 編集する

1. 本文を直接編集します。
   編集画面上部のツールバーで、段落書式（本文、見出し 1〜4、引用、コード）、[太字]、[斜体]、[箇条書き]、[番号付きリスト]、[リンク]、[表を挿入]、[画像サイズ]、[元に戻す]、[やり直す] を使えます。
2. Markdown ソースを直接編集したいときは、[Markdown] を押します。
   もう一度押すとビジュアル表示に戻ります。最後に使った表示は記憶され、次に [編集] を押したときに復元されます。
3. [保存] を押します。
   Markdown ファイルに書き込まれ、閲覧表示に戻ります。やめるときは [キャンセル] を押します。

> **ご注意**
>
> - 保存はファイルへの書き込みだけを行います。Git のステージングやコミットは自動では行いません。
> - 数式、Mermaid、TikZ、Vega-Lite などの図は、ビジュアル表示では描画結果を表示します。内容を変更するには [Markdown] に切り替えます。
> - MDX 固有の構文（コンポーネントや `import` など）を含む文書は、構文を保つために Markdown 表示だけで編集します。
> - front matter（先頭の `---` で囲まれた設定）は、ビジュアル表示で編集しても保持されます。

> **ヒント**
>
> - [VS Codeで開く] を押すと、通常のテキストエディターで開けます。テキストエディターで保存すると、ビューアーの表示も自動的に更新されます。
> - [編集] ボタンを表示したくないときは、[表示設定] の [編集ボタン] をオフにします。プロジェクト全体で非表示にするには、`lunascape-docs.json` の `editor.showEditButton` を `false` にします。
> - 最初に開く表示（ビジュアル／Markdown）の既定は、設定 `lunascapeDocEditor.editor.defaultMode` または `lunascape-docs.json` の `editor.defaultMode` で変更できます。
