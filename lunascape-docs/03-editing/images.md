# 画像のサイズを調整する

文書に貼った画像は、本文の幅と画面の高さに合わせて自動的に収まります。特定の大きさで見せたい画像には、幅を指定できます。

## 自動調整のしくみ

- 通常の Markdown 画像（`![説明](./images/screen.png)`）は、本文の幅に収まるように縮小されます。元の画像より大きく拡大されることはありません。
- 縦長のスクリーンショットは、画面の高さの 72% または 720px のどちらか小さいほうまでに収まります。

## 編集画面で幅を指定する

1. [編集] を押し、ビジュアル表示で画像を選択します。
2. ツールバーの [画像サイズ] から幅を選びます。
3. [保存] を押します。

| 選択肢 | 幅 |
|---|---|
| [自動] | 指定なし（自動調整） |
| [小 (360px)] | 360px |
| [中 (560px)] | 560px |
| [大 (760px)] | 760px |
| [本文幅 (920px)] | 920px |
| [任意…] | 16〜4096px の任意の整数 |

## Markdown で幅を指定する

HTML の `img` タグに数値の `width` を指定します。GitHub や MDX でも同じように表示される書きかたです。

```html
<img src="./images/screen.png" alt="設定画面" width="360" />
```

> **ご注意**
>
> - `width` には数値だけを指定します。`px` や `%` は付けません。本文の幅より大きい値を指定しても、表示は本文の幅に収まります。
> - 画像は文書からの相対パスで指定します。文書ルートの外にある画像は表示されません。
