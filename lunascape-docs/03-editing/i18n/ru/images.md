# Изменение размера изображений

Изображение, вставленное в документ, автоматически подгоняется под ширину текста и высоту экрана. Для изображения, которое должно иметь определенный размер, можно задать ширину.

## Как работает автоматическая подгонка

- Обычное изображение Markdown (`![описание](./images/screen.png)`) уменьшается так, чтобы уместиться по ширине текста. Оно никогда не увеличивается сверх исходного размера.
- Вытянутый по высоте снимок экрана ограничивается 72% высоты экрана или 720px — в зависимости от того, что меньше.

## Задание ширины в редакторе

1. Нажмите [Редактировать] и выберите изображение в визуальном режиме.
2. Выберите ширину из списка [Размер изображения] на панели инструментов.
3. Нажмите [Сохранить].

| Вариант | Ширина |
|---|---|
| [Автоматически] | Не задана (автоматическая подгонка) |
| [Маленькая (360px)] | 360px |
| [Средняя (560px)] | 560px |
| [Большая (760px)] | 760px |
| [Ширина текста (920px)] | 920px |
| [Произвольная…] | Любое целое число от 16 до 4096px |

## Задание ширины в Markdown

Укажите для HTML-тега `img` числовое значение `width`. При такой записи изображение так же отображается на GitHub и в MDX.

```html
<img src="./images/screen.png" alt="Экран настроек" width="360" />
```

> **Примечание**
>
> - В `width` указывается только число, без `px` или `%`. Даже если задать значение больше ширины текста, при отображении изображение уместится по ширине текста.
> - Путь к изображению указывается относительно документа. Изображения, находящиеся за пределами корня документации, не отображаются.
