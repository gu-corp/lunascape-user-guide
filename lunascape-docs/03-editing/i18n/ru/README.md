# Редактирование документа

Документы можно редактировать прямо в средстве просмотра. В редакторе есть «визуальное отображение», где вы редактируете то, что видите, и «отображение исходного кода Markdown»; переключение между ними выполняется одной кнопкой.

## Начало редактирования

Нажмите любой из следующих элементов. Все они открывают один и тот же редактор.

- [Редактировать] в правом нижнем углу документа
- [⋯] (Другие действия) в правом верхнем углу документа → [Редактировать]
- Меню элемента в INDEX → [Редактировать]

## Редактирование

1. Редактируйте текст напрямую.
   На панели инструментов в верхней части редактора доступны формат абзаца (основной текст, заголовки 1–4, цитата, код), [Полужирный], [Курсив], [Маркированный список], [Нумерованный список], [Ссылка], [Вставить таблицу], [Размер изображения], [Отменить] и [Повторить].
2. Чтобы редактировать исходный код Markdown напрямую, нажмите [Markdown].
   Нажмите ещё раз, чтобы вернуться к визуальному отображению. Последнее использованное отображение запоминается и восстанавливается при следующем нажатии [Редактировать].
3. Нажмите [Сохранить] (сохранить также можно с помощью Ctrl+S / ⌘S).
   Данные записываются в файл Markdown, и происходит возврат к режиму чтения. Чтобы прекратить редактирование и вернуться к последнему сохранённому содержимому, нажмите [Отменить правки].

## Всегда начинать с редактора (режим редактирования)

Нажмите [Режим редактирования] на панели инструментов, чтобы включить его: с этого момента каждый документ открывается в редакторе. Используйте это, когда пишете непрерывно, как в блокноте.

- Пока он включён, нажатие [Сохранить] не закрывает редактор. [Отменить правки] возвращает к последнему сохранённому содержимому и оставляет редактор открытым.
- Нажмите ещё раз, чтобы выключить его и вернуться к режиму чтения. Включённое/выключенное состояние запоминается для каждого пользователя.
- Он не отображается для корня документации, в который нельзя записывать (например, доступный только для чтения источник на GitHub).

## Несохранённые правки

Правки, которые вы не сохранили, автоматически сохраняются на этом устройстве. Переход к другому документу, а также закрытие вкладки или окна не приводят к их потере.

- [Не сохранено] в редакторе означает, что текст отличается от последнего сохранённого содержимого.
- При следующем открытии того же документа работа продолжается с сохранённых правок, о чём выводится сообщение. Если сам документ с тех пор изменился, об этом также сообщается; [Отменить правки] возвращает к последней версии.
- Сохранённые правки исчезают при нажатии [Сохранить] или [Отменить правки]. Так как сохранение не выполнено, они не появляются в Git или среди черновиков.

> **Примечание**
>
> - Сохранение только записывает файл. Индексирование и фиксация в Git никогда не выполняются автоматически.
> - Формулы и схемы, такие как Mermaid, TikZ и Vega-Lite, отображаются как результат отрисовки в визуальном отображении. Чтобы изменить их содержимое, переключитесь на [Markdown].
> - Документы, содержащие синтаксис, специфичный для MDX (компоненты, `import` и т. п.), редактируются только в отображении Markdown, чтобы сохранить этот синтаксис.
> - Front matter (блок настроек, заключённый в строки `---` в начале) сохраняется при редактировании в визуальном отображении.

> **Совет**
>
> - Нажатие [Открыть в VS Code] открывает файл в обычном текстовом редакторе. При сохранении там отображение в средстве просмотра обновляется автоматически.
> - Чтобы скрыть кнопку [Редактировать], выключите [Кнопка редактирования] в [Параметры отображения]. Чтобы скрыть её для всего проекта, задайте `editor.showEditButton` значение `false` в `lunascape-docs.json`.
> - Отображение, открываемое первым (визуальное или Markdown), по умолчанию можно изменить с помощью настройки `lunascapeDocEditor.editor.defaultMode` или `editor.defaultMode` в `lunascape-docs.json`.
