# Редактирование документа

Документы можно редактировать прямо в средстве просмотра. В окне редактирования есть визуальный режим, где вы правите текст так, как он выглядит, и режим исходного кода Markdown; переключение между ними выполняется одной кнопкой.

## Начало редактирования

Нажмите любой из следующих элементов. Все они открывают одно и то же окно редактирования.

- [Редактировать] в правом нижнем углу документа
- [⋯] (Другие действия) в правом верхнем углу документа → [Редактировать]
- Меню элемента в INDEX → [Редактировать]

## Редактирование

1. Правьте текст напрямую.
   На панели инструментов в верхней части окна редактирования доступны формат абзаца (обычный текст, заголовки 1–4, цитата, код), [Полужирный], [Курсив], [Маркированный список], [Нумерованный список], [Ссылка], [Вставить таблицу], [Размер изображения], [Отменить], [Повторить].
2. Чтобы править исходный код Markdown напрямую, нажмите [Markdown].
   Повторное нажатие возвращает визуальный режим. Последний использованный режим запоминается и восстанавливается при следующем нажатии кнопки [Редактировать].
3. Нажмите [Сохранить].
   Изменения записываются в файл Markdown, и происходит возврат в режим просмотра. Чтобы отказаться от изменений, нажмите [Отмена].

> **Примечание**
>
> - При сохранении выполняется только запись в файл. Индексирование и фиксация в Git автоматически не выполняются.
> - Формулы и схемы, такие как Mermaid, TikZ и Vega-Lite, в визуальном режиме отображаются в готовом виде. Чтобы изменить их содержимое, переключитесь в режим [Markdown].
> - Документы, содержащие синтаксис, специфичный для MDX (компоненты, `import` и т. п.), редактируются только в режиме Markdown, чтобы сохранить этот синтаксис.
> - Front matter (блок настроек в начале файла, ограниченный строками `---`) сохраняется и при редактировании в визуальном режиме.

> **Совет**
>
> - Нажатие [Открыть в VS Code] открывает файл в обычном текстовом редакторе. При сохранении в текстовом редакторе содержимое в средстве просмотра обновляется автоматически.
> - Если кнопку [Редактировать] показывать не нужно, отключите параметр [Кнопка редактирования] в разделе [Параметры отображения]. Чтобы скрыть ее для всего проекта, задайте для `editor.showEditButton` в файле `lunascape-docs.json` значение `false`.
> - Режим, открываемый первым (визуальный или Markdown), по умолчанию задается параметром `lunascapeDocEditor.editor.defaultMode` либо параметром `editor.defaultMode` в файле `lunascape-docs.json`.
