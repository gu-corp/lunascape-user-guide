# Создание и упорядочивание документов и папок

Из меню элемента в INDEX можно создавать, дублировать, переименовывать и удалять документы и папки. Ввод выполняется в небольшом диалоговом окне внутри средства просмотра и не прерывает чтение.

> **Примечание**
>
> Эти действия доступны только тогда, когда рабочая область в VS Code отмечена как надежная. Они не выполняются во время редактирования документа, во время обработки другой операции, а также если в целевом объекте есть несохраненные изменения.

## Создание документа или папки

1. Откройте меню элемента ([⋯] или щелчок правой кнопкой мыши) той папки, в которой нужно создать объект.
   Чтобы создать объект непосредственно в корне документации, используйте [⋯] у правого края заголовка INDEX или щелкните правой кнопкой мыши пустое место в INDEX.
2. Выберите [Новый документ] или [Новая папка].
3. Введите имя и нажмите [Создать].
   Имя документа должно содержать расширение Markdown (`.md`, `.markdown`, `.mdx` и т. п.).

Новый документ создается как документ на языке по умолчанию (исходный документ).

## Дублирование документа

1. Откройте меню элемента документа и выберите [Дублировать].
2. Введите новое имя и нажмите [Создать].

Дублируется только исходный документ. Переводы не дублируются.

## Изменение заголовка

Изменяется заголовок документа (H1). Имя файла остается прежним.

1. Откройте меню элемента документа или папки и выберите [Изменить заголовок].
2. Введите новый заголовок одной строкой и нажмите [Изменить].

Для папки изменяется заголовок ее файла `README.md`. Если отображается перевод, изменяется заголовок документа на этом языке.

## Изменение имени документа

Изменяется имя документа, показанное на панели инструментов (имя корня документации).

1. Щелкните правой кнопкой мыши имя документа на панели инструментов. То же меню открывается через [⋯] у правого края заголовка INDEX.
2. Выберите [Изменить имя документа] и введите новое имя.

Пока имя не задано, отображается имя папки без изменений.

Заданное имя записывается **туда, откуда имя документа берется сейчас**, чтобы видимый заголовок не оказался проигнорированным.

| Текущее состояние | Куда записывается |
|---|---|
| Имя задано в `lunascape-docs.json` | Обновляется `lunascape-docs.json` |
| Имени нет, но в корне документации есть README | Переписывается заголовок README (H1) |
| Нет ни того, ни другого | Создается `lunascape-docs.json`, и имя сохраняется в нем |

Сообщение, появляющееся после изменения, указывает, куда была выполнена запись.

> **Совет**
>
> Имя документа определяется в таком порядке: имя в `lunascape-docs.json`, затем заголовок README в корне документации, затем имя папки.

## Изменение имени файла или папки

1. Откройте меню элемента и выберите [Изменить имя файла] или [Изменить имя папки].
2. Введите новое имя и нажмите [Изменить].

Соответствующие переводы (тот же путь в `i18n/<язык>/`) переименовываются вместе с ним.

## Удаление

1. Откройте меню элемента и выберите [Переместить в корзину].
2. Проверьте содержание сообщения с подтверждением и подтвердите перемещение.

Объект перемещается в корзину операционной системы, поэтому при необходимости его можно восстановить. Переводы не удаляются и остаются на месте.

## Недопустимые имена

- Имена, начинающиеся с `.` (они не отображаются в INDEX)
- `i18n` (зарезервировано для файлов перевода)
- Имена, зарезервированные в Windows (`CON`, `PRN` и т. п.)
- Имена, заканчивающиеся точкой или пробелом
- Имена с управляющими символами или символами, недопустимыми в именах файлов
- Имена, уже имеющиеся в той же папке (включая имена, различающиеся только регистром букв)

> **Примечание**
>
> Начальную страницу (обычно `README.md` в корне) нельзя переименовать или переместить. Сначала измените `startPage` в `lunascape-docs.json`.
