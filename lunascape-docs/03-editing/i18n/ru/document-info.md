# Отображение сведений о документе

«Таблицу управления документом» в начале документа (таблица с ID документа, версией, датой обновления, состоянием и т. д.) при чтении собирается в компактную строку «сведения о документе». Сам Markdown остается обычной таблицей, поэтому нормально читается и на GitHub.

## Условия отображения

Сразу после заголовка (H1) поместите таблицу из двух столбцов, как показано ниже.

```markdown
# Функциональные требования

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- Условие — наличие строки с ID документа и нескольких полей управления.
- Также распознается таблица, помещенная под заголовком `## 文書管理` или `## Document information`.
- Таблицы в середине текста и обычные таблицы вида «пункт/значение» не преобразуются.

## Как это отображается

- При чтении мелким шрифтом показываются только состояние и дата обновления.
- Нажмите строку, чтобы показать все поля.
- При печати показываются все поля.
- В режиме редактирования таблица отображается как обычная и доступна для редактирования.

> **Совет**
>
> Чтобы таблица всегда отображалась вместо сворачивания, отключите параметр [Свернуть сведения о документе] в разделе [Параметры отображения].
