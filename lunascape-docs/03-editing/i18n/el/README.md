# Επεξεργασία εγγράφου

Τα έγγραφα μπορούν να επεξεργαστούν απευθείας μέσα στο πρόγραμμα προβολής. Η οθόνη επεξεργασίας έχει μια «οπτική προβολή», όπου επεξεργάζεστε αυτό που βλέπετε, και μια «προβολή πηγαίου κώδικα Markdown»· ένα κουμπί εναλλάσσει μεταξύ τους.

## Ξεκινήστε την επεξεργασία

Πατήστε οποιοδήποτε από τα παρακάτω. Όλα ανοίγουν την ίδια οθόνη επεξεργασίας.

- [Επεξεργασία] κάτω δεξιά στο κείμενο
- [⋯] (Περισσότερες ενέργειες) πάνω δεξιά στο κείμενο → [Επεξεργασία]
- Μενού στοιχείου του INDEX → [Επεξεργασία]

## Επεξεργασία

1. Επεξεργαστείτε το κείμενο απευθείας.
   Στη γραμμή εργαλείων στο επάνω μέρος της οθόνης επεξεργασίας μπορείτε να χρησιμοποιήσετε τη μορφή παραγράφου (σώμα κειμένου, επικεφαλίδες 1–4, παράθεση, κώδικας), [Έντονα], [Πλάγια], [Λίστα με κουκκίδες], [Αριθμημένη λίστα], [Σύνδεσμος], [Εισαγωγή πίνακα], [Μέγεθος εικόνας], [Αναίρεση], [Επανάληψη].
2. Όταν θέλετε να επεξεργαστείτε απευθείας τον πηγαίο κώδικα Markdown, πατήστε [Markdown].
   Πατήστε το ξανά για να επιστρέψετε στην οπτική προβολή. Η προβολή που χρησιμοποιήσατε τελευταία απομνημονεύεται και επαναφέρεται την επόμενη φορά που θα πατήσετε [Επεξεργασία].
3. Πατήστε [Αποθήκευση] (μπορείτε επίσης να αποθηκεύσετε με Ctrl+S / ⌘S).
   Γράφεται στο αρχείο Markdown και επιστρέφετε στην προβολή ανάγνωσης. Για να σταματήσετε την επεξεργασία και να επιστρέψετε στο περιεχόμενο που αποθηκεύτηκε τελευταία, πατήστε [Discard edits].

## Να ξεκινάτε πάντα από την οθόνη επεξεργασίας (λειτουργία επεξεργασίας)

Πατήστε [Λειτουργία επεξεργασίας] στη γραμμή εργαλείων για να την ενεργοποιήσετε: από τότε, κάθε φορά που ανοίγετε ένα έγγραφο, ξεκινάτε από την οθόνη επεξεργασίας. Χρησιμοποιήστε την όταν γράφετε συνεχώς, όπως σε ένα σημειωματάριο.

- Όσο είναι ενεργή, το πάτημα [Αποθήκευση] δεν κλείνει την οθόνη επεξεργασίας. Το [Discard edits] επιστρέφει στο περιεχόμενο που αποθηκεύτηκε τελευταία και διατηρεί την οθόνη επεξεργασίας ανοιχτή.
- Πατήστε το ξανά για να την απενεργοποιήσετε και να επιστρέψετε στην προβολή ανάγνωσης. Η επιλογή ενεργό/ανενεργό απομνημονεύεται για κάθε χρήστη.
- Δεν εμφανίζεται σε μια ρίζα τεκμηρίωσης όπου δεν είναι δυνατή η εγγραφή (όπως ένα αποθετήριο GitHub μόνο για ανάγνωση).

## Μη αποθηκευμένες επεξεργασίες

Οι επεξεργασίες που δεν έχετε αποθηκεύσει διατηρούνται αυτόματα σε αυτήν τη συσκευή. Δεν χάνονται ούτε αν μεταβείτε σε άλλο έγγραφο ούτε αν κλείσετε την καρτέλα ή το παράθυρο.

- Το [Unsaved] στην οθόνη επεξεργασίας υποδεικνύει ότι υπάρχει διαφορά από το περιεχόμενο που αποθηκεύτηκε τελευταία.
- Την επόμενη φορά που θα ανοίξετε το ίδιο έγγραφο, συνεχίζει από τις διατηρημένες επεξεργασίες και σας το γνωστοποιεί. Αν το αρχικό έγγραφο έχει ενημερωθεί στο μεταξύ, σας το γνωστοποιεί κι αυτό. Με το [Discard edits] μπορείτε να επιστρέψετε στο πιο πρόσφατο περιεχόμενο.
- Οι διατηρημένες επεξεργασίες εξαφανίζονται με [Αποθήκευση] ή [Discard edits]. Δεν έχουν αποθηκευτεί, επομένως δεν εμφανίζονται στο Git ούτε στα πρόχειρα.

> **Σημείωση**
>
> - Η αποθήκευση εκτελεί μόνο εγγραφή στο αρχείο. Δεν εκτελεί αυτόματα staging ούτε commit στο Git.
> - Τα μαθηματικά και τα διαγράμματα όπως Mermaid, TikZ και Vega-Lite εμφανίζονται ως αποτέλεσμα απόδοσης στην οπτική προβολή. Για να αλλάξετε το περιεχόμενό τους, μεταβείτε στο [Markdown].
> - Τα έγγραφα που περιέχουν σύνταξη ειδική για MDX (στοιχεία, `import` κ.λπ.) επεξεργάζονται μόνο στην προβολή Markdown, ώστε να διατηρηθεί η σύνταξη.
> - Το front matter (οι ρυθμίσεις που περικλείονται από `---` στην αρχή) διατηρείται ακόμη κι όταν το επεξεργάζεστε στην οπτική προβολή.

> **Συμβουλή**
>
> - Πατώντας [VS Codeで開く] (Άνοιγμα στο VS Code) μπορείτε να το ανοίξετε σε έναν κανονικό επεξεργαστή κειμένου. Όταν αποθηκεύετε στον επεξεργαστή κειμένου, η προβολή στο πρόγραμμα προβολής ενημερώνεται επίσης αυτόματα.
> - Όταν δεν θέλετε να εμφανίζεται το κουμπί [Επεξεργασία], απενεργοποιήστε το [Κουμπί επεξεργασίας] στις [Ρυθμίσεις προβολής]. Για να το αποκρύψετε σε ολόκληρο το έργο, ορίστε το `editor.showEditButton` σε `false` στο `lunascape-docs.json`.
> - Η προεπιλεγμένη αρχική προβολή (οπτική / Markdown) μπορεί να αλλάξει με τη ρύθμιση `lunascapeDocEditor.editor.defaultMode` ή με το `editor.defaultMode` στο `lunascape-docs.json`.
