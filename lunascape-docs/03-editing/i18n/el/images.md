# Προσαρμογή του μεγέθους των εικόνων

Οι εικόνες που τοποθετείτε σε ένα έγγραφο προσαρμόζονται αυτόματα στο πλάτος του κειμένου και στο ύψος της οθόνης. Για μια εικόνα που θέλετε να εμφανίζεται σε συγκεκριμένο μέγεθος, μπορείτε να ορίσετε το πλάτος της.

## Πώς λειτουργεί η αυτόματη προσαρμογή

- Μια συνηθισμένη εικόνα Markdown (`![περιγραφή](./images/screen.png)`) σμικρύνεται ώστε να χωρέσει στο πλάτος του κειμένου. Δεν μεγεθύνεται ποτέ πέρα από το αρχικό της μέγεθος.
- Ένα στιγμιότυπο οθόνης σε κατακόρυφη διάταξη περιορίζεται στο 72% του ύψους της οθόνης ή στα 720px, όποιο είναι μικρότερο.

## Ορισμός του πλάτους στην επεξεργασία

1. Πατήστε [Επεξεργασία] και επιλέξτε την εικόνα στην οπτική προβολή.
2. Επιλέξτε πλάτος από το [Μέγεθος εικόνας] στη γραμμή εργαλείων.
3. Πατήστε [Αποθήκευση].

| Επιλογή | Πλάτος |
|---|---|
| [Αυτόματο] | Χωρίς ορισμό (αυτόματη προσαρμογή) |
| [Μικρό (360px)] | 360px |
| [Μεσαίο (560px)] | 560px |
| [Μεγάλο (760px)] | 760px |
| [Πλάτος κειμένου (920px)] | 920px |
| [Προσαρμοσμένο…] | Οποιοσδήποτε ακέραιος από 16 έως 4096px |

## Ορισμός του πλάτους σε Markdown

Δώστε στην ετικέτα HTML `img` μια αριθμητική τιμή `width`. Η γραφή αυτή εμφανίζεται με τον ίδιο τρόπο και στο GitHub και σε MDX.

```html
<img src="./images/screen.png" alt="Οθόνη ρυθμίσεων" width="360" />
```

> **Σημείωση**
>
> - Στο `width` δίνετε μόνο αριθμό, χωρίς `px` ή `%`. Ακόμη και με τιμή μεγαλύτερη από το πλάτος του κειμένου, η εικόνα εμφανίζεται στο πλάτος του κειμένου.
> - Οι εικόνες ορίζονται με σχετική διαδρομή ως προς το έγγραφο. Εικόνες εκτός της ρίζας τεκμηρίωσης δεν εμφανίζονται.
