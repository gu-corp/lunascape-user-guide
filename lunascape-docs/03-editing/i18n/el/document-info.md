# Εμφάνιση των στοιχείων του εγγράφου

Ο «πίνακας διαχείρισης εγγράφου» που τοποθετείται στην αρχή ενός εγγράφου (αναγνωριστικό εγγράφου, έκδοση, ημερομηνία ενημέρωσης, κατάσταση κ.ο.κ.) εμφανίζεται κατά την ανάγνωση συγκεντρωμένος σε μια μικρή γραμμή «Στοιχεία εγγράφου». Το ίδιο το Markdown παραμένει ένας συνηθισμένος πίνακας, επομένως διαβάζεται κανονικά και στο GitHub.

## Προϋποθέσεις για την εμφάνιση

Τοποθετήστε αμέσως μετά την επικεφαλίδα (H1) έναν πίνακα δύο στηλών όπως ο ακόλουθος.

```markdown
# Προδιαγραφές λειτουργικών απαιτήσεων

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- Προϋπόθεση είναι να υπάρχει η γραμμή «文書ID» και περισσότερα από ένα πεδία διαχείρισης.
- Αναγνωρίζεται επίσης ένας πίνακας που βρίσκεται κάτω από επικεφαλίδα `## 文書管理` ή `## Document information`.
- Πίνακες στη μέση του κειμένου, καθώς και συνηθισμένοι πίνακες «πεδίο / περιεχόμενο», δεν μετατρέπονται.

## Τρόπος εμφάνισης

- Κατά την ανάγνωση εμφανίζονται με μικρά γράμματα μόνο η κατάσταση και η ημερομηνία ενημέρωσης.
- Πατήστε τη γραμμή για να εμφανιστούν όλα τα πεδία.
- Κατά την εκτύπωση εμφανίζονται όλα τα πεδία.
- Στην οθόνη επεξεργασίας εμφανίζεται ως συνηθισμένος πίνακας και μπορείτε να τον επεξεργαστείτε ως έχει.

> **Συμβουλή**
>
> Αν θέλετε να εμφανίζεται πάντα ως πίνακας, χωρίς σύμπτυξη, απενεργοποιήστε το [Σύμπτυξη των στοιχείων του εγγράφου] στις [Ρυθμίσεις προβολής].
