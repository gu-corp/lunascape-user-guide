# 變更文件的排序

INDEX 中顯示的順序可以用拖放或鍵盤變更。變更後的順序會以 `navigation.order` 的形式儲存在文件的 front matter 中。

## 用拖放變更排序

1. 在 INDEX 中拖曳文件或資料夾。
2. 放在同一層級項目的前後，或放到資料夾上。
   在同一層級內會變更順序。放到其他資料夾時，會移動到該資料夾。

## 用鍵盤或選單變更排序

- 將焦點移到 INDEX 的項目上，按 `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓`。
- 在項目選單中選擇 [上移一項] / [下移一項]。

## 儲存的內容

- 在同一層級中變更排序時，會更新正本文件 front matter 中的 `navigation.order`。若是資料夾，則寫入該資料夾的 `README.md`。資料夾中沒有 `README.md` 時，會建立只有 front matter 的 `README.md`。
- 移動到其他資料夾時，會將正本與對應的翻譯版本一併移動。移動前會顯示確認訊息，說明對相對連結的影響。
- 不會執行 Git 的暫存或提交。

> **注意**
>
> - 篩選中、編輯文件中，以及在未信任的工作區中無法變更排序。
> - 顯示「INDEX 已更新」時，表示剛剛套用了其他變更。請再操作一次。
> - 起始頁面無法移動到其他資料夾。

> **提示**
>
> 將 `navigation.order` 設為 100、200、300 這樣以 100 為間隔的值，日後就容易在中間插入文件。詳情請參閱 [設定導覽資訊](../04-document-tools/navigation-metadata.md)。
