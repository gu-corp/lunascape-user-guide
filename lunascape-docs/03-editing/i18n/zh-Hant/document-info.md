# 顯示文件資訊

放在文件開頭的「文件管理表」（記載文件 ID、版本、更新日期、狀態等的表格），在閱讀時會彙整成一列精簡的「文件資訊」顯示。Markdown 本身仍是普通的表格，因此在 GitHub 上也能照常閱讀。

## 顯示的條件

在標題（H1）的正下方，放置如下的兩欄表格。

```markdown
# 功能需求定義書

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- 條件是要有「文書ID」列，並且有多個管理項目。
- 放在 `## 文書管理` 或 `## Document information` 標題下的表格也適用。
- 位於內文中間的表格，以及一般的「項目／內容」表格，不會被轉換。

## 顯示方式

- 閱讀時只以小字顯示「狀態」與「更新日期」。
- 按下該列即可顯示所有項目。
- 列印時會顯示所有項目。
- 在編輯畫面中會以一般表格顯示，可直接編輯。

> **提示**
>
> 若想不摺疊、始終以表格形式顯示，請在 [顯示設定] 中關閉 [摺疊文件資訊]。
