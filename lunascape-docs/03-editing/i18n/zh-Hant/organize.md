# 建立及整理文件與資料夾

您可以從 INDEX 的項目功能表建立、複製、重新命名及刪除文件與資料夾。輸入會在檢視器內的小型對話方塊中進行，不會中斷閱讀。

> **注意**
>
> 這些操作僅在 VS Code 中信任工作區時才能使用。編輯文件期間、其他操作處理期間，或對象有未儲存的變更時，皆無法執行。

## 建立文件或資料夾

1. 開啟目標資料夾的項目功能表（[⋯] 或按一下滑鼠右鍵）。
   若要直接在文件根目錄下建立，請使用 INDEX 標題右端的 [⋯]，或在 INDEX 的空白處按一下滑鼠右鍵。
2. 選擇 [新文件] 或 [新增資料夾]。
3. 輸入名稱，然後按 [建立]。
   文件名稱需要 Markdown 的副檔名（`.md`、`.markdown`、`.mdx` 等）。

新文件會以預設語言的文件（正本）建立。

## 建立文件的複本

1. 開啟文件的項目功能表，選擇 [建立複本]。
2. 輸入新名稱，然後按 [建立]。

只會複製正本，不會複製翻譯版本。

## 變更標題

變更文件的標題（H1）。檔案名稱不會改變。

1. 開啟文件或資料夾的項目功能表，選擇 [變更標題]。
2. 以一行輸入新標題，然後按 [變更]。

若為資料夾，則會變更該資料夾 `README.md` 的標題。當顯示中的語言為翻譯版本時，變更的是該語言文件的標題。

## 變更文件名稱

變更工具列上顯示的文件名稱（文件根目錄的名稱）。

1. 在工具列的文件名稱上按一下滑鼠右鍵。也可以從 INDEX 標題右端的 [⋯] 開啟。
2. 選擇 [變更文件名稱]，然後輸入新名稱。

尚未設定時，會直接顯示資料夾名稱。

變更後的名稱會寫入**目前作為文件名稱使用的位置**。不會寫入未用於顯示的位置，以免看得見的標題遭到忽略。

| 目前狀態 | 寫入位置 |
|---|---|
| `lunascape-docs.json` 中有名稱 | 更新 `lunascape-docs.json` |
| 沒有名稱，但文件根目錄有 README | 改寫 README 的標題（H1） |
| 兩者皆無 | 建立 `lunascape-docs.json` 並儲存 |

寫入了哪一處，會顯示在變更後的訊息中。

> **提示**
>
> 文件名稱的決定順序為：`lunascape-docs.json` 中的名稱 → 文件根目錄 README 的標題 → 資料夾名稱。

## 變更檔案名稱或資料夾名稱

1. 開啟項目功能表，選擇 [變更檔案名稱] 或 [變更資料夾名稱]。
2. 輸入新名稱，然後按 [變更]。

對應的翻譯版本（`i18n/<語言>/` 下的相同路徑）也會一併變更。

## 刪除

1. 開啟項目功能表，選擇 [移至資源回收筒]。
2. 確認訊息內容後，核准移動。

對象會移至作業系統的資源回收筒，必要時可以還原。翻譯版本不會被刪除，會原樣保留。

## 不能使用的名稱

- 以 `.` 開頭的名稱（因為不會顯示在 INDEX 中）
- `i18n`（保留給翻譯檔案使用）
- Windows 保留的名稱（`CON`、`PRN` 等）
- 結尾為句點或空白的名稱
- 含有控制字元或檔案名稱不可使用之字元的名稱
- 同一資料夾中已存在的名稱（包含僅大小寫不同的名稱）

> **注意**
>
> 起始頁面（通常是根目錄的 `README.md`）無法重新命名或移動。請先變更 `lunascape-docs.json` 的 `startPage`。
