# 調整圖片大小

貼入文件的圖片會自動配合內文的寬度與畫面的高度顯示。若某張圖片需要以特定大小呈現，可以指定其寬度。

## 自動調整的運作方式

- 一般的 Markdown 圖片（`![說明](./images/screen.png)`）會縮小到符合內文的寬度，不會放大超過原始圖片的大小。
- 直式的螢幕截圖會限制在畫面高度的 72% 或 720px，取兩者中較小的值。

## 在編輯畫面指定寬度

1. 按下 [編輯]，在視覺化檢視中選取圖片。
2. 從工具列的 [圖片大小] 選擇寬度。
3. 按下 [儲存]。

| 選項 | 寬度 |
|---|---|
| [自動] | 不指定（自動調整） |
| [小 (360px)] | 360px |
| [中 (560px)] | 560px |
| [大 (760px)] | 760px |
| [內文寬度 (920px)] | 920px |
| [自訂…] | 16〜4096px 之間的任意整數 |

## 在 Markdown 指定寬度

在 HTML 的 `img` 標籤上指定數值的 `width`。這種寫法在 GitHub 和 MDX 上也會以相同方式顯示。

```html
<img src="./images/screen.png" alt="設定畫面" width="360" />
```

> **請注意**
>
> - `width` 只能指定數值，不要加上 `px` 或 `%`。即使指定比內文寬度更大的值，顯示時仍會收在內文的寬度內。
> - 圖片以相對於文件的路徑指定。位於文件根目錄外的圖片不會顯示。
