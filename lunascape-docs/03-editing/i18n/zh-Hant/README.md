# 編輯文件

文件可以直接在檢視器中編輯。編輯畫面有所見即所得的「視覺表示」與「Markdown 原始碼表示」，用一個按鈕即可切換。

## 開始編輯

按下以下任一項，都會開啟同一個編輯畫面。

- 內文右下角的 [編輯]
- 內文右上角的 [⋯]（其他操作）→ [編輯]
- INDEX 的項目選單 →  [編輯]

## 進行編輯

1. 直接編輯內文。
   編輯畫面上方的工具列提供段落格式（內文、標題 1～4、引用、程式碼）、[粗體]、[斜體]、[項目符號清單]、[編號清單]、[連結]、[插入表格]、[圖片大小]、[復原]、[重做]。
2. 想直接編輯 Markdown 原始碼時，按下 [Markdown]。
   再按一次就會回到視覺表示。系統會記住您上次使用的表示，下次按下 [編輯] 時便會還原。
3. 按下 [儲存]（也可以用 Ctrl+S／⌘S 儲存）。
   內容會寫入 Markdown 檔案，並回到閱讀表示。若要停止編輯並回復到上次儲存的內容，請按 [取消編輯]。

## 一律從編輯畫面開始（編輯模式）

按下工具列的 [編輯模式] 將其開啟後，每次開啟文件都會從編輯畫面開始。適合像記事本一樣持續書寫時使用。

- 開啟期間，即使按下 [儲存]，編輯畫面也不會關閉。[取消編輯] 會回復到上次儲存的內容，並保持編輯畫面。
- 再按一次即可關閉，並回到閱讀表示。開啟／關閉的狀態會依使用者分別記住。
- 在無法寫入的文件根目錄（例如 GitHub 的唯讀來源）中不會顯示。

## 未儲存的編輯

未儲存的編輯會自動保留在這台裝置上。即使切換到其他文件、關閉分頁或視窗，都不會遺失。

- 編輯畫面的 [未儲存] 表示內容與上次儲存的內容有差異。
- 下次開啟同一份文件時，會從保留的編輯繼續，並提示您這一點。若原始文件在這之後有更新，也會一併提示。可用 [取消編輯] 回復到最新的內容。
- 保留的編輯會在按下 [儲存] 或 [取消編輯] 後消失。由於尚未儲存，因此不會出現在 Git 或草稿中。

> **請注意**
>
> - 儲存只會寫入檔案。不會自動進行 Git 的暫存或提交。
> - 數學式、Mermaid、TikZ、Vega-Lite 等圖表，在視覺表示中會顯示描繪結果。若要變更內容，請切換到 [Markdown]。
> - 含有 MDX 專屬語法（元件或 `import` 等）的文件，為保留其語法，只能在 Markdown 表示中編輯。
> - front matter（開頭以 `---` 圍起的設定）即使在視覺表示中編輯也會被保留。

> **提示**
>
> - 按下 [在 VS Code 中開啟]，即可用一般的文字編輯器開啟。在文字編輯器中儲存後，檢視器的顯示也會自動更新。
> - 若不想顯示 [編輯] 按鈕，請在 [顯示設定] 中關閉 [編輯按鈕]。若要在整個專案中隱藏，請將 `lunascape-docs.json` 的 `editor.showEditButton` 設為 `false`。
> - 最初開啟的表示（視覺／Markdown）預設值，可透過設定 `lunascapeDocEditor.editor.defaultMode` 或 `lunascape-docs.json` 的 `editor.defaultMode` 變更。
