# 編輯文件

文件可以直接在檢視器中編輯。編輯畫面分為所見即所得的「視覺化顯示」與「Markdown 原始碼顯示」，以一個按鈕切換。

## 開始編輯

按下下列任一項目，都會開啟相同的編輯畫面。

- 內文右下方的 [編輯]
- 內文右上方的 [⋯]（其他操作）→ [編輯]
- INDEX 的項目選單 →ic [編輯]

## 編輯

1. 直接編輯內文。
   編輯畫面上方的工具列可使用段落格式（本文、標題 1～4、引述、程式碼）、[粗體]、[斜體]、[項目符號清單]、[編號清單]、[連結]、[插入表格]、[圖片大小]、[復原]、[重做]。
2. 想要直接編輯 Markdown 原始碼時，請按 [Markdown]。
   再按一次即可回到視覺化顯示。系統會記住最後使用的顯示方式，下次按下 [編輯] 時即會還原。
3. 按 [儲存]。
   內容會寫入 Markdown 檔案，並回到閱讀顯示。若要中止，請按 [取消]。

> **請注意**
>
> - 儲存只會寫入檔案，不會自動執行 Git 的暫存或提交。
> - 數學式，以及 Mermaid、TikZ、Vega-Lite 等圖表，在視覺化顯示中會呈現繪製結果。若要變更其內容，請切換到 [Markdown]。
> - 含有 MDX 專屬語法（元件或 `import` 等）的文件，為了保留語法，只能在 Markdown 顯示中編輯。
> - front matter（開頭以 `---` 包圍的設定）在視覺化顯示中編輯時也會保留。

> **提示**
>
> - 按下 [在 VS Code 中開啟]，即可用一般的文字編輯器開啟。在文字編輯器中儲存後，檢視器的顯示也會自動更新。
> - 不想顯示 [編輯] 按鈕時，請關閉 [顯示設定] 的 [編輯按鈕]。若要在整個專案中隱藏，請將 `lunascape-docs.json` 的 `editor.showEditButton` 設為 `false`。
> - 最初開啟的顯示方式（視覺化／Markdown）預設值，可透過設定 `lunascapeDocEditor.editor.defaultMode` 或 `lunascape-docs.json` 的 `editor.defaultMode` 變更。
