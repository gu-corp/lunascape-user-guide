# نمایش اطلاعات سند

«جدول مدیریت سند» که در ابتدای سند قرار می‌گیرد (جدولی شامل شناسهٔ سند، نسخه، تاریخ به‌روزرسانی، وضعیت و مانند آن‌ها) هنگام خواندن به‌صورت یک سطر کوچک «اطلاعات سند» نمایش داده می‌شود. خودِ Markdown همان جدول معمولی باقی می‌ماند، بنابراین در GitHub نیز به‌همان شکل خوانده می‌شود.

## شرایط نمایش

بلافاصله پس از عنوان (H1)، جدولی دوستونی مانند زیر قرار دهید.

```markdown
# سند نیازمندی‌های عملکردی

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- شرط آن است که جدول سطر «文書ID» و چند قلم مدیریتی داشته باشد.
- جدولی که زیر عنوان `## 文書管理` یا `## Document information` قرار گیرد نیز شناسایی می‌شود.
- جدول‌های میان متن و جدول‌های معمولیِ «مورد/محتوا» تبدیل نمی‌شوند.

## نحوهٔ نمایش

- هنگام خواندن، فقط وضعیت و تاریخ به‌روزرسانی با قلم کوچک نمایش داده می‌شود.
- با فشردن سطر، همهٔ اقلام نمایش داده می‌شود.
- هنگام چاپ، همهٔ اقلام نمایش داده می‌شود.
- در صفحهٔ ویرایش، به شکل جدول معمولی نمایش داده می‌شود و می‌توانید همان‌جا آن را ویرایش کنید.

> **نکته**
>
> اگر می‌خواهید جدول همیشه بدون جمع شدن نمایش داده شود، در [تنظیمات نمایش] گزینهٔ [جمع کردن اطلاعات سند] را خاموش کنید.
