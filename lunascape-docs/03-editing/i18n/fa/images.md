# تنظیم اندازهٔ تصویر

تصویری که در سند قرار می‌دهید به‌طور خودکار در عرض متن و ارتفاع صفحه جا می‌گیرد. برای تصویری که می‌خواهید با اندازهٔ مشخصی دیده شود، می‌توانید عرض آن را تعیین کنید.

## نحوهٔ تنظیم خودکار

- تصویر معمولی Markdown (`![توضیح](./images/screen.png)`) تا اندازه‌ای کوچک می‌شود که در عرض متن جا بگیرد. هرگز بزرگ‌تر از اندازهٔ اصلی خود نمایش داده نمی‌شود.
- تصویر عمودی (اسکرین‌شات بلند) حداکثر تا ۷۲٪ ارتفاع صفحه یا ۷۲۰px، هرکدام کوچک‌تر باشد، محدود می‌شود.

## تعیین عرض در صفحهٔ ویرایش

1. [ویرایش] را بزنید و تصویر را در نمای دیداری انتخاب کنید.
2. از [اندازهٔ تصویر] در نوار ابزار، عرض را انتخاب کنید.
3. [ذخیره] را بزنید.

| گزینه | عرض |
|---|---|
| [خودکار] | تعیین‌نشده (تنظیم خودکار) |
| [کوچک (۳۶۰px)] | ۳۶۰px |
| [متوسط (۵۶۰px)] | ۵۶۰px |
| [بزرگ (۷۶۰px)] | ۷۶۰px |
| [عرض متن (۹۲۰px)] | ۹۲۰px |
| [دلخواه…] | هر عدد صحیح از ۱۶ تا ۴۰۹۶px |

## تعیین عرض در Markdown

به برچسب `img` در HTML یک `width` عددی بدهید. این شیوهٔ نوشتن در GitHub و MDX هم به همین شکل نمایش داده می‌شود.

```html
<img src="./images/screen.png" alt="صفحهٔ تنظیمات" width="360" />
```

> **توجه**
>
> - برای `width` فقط عدد بنویسید؛ `px` یا `%` اضافه نکنید. اگر مقداری بزرگ‌تر از عرض متن بنویسید، تصویر باز هم در عرض متن نمایش داده می‌شود.
> - مسیر تصویر نسبت به سند نوشته می‌شود. تصویرهای بیرون از ریشهٔ مستندات نمایش داده نمی‌شوند.
