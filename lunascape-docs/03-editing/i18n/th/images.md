# การปรับขนาดภาพ

ภาพที่วางไว้ในเอกสารจะย่อให้พอดีกับความกว้างของเนื้อหาและความสูงของหน้าจอโดยอัตโนมัติ สำหรับภาพที่ต้องการแสดงในขนาดที่กำหนด คุณสามารถระบุความกว้างได้

## หลักการปรับขนาดอัตโนมัติ

- ภาพแบบ Markdown ทั่วไป (`![คำอธิบาย](./images/screen.png)`) จะถูกย่อให้พอดีกับความกว้างของเนื้อหา และจะไม่ถูกขยายให้ใหญ่กว่าขนาดต้นฉบับ
- ภาพหน้าจอแนวตั้งจะถูกจำกัดไว้ที่ 72% ของความสูงหน้าจอ หรือ 720px แล้วแต่ว่าค่าใดจะน้อยกว่า

## ระบุความกว้างในหน้าจอแก้ไข

1. กด [แก้ไข] แล้วเลือกภาพในมุมมองแบบวิชวล
2. เลือกความกว้างจาก [ขนาดภาพ] บนแถบเครื่องมือ
3. กด [บันทึก]

| ตัวเลือก | ความกว้าง |
|---|---|
| [อัตโนมัติ] | ไม่ระบุ (ปรับขนาดอัตโนมัติ) |
| [เล็ก (360px)] | 360px |
| [กลาง (560px)] | 560px |
| [ใหญ่ (760px)] | 760px |
| [ความกว้างเนื้อหา (920px)] | 920px |
| [กำหนดเอง…] | จำนวนเต็มใดก็ได้ตั้งแต่ 16 ถึง 4096px |

## ระบุความกว้างด้วย Markdown

ระบุค่า `width` เป็นตัวเลขในแท็ก `img` ของ HTML วิธีเขียนแบบนี้จะแสดงผลเหมือนกันทั้งบน GitHub และใน MDX

```html
<img src="./images/screen.png" alt="หน้าจอการตั้งค่า" width="360" />
```

> **ข้อควรระวัง**
>
> - `width` ระบุได้เฉพาะตัวเลขเท่านั้น ไม่ต้องใส่ `px` หรือ `%` แม้จะระบุค่าที่ใหญ่กว่าความกว้างของเนื้อหา การแสดงผลก็จะยังพอดีกับความกว้างของเนื้อหา
> - ระบุภาพด้วยเส้นทางแบบสัมพัทธ์จากตัวเอกสาร ภาพที่อยู่นอกรากเอกสารจะไม่แสดง
