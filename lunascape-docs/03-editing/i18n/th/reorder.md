# เปลี่ยนลำดับของเอกสาร

ลำดับที่แสดงใน INDEX เปลี่ยนได้ด้วยการลากแล้ววาง หรือด้วยแป้นพิมพ์ ลำดับที่เปลี่ยนแล้วจะถูกบันทึกไว้ใน front matter ของเอกสารในชื่อ `navigation.order`

## จัดลำดับด้วยการลากแล้ววาง

1. ลากเอกสารหรือโฟลเดอร์ใน INDEX
2. วางไว้ก่อนหรือหลังรายการในระดับเดียวกัน หรือวางลงบนโฟลเดอร์
   ภายในระดับเดียวกัน ลำดับจะเปลี่ยนไป ถ้าวางลงบนโฟลเดอร์อื่น รายการนั้นจะย้ายไปยังโฟลเดอร์นั้น

## จัดลำดับด้วยแป้นพิมพ์หรือเมนู

- วางโฟกัสไว้ที่รายการใน INDEX แล้วกด `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓`
- เลือก [เลื่อนขึ้นหนึ่งลำดับ] / [เลื่อนลงหนึ่งลำดับ] ในเมนูของรายการ

## สิ่งที่บันทึกไว้

- เมื่อจัดลำดับภายในระดับเดียวกัน จะอัปเดต `navigation.order` ใน front matter ของเอกสารต้นฉบับ ในกรณีของโฟลเดอร์ จะเขียนลงใน `README.md` ของโฟลเดอร์นั้น ส่วนโฟลเดอร์ที่ไม่มี `README.md` จะสร้าง `README.md` ที่มีเฉพาะ front matter ขึ้นมา
- เมื่อย้ายไปยังโฟลเดอร์อื่น จะย้ายเอกสารต้นฉบับพร้อมกับคำแปลที่ตรงกันไปด้วยกัน ก่อนการย้าย จะมีการแสดงข้อความให้ยืนยันเกี่ยวกับผลกระทบต่อลิงก์แบบสัมพัทธ์
- จะไม่มีการจัดเตรียม (staging) หรือคอมมิตใน Git

> **ข้อควรระวัง**
>
> - ไม่สามารถจัดลำดับได้ในระหว่างการกรอง ในระหว่างการแก้ไขเอกสาร และในพื้นที่ทำงานที่ไม่ได้เชื่อถือ
> - เมื่อแสดงข้อความ "INDEX ได้รับการอัปเดตแล้ว" หมายความว่าเพิ่งมีการเปลี่ยนแปลงอื่นถูกนำมาใช้ ให้ทำขั้นตอนนั้นอีกครั้ง
> - หน้าเริ่มต้นไม่สามารถย้ายไปยังโฟลเดอร์อื่นได้

> **เคล็ดลับ**
>
> ถ้ากำหนดค่า `navigation.order` ทีละ 100 เช่น 100, 200, 300 จะแทรกเอกสารเพิ่มระหว่างกลางได้ง่ายในภายหลัง ดูรายละเอียดได้ที่ [ตั้งค่าข้อมูลการนำทาง](../04-document-tools/navigation-metadata.md)
