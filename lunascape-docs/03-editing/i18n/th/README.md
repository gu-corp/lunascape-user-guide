# การแก้ไขเอกสาร

คุณสามารถแก้ไขเอกสารได้โดยตรงภายในตัวแสดงผล หน้าจอแก้ไขมี "การแสดงผลแบบภาพ" ที่แก้ไขตามที่เห็น และ "การแสดงผลซอร์ส Markdown" โดยสลับกันด้วยปุ่มเดียว

## เริ่มการแก้ไข

กดปุ่มใดปุ่มหนึ่งต่อไปนี้ ทั้งหมดจะเปิดหน้าจอแก้ไขเดียวกัน

- [แก้ไข] ที่มุมขวาล่างของเนื้อหา
- [⋯] (การดำเนินการอื่น ๆ) ที่มุมขวาบนของเนื้อหา → [แก้ไข]
- เมนูรายการของ INDEX → [แก้ไข]

## แก้ไข

1. แก้ไขเนื้อหาได้โดยตรง
   บนแถบเครื่องมือด้านบนของหน้าจอแก้ไข คุณสามารถใช้รูปแบบย่อหน้า (เนื้อความ, หัวข้อ 1–4, อ้างอิง, โค้ด), [ตัวหนา], [ตัวเอียง], [รายการสัญลักษณ์], [รายการลำดับเลข], [ลิงก์], [แทรกตาราง], [ขนาดภาพ], [เลิกทำ], [ทำซ้ำ] ได้
2. เมื่อต้องการแก้ไขซอร์ส Markdown โดยตรง ให้กด [Markdown]
   กดอีกครั้งเพื่อกลับไปยังการแสดงผลแบบภาพ การแสดงผลที่ใช้ครั้งล่าสุดจะถูกจดจำไว้ และจะถูกกู้คืนเมื่อคุณกด [แก้ไข] ในครั้งถัดไป
3. กด [บันทึก] (บันทึกด้วย Ctrl+S／⌘S ก็ได้)
   ระบบจะเขียนลงในไฟล์ Markdown และกลับไปยังการแสดงผลแบบอ่าน เมื่อต้องการหยุดการแก้ไขและกลับไปยังเนื้อหาที่บันทึกไว้ล่าสุด ให้กด [Discard edits]

## เริ่มจากหน้าจอแก้ไขเสมอ (โหมดแก้ไข)

กด [โหมดแก้ไข] บนแถบเครื่องมือเพื่อเปิดใช้งาน แล้วทุกครั้งที่เปิดเอกสารจะเริ่มจากหน้าจอแก้ไข ใช้เมื่อต้องการเขียนต่อเนื่องเหมือนสมุดบันทึก

- ขณะเปิดใช้งาน การกด [บันทึก] จะไม่ปิดหน้าจอแก้ไข ส่วน [Discard edits] จะกลับไปยังเนื้อหาที่บันทึกไว้ล่าสุดโดยที่หน้าจอแก้ไขยังคงอยู่
- กดอีกครั้งเพื่อปิดใช้งานและกลับไปยังการแสดงผลแบบอ่าน สถานะเปิด／ปิดจะถูกจดจำแยกตามผู้ใช้แต่ละคน
- จะไม่แสดงในรากเอกสารที่เขียนไม่ได้ (เช่น แบบอ่านอย่างเดียวของ GitHub)

## การแก้ไขที่ยังไม่ได้บันทึก

การแก้ไขที่ยังไม่ได้บันทึกจะถูกเก็บไว้บนเครื่องนี้โดยอัตโนมัติ แม้ย้ายไปยังเอกสารอื่น หรือปิดแท็บหรือหน้าต่างก็จะไม่สูญหาย

- [Unsaved] ในหน้าจอแก้ไขแสดงว่ามีความแตกต่างจากเนื้อหาที่บันทึกไว้ล่าสุด
- เมื่อเปิดเอกสารเดิมในครั้งถัดไป จะเริ่มต่อจากการแก้ไขที่เก็บไว้และแจ้งให้ทราบ หากเอกสารต้นฉบับได้รับการอัปเดตหลังจากนั้น ก็จะแจ้งเรื่องนั้นด้วย คุณสามารถกลับไปยังเนื้อหาล่าสุดได้ด้วย [Discard edits]
- การแก้ไขที่เก็บไว้จะหายไปเมื่อกด [บันทึก] หรือ [Discard edits] เนื่องจากยังไม่ได้บันทึก จึงไม่ปรากฏใน Git หรือฉบับร่าง

> **ข้อควรระวัง**
>
> - การบันทึกทำเพียงการเขียนลงในไฟล์เท่านั้น ไม่ได้ทำ staging หรือ commit ของ Git ให้โดยอัตโนมัติ
> - สูตรคณิตศาสตร์ และแผนภาพต่าง ๆ เช่น Mermaid, TikZ, Vega-Lite จะแสดงผลลัพธ์การวาดในการแสดงผลแบบภาพ เมื่อต้องการเปลี่ยนเนื้อหา ให้สลับไปที่ [Markdown]
> - เอกสารที่มีไวยากรณ์เฉพาะของ MDX (เช่น คอมโพเนนต์หรือ `import`) จะแก้ไขได้เฉพาะในการแสดงผล Markdown เท่านั้น เพื่อรักษาไวยากรณ์ไว้
> - front matter (การตั้งค่าที่อยู่ในกรอบ `---` ที่ส่วนบน) จะถูกคงไว้แม้แก้ไขในการแสดงผลแบบภาพ

> **เคล็ดลับ**
>
> - เมื่อกด [เปิดใน VS Code] คุณจะสามารถเปิดในโปรแกรมแก้ไขข้อความปกติได้ เมื่อบันทึกในโปรแกรมแก้ไขข้อความ การแสดงผลของตัวแสดงผลก็จะอัปเดตโดยอัตโนมัติ
> - เมื่อไม่ต้องการแสดงปุ่ม [แก้ไข] ให้ปิด [ปุ่มแก้ไข] ใน [การตั้งค่าการแสดงผล] หากต้องการซ่อนทั้งโปรเจกต์ ให้ตั้งค่า `editor.showEditButton` ใน `lunascape-docs.json` เป็น `false`
> - ค่าเริ่มต้นของการแสดงผลที่เปิดครั้งแรก (แบบภาพ／Markdown) เปลี่ยนได้ที่การตั้งค่า `lunascapeDocEditor.editor.defaultMode` หรือ `editor.defaultMode` ใน `lunascape-docs.json`
