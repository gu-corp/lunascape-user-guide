# การแก้ไขเอกสาร

คุณสามารถแก้ไขเอกสารได้โดยตรงภายในโปรแกรมดูเอกสาร หน้าจอแก้ไขมีทั้ง "มุมมองภาพ" ที่แก้ไขได้ตามที่เห็น และ "มุมมองซอร์ส Markdown" โดยสลับกันได้ด้วยปุ่มเดียว

## เริ่มแก้ไข

กดอย่างใดอย่างหนึ่งต่อไปนี้ ทั้งหมดจะเปิดหน้าจอแก้ไขเดียวกัน

- [แก้ไข] ที่มุมขวาล่างของเนื้อหา
- [⋯] (การดำเนินการอื่น) ที่มุมขวาบนของเนื้อหา → [แก้ไข]
- เมนูของรายการใน INDEX → [แก้ไข]

## แก้ไข

1. แก้ไขเนื้อหาได้โดยตรง
   แถบเครื่องมือด้านบนของหน้าจอแก้ไขมีรูปแบบย่อหน้า (เนื้อความ, หัวข้อ 1–4, ข้อความอ้างอิง, โค้ด), [ตัวหนา], [ตัวเอียง], [รายการสัญลักษณ์], [รายการลำดับเลข], [ลิงก์], [แทรกตาราง], [ขนาดภาพ], [เลิกทำ] และ [ทำซ้ำ] ให้ใช้งาน
2. เมื่อต้องการแก้ไขซอร์ส Markdown โดยตรง ให้กด [Markdown]
   กดอีกครั้งเพื่อกลับไปยังมุมมองภาพ ระบบจะจดจำมุมมองที่ใช้ล่าสุด และเรียกคืนให้เมื่อคุณกด [แก้ไข] ในครั้งถัดไป
3. กด [บันทึก]
   ระบบจะเขียนลงไฟล์ Markdown แล้วกลับสู่มุมมองการอ่าน หากต้องการยกเลิก ให้กด [ยกเลิก]

> **ข้อควรระวัง**
>
> - การบันทึกจะเขียนลงไฟล์เท่านั้น ไม่มีการ stage หรือ commit ใน Git โดยอัตโนมัติ
> - สูตรคณิตศาสตร์ และแผนภาพอย่าง Mermaid, TikZ, Vega-Lite จะแสดงเป็นผลลัพธ์ที่วาดแล้วในมุมมองภาพ หากต้องการเปลี่ยนเนื้อหา ให้สลับไปที่ [Markdown]
> - เอกสารที่มีไวยากรณ์เฉพาะของ MDX (เช่น คอมโพเนนต์หรือ `import`) จะแก้ไขได้ในมุมมอง Markdown เท่านั้น เพื่อรักษาไวยากรณ์นั้นไว้
> - front matter (ส่วนการตั้งค่าที่คั่นด้วย `---` ที่ต้นไฟล์) จะยังคงอยู่แม้แก้ไขในมุมมองภาพ

> **คำแนะนำ**
>
> - เมื่อกด [เปิดใน VS Code] จะเปิดไฟล์ในโปรแกรมแก้ไขข้อความตามปกติ เมื่อบันทึกในโปรแกรมแก้ไขข้อความ การแสดงผลในโปรแกรมดูเอกสารจะอัปเดตโดยอัตโนมัติ
> - หากไม่ต้องการให้แสดงปุ่ม [แก้ไข] ให้ปิด [ปุ่มแก้ไข] ใน [การตั้งค่าการแสดงผล] หากต้องการซ่อนทั้งโปรเจกต์ ให้ตั้ง `editor.showEditButton` ใน `lunascape-docs.json` เป็น `false`
> - มุมมองที่เปิดขึ้นเป็นอันดับแรก (ภาพ / Markdown) เปลี่ยนค่าเริ่มต้นได้ที่การตั้งค่า `lunascapeDocEditor.editor.defaultMode` หรือ `editor.defaultMode` ใน `lunascape-docs.json`
