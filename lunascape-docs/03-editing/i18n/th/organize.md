# สร้างและจัดระเบียบเอกสารและโฟลเดอร์

จากเมนูรายการใน INDEX คุณสามารถสร้าง ทำสำเนา เปลี่ยนชื่อ และลบเอกสารและโฟลเดอร์ได้ การป้อนข้อมูลทำในกล่องโต้ตอบขนาดเล็กภายในโปรแกรมดู จึงไม่ขัดจังหวะการอ่าน

> **ข้อควรทราบ**
>
> การดำเนินการเหล่านี้ใช้ได้เฉพาะเมื่อพื้นที่ทำงานเป็นพื้นที่ทำงานที่เชื่อถือได้ใน VS Code เท่านั้น และไม่สามารถทำได้ขณะกำลังแก้ไขเอกสาร ขณะที่การดำเนินการอื่นกำลังทำงานอยู่ หรือเมื่อรายการเป้าหมายมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก

## สร้างเอกสารหรือโฟลเดอร์

1. เปิดเมนูรายการ ([⋯] หรือคลิกขวา) ของโฟลเดอร์ปลายทางที่จะสร้าง
   หากต้องการสร้างใต้รากเอกสารโดยตรง ให้ใช้ [⋯] ที่ปลายด้านขวาของหัวข้อ INDEX หรือคลิกขวาที่พื้นที่ว่างของ INDEX
2. เลือก [เอกสารใหม่] หรือ [โฟลเดอร์ใหม่]
3. ป้อนชื่อแล้วกด [สร้าง]
   ชื่อเอกสารต้องมีนามสกุลของ Markdown (`.md`, `.markdown`, `.mdx` เป็นต้น)

เอกสารใหม่จะถูกสร้างเป็นเอกสารของภาษาเริ่มต้น (เอกสารต้นฉบับ)

## ทำสำเนาเอกสาร

1. เปิดเมนูรายการของเอกสารแล้วเลือก [ทำสำเนา]
2. ป้อนชื่อใหม่แล้วกด [สร้าง]

ระบบจะทำสำเนาเฉพาะเอกสารต้นฉบับเท่านั้น คำแปลจะไม่ถูกทำสำเนา

## เปลี่ยนชื่อเรื่อง

เป็นการเปลี่ยนหัวข้อของเอกสาร (H1) ชื่อไฟล์จะไม่เปลี่ยน

1. เปิดเมนูรายการของเอกสารหรือโฟลเดอร์แล้วเลือก [เปลี่ยนชื่อเรื่อง]
2. ป้อนชื่อเรื่องใหม่เป็นบรรทัดเดียวแล้วกด [เปลี่ยน]

ในกรณีของโฟลเดอร์ ระบบจะเปลี่ยนหัวข้อใน `README.md` ของโฟลเดอร์นั้น เมื่อภาษาที่แสดงอยู่เป็นคำแปล ชื่อเรื่องของเอกสารภาษานั้นจะถูกเปลี่ยน

## เปลี่ยนชื่อเอกสาร

เป็นการเปลี่ยนชื่อเอกสารที่แสดงในแถบเครื่องมือ (ชื่อของรากเอกสาร)

1. คลิกขวาที่ชื่อเอกสารในแถบเครื่องมือ หรือเปิดจาก [⋯] ที่ปลายด้านขวาของหัวข้อ INDEX ก็ได้
2. เลือก [เปลี่ยนชื่อเอกสาร] แล้วป้อนชื่อใหม่

หากยังไม่ได้ตั้งค่าไว้ ระบบจะแสดงชื่อโฟลเดอร์ตามที่เป็นอยู่

ชื่อที่เปลี่ยนจะถูกเขียนลงใน**ตำแหน่งที่ใช้เป็นชื่อเอกสารอยู่ในขณะนี้** ระบบจะไม่เขียนลงในตำแหน่งที่ไม่ได้ใช้แสดงผล จนทำให้หัวข้อที่มองเห็นอยู่ถูกละเลย

| สถานะปัจจุบัน | ตำแหน่งที่เขียน |
|---|---|
| มีชื่ออยู่ใน `lunascape-docs.json` | อัปเดต `lunascape-docs.json` |
| ไม่มีชื่อ แต่รากเอกสารมี README | เขียนทับหัวข้อ (H1) ของ README |
| ไม่มีทั้งสองอย่าง | สร้าง `lunascape-docs.json` แล้วบันทึกชื่อไว้ที่นั่น |

ข้อความที่แสดงหลังการเปลี่ยนจะบอกว่าเขียนลงที่ใด

> **เคล็ดลับ**
>
> ชื่อเอกสารถูกกำหนดตามลำดับนี้ ชื่อใน `lunascape-docs.json` → หัวข้อของ README ในรากเอกสาร → ชื่อโฟลเดอร์

## เปลี่ยนชื่อไฟล์หรือชื่อโฟลเดอร์

1. เปิดเมนูรายการแล้วเลือก [เปลี่ยนชื่อไฟล์] หรือ [เปลี่ยนชื่อโฟลเดอร์]
2. ป้อนชื่อใหม่แล้วกด [เปลี่ยน]

คำแปลที่เกี่ยวข้อง (เส้นทางเดียวกันภายใต้ `i18n/<ภาษา>/`) จะถูกเปลี่ยนชื่อไปพร้อมกัน

## ลบ

1. เปิดเมนูรายการแล้วเลือก [ย้ายไปถังขยะ]
2. ตรวจสอบเนื้อหาของข้อความยืนยัน แล้วอนุมัติการย้าย

รายการเป้าหมายจะถูกย้ายไปยังถังขยะของระบบปฏิบัติการ จึงกู้คืนได้หากจำเป็น คำแปลจะไม่ถูกลบและยังคงอยู่ตามเดิม

## ชื่อที่ใช้ไม่ได้

- ชื่อที่ขึ้นต้นด้วย `.` (เพราะจะไม่ปรากฏใน INDEX)
- `i18n` (สงวนไว้สำหรับไฟล์คำแปล)
- ชื่อที่สงวนไว้ใน Windows (`CON`, `PRN` เป็นต้น)
- ชื่อที่ลงท้ายด้วยจุดหรือช่องว่าง
- ชื่อที่มีอักขระควบคุมหรืออักขระที่ใช้ในชื่อไฟล์ไม่ได้
- ชื่อที่มีอยู่แล้วในโฟลเดอร์เดียวกัน (รวมถึงชื่อที่ต่างกันเพียงตัวพิมพ์ใหญ่เล็ก)

> **ข้อควรทราบ**
>
> หน้าเริ่มต้น (โดยปกติคือ `README.md` ที่ราก) ไม่สามารถเปลี่ยนชื่อหรือย้ายได้ กรุณาเปลี่ยน `startPage` ใน `lunascape-docs.json` ก่อน
