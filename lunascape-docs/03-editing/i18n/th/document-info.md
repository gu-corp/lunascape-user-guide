# แสดงข้อมูลเอกสาร

"ตารางควบคุมเอกสาร" ที่วางไว้ต้นเอกสาร (ตารางแสดงรหัสเอกสาร เวอร์ชัน วันที่อัปเดต สถานะ และอื่น ๆ) จะถูกรวบให้แสดงเป็นแถว "ข้อมูลเอกสาร" ขนาดเล็กขณะอ่าน ตัว Markdown ยังคงเป็นตารางธรรมดา จึงอ่านได้ตามปกติบน GitHub เช่นกัน

## เงื่อนไขในการแสดงผล

วางตารางสองคอลัมน์ดังต่อไปนี้ไว้ถัดจากหัวเรื่อง (H1) ทันที

```markdown
# ข้อกำหนดความต้องการเชิงหน้าที่

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- เงื่อนไขคือต้องมีแถวรหัสเอกสาร และมีรายการควบคุมหลายรายการ
- ตารางที่วางไว้ใต้หัวเรื่อง `## 文書管理` หรือ `## Document information` ก็เข้าข่ายเช่นกัน
- ตารางที่อยู่กลางเนื้อหา และตาราง "รายการ/เนื้อหา" ทั่วไป จะไม่ถูกแปลงรูปแบบ

## ลักษณะการแสดงผล

- ขณะอ่าน จะแสดงเฉพาะสถานะและวันที่อัปเดตด้วยตัวอักษรขนาดเล็ก
- กดที่แถวเพื่อแสดงทุกรายการ
- เมื่อพิมพ์ จะแสดงทุกรายการ
- ในหน้าจอแก้ไข ตารางจะแสดงเป็นตารางปกติและแก้ไขได้ตามเดิม

> **คำแนะนำ**
>
> หากต้องการให้แสดงเป็นตารางตลอดเวลาโดยไม่ย่อ ให้ปิด [ย่อข้อมูลเอกสาร] ใน [การตั้งค่าการแสดงผล]
