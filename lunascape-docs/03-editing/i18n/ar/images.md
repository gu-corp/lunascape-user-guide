# ضبط حجم الصور

تُلائم الصور المُدرجة في المستند عرضَ النص وارتفاعَ الشاشة تلقائيًا. ويمكنك تحديد عرض الصورة التي تريد عرضها بحجم معيّن.

## كيف يعمل الضبط التلقائي

- تُصغَّر صورة Markdown العادية (`![الوصف](./images/screen.png)` ) لتلائم عرض النص. ولا تُكبَّر أبدًا إلى أكثر من حجمها الأصلي.
- تقتصر لقطة الشاشة الطويلة على 72% من ارتفاع الشاشة أو 720px، أيهما أصغر.

## تحديد العرض في شاشة التحرير

1. اضغط [تحرير]، ثم حدّد الصورة في العرض المرئي.
2. اختر العرض من [حجم الصورة] في شريط الأدوات.
3. اضغط [حفظ].

| الخيار | العرض |
|---|---|
| [تلقائي] | غير محدّد (ضبط تلقائي) |
| [صغير (360px)] | 360px |
| [متوسط (560px)] | 560px |
| [كبير (760px)] | 760px |
| [عرض النص (920px)] | 920px |
| [مخصص…] | أي عدد صحيح من 16 إلى 4096px |

## تحديد العرض في Markdown

حدّد قيمة رقمية للسمة `width` في وسم HTML المسمّى `img`. هذه الطريقة تُعرض بالشكل نفسه على GitHub وفي MDX.

```html
<img src="./images/screen.png" alt="شاشة الإعدادات" width="360" />
```

> **ملاحظة**
>
> - لا تُحدَّد لـ `width` سوى قيمة رقمية، دون `px` أو `%`. وإذا حدّدت قيمة أكبر من عرض النص، فسيظل العرض ملائمًا لعرض النص.
> - تُحدَّد مسارات الصور نسبةً إلى المستند. ولا تُعرض الصور الموجودة خارج جذر التوثيق.
