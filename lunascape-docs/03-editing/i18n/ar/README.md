# تحرير مستند

يمكن تحرير المستندات داخل العارض مباشرة. تضم شاشة التحرير «العرض المرئي» الذي تحرّر فيه ما تراه، و«عرض مصدر Markdown»، ويجري التبديل بينهما بزر واحد.

## بدء التحرير

اضغط أيًّا مما يلي. جميعها تفتح شاشة التحرير نفسها.

- [تحرير] أسفل يسار المستند
- [⋯] (إجراءات أخرى) أعلى يسار المستند ← [تحرير]
- قائمة العنصر في INDEX ← [تحرير]

## التحرير

1. حرّر النص مباشرة.
   يوفّر شريط الأدوات أعلى شاشة التحرير تنسيق الفقرة (نص أساسي، عناوين ١ إلى ٤، اقتباس، تعليمة برمجية)، و[عريض]، و[مائل]، و[قائمة نقطية]، و[قائمة مرقّمة]، و[رابط]، و[إدراج جدول]، و[حجم الصورة]، و[تراجع]، و[إعادة].
2. لتحرير مصدر Markdown مباشرة، اضغط [Markdown].
   اضغطه مرة أخرى للعودة إلى العرض المرئي. يُحفظ آخر عرض استخدمته ويُستعاد عند ضغط [تحرير] في المرة التالية.
3. اضغط [حفظ].
   يُكتب ملف Markdown ويعود العارض إلى وضع القراءة. للتراجع، اضغط [إلغاء].

> **ملاحظة**
>
> - لا يؤدي الحفظ إلا إلى الكتابة في الملف. لا تتم التهيئة للإيداع في Git ولا الإيداع نفسه تلقائيًا.
> - تظهر المعادلات والرسوم التخطيطية مثل Mermaid وTikZ وVega-Lite بنتيجة عرضها في العرض المرئي. للتبديل في محتواها، انتقل إلى [Markdown].
> - تُحرَّر المستندات التي تتضمن صياغة خاصة بـ MDX (مكوّنات أو `import` وما إلى ذلك) في عرض Markdown فقط، حفاظًا على تلك الصياغة.
> - يُحتفظ بـ front matter (الإعدادات المحاطة بسطري `---` في الأعلى) حتى عند التحرير في العرض المرئي.

> **تلميح**
>
> - يفتح [الفتح في VS Code] الملف في محرّر النصوص المعتاد. والحفظ هناك يحدّث عرض العارض تلقائيًا.
> - لإخفاء زر [تحرير]، أوقف [زر التحرير] في [إعدادات العرض]. ولإخفائه في المشروع كله، اضبط `editor.showEditButton` على `false` في `lunascape-docs.json`.
> - يمكن تغيير العرض الافتراضي عند الفتح (المرئي أو Markdown) عبر الإعداد `lunascapeDocEditor.editor.defaultMode` أو عبر `editor.defaultMode` في `lunascape-docs.json`.
