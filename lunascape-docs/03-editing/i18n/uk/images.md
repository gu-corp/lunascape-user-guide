# Змінення розміру зображень

Зображення, вставлені в документ, автоматично вписуються в ширину тексту та висоту екрана. Для зображення, яке потрібно показати певного розміру, можна задати ширину.

## Як працює автоматичне припасування

- Звичайне зображення Markdown (`![опис](./images/screen.png)`) зменшується так, щоб уміститися в ширину тексту. Воно ніколи не збільшується понад свій вихідний розмір.
- Високий знімок екрана обмежується 72% висоти екрана або 720px — залежно від того, що менше.

## Задання ширини в режимі редагування

1. Натисніть [Редагувати] і виберіть зображення у візуальному поданні.
2. Виберіть ширину в списку [Розмір зображення] на панелі інструментів.
3. Натисніть [Зберегти].

| Варіант | Ширина |
|---|---|
| [Автоматично] | Не задано (автоматичне припасування) |
| [Мале (360px)] | 360px |
| [Середнє (560px)] | 560px |
| [Велике (760px)] | 760px |
| [Ширина тексту (920px)] | 920px |
| [Довільна…] | Будь-яке ціле число від 16 до 4096px |

## Задання ширини в Markdown

Укажіть числове значення `width` у теґу HTML `img`. Такий запис відображається так само на GitHub і в MDX.

```html
<img src="./images/screen.png" alt="Екран параметрів" width="360" />
```

> **Примітка**
>
> - У `width` вказується лише число, без `px` чи `%`. Навіть якщо значення більше за ширину тексту, зображення все одно вміщується в ширину тексту.
> - Шлях до зображення вказується відносно документа. Зображення за межами кореня документації не відображаються.
