# Редагування документа

Документи можна редагувати просто у переглядачі. Екран редагування має візуальний режим, у якому ви редагуєте те, що бачите, і режим вихідного коду Markdown; перемикання між ними виконує одна кнопка.

## Початок редагування

Натисніть будь-що з наведеного нижче. Усе це відкриває той самий екран редагування.

- [Редагувати] у нижньому правому куті тексту
- [⋯] (інші дії) у верхньому правому куті тексту → [Редагувати]
- Меню елемента INDEX → [Редагувати]

## Редагування

1. Редагуйте текст безпосередньо.
   На панелі інструментів угорі екрана редагування доступні формат абзацу (основний текст, заголовки 1–4, цитата, код), [Жирний], [Курсив], [Маркований список], [Нумерований список], [Посилання], [Вставити таблицю], [Розмір зображення], [Скасувати], [Повторити].
2. Щоб редагувати вихідний код Markdown безпосередньо, натисніть [Markdown].
   Повторне натискання повертає візуальний режим. Останній використаний режим запам'ятовується та відновлюється, коли ви наступного разу натиснете [Редагувати].
3. Натисніть [Зберегти].
   Зміни записуються у файл Markdown, і переглядач повертається до режиму читання. Щоб відмовитися від змін, натисніть [Скасувати].

> **Примітка**
>
> - Збереження лише записує файл. Індексування та фіксація у Git ніколи не виконуються автоматично.
> - Формули та діаграми, такі як Mermaid, TikZ і Vega-Lite, у візуальному режимі показуються у готовому вигляді. Щоб змінити їхній вміст, перемкніться на [Markdown].
> - Документи, які містять синтаксис, властивий MDX (компоненти, `import` тощо), редагуються лише в режимі Markdown, щоб зберегти цей синтаксис.
> - Front matter (налаштування на початку файлу, обмежені рядками `---`) зберігається й тоді, коли ви редагуєте у візуальному режимі.

> **Порада**
>
> - Кнопка [Відкрити у VS Code] відкриває файл у звичайному текстовому редакторі. Після збереження в текстовому редакторі вигляд у переглядачі оновлюється автоматично.
> - Щоб приховати кнопку [Редагувати], вимкніть [Кнопка редагування] у [Параметри відображення]. Щоб приховати її для всього проєкту, встановіть для `editor.showEditButton` значення `false` у `lunascape-docs.json`.
> - Режим, який відкривається першим (візуальний або Markdown), за замовчуванням змінюється параметром `lunascapeDocEditor.editor.defaultMode` або `editor.defaultMode` у `lunascape-docs.json`.
