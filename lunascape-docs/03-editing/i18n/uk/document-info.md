# Показ відомостей про документ

«Таблиця керування документом», розміщена на початку документа (ідентифікатор документа, версія, дата оновлення, стан тощо), під час перегляду відображається у вигляді невеликого рядка «Відомості про документ». Сам Markdown залишається звичайною таблицею, тож його так само можна читати на GitHub.

## Умови відображення

Одразу після заголовка (H1) розмістіть таблицю з двох стовпців, як показано нижче.

```markdown
# Специфікація функціональних вимог

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- Умова — наявність рядка з ідентифікатором документа та кількох полів керування.
- Таблиця, розміщена під заголовком `## 文書管理` або `## Document information`, теж розпізнається.
- Таблиці всередині основного тексту та звичайні таблиці «поле／значення» не перетворюються.

## Як це відображається

- Під час перегляду дрібним шрифтом показуються лише стан і дата оновлення.
- Натисніть рядок, щоб показати всі поля.
- Під час друку показуються всі поля.
- У редакторі таблиця відображається як звичайна й доступна для редагування.

> **Порада**
>
> Щоб таблиця завжди показувалася повністю, без згортання, вимкніть [Згорнути відомості про документ] у розділі [Параметри відображення].
