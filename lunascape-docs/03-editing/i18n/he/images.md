# התאמת גודל התמונות

תמונה שמוצבת במסמך מותאמת אוטומטית לרוחב גוף הטקסט ולגובה המסך. לתמונה שצריכה להופיע בגודל מסוים אפשר לקבוע רוחב.

## כיצד פועלת ההתאמה האוטומטית

- תמונת Markdown רגילה (`![תיאור](./images/screen.png)`) מוקטנת כך שתתאים לרוחב גוף הטקסט. היא לעולם אינה מוגדלת מעבר לגודלה המקורי.
- צילום מסך מאורך מוגבל ל‑72% מגובה המסך או ל‑720px, לפי הקטן מביניהם.

## קביעת הרוחב במסך העריכה

1. לחצו על [עריכה] ובחרו את התמונה בתצוגה החזותית.
2. בחרו רוחב מתוך [גודל התמונה] שבסרגל הכלים.
3. לחצו על [שמירה].

| אפשרות | רוחב |
|---|---|
| [אוטומטי] | לא צוין (התאמה אוטומטית) |
| [קטן (360px)] | 360px |
| [בינוני (560px)] | 560px |
| [גדול (760px)] | 760px |
| [רוחב גוף הטקסט (920px)] | 920px |
| [מותאם אישית…] | כל מספר שלם בין 16 ל‑4096px |

## קביעת הרוחב ב‑Markdown

ציינו `width` מספרי בתגית ה‑`img` של HTML. זוהי כתיבה שמוצגת באותו אופן גם ב‑GitHub וגם ב‑MDX.

```html
<img src="./images/screen.png" alt="מסך ההגדרות" width="360" />
```

> **שימו לב**
>
> - ב‑`width` יש לציין מספר בלבד, בלי `px` או `%`. גם אם תציינו ערך גדול מרוחב גוף הטקסט, התצוגה תותאם לרוחב גוף הטקסט.
> - נתיב התמונה מצוין באופן יחסי למסמך. תמונות שנמצאות מחוץ לשורש התיעוד אינן מוצגות.
