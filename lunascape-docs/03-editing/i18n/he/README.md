# עריכת מסמך

אפשר לערוך מסמכים ישירות בתוך המציג. למסך העריכה שתי תצוגות: תצוגה חזותית, שבה עורכים את מה שרואים, ותצוגת מקור Markdown; לחצן אחד מחליף ביניהן.

## התחלת העריכה

לחצו על אחת מהאפשרויות הבאות. כולן פותחות את אותו מסך עריכה.

- [עריכה] בפינה הימנית התחתונה של גוף המסמך
- [⋯] (פעולות נוספות) בפינה הימנית העליונה של גוף המסמך ← [עריכה]
- תפריט הפריט ב־INDEX ← [עריכה]

## עריכה

1. ערכו את גוף הטקסט ישירות.
   בסרגל הכלים שבראש מסך העריכה זמינים עיצוב הפסקה (גוף הטקסט, כותרות 1–4, ציטוט, קוד), [מודגש], [נטוי], [רשימת תבליטים], [רשימה ממוספרת], [קישור], [הוספת טבלה], [גודל התמונה], [ביטול] ו־[ביצוע מחדש].
2. כדי לערוך את מקור ה־Markdown ישירות, לחצו על [Markdown].
   לחיצה נוספת מחזירה לתצוגה החזותית. התצוגה שבה השתמשתם לאחרונה נשמרת ומשוחזרת בפעם הבאה שתלחצו על [עריכה].
3. לחצו על [שמירה].
   התוכן נכתב לקובץ Markdown והתצוגה חוזרת למצב קריאה. כדי להפסיק, לחצו על [ביטול].

> **שימו לב**
>
> - השמירה כותבת לקובץ בלבד. הוספה לאזור ההכנה של Git וביצוע commit אינם מתבצעים אוטומטית.
> - נוסחאות ותרשימים כגון Mermaid, TikZ ו־Vega-Lite מוצגים בתצוגה החזותית כתוצאה המעובדת. כדי לשנות את תוכנם, עברו אל [Markdown].
> - מסמכים הכוללים תחביר ייחודי ל־MDX (רכיבים, `import` וכדומה) נערכים בתצוגת Markdown בלבד, כדי לשמור על התחביר.
> - front matter (ההגדרות המוקפות בשורות `---` בראש הקובץ) נשמר גם כשעורכים בתצוגה החזותית.

> **טיפ**
>
> - לחיצה על [פתיחה ב־VS Code] פותחת את הקובץ בעורך הטקסט הרגיל. שמירה בעורך הטקסט מעדכנת אוטומטית גם את התצוגה במציג.
> - כדי שלחצן [עריכה] לא יוצג, כבו את [לחצן העריכה] שב[הגדרות תצוגה]. כדי להסתיר אותו בכל הפרויקט, הגדירו את `editor.showEditButton` שבקובץ `lunascape-docs.json` לערך `false`.
> - את ברירת המחדל של התצוגה שנפתחת תחילה (חזותית / Markdown) אפשר לשנות בהגדרה `lunascapeDocEditor.editor.defaultMode` או ב־`editor.defaultMode` שבקובץ `lunascape-docs.json`.
