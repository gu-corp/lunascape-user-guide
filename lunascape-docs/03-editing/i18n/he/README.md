# עריכת מסמך

ניתן לערוך מסמכים ישירות בתוך המציג. במסך העריכה יש "תצוגה חזותית", שבה עורכים את מה שרואים, ו"תצוגת מקור Markdown"; לחצן אחד מחליף ביניהן.

## התחלת העריכה

לחצו על אחד מהבאים. כולם פותחים את אותו מסך עריכה.

- [עריכה] בפינה הימנית התחתונה של גוף המסמך
- [⋯] (פעולות נוספות) בפינה הימנית העליונה של גוף המסמך ← [עריכה]
- תפריט הפריט ב-INDEX ← [עריכה]

## עריכה

1. ערכו את גוף המסמך ישירות.
   בסרגל הכלים שבחלק העליון של מסך העריכה זמינים עיצוב הפסקה (גוף, כותרות 1–4, ציטוט, קוד), [מודגש], [נטוי], [רשימת תבליטים], [רשימה ממוספרת], [קישור], [הוספת טבלה], [גודל התמונה], [ביטול] ו-[ביצוע מחדש].
2. כדי לערוך את מקור ה-Markdown ישירות, לחצו על [Markdown].
   לחיצה נוספת מחזירה לתצוגה החזותית. התצוגה שבה השתמשתם לאחרונה נשמרת ומשוחזרת בפעם הבאה שתלחצו על [עריכה].
3. לחצו על [שמירה] (אפשר לשמור גם באמצעות Ctrl+S / ⌘S).
   התוכן נכתב לקובץ ה-Markdown והתצוגה חוזרת למצב קריאה. כדי להפסיק לערוך ולחזור לתוכן שנשמר לאחרונה, לחצו על [Discard edits].

## להתחיל תמיד ממסך העריכה (מצב עריכה)

לחצו על [מצב עריכה] בסרגל הכלים כדי להפעיל אותו: מאותו רגע כל מסמך נפתח ממסך העריכה, כמו פנקס רשימות. השתמשו בכך כשאתם כותבים ברצף.

- בזמן שהמצב מופעל, לחיצה על [שמירה] אינה סוגרת את מסך העריכה. [Discard edits] מחזיר לתוכן שנשמר לאחרונה ומשאיר את מסך העריכה פתוח.
- לחיצה נוספת מכבה אותו ומחזירה למצב קריאה. ההפעלה/כיבוי נשמרים לכל משתמש בנפרד.
- הוא אינו מוצג בשורש תיעוד שלא ניתן לכתוב אליו (כגון מקור לקריאה בלבד ב-GitHub).

## עריכות שלא נשמרו

עריכות שלא שמרתם נשמרות אוטומטית במכשיר זה. הן אינן אובדות גם כשעוברים למסמך אחר או סוגרים את הכרטיסייה או החלון.

- [Unsaved] במסך העריכה מציין שיש הבדל בין התוכן לבין מה שנשמר לאחרונה.
- בפעם הבאה שתפתחו את אותו מסמך, העבודה תמשיך מהעריכות שנשמרו ותקבלו על כך הודעה. אם המסמך המקורי עודכן מאז, גם על כך תקבלו הודעה. באמצעות [Discard edits] אפשר לחזור לתוכן העדכני ביותר.
- העריכות שנשמרו נמחקות באמצעות [שמירה] או [Discard edits]. מכיוון שהן לא נשמרו, הן אינן מופיעות ב-Git או בטיוטות.

> **הערה**
>
> - השמירה מבצעת כתיבה לקובץ בלבד. העברה לאזור ההכנה (staging) של Git וביצוע commit אינם נעשים אוטומטית.
> - נוסחאות ותרשימים כגון Mermaid, TikZ ו-Vega-Lite מוצגים כתוצאת שרטוט בתצוגה החזותית. כדי לשנות את תוכנם, החליפו ל-[Markdown].
> - מסמכים הכוללים תחביר ייחודי ל-MDX (רכיבים, `import` וכדומה) נערכים בתצוגת Markdown בלבד, כדי לשמור על התחביר.
> - front matter (ההגדרות התחומות ב-`---` בראש הקובץ) נשמרים גם כשעורכים בתצוגה החזותית.

> **טיפ**
>
> - לחיצה על [פתיחה ב-VS Code] פותחת את הקובץ בעורך הטקסט הרגיל. שמירה בעורך הטקסט מעדכנת את תצוגת המציג אוטומטית.
> - כדי שלחצן [עריכה] לא יוצג, כבו את [לחצן העריכה] שב[הגדרות תצוגה]. כדי להסתיר אותו בכל הפרויקט, הגדירו את `editor.showEditButton` ל-`false` בקובץ `lunascape-docs.json`.
> - את ברירת המחדל של התצוגה שנפתחת ראשונה (חזותית / Markdown) אפשר לשנות בהגדרה `lunascapeDocEditor.editor.defaultMode` או ב-`editor.defaultMode` שבקובץ `lunascape-docs.json`.
