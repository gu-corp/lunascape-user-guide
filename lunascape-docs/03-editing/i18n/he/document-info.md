# הצגת פרטי המסמך

"טבלת ניהול המסמך" הממוקמת בראש המסמך (מזהה המסמך, גרסה, תאריך עדכון, מצב וכדומה) מוצגת בעת הקריאה כשורת "פרטי המסמך" קטנה. ה־Markdown עצמו נשאר טבלה רגילה, ולכן הוא נקרא כרגיל גם ב־GitHub.

## תנאים להצגה

מיד לאחר הכותרת (H1), הציבו טבלה בת שתי עמודות כדוגמת זו.

```markdown
# מסמך הגדרת דרישות פונקציונליות

| פריט | תוכן |
|---|---|
| מזהה מסמך | REQ-001 |
| גרסה | 1.0 |
| תאריך עדכון | 2026-08-31 |
| מצב | מאושר |
| אחראי המסמך | G.U.Corp |
```

- התנאי הוא שתהיה שורת "מזהה מסמך" ומספר פריטי ניהול.
- גם טבלה הממוקמת תחת הכותרת `## 文書管理` או `## Document information` נכללת.
- טבלה שנמצאת בתוך גוף הטקסט, וכן טבלת "פריט/תוכן" רגילה, אינן מומרות.

## אופן ההצגה

- בעת הקריאה מוצגים באותיות קטנות רק המצב ותאריך העדכון.
- לחיצה על השורה מציגה את כל הפריטים.
- בהדפסה מוצגים כל הפריטים.
- במסך העריכה הטבלה מוצגת כטבלה רגילה וניתן לערוך אותה ככזו.
