# יצירה וארגון של מסמכים ותיקיות

מתפריט הפריט של INDEX אפשר ליצור מסמכים ותיקיות, לשכפל אותם, לשנות את שמם ולמחוק אותם. ההזנה נעשית בחלון דו-שיח קטן בתוך המציג, בלי להפסיק את הקריאה.

> **הערה**
>
> פעולות אלה זמינות רק כאשר סביבת העבודה מהימנה ב-VS Code. אי אפשר לבצע אותן בזמן עריכת מסמך, בזמן שפעולה אחרת מתבצעת, או כאשר יש בפריט שינויים שלא נשמרו.

## יצירת מסמך או תיקייה

1. פתחו את תפריט הפריט ([⋯] או לחיצה ימנית) של התיקייה שבה ייווצר הפריט.
   כדי ליצור ישירות תחת שורש התיעוד, השתמשו ב-[⋯] שבקצה כותרת INDEX, או לחצו לחיצה ימנית על אזור ריק ב-INDEX.
2. בחרו ב-[מסמך חדש] או ב-[תיקייה חדשה].
3. הזינו שם ולחצו על [יצירה].
   שם של מסמך מחייב סיומת Markdown (‏`.md`, `.markdown`, `.mdx` וכדומה).

מסמכים חדשים נוצרים כמסמכים בשפת ברירת המחדל (מסמכי מקור).

## שכפול מסמך

1. פתחו את תפריט הפריט של המסמך ובחרו ב-[שכפול].
2. הזינו שם חדש ולחצו על [יצירה].

משוכפל רק מסמך המקור; התרגומים שלו אינם משוכפלים.

## שינוי הכותרת

משנה את כותרת המסמך (H1). שם הקובץ נשאר כשהיה.

1. פתחו את תפריט הפריט של מסמך או תיקייה ובחרו ב-[שינוי הכותרת].
2. הזינו את הכותרת החדשה בשורה אחת ולחצו על [שינוי].

בתיקייה משתנה הכותרת של `README.md` שבתוכה. כאשר מוצג תרגום, משתנה הכותרת של המסמך באותה שפה.

## שינוי שם המסמך

משנה את שם המסמך המוצג בסרגל הכלים (שם שורש התיעוד).

1. לחצו לחיצה ימנית על שם המסמך שבסרגל הכלים. גם [⋯] שבקצה כותרת INDEX פותח את אותו תפריט.
2. בחרו ב-[שינוי שם המסמך] והזינו שם חדש.

כל עוד לא הוגדר שם, מוצג שם התיקייה כפי שהוא.

השם ששיניתם נכתב **במקום שממנו נלקח כעת שם המסמך**, כדי שלעולם לא ייווצר מצב שבו מתעלמים מכותרת הנראית לעין.

| המצב הנוכחי | נכתב אל |
|---|---|
| ב-`lunascape-docs.json` יש שם | `lunascape-docs.json` מתעדכן |
| אין שם, אך בשורש התיעוד יש README | הכותרת (H1) של README נכתבת מחדש |
| אין אף אחד מהשניים | נוצר `lunascape-docs.json` והשם נשמר בו |

ההודעה המוצגת לאחר השינוי מציינת לאן נכתב השם.

> **טיפ**
>
> שם המסמך נקבע בסדר הזה: השם שב-`lunascape-docs.json`, אחריו הכותרת של README שבשורש התיעוד, ואחריה שם התיקייה.

## שינוי שם קובץ או תיקייה

1. פתחו את תפריט הפריט ובחרו ב-[שינוי שם הקובץ] או ב-[שינוי שם התיקייה].
2. הזינו את השם החדש ולחצו על [שינוי].

גם התרגומים המתאימים (אותו נתיב תחת `i18n/<שפה>/`) משנים את שמם יחד איתו.

## מחיקה

1. פתחו את תפריט הפריט ובחרו ב-[העברה לאשפה].
2. בדקו את תוכן הודעת האישור ואשרו את ההעברה.

הפריט מועבר לאשפה של מערכת ההפעלה, ולכן אפשר לשחזר אותו במידת הצורך. התרגומים אינם נמחקים ונשארים במקומם.

## שמות שאי אפשר להשתמש בהם

- שמות המתחילים ב-`.` (מפני שאינם מופיעים ב-INDEX)
- `i18n` (שמור לקובצי תרגום)
- שמות השמורים ב-Windows (‏`CON`, `PRN` וכדומה)
- שמות המסתיימים בנקודה או ברווח
- שמות הכוללים תווי בקרה או תווים שאינם מותרים בשמות קבצים
- שמות הקיימים כבר באותה תיקייה (כולל שמות הנבדלים זה מזה רק באותיות גדולות וקטנות)

> **הערה**
>
> אי אפשר לשנות את שם דף הפתיחה (בדרך כלל `README.md` שבשורש) ואי אפשר להעביר אותו. שנו תחילה את `startPage` ב-`lunascape-docs.json`.
