# 문서 정보 표시하기

문서의 맨 앞에 둔 "문서 관리표"(문서 ID, 판, 갱신일, 상태 등의 표)는 열람할 때 작은 "문서 정보" 행으로 정리되어 표시됩니다. Markdown 자체는 평범한 표 그대로이므로 GitHub에서도 그대로 읽을 수 있습니다.

## 표시되기 위한 조건

제목(H1) 바로 뒤에 다음과 같은 2열 표를 둡니다.

```markdown
# 기능 요건 정의서

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- "文書ID" 행이 있고, 여러 개의 관리 항목이 있는 것이 조건입니다.
- `## 文書管理` 또는 `## Document information`이라는 제목 아래에 둔 표도 대상입니다.
- 본문 도중에 있는 표나, 일반적인 "항목／내용" 표는 변환되지 않습니다.

## 표시 방법

- 열람할 때는 "상태"와 "갱신일"만 작게 표시합니다.
- 행을 누르면 모든 항목을 표시합니다.
- 인쇄할 때는 모든 항목을 표시합니다.
- 편집 화면에서는 일반 표로 표시되며, 그대로 편집할 수 있습니다.

> **힌트**
>
> 접지 않고 항상 표로 표시하고 싶을 때는 [표시 설정]의 [문서 정보 접기]를 끕니다.
