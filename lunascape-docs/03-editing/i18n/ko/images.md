# 이미지 크기 조정하기

문서에 넣은 이미지는 본문의 너비와 화면의 높이에 맞춰 자동으로 들어맞습니다. 특정 크기로 보여주고 싶은 이미지에는 너비를 지정할 수 있습니다.

## 자동 조정의 원리

- 일반적인 Markdown 이미지(`![설명](./images/screen.png)`)는 본문의 너비에 맞도록 축소됩니다. 원래 이미지보다 크게 확대되지는 않습니다.
- 세로로 긴 스크린샷은 화면 높이의 72% 또는 720px 중 작은 쪽까지로 제한됩니다.

## 편집 화면에서 너비 지정하기

1. [편집]을 누르고 비주얼 표시에서 이미지를 선택합니다.
2. 도구 모음의 [이미지 크기]에서 너비를 선택합니다.
3. [저장]을 누릅니다.

| 선택지 | 너비 |
|---|---|
| [자동] | 지정 없음(자동 조정) |
| [작게 (360px)] | 360px |
| [중간 (560px)] | 560px |
| [크게 (760px)] | 760px |
| [본문 너비 (920px)] | 920px |
| [직접 입력…] | 16〜4096px 사이의 임의의 정수 |

## Markdown에서 너비 지정하기

HTML의 `img` 태그에 숫자로 된 `width`를 지정합니다. GitHub나 MDX에서도 동일하게 표시되는 작성 방식입니다.

```html
<img src="./images/screen.png" alt="설정 화면" width="360" />
```

> **참고**
>
> - `width`에는 숫자만 지정합니다. `px`나 `%`는 붙이지 않습니다. 본문 너비보다 큰 값을 지정해도 화면에는 본문 너비에 맞춰 표시됩니다.
> - 이미지는 문서로부터의 상대 경로로 지정합니다. 문서 루트 밖에 있는 이미지는 표시되지 않습니다.
