# 문서 정렬 순서 변경하기

INDEX에 표시되는 순서는 끌어서 놓기 또는 키보드로 변경할 수 있습니다. 변경한 순서는 문서의 front matter에 `navigation.order`로 저장됩니다.

## 끌어서 놓기로 정렬하기

1. INDEX에서 문서 또는 폴더를 끕니다.
2. 같은 계층의 앞뒤 또는 폴더 위에 놓습니다.
   같은 계층 안에서는 순서가 바뀝니다. 다른 폴더에 놓으면 그 폴더로 이동합니다.

## 키보드나 메뉴로 정렬하기

- INDEX 항목에 포커스를 두고 `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓`를 누릅니다.
- 항목 메뉴에서 [위로 이동] / [아래로 이동]을 선택합니다.

## 저장되는 내용

- 같은 계층에서 정렬했을 때는 정본 문서의 front matter에 있는 `navigation.order`를 갱신합니다. 폴더의 경우에는 해당 폴더의 `README.md`에 기록합니다. `README.md`가 없는 폴더에서는 front matter만 있는 `README.md`를 만듭니다.
- 다른 폴더로 이동했을 때는 정본과 대응하는 번역본을 함께 이동합니다. 이동하기 전에 상대 링크에 미치는 영향에 대한 확인이 표시됩니다.
- Git 스테이징이나 커밋은 하지 않습니다.

> **참고**
>
> - 필터링 중, 문서 편집 중, 신뢰하지 않는 작업 영역에서는 정렬할 수 없습니다.
> - "INDEX가 업데이트되었습니다"라고 표시되었을 때는 다른 변경이 막 반영된 직후입니다. 다시 한 번 조작하십시오.
> - 시작 페이지는 다른 폴더로 이동할 수 없습니다.

> **힌트**
>
> `navigation.order`는 100, 200, 300과 같이 100 단위로 지정하면 나중에 사이에 끼워 넣기 쉬워집니다. 자세한 내용은 [탐색 정보 설정하기](../04-document-tools/navigation-metadata.md)를 참조하십시오.
