# 문서와 폴더 만들기·정리하기

INDEX의 항목 메뉴에서 문서와 폴더를 만들고, 복제하고, 이름을 바꾸고, 삭제할 수 있습니다. 입력은 뷰어 안의 작은 대화 상자에서 이루어지므로 읽기를 중단하지 않습니다.

> **주의**
>
> 이 작업들은 VS Code에서 작업 영역을 신뢰한 경우에만 사용할 수 있습니다. 문서를 편집하는 중이거나, 다른 작업이 처리되는 중이거나, 대상에 저장하지 않은 변경 사항이 있을 때는 실행할 수 없습니다.

## 문서나 폴더 만들기

1. 만들 위치가 될 폴더의 항목 메뉴([⋯] 또는 마우스 오른쪽 버튼 클릭)를 엽니다.
   문서 루트 바로 아래에 만들 때는 INDEX 제목 오른쪽 끝의 [⋯]를 사용하거나 INDEX의 빈 부분을 마우스 오른쪽 버튼으로 클릭합니다.
2. [새 문서] 또는 [새 폴더]를 선택합니다.
3. 이름을 입력하고 [작성]을 누릅니다.
   문서 이름에는 Markdown 확장자(`.md`, `.markdown`, `.mdx` 등)가 필요합니다.

새 문서는 기본 언어의 문서(정본 문서)로 만들어집니다.

## 문서 복제하기

1. 문서의 항목 메뉴를 열고 [복제]를 선택합니다.
2. 새 이름을 입력하고 [작성]을 누릅니다.

복제되는 것은 정본 문서뿐입니다. 번역본은 복제되지 않습니다.

## 제목 변경하기

문서의 제목(H1)을 변경합니다. 파일 이름은 바뀌지 않습니다.

1. 문서나 폴더의 항목 메뉴를 열고 [제목 변경]을 선택합니다.
2. 새 제목을 한 줄로 입력하고 [변경]을 누릅니다.

폴더의 경우에는 그 폴더의 `README.md` 제목이 변경됩니다. 표시 중인 언어가 번역본일 때는 해당 언어 문서의 제목이 바뀝니다.

## 문서 이름 변경하기

도구 모음에 표시되는 문서 이름(문서 루트의 이름)을 변경합니다.

1. 도구 모음의 문서 이름을 마우스 오른쪽 버튼으로 클릭합니다. INDEX 제목 오른쪽 끝의 [⋯]에서도 열 수 있습니다.
2. [문서 이름 변경]을 선택하고 새 이름을 입력합니다.

설정하지 않은 경우에는 폴더 이름이 그대로 표시됩니다.

변경한 이름은 **지금 문서 이름으로 사용되고 있는 곳**에 기록합니다. 표시에 사용되지 않는 곳에 기록해서 보이는 제목이 무시되는 상태로 만들지는 않습니다.

| 현재 상태 | 기록되는 곳 |
|---|---|
| `lunascape-docs.json`에 이름이 있음 | `lunascape-docs.json`을 갱신합니다 |
| 이름은 없지만 문서 루트에 README가 있음 | README의 제목(H1)을 다시 씁니다 |
| 둘 다 없음 | `lunascape-docs.json`을 만들어 저장합니다 |

어느 쪽에 기록했는지는 변경 후의 메시지에 표시됩니다.

> **팁**
>
> 문서 이름은 `lunascape-docs.json`의 이름 → 문서 루트 README의 제목 → 폴더 이름 순서로 정해집니다.

## 파일 이름이나 폴더 이름 변경하기

1. 항목 메뉴를 열고 [파일 이름 변경] 또는 [폴더 이름 변경]을 선택합니다.
2. 새 이름을 입력하고 [변경]을 누릅니다.

대응하는 번역본(`i18n/<언어>/` 아래의 같은 경로)도 함께 변경됩니다.

## 삭제하기

1. 항목 메뉴를 열고 [휴지통으로 이동]을 선택합니다.
2. 확인 메시지의 내용을 확인하고 이동을 승인합니다.

대상은 OS의 휴지통으로 이동하므로 필요하면 복원할 수 있습니다. 번역본은 삭제되지 않고 그대로 남습니다.

## 이름에 사용할 수 없는 것

- `.`으로 시작하는 이름(INDEX에 표시되지 않기 때문입니다)
- `i18n`(번역 파일용으로 예약되어 있습니다)
- Windows에서 예약된 이름(`CON`, `PRN` 등)
- 끝이 마침표나 공백으로 끝나는 이름
- 제어 문자나 파일 이름에 사용할 수 없는 문자
- 같은 폴더에 이미 있는 이름(대소문자만 다른 이름도 포함합니다)

> **주의**
>
> 시작 페이지(보통은 루트의 `README.md`)는 이름 변경이나 이동을 할 수 없습니다. 먼저 `lunascape-docs.json`의 `startPage`를 변경하십시오.
