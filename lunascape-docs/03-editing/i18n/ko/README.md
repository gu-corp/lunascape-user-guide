# 문서 편집하기

문서는 뷰어 안에서 그대로 편집할 수 있습니다. 편집 화면에는 보이는 그대로 편집하는 "비주얼 표시"와 "Markdown 소스 표시"가 있으며, 버튼 하나로 전환합니다.

## 편집 시작하기

다음 중 하나를 누릅니다. 모두 같은 편집 화면이 열립니다.

- 본문 오른쪽 아래의 [편집]
- 본문 오른쪽 위의 [⋯](기타 작업) → [편집]
- INDEX의 항목 메뉴 → [편집]

## 편집하기

1. 본문을 직접 편집합니다.
   편집 화면 위쪽의 도구 모음에서 단락 서식(본문, 제목 1~4, 인용, 코드), [굵게], [기울임꼴], [글머리 기호 목록], [번호 매기기 목록], [링크], [표 삽입], [이미지 크기], [실행 취소], [다시 실행]을 사용할 수 있습니다.
2. Markdown 소스를 직접 편집하려면 [Markdown]을 누릅니다.
   다시 누르면 비주얼 표시로 돌아갑니다. 마지막으로 사용한 표시는 기억되며, 다음에 [편집]을 누를 때 복원됩니다.
3. [저장]을 누릅니다.
   Markdown 파일에 기록되고 읽기 표시로 돌아갑니다. 중단하려면 [취소]를 누릅니다.

> **참고**
>
> - 저장은 파일에 기록하는 작업만 수행합니다. Git의 스테이징이나 커밋은 자동으로 수행하지 않습니다.
> - 수식, Mermaid, TikZ, Vega-Lite 등의 다이어그램은 비주얼 표시에서 렌더링 결과를 표시합니다. 내용을 변경하려면 [Markdown]으로 전환합니다.
> - MDX 고유의 구문(컴포넌트나 `import` 등)이 포함된 문서는 구문을 유지하기 위해 Markdown 표시에서만 편집합니다.
> - front matter(맨 앞의 `---`로 둘러싸인 설정)는 비주얼 표시에서 편집해도 유지됩니다.

> **힌트**
>
> - [VS Code에서 열기]를 누르면 일반 텍스트 편집기에서 열 수 있습니다. 텍스트 편집기에서 저장하면 뷰어의 표시도 자동으로 갱신됩니다.
> - [편집] 버튼을 표시하고 싶지 않을 때는 [표시 설정]의 [편집 버튼]을 끕니다. 프로젝트 전체에서 숨기려면 `lunascape-docs.json`의 `editor.showEditButton`을 `false`로 설정합니다.
> - 처음에 열리는 표시(비주얼/Markdown)의 기본값은 설정 `lunascapeDocEditor.editor.defaultMode` 또는 `lunascape-docs.json`의 `editor.defaultMode`에서 변경할 수 있습니다.
