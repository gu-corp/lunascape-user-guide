# 更改文档排序

INDEX 中显示的顺序可以通过拖放或键盘更改。更改后的顺序会作为 `navigation.order` 保存到文档的 front matter 中。

## 通过拖放排序

1. 在 INDEX 中拖动文档或文件夹。
2. 将其放到同级项目的前后，或放到文件夹上。
   在同一层级内会改变顺序。放到其他文件夹上时，会移动到该文件夹中。

## 通过键盘或菜单排序

- 将焦点置于 INDEX 的项目上，按 `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓`。
- 在项目菜单中选择 [上移一项] / [下移一项]。

## 保存的内容

- 在同一层级内排序时，会更新正本文档 front matter 中的 `navigation.order`。文件夹的情况下，写入该文件夹的 `README.md`。对于没有 `README.md` 的文件夹，会创建仅含 front matter 的 `README.md`。
- 移动到其他文件夹时，会将正本文档及其对应的翻译版本一并移动。移动前会显示确认，说明对相对链接的影响。
- 不会执行 Git 的暂存或提交。

> **注意**
>
> - 在筛选过程中、编辑文档过程中，以及在不受信任的工作区中，无法排序。
> - 显示"INDEX 已更新"时，表示刚刚应用了其他更改。请重新操作一次。
> - 起始页无法移动到其他文件夹。

> **提示**
>
> 将 `navigation.order` 按 100、200、300 这样以 100 为间隔设置，以后便于在中间插入。详情请参阅[设置导航信息](../04-document-tools/navigation-metadata.md)。
