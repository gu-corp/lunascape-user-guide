# 调整图片尺寸

贴入文档的图片会自动适应正文的宽度和屏幕的高度。对于需要以特定大小显示的图片，可以指定其宽度。

## 自动调整的原理

- 普通的 Markdown 图片（`![说明](./images/screen.png)`）会缩小到适应正文的宽度。它不会被放大到超过原始尺寸。
- 竖长的截图会被限制在屏幕高度的 72% 或 720px 中较小的那一个以内。

## 在编辑界面中指定宽度

1. 按 [编辑]，在可视化视图中选择图片。
2. 从工具栏的 [图片尺寸] 中选择宽度。
3. 按 [保存]。

| 选项 | 宽度 |
|---|---|
| [自动] | 不指定（自动调整） |
| [小 (360px)] | 360px |
| [中 (560px)] | 560px |
| [大 (760px)] | 760px |
| [正文宽度 (920px)] | 920px |
| [自定义…] | 16〜4096px 之间的任意整数 |

## 在 Markdown 中指定宽度

为 HTML 的 `img` 标签指定数值形式的 `width`。这种写法在 GitHub 和 MDX 中也能同样显示为图片。

```html
<img src="./images/screen.png" alt="设置界面" width="360" />
```

> **注意**
>
> - `width` 只指定数值，不加 `px` 或 `%`。即使指定了大于正文宽度的值，显示时也会收敛到正文的宽度。
> - 图片使用相对于文档的路径指定。文档根目录之外的图片不会显示。
