# 显示文档信息

放在文档开头的“文档管理表”（含文档 ID、版本、更新日期、状态等的表格），在阅读时会汇总显示为一行小小的“文档信息”。Markdown 本身仍是普通表格，因此在 GitHub 上也能照常阅读。

## 显示的条件

在标题（H1）的正下方，放置如下所示的 2 列表格。

```markdown
# 功能需求定义书

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- 条件是表格中包含“文档 ID”行，并且有多个管理项目。
- 放在 `## 文書管理` 或 `## Document information` 标题下的表格同样会被识别。
- 正文中间的表格，以及一般的“项目／内容”表格，不会被转换。

## 显示方式

- 阅读时只以小字显示“状态”和“更新日期”。
- 点击该行，即可显示所有项目。
- 打印时会显示所有项目。
- 在编辑界面中会显示为普通表格，可以直接编辑。

> **提示**
>
> 若希望始终以表格形式显示而不折叠，请在 [显示设置] 中关闭 [折叠文档信息]。
