# 编辑文档

文档可以直接在查看器中编辑。编辑界面分为所见即所得的“可视视图”和“Markdown 源码视图”，用一个按钮即可切换。

## 开始编辑

按下以下任意一项。它们打开的都是同一个编辑界面。

- 正文右下角的 [编辑]
- 正文右上角的 [⋯]（更多操作）→ [编辑]
- INDEX 的项目菜单 → [编辑]

## 编辑

1. 直接编辑正文。
   编辑界面顶部的工具栏提供段落格式（正文、标题 1～4、引用、代码）、[粗体]、[斜体]、[项目符号列表]、[编号列表]、[链接]、[插入表格]、[图片尺寸]、[撤销]、[重做]。
2. 要直接编辑 Markdown 源码时，按 [Markdown]。
   再按一次即可返回可视视图。系统会记住上次使用的视图，下次按 [编辑] 时会恢复该视图。
3. 按 [保存]。
   内容将写入 Markdown 文件，并返回阅读视图。要放弃编辑时，请按 [取消]。

> **注意**
>
> - 保存只会写入文件，不会自动执行 Git 的暂存或提交。
> - 公式以及 Mermaid、TikZ、Vega-Lite 等图，在可视视图中显示为渲染结果。要修改其内容，请切换到 [Markdown]。
> - 包含 MDX 专用语法（组件、`import` 等）的文档，为保持语法完整，只能在 Markdown 视图中编辑。
> - front matter（开头由 `---` 包围的设置）在可视视图中编辑后也会保留。

> **提示**
>
> - 按 [在 VS Code 中打开]，即可用普通文本编辑器打开。在文本编辑器中保存后，查看器的显示也会自动更新。
> - 不想显示 [编辑] 按钮时，请关闭 [显示设置] 中的 [编辑按钮]。要在整个项目中隐藏，请将 `lunascape-docs.json` 的 `editor.showEditButton` 设为 `false`。
> - 首次打开的视图（可视／Markdown）的默认值，可通过设置 `lunascapeDocEditor.editor.defaultMode` 或 `lunascape-docs.json` 的 `editor.defaultMode` 更改。
