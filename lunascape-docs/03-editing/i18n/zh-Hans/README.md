# 编辑文档

文档可以直接在查看器中编辑。编辑界面有所见即所得的“可视化视图”和“Markdown 源码视图”，用一个按钮即可切换。

## 开始编辑

按下以下任意一项。它们都会打开同一个编辑界面。

- 正文右下角的 [编辑]
- 正文右上角的 [⋯]（更多操作）→ [编辑]
- INDEX 的条目菜单 → [编辑]

## 编辑

1. 直接编辑正文。
   在编辑界面顶部的工具栏中，可以使用段落格式（正文、标题 1～4、引用、代码）、[粗体]、[斜体]、[项目符号列表]、[编号列表]、[链接]、[插入表格]、[图片尺寸]、[撤销]、[重做]。
2. 想直接编辑 Markdown 源码时，按 [Markdown]。
   再按一次即可返回可视化视图。系统会记住上次使用的视图，下次按 [编辑] 时予以恢复。
3. 按 [保存]（也可以用 Ctrl+S／⌘S 保存）。
   内容会写入 Markdown 文件，并返回阅读视图。想停止编辑并恢复到上次保存的内容时，按 [放弃编辑]。

## 始终从编辑界面开始（编辑模式）

按下工具栏的 [编辑模式] 将其开启后，每次打开文档都会从编辑界面开始。适合像记事本那样持续书写时使用。

- 开启期间，即使按 [保存]，编辑界面也不会关闭。[放弃编辑] 会恢复到上次保存的内容，而编辑界面保持不变。
- 再按一次即可关闭，并返回阅读视图。开启／关闭状态会按每个用户分别记住。
- 在无法写入的文档根目录（例如 GitHub 的只读来源）中不会显示。

## 未保存的编辑

未保存的编辑会自动保留在本设备上。即使切换到其他文档，或关闭标签页或窗口，也不会丢失。

- 编辑界面中的 [未保存] 表示内容与上次保存的内容存在差异。
- 下次打开同一文档时，会从保留的编辑继续，并予以提示。如果原文档在此期间已更新，也会一并提示。可用 [放弃编辑] 恢复到最新内容。
- 保留的编辑会在按 [保存] 或 [放弃编辑] 后消失。由于并未保存，因此不会出现在 Git 或草稿中。

> **注意**
>
> - 保存仅执行向文件的写入。不会自动进行 Git 的暂存或提交。
> - 数学公式，以及 Mermaid、TikZ、Vega-Lite 等图表，在可视化视图中显示为渲染结果。要修改其内容，请切换到 [Markdown]。
> - 包含 MDX 特有语法（组件或 `import` 等）的文档，为保持语法完整，仅在 Markdown 视图中编辑。
> - front matter（开头用 `---` 括起的设置）在可视化视图中编辑时也会予以保留。

> **提示**
>
> - 按 [在 VS Code 中打开] 可在普通文本编辑器中打开。在文本编辑器中保存后，查看器的显示也会自动更新。
> - 不想显示 [编辑] 按钮时，请关闭 [显示设置] 中的 [编辑按钮]。要在整个项目中隐藏，请将 `lunascape-docs.json` 的 `editor.showEditButton` 设为 `false`。
> - 首次打开的视图（可视化／Markdown）的默认值，可通过设置 `lunascapeDocEditor.editor.defaultMode` 或 `lunascape-docs.json` 的 `editor.defaultMode` 更改。
