# 创建和整理文档与文件夹

在 INDEX 的项目菜单中，可以创建、复制、重命名和删除文档与文件夹。输入在查看器内的小对话框中完成，不会中断阅读。

> **注意**
>
> 这些操作仅在 VS Code 中信任该工作区时才可使用。文档正在编辑、其他操作正在处理，或对象存在未保存的更改时，无法执行。

## 创建文档或文件夹

1. 打开目标文件夹的项目菜单（[⋯] 或右键单击）。
   若要直接在文档根目录下创建，请使用 INDEX 标题右端的 [⋯]，或右键单击 INDEX 的空白处。
2. 选择 [新建文档] 或 [新建文件夹]。
3. 输入名称，然后按 [创建]。
   文档名需要带 Markdown 扩展名（`.md`、`.markdown`、`.mdx` 等）。

新文档会作为默认语言的文档（正本文档）创建。

## 创建文档副本

1. 打开文档的项目菜单，选择 [创建副本]。
2. 输入新名称，然后按 [创建]。

只复制正本文档，翻译版本不会被复制。

## 修改标题

修改文档的标题（H1）。文件名不变。

1. 打开文档或文件夹的项目菜单，选择 [修改标题]。
2. 用一行输入新标题，然后按 [修改]。

对于文件夹，修改的是该文件夹中 `README.md` 的标题。当前显示的是翻译版本时，修改的是该语言文档的标题。

## 修改文档名

修改工具栏中显示的文档名（文档根目录的名称）。

1. 右键单击工具栏中的文档名。也可以从 INDEX 标题右端的 [⋯] 打开。
2. 选择 [修改文档名]，然后输入新名称。

未进行设置时，直接显示文件夹名。

修改后的名称会写入**当前用作文档名的位置**，不会写到未用于显示的位置，以免让可见的标题被忽略。

| 当前状态 | 写入位置 |
|---|---|
| `lunascape-docs.json` 中有名称 | 更新 `lunascape-docs.json` |
| 没有名称，但文档根目录有 README | 改写 README 的标题（H1） |
| 两者都没有 | 创建 `lunascape-docs.json` 并保存 |

写入了哪一处，会在修改后的消息中显示。

> **提示**
>
> 文档名按以下顺序确定：`lunascape-docs.json` 中的名称 → 文档根目录 README 的标题 → 文件夹名。

## 修改文件名或文件夹名

1. 打开项目菜单，选择 [修改文件名] 或 [修改文件夹名]。
2. 输入新名称，然后按 [修改]。

对应的翻译版本（`i18n/<语言>/` 下的同一路径）也会一并修改。

## 删除

1. 打开项目菜单，选择 [移至回收站]。
2. 确认提示消息的内容，然后批准移动。

对象会移至操作系统的回收站，必要时可以恢复。翻译版本不会被删除，会原样保留。

## 不能使用的名称

- 以 `.` 开头的名称（因为不会显示在 INDEX 中）
- `i18n`（保留给翻译文件使用）
- Windows 中的保留名称（`CON`、`PRN` 等）
- 以句点或空格结尾的名称
- 包含控制字符或文件名中不可使用字符的名称
- 同一文件夹中已存在的名称（包括仅大小写不同的名称）

> **注意**
>
> 起始页（通常是根目录的 `README.md`）无法重命名或移动。请先修改 `lunascape-docs.json` 中的 `startPage`。
