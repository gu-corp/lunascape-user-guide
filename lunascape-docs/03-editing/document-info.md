# 文書情報を表示する

文書の先頭に置いた「文書管理表」（文書 ID、版、更新日、状態などの表）は、閲覧時に小さな「文書情報」の行にまとめて表示されます。Markdown 自体は普通の表のままなので、GitHub でもそのまま読めます。

## 表示されるための条件

見出し（H1）の直後に、次のような 2 列の表を置きます。

```markdown
# 機能要件定義書

| 項目 | 内容 |
|---|---|
| 文書ID | REQ-001 |
| 版 | 1.0 |
| 更新日 | 2026-08-31 |
| 状態 | 承認済み |
| 文書責任者 | G.U.Corp |
```

- 「文書ID」の行と、複数の管理項目があることが条件です。
- `## 文書管理` または `## Document information` という見出しの下に置いた表も対象です。
- 本文の途中にある表や、一般的な「項目／内容」の表は変換されません。

## 表示のしかた

- 閲覧時は「状態」と「更新日」だけを小さく表示します。
- 行を押すと、すべての項目を表示します。
- 印刷時はすべての項目を表示します。
- 編集画面では通常の表として表示され、そのまま編集できます。

> **ヒント**
>
> 折りたたまずに常に表として表示したいときは、[表示設定] の [文書情報を折りたたむ] をオフにします。
