# テンプレートから文書を作成する

文書ツールの [作成] タブでは、テンプレートを選んで内容をプレビューしてから、新しい文書を作成できます。

1. ツールバーの [文書ツール] を押し、[作成] タブを開きます。
2. [テンプレートから作成] を押し、テンプレートを選びます。
3. 入力項目（タイトル、概要など）を入力します。必須の項目には「必須」と表示されます。
4. 保存先を、文書ルートからの相対パスで入力します（例: `03-design/api.md`）。
5. [プレビュー] を押し、生成される Markdown を確認します。
6. [この内容で作成] を押します。
   文書が作成され、ビューアーに表示されます。続けて、文書ルート全体のチェックが実行されます。

## 選べるテンプレート

| テンプレート | 内容 |
|---|---|
| 1ページ文書 | 短い仕様、メモ、単独の説明文書を 1 ファイルで作成します |
| 仕様書・マニュアル・ヘルプ | 仕様書、マニュアル、ヘルプに使える汎用的な章立てで 1 ファイルを作成します |
| Standard Pack のテンプレート | `lunascape-docs.json` で Standard Pack を選んでいると、そのプロファイルで使える文書種別（要件定義書、設計書など）が加わります |

> **ご注意**
>
> - 作成には信頼済みのワークスペースが必要です。
> - 既存のファイルは上書きしません。保存先に同じ名前の文書があると作成できません。
> - 保存先には `.md` または `.mdx` の拡張子が必要です。`i18n` の下（翻訳版の場所）には作成できません。
> - 入力を変更したあとは、もう一度 [プレビュー] を押してから作成します。

> **ヒント**
>
> 文書フォルダがまだないプロジェクトでは、コマンドパレットの「Lunascape Docs: テンプレートからドキュメントを作成」で最初の一式を作成できます。[文書をはじめて作成する](../01-introduction/first-documents.md) を参照してください。
