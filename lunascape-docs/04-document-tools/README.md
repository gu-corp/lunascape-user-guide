# 文書ツールを使う

文書ツールは、文書のチェック、テンプレートからの作成、翻訳をまとめたパネルです。ツールバーの [文書ツール]（チェックマーク）から開きます。

## 文書ツールを開く

1. ツールバーの [文書ツール] を押します。
   画面右にパネルが開きます。
2. 上部のタブで機能を選びます。
3. パネルを閉じるには、[閉じる] を押すか、もう一度 [文書ツール] を押します。

| タブ | 機能 |
|---|---|
| [翻訳] | 表示中のページの翻訳案の作成、プロジェクトの言語設定、一括翻訳 |
| [チェック] | docs-lint による文書ルート全体のチェック、結果の一覧、ルールの確認と変更 |
| [作成] | 組み込みまたは Standard Pack のテンプレートからの文書作成 |

> **ヒント**
>
> - ツールバーの [文書ツール] には、チェック結果の状態（指摘なし、指摘の件数、再検証が必要など）が表示されます。
> - 言語メニューの [翻訳を作成・管理…] を選ぶと、[翻訳] タブが開いた状態で文書ツールが表示されます。

> **ご注意**
>
> - チェック設定の保存、テンプレートからの作成、翻訳は、VS Code でワークスペースを信頼している場合にだけ実行できます。
> - ヘルプの表示中や、文書ルートに属さないフォルダを一時的に開いているときは、一部の機能が使えません。
