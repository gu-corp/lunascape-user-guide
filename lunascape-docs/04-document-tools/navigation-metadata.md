# ナビゲーション情報を設定する

INDEX に表示する名前と順番は、各文書の YAML front matter に書きます。書かなくても文書は表示され、見出し（H1）とファイル名順が使われます。

## 文書の名前と順番

文書の先頭に、次のように書きます。

```yaml
---
navigation:
  title: はじめに
  order: 200
---
```

| 項目 | 内容 |
|---|---|
| `navigation.title` | INDEX に表示する名前です。省略すると H1、それもなければファイル名を使います |
| `navigation.order` | 並び順を決める整数です。小さい順に並びます。省略すると安定した既定の順（ファイル名順）になります |

> **ヒント**
>
> - `order` は 100、200、300 のように 100 刻みで付けると、あとから 150 のように間に差し込めます。
> - 未指定、不正、重複した `order` があっても文書は隠れません。
> - INDEX で並び替えると、`navigation.order` が自動的に書き込まれます。手で書く必要はありません。

## フォルダの名前と順番

フォルダの名前と順番は、そのフォルダの `README.md`（なければ `index.md`）の front matter が持ちます。表紙の本文がなくてもかまいません。

```yaml
---
navigation:
  title: 製品企画
  order: 100
---
```

表紙がないフォルダは、フォルダ名と既定の順番で表示されます。INDEX でタイトルの変更や並び替えを行ったときに必要であれば、front matter だけの `README.md` が作成されます。閲覧するだけでファイルが作られることはありません。

## 翻訳版での扱い

- 順番と、フォルダの役割（表紙か設定専用か）は、既定言語の文書だけが決めます。
- 翻訳版は `navigation.title` だけを上書きできます。正本に本文があるときは、翻訳版の H1 も名前として使われます。
- 翻訳版だけがあってもページは増えません。

## 子項目の並びと折りたたみ

フォルダの表紙で、直下の子項目の並びかたと最初の折りたたみ状態を指定する `navigation.children.sort` と `navigation.children.defaultCollapsed` が定義されています。VS Code での読み取りと編集は今後対応予定です。
