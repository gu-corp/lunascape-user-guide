# 使用文件工具

文件工具是一個面板，整合了文件檢查、從範本建立文件與翻譯等功能。請從工具列的 [文件工具]（勾選標記）開啟。

## 開啟文件工具

1. 按下工具列的 [文件工具]。
   面板會在畫面右側開啟。
2. 以上方的索引標籤選擇功能。
3. 若要關閉面板，請按 [關閉]，或再按一次 [文件工具]。

| 索引標籤 | 功能 |
|---|---|
| [翻譯] | 為目前顯示的頁面建立翻譯草案、設定專案的語言、批次翻譯 |
| [檢查] | 以 docs-lint 檢查整個文件根目錄、列出結果、確認與變更規則 |
| [建立] | 使用內建或 Standard Pack 的範本建立文件 |

> **提示**
>
> - 工具列的 [文件工具] 會顯示檢查結果的狀態（無問題、問題件數、需要重新驗證等）。
> - 在語言選單中選擇 [建立・管理翻譯…]，會在開啟 [翻譯] 索引標籤的狀態下顯示文件工具。

> **注意**
>
> - 儲存檢查設定、從範本建立文件與翻譯，只有在 VS Code 中信任工作區時才能執行。
> - 顯示說明時，或暫時開啟不屬於文件根目錄的資料夾時，部分功能無法使用。
