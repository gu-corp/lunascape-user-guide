# 從範本建立文件

在文件工具的 [建立] 分頁中，可以選擇範本並預覽內容，然後建立新的文件。

1. 按下工具列的 [文件工具]，開啟 [建立] 分頁。
2. 按下 [從範本建立]，選擇範本。
3. 填寫輸入項目（標題、概要等）。必填的項目會顯示「必填」。
4. 以文件根目錄的相對路徑輸入儲存位置（例如：`03-design/api.md`）。
5. 按下 [預覽]，確認產生的 Markdown。
6. 按下 [以此內容建立]。
   文件隨即建立並顯示於檢視器中。接著會執行整個文件根目錄的檢查。

## 可選用的範本

| 範本 | 內容 |
|---|---|
| 單頁文件 | 以 1 個檔案建立簡短的規格、備忘或單獨的說明文件 |
| 規格書、手冊、說明 | 以 1 個檔案建立適用於規格書、手冊、說明的通用章節架構 |
| Standard Pack 的範本 | 在 `lunascape-docs.json` 中選擇 Standard Pack 後，會加入該設定檔可使用的文件類型（需求定義書、設計書等） |

> **注意**
>
> - 建立時需要受信任的工作區。
> - 不會覆寫既有的檔案。若儲存位置已有同名文件，就無法建立。
> - 儲存位置需要 `.md` 或 `.mdx` 的副檔名。無法在 `i18n` 之下（翻譯版所在的位置）建立。
> - 變更輸入內容後，請再按一次 [預覽] 再建立。

> **提示**
>
> 在尚未有文件資料夾的專案中，可使用命令選擇區的「Lunascape Docs: 從範本建立文件」建立最初的一整套。請參閱[初次建立文件](../01-introduction/first-documents.md)。
