# প্রকল্প কনফিগারেশন

ডকুমেন্টেশন রুটের ঠিক নিচে থাকা `lunascape-docs.json` হলো দলের মধ্যে ভাগ করে নেওয়া ডকুমেন্টেশন রুটের সেটিংস। এটি Git দিয়ে পরিচালিত হয়।

## কনফিগারেশন ফাইল তৈরি বা সম্পাদনা করা

- টুলবারের [নথি সরঞ্জাম] → [পরীক্ষা] ট্যাব → [নিয়মের উৎস ও নথি সেটিংস] → [নথি সেটিংস সম্পাদনা করুন] চাপলে ফাইলটি VS Code-এ খোলে। ফাইলটি না থাকলে তখনই একটি প্রাথমিক ফাইল তৈরি হয়।
- `lunascape-docs.json` ফাইলনামের সঙ্গে সঙ্গে থাকা JSON Schema স্বয়ংক্রিয়ভাবে যুক্ত হয়, ফলে ইনপুট সম্পূর্ণকরণ ও প্রতিটি ক্ষেত্রের বিবরণ দেখা যায়। `$schema` লেখার প্রয়োজন নেই।

## কনফিগারেশনের উদাহরণ

```json
{
  "id": "product-docs",
  "title": "পণ্যের ডকুমেন্টেশন",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## ক্ষেত্রগুলোর বিবরণ

| ক্ষেত্র | বিষয়বস্তু | ডিফল্ট |
|---|---|---|
| `id` | ব্যবহারকারীভেদে প্রদর্শন সেটিংস সংরক্ষণের কী। ফোল্ডার সরালেও সেটিংস ধরে রাখতে চাইলে একটি স্থির ID দিন | ফোল্ডারের পাথ |
| `title` | টুলবারের বাঁ প্রান্তে ও ডকুমেন্টেশন রুটের তালিকায় দেখানো নাম। প্রদর্শন ভাষা বদলালেও এটি বদলায় না | রুটের README/index-এর শিরোনাম, না থাকলে ফোল্ডারের নাম |
| `indexTitle` | INDEX-এর শিরোনাম | `INDEX` |
| `startPage` | প্রথমে খোলা নথি (ডকুমেন্টেশন রুট থেকে আপেক্ষিক পাথ) | `README.md` |
| `appearance` | রঙের বিন্যাস। `light` (সবসময় উজ্জ্বল) বা `auto` (VS Code-এর থিম অনুসরণ করে) | `light` |
| `defaultLocale` | ডিফল্ট ভাষা (মূল নথির ভাষা)। BCP 47 ভাষা ট্যাগে (`ja`, `en`, `zh-Hant` ইত্যাদি) লিখুন। এটিই অনুবাদের উৎস | নির্ধারিত নয় (মূল লেখা থেকে অনুমান করে দেখানো হয়) |
| `fallbackLocale` | যে পাঠকের পরিবেশের ভাষা সমর্থিত ভাষাগুলোর কোনোটির সঙ্গে মেলে না, তাকে প্রথমে যে ভাষা দেখানো হবে। `locales`-এ থাকা একটি ভাষা লিখুন | নির্ধারিত নয় (`defaultLocale` ব্যবহৃত হয়) |
| `locales` | সমর্থিত ভাষার তালিকা। এতে `defaultLocale` অন্তর্ভুক্ত থাকে। এগুলোই ভাষা মেনু ও অনুবাদের লক্ষ্য হয় | কেবল `defaultLocale` |
| `ignoredDirectories` | INDEX, অনুসন্ধান ও পরীক্ষা থেকে বাদ দেওয়া ফোল্ডারের নাম। লিখলে ডিফল্টের বদলে এটি কার্যকর হয় | `["99-archive"]` |
| `tree` | INDEX কীভাবে দেখানো হবে তার ডিফল্ট মান। ব্যবহারকারী প্রদর্শন সেটিংস দিয়ে বদলাতে পারেন | উপরের উদাহরণ অনুযায়ী |
| `editor.defaultMode` | ব্যবহারকারী এখনো বদলাননি এমন অবস্থায় সম্পাদনার প্রদর্শন। `visual` বা `source` | `visual` |
| `editor.showEditButton` | নথির নিচে ডান দিকে [সম্পাদনা] দেখানো হবে কি না | `true` |
| `documentStandards.pack` | নথি পরীক্ষা ও টেমপ্লেটে ব্যবহৃত Standard Pack। `builtin:<নাম>`, অথবা ডকুমেন্টেশন রুট থেকে আপেক্ষিক পাথ | নেই |
| `documentStandards.profile` | Pack-এ সংজ্ঞায়িত প্রোফাইলের নাম | নেই |
| `translation.enabled` | অনুবাদের খসড়া তৈরি ও একসঙ্গে অনুবাদ সক্রিয় করে | `true` |
| `translation.contextFiles` | অনুবাদের সময় পরিভাষা ও লেখনশৈলীর উদাহরণ হিসেবে দেওয়া মূল নথির Markdown (ডকুমেন্টেশন রুট থেকে আপেক্ষিক পাথ) | `[]` |
| `translation.maxContextCharacters` | উদাহরণ নথিগুলোর মোট অক্ষরসংখ্যার ঊর্ধ্বসীমা (সর্বোচ্চ 1048576) | `49152` |
| `description` | নথিসমষ্টির এক লাইনের বর্ণনা। রিপোজিটরির হোমের কার্ডে দেখানো হয়। `title`-এর মতোই স্ট্রিং বা ভাষাভেদে অবজেক্ট আকারে লেখা যায় | নেই |

## রিপোজিটরির কোথায় নথি আছে তা জানানো

রিপোজিটরির ঠিক নিচে রাখা `lunascape-docs.json`-এ সেই ফোল্ডারের সেটিংস নয়, বরং **রিপোজিটরির মানচিত্র** লেখা যায়। নিচের তিনটি ক্ষেত্রের যেকোনো একটি লিখলে সেটি মানচিত্র হয়ে যায়, আর সেই ফোল্ডারটি নিজে ডকুমেন্টেশন রুট থাকে না।

| ক্ষেত্র | বিষয়বস্তু | ডিফল্ট |
|---|---|---|
| `defaultFolder` | নথিগুলো কোন ফোল্ডারে আছে (এই ফোল্ডার থেকে আপেক্ষিক পাথ)। যে ফোল্ডারকে নির্দেশ করে, সেখানে কোনো কনফিগারেশন ফাইল লাগে না | নেই (`docs` ব্যবহৃত হয়) |
| `roots` | একাধিক নথিসমষ্টি থাকলে তার তালিকা (এই ফোল্ডার থেকে আপেক্ষিক পাথ, প্রদর্শনের ক্রমে)। এ ক্ষেত্রে এই ফোল্ডারটিই হোম হয় | নেই |
| `excludes` | ডকুমেন্টেশন রুট খোঁজা থেকে বাদ দেওয়া ফোল্ডার (এই ফোল্ডার থেকে আপেক্ষিক পাথ)। `node_modules`-এর মতো ডিফল্ট বর্জনের সঙ্গে যোগ হয় | `[]` |
| `home.cards` | হোমের README-এর নিচে নথিসমষ্টির কার্ড দেখানো হবে কি না। README-এ নিজে লিংক লিখলে `false` করুন | `true` |

ডকুমেন্টেশন রুট নিচের ক্রমে নির্ধারিত হয়। উপর থেকে শুরু করে প্রথমে যেটি পাওয়া যায়, সেটিই ব্যবহৃত হয়।

1. সেটিংস বা কমান্ড দিয়ে কোনো ফোল্ডার নির্দিষ্ট করা হলে সেই ফোল্ডার
2. ঠিক নিচের `lunascape-docs.json`-এর `defaultFolder` বা `roots` যেখানে নির্দেশ করে
3. যে ফোল্ডারে `lunascape-docs.json` আছে (একই মূল ফোল্ডারের নিচে দুটি বা তার বেশি থাকলে সেই মূল ফোল্ডারটিই হোম)
4. `docs` ফোল্ডার (`lunascapeDocEditor.rootDirectoryNames`)
5. রিপোজিটরির ঠিক নিচের অংশটিই

> **ইঙ্গিত**
>
> কিছু না লিখলে ৪ নম্বরটি কাজ করে, তাই একটিমাত্র `docs/` আছে এমন সাধারণ রিপোজিটরি আগের মতোই চলে। ফোল্ডারের নাম `manual` রাখতে চাইলেই কেবল `defaultFolder` লিখুন।

### মানচিত্রের উদাহরণ

```json
{
  "title": "Lunascape সহায়তা",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## সেটিংসের অগ্রাধিকার

প্রদর্শন সংক্রান্ত ক্ষেত্রগুলো নিচের ক্রমে অগ্রাধিকার পায়।

1. ব্যবহারকারীর প্রদর্শন সেটিংস ([প্রদর্শন সেটিংস] প্যানেল)
2. VS Code-এর সেটিংস (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. পণ্যের ডিফল্ট মান

কেবল ভাষা (`defaultLocale`, `fallbackLocale`, `locales`) এর ব্যতিক্রম — এ ক্ষেত্রে `lunascape-docs.json`-ই চূড়ান্ত। VS Code-এর ব্যক্তিগত সেটিংস দিয়ে প্রকল্পের ভাষা বদলানো যায় না।

> **দ্রষ্টব্য**
>
> `docs-lint.config.json`-এও `standard` হিসেবে Standard Pack নির্দিষ্ট করা যায়। দুটিতেই থাকলে `docs-lint.config.json` অগ্রাধিকার পায়।
