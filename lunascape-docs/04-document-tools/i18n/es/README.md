# Usar las herramientas de documentos

Las herramientas de documentos son un panel que reúne la comprobación de documentos, la creación a partir de plantillas y la traducción. Se abre con [Herramientas de documentos] (marca de verificación) en la barra de herramientas.

## Abrir las herramientas de documentos

1. Presione [Herramientas de documentos] en la barra de herramientas.
   El panel se abre a la derecha de la pantalla.
2. Elija una función con las pestañas de la parte superior.
3. Para cerrar el panel, presione [Cerrar] o presione [Herramientas de documentos] otra vez.

| Pestaña | Función |
|---|---|
| [Traducir] | Propuestas de traducción de la página mostrada, configuración de idiomas del proyecto y traducción por lotes |
| [Comprobación] | Comprobación de toda la raíz de documentación con docs-lint, lista de resultados, y revisión y cambio de reglas |
| [Crear] | Creación de documentos a partir de plantillas integradas o del Standard Pack |

> **Sugerencia**
>
> - [Herramientas de documentos] en la barra de herramientas muestra el estado de la comprobación (sin observaciones, cantidad de observaciones, se requiere volver a validar, etc.).
> - Si elige [Crear y administrar traducciones…] en el menú de idiomas, las herramientas de documentos se abren con la pestaña [Traducir] seleccionada.

> **Nota**
>
> - Guardar la configuración de comprobación, crear a partir de plantillas y traducir solo se pueden ejecutar cuando el área de trabajo es de confianza en VS Code.
> - Mientras se muestra la ayuda, o mientras hay abierta temporalmente una carpeta que no pertenece a ninguna raíz de documentación, algunas funciones no están disponibles.
