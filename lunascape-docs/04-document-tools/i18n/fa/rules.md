# تغییر قواعد بررسی

می‌توانید سطح اعلان هر مورد بررسی (خطا، هشدار، اطلاعات) را تغییر دهید یا آن را خاموش کنید. تغییرها در `docs-lint.config.json` در ریشهٔ مستندات ذخیره می‌شود و با تیم به اشتراک گذاشته می‌شود.

## تغییر سطح اعلان

1. در نوار ابزار [ابزارهای سند] را فشار دهید و زبانهٔ [بررسی] را باز کنید.
2. [بررسی و تغییر قواعد] را فشار دهید.
   فهرست موارد بررسی در همان کارت باز می‌شود. هر مورد هدف خود و منبع تنظیم فعلی‌اش (Project، Profile، Pack یا Default) را نشان می‌دهد.
3. سطح اعلان مورد دلخواه خود را انتخاب کنید.
4. [ذخیره و بررسی دوباره] را فشار دهید.
   تنظیم ذخیره می‌شود و کل ریشهٔ مستندات با تنظیم جدید دوباره بررسی می‌شود.

| گزینه | معنی |
|---|---|
| [تنظیم استاندارد (…)] | بازنویسی را حذف می‌کند و به تنظیم استانداردی بازمی‌گردد که به‌ترتیب از پروفایل، Standard Pack و مقدار پیش‌فرض تعیین می‌شود |
| [خاموش] | این مورد بررسی نمی‌شود |
| [اطلاعات] / [هشدار] / [خطا] | با این سطح اعلان گزارش می‌شود |

> **توجه**
>
> - ذخیره‌سازی به فضای کاری مورد اعتماد نیاز دارد.
> - تنها سطح اعلان هر مورد ذخیره می‌شود. گزینه‌های هر مورد دست‌نخورده باقی می‌مانند. خودِ Standard Pack و پروفایل در این صفحه تغییر نمی‌کنند.
> - اگر `docs-lint.config.json` درست پیش از ذخیره‌سازی از بیرون تغییر کرده باشد، ذخیره‌سازی متوقف می‌شود. وضعیت به‌روز را بارگذاری کنید و دوباره تلاش کنید.
> - اگر `docs-lint.config.json` وجود نداشته باشد، هنگام ذخیره ساخته می‌شود.

## ویرایش مستقیم فایل‌های تنظیمات

- با فشردن [باز کردن تنظیمات پیشرفته]، فایل `docs-lint.config.json` در VS Code باز می‌شود.
- [منبع قواعد و تنظیمات سند] را باز کنید و [ویرایش تنظیمات سند] را فشار دهید تا `lunascape-docs.json` در VS Code باز شود. Standard Pack و پروفایل را اینجا انتخاب می‌کنید.

در هر دو فایل، تکمیل ورودی و توضیح‌ها بر پایهٔ JSON Schema همراه افزونه فعال است.

## Standard Pack و پروفایل‌ها

Standard Pack یک استاندارد مستندسازی است که انواع سند لازم، ساختار فصل‌ها، اصطلاحات و الگوها را گرد هم می‌آورد. آن را با `documentStandards` در `lunascape-docs.json` انتخاب می‌کنید.

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

Pack همراه محصول، یعنی `builtin:gu-corp-software`، پروفایل‌های `base`، `web-application`، `api-service`، `regulated-financial-product` و `smart-contract` را دارد.
