# تنظیمات پروژه

فایل `lunascape-docs.json` که مستقیماً زیر ریشهٔ مستندات قرار دارد، تنظیمات آن ریشهٔ مستندات است که در تیم به اشتراک گذاشته می‌شود. این فایل با Git مدیریت می‌شود.

## ساختن یا ویرایش فایل تنظیمات

- در نوار ابزار [ابزارهای سند] ← زبانهٔ [بررسی] ← [منبع قواعد و تنظیمات سند] ← [ویرایش تنظیمات سند] را فشار دهید تا فایل در VS Code باز شود. اگر فایل وجود نداشته باشد، در همان لحظه یک فایل اولیه ساخته می‌شود.
- نام فایل `lunascape-docs.json` به‌طور خودکار به JSON Schema همراه محصول پیوند می‌خورد و تکمیل خودکار و توضیح هر مورد نمایش داده می‌شود. نوشتن `$schema` لازم نیست.

## نمونهٔ تنظیمات

```json
{
  "id": "product-docs",
  "title": "مستندات محصول",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## شرح موردها

| مورد | محتوا | پیش‌فرض |
|---|---|---|
| `id` | کلیدی که تنظیمات نمایش هر کاربر با آن ذخیره می‌شود. اگر می‌خواهید با جابه‌جا شدن پوشه تنظیمات حفظ شود، یک شناسهٔ ثابت بگذارید | مسیر پوشه |
| `title` | نامی که در سمت چپ نوار ابزار و در فهرست ریشه‌های مستندات نمایش داده می‌شود. با تغییر زبان نمایش عوض نمی‌شود | عنوان README/index ریشه، و در نبود آن نام پوشه |
| `indexTitle` | عنوان INDEX | `INDEX` |
| `startPage` | سندی که نخست باز می‌شود (مسیر نسبی از ریشهٔ مستندات) | `README.md` |
| `appearance` | طرح رنگ. `light` (همیشه روشن) یا `auto` (پیروی از پوستهٔ VS Code) | `light` |
| `defaultLocale` | زبان پیش‌فرض (زبان سند مرجع). با برچسب زبان BCP 47 مانند `ja`، `en` یا `zh-Hant` مشخص می‌شود. مبدأ ترجمه است | تنظیم‌نشده (از متن حدس زده و نمایش داده می‌شود) |
| `fallbackLocale` | زبانی که نخست به خوانندگانی نشان داده می‌شود که زبان محیط آن‌ها با هیچ‌یک از زبان‌های پشتیبانی‌شده یکی نیست. زبانی را مشخص کنید که در `locales` باشد | تنظیم‌نشده (از `defaultLocale` استفاده می‌شود) |
| `locales` | فهرست زبان‌های پشتیبانی‌شده، شامل `defaultLocale`. این‌ها در منوی زبان می‌آیند و مقصد ترجمه می‌شوند | تنها `defaultLocale` |
| `ignoredDirectories` | نام پوشه‌هایی که از INDEX، جست‌وجو و بررسی کنار گذاشته می‌شوند. مشخص کردن آن جایگزین پیش‌فرض می‌شود | `["99-archive"]` |
| `tree` | مقدارهای پیش‌فرض نمایش INDEX. کاربر می‌تواند آن‌ها را در تنظیمات نمایش بازنویسی کند | مانند نمونهٔ بالا |
| `editor.defaultMode` | نمای ویرایش تا وقتی کاربر هنوز آن را عوض نکرده است. `visual` یا `source` | `visual` |
| `editor.showEditButton` | اینکه [ویرایش] در پایین سمت راست متن نمایش داده شود یا نه | `true` |
| `documentStandards.pack` | Standard Pack که برای بررسی سند و الگوها به کار می‌رود. `builtin:<نام>` یا مسیر نسبی از ریشهٔ مستندات | ندارد |
| `documentStandards.profile` | نام نمایه‌ای که Pack تعریف می‌کند | ندارد |
| `translation.enabled` | ساختن پیشنهاد ترجمه و ترجمهٔ گروهی را فعال می‌کند | `true` |
| `translation.contextFiles` | فایل‌های Markdown سند مرجع (مسیر نسبی از ریشهٔ مستندات) که هنگام ترجمه به‌عنوان مرجع اصطلاح و سبک نوشتار داده می‌شوند | `[]` |
| `translation.maxContextCharacters` | حد بالای مجموع تعداد نویسه‌های سندهای مرجع (حداکثر 1048576) | `49152` |
| `description` | توضیح یک‌خطی مجموعهٔ سندها. روی کارت‌های صفحهٔ خانهٔ مخزن نمایش داده می‌شود. مانند `title` می‌توان آن را به صورت رشته یا شیء تفکیک‌شده بر پایهٔ زبان نوشت | ندارد |

## گفتن اینکه سندها کجای مخزن هستند

در فایل `lunascape-docs.json` که مستقیماً زیر مخزن گذاشته می‌شود، می‌توان به‌جای تنظیمات آن پوشه، **نقشهٔ مخزن** را نوشت. اگر یکی از سه مورد زیر نوشته شود، فایل به نقشه تبدیل می‌شود و خود آن پوشه دیگر ریشهٔ مستندات نخواهد بود.

| مورد | محتوا | پیش‌فرض |
|---|---|---|
| `defaultFolder` | اینکه سندها در کدام پوشه هستند (مسیر نسبی از همان پوشه). پوشه‌ای که به آن اشاره می‌کند به فایل تنظیمات نیاز ندارد | ندارد (از `docs` استفاده می‌شود) |
| `roots` | وقتی چند مجموعه سند دارید، فهرست آن‌ها (مسیر نسبی از همان پوشه، به ترتیب نمایش). در این حالت، همان پوشه صفحهٔ خانه می‌شود | ندارد |
| `excludes` | پوشه‌هایی که از یافتن ریشهٔ مستندات کنار گذاشته می‌شوند (مسیر نسبی از همان پوشه). به کنارگذاشته‌های پیش‌فرض مانند `node_modules` افزوده می‌شود | `[]` |
| `home.cards` | اینکه در صفحهٔ خانه زیر README کارت‌های مجموعه‌های سند نمایش داده شود یا نه. اگر پیوندها را خودتان در README می‌نویسید، آن را `false` کنید | `true` |

ریشهٔ مستندات به ترتیب زیر تعیین می‌شود. از بالا به پایین، نخستین موردی که پیدا شود به کار می‌رود.

1. وقتی پوشه‌ای را با تنظیمات یا فرمان مشخص کرده باشید، همان پوشه
2. جایی که `defaultFolder` یا `roots` در `lunascape-docs.json` زیر مخزن به آن اشاره می‌کند
3. پوشه‌ای که `lunascape-docs.json` دارد (اگر زیر یک والد مشترک دو تا یا بیشتر باشد، آن والد صفحهٔ خانه می‌شود)
4. پوشهٔ `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. خود ریشهٔ مخزن

> **نکته**
>
> اگر چیزی ننویسید مورد ۴ عمل می‌کند، پس مخزن معمولی که یک `docs/` دارد مانند گذشته کار می‌کند. تنها وقتی نام پوشه را `manual` می‌خواهید، `defaultFolder` را بنویسید.

### نمونهٔ نقشه

```json
{
  "title": "راهنمای Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## ترتیب اولویت تنظیمات

موردهای مربوط به نمایش، به ترتیب زیر اولویت دارند.

1. تنظیمات نمایش کاربر (پنل [تنظیمات نمایش])
2. تنظیمات VS Code (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. مقدارهای پیش‌فرض محصول

تنها زبان‌ها (`defaultLocale`، `fallbackLocale`، `locales`) استثنا هستند و `lunascape-docs.json` در آن‌ها مرجع است. با تنظیمات شخصی VS Code نمی‌توان زبان‌های پروژه را بازنویسی کرد.

> **توجه**
>
> در `docs-lint.config.json` نیز می‌توان Standard Pack را با کلید `standard` مشخص کرد. اگر در هر دو باشد، `docs-lint.config.json` اولویت دارد.
