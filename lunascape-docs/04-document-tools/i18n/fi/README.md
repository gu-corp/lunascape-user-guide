# Dokumenttityökalujen käyttö

Dokumenttityökalut on paneeli, joka kokoaa yhteen dokumenttien tarkistuksen, luomisen mallista ja käännökset. Avaa se työkalurivin painikkeesta [Dokumenttityökalut] (valintamerkki).

## Dokumenttityökalujen avaaminen

1. Paina työkalurivin painiketta [Dokumenttityökalut].
   Paneeli avautuu näytön oikeaan reunaan.
2. Valitse toiminto yläreunan välilehdillä.
3. Sulje paneeli painamalla [Sulje] tai painamalla [Dokumenttityökalut] uudelleen.

| Välilehti | Toiminto |
|---|---|
| [Käännä] | Näkyvillä olevan sivun käännösehdotuksen luominen, projektin kieliasetukset, joukkokäännös |
| [Tarkistus] | Koko dokumenttijuuren tarkistus docs-lintillä, tulosten luettelo, sääntöjen tarkastelu ja muuttaminen |
| [Luo] | Dokumentin luominen sisäänrakennetusta tai Standard Pack -mallista |

> **Vinkki**
>
> - Työkalurivin painike [Dokumenttityökalut] näyttää tarkistuksen tilan (ei huomautuksia, huomautusten määrä, uudelleentarkistus tarpeen ja niin edelleen).
> - Kun valitset kielivalikosta [Luo tai hallitse käännöksiä…], Dokumenttityökalut avautuu [Käännä]-välilehti valittuna.

> **Huomautus**
>
> - Tarkistusasetusten tallentaminen, mallista luominen ja kääntäminen onnistuvat vain, kun työtila on luotettu VS Codessa.
> - Osa toiminnoista ei ole käytettävissä, kun ohje on näkyvissä tai kun väliaikaisesti avattuna on kansio, joka ei kuulu mihinkään dokumenttijuureen.
