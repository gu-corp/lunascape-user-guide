# Utiliser les outils de document

Les outils de document constituent le panneau qui réunit la vérification des documents, la création à partir de modèles et la traduction. Ouvrez-les avec [Outils de document] (coche) dans la barre d'outils.

## Ouvrir les outils de document

1. Appuyez sur [Outils de document] dans la barre d'outils.
   Le panneau s'ouvre à droite de l'écran.
2. Choisissez une fonction à l'aide des onglets en haut.
3. Pour fermer le panneau, appuyez sur [Fermer] ou appuyez de nouveau sur [Outils de document].

| Onglet | Fonction |
|---|---|
| [Traduire] | Création de propositions de traduction pour la page affichée, paramètres de langue du projet, traduction par lots |
| [Vérification] | Vérification de toute la racine de documentation par docs-lint, liste des résultats, consultation et modification des règles |
| [Créer] | Création de documents à partir des modèles intégrés ou du Standard Pack |

> **Astuce**
>
> - [Outils de document] dans la barre d'outils indique l'état de la vérification (aucune remarque, nombre de remarques, nouvelle vérification nécessaire, etc.).
> - Si vous choisissez [Créer et gérer les traductions…] dans le menu des langues, les outils de document s'affichent avec l'onglet [Traduire] ouvert.

> **Remarque**
>
> - L'enregistrement des paramètres de vérification, la création à partir de modèles et la traduction ne peuvent s'exécuter que si l'espace de travail est approuvé dans VS Code.
> - Certaines fonctions ne sont pas disponibles pendant l'affichage de l'aide ou lorsqu'un dossier n'appartenant pas à une racine de documentation est ouvert temporairement.
