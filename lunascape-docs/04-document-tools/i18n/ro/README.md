# Utilizarea instrumentelor pentru documente

Instrumentele pentru documente reprezintă panoul care reunește verificarea documentelor, crearea din șabloane și traducerea. Îl deschideți din [Instrumente pentru documente] (bifă) din bara de instrumente.

## Deschiderea instrumentelor pentru documente

1. Apăsați [Instrumente pentru documente] în bara de instrumente.
   Panoul se deschide în partea dreaptă a ecranului.
2. Alegeți funcția cu ajutorul filelor din partea de sus.
3. Pentru a închide panoul, apăsați [Închide] sau apăsați din nou [Instrumente pentru documente].

| Filă | Funcție |
|---|---|
| [Traducere] | Propuneri de traducere pentru pagina afișată, setările de limbă ale proiectului, traducere în bloc |
| [Verificare] | Verificarea întregii rădăcini a documentației cu docs-lint, lista rezultatelor, consultarea și modificarea regulilor |
| [Creează] | Crearea documentelor din șabloane încorporate sau din Standard Pack |

> **Sfat**
>
> - [Instrumente pentru documente] din bara de instrumente afișează starea verificării (fără observații, numărul de observații, necesită reverificare și așa mai departe).
> - Dacă alegeți [Creează și gestionează traduceri…] din meniul de limbă, instrumentele pentru documente se deschid cu fila [Traducere] selectată.

> **Notă**
>
> - Salvarea setărilor de verificare, crearea din șabloane și traducerea se pot executa numai dacă spațiul de lucru este de încredere în VS Code.
> - Unele funcții nu sunt disponibile în timpul afișării ajutorului sau atunci când este deschis temporar un folder care nu aparține unei rădăcini a documentației.
