# שינוי כללי הבדיקה

אפשר לשנות את רמת ההתראה של כל בדיקה (שגיאה, אזהרה, מידע) או להפסיק להשתמש בה. השינויים נשמרים בקובץ `docs-lint.config.json` שבשורש התיעוד ומשותפים לצוות.

## שינוי רמת ההתראה

1. לחצו על [כלי מסמכים] בסרגל הכלים ופתחו את הלשונית [בדיקה].
2. לחצו על [הצגה ושינוי של הכללים].
   רשימת הבדיקות נפרשת בתוך אותו כרטיס. לצד כל פריט מוצגות מטרתו ומקור ההגדרה הנוכחית שלו (Project‏, Profile‏, Pack או Default).
3. בחרו את רמת ההתראה של הפריט שברצונכם לשנות.
4. לחצו על [שמירה ובדיקה מחדש].
   ההגדרה נשמרת, וכל שורש התיעוד נבדק מחדש לפי ההגדרות החדשות.

| אפשרות | משמעות |
|---|---|
| [הגדרה רגילה (…)] | מסירה את הדריסה ומחזירה את ההגדרה הרגילה, הנקבעת לפי הפרופיל, ה‑Standard Pack וברירת המחדל, בסדר הזה |
| [לא בשימוש] | הפריט הזה אינו נבדק |
| [מידע] / [אזהרה] / [שגיאה] | מדווח ברמת ההתראה הזאת |

> **שימו לב**
>
> - לשמירה דרושה סביבת עבודה מהימנה.
> - נשמרת רק רמת ההתראה של כל פריט. האפשרויות של כל פריט נשמרות כמות שהן. ה‑Standard Pack והפרופיל עצמם אינם משתנים במסך הזה.
> - אם הקובץ `docs-lint.config.json` שונה מבחוץ בסמוך לשמירה, השמירה מבוטלת. טענו את המצב העדכני ונסו שוב.
> - אם הקובץ `docs-lint.config.json` אינו קיים, הוא נוצר בעת השמירה.

## עריכה ישירה של קובצי ההגדרות

- לחיצה על [פתיחת ההגדרות המלאות] פותחת את `docs-lint.config.json` ב‑VS Code.
- פתחו את [מקור הכללים והגדרות המסמכים] ולחצו על [עריכת הגדרות המסמכים] כדי לפתוח את `lunascape-docs.json` ב‑VS Code. ה‑Standard Pack והפרופיל נבחרים שם.

בשני הקבצים פעילים השלמה אוטומטית והסברים מתוך ה‑JSON Schema המצורפים להרחבה.

## Standard Pack ופרופילים

Standard Pack הוא תקן תיעוד המרכז את סוגי המסמכים הנדרשים, את מבנה הפרקים, את המונחים ואת התבניות. בוחרים אותו באמצעות `documentStandards` שבקובץ `lunascape-docs.json`.

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

ה‑Pack המצורף `builtin:gu-corp-software` כולל את הפרופילים `base`‏, `web-application`‏, `api-service`‏, `regulated-financial-product` ו‑`smart-contract`.
