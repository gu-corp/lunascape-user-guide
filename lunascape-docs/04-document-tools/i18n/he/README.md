# שימוש בכלי מסמכים

כלי מסמכים הוא החלונית שמרכזת את בדיקת המסמכים, יצירה מתבניות ותרגום. פותחים אותה באמצעות [כלי מסמכים] (סימן וי) שבסרגל הכלים.

## פתיחת כלי מסמכים

1. לחצו על [כלי מסמכים] שבסרגל הכלים.
   החלונית נפתחת בצד ימין של המסך.
2. בחרו פעולה באמצעות הלשוניות שבחלק העליון.
3. לסגירת החלונית, לחצו על [סגירה] או לחצו שוב על [כלי מסמכים].

| לשונית | פעולה |
|---|---|
| [תרגום] | יצירת הצעת תרגום לדף המוצג, הגדרות השפה של הפרויקט, תרגום מרוכז |
| [בדיקה] | בדיקה של שורש התיעוד כולו באמצעות docs-lint, רשימת הממצאים, עיון בכללים ושינוים |
| [יצירה] | יצירת מסמך מתבניות מובנות או מתבניות Standard Pack |

> **טיפ**
>
> - [כלי מסמכים] שבסרגל הכלים מציג את מצב הבדיקה (אין ממצאים, מספר הממצאים, נדרשת בדיקה חוזרת וכדומה).
> - בחירה ב[יצירה וניהול של תרגומים…] בתפריט השפה פותחת את כלי מסמכים כשהלשונית [תרגום] מוצגת.

> **שימו לב**
>
> - שמירת הגדרות הבדיקה, יצירה מתבניות ותרגום פועלים רק כאשר סביבת העבודה מהימנה ב‑VS Code.
> - חלק מהפעולות אינן זמינות בזמן הצגת העזרה או כאשר פתוחה באופן זמני תיקייה שאינה שייכת לשורש התיעוד.
