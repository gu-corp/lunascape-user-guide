# בדיקת מסמכים

באמצעות docs-lint אפשר לבדוק את מבנה הכותרות, קישורים שבורים, מסמכים או פרקים חובה שחסרים, חוסר אחידות במונחים, התאמה של מזהי דרישות ועוד. הבדיקה מתבצעת תמיד על כל שורש התיעוד.

## הרצת בדיקה

1. לחצו על [כלי מסמכים] בסרגל הכלים ופתחו את הלשונית [בדיקה].
2. לחצו על [בדיקת שורש התיעוד].
   אפשר להריץ גם באמצעות «Lunascape Docs: בדיקת שורש התיעוד» בלוח הפקודות.
3. עיינו ברשימת הממצאים.

## קריאת התוצאות

- באמצעות [מסמך זה] / [הכול] שמעל הרשימה אפשר להחליף את הטווח המוצג. טווח הבדיקה עצמה הוא תמיד כל שורש התיעוד.
- לממצאים יש ארבע דרגות: «שגיאה», «אזהרה», «מידע» ו«הצעה». ב[כלי מסמכים] שבסרגל הכלים מוצג מספר השגיאות והאזהרות.
- לחיצה על ממצא פותחת את המיקום המתאים במקור ה‑Markdown בעורך של VS Code.
- ממצאים הנוגעים לכל שורש התיעוד (כגון מסמך בדיקות חסר) מוצגים כפריטים של «כל שורש התיעוד» ואין להם מיקום.
- אותם ממצאים מוצגים גם בלוח «בעיות» של VS Code.

## מה נבדק

לחיצה על [הצגה ושינוי של הכללים] מציגה את רשימת הבדיקות הפעילות ואת מטרתה של כל אחת. אלה הפריטים העיקריים.

| פריט | תוכן |
|---|---|
| מבנה הכותרות | קיימת כותרת H1 אחת ורמות הכותרות אינן מדלגות באמצע |
| קישורים פנימיים | המסמך שאליו מפנה הקישור קיים ואינו יוצא מחוץ לשורש התיעוד |
| שפת מקטעי הקוד | האם צוין שם שפה במקטעי הקוד |
| תיקיות ומסמכים נדרשים | האם קיימות התיקיות והמסמכים שהפרופיל של Standard Pack דורש |
| פרקים נדרשים במסמך | האם קיימים הפרקים הנדרשים לכל סוג מסמך |
| אחידות המונחים | איתור ניסוחים שיש להימנע מהם ועידוד אחידות למונחים המומלצים |
| שמות מזהי דרישות וכפילויות | האם מזהי הדרישות עומדים בכלל השמות ואינם מוגדרים פעמיים |
| התאמת הפניות למזהי דרישות | האם מזהי הדרישות שאליהם מפנים העיצוב, הבדיקות וטבלאות המצב אכן קיימים |
| התאמה בין דרישות לבדיקות | האם מזהי הדרישות מופנים ממסמכי הבדיקות |

הפריטים שיהיו פעילים נקבעים לפי Standard Pack והפרופיל שנבחרו ב‑`lunascape-docs.json` ולפי `docs-lint.config.json`.

> **שימו לב**
>
> - שינוי במסמך או בהגדרות מסמן את התוצאה הקודמת כ«דורשת בדיקה מחדש». דבר אינו עובר אוטומטית. לחצו שוב על [בדיקת שורש התיעוד].
> - שינויים שלא נשמרו אינם נכללים בבדיקה. שמרו תחילה.
> - הבדיקה מתבצעת במחשב עצמו ובאופן דטרמיניסטי. תוצאות של הערכה או תרגום באמצעות AI אינן מתערבבות בתוצאות הבדיקה.
