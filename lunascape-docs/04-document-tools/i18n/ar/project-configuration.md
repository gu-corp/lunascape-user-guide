# إعدادات المشروع

الملف `lunascape-docs.json` الموجود مباشرة تحت جذر التوثيق هو إعدادات جذر التوثيق التي يشترك فيها الفريق. تتم إدارته في Git.

## إنشاء ملف الإعدادات أو تحريره

- اضغط [أدوات المستندات] في شريط الأدوات ← علامة التبويب [فحص] ← [مصدر القواعد وإعدادات المستندات] ← [تحرير إعدادات المستندات] ليُفتح الملف في VS Code. وإذا لم يكن الملف موجودًا، يُنشأ ملف مبدئي في تلك اللحظة.
- يرتبط اسم الملف `lunascape-docs.json` تلقائيًا بـ JSON Schema المضمّن، فيظهر الإكمال التلقائي ووصف لكل بند. ولا حاجة إلى كتابة `$schema`.

## مثال على الإعدادات

```json
{
  "id": "product-docs",
  "title": "وثائق المنتج",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## شرح البنود

| البند | المحتوى | الافتراضي |
|---|---|---|
| `id` | المفتاح الذي تُحفظ تحته إعدادات العرض الخاصة بكل مستخدم. أعطه قيمة ثابتة إذا أردت الاحتفاظ بالإعدادات عند نقل المجلد | مسار المجلد |
| `title` | الاسم المعروض في أقصى يسار شريط الأدوات وفي قائمة جذور التوثيق. ولا يتغيّر بتغيير لغة الواجهة | عنوان ملف README/index في الجذر، وإلا فاسم المجلد |
| `indexTitle` | عنوان INDEX | `INDEX` |
| `startPage` | المستند الذي يُفتح أولًا (مسار نسبي من جذر التوثيق) | `README.md` |
| `appearance` | نظام الألوان: `light` (فاتح دائمًا) أو `auto` (يتبع سمة VS Code) | `light` |
| `defaultLocale` | اللغة الافتراضية (لغة المستند الأصلي)، تُحدَّد بوسم لغة وفق BCP 47 مثل `ja` أو `en` أو `zh-Hant`. وهي مصدر الترجمة | غير محدَّدة (تُستنتج من النص للعرض) |
| `fallbackLocale` | اللغة التي تُعرض أولًا للقارئ الذي لا تطابق لغة بيئته أيًّا من اللغات المدعومة. حدِّد لغة مضمّنة في `locales` | غير محدَّدة (تُستخدم `defaultLocale`) |
| `locales` | قائمة اللغات المدعومة، وتشمل `defaultLocale`. تظهر في قائمة اللغات وتكون وجهات الترجمة | `defaultLocale` فقط |
| `ignoredDirectories` | أسماء المجلدات المستبعَدة من INDEX والبحث والفحص. وتحديدها يحلّ محلّ القيمة الافتراضية | `["99-archive"]` |
| `tree` | القيم الافتراضية لعرض INDEX. ويمكن للمستخدم تجاوزها من إعدادات العرض | كما في المثال أعلاه |
| `editor.defaultMode` | عرض التحرير المستخدَم قبل أن يبدّله المستخدم: `visual` أو `source` | `visual` |
| `editor.showEditButton` | ما إذا كان زر [تحرير] يظهر أسفل يمين المستند | `true` |
| `documentStandards.pack` | حزمة Standard Pack المستخدمة لفحص المستندات وللقوالب: `builtin:<الاسم>` أو مسار نسبي من جذر التوثيق | لا شيء |
| `documentStandards.profile` | اسم ملف تعريف تحدّده الحزمة | لا شيء |
| `translation.enabled` | يفعّل إنشاء مقترحات الترجمة والترجمة الدُّفعية | `true` |
| `translation.contextFiles` | ملفات Markdown للمستند الأصلي (مسارات نسبية من جذر التوثيق) تُمرَّر عند الترجمة كمرجع للمصطلحات والأسلوب | `[]` |
| `translation.maxContextCharacters` | الحد الأقصى لمجموع أحرف المستندات المرجعية (أقصاه 1048576) | `49152` |
| `description` | وصف من سطر واحد لمجموعة المستندات. يظهر على بطاقات صفحة المستودع الرئيسية. ويمكن كتابته، مثل `title`، نصًّا أو كائنًا لكل لغة | لا شيء |

## الإشارة إلى موضع المستندات في المستودع

الملف `lunascape-docs.json` الموضوع مباشرة تحت المستودع يمكن أن يحمل **خريطة المستودع** بدلًا من إعدادات ذلك المجلد. وكتابة أي من البنود الثلاثة التالية تجعله خريطة، فلا يصير المجلد نفسه جذر توثيق.

| البند | المحتوى | الافتراضي |
|---|---|---|
| `defaultFolder` | المجلد الذي يحوي المستندات (مسار نسبي من هذا المجلد). ولا يحتاج المجلد المشار إليه إلى ملف إعدادات خاص به | لا شيء (يُستخدم `docs`) |
| `roots` | قائمة مجموعات المستندات عند وجود أكثر من واحدة (مسارات نسبية من هذا المجلد، بترتيب العرض). وعندئذٍ يصير هذا المجلد الصفحة الرئيسية | لا شيء |
| `excludes` | المجلدات المستبعَدة من اكتشاف جذور التوثيق (مسارات نسبية من هذا المجلد). تُضاف إلى الاستبعادات الافتراضية مثل `node_modules` | `[]` |
| `home.cards` | ما إذا كانت الصفحة الرئيسية تعرض بطاقات مجموعات المستندات أسفل ملف README. اجعله `false` إذا كنت تكتب الروابط بنفسك في README | `true` |

يُحدَّد جذر التوثيق بالترتيب التالي، ويُستخدم أول ما يُعثَر عليه من الأعلى.

1. المجلد الذي حدّدته في الإعدادات أو في الأمر
2. ما يشير إليه `defaultFolder` أو `roots` في ملف `lunascape-docs.json` الموجود مباشرة تحت المستودع
3. المجلد الذي يوجد فيه `lunascape-docs.json` (وإن وُجد اثنان أو أكثر تحت أصل مشترك، صار ذلك الأصل الصفحة الرئيسية)
4. المجلد `docs` (‏`lunascapeDocEditor.rootDirectoryNames`)
5. المستودع مباشرةً

> **تلميح**
>
> إن لم تكتب شيئًا عمل البند الرابع، فيبقى المستودع العادي الذي يحوي `docs/` واحدًا كما كان. ولا تكتب `defaultFolder` إلا إذا أردت أن يكون اسم المجلد `manual`.

### مثال على الخريطة

```json
{
  "title": "مساعدة Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## أولوية الإعدادات

تُطبَّق البنود المتعلقة بالعرض بالترتيب التالي.

1. إعدادات العرض الخاصة بالمستخدم (لوحة [إعدادات العرض])
2. إعدادات VS Code (‏`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. القيم الافتراضية للمنتج

واللغات (`defaultLocale` و`fallbackLocale` و`locales`) وحدها استثناء، إذ يكون `lunascape-docs.json` هو المرجع. ولا يمكن تجاوز لغات المشروع من إعدادات VS Code الشخصية.

> **ملاحظة**
>
> يمكن أيضًا تحديد حزمة Standard Pack في `docs-lint.config.json` عبر `standard`. وعند وجودها في الموضعين، تكون الأولوية لـ `docs-lint.config.json`.
