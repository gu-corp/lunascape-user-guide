# تغيير قواعد الفحص

يمكنك تغيير مستوى الإشعار (خطأ، تحذير، معلومة) لكل بند فحص، أو إيقاف استخدامه. تُحفظ التغييرات في ملف `docs-lint.config.json` داخل جذر التوثيق، وتُشارَك مع الفريق.

## تغيير مستوى الإشعار

1. اضغط [أدوات المستندات] في شريط الأدوات، ثم افتح علامة التبويب [فحص].
2. اضغط [مراجعة القواعد وتغييرها].
   تنفتح قائمة بنود الفحص داخل البطاقة نفسها. يعرض كل بند الغرض منه ومصدر إعداده الحالي (Project أو Profile أو Pack أو Default).
3. اختر مستوى الإشعار للبند الذي تريد تغييره.
4. اضغط [حفظ وإعادة الفحص].
   يُحفظ الإعداد، ويُعاد فحص جذر التوثيق بأكمله بالإعداد الجديد.

| الخيار | المعنى |
|---|---|
| [الإعداد القياسي (…)] | يحذف التجاوز ويعيد الإعداد القياسي المحدَّد بترتيب: الملف التعريفي، ثم Standard Pack، ثم القيمة الافتراضية |
| [إيقاف] | لا يفحص هذا البند |
| [معلومة] / [تحذير] / [خطأ] | يُبلِّغ بهذا المستوى من الإشعار |

> **ملاحظة**
>
> - يتطلب الحفظ مساحة عمل موثوقة.
> - لا يُحفظ سوى مستوى الإشعار لكل بند. تبقى خيارات كل بند كما هي. أمّا Standard Pack والملف التعريفي نفسه فلا يتغيّران من هذه الشاشة.
> - إذا تغيّر ملف `docs-lint.config.json` خارجيًا قبيل الحفظ، يُلغى الحفظ. حمّل أحدث حالة ثم أعد المحاولة.
> - إذا لم يكن ملف `docs-lint.config.json` موجودًا، فسيُنشأ عند الحفظ.

## تحرير ملفات الإعدادات مباشرةً

- عند الضغط على [فتح الإعدادات التفصيلية] يُفتح ملف `docs-lint.config.json` في VS Code.
- افتح [مصدر القواعد وإعدادات المستندات] واضغط [تحرير إعدادات المستندات] ليُفتح ملف `lunascape-docs.json` في VS Code. ومن هناك تختار Standard Pack والملف التعريفي.

يتوفّر في كلا الملفين إكمال الإدخال والشروح عبر JSON Schema المرفق مع الامتداد.

## Standard Pack والملفات التعريفية

Standard Pack هو معيار توثيق يجمع أنواع المستندات المطلوبة، وبنية الفصول، والمصطلحات، والقوالب. تختاره عبر `documentStandards` في `lunascape-docs.json`.

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

تحتوي الحزمة المرفقة `builtin:gu-corp-software` على الملفات التعريفية `base` و`web-application` و`api-service` و`regulated-financial-product` و`smart-contract`.
