# Зміна правил перевірки

Ви можете змінити рівень сповіщення (помилка, попередження, інформація) для кожного пункту перевірки або вимкнути його. Зміни зберігаються у файлі `docs-lint.config.json` у корені документації та стають спільними для команди.

## Зміна рівня сповіщення

1. Натисніть [Інструменти документа] на панелі інструментів і відкрийте вкладку [Перевірка].
2. Натисніть [Переглянути та змінити правила].
   Список пунктів перевірки розгорнеться в тій самій картці. Для кожного пункту показано його призначення та джерело поточного налаштування (Project, Profile, Pack або Default).
3. Виберіть рівень сповіщення для пункту, який потрібно змінити.
4. Натисніть [Зберегти та перевірити знову].
   Налаштування зберігається, і весь корінь документації перевіряється знову з новими налаштуваннями.

| Варіант | Значення |
|---|---|
| [Стандартне налаштування (…)] | Видаляє перевизначення та повертає стандартне налаштування, яке визначається профілем, Standard Pack і значенням за замовчуванням — у цьому порядку |
| [Не використовувати] | Цей пункт не перевіряється |
| [Інформація] / [Попередження] / [Помилка] | Повідомляти на цьому рівні |

> **Примітка**
>
> - Для збереження потрібна надійна робоча область.
> - Зберігається лише рівень сповіщення кожного пункту. Параметри окремих пунктів залишаються без змін. Сам Standard Pack і профіль на цьому екрані не змінюються.
> - Якщо безпосередньо перед збереженням файл `docs-lint.config.json` було змінено ззовні, збереження скасовується. Завантажте найновіший стан і повторіть спробу.
> - Якщо файла `docs-lint.config.json` немає, він створюється під час збереження.

## Пряме редагування файлів налаштувань

- Натисніть [Відкрити докладні параметри], щоб відкрити `docs-lint.config.json` у VS Code.
- Відкрийте [Джерело правил і параметри документів] і натисніть [Редагувати параметри документів], щоб відкрити `lunascape-docs.json` у VS Code. Standard Pack і профіль вибираються саме там.

Для обох файлів доступні автодоповнення та описи, які надає JSON Schema, що входить до складу розширення.

## Standard Pack і профілі

Standard Pack — це стандарт документації, який об’єднує потрібні типи документів, структуру розділів, термінологію та шаблони. Його вибирають у полі `documentStandards` файла `lunascape-docs.json`.

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

Вбудований пакет `builtin:gu-corp-software` містить профілі `base`, `web-application`, `api-service`, `regulated-financial-product` і `smart-contract`.
