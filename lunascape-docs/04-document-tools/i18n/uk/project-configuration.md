# Налаштування проєкту

Файл `lunascape-docs.json` безпосередньо в корені документації — це спільні для команди параметри цього кореня документації. Він зберігається в Git.

## Створення та редагування файлу налаштувань

- Натисніть на панелі інструментів [Інструменти документа] → вкладка [Перевірка] → [Джерело правил і параметри документів] → [Редагувати параметри документів], і файл відкриється у VS Code. Якщо файлу немає, у цей момент створюється початковий файл.
- З іменем файлу `lunascape-docs.json` автоматично пов'язується вбудована JSON Schema, тому працює автодоповнення й показуються описи кожного пункту. Запис `$schema` не потрібен.

## Приклад налаштувань

```json
{
  "id": "product-docs",
  "title": "Документація продукту",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## Опис пунктів

| Пункт | Зміст | За замовчуванням |
|---|---|---|
| `id` | Ключ, під яким зберігаються параметри відображення кожного користувача. Задайте сталий ID, якщо хочете зберегти параметри після переміщення папки | Шлях до папки |
| `title` | Назва, яка показується ліворуч на панелі інструментів і в списку коренів документації. Не змінюється під час зміни мови інтерфейсу | Заголовок README/index кореня, інакше ім'я папки |
| `indexTitle` | Заголовок INDEX | `INDEX` |
| `startPage` | Документ, який відкривається першим (шлях відносно кореня документації) | `README.md` |
| `appearance` | Кольорова схема. `light` (завжди світла) або `auto` (за темою VS Code) | `light` |
| `defaultLocale` | Мова за замовчуванням (мова оригіналу документа). Вказується мовним тегом BCP 47 (`ja`, `en`, `zh-Hant` тощо). Є джерелом перекладу | Не задано (визначається з тексту для показу) |
| `fallbackLocale` | Мова, яка першою показується читачам, чия мова середовища не збігається з жодною з підтримуваних. Вкажіть мову, що входить до `locales` | Не задано (використовується `defaultLocale`) |
| `locales` | Перелік підтримуваних мов. Включає `defaultLocale`. Вони з'являються в меню мов і є цілями перекладу | Лише `defaultLocale` |
| `ignoredDirectories` | Імена папок, які виключаються з INDEX, пошуку та перевірок. Якщо задано, заміняє значення за замовчуванням | `["99-archive"]` |
| `tree` | Значення за замовчуванням для відображення INDEX. Користувач може змінити їх у параметрах відображення | Як у прикладі вище |
| `editor.defaultMode` | Режим редагування, доки користувач його не перемкнув. `visual` або `source` | `visual` |
| `editor.showEditButton` | Чи показувати [Редагувати] у нижньому правому куті документа | `true` |
| `documentStandards.pack` | Standard Pack для перевірки документів і шаблонів. `builtin:<ім'я>` або шлях відносно кореня документації | Немає |
| `documentStandards.profile` | Ім'я профілю, визначеного в Pack | Немає |
| `translation.enabled` | Вмикає створення варіантів перекладу та пакетний переклад | `true` |
| `translation.contextFiles` | Файли Markdown оригіналу (шлях відносно кореня документації), які передаються під час перекладу як довідка щодо термінів і стилю | `[]` |
| `translation.maxContextCharacters` | Обмеження загальної кількості символів довідкових документів (максимум 1048576) | `49152` |
| `description` | Опис набору документів в один рядок. Показується на картці на головній сторінці репозиторію. Як і `title`, записується рядком або об'єктом за мовами | Немає |

## Як указати, де в репозиторії лежать документи

Файл `lunascape-docs.json`, розміщений безпосередньо в корені репозиторію, може містити не параметри цієї папки, а **карту репозиторію**. Якщо записати будь-який із трьох пунктів нижче, файл стає картою, а сама папка перестає бути коренем документації.

| Пункт | Зміст | За замовчуванням |
|---|---|---|
| `defaultFolder` | У якій папці лежать документи (шлях відносно цієї папки). Папці, на яку він указує, власні налаштування не потрібні | Немає (використовується `docs`) |
| `roots` | Перелік наборів документів, якщо їх кілька (шляхи відносно цієї папки, у порядку показу). У цьому разі ця папка стає головною сторінкою | Немає |
| `excludes` | Папки, які виключаються з пошуку коренів документації (шляхи відносно цієї папки). Додаються до стандартних винятків на кшталт `node_modules` | `[]` |
| `home.cards` | Чи показувати картки наборів документів під README головної сторінки. Якщо ви пишете посилання в README самі, задайте `false` | `true` |

Корінь документації визначається в такому порядку. Використовується перший знайдений згори.

1. Папка, вказана в налаштуваннях або команді
2. Те, на що вказує `defaultFolder` або `roots` у `lunascape-docs.json` в корені репозиторію
3. Папка, у якій є `lunascape-docs.json` (якщо таких дві чи більше під спільною батьківською папкою, ця батьківська папка стає головною сторінкою)
4. Папка `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. Сам корінь репозиторію

> **Порада**
>
> Якщо нічого не записано, спрацьовує пункт 4, тож звичайний репозиторій з однією папкою `docs/` працює як раніше. `defaultFolder` записують лише тоді, коли папку треба назвати інакше, наприклад `manual`.

### Приклад карти

```json
{
  "title": "Довідка Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## Пріоритет налаштувань

Пункти, що стосуються відображення, мають такий порядок пріоритету.

1. Параметри відображення користувача (панель [Параметри відображення])
2. Налаштування VS Code (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. Значення за замовчуванням продукту

Виняток становлять лише мови (`defaultLocale`, `fallbackLocale`, `locales`): тут головним є `lunascape-docs.json`. Особисті налаштування VS Code не можуть змінити мови проєкту.

> **Увага**
>
> Standard Pack можна вказати також у `docs-lint.config.json` як `standard`. Якщо він є в обох місцях, пріоритет має `docs-lint.config.json`.
