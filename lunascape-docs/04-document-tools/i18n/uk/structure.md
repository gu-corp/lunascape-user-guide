# Корені документації та правила для файлів

Правила, за якими Lunascape Docs знаходить документи та формує INDEX. Оригіналом є сама файлова система, тому не потрібні ні реєстр, ні налаштування збирання.

## Корінь документації

- Коренем документації стає найближча папка `docs` або папка, у якій розміщено `lunascape-docs.json`.
- Якщо покласти `lunascape-docs.json`, папка не обов'язково має називатися `docs`.
- Коли ви відкриваєте файл Markdown, що не належить до жодного кореня документації, його папка показується як тимчасовий корінь документації.

## Файли, які показуються в INDEX

- Показуються файли `.md`, `.markdown` та `.mdx`. Нові файли з'являються завжди, навіть без front matter чи навігаційних даних.
- Папки, назви яких починаються з `.`, папка `node_modules`, а також папки, указані в `ignoredDirectories` (за замовчуванням `99-archive`), не показуються.
- Усе, що розміщено в `i18n/`, вважається перекладами й не наводиться в INDEX окремо.

## Титульні сторінки папок

- Файл `README.md` з основним текстом (або `index.md`, якщо README немає) є титульною сторінкою своєї папки. Натисніть назву папки в INDEX, щоб відкрити її.
- Файл `README.md`, що складається лише з front matter і не має основного тексту, вважається «дескриптором лише з налаштуваннями» і не показується як сторінка. Використовуйте його, коли папці потрібні тільки заголовок або порядок.
- Якщо є і `README.md`, і `index.md`, перевага надається `README.md`.

## Мова за замовчуванням і переклади

- Документи мовою за замовчуванням (оригінали документів) залишаються на своєму місці.
- Переклад розміщується в папці `i18n/<мова>/` поруч із оригіналом, під тією самою назвою файлу. Відтворення структури папок під `i18n/` не розпізнається.
- Це єдине місце, з якого визначається переклад. Той самий файл, розміщений деінде, стає осиротілим і не вважається перекладом жодного документа.

```text
docs/
  lunascape-docs.json
  README.md                  ← титульна сторінка кореня (початкова сторінка)
  i18n/en/README.md          ← її англійський переклад
  01-product/
    README.md                ← титульна сторінка папки
    requirements.md
    i18n/en/README.md        ← англійські переклади двох файлів вище
    i18n/en/requirements.md
  99-archive/                ← за замовчуванням виключено з INDEX
```

## Про `_meta.json`

Файл `_meta.json` із Nextra не використовується для навігації. Наявні файли не змінюються й не видаляються. Надалі з ними працюватиме лише окрема функція явного імпорту та експорту.
