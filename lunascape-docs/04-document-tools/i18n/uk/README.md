# Використання інструментів документа

Інструменти документа — це панель, що поєднує перевірку документів, створення з шаблонів і переклад. Відкрийте її кнопкою [Інструменти документа] (позначка) на панелі інструментів.

## Відкриття інструментів документа

1. Натисніть [Інструменти документа] на панелі інструментів.
   Панель відкриється праворуч на екрані.
2. Виберіть потрібну функцію за допомогою вкладок угорі.
3. Щоб закрити панель, натисніть [Закрити] або ще раз натисніть [Інструменти документа].

| Вкладка | Функція |
|---|---|
| [Перекласти] | Створення варіанта перекладу поточної сторінки, налаштування мов проєкту, пакетний переклад |
| [Перевірка] | Перевірка всього кореня документації за допомогою docs-lint, список результатів, перегляд і зміна правил |
| [Створити] | Створення документа з вбудованих шаблонів або шаблонів Standard Pack |

> **Порада**
>
> - Кнопка [Інструменти документа] на панелі інструментів показує стан перевірки (немає зауважень, кількість зауважень, потрібна повторна перевірка тощо).
> - Якщо в мовному меню вибрати [Створити та керувати перекладами…], інструменти документа відкриються з вибраною вкладкою [Перекласти].

> **Примітка**
>
> - Збереження параметрів перевірки, створення з шаблонів і переклад виконуються лише тоді, коли робоча область у VS Code є надійною.
> - Під час показу довідки або коли тимчасово відкрито папку, яка не належить до жодного кореня документації, деякі функції недоступні.
