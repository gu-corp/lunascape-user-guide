# Створення документа з шаблону

На вкладці [Створити] Інструментів документа можна вибрати шаблон, переглянути вміст і створити новий документ.

1. Натисніть [Інструменти документа] на панелі інструментів і відкрийте вкладку [Створити].
2. Натисніть [Створити з шаблону] та виберіть шаблон.
3. Заповніть поля введення (заголовок, короткий опис тощо). Обов'язкові поля позначено написом «Обов'язково».
4. Введіть місце збереження як шлях відносно кореня документації (наприклад, `03-design/api.md`).
5. Натисніть [Попередній перегляд] і перевірте згенерований Markdown.
6. Натисніть [Створити з цим вмістом].
   Документ буде створено й показано в переглядачі. Після цього виконається перевірка всього кореня документації.

## Доступні шаблони

| Шаблон | Вміст |
|---|---|
| Односторінковий документ | Коротка специфікація, нотатки або окремий пояснювальний документ в одному файлі |
| Специфікація, посібник, довідка | Один файл із універсальною структурою розділів, придатною для специфікації, посібника чи довідки |
| Шаблони Standard Pack | Якщо у `lunascape-docs.json` вибрано Standard Pack, додаються типи документів, доступні в цьому профілі (документ вимог, проєктний документ тощо) |

> **Примітка**
>
> - Для створення потрібна надійна робоча область.
> - Наявні файли не перезаписуються. Якщо в місці збереження вже є документ із такою самою назвою, створити його не вдасться.
> - Місце збереження повинно мати розширення `.md` або `.mdx`. Створювати документи в папці `i18n` (де зберігаються переклади) не можна.
> - Після зміни введених даних ще раз натисніть [Попередній перегляд], а потім створюйте документ.

> **Порада**
>
> У проєкті, де ще немає папки з документами, перший комплект можна створити командою «Lunascape Docs: Створити документацію з шаблону» в палітрі команд. Див. [Створення перших документів](../01-introduction/first-documents.md).
