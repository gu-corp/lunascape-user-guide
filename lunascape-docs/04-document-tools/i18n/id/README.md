# Menggunakan Alat Dokumen

Alat Dokumen adalah panel yang menyatukan pemeriksaan dokumen, pembuatan dari templat, dan terjemahan. Buka panel ini dari [Alat Dokumen] (tanda centang) di bilah alat.

## Membuka Alat Dokumen

1. Tekan [Alat Dokumen] di bilah alat.
   Panel terbuka di sisi kanan layar.
2. Pilih fungsi melalui tab di bagian atas.
3. Untuk menutup panel, tekan [Tutup] atau tekan [Alat Dokumen] sekali lagi.

| Tab | Fungsi |
|---|---|
| [Terjemahkan] | Pembuatan usulan terjemahan untuk halaman yang sedang ditampilkan, pengaturan bahasa proyek, terjemahan sekaligus |
| [Pemeriksaan] | Pemeriksaan seluruh root dokumentasi dengan docs-lint, daftar hasil, peninjauan dan perubahan aturan |
| [Buat] | Pembuatan dokumen dari templat bawaan atau templat Standard Pack |

> **Tip**
>
> - [Alat Dokumen] di bilah alat menampilkan status hasil pemeriksaan (tidak ada temuan, jumlah temuan, perlu diperiksa ulang, dan sebagainya).
> - Jika Anda memilih [Buat atau kelola terjemahan…] pada menu bahasa, Alat Dokumen terbuka dengan tab [Terjemahkan] terpilih.

> **Catatan**
>
> - Penyimpanan pengaturan pemeriksaan, pembuatan dari templat, dan terjemahan hanya dapat dijalankan bila ruang kerja dipercaya di VS Code.
> - Sebagian fungsi tidak tersedia saat bantuan sedang ditampilkan atau saat folder di luar root dokumentasi dibuka untuk sementara.
