# Menggunakan Alat Dokumen

Alat Dokumen ialah panel yang menghimpunkan semakan dokumen, penciptaan daripada templat dan terjemahan. Buka panel ini melalui [Alat Dokumen] (tanda semak) pada bar alat.

## Membuka Alat Dokumen

1. Tekan [Alat Dokumen] pada bar alat.
   Panel akan dibuka di sebelah kanan skrin.
2. Pilih fungsi dengan tab di bahagian atas.
3. Untuk menutup panel, tekan [Tutup] atau tekan [Alat Dokumen] sekali lagi.

| Tab | Fungsi |
|---|---|
| [Terjemah] | Cadangan terjemahan bagi halaman yang sedang dipaparkan, tetapan bahasa projek, terjemahan pukal |
| [Semakan] | Semakan seluruh akar dokumentasi dengan docs-lint, senarai penemuan, penyemakan dan perubahan peraturan |
| [Cipta] | Penciptaan dokumen daripada templat terbina dalam atau templat Standard Pack |

> **Petua**
>
> - [Alat Dokumen] pada bar alat memaparkan status hasil semakan (tiada penemuan, bilangan penemuan, perlu disahkan semula dan sebagainya).
> - Memilih [Cipta atau urus terjemahan…] dalam menu bahasa akan membuka Alat Dokumen dengan tab [Terjemah] dipilih.

> **Nota**
>
> - Penyimpanan tetapan semakan, penciptaan daripada templat dan terjemahan hanya boleh dijalankan apabila ruang kerja dipercayai dalam VS Code.
> - Sebahagian fungsi tidak boleh digunakan semasa bantuan dipaparkan atau semasa folder di luar mana-mana akar dokumentasi dibuka buat sementara.
