# जाँच के नियम बदलना

आप हर जाँच की सूचना का स्तर (त्रुटि, चेतावनी, जानकारी) बदल सकते हैं, या उस जाँच को बंद कर सकते हैं। बदलाव दस्तावेज़ रूट की `docs-lint.config.json` में सहेजे जाते हैं और टीम के साथ साझा होते हैं।

## सूचना का स्तर बदलना

1. टूलबार में [दस्तावेज़ उपकरण] दबाएँ और [जाँच] टैब खोलें।
2. [नियम देखें और बदलें] दबाएँ।
   जाँच की सूची उसी कार्ड के भीतर खुल जाती है। हर मद के साथ उसका उद्देश्य और वर्तमान सेटिंग कहाँ से आती है (Project, Profile, Pack या Default) दिखाया जाता है।
3. जिस मद को बदलना है, उसकी सूचना का स्तर चुनें।
4. [सहेजें और फिर से जाँचें] दबाएँ।
   सेटिंग सहेजी जाती है और पूरे दस्तावेज़ रूट की नई सेटिंग से फिर से जाँच होती है।

| विकल्प | अर्थ |
|---|---|
| [मानक सेटिंग (…)] | अधिलेखन हटाकर प्रोफ़ाइल, Standard Pack और डिफ़ॉल्ट — इसी क्रम से तय होने वाली मानक सेटिंग पर लौटाता है |
| [उपयोग न करें] | इस मद की जाँच नहीं करता |
| [जानकारी] / [चेतावनी] / [त्रुटि] | इसी सूचना स्तर पर रिपोर्ट करता है |

> **ध्यान दें**
>
> - सहेजने के लिए विश्वसनीय कार्यस्थान आवश्यक है।
> - केवल हर मद की सूचना का स्तर सहेजा जाता है। मद-वार विकल्प जैसे हैं वैसे ही रहते हैं। Standard Pack और प्रोफ़ाइल स्वयं इस स्क्रीन से नहीं बदले जाते।
> - यदि सहेजने से ठीक पहले `docs-lint.config.json` बाहर से बदली गई हो, तो सहेजना रोक दिया जाता है। नवीनतम स्थिति लोड करके फिर से प्रयास करें।
> - यदि `docs-lint.config.json` मौजूद न हो, तो सहेजते समय वह बना दी जाती है।

## सेटिंग फ़ाइलें सीधे संपादित करना

- [विस्तृत सेटिंग्स खोलें] दबाने पर `docs-lint.config.json` VS Code में खुलती है।
- [नियम कहाँ से आते हैं, और दस्तावेज़ सेटिंग्स] खोलकर [दस्तावेज़ सेटिंग्स संपादित करें] दबाने पर `lunascape-docs.json` VS Code में खुलती है। Standard Pack और प्रोफ़ाइल वहीं चुने जाते हैं।

दोनों फ़ाइलों में एक्सटेंशन के साथ आए JSON Schema से इनपुट सुझाव और विवरण मिलते हैं।

## Standard Pack और प्रोफ़ाइल

Standard Pack एक दस्तावेज़ीकरण मानक है, जिसमें आवश्यक दस्तावेज़ों के प्रकार, अध्याय-रचना, शब्दावली और टेम्पलेट एक साथ होते हैं। इसे `lunascape-docs.json` के `documentStandards` में चुनें।

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

साथ आने वाले Pack `builtin:gu-corp-software` में `base`, `web-application`, `api-service`, `regulated-financial-product` और `smart-contract` प्रोफ़ाइलें हैं।
