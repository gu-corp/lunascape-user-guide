# दस्तावेज़ उपकरण का उपयोग करना

दस्तावेज़ उपकरण एक ऐसा पैनल है जिसमें दस्तावेज़ की जाँच, टेम्पलेट से निर्माण और अनुवाद एक साथ मिलते हैं। इसे टूलबार के [दस्तावेज़ उपकरण] (चेक मार्क) से खोलें।

## दस्तावेज़ उपकरण खोलना

1. टूलबार में [दस्तावेज़ उपकरण] दबाएँ।
   स्क्रीन के दाईं ओर पैनल खुलता है।
2. ऊपर दिए गए टैब से कोई कार्य चुनें।
3. पैनल बंद करने के लिए [बंद करें] दबाएँ, या [दस्तावेज़ उपकरण] दोबारा दबाएँ।

| टैब | कार्य |
|---|---|
| [अनुवाद] | प्रदर्शित पृष्ठ के अनुवाद का प्रस्ताव बनाना, प्रोजेक्ट की भाषा सेटिंग्स, एक साथ अनुवाद |
| [जाँच] | docs-lint द्वारा पूरे दस्तावेज़ रूट की जाँच, परिणामों की सूची, नियमों को देखना और बदलना |
| [बनाएँ] | अंतर्निहित या Standard Pack के टेम्पलेट से दस्तावेज़ बनाना |

> **संकेत**
>
> - टूलबार के [दस्तावेज़ उपकरण] पर जाँच के परिणाम की स्थिति दिखती है (कोई टिप्पणी नहीं, टिप्पणियों की संख्या, पुनः जाँच आवश्यक आदि)।
> - भाषा मेनू में [अनुवाद बनाएँ और प्रबंधित करें…] चुनने पर दस्तावेज़ उपकरण [अनुवाद] टैब खुली हुई स्थिति में दिखता है।

> **ध्यान दें**
>
> - जाँच सेटिंग्स सहेजना, टेम्पलेट से बनाना और अनुवाद करना केवल तभी चलते हैं जब VS Code में कार्यस्थान विश्वसनीय हो।
> - सहायता प्रदर्शित होने के दौरान, या किसी दस्तावेज़ रूट से बाहर का फ़ोल्डर अस्थायी रूप से खुला होने पर, कुछ कार्य उपलब्ध नहीं होते।
