# प्रोजेक्ट सेटिंग्स

दस्तावेज़ रूट के ठीक नीचे रखी `lunascape-docs.json` उस दस्तावेज़ रूट की टीम में साझा की जाने वाली सेटिंग्स है। इसे Git में रखा जाता है।

## सेटिंग फ़ाइल बनाएँ या संपादित करें

- टूलबार में [दस्तावेज़ उपकरण] → [जाँच] टैब → [नियम कहाँ से आते हैं, और दस्तावेज़ सेटिंग्स] → [दस्तावेज़ सेटिंग्स संपादित करें] दबाने पर फ़ाइल VS Code में खुलती है। फ़ाइल न होने पर उसी समय एक प्रारंभिक फ़ाइल बन जाती है।
- फ़ाइल नाम `lunascape-docs.json` के साथ साथ में दिया गया JSON Schema अपने आप जुड़ जाता है, जिससे इनपुट पूर्णता और हर मद का विवरण दिखता है। `$schema` लिखने की आवश्यकता नहीं है।

## सेटिंग का उदाहरण

```json
{
  "id": "product-docs",
  "title": "उत्पाद दस्तावेज़",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## मदों का विवरण

| मद | विवरण | डिफ़ॉल्ट |
|---|---|---|
| `id` | प्रत्येक उपयोगकर्ता की प्रदर्शन सेटिंग्स सहेजने की कुंजी है। फ़ोल्डर हटाने पर भी सेटिंग्स बनाए रखनी हों, तो एक स्थिर ID दें | फ़ोल्डर का पथ |
| `title` | टूलबार के बाएँ सिरे पर और दस्तावेज़ रूट की सूची में दिखाया जाने वाला नाम है। प्रदर्शन भाषा बदलने पर भी यह नहीं बदलता | रूट के README/index का शीर्षक, न होने पर फ़ोल्डर का नाम |
| `indexTitle` | INDEX का शीर्षक है | `INDEX` |
| `startPage` | सबसे पहले खुलने वाला दस्तावेज़ (दस्तावेज़ रूट से सापेक्ष पथ) है | `README.md` |
| `appearance` | रंग-संयोजन है। `light` (सदा उजला) या `auto` (VS Code की थीम का अनुसरण) | `light` |
| `defaultLocale` | डिफ़ॉल्ट भाषा (प्रामाणिक दस्तावेज़ की भाषा) है। BCP 47 के भाषा टैग (`ja`, `en`, `zh-Hant` आदि) से बताएँ। यही अनुवाद का स्रोत बनती है | असेट (पाठ से अनुमान लगाकर दिखाया जाता है) |
| `fallbackLocale` | जिन पाठकों के वातावरण की भाषा किसी भी समर्थित भाषा से मेल नहीं खाती, उन्हें सबसे पहले दिखाई जाने वाली भाषा है। `locales` में शामिल कोई भाषा बताएँ | असेट (`defaultLocale` का उपयोग) |
| `locales` | समर्थित भाषाओं की सूची है। इसमें `defaultLocale` शामिल करें। ये भाषा मेनू में दिखती हैं और अनुवाद के लक्ष्य बनती हैं | केवल `defaultLocale` |
| `ignoredDirectories` | INDEX, खोज और जाँच से बाहर रखे जाने वाले फ़ोल्डरों के नाम हैं। इसे बताने पर डिफ़ॉल्ट की जगह ले लेता है | `["99-archive"]` |
| `tree` | INDEX के प्रदर्शन के डिफ़ॉल्ट मान हैं। उपयोगकर्ता इन्हें प्रदर्शन सेटिंग्स में बदल सकते हैं | ऊपर के उदाहरण के अनुसार |
| `editor.defaultMode` | जब तक उपयोगकर्ता ने बदला न हो, तब तक का संपादन दृश्य है। `visual` या `source` | `visual` |
| `editor.showEditButton` | पाठ के नीचे दाईं ओर [संपादित करें] दिखाना है या नहीं | `true` |
| `documentStandards.pack` | दस्तावेज़ जाँच और टेम्पलेट के लिए उपयोग होने वाला Standard Pack है। `builtin:<नाम>`, या दस्तावेज़ रूट से सापेक्ष पथ | नहीं |
| `documentStandards.profile` | Pack द्वारा परिभाषित प्रोफ़ाइल का नाम है | नहीं |
| `translation.enabled` | अनुवाद प्रस्ताव बनाना और एक साथ अनुवाद सक्षम करता है | `true` |
| `translation.contextFiles` | अनुवाद के समय शब्दावली और शैली के संदर्भ के रूप में दिया जाने वाला प्रामाणिक Markdown (दस्तावेज़ रूट से सापेक्ष पथ) है | `[]` |
| `translation.maxContextCharacters` | संदर्भ दस्तावेज़ों के कुल अक्षरों की ऊपरी सीमा है (अधिकतम 1048576) | `49152` |
| `description` | दस्तावेज़ समूह का एक-पंक्ति विवरण है। रिपॉज़िटरी के होम के कार्ड पर दिखता है। `title` की तरह, इसे स्ट्रिंग या भाषा-वार ऑब्जेक्ट के रूप में लिखा जा सकता है | नहीं |

## रिपॉज़िटरी में दस्तावेज़ कहाँ हैं, यह बताना

रिपॉज़िटरी के ठीक नीचे रखी `lunascape-docs.json` में उस फ़ोल्डर की सेटिंग्स के बजाय **रिपॉज़िटरी का नक्शा** लिखा जा सकता है। नीचे दिए तीन मदों में से कोई एक लिखने पर वह नक्शा बन जाती है, और वह फ़ोल्डर स्वयं दस्तावेज़ रूट नहीं रहता।

| मद | विवरण | डिफ़ॉल्ट |
|---|---|---|
| `defaultFolder` | दस्तावेज़ किस फ़ोल्डर में हैं (इस फ़ोल्डर से सापेक्ष पथ)। जिस फ़ोल्डर की ओर यह संकेत करता है, उसमें सेटिंग फ़ाइल की आवश्यकता नहीं | नहीं (`docs` का उपयोग) |
| `roots` | कई दस्तावेज़ समूह होने पर उनकी सूची है (इस फ़ोल्डर से सापेक्ष पथ, प्रदर्शन क्रम में)। ऐसी स्थिति में यह फ़ोल्डर होम बन जाता है | नहीं |
| `excludes` | दस्तावेज़ रूट की खोज से बाहर रखे जाने वाले फ़ोल्डर हैं (इस फ़ोल्डर से सापेक्ष पथ)। `node_modules` जैसे डिफ़ॉल्ट अपवर्जनों में जुड़ते हैं | `[]` |
| `home.cards` | होम के README के नीचे दस्तावेज़ समूहों के कार्ड दिखाने हैं या नहीं। README में लिंक स्वयं लिखने पर इसे `false` कर दें | `true` |

दस्तावेज़ रूट इस क्रम में तय होता है। ऊपर से क्रमशः, जो सबसे पहले मिले वही उपयोग होता है।

1. सेटिंग या कमांड से फ़ोल्डर बताया हो, तो वह फ़ोल्डर
2. ठीक नीचे की `lunascape-docs.json` के `defaultFolder` या `roots` जिस ओर संकेत करते हैं, वह स्थान
3. जिस फ़ोल्डर में `lunascape-docs.json` है, वह फ़ोल्डर (एक ही मूल फ़ोल्डर के नीचे दो या अधिक हों, तो वह मूल फ़ोल्डर होम बनता है)
4. `docs` फ़ोल्डर (`lunascapeDocEditor.rootDirectoryNames`)
5. रिपॉज़िटरी का ठीक नीचे का स्थान ही

> **संकेत**
>
> कुछ न लिखने पर चौथा चरण लागू होता है, इसलिए एक `docs/` वाली सामान्य रिपॉज़िटरी पहले की तरह ही रहती है। फ़ोल्डर का नाम `manual` रखना हो, केवल तभी `defaultFolder` लिखें।

### नक्शे का उदाहरण

```json
{
  "title": "Lunascape सहायता",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## सेटिंग्स की प्राथमिकता

प्रदर्शन से जुड़े मद इस क्रम में प्राथमिकता पाते हैं।

1. उपयोगकर्ता की प्रदर्शन सेटिंग्स ([प्रदर्शन सेटिंग्स] पैनल)
2. VS Code की सेटिंग्स (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. उत्पाद के डिफ़ॉल्ट मान

केवल भाषाएँ (`defaultLocale`, `fallbackLocale`, `locales`) अपवाद हैं — इनके लिए `lunascape-docs.json` ही प्रामाणिक है। VS Code की व्यक्तिगत सेटिंग्स से प्रोजेक्ट की भाषाएँ नहीं बदली जा सकतीं।

> **ध्यान दें**
>
> `docs-lint.config.json` में भी `standard` के रूप में Standard Pack बताया जा सकता है। दोनों जगह होने पर `docs-lint.config.json` को प्राथमिकता मिलती है।
