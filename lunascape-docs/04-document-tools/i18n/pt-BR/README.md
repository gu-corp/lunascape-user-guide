# Usar as Ferramentas de documento

As Ferramentas de documento são um painel que reúne a verificação de documentos, a criação a partir de modelos e a tradução. Abra-o em [Ferramentas de documento] (marca de seleção), na barra de ferramentas.

## Abrir as Ferramentas de documento

1. Pressione [Ferramentas de documento] na barra de ferramentas.
   O painel se abre à direita da tela.
2. Escolha a função nas guias da parte superior.
3. Para fechar o painel, pressione [Fechar] ou pressione [Ferramentas de documento] novamente.

| Guia | Função |
|---|---|
| [Traduzir] | Criação de propostas de tradução da página exibida, configurações de idioma do projeto, tradução em lote |
| [Verificação] | Verificação de toda a raiz da documentação com o docs-lint, lista de resultados, consulta e alteração de regras |
| [Criar] | Criação de documentos a partir de modelos internos ou do Standard Pack |

> **Dica**
>
> - [Ferramentas de documento], na barra de ferramentas, mostra o estado do resultado da verificação (sem apontamentos, número de apontamentos, necessidade de nova verificação, entre outros).
> - Ao escolher [Criar e gerenciar traduções…] no menu de idiomas, as Ferramentas de documento são exibidas com a guia [Traduzir] aberta.

> **Nota**
>
> - Salvar as configurações de verificação, criar a partir de modelos e traduzir só é possível quando o espaço de trabalho é confiável no VS Code.
> - Enquanto a ajuda estiver sendo exibida ou enquanto uma pasta fora de qualquer raiz da documentação estiver aberta temporariamente, algumas funções ficam indisponíveis.
