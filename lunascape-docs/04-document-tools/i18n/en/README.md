# Using Document Tools

Document Tools is the panel that brings together document checks, creation from templates and translation. Open it with [文書ツール] (Document Tools, check mark) in the toolbar.

## Open Document Tools

1. Press [文書ツール] (Document Tools) in the toolbar.
   The panel opens on the right of the screen.
2. Choose a function with the tabs at the top.
3. To close the panel, press [閉じる] (Close) or press [文書ツール] again.

| Tab | Function |
|---|---|
| [翻訳] (Translation) | Translation proposals for the current page, project language settings, batch translation |
| [チェック] (Check) | docs-lint checks of the whole documentation root, the list of findings, reviewing and changing rules |
| [作成] (Create) | Creating documents from built-in or Standard Pack templates |

> **Hint**
>
> - [文書ツール] (Document Tools) in the toolbar shows the check status (no findings, the number of findings, revalidation required, and so on).
> - Choosing [翻訳を作成・管理…] (Create or manage translations…) in the language menu opens Document Tools with the [翻訳] (Translation) tab selected.

> **Note**
>
> - Saving check settings, creating from templates and translating run only when the workspace is trusted in VS Code.
> - Some functions are unavailable while the help is shown or while a folder outside any documentation root is open temporarily.
