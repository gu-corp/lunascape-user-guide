# Dokumentwerkzeuge verwenden

Die Dokumentwerkzeuge sind die Palette, die Prüfung von Dokumenten, Erstellung aus Vorlagen und Übersetzung zusammenfasst. Sie öffnen sie über [Dokumentwerkzeuge] (Häkchen) in der Symbolleiste.

## Dokumentwerkzeuge öffnen

1. Drücken Sie in der Symbolleiste auf [Dokumentwerkzeuge].
   Die Palette öffnet sich rechts im Fenster.
2. Wählen Sie über die Registerkarten oben eine Funktion.
3. Zum Schließen der Palette drücken Sie [Schließen] oder erneut [Dokumentwerkzeuge].

| Registerkarte | Funktion |
|---|---|
| [Übersetzen] | Übersetzungsvorschläge für die angezeigte Seite, Spracheinstellungen des Projekts, Sammelübersetzung |
| [Prüfung] | Prüfung der gesamten Dokumentwurzel durch docs-lint, Liste der Befunde, Regeln ansehen und ändern |
| [Erstellen] | Dokumente aus integrierten Vorlagen oder aus Vorlagen des Standard Pack erstellen |

> **Hinweis**
>
> - [Dokumentwerkzeuge] in der Symbolleiste zeigt den Stand der Prüfung an (keine Befunde, Anzahl der Befunde, erneute Prüfung erforderlich und so weiter).
> - Wenn Sie im Sprachmenü [Übersetzungen erstellen und verwalten…] wählen, erscheinen die Dokumentwerkzeuge mit geöffneter Registerkarte [Übersetzen].

> **Achtung**
>
> - Das Speichern der Prüfeinstellungen, das Erstellen aus Vorlagen und das Übersetzen lassen sich nur ausführen, wenn Sie dem Arbeitsbereich in VS Code vertrauen.
> - Während die Hilfe angezeigt wird oder während vorübergehend ein Ordner geöffnet ist, der zu keiner Dokumentwurzel gehört, stehen einige Funktionen nicht zur Verfügung.
