# Настройки на проекта

Файлът `lunascape-docs.json` непосредствено под коренната папка на документацията съдържа настройките на тази папка, споделени в екипа. Управлява се с Git.

## Създаване и редактиране на файла с настройки

- В лентата с инструменти натиснете [Инструменти за документи] → раздел [Проверка] → [Източник на правилата и настройки на документите] → [Редактиране на настройките на документите] и файлът се отваря във VS Code. Ако файлът не съществува, в този момент се създава начален файл.
- Името на файла `lunascape-docs.json` автоматично се свързва с вградената JSON Schema, която дава автоматично довършване и описание на всяко поле. Не е необходимо да пишете `$schema`.

## Пример за настройки

```json
{
  "id": "product-docs",
  "title": "Продуктова документация",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## Описание на полетата

| Поле | Съдържание | По подразбиране |
|---|---|---|
| `id` | Ключът, под който се запазват настройките на изгледа за всеки потребител. Задайте му постоянна стойност, когато искате настройките да се запазят и след преместване на папката | Пътят на папката |
| `title` | Името, което се показва в най-левия край на лентата с инструменти и в списъка с коренни папки на документацията. Не се променя при смяна на езика на интерфейса | Заглавието на README/index в корена, а ако липсва — името на папката |
| `indexTitle` | Заглавието на INDEX | `INDEX` |
| `startPage` | Документът, който се отваря пръв (път спрямо коренната папка на документацията) | `README.md` |
| `appearance` | Цветова схема: `light` (винаги светла) или `auto` (следва темата на VS Code) | `light` |
| `defaultLocale` | Езикът по подразбиране (езикът на изходните документи). Задава се с езиков етикет по BCP 47 (`ja`, `en`, `zh-Hant` и др.). Той е източникът за превода | Незададено (извежда се от текста само за показване) |
| `fallbackLocale` | Езикът, който се показва пръв на читатели, чийто език на средата не съвпада с нито един от поддържаните езици. Посочете език, който присъства в `locales` | Незададено (използва се `defaultLocale`) |
| `locales` | Списъкът с поддържани езици. Включва `defaultLocale`. Те се появяват в менюто за език и са възможните езици за превод | Само `defaultLocale` |
| `ignoredDirectories` | Имената на папките, изключени от INDEX, търсенето и проверките. Ако е зададено, заменя стойността по подразбиране | `["99-archive"]` |
| `tree` | Стойностите по подразбиране за показването на INDEX. Потребителят може да ги замени в Настройки на изгледа | Както в примера по-горе |
| `editor.defaultMode` | Изгледът за редактиране, докато потребителят не го е сменил: `visual` или `source` | `visual` |
| `editor.showEditButton` | Дали [Редактиране] се показва долу вдясно в документа | `true` |
| `documentStandards.pack` | Standard Pack, използван за проверките на документите и за шаблоните: `builtin:<име>` или път спрямо коренната папка на документацията | Няма |
| `documentStandards.profile` | Име на профил, дефиниран в пакета | Няма |
| `translation.enabled` | Включва създаването на предложения за превод и груповия превод | `true` |
| `translation.contextFiles` | Изходни файлове на Markdown (пътища спрямо коренната папка на документацията), които се подават при превод като справка за терминологията и стила | `[]` |
| `translation.maxContextCharacters` | Горна граница за общия брой знаци на справочните документи (максимум 1048576) | `49152` |
| `description` | Едноредово описание на набора от документи. Показва се в картата на началната страница на хранилището. Както и `title`, може да бъде низ или обект по езици | Няма |

## Как да укажете къде в хранилището са документите

Файлът `lunascape-docs.json`, поставен непосредствено под хранилището, може да съдържа не настройките на тази папка, а **карта на хранилището**. Ако запишете някое от следващите 3 полета, файлът става карта и самата папка вече не е коренна папка на документацията.

| Поле | Съдържание | По подразбиране |
|---|---|---|
| `defaultFolder` | В коя папка са документите (път спрямо тази папка). Папката, която се посочва, няма нужда от собствен файл с настройки | Няма (използва се `docs`) |
| `roots` | Списъкът на наборите от документи, когато те са няколко (пътища спрямо тази папка, в реда на показване). В този случай самата папка става началната страница | Няма |
| `excludes` | Папките, изключени от откриването на коренни папки на документацията (пътища спрямо тази папка). Добавят се към изключенията по подразбиране, като `node_modules` | `[]` |
| `home.cards` | Дали началната страница показва картите на наборите от документи под своя README. Задайте `false`, когато сами пишете връзките в README | `true` |

Коренната папка на документацията се определя в следния ред. Използва се първата намерена, като се върви отгоре надолу.

1. Папката, посочена в настройка или в изпълнената команда
2. Целта, към която сочи `defaultFolder` или `roots` в `lunascape-docs.json` непосредствено под хранилището
3. Папка, в която има `lunascape-docs.json` (ако под общ родител има две или повече, този родител става началната страница)
4. Папката `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. Самото ниво непосредствено под хранилището

> **Съвет**
>
> Ако не запишете нищо, действа точка 4, така че обикновено хранилище с една папка `docs/` работи както досега. Записвайте `defaultFolder` само когато искате папката да се казва например `manual`.

### Пример за карта

```json
{
  "title": "Помощ за Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## Приоритет на настройките

Полетата, свързани с показването, имат следния приоритет.

1. Настройките на изгледа на потребителя (панелът [Настройки на изгледа])
2. Настройките на VS Code (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. Стойностите по подразбиране на продукта

Единственото изключение са езиците (`defaultLocale`, `fallbackLocale`, `locales`): за тях меродавен е `lunascape-docs.json`. Личните настройки на VS Code не могат да заменят езиците на проекта.

> **Забележка**
>
> Standard Pack може да се посочи и като `standard` в `docs-lint.config.json`. Когато е указан и на двете места, предимство има `docs-lint.config.json`.
