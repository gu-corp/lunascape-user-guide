# Χρήση των εργαλείων εγγράφων

Τα εργαλεία εγγράφων είναι ο πίνακας που συγκεντρώνει τον έλεγχο των εγγράφων, τη δημιουργία από πρότυπα και τη μετάφραση. Ανοίγει από το [Εργαλεία εγγράφων] (σημάδι επιλογής) στη γραμμή εργαλείων.

## Άνοιγμα των εργαλείων εγγράφων

1. Πατήστε [Εργαλεία εγγράφων] στη γραμμή εργαλείων.
   Ο πίνακας ανοίγει στα δεξιά της οθόνης.
2. Επιλέξτε λειτουργία από τις καρτέλες στο επάνω μέρος.
3. Για να κλείσετε τον πίνακα, πατήστε [Κλείσιμο] ή πατήστε ξανά [Εργαλεία εγγράφων].

| Καρτέλα | Λειτουργία |
|---|---|
| [Μετάφραση] | Δημιουργία πρότασης μετάφρασης για την τρέχουσα σελίδα, ρυθμίσεις γλωσσών του έργου, μαζική μετάφραση |
| [Έλεγχος] | Έλεγχος ολόκληρης της ρίζας τεκμηρίωσης με το docs-lint, λίστα αποτελεσμάτων, έλεγχος και αλλαγή κανόνων |
| [Δημιουργία] | Δημιουργία εγγράφου από ενσωματωμένα πρότυπα ή πρότυπα του Standard Pack |

> **Συμβουλή**
>
> - Το [Εργαλεία εγγράφων] στη γραμμή εργαλείων δείχνει την κατάσταση του ελέγχου (καμία επισήμανση, πλήθος επισημάνσεων, απαιτείται νέος έλεγχος κ.ο.κ.).
> - Αν επιλέξετε [Δημιουργία και διαχείριση μεταφράσεων…] στο μενού γλωσσών, τα εργαλεία εγγράφων εμφανίζονται με ανοιχτή την καρτέλα [Μετάφραση].

> **Σημείωση**
>
> - Η αποθήκευση των ρυθμίσεων ελέγχου, η δημιουργία από πρότυπα και η μετάφραση εκτελούνται μόνο όταν ο χώρος εργασίας είναι αξιόπιστος στο VS Code.
> - Ενώ εμφανίζεται η βοήθεια ή ενώ είναι προσωρινά ανοιχτός ένας φάκελος που δεν ανήκει σε ρίζα τεκμηρίωσης, ορισμένες λειτουργίες δεν είναι διαθέσιμες.
