# Ρυθμίσεις έργου

Το `lunascape-docs.json` απευθείας κάτω από τη ρίζα τεκμηρίωσης είναι η ρύθμιση της ρίζας τεκμηρίωσης που μοιράζεται η ομάδα. Διαχειρίζεται με το Git.

## Δημιουργία και επεξεργασία του αρχείου ρυθμίσεων

- Πατήστε [Εργαλεία εγγράφων] στη γραμμή εργαλείων → καρτέλα [Έλεγχος] → [Προέλευση των κανόνων και ρυθμίσεις εγγράφων] → [Επεξεργασία των ρυθμίσεων εγγράφων] και το αρχείο ανοίγει στο VS Code. Αν το αρχείο δεν υπάρχει, δημιουργείται εκείνη τη στιγμή ένα αρχικό αρχείο.
- Στο όνομα αρχείου `lunascape-docs.json` αντιστοιχίζεται αυτόματα το ενσωματωμένο JSON Schema, οπότε εμφανίζονται συμπλήρωση εισαγωγής και περιγραφή για κάθε πεδίο. Δεν χρειάζεται καταχώριση `$schema`.

## Παράδειγμα ρυθμίσεων

```json
{
  "id": "product-docs",
  "title": "Τεκμηρίωση προϊόντος",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## Περιγραφή των πεδίων

| Πεδίο | Περιεχόμενο | Προεπιλογή |
|---|---|---|
| `id` | Το κλειδί με το οποίο αποθηκεύονται οι ρυθμίσεις προβολής κάθε χρήστη. Δώστε ένα σταθερό ID όταν θέλετε να διατηρηθούν οι ρυθμίσεις μετά από μετακίνηση του φακέλου | Η διαδρομή του φακέλου |
| `title` | Το όνομα που εμφανίζεται στο αριστερό άκρο της γραμμής εργαλείων και στη λίστα των ριζών τεκμηρίωσης. Δεν αλλάζει με τη γλώσσα εμφάνισης | Ο τίτλος του README/index της ρίζας, αλλιώς το όνομα του φακέλου |
| `indexTitle` | Ο τίτλος του INDEX | `INDEX` |
| `startPage` | Το έγγραφο που ανοίγει πρώτο (σχετική διαδρομή από τη ρίζα τεκμηρίωσης) | `README.md` |
| `appearance` | Ο χρωματικός συνδυασμός: `light` (πάντα φωτεινός) ή `auto` (ακολουθεί το θέμα του VS Code) | `light` |
| `defaultLocale` | Η προεπιλεγμένη γλώσσα (η γλώσσα του πρωτότυπου εγγράφου). Ορίζεται με ετικέτα γλώσσας BCP 47 (`ja`, `en`, `zh-Hant` κ.ά.). Αποτελεί την πηγή της μετάφρασης | Χωρίς τιμή (συνάγεται από το κείμενο για την εμφάνιση) |
| `fallbackLocale` | Η γλώσσα που εμφανίζεται πρώτη στους αναγνώστες των οποίων η γλώσσα περιβάλλοντος δεν ταιριάζει με καμία από τις υποστηριζόμενες γλώσσες. Ορίστε μια γλώσσα που περιέχεται στο `locales` | Χωρίς τιμή (χρησιμοποιείται το `defaultLocale`) |
| `locales` | Ο κατάλογος των υποστηριζόμενων γλωσσών. Περιλαμβάνει το `defaultLocale`. Αποτελούν το μενού γλωσσών και τους προορισμούς της μετάφρασης | Μόνο το `defaultLocale` |
| `ignoredDirectories` | Τα ονόματα των φακέλων που εξαιρούνται από το INDEX, την αναζήτηση και τους ελέγχους. Αν οριστεί, αντικαθιστά την προεπιλογή | `["99-archive"]` |
| `tree` | Οι προεπιλεγμένες τιμές για την εμφάνιση του INDEX. Ο χρήστης μπορεί να τις παρακάμψει από τις ρυθμίσεις προβολής | Όπως στο παραπάνω παράδειγμα |
| `editor.defaultMode` | Η προβολή επεξεργασίας όσο ο χρήστης δεν έχει αλλάξει ακόμη: `visual` ή `source` | `visual` |
| `editor.showEditButton` | Αν εμφανίζεται το [Επεξεργασία] κάτω δεξιά στο κείμενο | `true` |
| `documentStandards.pack` | Το Standard Pack που χρησιμοποιείται για τον έλεγχο εγγράφων και τα πρότυπα: `builtin:<όνομα>` ή σχετική διαδρομή από τη ρίζα τεκμηρίωσης | Κανένα |
| `documentStandards.profile` | Το όνομα προφίλ που ορίζει το Pack | Κανένα |
| `translation.enabled` | Ενεργοποιεί τη δημιουργία προτάσεων μετάφρασης και τη μαζική μετάφραση | `true` |
| `translation.contextFiles` | Τα αρχεία Markdown του πρωτότυπου (σχετική διαδρομή από τη ρίζα τεκμηρίωσης) που δίνονται κατά τη μετάφραση ως αναφορά ορολογίας και ύφους | `[]` |
| `translation.maxContextCharacters` | Το ανώτατο όριο του συνολικού αριθμού χαρακτήρων των εγγράφων αναφοράς (έως 1048576) | `49152` |
| `description` | Μια περιγραφή μίας γραμμής για το σύνολο εγγράφων. Εμφανίζεται στις κάρτες της αρχικής σελίδας του αποθετηρίου. Όπως και το `title`, γράφεται ως συμβολοσειρά ή ως αντικείμενο ανά γλώσσα | Καμία |

## Δηλώστε πού βρίσκονται τα έγγραφα στο αποθετήριο

Στο `lunascape-docs.json` που τοποθετείται απευθείας κάτω από το αποθετήριο μπορείτε να γράψετε όχι τις ρυθμίσεις εκείνου του φακέλου, αλλά έναν **χάρτη του αποθετηρίου**. Αν γράψετε οποιοδήποτε από τα επόμενα 3 πεδία, γίνεται χάρτης και ο ίδιος ο φάκελος δεν αποτελεί πλέον ρίζα τεκμηρίωσης.

| Πεδίο | Περιεχόμενο | Προεπιλογή |
|---|---|---|
| `defaultFolder` | Σε ποιον φάκελο βρίσκονται τα έγγραφα (σχετική διαδρομή από αυτόν τον φάκελο). Ο φάκελος στον οποίο δείχνει δεν χρειάζεται δικό του αρχείο ρυθμίσεων | Καμία (χρησιμοποιείται το `docs`) |
| `roots` | Ο κατάλογος των συνόλων εγγράφων, όταν υπάρχουν περισσότερα από ένα (σχετικές διαδρομές από αυτόν τον φάκελο, με τη σειρά εμφάνισης). Σε αυτήν την περίπτωση ο ίδιος ο φάκελος γίνεται η αρχική σελίδα | Καμία |
| `excludes` | Οι φάκελοι που εξαιρούνται από την ανακάλυψη ριζών τεκμηρίωσης (σχετικές διαδρομές από αυτόν τον φάκελο). Προστίθενται στις προεπιλεγμένες εξαιρέσεις, όπως το `node_modules` | `[]` |
| `home.cards` | Αν η αρχική σελίδα εμφανίζει τις κάρτες των συνόλων εγγράφων κάτω από το README της. Ορίστε το σε `false` όταν γράφετε μόνοι σας τους συνδέσμους στο README | `true` |

Η ρίζα τεκμηρίωσης καθορίζεται με την εξής σειρά. Χρησιμοποιείται η πρώτη που βρίσκεται, από πάνω προς τα κάτω.

1. Ο φάκελος που ορίστηκε από μια ρύθμιση ή από την εντολή που εκτελέσατε
2. Ο φάκελος στον οποίο δείχνει το `defaultFolder` ή το `roots` του `lunascape-docs.json` που βρίσκεται απευθείας κάτω από το αποθετήριο
3. Ο φάκελος που περιέχει `lunascape-docs.json` (αν υπάρχουν δύο ή περισσότεροι κάτω από κοινό γονέα, ο γονέας γίνεται η αρχική σελίδα)
4. Ο φάκελος `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. Το ίδιο το επάνω επίπεδο του αποθετηρίου

> **Συμβουλή**
>
> Αν δεν γράψετε τίποτα, ισχύει το βήμα 4, οπότε ένα συνηθισμένο αποθετήριο με ένα μόνο `docs/` λειτουργεί όπως πριν. Γράψτε `defaultFolder` μόνο όταν θέλετε ο φάκελος να λέγεται αλλιώς, π.χ. `manual`.

### Παράδειγμα χάρτη

```json
{
  "title": "Βοήθεια Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## Σειρά προτεραιότητας των ρυθμίσεων

Τα πεδία που αφορούν την εμφάνιση ισχύουν με την εξής σειρά προτεραιότητας.

1. Οι ρυθμίσεις προβολής του χρήστη (πίνακας [Ρυθμίσεις προβολής])
2. Οι ρυθμίσεις του VS Code (`lunascapeDocEditor.*`)
3. Το `lunascape-docs.json`
4. Οι προεπιλεγμένες τιμές του προϊόντος

Εξαίρεση αποτελούν μόνο οι γλώσσες (`defaultLocale`, `fallbackLocale`, `locales`): εκεί το `lunascape-docs.json` είναι το πρωτότυπο. Οι προσωπικές ρυθμίσεις του VS Code δεν μπορούν να παρακάμψουν τις γλώσσες του έργου.

> **Σημείωση**
>
> Ένα Standard Pack μπορεί να οριστεί και ως `standard` στο `docs-lint.config.json`. Όταν υπάρχει και στα δύο, υπερισχύει το `docs-lint.config.json`.
