# Bruke Dokumentverktøy

Dokumentverktøy er panelet som samler dokumentkontroller, oppretting fra maler og oversettelse. Åpne det med [Dokumentverktøy] (avmerkingsmerke) på verktøylinjen.

## Åpne Dokumentverktøy

1. Trykk på [Dokumentverktøy] på verktøylinjen.
   Panelet åpnes til høyre på skjermen.
2. Velg en funksjon med fanene øverst.
3. Trykk på [Lukk] eller trykk på [Dokumentverktøy] en gang til for å lukke panelet.

| Fane | Funksjon |
|---|---|
| [Oversett] | Oversettelsesforslag for den gjeldende siden, språkinnstillinger for prosjektet, samleoversettelse |
| [Kontroll] | docs-lint-kontroll av hele dokumentroten, oversikt over funn, gjennomgang og endring av regler |
| [Opprett] | Oppretting av dokumenter fra innebygde maler eller Standard Pack-maler |

> **Tips**
>
> - [Dokumentverktøy] på verktøylinjen viser kontrollstatusen (ingen funn, antall funn, ny kontroll nødvendig og så videre).
> - Når du velger [Opprett eller administrer oversettelser …] i språkmenyen, åpnes Dokumentverktøy med fanen [Oversett] valgt.

> **Merk**
>
> - Lagring av kontrollinnstillinger, oppretting fra maler og oversettelse kan bare kjøres når arbeidsområdet er klarert i VS Code.
> - Enkelte funksjoner er utilgjengelige mens hjelpen vises, eller mens en mappe som ikke tilhører noen dokumentrot, er midlertidig åpnet.
