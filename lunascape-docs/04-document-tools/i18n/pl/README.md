# Korzystanie z Narzędzi dokumentów

Narzędzia dokumentów to panel łączący sprawdzanie dokumentów, tworzenie z szablonów i tłumaczenie. Otwiera się go przyciskiem [Narzędzia dokumentów] (znacznik wyboru) na pasku narzędzi.

## Otwieranie Narzędzi dokumentów

1. Naciśnij [Narzędzia dokumentów] na pasku narzędzi.
   Panel otworzy się po prawej stronie ekranu.
2. Wybierz funkcję za pomocą kart u góry.
3. Aby zamknąć panel, naciśnij [Zamknij] lub ponownie naciśnij [Narzędzia dokumentów].

| Karta | Funkcja |
|---|---|
| [Przetłumacz] | Propozycje tłumaczenia bieżącej strony, ustawienia języków projektu, tłumaczenie zbiorcze |
| [Sprawdzanie] | Sprawdzanie całego katalogu głównego dokumentacji przez docs-lint, lista uwag, przeglądanie i zmiana reguł |
| [Utwórz] | Tworzenie dokumentów z szablonów wbudowanych lub z Standard Pack |

> **Wskazówka**
>
> - Przycisk [Narzędzia dokumentów] na pasku narzędzi pokazuje stan sprawdzania (brak uwag, liczba uwag, konieczna ponowna weryfikacja itp.).
> - Wybranie pozycji [Utwórz lub zarządzaj tłumaczeniami…] w menu języka otwiera Narzędzia dokumentów z wybraną kartą [Przetłumacz].

> **Uwaga**
>
> - Zapisywanie ustawień sprawdzania, tworzenie z szablonów i tłumaczenie działają tylko wtedy, gdy obszar roboczy jest zaufany w VS Code.
> - Niektóre funkcje są niedostępne, gdy wyświetlana jest pomoc lub gdy tymczasowo otwarty jest folder spoza katalogu głównego dokumentacji.
