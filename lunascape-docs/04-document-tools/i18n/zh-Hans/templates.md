# 从模板创建文档

在文档工具的 [创建] 选项卡中，可以选择模板并预览内容，然后创建新文档。

1. 按工具栏中的 [文档工具]，打开 [创建] 选项卡。
2. 按 [从模板创建]，选择模板。
3. 填写输入项（标题、概要等）。必填项会显示"必填"。
4. 以文档根目录起始的相对路径输入保存位置（例如：`03-design/api.md`）。
5. 按 [预览]，确认生成的 Markdown。
6. 按 [按此内容创建]。
   文档随即创建并显示在查看器中。接着会对整个文档根目录执行检查。

## 可选的模板

| 模板 | 内容 |
|---|---|
| 单页文档 | 用一个文件创建简短的规格、备忘或独立的说明文档 |
| 规格书・手册・帮助 | 用一个文件创建适用于规格书、手册、帮助的通用章节结构 |
| Standard Pack 的模板 | 在 `lunascape-docs.json` 中选择了 Standard Pack 时，会增加该配置文件可用的文档类型（需求定义书、设计书等） |

> **注意**
>
> - 创建需要受信任的工作区。
> - 不会覆盖已有文件。保存位置存在同名文档时无法创建。
> - 保存位置需要 `.md` 或 `.mdx` 扩展名。无法在 `i18n` 之下（翻译版的位置）创建。
> - 更改输入内容后，请再次按 [预览]，然后再创建。

> **提示**
>
> 在尚未有文档文件夹的项目中，可以通过命令面板的"Lunascape Docs: 从模板创建文档"创建最初的一套文档。请参阅[首次创建文档](../01-introduction/first-documents.md)。
