# 使用文档工具

文档工具是将文档检查、从模板创建文档和翻译集中在一起的面板。通过工具栏的 [文档工具]（对勾图标）打开。

## 打开文档工具

1. 按工具栏的 [文档工具]。
   面板会在屏幕右侧打开。
2. 用顶部的标签页选择功能。
3. 要关闭面板，按 [关闭]，或再按一次 [文档工具]。

| 标签页 | 功能 |
|---|---|
| [翻译] | 为当前页面创建翻译草案、设置项目的语言、批量翻译 |
| [检查] | 用 docs-lint 检查整个文档根目录、查看结果列表、确认和修改规则 |
| [创建] | 从内置模板或 Standard Pack 模板创建文档 |

> **提示**
>
> - 工具栏的 [文档工具] 会显示检查结果的状态（无问题、问题数量、需要重新检查等）。
> - 在语言菜单中选择 [创建和管理翻译…]，会打开文档工具并切换到 [翻译] 标签页。

> **注意**
>
> - 保存检查设置、从模板创建文档和翻译，只有在 VS Code 中信任该工作区时才能执行。
> - 显示帮助时，或临时打开了不属于文档根目录的文件夹时，部分功能无法使用。
