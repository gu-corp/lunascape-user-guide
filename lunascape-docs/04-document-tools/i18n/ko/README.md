# 문서 도구 사용하기

문서 도구는 문서 검사, 템플릿에서 작성, 번역을 한데 모은 패널입니다. 도구 모음의 [문서 도구](체크 표시)에서 엽니다.

## 문서 도구 열기

1. 도구 모음의 [문서 도구]를 누릅니다.
   화면 오른쪽에 패널이 열립니다.
2. 위쪽 탭에서 기능을 선택합니다.
3. 패널을 닫으려면 [닫기]를 누르거나 [문서 도구]를 다시 누릅니다.

| 탭 | 기능 |
|---|---|
| [번역] | 표시 중인 페이지의 번역안 작성, 프로젝트의 언어 설정, 일괄 번역 |
| [검사] | docs-lint를 통한 문서 루트 전체 검사, 결과 목록, 규칙 확인 및 변경 |
| [작성] | 기본 제공 또는 Standard Pack 템플릿에서 문서 작성 |

> **팁**
>
> - 도구 모음의 [문서 도구]에는 검사 결과의 상태(지적 사항 없음, 지적 사항 건수, 재검증 필요 등)가 표시됩니다.
> - 언어 메뉴에서 [번역 작성·관리…]를 선택하면 [번역] 탭이 열린 상태로 문서 도구가 표시됩니다.

> **참고**
>
> - 검사 설정 저장, 템플릿에서 작성, 번역은 VS Code에서 작업 영역을 신뢰한 경우에만 실행할 수 있습니다.
> - 도움말을 표시 중이거나 문서 루트에 속하지 않는 폴더를 일시적으로 열고 있을 때는 일부 기능을 사용할 수 없습니다.
