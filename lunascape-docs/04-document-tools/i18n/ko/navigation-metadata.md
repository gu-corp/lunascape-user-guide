# 탐색 정보 설정하기

INDEX에 표시할 이름과 순서는 각 문서의 YAML front matter에 씁니다. 쓰지 않아도 문서는 표시되며, 제목(H1)과 파일 이름순이 사용됩니다.

## 문서의 이름과 순서

문서 맨 앞에 다음과 같이 씁니다.

```yaml
---
navigation:
  title: 시작하기
  order: 200
---
```

| 항목 | 내용 |
|---|---|
| `navigation.title` | INDEX에 표시할 이름입니다. 생략하면 H1을, 그것도 없으면 파일 이름을 사용합니다 |
| `navigation.order` | 정렬 순서를 정하는 정수입니다. 작은 순서대로 정렬됩니다. 생략하면 안정적인 기본 순서(파일 이름순)가 됩니다 |

> **힌트**
>
> - `order`는 100, 200, 300처럼 100 단위로 매기면 나중에 150처럼 사이에 끼워 넣을 수 있습니다.
> - 지정하지 않았거나, 잘못되었거나, 중복된 `order`가 있어도 문서는 숨겨지지 않습니다.
> - INDEX에서 순서를 바꾸면 `navigation.order`가 자동으로 기록됩니다. 직접 쓸 필요는 없습니다.

## 폴더의 이름과 순서

폴더의 이름과 순서는 그 폴더의 `README.md`(없으면 `index.md`)의 front matter가 가집니다. 표지의 본문이 없어도 됩니다.

```yaml
---
navigation:
  title: 제품 기획
  order: 100
---
```

표지가 없는 폴더는 폴더 이름과 기본 순서로 표시됩니다. INDEX에서 제목을 변경하거나 순서를 바꿀 때 필요하면 front matter만 있는 `README.md`가 생성됩니다. 열람만 해서는 파일이 만들어지지 않습니다.

## 번역판에서의 처리

- 순서와 폴더의 역할(표지인지 설정 전용인지)은 기본 언어의 문서만이 정합니다.
- 번역판은 `navigation.title`만 덮어쓸 수 있습니다. 정본에 본문이 있을 때는 번역판의 H1도 이름으로 사용됩니다.
- 번역판만 있어도 페이지가 늘어나지는 않습니다.

## 하위 항목의 정렬과 접기
