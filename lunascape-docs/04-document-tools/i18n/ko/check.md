# 문서 검사하기

docs-lint를 사용하면 제목 구성, 끊어진 링크, 필수 문서나 장의 누락, 용어의 불일치, 요구사항 ID의 정합성 등을 확인할 수 있습니다. 검사는 항상 문서 루트 전체를 대상으로 실행됩니다.

## 검사 실행하기

1. 도구 모음에서 [문서 도구]를 누르고 [검사] 탭을 엽니다.
2. [문서 루트 검사]를 누릅니다.
   명령 팔레트에서 "Lunascape Docs: 문서 루트 검사"로도 실행할 수 있습니다.
3. 결과 목록을 확인합니다.

## 결과 읽기

- 목록 위의 [이 문서] / [전체]로 표시할 범위를 전환합니다. 검사의 범위 자체는 항상 문서 루트 전체입니다.
- 지적 사항에는 "오류", "경고", "정보", "제안"의 4단계가 있습니다. 도구 모음의 [문서 도구]에는 오류와 경고의 건수가 표시됩니다.
- 지적 사항을 누르면 해당하는 Markdown 원본의 위치가 VS Code 편집기에서 열립니다.
- 문서 루트 전체에 관한 지적 사항(테스트 문서의 누락 등)은 "문서 루트 전체" 항목으로 표시되며 위치를 갖지 않습니다.
- 같은 지적 사항은 VS Code의 "문제" 패널에도 표시됩니다.

## 검사하는 항목

[규칙 확인·변경]을 누르면 활성화된 검사의 목록과 각각의 목적이 표시됩니다. 주요 항목은 다음과 같습니다.

| 항목 | 내용 |
|---|---|
| 제목 구성 | H1이 하나 있고, 제목 수준이 중간에 건너뛰지 않았는지 |
| 내부 링크 | 링크 대상 문서가 존재하고, 문서 루트 밖으로 벗어나지 않았는지 |
| 코드 블록의 언어 | 코드 블록에 언어 이름이 지정되어 있는지 |
| 필요한 폴더와 문서 | Standard Pack의 프로필이 요구하는 폴더와 문서가 갖추어져 있는지 |
| 문서에 필요한 장 | 문서 종류마다 필요한 장이 있는지 |
| 용어의 통일 | 피해야 할 표현을 검출하고, 권장 용어로 통일하도록 안내 |
| 요구사항 ID의 명명과 중복 | 요구사항 ID가 명명 규칙에 맞고, 중복으로 정의되지 않았는지 |
| 요구사항 ID의 참조 정합성 | 설계, 테스트, 현황표 등이 참조하는 요구사항 ID가 실제로 존재하는지 |
| 요구사항과 테스트의 대응 | 요구사항 ID가 테스트 문서에서 참조되고 있는지 |

활성화되는 항목은 `lunascape-docs.json`에서 선택한 Standard Pack과 프로필, 그리고 `docs-lint.config.json`에 따라 결정됩니다.

> **참고**
>
> - 문서나 설정을 변경하면 이전 결과는 "재검사 필요" 상태가 됩니다. 자동으로 합격 처리되지 않습니다. [문서 루트 검사]를 다시 눌러 주십시오.
> - 저장하지 않은 변경 내용은 검사에 반영되지 않습니다. 먼저 저장해 주십시오.
> - 검사는 단말 내에서 결정적으로 실행됩니다. AI에 의한 평가나 번역의 결과가 검사 결과에 섞이는 일은 없습니다.
