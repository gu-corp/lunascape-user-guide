# การตั้งค่าโครงการ

ไฟล์ `lunascape-docs.json` ที่อยู่ใต้รากเอกสารโดยตรงคือการตั้งค่าของรากเอกสารที่ใช้ร่วมกันในทีม จัดการด้วย Git

## สร้างหรือแก้ไขไฟล์การตั้งค่า

- กด [เครื่องมือเอกสาร] บนแถบเครื่องมือ → แท็บ [ตรวจสอบ] → [แหล่งที่มาของกฎและการตั้งค่าเอกสาร] → [แก้ไขการตั้งค่าเอกสาร] แล้วไฟล์จะเปิดใน VS Code หากยังไม่มีไฟล์ ระบบจะสร้างไฟล์เริ่มต้นให้ในตอนนั้น
- ชื่อไฟล์ `lunascape-docs.json` จะเชื่อมโยงกับ JSON Schema ที่มาพร้อมกับผลิตภัณฑ์โดยอัตโนมัติ จึงมีการเติมข้อความให้และแสดงคำอธิบายของแต่ละรายการ ไม่จำเป็นต้องเขียน `$schema`

## ตัวอย่างการตั้งค่า

```json
{
  "id": "product-docs",
  "title": "เอกสารผลิตภัณฑ์",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## คำอธิบายของแต่ละรายการ

| รายการ | เนื้อหา | ค่าเริ่มต้น |
|---|---|---|
| `id` | คีย์ที่ใช้บันทึกการตั้งค่าการแสดงผลของผู้ใช้แต่ละคน กำหนด ID คงที่ไว้เมื่อต้องการให้การตั้งค่าติดตามไปด้วยแม้ย้ายโฟลเดอร์ | เส้นทางของโฟลเดอร์ |
| `title` | ชื่อที่แสดงที่ปลายซ้ายของแถบเครื่องมือและในรายการรากเอกสาร ไม่เปลี่ยนแปลงแม้สลับภาษาที่แสดง | หัวเรื่องของ README/index ที่ราก หากไม่มีจะใช้ชื่อโฟลเดอร์ |
| `indexTitle` | หัวเรื่องของ INDEX | `INDEX` |
| `startPage` | เอกสารที่เปิดเป็นอันดับแรก (เส้นทางสัมพัทธ์จากรากเอกสาร) | `README.md` |
| `appearance` | ชุดสี `light` (สว่างเสมอ) หรือ `auto` (ตามธีมของ VS Code) | `light` |
| `defaultLocale` | ภาษาเริ่มต้น (ภาษาของเอกสารต้นฉบับ) ระบุด้วยแท็กภาษาแบบ BCP 47 (เช่น `ja`, `en`, `zh-Hant`) และใช้เป็นต้นทางของคำแปล | ไม่ได้ตั้งค่า (คาดเดาจากเนื้อหาเพื่อแสดงผล) |
| `fallbackLocale` | ภาษาที่แสดงเป็นอันดับแรกแก่ผู้อ่านที่ภาษาของสภาพแวดล้อมไม่ตรงกับภาษาที่รองรับใดเลย ให้ระบุภาษาที่อยู่ใน `locales` | ไม่ได้ตั้งค่า (ใช้ `defaultLocale`) |
| `locales` | รายการภาษาที่รองรับ ให้รวม `defaultLocale` ไว้ด้วย ภาษาเหล่านี้จะปรากฏในเมนูภาษาและเป็นปลายทางของคำแปล | เฉพาะ `defaultLocale` |
| `ignoredDirectories` | ชื่อโฟลเดอร์ที่ยกเว้นจาก INDEX การค้นหา และการตรวจสอบ เมื่อระบุแล้วจะแทนที่ค่าเริ่มต้น | `["99-archive"]` |
| `tree` | ค่าเริ่มต้นของการแสดงผล INDEX ผู้ใช้เขียนทับได้จากการตั้งค่าการแสดงผล | ตามตัวอย่างข้างต้น |
| `editor.defaultMode` | มุมมองการแก้ไขที่ใช้จนกว่าผู้ใช้จะสลับเอง `visual` หรือ `source` | `visual` |
| `editor.showEditButton` | จะแสดง [แก้ไข] ที่มุมขวาล่างของเนื้อหาหรือไม่ | `true` |
| `documentStandards.pack` | Standard Pack ที่ใช้กับการตรวจสอบเอกสารและเทมเพลต ระบุเป็น `builtin:<ชื่อ>` หรือเส้นทางสัมพัทธ์จากรากเอกสาร | ไม่มี |
| `documentStandards.profile` | ชื่อโปรไฟล์ที่ Pack กำหนดไว้ | ไม่มี |
| `translation.enabled` | เปิดใช้การสร้างร่างคำแปลและการแปลทั้งชุด | `true` |
| `translation.contextFiles` | ไฟล์ Markdown ของเอกสารต้นฉบับ (เส้นทางสัมพัทธ์จากรากเอกสาร) ที่ส่งไปเป็นข้อมูลอ้างอิงด้านศัพท์และสำนวนขณะแปล | `[]` |
| `translation.maxContextCharacters` | ขีดจำกัดจำนวนอักขระรวมของเอกสารอ้างอิง (สูงสุด 1048576) | `49152` |
| `description` | คำอธิบายหนึ่งบรรทัดของชุดเอกสาร แสดงบนการ์ดที่หน้าแรกของที่เก็บ เขียนเป็นสตริงหรือเป็นออบเจ็กต์แยกตามภาษาได้เช่นเดียวกับ `title` | ไม่มี |

## บอกว่าเอกสารอยู่ที่ใดในที่เก็บ

ไฟล์ `lunascape-docs.json` ที่วางไว้ใต้ที่เก็บโดยตรงสามารถเขียน **แผนที่ของที่เก็บ** แทนการตั้งค่าของโฟลเดอร์นั้นได้ เมื่อเขียนรายการใดรายการหนึ่งใน 3 รายการต่อไปนี้ ไฟล์จะกลายเป็นแผนที่ และโฟลเดอร์นั้นเองจะไม่เป็นรากเอกสาร

| รายการ | เนื้อหา | ค่าเริ่มต้น |
|---|---|---|
| `defaultFolder` | เอกสารอยู่ในโฟลเดอร์ใด (เส้นทางสัมพัทธ์จากโฟลเดอร์นี้) โฟลเดอร์ปลายทางไม่จำเป็นต้องมีไฟล์การตั้งค่า | ไม่มี (ใช้ `docs`) |
| `roots` | รายการชุดเอกสารเมื่อมีหลายชุด (เส้นทางสัมพัทธ์จากโฟลเดอร์นี้ เรียงตามลำดับที่แสดง) ในกรณีนี้โฟลเดอร์นี้จะกลายเป็นหน้าแรก | ไม่มี |
| `excludes` | โฟลเดอร์ที่ยกเว้นจากการค้นหารากเอกสาร (เส้นทางสัมพัทธ์จากโฟลเดอร์นี้) เพิ่มเข้ากับรายการยกเว้นเริ่มต้น เช่น `node_modules` | `[]` |
| `home.cards` | จะแสดงการ์ดของชุดเอกสารใต้ README ของหน้าแรกหรือไม่ หากเขียนลิงก์เองใน README ให้ตั้งเป็น `false` | `true` |

รากเอกสารถูกกำหนดตามลำดับต่อไปนี้ โดยใช้รายการแรกที่พบจากบนลงล่าง

1. โฟลเดอร์ที่ระบุไว้ด้วยการตั้งค่าหรือคำสั่ง
2. ปลายทางที่ `defaultFolder` หรือ `roots` ใน `lunascape-docs.json` ใต้ที่เก็บโดยตรงชี้ไป
3. โฟลเดอร์ที่มี `lunascape-docs.json` (หากมีตั้งแต่ 2 โฟลเดอร์ขึ้นไปใต้โฟลเดอร์แม่เดียวกัน โฟลเดอร์แม่นั้นจะเป็นหน้าแรก)
4. โฟลเดอร์ `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. ตัวที่เก็บโดยตรงเอง

> **เคล็ดลับ**
>
> หากไม่เขียนอะไรเลย ข้อ 4 จะทำงาน ที่เก็บทั่วไปที่มี `docs/` เพียงชุดเดียวจึงทำงานเหมือนเดิม เขียน `defaultFolder` เฉพาะเมื่อต้องการให้ชื่อโฟลเดอร์เป็น `manual` เท่านั้น

### ตัวอย่างแผนที่

```json
{
  "title": "วิธีใช้ Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## ลำดับความสำคัญของการตั้งค่า

รายการที่เกี่ยวกับการแสดงผลมีลำดับความสำคัญดังนี้

1. การตั้งค่าการแสดงผลของผู้ใช้ (แผง [การตั้งค่าการแสดงผล])
2. การตั้งค่าของ VS Code (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. ค่าเริ่มต้นของผลิตภัณฑ์

ยกเว้นเรื่องภาษา (`defaultLocale`, `fallbackLocale`, `locales`) เท่านั้นที่ `lunascape-docs.json` เป็นต้นฉบับ ไม่สามารถเขียนทับภาษาของโครงการด้วยการตั้งค่าส่วนตัวของ VS Code ได้

> **ข้อควรระวัง**
>
> สามารถระบุ Standard Pack เป็น `standard` ใน `docs-lint.config.json` ได้เช่นกัน หากมีทั้งสองที่ `docs-lint.config.json` จะมีลำดับความสำคัญเหนือกว่า
