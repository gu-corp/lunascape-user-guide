# เปลี่ยนกฎการตรวจสอบ

คุณสามารถเปลี่ยนระดับการแจ้งเตือน (ข้อผิดพลาด คำเตือน ข้อมูล) ของแต่ละรายการตรวจสอบ หรือเลือกไม่ใช้รายการนั้นได้ การเปลี่ยนแปลงจะบันทึกไว้ใน `docs-lint.config.json` ของรากเอกสาร และใช้ร่วมกันทั้งทีม

## เปลี่ยนระดับการแจ้งเตือน

1. กด [เครื่องมือเอกสาร] บนแถบเครื่องมือ แล้วเปิดแท็บ [ตรวจสอบ]
2. กด [ตรวจสอบและแก้ไขกฎ]
   รายการตรวจสอบจะขยายออกภายในการ์ดเดียวกัน แต่ละรายการจะแสดงวัตถุประสงค์ และแหล่งที่มาของการตั้งค่าปัจจุบัน (Project, Profile, Pack, Default)
3. เลือกระดับการแจ้งเตือนของรายการที่ต้องการเปลี่ยน
4. กด [บันทึกและตรวจสอบใหม่]
   การตั้งค่าจะถูกบันทึก และรากเอกสารทั้งหมดจะถูกตรวจสอบใหม่ด้วยการตั้งค่าใหม่

| ตัวเลือก | ความหมาย |
|---|---|
| [การตั้งค่ามาตรฐาน (…)] | ลบการตั้งค่าที่เขียนทับไว้ และกลับไปใช้การตั้งค่ามาตรฐานที่กำหนดตามลำดับ โปรไฟล์ Standard Pack และค่าเริ่มต้น |
| [ไม่ใช้] | ไม่ตรวจสอบรายการนี้ |
| [ข้อมูล] / [คำเตือน] / [ข้อผิดพลาด] | รายงานด้วยระดับการแจ้งเตือนนี้ |

> **ข้อควรระวัง**
>
> - การบันทึกต้องใช้พื้นที่ทำงานที่เชื่อถือได้
> - สิ่งที่บันทึกคือระดับการแจ้งเตือนของแต่ละรายการเท่านั้น ตัวเลือกของแต่ละรายการจะยังคงอยู่เหมือนเดิม ส่วน Standard Pack และโปรไฟล์นั้นจะไม่เปลี่ยนแปลงจากหน้าจอนี้
> - หาก `docs-lint.config.json` ถูกแก้ไขจากภายนอกก่อนการบันทึกเพียงเล็กน้อย การบันทึกจะถูกยกเลิก โปรดโหลดสถานะล่าสุดแล้วทำใหม่อีกครั้ง
> - หากไม่มี `docs-lint.config.json` ไฟล์จะถูกสร้างขึ้นเมื่อคุณบันทึก

## แก้ไขไฟล์การตั้งค่าโดยตรง

- เมื่อกด [เปิดการตั้งค่าโดยละเอียด] จะเปิด `docs-lint.config.json` ใน VS Code
- เมื่อเปิด [แหล่งที่มาของกฎและการตั้งค่าเอกสาร] แล้วกด [แก้ไขการตั้งค่าเอกสาร] จะเปิด `lunascape-docs.json` ใน VS Code โดยเลือก Standard Pack และโปรไฟล์ได้ที่นี่

ทั้งสองไฟล์รองรับการเติมข้อความอัตโนมัติและคำอธิบายจาก JSON Schema ที่มาพร้อมกับส่วนขยาย

## Standard Pack และโปรไฟล์

Standard Pack คือมาตรฐานเอกสารที่รวมประเภทเอกสารที่จำเป็น โครงสร้างบท คำศัพท์ และเทมเพลตไว้ด้วยกัน เลือกได้ที่ `documentStandards` ใน `lunascape-docs.json`

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

Pack ที่มาพร้อมกัน `builtin:gu-corp-software` มีโปรไฟล์ `base`, `web-application`, `api-service`, `regulated-financial-product` และ `smart-contract`
