# ตั้งค่าข้อมูลการนำทาง

ชื่อและลำดับที่แสดงใน INDEX เขียนไว้ใน YAML front matter ของเอกสารแต่ละฉบับ แม้ไม่เขียนก็แสดงเอกสารได้ โดยใช้หัวเรื่อง (H1) และลำดับตามชื่อไฟล์

## ชื่อและลำดับของเอกสาร

เขียนข้อความต่อไปนี้ที่ส่วนต้นของเอกสาร

```yaml
---
navigation:
  title: เริ่มต้นใช้งาน
  order: 200
---
```

| รายการ | เนื้อหา |
|---|---|
| `navigation.title` | ชื่อที่แสดงใน INDEX หากละไว้ จะใช้ H1 และหากไม่มีจะใช้ชื่อไฟล์ |
| `navigation.order` | จำนวนเต็มที่กำหนดลำดับ เรียงจากน้อยไปมาก หากละไว้ จะใช้ลำดับเริ่มต้นที่คงที่ (ตามชื่อไฟล์) |

> **คำแนะนำ**
>
> - กำหนดค่า `order` ทีละ 100 เช่น 100, 200, 300 เพื่อให้แทรกค่าอย่าง 150 ไว้ตรงกลางได้ในภายหลัง
> - แม้มี `order` ที่ไม่ได้ระบุ ไม่ถูกต้อง หรือซ้ำกัน เอกสารก็ไม่ถูกซ่อน
> - เมื่อจัดลำดับใหม่ใน INDEX ระบบจะเขียน `navigation.order` ให้อัตโนมัติ ไม่จำเป็นต้องเขียนเอง

## ชื่อและลำดับของโฟลเดอร์

ชื่อและลำดับของโฟลเดอร์อยู่ใน front matter ของ `README.md` (หากไม่มี จะเป็น `index.md`) ในโฟลเดอร์นั้น โดยหน้าปกไม่จำเป็นต้องมีเนื้อหา

```yaml
---
navigation:
  title: การวางแผนผลิตภัณฑ์
  order: 100
---
```

โฟลเดอร์ที่ไม่มีหน้าปกจะแสดงด้วยชื่อโฟลเดอร์และลำดับเริ่มต้น เมื่อเปลี่ยนชื่อหรือจัดลำดับใหม่ใน INDEX และมีความจำเป็น ระบบจะสร้าง `README.md` ที่มีเพียง front matter ขึ้นมา การเปิดอ่านเพียงอย่างเดียวจะไม่สร้างไฟล์

## การจัดการในฉบับแปล

- ลำดับ และบทบาทของโฟลเดอร์ (หน้าปกหรือใช้สำหรับการตั้งค่าเท่านั้น) กำหนดโดยเอกสารในภาษาเริ่มต้นเท่านั้น
- ฉบับแปลเขียนทับได้เฉพาะ `navigation.title` เมื่อเอกสารต้นฉบับมีเนื้อหา H1 ของฉบับแปลจะถูกใช้เป็นชื่อด้วย
- การมีเพียงฉบับแปลจะไม่ทำให้จำนวนหน้าเพิ่มขึ้น

## การเรียงลำดับและการยุบรายการย่อย

ในหน้าปกของโฟลเดอร์ มีการกำหนด `navigation.children.sort` และ `navigation.children.defaultCollapsed` สำหรับระบุวิธีเรียงลำดับรายการย่อยที่อยู่ถัดลงไปหนึ่งชั้น และสถานะการยุบเมื่อเริ่มต้น การอ่านและการแก้ไขใน VS Code จะรองรับในอนาคต
