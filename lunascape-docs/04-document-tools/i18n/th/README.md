# การใช้เครื่องมือเอกสาร

เครื่องมือเอกสารคือแผงที่รวมการตรวจสอบเอกสาร การสร้างจากเทมเพลต และการแปลไว้ด้วยกัน เปิดได้จาก [เครื่องมือเอกสาร] (เครื่องหมายถูก) บนแถบเครื่องมือ

## เปิดเครื่องมือเอกสาร

1. กด [เครื่องมือเอกสาร] บนแถบเครื่องมือ
   แผงจะเปิดขึ้นทางด้านขวาของหน้าจอ
2. เลือกฟังก์ชันด้วยแท็บด้านบน
3. หากต้องการปิดแผง ให้กด [ปิด] หรือกด [เครื่องมือเอกสาร] อีกครั้ง

| แท็บ | ฟังก์ชัน |
|---|---|
| [แปล] | การสร้างคำแปลของหน้าที่แสดงอยู่ การตั้งค่าภาษาของโครงการ และการแปลเป็นชุด |
| [ตรวจสอบ] | การตรวจสอบรากเอกสารทั้งหมดด้วย docs-lint รายการผลการตรวจสอบ การดูและแก้ไขกฎ |
| [สร้าง] | การสร้างเอกสารจากเทมเพลตในตัวหรือของ Standard Pack |

> **คำแนะนำ**
>
> - [เครื่องมือเอกสาร] บนแถบเครื่องมือจะแสดงสถานะของผลการตรวจสอบ (ไม่พบข้อสังเกต จำนวนข้อสังเกต จำเป็นต้องตรวจสอบใหม่ เป็นต้น)
> - เมื่อเลือก [สร้างและจัดการคำแปล…] ในเมนูภาษา เครื่องมือเอกสารจะแสดงขึ้นโดยเปิดแท็บ [แปล] ไว้

> **ข้อควรระวัง**
>
> - การบันทึกการตั้งค่าการตรวจสอบ การสร้างจากเทมเพลต และการแปล จะทำได้เฉพาะเมื่อพื้นที่ทำงานได้รับความเชื่อถือใน VS Code เท่านั้น
> - ขณะที่แสดงวิธีใช้อยู่ หรือขณะที่เปิดโฟลเดอร์ซึ่งไม่ได้อยู่ในรากเอกสารไว้ชั่วคราว จะใช้บางฟังก์ชันไม่ได้
