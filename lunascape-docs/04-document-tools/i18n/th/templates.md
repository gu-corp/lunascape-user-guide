# สร้างเอกสารจากเทมเพลต

ในแท็บ [สร้าง] ของเครื่องมือเอกสาร คุณสามารถเลือกเทมเพลต ดูตัวอย่างเนื้อหา แล้วสร้างเอกสารใหม่ได้

1. กด [เครื่องมือเอกสาร] บนแถบเครื่องมือ แล้วเปิดแท็บ [สร้าง]
2. กด [สร้างจากเทมเพลต] แล้วเลือกเทมเพลต
3. กรอกช่องข้อมูล (ชื่อเรื่อง บทสรุป และอื่น ๆ) ช่องที่จำเป็นจะแสดงคำว่า "จำเป็น"
4. กรอกปลายทางที่จะบันทึกเป็นพาธสัมพัทธ์จากรากเอกสาร (ตัวอย่าง: `03-design/api.md`)
5. กด [ตัวอย่าง] แล้วตรวจดู Markdown ที่สร้างขึ้น
6. กด [สร้างด้วยเนื้อหานี้]
   ระบบจะสร้างเอกสารและแสดงในตัวแสดงผล จากนั้นจะเรียกใช้การตรวจสอบรากเอกสารทั้งหมดต่อไป

## เทมเพลตที่เลือกได้

| เทมเพลต | เนื้อหา |
|---|---|
| เอกสารหน้าเดียว | สร้างข้อกำหนดสั้น ๆ บันทึกย่อ หรือเอกสารคำอธิบายเดี่ยว ๆ ในไฟล์เดียว |
| ข้อกำหนด・คู่มือ・วิธีใช้ | สร้างไฟล์เดียวด้วยโครงบทที่ใช้ได้ทั่วไปสำหรับข้อกำหนด คู่มือ และวิธีใช้ |
| เทมเพลตของ Standard Pack | เมื่อเลือก Standard Pack ไว้ใน `lunascape-docs.json` จะมีชนิดเอกสารที่ใช้ได้ในโปรไฟล์นั้น (เอกสารกำหนดความต้องการ เอกสารออกแบบ และอื่น ๆ) เพิ่มเข้ามา |

> **ข้อควรระวัง**
>
> - การสร้างต้องใช้พื้นที่ทำงานที่เชื่อถือได้
> - ระบบจะไม่เขียนทับไฟล์ที่มีอยู่ หากปลายทางมีเอกสารชื่อเดียวกันอยู่แล้ว จะสร้างไม่ได้
> - ปลายทางต้องมีนามสกุล `.md` หรือ `.mdx` และสร้างภายใต้ `i18n` (ที่เก็บฉบับแปล) ไม่ได้
> - หลังจากแก้ไขข้อมูลที่กรอก ให้กด [ตัวอย่าง] อีกครั้งก่อนสร้าง

> **คำแนะนำ**
>
> ในโครงการที่ยังไม่มีโฟลเดอร์เอกสาร คุณสามารถสร้างชุดแรกได้ด้วย "Lunascape Docs: สร้างเอกสารจากเทมเพลต" ในแผงคำสั่ง ดู [สร้างเอกสารครั้งแรก](../01-introduction/first-documents.md)
