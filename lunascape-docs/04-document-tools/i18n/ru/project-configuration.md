# Настройки проекта

Файл `lunascape-docs.json` непосредственно в корне документации — это общие для команды настройки корня документации. Он управляется через Git.

## Создание и изменение файла настроек

- На панели инструментов нажмите [Инструменты документа] → вкладка [Проверка] → [Источник правил и настройки документов] → [Изменить настройки документов], и файл откроется в VS Code. Если файла нет, в этот момент создается начальный файл.
- С именем файла `lunascape-docs.json` автоматически связывается встроенная JSON Schema, поэтому доступны автодополнение ввода и описания каждого поля. Запись `$schema` не требуется.

## Пример настроек

```json
{
  "id": "product-docs",
  "title": "Документация продукта",
  "indexTitle": "INDEX",
  "startPage": "README.md",
  "appearance": "light",
  "defaultLocale": "ja",
  "fallbackLocale": "en",
  "locales": ["ja", "en"],
  "ignoredDirectories": ["99-archive"],
  "tree": {
    "autoHideSingleItem": true,
    "showFileNames": false,
    "showDocumentIcons": false,
    "showFolderIcons": false,
    "showItemCounts": false,
    "showGuides": true,
    "density": "comfortable"
  },
  "editor": {
    "defaultMode": "visual",
    "showEditButton": true
  },
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  },
  "translation": {
    "enabled": true,
    "contextFiles": ["README.md", "glossary/TERMS.md"],
    "maxContextCharacters": 49152
  }
}
```

## Описание полей

| Поле | Содержание | По умолчанию |
|---|---|---|
| `id` | Ключ, под которым сохраняются настройки отображения для каждого пользователя. Задайте фиксированный ID, если хотите сохранить настройки при перемещении папки | Путь к папке |
| `title` | Имя, отображаемое в левом краю панели инструментов и в списке корней документации. Не меняется при переключении языка интерфейса | Заголовок README/index корня, иначе имя папки |
| `indexTitle` | Заголовок INDEX | `INDEX` |
| `startPage` | Документ, открываемый первым (относительный путь от корня документации) | `README.md` |
| `appearance` | Цветовая схема: `light` (всегда светлая) или `auto` (следует теме VS Code) | `light` |
| `defaultLocale` | Язык по умолчанию (язык исходного документа). Указывается языковым тегом BCP 47 (`ja`, `en`, `zh-Hant` и т. п.). Служит источником перевода | Не задано (определяется по тексту для отображения) |
| `fallbackLocale` | Язык, который первым показывается читателям, чей язык окружения не совпадает ни с одним из поддерживаемых. Укажите язык, входящий в `locales` | Не задано (используется `defaultLocale`) |
| `locales` | Список поддерживаемых языков. Включите в него `defaultLocale`. Становится языковым меню и списком возможных языков перевода | Только `defaultLocale` |
| `ignoredDirectories` | Имена папок, исключаемых из INDEX, поиска и проверок. Если задано, заменяет значение по умолчанию | `["99-archive"]` |
| `tree` | Значения по умолчанию для отображения INDEX. Пользователь может переопределить их в параметрах отображения | Как в примере выше |
| `editor.defaultMode` | Режим редактирования, пока пользователь его не переключил: `visual` или `source` | `visual` |
| `editor.showEditButton` | Показывать ли [Редактировать] в правом нижнем углу документа | `true` |
| `documentStandards.pack` | Standard Pack, используемый для проверки документов и шаблонов: `builtin:<имя>` или относительный путь от корня документации | Нет |
| `documentStandards.profile` | Имя профиля, определяемого Pack | Нет |
| `translation.enabled` | Включает создание вариантов перевода и пакетный перевод | `true` |
| `translation.contextFiles` | Markdown исходного документа (относительный путь от корня документации), передаваемый при переводе как справка по терминологии и стилю | `[]` |
| `translation.maxContextCharacters` | Верхний предел суммарного числа символов справочных документов (максимум 1048576) | `49152` |
| `description` | Однострочное описание набора документов. Отображается на карточке домашней страницы репозитория. Как и `title`, может быть строкой или объектом с разбивкой по языкам | Нет |

## Указание, где в репозитории находятся документы

В файле `lunascape-docs.json`, помещенном непосредственно в репозитории, можно записать не настройки этой папки, а **карту репозитория**. Если записать любое из трех полей ниже, файл становится картой, а сама папка перестает быть корнем документации.

| Поле | Содержание | По умолчанию |
|---|---|---|
| `defaultFolder` | В какой папке находятся документы (относительный путь от текущей папки). Папке, на которую он указывает, файл настроек не нужен | Нет (используется `docs`) |
| `roots` | Список нескольких наборов документов, если они есть (относительные пути от текущей папки, в порядке отображения). В этом случае текущая папка становится домашней страницей | Нет |
| `excludes` | Папки, исключаемые из обнаружения корней документации (относительные пути от текущей папки). Добавляется к исключениям по умолчанию, таким как `node_modules` | `[]` |
| `home.cards` | Показывать ли карточки наборов документов под README домашней страницы. Установите `false`, если пишете ссылки в README самостоятельно | `true` |

Корень документации определяется в следующем порядке. Используется первый найденный сверху вниз.

1. Папка, указанная в настройках или команде
2. То, на что указывает `defaultFolder` или `roots` в `lunascape-docs.json` непосредственно в репозитории
3. Папка, в которой есть `lunascape-docs.json` (если под общим родителем их два или более, этот родитель становится домашней страницей)
4. Папка `docs` (`lunascapeDocEditor.rootDirectoryNames`)
5. Сам корень репозитория

> **Совет**
>
> Если ничего не записать, срабатывает пункт 4, поэтому обычный репозиторий с одной папкой `docs/` работает как прежде. Записывайте `defaultFolder` только тогда, когда папка называется иначе, например `manual`.

### Пример карты

```json
{
  "title": "Справка Lunascape",
  "roots": ["desktop", "mobile"],
  "excludes": ["third-party"],
  "home": { "cards": true }
}
```

## Приоритет настроек

Поля, связанные с отображением, применяются в следующем порядке.

1. Настройки отображения пользователя (панель [Параметры отображения])
2. Настройки VS Code (`lunascapeDocEditor.*`)
3. `lunascape-docs.json`
4. Значения по умолчанию продукта

Исключение составляют только языки (`defaultLocale`, `fallbackLocale`, `locales`): здесь эталоном является `lunascape-docs.json`. Переопределить языки проекта в личных настройках VS Code нельзя.

> **Примечание**
>
> Standard Pack можно указать и как `standard` в `docs-lint.config.json`. Если он задан в обоих местах, приоритет имеет `docs-lint.config.json`.
