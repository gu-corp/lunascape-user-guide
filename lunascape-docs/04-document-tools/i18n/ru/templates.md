# Создание документа из шаблона

На вкладке [Создать] в Инструментах документа можно выбрать шаблон, просмотреть содержимое и затем создать новый документ.

1. Нажмите [Инструменты документа] на панели инструментов и откройте вкладку [Создать].
2. Нажмите [Создать из шаблона] и выберите шаблон.
3. Заполните поля ввода (заголовок, краткое описание и другие). Обязательные поля отмечены словом «Обязательно».
4. Укажите место сохранения как путь относительно корня документации (например, `03-design/api.md`).
5. Нажмите [Предпросмотр] и проверьте создаваемый Markdown.
6. Нажмите [Создать с этим содержимым].
   Документ будет создан и открыт в средстве просмотра. Затем выполняется проверка всего корня документации.

## Доступные шаблоны

| Шаблон | Содержимое |
|---|---|
| Одностраничный документ | Короткая спецификация, заметка или отдельный пояснительный документ в одном файле |
| Спецификация, руководство, справка | Один файл с универсальной структурой разделов, пригодной для спецификации, руководства или справки |
| Шаблоны Standard Pack | Если в `lunascape-docs.json` выбран Standard Pack, добавляются типы документов, доступные в этом профиле (требования, проектная документация и другие) |

> **Примечание**
>
> - Для создания требуется надежная рабочая область.
> - Существующие файлы не перезаписываются. Если в месте сохранения уже есть документ с таким именем, создать его не удастся.
> - Место сохранения должно иметь расширение `.md` или `.mdx`. Внутри `i18n` (где находятся переводы) создавать документы нельзя.
> - После изменения введенных данных снова нажмите [Предпросмотр], а затем создайте документ.

> **Совет**
>
> В проекте, где еще нет папки с документами, первый комплект можно создать командой «Lunascape Docs: Создать документы из шаблона» в палитре команд. См. раздел [Создание первых документов](../01-introduction/first-documents.md).
