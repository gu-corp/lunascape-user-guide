# Корень документации и соглашения о файлах

Правила, по которым Lunascape Docs находит документы и собирает INDEX. Исходником служит сама файловая система, поэтому не нужны ни реестр, ни настройка сборки.

## Корень документации

- Корнем документации становится ближайшая папка `docs` или папка, в которой лежит `lunascape-docs.json`.
- Если положить `lunascape-docs.json`, папка может называться и не `docs`.
- Если открыть файл Markdown, не входящий ни в один корень документации, его папка временно показывается как корень документации.

## Файлы, которые видны в INDEX

- Показываются файлы `.md`, `.markdown` и `.mdx`. Новые файлы появляются всегда, даже без front matter и сведений о навигации.
- Папки, имя которых начинается с `.`, папка `node_modules` и папки, перечисленные в `ignoredDirectories` (по умолчанию `99-archive`), не показываются.
- Всё, что лежит внутри `i18n/`, считается переводами и отдельно в INDEX не выводится.

## Титульная страница папки

- Файл `README.md` с текстом (а если его нет — `index.md`) становится титульной страницей своей папки. Нажатие на имя папки в INDEX открывает её.
- Файл `README.md`, состоящий только из front matter, без текста, считается «дескриптором настроек» и как страница не показывается. Используйте его, когда папке нужны только заголовок или порядок.
- Если есть и `README.md`, и `index.md`, приоритет у `README.md`.

## Язык по умолчанию и переводы

- Документы на языке по умолчанию (исходные) остаются на своих местах.
- Перевод кладётся в папку `i18n/<язык>/` рядом с документом, под тем же именем файла. Воссозданная под `i18n/` структура папок не распознаётся.
- Это единственное место, откуда определяется перевод. Тот же файл в любом другом месте останется отдельным файлом, который ни один документ не считает своим переводом.

```text
docs/
  lunascape-docs.json
  README.md                  ← landing page of the root (start page)
  i18n/en/README.md          ← its English translation
  01-product/
    README.md                ← landing page of the folder
    requirements.md
    i18n/en/README.md        ← the English translations of the two above
    i18n/en/requirements.md
  99-archive/                ← excluded from the INDEX by default
```

## О файле `_meta.json`

Файл `_meta.json` из Nextra для навигации не используется. Существующие файлы не изменяются и не удаляются. В будущем их будет обрабатывать только явная функция импорта и экспорта.
