# Изменение правил проверки

Вы можете изменить уровень уведомления (ошибка, предупреждение, информация) для каждой проверки или выключить проверку. Изменения сохраняются в файле `docs-lint.config.json` в корне документации и становятся общими для всей команды.

## Изменение уровня уведомления

1. Нажмите [Инструменты документа] на панели инструментов и откройте вкладку [Проверка].
2. Нажмите [Просмотреть и изменить правила].
   Список проверок раскрывается внутри той же карточки. Для каждой проверки отображается ее назначение и источник текущей настройки (Project, Profile, Pack, Default).
3. Выберите уровень уведомления для нужной проверки.
4. Нажмите [Сохранить и проверить снова].
   Настройка сохраняется, и весь корень документации проверяется заново с новыми параметрами.

| Вариант | Значение |
|---|---|
| [Стандартная настройка (…)] | Удаляет переопределение и возвращает стандартную настройку, определяемую в порядке: профиль, Standard Pack, значение по умолчанию |
| [Выключено] | Эта проверка не выполняется |
| [Информация] / [Предупреждение] / [Ошибка] | Сообщать с этим уровнем уведомления |

> **Примечание**
>
> - Для сохранения требуется надежная рабочая область.
> - Сохраняется только уровень уведомления каждой проверки. Параметры отдельных проверок сохраняются без изменений. Сам Standard Pack и профиль на этом экране не изменяются.
> - Если непосредственно перед сохранением файл `docs-lint.config.json` был изменен извне, сохранение отменяется. Загрузите последнее состояние и повторите попытку.
> - Если файла `docs-lint.config.json` нет, он создается при сохранении.

## Прямое редактирование файлов настроек

- Нажмите [Открыть подробные настройки], чтобы открыть `docs-lint.config.json` в VS Code.
- Откройте [Источник правил и настройки документов] и нажмите [Изменить настройки документов], чтобы открыть `lunascape-docs.json` в VS Code. Standard Pack и профиль выбираются здесь.

Для обоих файлов действуют автодополнение и описания из схем JSON Schema, входящих в состав расширения.

## Standard Pack и профили

Standard Pack — это стандарт документации, объединяющий необходимые типы документов, структуру разделов, терминологию и шаблоны. Он выбирается в параметре `documentStandards` файла `lunascape-docs.json`.

```json
{
  "documentStandards": {
    "pack": "builtin:gu-corp-software",
    "profile": "web-application"
  }
}
```

Входящий в комплект пакет `builtin:gu-corp-software` содержит профили `base`, `web-application`, `api-service`, `regulated-financial-product` и `smart-contract`.
