# Работа с инструментами документа

Инструменты документа — это панель, объединяющая проверку документов, создание из шаблонов и перевод. Она открывается кнопкой [Инструменты документа] (галочка) на панели инструментов.

## Открытие инструментов документа

1. Нажмите [Инструменты документа] на панели инструментов.
   Панель откроется в правой части экрана.
2. Выберите нужную функцию с помощью вкладок вверху.
3. Чтобы закрыть панель, нажмите [Закрыть] или нажмите [Инструменты документа] еще раз.

| Вкладка | Функция |
|---|---|
| [Перевести] | Создание вариантов перевода текущей страницы, настройка языков проекта, пакетный перевод |
| [Проверка] | Проверка всего корня документации с помощью docs-lint, список замечаний, просмотр и изменение правил |
| [Создать] | Создание документа из встроенных шаблонов или шаблонов Standard Pack |

> **Совет**
>
> - На кнопке [Инструменты документа] на панели инструментов отображается состояние проверки (замечаний нет, количество замечаний, требуется повторная проверка и т. п.).
> - Если выбрать в языковом меню пункт [Создать переводы и управлять ими…], инструменты документа откроются на вкладке [Перевести].

> **Примечание**
>
> - Сохранение параметров проверки, создание из шаблонов и перевод выполняются, только если рабочая область в VS Code отмечена как надежная.
> - Во время показа справки, а также при временно открытой папке, не входящей в корень документации, часть функций недоступна.
