# Настройка метаданных навигации

Имя и порядок, отображаемые в INDEX, записываются в YAML front matter каждого документа. Документы отображаются и без них — используются заголовок (H1) и порядок по имени файла.

## Имя и порядок документа

В начале документа напишите следующее.

```yaml
---
navigation:
  title: Введение
  order: 200
---
```

| Поле | Значение |
|---|---|
| `navigation.title` | Имя, отображаемое в INDEX. Если пропущено, используется H1, а если и его нет — имя файла |
| `navigation.order` | Целое число, определяющее порядок по возрастанию. Если пропущено, применяется стабильный порядок по умолчанию (по имени файла) |

> **Совет**
>
> - Задавайте значения `order` с шагом 100, например 100, 200, 300, чтобы позже можно было вставить между ними 150.
> - Отсутствующие, неверные или повторяющиеся значения `order` никогда не скрывают документ.
> - При изменении порядка в INDEX значение `navigation.order` записывается автоматически. Вручную его писать не нужно.

## Имя и порядок папки

Имя и порядок папки хранятся во front matter её файла `README.md` (или `index.md`, если README нет). Тело титульной страницы при этом не требуется.

```yaml
---
navigation:
  title: Планирование продукта
  order: 100
---
```

Папка без титульной страницы отображается с именем папки и порядком по умолчанию. Когда изменение имени или порядка в INDEX этого требует, создаётся файл `README.md`, содержащий только front matter. При простом просмотре файлы не создаются.

## Обработка в переводах

- Порядок и роль папки (титульная страница или только для настроек) определяет только документ на языке по умолчанию.
- Перевод может переопределить только `navigation.title`. Если у исходного документа есть тело, имя берётся и из H1 перевода.
- Наличие одного лишь перевода не добавляет страницу.

## Сортировка и сворачивание дочерних элементов

На титульной странице папки определены `navigation.children.sort` и `navigation.children.defaultCollapsed`, которые задают порядок сортировки непосредственных дочерних элементов и их начальное состояние сворачивания. Чтение и редактирование в VS Code планируется в будущем.
