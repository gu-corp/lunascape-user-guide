# 渡せる作業

[AI] タブの [作業] から選びます。作業ごとに、渡す指示と事後チェックが変わります。

| 作業 | 内容 | 必要なもの | API 型 |
|---|---|---|---|
| このページを翻訳 | 表示中の文書を、選んだ言語へ翻訳します | 対象の文書を開いていること、対象言語 | ○ |
| 未訳をまとめて翻訳 | 選んだ言語の未訳および要更新の文書を、順に翻訳します | 対象言語 | セッション型のみ |
| このページを校正 | 用語、文体、および文書標準が要求する章立てを確認し、修正します | 対象の文書を開いていること | ○ |
| 新しい文書を作成 | 文書標準とテンプレートに従い、新しい文書を作成します | 主題（省略可） | セッション型のみ |

## 指示に含まれるもの

| 項番 | 内容 |
|---|---|
| 1 | 文書ルートの位置。この外は変更しないよう指示します |
| 2 | 既定言語（正本）と、翻訳版の置き場所（文書と同じフォルダーの `i18n/<言語>/`） |
| 3 | `navigation.order` は正本だけが持つこと、翻訳版が上書きしてよいのは `navigation.title` だけであること |
| 4 | 要件 ID、リンク、コード、Mermaid、TeX、front matter の構造を変更しないこと |
| 5 | 文書標準と用語集（`docs-lint.config.json` の `terminology`） |
| 6 | 終わったら文書チェックを実行し、変更したファイルを報告し、Git 操作は行わないこと |

> **ヒント**
>
> 「未訳をまとめて翻訳」の対象は台帳から作られ、1 回あたり 200 文書までです。多い場合は繰り返し実行してください。
