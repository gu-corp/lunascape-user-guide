# 台帳と記録

[AI] タブの上部にある台帳は、対応言語ごとの翻訳状況です。AI を使わなくても、何が足りないかを確認できます。

| 表示 | 意味 |
|---|---|
| 未訳 | 翻訳版がまだない文書の数 |
| 要更新 | 翻訳版はあるが、記録した時点より正本が新しい文書の数 |
| 翻訳済み | 正本に追随している翻訳版の数 |

台帳は文書ルートを走査して算出します。AI も言語モデルも関与しません。

## 翻訳の記録を更新する

「要更新」を判定するには、翻訳した時点の正本と翻訳版を記録しておく必要があります。セッション型の AI はファイルを直接書くため、記録は自動では作られません。

1. 翻訳が終わり、内容を確認したら、[翻訳の記録を更新] を押します。
2. 記録のない翻訳版が、現在の正本に対応するものとして記録されます。

Claude Code のセッションと API 型の保存は、記録を自動で行います（セッションは MCP ツール `record_translation_freshness` を使うよう指示されます）。このボタンが必要なのは、Codex や VS Code のチャットで翻訳した場合です。

以後、正本を変更すると、その翻訳版は「要更新」として表示されます。

> **ご注意**
>
> - 既に記録がある翻訳版は上書きしません。「要更新」の状態を消してしまわないためです。
> - 記録は `.lunascape-docs/translation-freshness.json` に保存されます。保存されるのは相対パス、言語、内容のハッシュ、日時だけで、本文は含みません。
