# AI に作業を渡す

Lunascape Docs は言語モデルを呼び出しません。**文脈と道具と検算**を用意し、翻訳・校正・作成の実行はお使いの AI に任せます。

## 考えかた

| 製品が用意するもの | 内容 |
|---|---|
| コンテキスト | 文書の規約（翻訳版の置き場所、front matter、文書標準、用語集）と、対象文書の位置 |
| 作業ツール | 未訳・要更新の台帳、文書の読み書き、テンプレートからの作成 |
| 事後チェック | docs-lint による検証、網羅状況と鮮度の差分 |

指示文には文書の本文を含めません。AI が自分でファイルを読み、自分で書き、自分で検証します。

## 作業を渡す

1. ツールバーの [文書ツール] を押し、[AI] タブを開きます。
2. [作業] から、渡したい作業を選びます。
3. 必要な項目（対象言語、主題）を入力します。
4. [この作業を渡す] を押します。
   VS Code のターミナルが開き、選んだ AI が指示を受け取って作業を始めます。

> **ヒント**
>
> Claude Code のセッションには、作業ツール（MCP サーバー `lunascape-docs`）が同伴します。セッションは未訳・要更新の一覧の取得、docs-lint の実行、翻訳後の鮮度記録を自分で行えます。

## 結果の確認

| プロバイダーの形態 | 結果の着地先 |
|---|---|
| セッション型（Claude Code、Codex） | 作業ツリーに直接書き込みます。**Git の差分で確認**してください |
| API 型（VS Code の言語モデル、Anthropic、OpenAI 互換） | 1 文書ずつ提案を返します。[差分を開く] で確認し、[保存] で書き込みます |

### API 型の提案を確認する

API 型で実行すると、[AI] タブに提案が届きます。

1. [差分を開く] を押し、現在の内容との違いを確認します。
2. よければ [保存] を押します。翻訳の場合は鮮度も記録されます。やめるときは [破棄] を押します。
   生成を途中でやめるには [中止] を押します。

> **ご注意**
>
> - Lunascape Docs が Git のステージやコミットを行うことはありません。変更は必ず差分で確認してください。
> - 信頼していないワークスペース、および文書ルート外の一時的なフォルダ表示では、作業を渡せません。
