# การตั้งค่า AI

เลือก AI และโมเดลที่จะรับงานของคุณ หน้าจอนี้ไม่ได้ใช้ quick pick ของ VS Code แต่ให้เลือกจากรายการแบบดึงลงในหน้าจอนี้

1. กด [เครื่องมือเอกสาร] → แท็บ [AI] → [การตั้งค่า AI…]
2. เลือก [ผู้ให้บริการ]
   รายการที่ใช้ในสภาพแวดล้อมนี้ไม่ได้จะแสดงในสถานะที่เลือกไม่ได้ พร้อมเหตุผลกำกับ
3. เลือก [โมเดล] ตัวเลือกจะเปลี่ยนไปตามผู้ให้บริการ
4. ปิดหน้าจอ ระบบจะบันทึกตัวเลือกไว้ตามผู้ใช้แต่ละคน และใช้ต่อในครั้งถัดไป

## ผู้ให้บริการ

| ผู้ให้บริการ | รูปแบบ | วิธีตรวจหา |
|---|---|---|
| Claude Code | แบบเซสชัน | มีคำสั่ง `claude` หรือไม่ |
| Codex | แบบเซสชัน | มีคำสั่ง `codex` หรือไม่ |
| โมเดลภาษาของ VS Code | แบบ API | โมเดลที่ลงทะเบียนไว้กับ VS Code Language Model API |
| Anthropic API | แบบ API | การลงทะเบียนคีย์ API |
| API ที่เข้ากันได้กับ OpenAI | แบบ API | การลงทะเบียนคีย์ API และปลายทาง |

**แบบเซสชัน** จะอ่านและเขียนไฟล์เอง และรันการตรวจสอบเอกสารเอง ผลลัพธ์จะถูกเขียนลงในโครงสร้างงานโดยตรง และตรวจดูได้จากส่วนต่างของ Git

**แบบ API** จะคืนค่าเป็น Markdown ของเอกสาร 1 ฉบับ แล้วส่วนขยายจะแสดงส่วนต่างให้ดูก่อนบันทึก

## การลงทะเบียนคีย์ API

Anthropic API และ API ที่เข้ากันได้กับ OpenAI จะใช้งานได้เมื่อลงทะเบียนคีย์ API แล้ว

1. เลือกปลายทางที่จะลงทะเบียนใน [ผู้ให้บริการ] ช่องกรอกคีย์ API จะปรากฏขึ้น
2. กรอก [คีย์ API] หากเป็นแบบที่เข้ากันได้กับ OpenAI ให้กรอก [ปลายทาง] ด้วย (ตัวอย่าง: `https://api.openai.com/v1`)
3. กด [บันทึก] จะแสดงข้อความ "ลงทะเบียนคีย์แล้ว"

> **ข้อควรระวัง**
>
> - คีย์จะถูกบันทึกไว้ใน SecretStorage ของ VS Code และจะไม่แสดงอีก ทั้งจะไม่ถูกเขียนลงใน `settings.json` หรือในเอกสารใด ๆ ลบได้ด้วย [ลบคีย์]
> - รายการโมเดลจะดึงมาจากแต่ละบริการด้วยคีย์ที่ลงทะเบียนไว้ ระหว่างที่ยังดึงไม่ได้ จะแสดงรายการที่ทราบอยู่แล้ว
> - งานที่รันได้ด้วยแบบ API มีเพียง "แปลหน้านี้" และ "ตรวจทานหน้านี้" เท่านั้น การไล่ดูเอกสารหลายฉบับและการสร้างเอกสารให้รันด้วยแบบเซสชัน

> **เคล็ดลับ**
>
> หากไม่พบผู้ให้บริการใดเลย ให้ติดตั้ง Claude Code หรือ Codex หรือลงทะเบียนคีย์ API แล้วเปิด [การตั้งค่า AI…] ขึ้นมาใหม่ ระบบจะตรวจพบ
