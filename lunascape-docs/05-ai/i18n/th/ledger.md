# บัญชีรายการและบันทึก

บัญชีรายการที่อยู่ด้านบนของแท็บ [AI] คือสถานะคำแปลของแต่ละภาษาที่รองรับ แม้ไม่ใช้ AI ก็ตรวจสอบได้ว่าขาดสิ่งใดบ้าง

| การแสดงผล | ความหมาย |
|---|---|
| ยังไม่ได้แปล | จำนวนเอกสารที่ยังไม่มีฉบับแปล |
| ต้องอัปเดต | จำนวนเอกสารที่มีฉบับแปลแล้ว แต่เอกสารต้นฉบับใหม่กว่าเวลาที่บันทึกไว้ |
| แปลแล้ว | จำนวนฉบับแปลที่ตามทันเอกสารต้นฉบับ |

บัญชีรายการคำนวณจากการไล่ตรวจรากเอกสาร ไม่มี AI และไม่มีโมเดลภาษาเข้ามาเกี่ยวข้อง

## อัปเดตบันทึกคำแปล

การจะตัดสินว่า "ต้องอัปเดต" ได้นั้น ต้องมีบันทึกของเอกสารต้นฉบับและฉบับแปล ณ เวลาที่แปลไว้ AI แบบเซสชันจะเขียนไฟล์โดยตรง จึงไม่มีการสร้างบันทึกโดยอัตโนมัติ

1. เมื่อแปลเสร็จและตรวจทานเนื้อหาแล้ว ให้กด [อัปเดตบันทึกคำแปล]
2. ฉบับแปลที่ยังไม่มีบันทึกจะถูกบันทึกว่าตรงกับเอกสารต้นฉบับปัจจุบัน

เซสชันของ Claude Code และการบันทึกแบบ API จะทำบันทึกให้โดยอัตโนมัติ (เซสชันจะได้รับคำสั่งให้ใช้เครื่องมือ MCP `record_translation_freshness`) ปุ่มนี้จำเป็นเมื่อคุณแปลด้วย Codex หรือแชทของ VS Code

นับจากนั้น เมื่อคุณแก้ไขเอกสารต้นฉบับ ฉบับแปลนั้นจะแสดงเป็น "ต้องอัปเดต"

> **ข้อควรระวัง**
>
> - ฉบับแปลที่มีบันทึกอยู่แล้วจะไม่ถูกเขียนทับ เพื่อไม่ให้สถานะ "ต้องอัปเดต" หายไป
> - บันทึกจะถูกเก็บไว้ใน `.lunascape-docs/translation-freshness.json` สิ่งที่เก็บมีเพียงเส้นทางแบบสัมพัทธ์ ภาษา แฮชของเนื้อหา และวันเวลาเท่านั้น ไม่มีเนื้อความของเอกสาร
