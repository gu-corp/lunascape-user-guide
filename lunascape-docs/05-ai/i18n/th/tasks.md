# งานที่ส่งต่อได้

เลือกจาก [งาน] ในแท็บ [AI] แต่ละงานจะเปลี่ยนคำสั่งที่ส่งต่อและการตรวจสอบหลังจากนั้น

| งาน | เนื้อหา | สิ่งที่ต้องมี | แบบ API |
|---|---|---|---|
| แปลหน้านี้ | แปลเอกสารที่แสดงอยู่เป็นภาษาที่เลือก | เปิดเอกสารเป้าหมายไว้ และภาษาปลายทาง | ○ |
| แปลส่วนที่ยังไม่ได้แปลทั้งหมด | แปลเอกสารที่ยังไม่ได้แปลและที่ต้องอัปเดตของภาษาที่เลือกตามลำดับ | ภาษาปลายทาง | แบบเซสชันเท่านั้น |
| ตรวจทานหน้านี้ | ตรวจสอบและแก้ไขคำศัพท์ รูปแบบการเขียน และการแบ่งหัวข้อตามที่มาตรฐานเอกสารกำหนด | เปิดเอกสารเป้าหมายไว้ | ○ |
| สร้างเอกสารใหม่ | สร้างเอกสารใหม่ตามมาตรฐานเอกสารและเทมเพลต | หัวเรื่อง (จะไม่ระบุก็ได้) | แบบเซสชันเท่านั้น |

## สิ่งที่อยู่ในคำสั่ง

| ลำดับ | เนื้อหา |
|---|---|
| 1 | ตำแหน่งของรากเอกสาร พร้อมคำสั่งไม่ให้แก้ไขสิ่งใดนอกเหนือจากนี้ |
| 2 | ภาษาเริ่มต้น (เอกสารต้นฉบับ) และที่เก็บฉบับแปล (`i18n/<ภาษา>/` ในโฟลเดอร์เดียวกับเอกสาร) |
| 3 | `navigation.order` เป็นของเอกสารต้นฉบับเท่านั้น และฉบับแปลเขียนทับได้เฉพาะ `navigation.title` |
| 4 | ห้ามเปลี่ยน ID ข้อกำหนด ลิงก์ โค้ด Mermaid TeX และโครงสร้าง front matter |
| 5 | มาตรฐานเอกสารและอภิธานศัพท์ (`terminology` ใน `docs-lint.config.json`) |
| 6 | เมื่อเสร็จแล้วให้เรียกใช้การตรวจสอบเอกสาร รายงานไฟล์ที่แก้ไข และไม่ดำเนินการใด ๆ กับ Git |

> **คำแนะนำ**
>
> เป้าหมายของ "แปลส่วนที่ยังไม่ได้แปลทั้งหมด" สร้างขึ้นจากทะเบียน และได้ครั้งละไม่เกิน 200 เอกสาร หากมีมากกว่านั้น ให้เรียกใช้ซ้ำ
