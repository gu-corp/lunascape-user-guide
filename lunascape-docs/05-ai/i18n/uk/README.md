# Передавання роботи ШІ

Lunascape Docs не викликає мовну модель. Він готує **контекст, інструменти та перевірки**, а переклад, вичитування та створення залишає тому ШІ, яким ви користуєтеся.

## Як це влаштовано

| Що надає продукт | Зміст |
|---|---|
| Контекст | Угоди документації (де лежать переклади, front matter, стандарт документа, глосарій) і розташування потрібного документа |
| Робочі інструменти | Реєстр документів без перекладу та тих, що потребують оновлення, читання й запис документів, створення за шаблоном |
| Подальші перевірки | Перевірка через docs-lint, різниця в повноті та свіжості |

Текст документа в інструкцію не входить: ШІ сам читає файли, сам пише і сам перевіряє.

## Передати роботу

1. Натисніть [Інструменти документа] на панелі інструментів і відкрийте вкладку [AI].
2. У полі [Робота] виберіть роботу, яку хочете передати.
3. Заповніть потрібні поля (мова призначення, тема).
4. Натисніть [Передати цю роботу].
   Відкриється термінал VS Code, і вибраний ШІ отримає інструкцію та почне роботу.

> **Підказка**
>
> Сеанс Claude Code супроводжують робочі інструменти (сервер MCP `lunascape-docs`). Сеанс може сам отримати список документів без перекладу та тих, що потребують оновлення, запустити docs-lint і записати свіжість після перекладу.

## Перевірка результату

| Вид постачальника | Куди потрапляє результат |
|---|---|
| Сеансовий (Claude Code, Codex) | Записує безпосередньо в робоче дерево. **Перевіряйте в різниці Git** |
| API (мовні моделі VS Code, Anthropic, сумісні з OpenAI) | Повертає пропозицію по одному документу. Перевірте її через [Відкрити різницю] і запишіть кнопкою [Зберегти] |

### Перевірка пропозиції від API

Після запуску з постачальником типу API пропозиція надходить на вкладку [AI].

1. Натисніть [Відкрити різницю] і порівняйте з поточним вмістом.
2. Якщо все гаразд, натисніть [Зберегти]. Для перекладу також записується свіжість. Щоб відмовитися, натисніть [Відхилити].
   Щоб зупинити генерування на півдорозі, натисніть [Припинити].

> **Примітка**
>
> - Lunascape Docs ніколи не виконує індексування чи коміти в Git. Обов'язково перевіряйте зміни в різниці.
> - У ненадійній робочій області, а також під час тимчасового перегляду папки поза коренем документації передати роботу не можна.
