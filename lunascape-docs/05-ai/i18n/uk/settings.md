# Налаштування AI

Виберіть AI та модель, яким передаватимете роботу. Вибір робиться в розкривних списках цього екрана, а не через швидкий вибір VS Code.

1. Натисніть [Інструменти документа] → вкладку [AI] → [Налаштування AI…].
2. Виберіть [Постачальник].
   Ті, що недоступні в цьому середовищі, показуються неактивними із зазначенням причини.
3. Виберіть [Модель]. Набір варіантів залежить від постачальника.
4. Закрийте екран. Вибір зберігається для кожного користувача й використовується наступного разу.

## Постачальники

| Постачальник | Тип | Спосіб виявлення |
|---|---|---|
| Claude Code | Сеансовий | Наявність команди `claude` |
| Codex | Сеансовий | Наявність команди `codex` |
| Мовні моделі VS Code | API | Моделі, зареєстровані у VS Code Language Model API |
| Anthropic API | API | Зареєстрований ключ API |
| API, сумісний з OpenAI | API | Зареєстровані ключ API та кінцева точка |

**Сеансовий** тип сам читає й записує файли та сам виконує перевірку документів. Результати записуються безпосередньо в робоче дерево, і їх переглядають у різниці Git.

**Тип API** повертає Markdown одного документа, а розширення показує різницю перед збереженням.

## Реєстрація ключа API

Anthropic API та API, сумісні з OpenAI, стають доступними після реєстрації ключа API.

1. Виберіть у списку [Постачальник] той, для якого реєструєте ключ. З’явиться поле для введення ключа API.
2. Введіть [Ключ API]. Для API, сумісного з OpenAI, введіть також [Кінцеву точку] (наприклад, `https://api.openai.com/v1`).
3. Натисніть [Зберегти]. З’явиться напис «Ключ зареєстровано».

> **Примітка**
>
> - Ключ зберігається в SecretStorage у VS Code й більше не показується. Він також не записується ані в `settings.json`, ані в документи. Видалити його можна через [Видалити ключ].
> - Список моделей отримується від кожної служби за зареєстрованим ключем. Поки його не отримано, показується відомий список.
> - Тип API може виконувати лише «Перекласти цю сторінку» та «Вичитати цю сторінку». Обхід кількох документів і створення документів виконуйте сеансовим типом.

> **Порада**
>
> Якщо не знайдено жодного постачальника, встановіть Claude Code чи Codex або зареєструйте ключ API. Після повторного відкриття [Налаштування AI…] його буде виявлено.
