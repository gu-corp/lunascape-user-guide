# Доступні завдання

Виберіть у списку [Завдання] на вкладці [AI]. Для кожного завдання змінюються інструкція, яку буде передано, і перевірка після виконання.

| Завдання | Зміст | Що потрібно | Тип API |
|---|---|---|---|
| Перекласти цю сторінку | Перекладає відкритий документ вибраною мовою | Відкритий потрібний документ, мова перекладу | ○ |
| Перекласти все без перекладу | По черзі перекладає документи вибраної мови, які без перекладу або потребують оновлення | Мова перекладу | Лише сеансовий тип |
| Вичитати цю сторінку | Перевіряє та виправляє терміни, стиль і структуру розділів, якої вимагає стандарт документів | Відкритий потрібний документ | ○ |
| Створити новий документ | Створює новий документ за стандартом документів і шаблонами | Тема (необов'язково) | Лише сеансовий тип |

## Що містить інструкція

| № | Зміст |
|---|---|
| 1 | Розташування кореня документації. Вказівка не змінювати нічого за його межами |
| 2 | Мова за замовчуванням (оригінал документа) і місце для перекладів (папка `i18n/<мова>/` поряд із документом) |
| 3 | Те, що `navigation.order` має лише оригінал документа, а переклад може перевизначати тільки `navigation.title` |
| 4 | Те, що не можна змінювати ідентифікатори вимог, посилання, код, Mermaid, TeX і структуру front matter |
| 5 | Стандарт документів і глосарій (`terminology` у `docs-lint.config.json`) |
| 6 | Після завершення виконати перевірку документа, повідомити про змінені файли й не виконувати жодних операцій Git |

> **Порада**
>
> Цілі для «Перекласти все без перекладу» беруться з реєстру, до 200 документів за один запуск. Якщо документів більше, запустіть завдання ще раз.
