# Журнал і записи

Журнал угорі вкладки [ШІ] — це стан перекладу для кожної підтримуваної мови. Він корисний і без ШІ: показує, чого бракує.

| Показник | Значення |
|---|---|
| Без перекладу | Кількість документів, які ще не мають перекладу |
| Потребує оновлення | Кількість документів, переклад яких існує, але оригінал документа новіший за момент запису |
| Перекладено | Кількість перекладів, що відповідають оригіналу документа |

Журнал обчислюється обходом кореня документації. Ані ШІ, ані мовна модель у цьому не беруть участі.

## Оновлення записів про переклад

Щоб визначати стан «Потребує оновлення», потрібно зберегти запис про оригінал документа та переклад на момент перекладання. Сеансовий ШІ записує файли безпосередньо, тому запис не створюється автоматично.

1. Коли переклад завершено й ви перевірили його вміст, натисніть [Оновити записи про переклад].
2. Переклади без запису буде записано як такі, що відповідають поточному оригіналу документа.

Сеанси Claude Code та збереження через API створюють записи автоматично (сеанс отримує вказівку використати інструмент MCP `record_translation_freshness`). Ця кнопка потрібна, якщо ви перекладали в Codex або в чаті VS Code.

Відтоді зміна оригіналу документа позначає його переклад як такий, що потребує оновлення.

> **Примітка**
>
> - Переклади, які вже мають запис, не перезаписуються — щоб не стерти наявний стан «Потребує оновлення».
> - Записи зберігаються у файлі `.lunascape-docs/translation-freshness.json`. Зберігаються лише відносні шляхи, мови, хеші вмісту та дата й час — сам текст документа не зберігається.
