# السجل والقيود

السجل الموجود أعلى تبويب [AI] هو حالة الترجمة لكل لغة مدعومة. ويمكنك معرفة ما ينقص دون استخدام الذكاء الاصطناعي.

| العرض | المعنى |
|---|---|
| ترجمة مفقودة | عدد المستندات التي لا توجد لها ترجمة بعد |
| غير محدّث | عدد المستندات التي توجد لها ترجمة، لكن المستند الأصلي أحدث من وقت تسجيل القيد |
| مترجَم | عدد الترجمات التي تتابع مستندها الأصلي |

يُحسب السجل بمسح جذر التوثيق. ولا يتدخل في ذلك ذكاء اصطناعي ولا نموذج لغوي.

## تحديث قيود الترجمة

لتحديد حالة «غير محدّث» يلزم تسجيل المستند الأصلي والترجمة كما كانا وقت الترجمة. والذكاء الاصطناعي من نوع الجلسة يكتب الملفات مباشرةً، لذا لا يُنشأ القيد تلقائيًا.

1. بعد انتهاء الترجمة ومراجعة محتواها، اضغط [تحديث قيود الترجمة].
2. تُسجَّل الترجمات التي لا قيد لها على أنها مطابقة للمستند الأصلي الحالي.

تسجّل جلسات Claude Code وعمليات الحفظ من النوع API القيدَ تلقائيًا (تُوجَّه الجلسة إلى استخدام أداة MCP باسم `record_translation_freshness`). وتحتاج إلى هذا الزر عندما تترجم عبر Codex أو محادثة VS Code.

وبعد ذلك، عند تغيير المستند الأصلي تظهر ترجمته على أنها «غير محدّث».

> **ملاحظة**
>
> - لا تُستبدل الترجمات التي لها قيد بالفعل، حتى لا تُمحى حالة «غير محدّث».
> - تُحفظ القيود في `.lunascape-docs/translation-freshness.json`. ولا يُحفظ سوى المسارات النسبية واللغات وبصمات المحتوى والتاريخ والوقت، دون نص المستند.
