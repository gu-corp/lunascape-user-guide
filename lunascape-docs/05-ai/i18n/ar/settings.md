# إعدادات الذكاء الاصطناعي

اختر الذكاء الاصطناعي والنموذج اللذين تُسلَّم إليهما الأعمال. لا تُستخدَم قائمة الاختيار السريع في VS Code، بل القوائم المنسدلة في هذه الشاشة.

1. اضغط [أدوات المستندات] ← تبويب [الذكاء الاصطناعي] ← [إعدادات الذكاء الاصطناعي…].
2. اختر [المزوّد].
   تظهر المزوّدات غير المتاحة في هذه البيئة بحالة غير قابلة للاختيار، مع ذكر السبب.
3. اختر [النموذج]. تتغيّر الخيارات بحسب المزوّد.
4. أغلق الشاشة. يُحفَظ الاختيار لكل مستخدم ويُستخدَم في المرة التالية.

## المزوّدات

| المزوّد | الشكل | طريقة الاكتشاف |
|---|---|---|
| Claude Code | جلسة | وجود الأمر `claude` |
| Codex | جلسة | وجود الأمر `codex` |
| نماذج اللغة في VS Code | واجهة برمجية | النماذج المسجَّلة في VS Code Language Model API |
| Anthropic API | واجهة برمجية | تسجيل مفتاح API |
| واجهة برمجية متوافقة مع OpenAI | واجهة برمجية | تسجيل مفتاح API ونقطة النهاية |

يقرأ مزوّد **الجلسة** الملفات ويكتبها بنفسه، ويُجري فحص المستندات بنفسه. تُكتَب النتائج مباشرةً في شجرة العمل، وتُراجَع في فروق Git.

يُعيد مزوّد **الواجهة البرمجية** مستندًا واحدًا بصيغة Markdown، ويعرض الامتداد الفروق قبل الحفظ.

## تسجيل مفتاح API

يصبح Anthropic API والواجهات البرمجية المتوافقة مع OpenAI قابلَين للاستخدام بعد تسجيل مفتاح API.

1. اختر جهة التسجيل من [المزوّد]. يظهر حقل إدخال مفتاح API.
2. أدخل [مفتاح API]. وفي حالة التوافق مع OpenAI، أدخل أيضًا [نقطة النهاية] (مثال: `https://api.openai.com/v1`).
3. اضغط [حفظ]. تظهر عبارة «تم تسجيل المفتاح».

> **ملاحظة**
>
> - يُحفَظ المفتاح في SecretStorage الخاص بـ VS Code ولا يُعرَض مرة أخرى. ولا يُكتَب في `settings.json` ولا في أي مستند. ويمكن حذفه بـ [حذف المفتاح].
> - تُجلَب قائمة النماذج من كل خدمة باستخدام المفتاح المسجَّل. وإلى أن يتم الجلب، تُعرَض قائمة معروفة.
> - الأعمال التي يمكن تنفيذها بمزوّد الواجهة البرمجية هي «ترجمة هذه الصفحة» و«تدقيق هذه الصفحة» فقط. أمّا المرور على عدة مستندات وإنشاء المستندات فنفِّذهما بمزوّد الجلسة.

> **تلميح**
>
> إذا لم يُعثَر على أي مزوّد، فثبِّت Claude Code أو Codex، أو سجِّل مفتاح API. أعِد فتح [إعدادات الذكاء الاصطناعي…] ليتم اكتشافه.
