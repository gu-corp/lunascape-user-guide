# تسليم العمل إلى الذكاء الاصطناعي

لا يستدعي Lunascape Docs أي نموذج لغوي. فهو يهيّئ **السياق والأدوات والفحص**، ويترك تنفيذ الترجمة والتدقيق والكتابة للذكاء الاصطناعي الذي تستخدمه.

## الفكرة

| ما يوفّره المنتج | المحتوى |
|---|---|
| السياق | أعراف التوثيق (مكان النسخ المترجمة، وfront matter، ومعيار المستندات، ومسرد المصطلحات) وموضع المستند المقصود |
| أدوات العمل | سجل الترجمات المفقودة وغير المحدّثة، وقراءة المستندات وكتابتها، والإنشاء من قالب |
| الفحص اللاحق | التحقق عبر docs-lint، وفرق التغطية والحداثة |

لا تتضمّن التعليمات نصّ المستند؛ فالذكاء الاصطناعي يقرأ الملفات بنفسه، ويكتبها بنفسه، ويتحقق منها بنفسه.

## تسليم العمل

1. اضغط [أدوات المستندات] في شريط الأدوات، ثم افتح علامة التبويب [AI].
2. اختر العمل الذي تريد تسليمه من [المهمة].
3. أدخل العناصر المطلوبة (اللغة الهدف، الموضوع).
4. اضغط [سلّم هذه المهمة].
   تُفتح طرفية VS Code، ويتلقّى الذكاء الاصطناعي الذي اخترته التعليمات ويبدأ العمل.

> **تلميح**
>
> ترافق جلسةَ Claude Code أدواتُ عمل (خادم MCP باسم `lunascape-docs`). ويمكن للجلسة أن تجلب قائمة الترجمات المفقودة وغير المحدّثة، وتشغّل docs-lint، وتسجّل الحداثة بعد الترجمة بنفسها.

## التحقق من النتيجة

| شكل المزوّد | مكان وصول النتيجة |
|---|---|
| جلسة (Claude Code، Codex) | يكتب مباشرةً في شجرة العمل. **تحقّق منه في فرق Git** |
| واجهة برمجية (نماذج VS Code اللغوية، Anthropic، المتوافقة مع OpenAI) | يعيد اقتراحًا لمستند واحد في كل مرة. تحقّق منه عبر [فتح الفرق]، ثم اكتبه عبر [حفظ] |

### التحقق من اقتراح الواجهة البرمجية

عند التشغيل بمزوّد واجهة برمجية، يصل الاقتراح إلى علامة التبويب [AI].

1. اضغط [فتح الفرق] وقارن الاقتراح بالمحتوى الحالي.
2. إذا كان مناسبًا فاضغط [حفظ]. وفي حالة الترجمة تُسجَّل الحداثة أيضًا. وللتراجع اضغط [تجاهل].
   ولإيقاف التوليد في منتصفه اضغط [إيقاف].

> **ملاحظة**
>
> - لا يقوم Lunascape Docs بتجهيز التغييرات في Git أو إيداعها إطلاقًا. تحقّق من التغييرات في الفرق دائمًا.
> - لا يمكن تسليم العمل في مساحة عمل غير موثوقة، ولا أثناء عرض مجلد مؤقت خارج جذر التوثيق.
