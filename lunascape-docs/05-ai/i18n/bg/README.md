# Възлагане на работа на AI

Lunascape Docs не извиква езиков модел. Той подготвя **контекст, инструменти и проверки**, а превеждането, редактирането и създаването остават за AI, който използвате.

## Идеята

| Какво осигурява продуктът | Съдържание |
|---|---|
| Контекст | Правилата на документацията (къде се намират преводите, front matter, стандартът за документи, речникът) и мястото на целевия документ |
| Работни инструменти | Регистърът на липсващите и остарелите преводи, четене и запис на документи, създаване от шаблон |
| Последващи проверки | Проверка с docs-lint, разликата в обхвата и актуалността |

Указанието не съдържа текста на документа: AI сам чете файловете, сам ги записва и сам ги проверява.

## Възлагане на работа

1. Натиснете [Инструменти за документи] в лентата с инструменти и отворете раздела [AI].
2. От [Задача] изберете работата, която искате да възложите.
3. Попълнете необходимите полета (целеви език, тема).
4. Натиснете [Възложи тази задача].
   Отваря се терминал на VS Code и избраният AI получава указанието и започва работа.

> **Съвет**
>
> Сесията на Claude Code се придружава от работни инструменти (MCP сървърът `lunascape-docs`). Сесията може сама да получи списъка с липсващи и остарели преводи, да изпълни docs-lint и да запише актуалността след превода.

## Проверка на резултата

| Вид доставчик | Къде се появява резултатът |
|---|---|
| Сесиен (Claude Code, Codex) | Записва направо в работното дърво. **Проверете в разликата на Git** |
| API (езиковите модели на VS Code, Anthropic, съвместими с OpenAI) | Връща предложение по един документ. Проверете с [Отваряне на разликата] и запишете със [Запазване] |

### Проверка на предложение от API

При изпълнение с доставчик от вид API предложението пристига в раздела [AI].

1. Натиснете [Отваряне на разликата] и сравнете с текущото съдържание.
2. Ако всичко е наред, натиснете [Запазване]. При превод се записва и актуалността. За да се откажете, натиснете [Отхвърляне].
   За да прекъснете генерирането, натиснете [Спиране].

> **Забележка**
>
> - Lunascape Docs никога не добавя в индекса на Git и не прави подавания. Винаги проверявайте промените в разликата.
> - В ненадеждно работно пространство, както и при временно разглеждане на папка извън коренна папка на документацията, не можете да възлагате работа.
