# Настройки на AI

Изберете AI и модела, на които възлагате работата. Не се използва бързият избор на VS Code — изборът става от падащите менюта на този екран.

1. Натиснете [Инструменти за документи] → раздел [AI] → [Настройки на AI…].
2. Изберете [Доставчик].
   Тези, които не могат да се използват в тази среда, се показват като недостъпни за избор, с посочена причина.
3. Изберете [Модел]. Възможностите за избор се променят според доставчика.
4. Затворете екрана. Изборът се запазва за всеки потребител и се използва и следващия път.

## Доставчици

| Доставчик | Вид | Начин на откриване |
|---|---|---|
| Claude Code | Сесиен | Наличие на командата `claude` |
| Codex | Сесиен | Наличие на командата `codex` |
| Езикови модели на VS Code | API | Модели, регистрирани във VS Code Language Model API |
| Anthropic API | API | Регистриран API ключ |
| API, съвместим с OpenAI | API | Регистриран API ключ и адрес |

**Сесийният** вид сам чете и записва файловете и сам изпълнява проверката на документите. Резултатите се записват направо в работното дърво и се преглеждат в разликите на Git.

**API** видът връща Markdown за един документ, а разширението показва разликите, преди да запази.

## Регистриране на API ключ

Anthropic API и API, съвместим с OpenAI, стават използваеми, след като се регистрира API ключ.

1. Изберете доставчика в [Доставчик]. Показва се поле за въвеждане на API ключ.
2. Въведете [API ключ]. При API, съвместим с OpenAI, въведете и [Адрес] (например `https://api.openai.com/v1`).
3. Натиснете [Запазване]. Показва се „Ключът е регистриран“.

> **Забележка**
>
> - Ключът се съхранява в SecretStorage на VS Code и не се показва повторно. Той не се записва нито в `settings.json`, нито в документ. Можете да го изтриете с [Изтриване на ключа].
> - Списъкът с модели се получава от всяка услуга с регистрирания ключ. Докато това не стане, се показва известен списък.
> - С API вида могат да се изпълняват само „Превод на тази страница“ и „Коректура на тази страница“. Обхождането на няколко документа и създаването на документи изпълнявайте със сесийния вид.

> **Съвет**
>
> Ако не бъде открит нито един доставчик, инсталирайте Claude Code или Codex, или регистрирайте API ключ. Отворете отново [Настройки на AI…] и той ще бъде открит.
