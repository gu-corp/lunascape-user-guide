# 대장과 기록

[AI] 탭 상단의 대장은 지원 언어별 번역 상태입니다. AI를 사용하지 않아도 무엇이 부족한지 확인할 수 있습니다.

| 표시 | 의미 |
|---|---|
| 미번역 | 번역본이 아직 없는 문서 수 |
| 갱신 필요 | 번역본은 있지만 기록한 시점보다 정본이 더 새로운 문서 수 |
| 번역 완료 | 정본을 따라가고 있는 번역본 수 |

대장은 문서 루트를 훑어서 산출합니다. AI도 언어 모델도 관여하지 않습니다.

## 번역 기록 갱신하기

"갱신 필요"를 판정하려면 번역한 시점의 정본과 번역본을 기록해 두어야 합니다. 세션형 AI는 파일을 직접 쓰기 때문에 기록이 자동으로 만들어지지 않습니다.

1. 번역이 끝나고 내용을 확인했으면 [번역 기록 갱신]을 누릅니다.
2. 기록이 없는 번역본이 현재 정본에 대응하는 것으로 기록됩니다.

Claude Code의 세션과 API형 저장은 기록을 자동으로 남깁니다(세션에는 MCP 도구 `record_translation_freshness`를 사용하도록 지시됩니다). 이 버튼이 필요한 경우는 Codex나 VS Code 채팅으로 번역했을 때입니다.

이후 정본을 변경하면 해당 번역본은 "갱신 필요"로 표시됩니다.

> **참고**
>
> - 이미 기록이 있는 번역본은 덮어쓰지 않습니다. "갱신 필요" 상태를 지워 버리지 않기 위해서입니다.
> - 기록은 `.lunascape-docs/translation-freshness.json`에 저장됩니다. 저장되는 것은 상대 경로, 언어, 내용의 해시, 일시뿐이며 본문은 포함하지 않습니다.
