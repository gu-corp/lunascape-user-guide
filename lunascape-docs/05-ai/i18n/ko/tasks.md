# 맡길 수 있는 작업

[AI] 탭의 [작업]에서 선택합니다. 작업마다 전달하는 지시와 사후 검사가 달라집니다.

| 작업 | 내용 | 필요한 것 | API 형 |
|---|---|---|---|
| 이 페이지 번역 | 표시 중인 문서를 선택한 언어로 번역합니다 | 대상 문서를 열어 둘 것, 대상 언어 | ○ |
| 미번역 일괄 번역 | 선택한 언어의 미번역 및 갱신 필요 문서를 차례로 번역합니다 | 대상 언어 | 세션형만 |
| 이 페이지 교정 | 용어, 문체 및 문서 표준이 요구하는 장 구성을 확인하고 수정합니다 | 대상 문서를 열어 둘 것 | ○ |
| 새 문서 작성 | 문서 표준과 템플릿에 따라 새 문서를 작성합니다 | 주제(생략 가능) | 세션형만 |

## 지시에 포함되는 것

| 항번 | 내용 |
|---|---|
| 1 | 문서 루트의 위치. 그 밖은 변경하지 않도록 지시합니다 |
| 2 | 기본 언어(정본)와 번역본을 두는 위치(문서와 같은 폴더의 `i18n/<언어>/`) |
| 3 | `navigation.order`는 정본만 가진다는 것, 번역본이 덮어써도 되는 것은 `navigation.title`뿐이라는 것 |
| 4 | 요건 ID, 링크, 코드, Mermaid, TeX, front matter의 구조를 변경하지 않을 것 |
| 5 | 문서 표준과 용어집(`docs-lint.config.json`의 `terminology`) |
| 6 | 끝나면 문서 검사를 실행하고, 변경한 파일을 보고하며, Git 조작은 하지 않을 것 |

> **힌트**
>
> "미번역 일괄 번역"의 대상은 대장에서 만들어지며, 1회당 200개 문서까지입니다. 많을 경우에는 반복해서 실행하십시오.
