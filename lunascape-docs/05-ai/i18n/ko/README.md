# AI에 작업 맡기기

Lunascape Docs는 언어 모델을 호출하지 않습니다. **문맥과 도구와 검증**을 준비하고, 번역·교정·작성의 실행은 사용 중인 AI에 맡깁니다.

## 사고방식

| 제품이 준비하는 것 | 내용 |
|---|---|
| 컨텍스트 | 문서의 규약(번역판을 두는 위치, front matter, 문서 표준, 용어집)과 대상 문서의 위치 |
| 작업 도구 | 미번역·갱신 필요 대장, 문서 읽기와 쓰기, 템플릿에서 만들기 |
| 사후 검사 | docs-lint에 의한 검증, 망라 상황과 최신성의 차이 |

지시문에는 문서의 본문을 포함하지 않습니다. AI가 스스로 파일을 읽고, 스스로 쓰고, 스스로 검증합니다.

## 작업 맡기기

1. 도구 모음에서 [문서 도구]를 누르고 [AI] 탭을 엽니다.
2. [작업]에서 맡길 작업을 선택합니다.
3. 필요한 항목(대상 언어, 주제)을 입력합니다.
4. [이 작업 맡기기]를 누릅니다.
   VS Code의 터미널이 열리고, 선택한 AI가 지시를 받아 작업을 시작합니다.

> **힌트**
>
> Claude Code 세션에는 작업 도구(MCP 서버 `lunascape-docs`)가 함께합니다. 세션은 미번역·갱신 필요 목록 가져오기, docs-lint 실행, 번역 후 최신성 기록을 스스로 할 수 있습니다.

## 결과 확인

| 공급자의 형태 | 결과가 도착하는 곳 |
|---|---|
| 세션형(Claude Code, Codex) | 작업 트리에 직접 씁니다. **Git 차이로 확인**하십시오 |
| API형(VS Code의 언어 모델, Anthropic, OpenAI 호환) | 문서 하나씩 제안을 돌려줍니다. [차이 열기]로 확인하고 [저장]으로 씁니다 |

### API형의 제안 확인하기

API형으로 실행하면 [AI] 탭에 제안이 도착합니다.

1. [차이 열기]를 누르고 현재 내용과의 차이를 확인합니다.
2. 괜찮으면 [저장]을 누릅니다. 번역인 경우 최신성도 기록됩니다. 그만둘 때는 [버리기]를 누릅니다.
   생성을 도중에 그만두려면 [중지]를 누릅니다.

> **참고**
>
> - Lunascape Docs가 Git의 스테이지나 커밋을 하는 일은 없습니다. 변경은 반드시 차이로 확인하십시오.
> - 신뢰하지 않는 작업 영역, 그리고 문서 루트 밖의 일시적인 폴더 표시에서는 작업을 맡길 수 없습니다.
