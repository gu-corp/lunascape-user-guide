# AI 설정

작업을 맡길 AI와 모델을 선택합니다. VS Code의 빠른 선택은 사용하지 않고, 이 화면의 드롭다운에서 선택합니다.

1. [문서 도구] → [AI] 탭 → [AI 설정…]을 누릅니다.
2. [공급자]를 선택합니다.
   이 환경에서 사용할 수 없는 항목은 이유와 함께 선택할 수 없는 상태로 표시됩니다.
3. [모델]을 선택합니다. 선택지는 공급자마다 다릅니다.
4. 화면을 닫습니다. 선택 내용은 사용자별로 저장되어 다음에도 사용됩니다.

## 공급자

| 공급자 | 형태 | 검출 방법 |
|---|---|---|
| Claude Code | 세션형 | `claude` 명령의 유무 |
| Codex | 세션형 | `codex` 명령의 유무 |
| VS Code의 언어 모델 | API형 | VS Code Language Model API에 등록된 모델 |
| Anthropic API | API형 | API 키 등록 |
| OpenAI 호환 API | API형 | API 키와 엔드포인트 등록 |

**세션형**은 스스로 파일을 읽고 쓰며, 문서 검사도 직접 실행합니다. 결과는 작업 트리에 직접 기록되며, Git의 차이로 확인합니다.

**API형**은 문서 한 개 분량의 Markdown을 반환하고, 확장 기능이 차이를 보여준 다음 저장합니다.

## API 키 등록하기

Anthropic API와 OpenAI 호환 API는 API 키를 등록하면 사용할 수 있습니다.

1. [공급자]에서 등록할 대상을 선택합니다. API 키 입력란이 표시됩니다.
2. [API 키]를 입력합니다. OpenAI 호환의 경우에는 [엔드포인트](예: `https://api.openai.com/v1`)도 입력합니다.
3. [저장]을 누릅니다. "키 등록됨"이라고 표시됩니다.

> **참고**
>
> - 키는 VS Code의 SecretStorage에 저장되며 다시 표시되지 않습니다. `settings.json`이나 문서에 기록되는 일도 없습니다. [키 삭제]로 삭제할 수 있습니다.
> - 모델 목록은 등록한 키로 각 서비스에서 가져옵니다. 가져오지 못하는 동안에는 알려진 목록을 표시합니다.
> - API형으로 실행할 수 있는 작업은 "이 페이지 번역"과 "이 페이지 교정"뿐입니다. 여러 문서를 순회하거나 문서를 작성하는 작업은 세션형으로 실행하세요.

> **힌트**
>
> 어떤 공급자도 찾을 수 없는 경우에는 Claude Code나 Codex를 설치하거나 API 키를 등록하세요. [AI 설정…]을 다시 열면 검출됩니다.
