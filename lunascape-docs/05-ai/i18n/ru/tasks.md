# Доступные задачи

Выберите задачу в поле [Задача] на вкладке [AI]. Для каждой задачи меняются передаваемые указания и последующая проверка.

| Задача | Содержание | Что требуется | Тип API |
|---|---|---|---|
| Перевести эту страницу | Переводит открытый документ на выбранный язык | Открытый документ, целевой язык | ○ |
| Перевести всё непереведённое | По очереди переводит документы выбранного языка, для которых нет перевода или которые устарели | Целевой язык | Только сеансовый |
| Вычитать эту страницу | Проверяет и исправляет термины, стиль и разделы, которых требует стандарт документа | Открытый документ | ○ |
| Создать новый документ | Создаёт новый документ по стандарту документа и шаблонам | Тема (необязательно) | Только сеансовый |

## Что входит в указания

| № | Содержание |
|---|---|
| 1 | Расположение корня документации. Указание не изменять ничего за его пределами |
| 2 | Язык по умолчанию (исходный документ) и место хранения переводов (папка `i18n/<язык>/` рядом с документом) |
| 3 | Что `navigation.order` есть только у исходного документа, а перевод может переопределять только `navigation.title` |
| 4 | Что идентификаторы требований, ссылки, код, Mermaid, TeX и структуру front matter изменять нельзя |
| 5 | Стандарт документа и глоссарий (`terminology` в `docs-lint.config.json`) |
| 6 | По завершении выполнить проверку документа, сообщить об изменённых файлах и не выполнять операции Git |

> **Совет**
>
> Список для задачи «Перевести всё непереведённое» составляется по реестру, не более 200 документов за один раз. Если документов больше, выполните задачу повторно.
