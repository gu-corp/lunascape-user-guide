# Передача работы ИИ

Lunascape Docs не вызывает языковую модель. Он готовит **контекст, инструменты и проверки**, а перевод, вычитку и создание текста оставляет тому ИИ, которым вы уже пользуетесь.

## Как это устроено

| Что предоставляет продукт | Содержание |
|---|---|
| Контекст | Соглашения документации (где лежат переводы, front matter, стандарт документа, глоссарий) и расположение нужного документа |
| Рабочие инструменты | Реестр документов без перевода и устаревших, чтение и запись документов, создание по шаблону |
| Проверки | Проверка docs-lint, разница в полноте и актуальности |

Текст документа в указание не входит: ИИ сам читает файлы, сам пишет и сам проверяет.

## Передача работы

1. Нажмите [Инструменты документа] на панели инструментов и откройте вкладку [AI].
2. В поле [Задача] выберите работу, которую хотите передать.
3. Заполните нужные поля (язык перевода, тема).
4. Нажмите [Передать эту работу].
   Откроется терминал VS Code, и выбранный ИИ получит указание и начнет работу.

> **Совет**
>
> Сеанс Claude Code сопровождают рабочие инструменты (сервер MCP `lunascape-docs`). Сеанс может сам получить список документов без перевода и устаревших, запустить docs-lint и записать актуальность после перевода.

## Проверка результата

| Тип поставщика | Куда попадает результат |
|---|---|
| Сеансовый (Claude Code, Codex) | Пишет прямо в рабочее дерево. **Проверяйте по различиям в Git** |
| API (языковые модели VS Code, Anthropic, совместимые с OpenAI) | Возвращает предложение по одному документу. Проверьте его через [Открыть различия] и запишите кнопкой [Сохранить] |

### Проверка предложения от API

При запуске через API предложение приходит на вкладку [AI].

1. Нажмите [Открыть различия] и сравните с текущим содержимым.
2. Если все верно, нажмите [Сохранить]. Для перевода также записывается актуальность. Чтобы отказаться, нажмите [Отклонить].
   Чтобы прервать создание, нажмите [Остановить].

> **Примечание**
>
> - Lunascape Docs никогда не выполняет в Git индексирование и фиксацию. Обязательно проверяйте изменения по различиям.
> - В ненадежной рабочей области, а также при временном просмотре папки вне корня документации передать работу нельзя.
