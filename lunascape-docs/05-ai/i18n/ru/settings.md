# Настройки AI

Выберите AI и модель, которым передается работа. Здесь используются раскрывающиеся списки этого экрана, а не быстрый выбор VS Code.

1. Нажмите [Инструменты документа] → вкладка [AI] → [Настройки AI…].
2. Выберите [Поставщик].
   Недоступные в этой среде отображаются как невыбираемые, с указанием причины.
3. Выберите [Модель]. Набор вариантов зависит от поставщика.
4. Закройте экран. Выбор сохраняется для каждого пользователя и используется в следующий раз.

## Поставщики

| Поставщик | Тип | Способ обнаружения |
|---|---|---|
| Claude Code | Сеансовый | Наличие команды `claude` |
| Codex | Сеансовый | Наличие команды `codex` |
| Языковые модели VS Code | API | Модели, зарегистрированные в VS Code Language Model API |
| Anthropic API | API | Зарегистрированный ключ API |
| API, совместимый с OpenAI | API | Зарегистрированные ключ API и конечная точка |

**Сеансовый** поставщик сам читает и записывает файлы и сам выполняет проверку документа. Результат записывается прямо в рабочее дерево и просматривается в различиях Git.

**Поставщик API** возвращает Markdown одного документа, а расширение показывает различия перед сохранением.

## Регистрация ключа API

Anthropic API и API, совместимые с OpenAI, становятся доступны после регистрации ключа API.

1. Выберите нужного поставщика в поле [Поставщик]. Появится поле для ввода ключа API.
2. Введите [Ключ API]. Для API, совместимого с OpenAI, введите также [Конечная точка] (например, `https://api.openai.com/v1`).
3. Нажмите [Сохранить]. Появится надпись «Ключ зарегистрирован».

> **Примечание**
>
> - Ключ хранится в SecretStorage VS Code и больше не отображается. Он не записывается ни в `settings.json`, ни в документы. Удалить его можно кнопкой [Удалить ключ].
> - Список моделей запрашивается у каждой службы с помощью зарегистрированного ключа. Пока получить его не удается, отображается известный список.
> - Поставщик API может выполнить только «Перевести эту страницу» и «Вычитать эту страницу». Обход нескольких документов и создание документов выполняйте с сеансовым поставщиком.

> **Совет**
>
> Если не найден ни один поставщик, установите Claude Code или Codex либо зарегистрируйте ключ API. Откройте [Настройки AI…] заново — поставщик будет обнаружен.
