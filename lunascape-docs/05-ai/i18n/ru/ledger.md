# Реестр и записи

Реестр в верхней части вкладки [ИИ] показывает состояние перевода для каждого поддерживаемого языка. Он полезен и без ИИ: он показывает, чего не хватает.

| Отображение | Значение |
|---|---|
| Нет перевода | Количество документов, для которых перевода еще нет |
| Устарел | Количество документов, перевод которых существует, но исходный документ новее момента записи |
| Переведено | Количество переводов, которые соответствуют исходному документу |

Реестр вычисляется обходом корня документации. Ни ИИ, ни языковая модель в этом не участвуют.

## Обновление записей о переводе

Чтобы определить состояние «устарел», нужна запись об исходном документе и переводе на момент перевода. Сеансовый ИИ пишет файлы напрямую, поэтому запись не создается автоматически.

1. Когда перевод готов и вы проверили содержание, нажмите [Обновить записи о переводе].
2. Переводы без записи будут записаны как соответствующие текущему исходному документу.

Сеансы Claude Code и сохранение через API-провайдера выполняют запись автоматически (сеансу дается указание использовать инструмент MCP `record_translation_freshness`). Эта кнопка нужна, если вы переводили в Codex или в чате VS Code.

После этого при изменении исходного документа его перевод отображается как «устарел».

> **Примечание**
>
> - Переводы, для которых запись уже есть, не перезаписываются. Это сделано для того, чтобы не стереть состояние «устарел».
> - Записи хранятся в `.lunascape-docs/translation-freshness.json`. Сохраняются только относительные пути, языки, хеши содержания и дата со временем; текст документа не сохраняется.
