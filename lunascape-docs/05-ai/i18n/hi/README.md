# AI को काम सौंपना

Lunascape Docs भाषा मॉडल को नहीं बुलाता। यह **संदर्भ, उपकरण और जाँच** तैयार करता है, और अनुवाद, प्रूफ़रीडिंग तथा लेखन का काम आपके अपने AI पर छोड़ देता है।

## सोच

| उत्पाद जो तैयार करता है | विषय-वस्तु |
|---|---|
| संदर्भ | दस्तावेज़ के नियम (अनुवादों का स्थान, front matter, दस्तावेज़ मानक, शब्दावली) और लक्ष्य दस्तावेज़ की स्थिति |
| कार्य उपकरण | अननुवादित और अद्यतन आवश्यक का रजिस्टर, दस्तावेज़ों को पढ़ना और लिखना, टेम्पलेट से निर्माण |
| बाद की जाँच | docs-lint द्वारा सत्यापन, व्याप्ति और ताज़गी का अंतर |

निर्देश में दस्तावेज़ का मूल पाठ शामिल नहीं होता। AI स्वयं फ़ाइलें पढ़ता है, स्वयं लिखता है और स्वयं सत्यापित करता है।

## काम सौंपना

1. टूलबार में [दस्तावेज़ उपकरण] दबाएँ और [AI] टैब खोलें।
2. [कार्य] से वह काम चुनें जो आप सौंपना चाहते हैं।
3. आवश्यक जानकारी (लक्ष्य भाषा, विषय) भरें।
4. [यह काम सौंपें] दबाएँ।
   VS Code का टर्मिनल खुलता है और चुना हुआ AI निर्देश लेकर काम शुरू कर देता है।

> **संकेत**
>
> Claude Code के सत्र के साथ कार्य उपकरण (MCP सर्वर `lunascape-docs`) भी चलते हैं। सत्र स्वयं अननुवादित और अद्यतन आवश्यक की सूची प्राप्त कर सकता है, docs-lint चला सकता है, और अनुवाद के बाद ताज़गी दर्ज कर सकता है।

## परिणाम की जाँच

| प्रदाता का स्वरूप | परिणाम कहाँ पहुँचता है |
|---|---|
| सत्र प्रकार (Claude Code, Codex) | कार्य ट्री में सीधे लिखता है। **Git के अंतर में जाँचें** |
| API प्रकार (VS Code के भाषा मॉडल, Anthropic, OpenAI-संगत) | एक-एक दस्तावेज़ का सुझाव लौटाता है। [अंतर खोलें] से जाँचें और [सहेजें] से लिखें |

### API प्रकार के सुझाव की जाँच

API प्रकार से चलाने पर [AI] टैब में सुझाव पहुँचता है।

1. [अंतर खोलें] दबाएँ और वर्तमान विषय-वस्तु से अंतर देखें।
2. ठीक लगे तो [सहेजें] दबाएँ। अनुवाद की स्थिति में ताज़गी भी दर्ज होती है। रहने देना हो तो [त्यागें] दबाएँ।
   निर्माण को बीच में रोकने के लिए [रोकें] दबाएँ।

> **ध्यान दें**
>
> - Lunascape Docs कभी Git में स्टेज या कमिट नहीं करता। परिवर्तनों को अवश्य अंतर में जाँचें।
> - विश्वसनीय न माने गए कार्यस्थान में, तथा दस्तावेज़ रूट के बाहर के किसी अस्थायी फ़ोल्डर के प्रदर्शन में, काम नहीं सौंपा जा सकता।
