# AI सेटिंग्स

काम सौंपने के लिए AI और मॉडल चुनें। VS Code की क्विक पिक का उपयोग नहीं होता; इसी स्क्रीन के ड्रॉप-डाउन से चुनें।

1. [दस्तावेज़ उपकरण] → [AI] टैब → [AI सेटिंग्स…] दबाएँ।
2. [प्रदाता] चुनें।
   इस परिवेश में जो उपलब्ध नहीं हैं, वे कारण सहित अचयनीय अवस्था में दिखते हैं।
3. [मॉडल] चुनें। विकल्प प्रत्येक प्रदाता के अनुसार बदलते हैं।
4. स्क्रीन बंद करें। चयन प्रति उपयोगकर्ता सहेजा जाता है और अगली बार भी उपयोग होता है।

## प्रदाता

| प्रदाता | स्वरूप | पहचान का तरीका |
|---|---|---|
| Claude Code | सत्र-प्रकार | `claude` कमांड की उपस्थिति |
| Codex | सत्र-प्रकार | `codex` कमांड की उपस्थिति |
| VS Code के भाषा मॉडल | API-प्रकार | VS Code Language Model API में पंजीकृत मॉडल |
| Anthropic API | API-प्रकार | API कुंजी का पंजीकरण |
| OpenAI-संगत API | API-प्रकार | API कुंजी और एंडपॉइंट का पंजीकरण |

**सत्र-प्रकार** स्वयं फ़ाइलें पढ़ता-लिखता है और दस्तावेज़ की जाँच भी स्वयं चलाता है। परिणाम सीधे कार्य वृक्ष में लिखे जाते हैं और Git के अंतर में देखे जाते हैं।

**API-प्रकार** एक दस्तावेज़ जितना Markdown लौटाता है, और एक्सटेंशन अंतर दिखाने के बाद सहेजता है।

## API कुंजी पंजीकृत करना

Anthropic API और OpenAI-संगत API, API कुंजी पंजीकृत करने पर उपयोग में आते हैं।

1. [प्रदाता] में पंजीकरण का लक्ष्य चुनें। API कुंजी का प्रविष्टि क्षेत्र दिखाई देता है।
2. [API कुंजी] दर्ज करें। OpenAI-संगत की स्थिति में [एंडपॉइंट] (उदाहरण: `https://api.openai.com/v1`) भी दर्ज करें।
3. [सहेजें] दबाएँ। "कुंजी पंजीकृत" दिखाई देता है।

> **ध्यान दें**
>
> - कुंजी VS Code के SecretStorage में सहेजी जाती है और दोबारा नहीं दिखाई जाती। वह `settings.json` या किसी दस्तावेज़ में भी नहीं लिखी जाती। [कुंजी हटाएँ] से उसे हटाया जा सकता है।
> - मॉडलों की सूची पंजीकृत कुंजी से प्रत्येक सेवा से प्राप्त की जाती है। जब तक वह प्राप्त न हो, ज्ञात सूची दिखाई जाती है।
> - API-प्रकार से केवल "इस पृष्ठ का अनुवाद करें" और "इस पृष्ठ का प्रूफ़ पढ़ें" ही चलाए जा सकते हैं। कई दस्तावेज़ों का भ्रमण और दस्तावेज़ बनाना सत्र-प्रकार से चलाएँ।

> **संकेत**
>
> यदि कोई भी प्रदाता न मिले, तो Claude Code या Codex स्थापित करें, या API कुंजी पंजीकृत करें। [AI सेटिंग्स…] दोबारा खोलने पर वह पहचान लिया जाता है।
