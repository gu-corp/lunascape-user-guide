# سپردن کار به هوش مصنوعی

Lunascape Docs مدل زبانی را فراخوانی نمی‌کند. **زمینه، ابزار و وارسی** را آماده می‌کند و انجام ترجمه، نمونه‌خوانی و نوشتن را به هوش مصنوعی شما می‌سپارد.

## رویکرد

| آنچه محصول فراهم می‌کند | محتوا |
|---|---|
| زمینه | قواعد سند (جای نسخه‌های ترجمه‌شده، front matter، استاندارد سند، واژه‌نامه) و جای سند مورد نظر |
| ابزارهای کار | دفتر ثبت ترجمه‌نشده‌ها و نیازمند به‌روزرسانی‌ها، خواندن و نوشتن سندها، ساخت از الگو |
| بررسی پس از کار | وارسی با docs-lint، تفاوت پوشش و تازگی |

در متن دستور، متن سند گنجانده نمی‌شود. هوش مصنوعی خودش پرونده‌ها را می‌خواند، خودش می‌نویسد و خودش وارسی می‌کند.

## سپردن کار

1. در نوار ابزار [ابزارهای سند] را بزنید و زبانهٔ [AI] را باز کنید.
2. از [کار]، کاری را که می‌خواهید بسپارید برگزینید.
3. موارد لازم (زبان مقصد، موضوع) را وارد کنید.
4. [سپردن این کار] را بزنید.
   ترمینال VS Code باز می‌شود و هوش مصنوعیِ انتخاب‌شده دستور را می‌گیرد و کار را آغاز می‌کند.

> **نکته**
>
> نشست Claude Code با ابزارهای کار (سرور MCP `lunascape-docs`) همراه است. نشست می‌تواند خودش فهرست ترجمه‌نشده‌ها و نیازمند به‌روزرسانی‌ها را بگیرد، docs-lint را اجرا کند و تازگی را پس از ترجمه ثبت کند.

## بررسی نتیجه

| شکل ارائه‌دهنده | نتیجه کجا می‌نشیند |
|---|---|
| نشستی (Claude Code، Codex) | مستقیم در درخت کاری می‌نویسد. **در تفاوت‌های Git بررسی کنید** |
| API (مدل‌های زبانی VS Code، Anthropic، سازگار با OpenAI) | هر بار پیشنهاد یک سند را برمی‌گرداند. با [باز کردن تفاوت‌ها] بررسی کنید و با [ذخیره] بنویسید |

### بررسی پیشنهاد نوع API

با اجرای نوع API، پیشنهاد در زبانهٔ [AI] می‌رسد.

1. [باز کردن تفاوت‌ها] را بزنید و تفاوت آن را با محتوای کنونی ببینید.
2. اگر خوب بود، [ذخیره] را بزنید. در مورد ترجمه، تازگی هم ثبت می‌شود. برای صرف‌نظر، [دور انداختن] را بزنید.
   برای توقف تولید در میانهٔ کار، [توقف] را بزنید.

> **توجه**
>
> - Lunascape Docs هرگز در Git چیزی را stage یا commit نمی‌کند. تغییرها را حتماً در تفاوت‌ها بررسی کنید.
> - در فضای کاری‌ای که مورد اعتماد نیست و نیز هنگام نمایش موقت پوشه‌ای بیرون از ریشهٔ مستندات، نمی‌توان کاری را سپرد.
