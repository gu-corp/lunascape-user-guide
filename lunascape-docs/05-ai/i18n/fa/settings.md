# تنظیمات هوش مصنوعی

هوش مصنوعی و مدلی را که کار به آن سپرده می‌شود انتخاب کنید. از انتخابگر سریع VS Code استفاده نمی‌شود؛ انتخاب با فهرست‌های کشویی همین صفحه انجام می‌شود.

1. [ابزارهای سند] ← زبانهٔ [هوش مصنوعی] ← [تنظیمات هوش مصنوعی…] را فشار دهید.
2. [ارائه‌دهنده] را انتخاب کنید.
   مواردی که در این محیط قابل استفاده نیستند، همراه با دلیل و به‌صورت غیرقابل‌انتخاب نمایش داده می‌شوند.
3. [مدل] را انتخاب کنید. گزینه‌ها برای هر ارائه‌دهنده متفاوت است.
4. صفحه را ببندید. انتخاب برای هر کاربر ذخیره می‌شود و دفعهٔ بعد نیز به کار می‌رود.

## ارائه‌دهندگان

| ارائه‌دهنده | نوع | روش تشخیص |
|---|---|---|
| Claude Code | نشستی | وجود فرمان `claude` |
| Codex | نشستی | وجود فرمان `codex` |
| مدل‌های زبانی VS Code | API | مدل‌های ثبت‌شده در VS Code Language Model API |
| Anthropic API | API | ثبت کلید API |
| API سازگار با OpenAI | API | ثبت کلید API و نقطهٔ پایانی |

نوع **نشستی** خودش فایل‌ها را می‌خواند و می‌نویسد و بررسی سند را نیز خودش اجرا می‌کند. نتیجه مستقیماً در درخت کاری نوشته می‌شود و با تفاوت‌های Git بررسی می‌شود.

نوع **API** به اندازهٔ یک سند Markdown برمی‌گرداند و افزونه پیش از ذخیره، تفاوت‌ها را نشان می‌دهد.

## ثبت کلید API

Anthropic API و API سازگار با OpenAI با ثبت کلید API قابل استفاده می‌شوند.

1. در [ارائه‌دهنده] مقصد ثبت را انتخاب کنید. کادر ورود کلید API نمایش داده می‌شود.
2. [کلید API] را وارد کنید. در حالت سازگار با OpenAI، [نقطهٔ پایانی] (مثلاً `https://api.openai.com/v1`) را نیز وارد کنید.
3. [ذخیره] را فشار دهید. پیام «کلید ثبت شد» نمایش داده می‌شود.

> **توجه**
>
> - کلید در SecretStorage مربوط به VS Code ذخیره می‌شود و دوباره نمایش داده نمی‌شود. در `settings.json` یا در سندها نیز نوشته نمی‌شود. با [حذف کلید] می‌توانید آن را حذف کنید.
> - فهرست مدل‌ها با کلید ثبت‌شده از هر سرویس دریافت می‌شود. تا زمانی که دریافت نشده است، فهرست شناخته‌شده نمایش داده می‌شود.
> - کارهایی که با نوع API می‌توان اجرا کرد فقط «ترجمهٔ این صفحه» و «نمونه‌خوانی این صفحه» است. پیمایش چند سند و ایجاد سند را با نوع نشستی اجرا کنید.

> **نکته**
>
> اگر هیچ ارائه‌دهنده‌ای پیدا نشد، Claude Code یا Codex را نصب کنید یا کلید API را ثبت کنید. با باز کردن دوبارهٔ [تنظیمات هوش مصنوعی…] تشخیص داده می‌شود.
