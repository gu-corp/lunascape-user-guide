# হস্তান্তরযোগ্য কাজ

[AI] ট্যাবের [কাজ] থেকে বেছে নিন। প্রতিটি কাজের জন্য হস্তান্তরিত নির্দেশনা এবং পরবর্তী পরীক্ষা আলাদা হয়।

| কাজ | বিষয়বস্তু | যা প্রয়োজন | API ধরন |
|---|---|---|---|
| এই পৃষ্ঠাটি অনুবাদ করুন | প্রদর্শিত নথিটি নির্বাচিত ভাষায় অনুবাদ করে | লক্ষ্য নথিটি খোলা থাকা, লক্ষ্য ভাষা | ○ |
| অনূদিত নয় এমন সব একসাথে অনুবাদ করুন | নির্বাচিত ভাষার অনূদিত নয় এবং হালনাগাদ প্রয়োজন নথিগুলি ক্রমানুসারে অনুবাদ করে | লক্ষ্য ভাষা | শুধু সেশন ধরন |
| এই পৃষ্ঠাটি সংশোধন করুন | পরিভাষা, রচনাশৈলী এবং নথির মান যে অধ্যায়বিন্যাস দাবি করে তা পরীক্ষা করে সংশোধন করে | লক্ষ্য নথিটি খোলা থাকা | ○ |
| নতুন নথি তৈরি করুন | নথির মান ও টেমপ্লেট অনুসরণ করে নতুন নথি তৈরি করে | বিষয় (ঐচ্ছিক) | শুধু সেশন ধরন |

## নির্দেশনায় যা থাকে

| ক্রমিক | বিষয়বস্তু |
|---|---|
| ১ | ডকুমেন্টেশন রুটের অবস্থান। এর বাইরে কিছু পরিবর্তন না করার নির্দেশ দেওয়া হয় |
| ২ | ডিফল্ট ভাষা (মূল নথি) এবং অনূদিত সংস্করণের স্থান (নথির একই ফোল্ডারের `i18n/<ভাষা>/`) |
| ৩ | `navigation.order` কেবল মূল নথিরই থাকে, এবং অনূদিত সংস্করণ কেবল `navigation.title` অগ্রাহ্য করে লিখতে পারে |
| ৪ | প্রয়োজনীয়তার ID, লিঙ্ক, কোড, Mermaid, TeX এবং front matter-এর গঠন পরিবর্তন না করা |
| ৫ | নথির মান এবং পরিভাষা তালিকা (`docs-lint.config.json`-এর `terminology`) |
| ৬ | শেষে নথি পরীক্ষা চালানো, পরিবর্তিত ফাইলগুলির প্রতিবেদন দেওয়া এবং কোনো Git কার্যক্রম না করা |

> **ইঙ্গিত**
>
> "অনূদিত নয় এমন সব একসাথে অনুবাদ করুন"-এর লক্ষ্য নথিগুলি খতিয়ান থেকে তৈরি হয় এবং প্রতিবারে সর্বাধিক ২০০টি নথি। বেশি হলে বারবার চালান।
