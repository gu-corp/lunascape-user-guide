# AI সেটিংস

যে AI এবং মডেলের কাছে কাজ পাঠানো হবে তা বেছে নিন। VS Code-এর কুইক পিক ব্যবহার না করে এই স্ক্রিনের ড্রপ-ডাউন থেকে বেছে নিন।

1. [নথি সরঞ্জাম] → [AI] ট্যাব → [AI সেটিংস…] চাপুন।
2. [প্রোভাইডার] বেছে নিন।
   এই পরিবেশে যেগুলি ব্যবহার করা যায় না, সেগুলি কারণ সহ নির্বাচন-অযোগ্য অবস্থায় দেখানো হয়।
3. [মডেল] বেছে নিন। প্রোভাইডার অনুযায়ী বিকল্পগুলি বদলায়।
4. স্ক্রিনটি বন্ধ করুন। নির্বাচনটি প্রতিটি ব্যবহারকারীর জন্য সংরক্ষিত হয় এবং পরের বারও ব্যবহৃত হয়।

## প্রোভাইডার

| প্রোভাইডার | ধরন | শনাক্তকরণের পদ্ধতি |
|---|---|---|
| Claude Code | সেশন-ভিত্তিক | `claude` কমান্ড আছে কি না |
| Codex | সেশন-ভিত্তিক | `codex` কমান্ড আছে কি না |
| VS Code-এর ভাষা মডেল | API-ভিত্তিক | VS Code Language Model API-তে নিবন্ধিত মডেল |
| Anthropic API | API-ভিত্তিক | API কী-এর নিবন্ধন |
| OpenAI-সঙ্গতিপূর্ণ API | API-ভিত্তিক | API কী ও এন্ডপয়েন্টের নিবন্ধন |

**সেশন-ভিত্তিক** প্রোভাইডার নিজেই ফাইল পড়ে ও লেখে এবং নথির পরীক্ষাও নিজেই চালায়। ফলাফল সরাসরি কাজের ট্রিতে লেখা হয় এবং Git-এর পার্থক্যে দেখে নেওয়া যায়।

**API-ভিত্তিক** প্রোভাইডার একটি নথির পরিমাণ Markdown ফেরত দেয়, আর এক্সটেনশন পার্থক্য দেখানোর পর সংরক্ষণ করে।

## API কী নিবন্ধন করা

Anthropic API এবং OpenAI-সঙ্গতিপূর্ণ API-তে API কী নিবন্ধন করলেই সেগুলি ব্যবহার করা যায়।

1. [প্রোভাইডার]-এ যেটির জন্য নিবন্ধন করবেন তা বেছে নিন। API কী লেখার ঘর দেখা যাবে।
2. [API কী] লিখুন। OpenAI-সঙ্গতিপূর্ণ হলে [এন্ডপয়েন্ট]ও (যেমন: `https://api.openai.com/v1`) লিখুন।
3. [সংরক্ষণ] চাপুন। «কী নিবন্ধিত» দেখানো হবে।

> **দ্রষ্টব্য**
>
> - কী VS Code-এর SecretStorage-এ সংরক্ষিত হয় এবং আর দেখানো হয় না। `settings.json`-এ বা কোনো নথিতেও লেখা হয় না। [কী মুছুন] দিয়ে মুছে ফেলা যায়।
> - মডেলের তালিকা নিবন্ধিত কী দিয়ে প্রতিটি পরিষেবা থেকে আনা হয়। যতক্ষণ তা আনা না যায়, ততক্ষণ পরিচিত একটি তালিকা দেখানো হয়।
> - API-ভিত্তিক প্রোভাইডার দিয়ে কেবল «এই পৃষ্ঠাটি অনুবাদ করুন» এবং «এই পৃষ্ঠাটি সংশোধন করুন» চালানো যায়। একাধিক নথি ঘুরে দেখা বা নথি তৈরি করা সেশন-ভিত্তিক প্রোভাইডার দিয়ে চালান।

> **পরামর্শ**
>
> কোনো প্রোভাইডারই খুঁজে পাওয়া না গেলে Claude Code বা Codex ইনস্টল করুন, অথবা API কী নিবন্ধন করুন। [AI সেটিংস…] আবার খুললে সেটি শনাক্ত হবে।
