# AI-কে কাজ হস্তান্তর করা

Lunascape Docs কোনও ভাষা মডেল ডাকে না। এটি **প্রসঙ্গ, সরঞ্জাম ও যাচাই** প্রস্তুত করে, আর অনুবাদ, সংশোধন ও রচনার কাজ আপনার ব্যবহৃত AI-এর হাতে ছেড়ে দেয়।

## ভাবনার ধরন

| পণ্য যা সরবরাহ করে | বিষয়বস্তু |
|---|---|
| প্রসঙ্গ | নথির নিয়মকানুন (অনূদিত সংস্করণ কোথায় রাখা হয়, front matter, নথির মান, পরিভাষা তালিকা) এবং লক্ষ্য নথির অবস্থান |
| কাজের সরঞ্জাম | অনূদিত নয় ও হালনাগাদ প্রয়োজন নথির খতিয়ান, নথি পড়া ও লেখা, টেমপ্লেট থেকে তৈরি করা |
| পরবর্তী পরীক্ষা | docs-lint দিয়ে যাচাই, ব্যাপ্তি ও সতেজতার পার্থক্য |

নির্দেশনায় নথির মূল লেখা অন্তর্ভুক্ত থাকে না। AI নিজেই ফাইল পড়ে, নিজেই লেখে এবং নিজেই যাচাই করে।

## কাজ হস্তান্তর করা

1. টুলবারের [নথি সরঞ্জাম] চাপুন এবং [AI] ট্যাব খুলুন।
2. [কাজ] থেকে যে কাজটি হস্তান্তর করতে চান তা বেছে নিন।
3. প্রয়োজনীয় তথ্য (লক্ষ্য ভাষা, বিষয়) লিখুন।
4. [এই কাজটি হস্তান্তর করুন] চাপুন।
   VS Code-এর টার্মিনাল খুলবে এবং নির্বাচিত AI নির্দেশনা পেয়ে কাজ শুরু করবে।

> **ইঙ্গিত**
>
> Claude Code-এর সেশনের সঙ্গে কাজের সরঞ্জাম (MCP সার্ভার `lunascape-docs`) থাকে। সেশনটি নিজেই অনূদিত নয় ও হালনাগাদ প্রয়োজন নথির তালিকা আনতে, docs-lint চালাতে এবং অনুবাদের পরে সতেজতা নথিভুক্ত করতে পারে।

## ফলাফল যাচাই করা

| প্রদানকারীর ধরন | ফলাফল কোথায় পৌঁছায় |
|---|---|
| সেশনভিত্তিক (Claude Code, Codex) | সরাসরি কাজের ট্রিতে লেখে। **Git-এর পার্থক্যে যাচাই করুন** |
| API ভিত্তিক (VS Code-এর ভাষা মডেল, Anthropic, OpenAI-সঙ্গতিপূর্ণ) | একবারে একটি নথির প্রস্তাব ফেরত দেয়। [পার্থক্য খুলুন] দিয়ে যাচাই করে [সংরক্ষণ] দিয়ে লিখুন |

### API ভিত্তিক প্রস্তাব যাচাই করা

API ভিত্তিক প্রদানকারী দিয়ে চালালে [AI] ট্যাবে প্রস্তাব পৌঁছায়।

1. [পার্থক্য খুলুন] চাপুন এবং বর্তমান বিষয়বস্তুর সঙ্গে পার্থক্য দেখে নিন।
2. ঠিক থাকলে [সংরক্ষণ] চাপুন। অনুবাদের ক্ষেত্রে সতেজতাও নথিভুক্ত হয়। বাতিল করতে চাইলে [বর্জন] চাপুন।
   তৈরির কাজ মাঝপথে থামাতে [থামান] চাপুন।

> **দ্রষ্টব্য**
>
> - Lunascape Docs কখনও Git-এ স্টেজ বা কমিট করে না। পরিবর্তন অবশ্যই পার্থক্যে যাচাই করুন।
> - বিশ্বস্ত নয় এমন ওয়ার্কস্পেসে, এবং ডকুমেন্টেশন রুটের বাইরের অস্থায়ী ফোল্ডার প্রদর্শনে কাজ হস্তান্তর করা যায় না।
