# הפנקס והרשומות

הפנקס שבראש הלשונית [AI] מציג את מצב התרגום של כל שפה נתמכת. אפשר להיעזר בו גם בלי AI: הוא מראה מה חסר.

| תווית | משמעות |
|---|---|
| תרגום חסר | מספר המסמכים שאין להם עדיין גרסה מתורגמת |
| דורש עדכון | מספר המסמכים שיש להם גרסה מתורגמת, אך מסמך המקור חדש יותר מן הרשומה |
| מתורגם | מספר גרסאות התרגום העוקבות אחר מסמך המקור |

הפנקס מחושב מתוך סריקה של שורש התיעוד. אין בכך מעורבות של AI ולא של מודל שפה.

## עדכון רשומות התרגום

כדי לקבוע "דורש עדכון" יש לתעד את מסמך המקור ואת גרסת התרגום כפי שהיו בזמן התרגום. ספק מסוג סשן כותב את הקבצים ישירות, ולכן אין רשומה שנוצרת מאליה.

1. כשהתרגום הסתיים ובדקתם את התוכן, לחצו על [עדכון רשומות התרגום].
2. גרסאות תרגום שאין להן רשומה נרשמות כמתאימות למסמך המקור הנוכחי.

סשנים של Claude Code ושמירה בספק מסוג API רושמים זאת מאליהם (הסשן מקבל הנחיה להשתמש בכלי MCP‏ `record_translation_freshness`). הכפתור נחוץ כאשר תרגמתם ב‑Codex או בצ'אט של VS Code.

מכאן ואילך, שינוי במסמך המקור מסמן את גרסת התרגום שלו כ"דורש עדכון".

> **שימו לב**
>
> - גרסאות תרגום שכבר יש להן רשומה אינן נדרסות, כדי שמצב "דורש עדכון" קיים לא יימחק.
> - הרשומות נשמרות בקובץ `.lunascape-docs/translation-freshness.json`. נשמרים רק נתיבים יחסיים, שפות, גיבובי תוכן ותאריך ושעה — גוף המסמך אינו נכלל.
