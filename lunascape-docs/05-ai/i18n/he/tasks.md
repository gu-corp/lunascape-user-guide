# עבודות שאפשר למסור

בוחרים מתוך [משימה] בלשונית [AI]. לכל עבודה משתנים ההנחיה הנמסרת והבדיקה שאחריה.

| עבודה | תוכן | דרוש | סוג API |
|---|---|---|---|
| תרגם דף זה | מתרגם את המסמך המוצג לשפה שנבחרה | המסמך פתוח, שפת יעד | ○ |
| תרגם את כל התרגומים החסרים | מתרגם בזה אחר זה את המסמכים בשפה שנבחרה שתרגומם חסר או דורש עדכון | שפת יעד | סוג מושב בלבד |
| הגה דף זה | בודק ומתקן מונחים, סגנון ואת מבנה הפרקים שתקן המסמכים דורש | המסמך פתוח | ○ |
| צור מסמך חדש | יוצר מסמך חדש לפי תקן המסמכים והתבניות | נושא (לא חובה) | סוג מושב בלבד |

## מה שנכלל בהנחיה

| מס' | תוכן |
|---|---|
| 1 | מיקום שורש התיעוד. יש הנחיה לא לשנות דבר מחוצה לו |
| 2 | שפת ברירת המחדל (מסמך המקור) ומקום התרגומים (`i18n/<שפה>/` בתיקייה של המסמך) |
| 3 | ש‏`navigation.order` שייך למסמך המקור בלבד, ושתרגום רשאי לדרוס רק את `navigation.title` |
| 4 | שאין לשנות מזהי דרישות, קישורים, קוד, Mermaid, TeX ואת מבנה ה־front matter |
| 5 | תקן המסמכים ומילון המונחים (`terminology` שב־`docs-lint.config.json`) |
| 6 | להריץ בסיום את בדיקת המסמכים, לדווח על הקבצים ששונו ולא לבצע פעולות Git |

> **עצה**
>
> היעדים של "תרגם את כל התרגומים החסרים" נוצרים מתוך הפנקס, עד 200 מסמכים בכל הרצה. אם יש יותר, יש להריץ שוב ושוב.
