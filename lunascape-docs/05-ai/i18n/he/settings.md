# הגדרות AI

בוחרים את ה‑AI ואת המודל שיקבלו את העבודה. אין שימוש בבחירה המהירה של VS Code; הבחירה נעשית בתפריטים הנפתחים שבמסך זה.

1. לוחצים על [כלי מסמכים] ← לשונית [AI] ← [הגדרות AI…].
2. בוחרים [ספק].
   ספקים שאינם זמינים בסביבה זו מוצגים כלא ניתנים לבחירה, בליווי הסיבה.
3. בוחרים [מודל]. האפשרויות משתנות לפי הספק.
4. סוגרים את המסך. הבחירה נשמרת לכל משתמש ומשמשת גם בפעם הבאה.

## ספקים

| ספק | צורה | אופן הזיהוי |
|---|---|---|
| Claude Code | מבוסס הפעלה | קיום הפקודה `claude` |
| Codex | מבוסס הפעלה | קיום הפקודה `codex` |
| מודלי השפה של VS Code | מבוסס API | מודלים הרשומים ב‑VS Code Language Model API |
| Anthropic API | מבוסס API | רישום מפתח API |
| API תואם OpenAI | מבוסס API | רישום מפתח API וכתובת קצה |

ספק **מבוסס הפעלה** קורא וכותב קבצים בעצמו, ומריץ גם את בדיקת המסמך בעצמו. התוצאות נכתבות ישירות לעץ העבודה ונבדקות בהפרש של Git.

ספק **מבוסס API** מחזיר Markdown של מסמך אחד, וההרחבה מציגה את ההפרש לפני השמירה.

## רישום מפתח API

Anthropic API ו‑API תואם OpenAI זמינים לשימוש לאחר רישום מפתח API.

1. בוחרים ב‑[ספק] את היעד לרישום. שדה הזנת מפתח ה‑API מופיע.
2. מזינים [מפתח API]. עבור API תואם OpenAI מזינים גם [כתובת קצה] (לדוגמה: `https://api.openai.com/v1`).
3. לוחצים על [שמירה]. מוצגת ההודעה „המפתח נרשם”.

> **שים לב**
>
> - המפתח נשמר ב‑SecretStorage של VS Code ואינו מוצג שוב. הוא גם אינו נכתב אל `settings.json` או אל מסמך כלשהו. אפשר למחוק אותו באמצעות [מחיקת מפתח].
> - רשימת המודלים נטענת מכל שירות באמצעות המפתח הרשום. עד לקבלת הרשימה מוצגת רשימה ידועה מראש.
> - בספק מבוסס API אפשר להריץ רק את „תרגום דף זה” ואת „הגהה של דף זה”. מעבר על כמה מסמכים ויצירת מסמכים יש להריץ בספק מבוסס הפעלה.

> **טיפ**
>
> אם לא נמצא אף ספק, התקינו את Claude Code או את Codex, או רשמו מפתח API. פתיחה מחדש של [הגדרות AI…] תזהה אותם.
