# Ανάθεση εργασίας σε AI

Το Lunascape Docs δεν καλεί γλωσσικό μοντέλο. Ετοιμάζει **το πλαίσιο, τα εργαλεία και τους ελέγχους**, και αφήνει τη μετάφραση, τη διόρθωση και τη σύνταξη στο AI που χρησιμοποιείτε.

## Η ιδέα

| Τι παρέχει το προϊόν | Περιεχόμενο |
|---|---|
| Πλαίσιο | Τις συμβάσεις της τεκμηρίωσης (πού βρίσκονται οι μεταφράσεις, front matter, το πρότυπο εγγράφων, το γλωσσάρι) και τη θέση του εγγράφου-στόχου |
| Εργαλεία εργασίας | Το μητρώο των εγγράφων χωρίς μετάφραση και όσων χρειάζονται ενημέρωση, την ανάγνωση και εγγραφή εγγράφων, τη δημιουργία από πρότυπα |
| Έλεγχοι εκ των υστέρων | Τον έλεγχο με docs-lint και τη διαφορά κάλυψης και φρεσκάδας |

Η οδηγία δεν περιλαμβάνει το κείμενο του εγγράφου: το AI διαβάζει μόνο του τα αρχεία, τα γράφει και τα επαληθεύει.

## Ανάθεση της εργασίας

1. Πατήστε [Εργαλεία εγγράφων] στη γραμμή εργαλείων και ανοίξτε την καρτέλα [AI].
2. Επιλέξτε την εργασία από το [Εργασία].
3. Συμπληρώστε τα απαιτούμενα στοιχεία (γλώσσα-στόχο, θέμα).
4. Πατήστε [Ανάθεση αυτής της εργασίας].
   Ανοίγει ένα τερματικό του VS Code και το AI που επιλέξατε παραλαμβάνει την οδηγία και ξεκινά.

> **Συμβουλή**
>
> Μια συνεδρία του Claude Code συνοδεύεται από τα εργαλεία εργασίας (τον διακομιστή MCP `lunascape-docs`). Η συνεδρία μπορεί μόνη της να ανακτήσει τη λίστα με όσα δεν έχουν μετάφραση ή χρειάζονται ενημέρωση, να εκτελέσει το docs-lint και να καταγράψει τη φρεσκάδα μετά τη μετάφραση.

## Έλεγχος του αποτελέσματος

| Μορφή παρόχου | Πού καταλήγει το αποτέλεσμα |
|---|---|
| Τύπου συνεδρίας (Claude Code, Codex) | Γράφει απευθείας στο δέντρο εργασίας. **Ελέγξτε το στη διαφορά του Git** |
| Τύπου API (γλωσσικά μοντέλα του VS Code, Anthropic, συμβατά με OpenAI) | Επιστρέφει προτάσεις ανά έγγραφο. Ελέγξτε τις με το [Άνοιγμα διαφοράς] και γράψτε τις με το [Αποθήκευση] |

### Έλεγχος μιας πρότασης τύπου API

Όταν η εκτέλεση γίνεται με πάροχο τύπου API, η πρόταση φτάνει στην καρτέλα [AI].

1. Πατήστε [Άνοιγμα διαφοράς] και δείτε τις διαφορές από το τρέχον περιεχόμενο.
2. Αν συμφωνείτε, πατήστε [Αποθήκευση]. Σε περίπτωση μετάφρασης καταγράφεται και η φρεσκάδα. Για να το ακυρώσετε, πατήστε [Απόρριψη].
   Για να σταματήσετε τη δημιουργία στη μέση, πατήστε [Διακοπή].

> **Σημείωση**
>
> - Το Lunascape Docs δεν κάνει ποτέ stage ούτε commit στο Git. Ελέγχετε πάντα τις αλλαγές στη διαφορά.
> - Δεν μπορείτε να αναθέσετε εργασία σε χώρο εργασίας που δεν είναι αξιόπιστος, ούτε κατά την προσωρινή προβολή φακέλου εκτός ρίζας τεκμηρίωσης.
