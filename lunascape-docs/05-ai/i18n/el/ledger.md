# Το μητρώο και οι καταγραφές

Το μητρώο στο επάνω μέρος της καρτέλας [AI] δείχνει την κατάσταση της μετάφρασης για κάθε υποστηριζόμενη γλώσσα. Μπορείτε να δείτε τι λείπει χωρίς να χρησιμοποιήσετε AI.

| Ένδειξη | Σημασία |
|---|---|
| Χωρίς μετάφραση | Πλήθος εγγράφων που δεν έχουν ακόμη μεταφρασμένη έκδοση |
| Χρειάζεται ενημέρωση | Πλήθος εγγράφων που έχουν μεταφρασμένη έκδοση, αλλά το πρωτότυπο έγγραφο είναι νεότερο από τη στιγμή της καταγραφής |
| Μεταφρασμένα | Πλήθος μεταφρασμένων εκδόσεων που ακολουθούν το πρωτότυπο έγγραφο |

Το μητρώο υπολογίζεται με σάρωση της ρίζας τεκμηρίωσης. Δεν εμπλέκεται ούτε AI ούτε γλωσσικό μοντέλο.

## Ενημέρωση των καταγραφών μετάφρασης

Για να κριθεί ότι ένα έγγραφο «χρειάζεται ενημέρωση», πρέπει να έχουν καταγραφεί το πρωτότυπο έγγραφο και η μεταφρασμένη έκδοση όπως ήταν τη στιγμή της μετάφρασης. Το AI τύπου συνεδρίας γράφει απευθείας τα αρχεία, οπότε δεν δημιουργείται αυτόματα καταγραφή.

1. Όταν ολοκληρωθεί η μετάφραση και ελέγξετε το περιεχόμενο, πατήστε [Ενημέρωση καταγραφών μετάφρασης].
2. Οι μεταφρασμένες εκδόσεις χωρίς καταγραφή καταγράφονται ως αντίστοιχες του τρέχοντος πρωτότυπου εγγράφου.

Οι συνεδρίες του Claude Code και η αποθήκευση μέσω παρόχου τύπου API κάνουν την καταγραφή αυτόματα (η συνεδρία λαμβάνει οδηγία να χρησιμοποιήσει το εργαλείο MCP `record_translation_freshness`). Αυτό το κουμπί χρειάζεται όταν η μετάφραση έγινε με το Codex ή με τη συνομιλία του VS Code.

Από εκεί και έπειτα, όταν αλλάζετε ένα πρωτότυπο έγγραφο, η μεταφρασμένη έκδοσή του εμφανίζεται ως «χρειάζεται ενημέρωση».

> **Σημείωση**
>
> - Οι μεταφρασμένες εκδόσεις που έχουν ήδη καταγραφή δεν αντικαθίστανται, ώστε να μη σβήνεται η κατάσταση «χρειάζεται ενημέρωση».
> - Οι καταγραφές αποθηκεύονται στο `.lunascape-docs/translation-freshness.json`. Αποθηκεύονται μόνο η σχετική διαδρομή, η γλώσσα, ο κατακερματισμός του περιεχομένου και η ημερομηνία και ώρα — ποτέ το κείμενο του εγγράφου.
