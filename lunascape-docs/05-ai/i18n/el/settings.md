# Ρυθμίσεις AI

Επιλέξτε το AI και το μοντέλο στα οποία παραδίδετε την εργασία σας. Δεν χρησιμοποιείται η γρήγορη επιλογή του VS Code· η επιλογή γίνεται από τις αναπτυσσόμενες λίστες αυτής της οθόνης.

1. Πατήστε [Εργαλεία εγγράφων] → καρτέλα [AI] → [Ρυθμίσεις AI…].
2. Επιλέξτε [Πάροχος].
   Όσοι πάροχοι δεν είναι διαθέσιμοι σε αυτό το περιβάλλον εμφανίζονται ως μη επιλέξιμοι, με την αιτία.
3. Επιλέξτε [Μοντέλο]. Οι επιλογές αλλάζουν ανάλογα με τον πάροχο.
4. Κλείστε την οθόνη. Η επιλογή αποθηκεύεται ανά χρήστη και χρησιμοποιείται και την επόμενη φορά.

## Πάροχοι

| Πάροχος | Μορφή | Τρόπος εντοπισμού |
|---|---|---|
| Claude Code | Συνεδρία | Ύπαρξη της εντολής `claude` |
| Codex | Συνεδρία | Ύπαρξη της εντολής `codex` |
| Γλωσσικά μοντέλα του VS Code | API | Μοντέλα καταχωρισμένα στο VS Code Language Model API |
| Anthropic API | API | Καταχώριση κλειδιού API |
| API συμβατό με OpenAI | API | Καταχώριση κλειδιού API και τελικού σημείου |

Ο πάροχος **συνεδρίας** διαβάζει και γράφει ο ίδιος τα αρχεία και εκτελεί ο ίδιος τον έλεγχο εγγράφου. Τα αποτελέσματα γράφονται απευθείας στο δέντρο εργασίας και ελέγχονται από τη διαφορά του Git.

Ο πάροχος **API** επιστρέφει Markdown ενός εγγράφου και η επέκταση δείχνει τη διαφορά πριν από την αποθήκευση.

## Καταχώριση κλειδιού API

Το Anthropic API και τα API συμβατά με OpenAI γίνονται διαθέσιμα μόλις καταχωριστεί ένα κλειδί API.

1. Επιλέξτε στο [Πάροχος] εκείνον για τον οποίο θα γίνει η καταχώριση. Εμφανίζεται το πεδίο του κλειδιού API.
2. Συμπληρώστε το [Κλειδί API]. Για API συμβατό με OpenAI, συμπληρώστε και το [Τελικό σημείο] (παράδειγμα: `https://api.openai.com/v1`).
3. Πατήστε [Αποθήκευση]. Εμφανίζεται η ένδειξη «Το κλειδί καταχωρίστηκε».

> **Σημείωση**
>
> - Το κλειδί αποθηκεύεται στο SecretStorage του VS Code και δεν εμφανίζεται ξανά. Ούτε γράφεται στο `settings.json` ή σε κάποιο έγγραφο. Μπορείτε να το διαγράψετε με το [Διαγραφή κλειδιού].
> - Η λίστα των μοντέλων λαμβάνεται από κάθε υπηρεσία με το καταχωρισμένο κλειδί. Όσο η λήψη δεν είναι δυνατή, εμφανίζεται μια γνωστή λίστα.
> - Με πάροχο API μπορούν να εκτελεστούν μόνο οι εργασίες «Μετάφραση αυτής της σελίδας» και «Διόρθωση αυτής της σελίδας». Η διαδοχική επεξεργασία πολλών εγγράφων και η δημιουργία εγγράφων εκτελούνται με πάροχο συνεδρίας.

> **Συμβουλή**
>
> Αν δεν βρίσκεται κανένας πάροχος, εγκαταστήστε το Claude Code ή το Codex ή καταχωρίστε ένα κλειδί API. Ανοίξτε ξανά τις [Ρυθμίσεις AI…] και θα εντοπιστεί.
