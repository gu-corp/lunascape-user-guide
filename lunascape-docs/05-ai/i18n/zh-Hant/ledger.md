# 台帳與記錄

[AI] 標籤頁上方的台帳，顯示各支援語言的翻譯狀況。即使不使用 AI，也能確認缺少哪些內容。

| 顯示 | 意義 |
|---|---|
| 未翻譯 | 尚無翻譯版本的文件數量 |
| 需更新 | 已有翻譯版本，但正本比記錄時點更新的文件數量 |
| 已翻譯 | 與正本同步的翻譯版本數量 |

台帳是掃描文件根目錄後計算得出的。過程中不涉及 AI，也不涉及語言模型。

## 更新翻譯記錄

若要判定「需更新」，必須記錄翻譯當時的正本與翻譯版本。工作階段型的 AI 會直接寫入檔案，因此不會自動建立記錄。

1. 翻譯完成並確認內容後，按下 [更新翻譯記錄]。
2. 沒有記錄的翻譯版本，會被記錄為對應目前的正本。

Claude Code 的工作階段與 API 型的儲存會自動建立記錄（工作階段會被指示使用 MCP 工具 `record_translation_freshness`）。需要用到這個按鈕的情況，是以 Codex 或 VS Code 的聊天進行翻譯時。

此後只要變更正本，該翻譯版本就會顯示為「需更新」。

> **注意**
>
> - 已有記錄的翻譯版本不會被覆寫，以免抹除「需更新」的狀態。
> - 記錄儲存於 `.lunascape-docs/translation-freshness.json`。儲存的只有相對路徑、語言、內容的雜湊值與日期時間，不含內文。
