# 可交付的工作

在 [AI] 索引標籤的 [工作] 中選擇。每項工作所交付的指示與事後檢查各不相同。

| 工作 | 內容 | 必要條件 | API 型 |
|---|---|---|---|
| 翻譯本頁 | 將目前顯示的文件翻譯成所選的語言 | 已開啟目標文件、目標語言 | ○ |
| 批次翻譯未翻譯文件 | 依序翻譯所選語言中未翻譯與需更新的文件 | 目標語言 | 僅工作階段型 |
| 校對本頁 | 確認並修正用語、文體，以及文件標準所要求的章節架構 | 已開啟目標文件 | ○ |
| 建立新文件 | 依照文件標準與範本建立新文件 | 主題（可省略） | 僅工作階段型 |

## 指示包含的內容

| 項次 | 內容 |
|---|---|
| 1 | 文件根目錄的位置。指示不得變更其範圍以外的內容 |
| 2 | 預設語言（正本），以及翻譯版的存放位置（與文件相同資料夾下的 `i18n/<語言>/`） |
| 3 | `navigation.order` 只屬於正本，翻譯版可覆寫的僅有 `navigation.title` |
| 4 | 不得變更需求 ID、連結、程式碼、Mermaid、TeX 與 front matter 的結構 |
| 5 | 文件標準與詞彙表（`docs-lint.config.json` 的 `terminology`） |
| 6 | 完成後執行文件檢查、回報變更過的檔案，且不進行任何 Git 操作 |

> **提示**
>
> 「批次翻譯未翻譯文件」的對象由清冊產生，每次最多 200 份文件。數量較多時請重複執行。
