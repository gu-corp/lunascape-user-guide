# AI 設定

選擇要接手工作的 AI 與模型。不使用 VS Code 的快速選擇，而是在本畫面的下拉式選單中選擇。

1. 按下 [文件工具] → [AI] 索引標籤 → [AI 設定…]。
2. 選擇 [提供者]。
   此環境無法使用的項目會顯示為無法選取，並附上原因。
3. 選擇 [模型]。選項會依提供者而異。
4. 關閉畫面。選擇會依使用者儲存，下次仍會沿用。

## 提供者

| 提供者 | 型態 | 偵測方式 |
|---|---|---|
| Claude Code | 工作階段型 | 是否有 `claude` 指令 |
| Codex | 工作階段型 | 是否有 `codex` 指令 |
| VS Code 的語言模型 | API 型 | 已註冊於 VS Code Language Model API 的模型 |
| Anthropic API | API 型 | 已註冊的 API 金鑰 |
| OpenAI 相容 API | API 型 | 已註冊的 API 金鑰與端點 |

**工作階段型**會自行讀寫檔案，文件檢查也由其自行執行。結果會直接寫入工作樹，請以 Git 的差異確認。

**API 型**會回傳一份文件份量的 Markdown，由擴充功能顯示差異後再儲存。

## 註冊 API 金鑰

Anthropic API 與 OpenAI 相容 API 在註冊 API 金鑰後即可使用。

1. 在 [提供者] 中選擇要註冊的對象。API 金鑰的輸入欄位會出現。
2. 輸入 [API 金鑰]。若為 OpenAI 相容，請一併輸入 [端點]（例如：`https://api.openai.com/v1`）。
3. 按下 [儲存]。畫面會顯示「金鑰已註冊」。

> **注意**
>
> - 金鑰會儲存在 VS Code 的 SecretStorage，不會再次顯示，也不會寫入 `settings.json` 或文件中。可用 [刪除金鑰] 刪除。
> - 模型清單會以註冊的金鑰向各服務取得。在無法取得期間，會顯示已知的清單。
> - API 型可執行的工作只有「翻譯本頁」與「校對本頁」。多份文件的巡覽與文件的建立，請以工作階段型執行。

> **提示**
>
> 若找不到任何提供者，請安裝 Claude Code 或 Codex，或註冊 API 金鑰。重新開啟 [AI 設定…] 即可偵測到。
