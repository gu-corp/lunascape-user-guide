# 台账与记录

[AI] 选项卡顶部的台账显示各支持语言的翻译状况。即使不使用 AI，也能确认还缺少什么。

| 显示 | 含义 |
|---|---|
| 未翻译 | 尚无翻译版的文档数量 |
| 需更新 | 已有翻译版，但正本文档比记录时点更新的文档数量 |
| 已翻译 | 与正本文档保持一致的翻译版数量 |

台账通过扫描文档根目录计算得出，不涉及 AI，也不涉及语言模型。

## 更新翻译记录

要判定"需更新"，需要记录下翻译时点的正本文档与翻译版。会话型 AI 会直接写入文件，因此不会自动生成记录。

1. 翻译完成并确认内容后，按 [更新翻译记录]。
2. 没有记录的翻译版将被记录为与当前正本文档相对应。

Claude Code 的会话和 API 型的保存会自动记录（会话会被指示使用 MCP 工具 `record_translation_freshness`）。需要用到此按钮的，是使用 Codex 或 VS Code 聊天进行翻译的情况。

此后，只要修改正本文档，其翻译版就会显示为"需更新"。

> **注意**
>
> - 已有记录的翻译版不会被覆盖，以免抹去"需更新"的状态。
> - 记录保存在 `.lunascape-docs/translation-freshness.json` 中。保存的只有相对路径、语言、内容的哈希值和日期时间，不包含正文。
