# 可交付的作业

在 [AI] 标签页的 [作业] 中选择。作业不同，交付的指示和事后检查也不同。

| 作业 | 内容 | 所需条件 | API 类型 |
|---|---|---|---|
| 翻译本页 | 将当前显示的文档翻译为所选语言 | 已打开目标文档、目标语言 | ○ |
| 批量翻译未翻译内容 | 依次翻译所选语言中未翻译和需更新的文档 | 目标语言 | 仅会话型 |
| 校对本页 | 确认并修正术语、文体以及文档标准要求的章节结构 | 已打开目标文档 | ○ |
| 新建文档 | 按照文档标准和模板新建文档 | 主题（可省略） | 仅会话型 |

## 指示中包含的内容

| 项号 | 内容 |
|---|---|
| 1 | 文档根目录的位置。指示不得改动其外部的内容 |
| 2 | 默认语言（正本）以及译文的存放位置（与文档同一文件夹下的 `i18n/<语言>/`） |
| 3 | `navigation.order` 仅由正本文档持有，译文可覆盖的只有 `navigation.title` |
| 4 | 不得改动需求 ID、链接、代码、Mermaid、TeX 和 front matter 的结构 |
| 5 | 文档标准和术语表（`docs-lint.config.json` 的 `terminology`） |
| 6 | 结束后运行文档检查，报告已改动的文件，并且不进行 Git 操作 |

> **提示**
>
> “批量翻译未翻译内容”的对象取自台账，每次最多 200 篇文档。数量较多时请重复运行。
