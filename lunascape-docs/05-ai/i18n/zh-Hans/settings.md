# AI 设置

选择接收工作的 AI 和模型。本界面不使用 VS Code 的快速选择，而是通过本界面的下拉菜单选择。

1. 按 [文档工具] → [AI] 选项卡 → [AI 设置…]。
2. 在 [提供方] 中选择。
   本环境无法使用的提供方会显示为不可选状态，并附上原因。
3. 选择 [模型]。可选项因提供方而异。
4. 关闭界面。选择按用户保存，下次继续使用。

## 提供方

| 提供方 | 形态 | 检测方式 |
|---|---|---|
| Claude Code | 会话型 | 是否存在 `claude` 命令 |
| Codex | 会话型 | 是否存在 `codex` 命令 |
| VS Code 的语言模型 | API 型 | 已注册到 VS Code Language Model API 的模型 |
| Anthropic API | API 型 | 已注册 API 密钥 |
| OpenAI 兼容 API | API 型 | 已注册 API 密钥和端点 |

**会话型**自行读写文件，也自行执行文档检查。结果直接写入工作树，通过 Git 差异确认。

**API 型**返回一篇文档的 Markdown，由扩展显示差异后保存。

## 注册 API 密钥

Anthropic API 和 OpenAI 兼容 API 在注册 API 密钥后即可使用。

1. 在 [提供方] 中选择注册对象。此时会显示 API 密钥的输入框。
2. 输入 [API 密钥]。如果是 OpenAI 兼容 API，还需输入 [端点]（例如 `https://api.openai.com/v1`）。
3. 按 [保存]。界面会显示"密钥已注册"。

> **注意**
>
> - 密钥保存在 VS Code 的 SecretStorage 中，不会再次显示，也不会写入 `settings.json` 或文档。可通过 [删除密钥] 删除。
> - 模型列表使用已注册的密钥从各服务获取。在获取到之前，显示已知的列表。
> - API 型可执行的工作只有"翻译本页"和"校对本页"。多篇文档的巡回处理和文档的创建请使用会话型执行。

> **提示**
>
> 如果找不到任何提供方，请安装 Claude Code 或 Codex，或者注册 API 密钥。重新打开 [AI 设置…] 即可检测到。
