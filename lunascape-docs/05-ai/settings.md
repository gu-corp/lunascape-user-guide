# AI 設定

作業を渡す AI とモデルを選びます。VS Code のクイックピックは使わず、この画面のプルダウンで選びます。

1. [文書ツール] → [AI] タブ → [AI 設定…] を押します。
2. [プロバイダー] を選びます。
   この環境で使えないものは、理由を添えて選択できない状態で表示されます。
3. [モデル] を選びます。選択肢はプロバイダーごとに変わります。
4. 画面を閉じます。選択は利用者ごとに保存され、次回も使われます。

## プロバイダー

| プロバイダー | 形態 | 検出方法 |
|---|---|---|
| Claude Code | セッション型 | `claude` コマンドの有無 |
| Codex | セッション型 | `codex` コマンドの有無 |
| VS Code の言語モデル | API 型 | VS Code Language Model API に登録されたモデル |
| Anthropic API | API 型 | API キーの登録 |
| OpenAI 互換 API | API 型 | API キーとエンドポイントの登録 |

**セッション型**は自分でファイルを読み書きし、文書チェックも自分で実行します。結果は作業ツリーに直接書き込まれ、Git の差分で確認します。

**API 型**は 1 文書分の Markdown を返し、拡張機能が差分を見せてから保存します。

## API キーを登録する

Anthropic API と OpenAI 互換 API は、API キーを登録すると使えます。

1. [プロバイダー] で登録先を選びます。API キーの入力欄が表示されます。
2. [API キー] を入力します。OpenAI 互換の場合は [エンドポイント]（例: `https://api.openai.com/v1`）も入力します。
3. [保存] を押します。「キー登録済み」と表示されます。

> **ご注意**
>
> - キーは VS Code の SecretStorage に保存され、再表示されません。`settings.json` や文書に書き込まれることもありません。[キーを削除] で削除できます。
> - モデルの一覧は、登録したキーで各サービスから取得します。取得できない間は既知の一覧を表示します。
> - API 型で実行できる作業は「このページを翻訳」と「このページを校正」だけです。複数文書の巡回や文書の作成はセッション型で実行してください。

> **ヒント**
>
> どのプロバイダーも見つからない場合は、Claude Code か Codex をインストールするか、API キーを登録してください。[AI 設定…] を開き直すと検出されます。
