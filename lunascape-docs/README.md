# Lunascape Docs ヘルプガイド

Lunascape Docs は、リポジトリの中にある Markdown 文書を、ビルドや専用サーバーなしで Web サイトのように読み、書き、確かめるための文書ワークスペースです。文書の正本はいつも Markdown ファイルのままで、保存やコミットを勝手に行うことはありません。

このヘルプガイドは、VS Code 拡張機能「Lunascape Docs」の使いかたを中心に、Web ブラウザ版の使いかたもあわせて説明しています。

## 本ヘルプガイドの使いかた

- 左の INDEX で項目を選ぶか、本文中のリンクをたどって読み進めます。
- INDEX の上にある [文書を絞り込み] に言葉を入力すると、該当する項目だけを表示できます。
- 右の「このページ」には、表示中のページの見出しが並びます。
- 画面に表示される項目名は [編集] のように [ ] で示します。キー操作は `Alt`+`←` のように示します。
- ヘルプを閉じて元の文書に戻るには、ツールバーの [ヘルプ] をもう一度押すか、その右にある [×] を押します。
