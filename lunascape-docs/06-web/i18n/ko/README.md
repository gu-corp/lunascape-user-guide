# 웹 버전에서 할 수 있는 일

웹 브라우저 버전 Lunascape Docs는 <https://docs.lunascape.org/> 에 공개되어 있습니다. 설치 없이 GitHub에 있는 문서를 웹 사이트처럼 읽을 수 있습니다.

## 할 수 있는 일

| 기능 | 내용 |
|---|---|
| 공개 리포지토리 열람 | 로그인 없이 GitHub 공개 리포지토리의 문서를 엽니다 |
| 비공개 리포지토리 열람 | GitHub으로 로그인하면 자신에게 읽기 권한이 있는 리포지토리를 열 수 있습니다 |
| 로컬 폴더 열람 | [문서 열기]의 [로컬 폴더의 문서 열기]로 기기 안의 폴더를 엽니다(지원되는 브라우저만) |
| 열람 기능 | INDEX, 링크, 기록, 필터, 이 페이지, 언어 전환, 테마 전환. VS Code 버전과 같습니다 |
| 다이어그램과 수식 | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, KaTeX 수식 |
| 초안 | 문서를 편집하고 변경 내용을 기기 안의 초안으로 보관합니다. 리포지토리에는 기록하지 않습니다 |
| 페이지 직접 링크 | URL로 리포지토리와 페이지를 지정하여 특정 페이지를 바로 열 수 있습니다 |

## VS Code 버전과의 차이

- 문서 검사, 템플릿에서 만들기, 번역안 생성, INDEX에서 정리하기는 웹 버전에 없습니다.
- TikZ 다이어그램은 그려지지 않습니다.
- 편집 내용은 리포지토리에 기록되지 않고 기기 안의 초안이 됩니다. 초안을 Pull Request로 보내는 "게시 요청"은 구현되어 있지만 공개 뷰어에서는 활성화되어 있지 않습니다. 리포지토리에 반영하려면 VS Code 버전이나 로컬 클론에서 편집하십시오.
