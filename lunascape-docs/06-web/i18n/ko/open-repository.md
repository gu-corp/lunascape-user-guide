# GitHub 리포지토리 열기

Web 버전에서는 GitHub 리포지토리를 지정하여 문서를 엽니다. 공개 리포지토리라면 로그인이 필요 없습니다.

## 화면에서 열기

1. <https://docs.lunascape.org/> 을 엽니다.
2. 도구 모음의 [문서 열기](폴더 아이콘)를 누릅니다.
3. [리포지토리 직접 지정]에 리포지토리를 입력하고 [열기]를 누릅니다.
   GitHub에 로그인되어 있을 때는 [읽을 수 있는 리포지토리에서 선택]에서 목록으로 고를 수도 있습니다.

> **힌트**
>
> - 옆에 있는 GitHub 아이콘은 지금 읽고 있는 문서를 github.com에서 엽니다. 문서를 여는 조작이 아닙니다.

## URL로 열기

주소는 리포지토리와 문서의 위치를 그대로 나열한 형태입니다. 경로는 리포지토리 안에서의 위치이므로 GitHub의 URL과 같은 순서가 됩니다.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 지정 | 쓰는 방법 |
|---|---|
| 리포지토리만(기본 브랜치) | `/github/owner/repo` |
| 리포지토리 안의 문서 | `/github/owner/repo/docs/01-product/vision.md` |
| 브랜치 또는 태그 지정 | 끝에 `?ref=v1.2.0` 을 붙입니다 |

페이지를 이동하면 주소도 바뀝니다. 도구 모음의 [이 문서 공유]를 누르면 지금 읽고 있는 페이지의 링크를 건넬 수 있습니다. 브라우저의 [뒤로] [앞으로]도 사용할 수 있습니다.

이전의 `?source=` 형태도 지금까지와 같이 열 수 있습니다. 열린 뒤에는 새로운 형태로 바뀝니다.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **참고**
>
> - 로그인하지 않은 상태에서는 GitHub API의 이용 제한(1시간당 60회)이 있습니다. 문서가 많은 리포지토리나 반복해서 볼 때는 [GitHub으로 로그인]하십시오.
> - `/` 를 포함하는 브랜치 이름(`feature/xxx` 등)은 위 주소 형식의 `?ref=` 로 지정할 수 있습니다. `?source=` 형태로는 쓸 수 없습니다.
> - 문서는 열람자의 GitHub 권한으로 읽어 들입니다. 읽기 권한이 없는 사람에게는 표시되지 않습니다.

## 로컬 폴더의 문서 열기

도구 모음의 [문서 열기]를 누르고, 목록 아래에 있는 [로컬 폴더의 문서 열기]에서 단말기 안의 폴더를 선택합니다. 파일은 브라우저 안에서 처리되며 외부로 전송되지 않습니다. 폴더 선택을 지원하는 브라우저(Chrome, Edge 등)에서 사용할 수 있습니다.
