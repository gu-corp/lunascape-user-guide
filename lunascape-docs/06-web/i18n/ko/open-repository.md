# GitHub 리포지토리 열기

웹 버전과 Lunascape에서는 GitHub 리포지토리를 복제하지 않고 그대로 열어 읽을 수 있습니다. 공개 리포지토리는 로그인하지 않아도 됩니다.

## 화면에서 열기

1. 도구 모음에서 폴더 아이콘인 [문서 열기]를 누릅니다. '문서 열기' 화면이 열립니다.
2. 왼쪽 목록에서 열 위치를 선택합니다.

   | 위치 | 표시되는 항목 |
   |---|---|
   | 모두 | 아래의 모든 항목. 최근에 연 항목이 맨 위에 표시됩니다 |
   | 최근에 연 항목 | 지금까지 연 리포지토리와 폴더 |
   | 추천 | 사이트에서 소개하는 매뉴얼 |
   | GitHub 리포지토리 | GitHub으로 로그인한 경우, 본인이 읽을 수 있는 리포지토리 |
   | 이 컴퓨터 | 이 기기의 폴더. Lunascape에서는 복제한 리포지토리도 여기에 표시됩니다 |

3. 열려는 행의 [열기]를 누릅니다. 위쪽의 [문서 이름 또는 리포지토리 이름으로 필터링]에 입력하면 표시되는 행을 좁힐 수 있습니다.

목록에 없는 리포지토리는 왼쪽 목록의 [owner/repo를 입력하여 열기]에서 지정합니다.

> **힌트**
>
> - 목록에 표시되는 GitHub 리포지토리는 GitHub 앱 'Lunascape Docs'가 설치되어 있고 본인에게 읽기 권한이 있는 리포지토리입니다. 원하는 리포지토리가 보이지 않으면 리포지토리 소유자에게 앱 추가를 요청하세요.

## 문서 위치 확인하기

도구 모음 왼쪽에 있는 작은 아이콘(위치 칩)은 지금 읽고 있는 문서의 위치를 나타냅니다.

| 아이콘 | 위치 |
|---|---|
| GitHub 마크 | GitHub에서 읽고 있습니다. 이 기기에는 저장되어 있지 않습니다 |
| 컴퓨터 | Lunascape가 관리하는 이 기기의 폴더입니다. Git 브랜치 이름과 변경한 파일 수도 표시됩니다 |
| 폴더 | 이 기기의 폴더입니다 |

아이콘을 누르면 위치와 상태, 그리고 그 위치에서 할 수 있는 작업([GitHub에서 보기], [링크 복사] 등)이 표시됩니다.

## Lunascape에서 리포지토리 복제하기

Lunascape에서는 GitHub 리포지토리를 이 기기에 복제한 다음 Git으로 편집하고 커밋할 수 있습니다.

- '문서 열기' 화면에서 리포지토리 행의 [복제]를 누릅니다.
- GitHub에서 열어 읽고 있을 때는 위치 칩을 누른 다음 [이 컴퓨터에 복제]를 누릅니다. 복제가 끝나면 같은 문서가 이 기기에 있는 사본으로 열립니다.

복제한 리포지토리는 목록에 '이 컴퓨터에 있음'으로 표시되고, [이 컴퓨터에서 열기]가 앞쪽에 표시됩니다.

## URL로 열기

주소는 리포지토리와 문서의 위치를 그대로 이어 붙인 형태입니다. 경로는 리포지토리 안에서의 위치이므로 GitHub URL과 같은 순서가 됩니다.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 지정 대상 | 작성 방법 |
|---|---|
| 리포지토리만(기본 브랜치) | `/github/owner/repo` |
| 리포지토리 안의 문서 | `/github/owner/repo/docs/01-product/vision.md` |
| 브랜치 또는 태그 지정 | 끝에 `?ref=v1.2.0`을 붙입니다 |

페이지를 이동하면 주소도 바뀝니다. 도구 모음의 [이 문서 공유]를 누르면 지금 읽고 있는 페이지의 링크를 다른 사람에게 전달할 수 있습니다. 브라우저의 [뒤로]와 [앞으로]도 사용할 수 있습니다.

이전의 `?source=` 형식으로도 기존과 같이 열 수 있습니다. 연 다음에는 주소가 새 형식으로 바뀝니다.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **주의**
>
> - 로그인하지 않은 상태에서는 GitHub API 이용 제한(1시간에 60회)이 적용됩니다. 문서가 많은 리포지토리를 보거나 반복해서 열람할 때는 [GitHub으로 로그인]을 눌러 로그인하세요.
> - `/`를 포함한 브랜치 이름(`feature/xxx` 등)은 위의 주소 형식에서 `?ref=`로 지정할 수 있습니다. `?source=` 형식으로는 지정할 수 없습니다.
> - 문서는 열람자의 GitHub 권한으로 불러옵니다. 읽기 권한이 없는 사람에게는 표시되지 않습니다.

## 로컬 폴더의 문서 열기

도구 모음의 [문서 열기]를 누르고, 왼쪽 목록에 있는 [로컬 폴더의 문서 열기]에서 기기 안의 폴더를 선택합니다. 파일은 브라우저 안에서 처리되며 외부로 전송되지 않습니다. 폴더 선택을 지원하는 브라우저(Chrome, Edge 등)에서 사용할 수 있습니다.
