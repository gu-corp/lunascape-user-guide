# 비공개 리포지토리 열람하기

비공개 리포지토리의 문서는 GitHub으로 로그인하면 자신에게 읽기 권한이 있는 리포지토리에 한해 열람할 수 있습니다. Lunascape Docs가 자체 계정이나 권한을 갖는 일은 없습니다.

## 로그인해서 열기

1. <https://docs.lunascape.org/>를 엽니다.
   비공개 문서를 지정했거나 아직 로그인하지 않은 경우에는 로그인 화면이 표시됩니다.
2. [GitHub으로 로그인]을 누릅니다.
   GitHub 인증 화면이 팝업으로 열립니다.
3. 로그인이 끝나면 도구 모음의 [문서 열기]를 누르고, [읽을 수 있는 리포지토리에서 선택]에서 열고 싶은 리포지토리를 선택합니다.

> **힌트**
>
> - 로그인 중인 계정 이름은 도구 모음에 표시됩니다. [로그아웃]이나 [다른 계정으로 로그인]도 여기서 할 수 있습니다.
> - 목록에 표시되는 것은 GitHub App「Lunascape Docs」가 설치된 계정(조직 또는 개인)의 리포지토리 중 자신에게 읽기 권한이 있는 것입니다.

## 리포지토리 소유자가 하는 설정

목록에 해당 리포지토리가 표시되지 않는 경우에는 리포지토리 소유자 또는 조직 관리자가 GitHub App「Lunascape Docs」를 설치해야 합니다.

- 요청하는 권한은 Contents(읽기·쓰기)와 Pull requests(읽기·쓰기)입니다. 읽기는 열람을 위한 것이고, 쓰기는 Web에서의 공개 요청(Pull Request)을 위한 것입니다. 문서의 내용을 Lunascape Docs가 저장하는 일은 없습니다.
- 설치 단위는 계정(조직 또는 개인)입니다. 대상을 「All repositories」(이후 생성되는 리포지토리도 자동으로 포함)로 할지, 선택한 리포지토리만으로 할지를 설정합니다.

| 상황 | 절차 |
|---|---|
| 새로 조직 또는 개인 계정에 도입한다 | [설치 페이지](https://github.com/apps/lunascape-docs/installations/new)에서 실시합니다 |
| 이미 도입된 조직에서 대상 리포지토리를 추가한다 | 조직의 Settings → GitHub Apps → Lunascape Docs → Configure → Repository access에서 설정합니다 |

조직 전체에 설치하더라도 각 구성원이 열람할 수 있는 것은 본인이 읽기 권한을 가진 리포지토리뿐입니다. 공개 요청을 보낼 수 있는 것도 본인이 쓰기 권한을 가진 리포지토리뿐입니다.

> **힌트**
> - 새로 설치하는 경우, 요청하는 권한은 설치 화면에 목록으로 표시되며 「Install」을 누른 시점에 승인한 것이 됩니다. 추가 작업은 없습니다.
> - 권한이 늘어나기 전부터 설치해 온 조직에는 관리자에게 확인 메일이 도착하고, 조직의 Settings → GitHub Apps → Lunascape Docs → Configure 상단에 승인 버튼이 표시됩니다. 승인하기 전까지 그 조직에서는 열람만 할 수 있으며, 공개 요청을 보내면 「쓰기 권한 부여가 필요합니다」라고 표시됩니다.
> - 지금 어떤 권한으로 들어와 있는지는 같은 Configure 화면에서 확인할 수 있습니다. 개인 계정의 경우에는 Settings → Applications → Installed GitHub Apps입니다.
> - 대상 리포지토리를 실수로 제외했거나 제거한 경우에는 [설치 페이지](https://github.com/apps/lunascape-docs/installations/new)에서 다시 넣으면 원래대로 돌아갑니다. 공개 요청 거부 메시지에는 수정하는 화면으로 가는 링크가 붙습니다.
> - 리포지토리 쪽에서 공개 요청을 받고 싶지 않은 경우에는 `lunascape-docs.json`에 `"publish": { "enabled": false }`라고 적습니다. 열람은 그대로 사용할 수 있습니다.
