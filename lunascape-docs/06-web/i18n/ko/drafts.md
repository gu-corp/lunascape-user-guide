# 초안 저장하기

Web 버전에서 문서를 편집하면 변경 내용은 리포지토리에 기록되지 않고 브라우저 안에 "초안"으로 저장됩니다.

## 초안 만들기

1. 문서를 열고 오른쪽 아래의 [편집]을 누릅니다.
2. 편집한 뒤 [저장]을 누릅니다.
   "초안으로 저장했습니다"라고 표시되며 변경 내용이 브라우저 안에 저장됩니다.

- 초안이 있는 문서에는 INDEX에 배지가 붙습니다. 본문 위에는 "이 문서는 단말기 내 초안입니다(미게시)"라고 표시됩니다.
- 도구 모음의 [초안]에는 건수가 표시되며, 누르면 초안 목록이 열립니다.

## 초안 버리기

- 문서별로 버리려면 본문 위의 [초안 버리기]를 누릅니다.
- 모두 버리려면 초안 목록에서 조작합니다.

## 리포지토리에 반영하기

초안을 Pull Request로 보내는 "게시 요청"은 구현되어 있지만, 공개 뷰어에서는 활성화되어 있지 않습니다. 리포지토리에 반영하려면 VS Code 버전이나 로컬 클론에서 편집하십시오.

> **참고**
>
> - 초안은 브라우저(IndexedDB)에 저장됩니다. 다른 브라우저나 다른 단말기로는 이어지지 않습니다. 브라우저의 사이트 데이터를 지우면 초안도 지워집니다.
> - 초안을 만든 뒤 리포지토리 쪽 문서가 갱신되면 "업스트림이 갱신되었습니다"라고 표시됩니다. 내용을 확인한 다음 초안을 버릴지 그대로 사용할지 판단하십시오.
> - [문서 열기]에서 로컬 폴더를 열어 편집한 경우에는 브라우저가 지원한다면 파일에 직접 저장됩니다. 지원하지 않는 브라우저에서는 해당 세션 동안에만 유지됩니다.
