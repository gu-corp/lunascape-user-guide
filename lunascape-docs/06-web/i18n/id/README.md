# Yang dapat dilakukan versi Web

Lunascape Docs versi peramban Web tersedia di <https://docs.lunascape.org/>. Tanpa memasang apa pun, Anda dapat membaca dokumen di GitHub seperti sebuah situs web.

## Yang dapat dilakukan

| Fitur | Keterangan |
|---|---|
| Membaca repositori publik | Membuka dokumen repositori publik GitHub tanpa masuk |
| Membaca repositori privat | Setelah masuk dengan GitHub, membuka repositori yang Anda miliki hak bacanya |
| Membaca folder lokal | [Buka dokumen] lalu [Buka dokumen dari folder lokal] membuka folder di perangkat Anda (hanya peramban yang didukung) |
| Fitur membaca | INDEX, tautan, riwayat, penyaringan, daftar isi halaman, pengalihan bahasa, dan pengalihan tema. Sama dengan versi VS Code |
| Diagram dan rumus | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, rumus KaTeX |
| Draf | Menyunting dokumen dan menyimpan perubahan sebagai draf di perangkat Anda. Tidak ada yang ditulis ke repositori |
| Tautan langsung ke halaman | URL dapat menyebutkan repositori dan halaman, sehingga halaman tertentu dapat dibuka langsung |

## Perbedaan dengan versi VS Code

- Pemeriksaan dokumen, pembuatan dari templat, pembuatan usulan terjemahan, dan penataan dari INDEX tidak tersedia di versi Web.
- Diagram TikZ tidak digambar.
- Hasil suntingan tidak ditulis ke repositori, melainkan menjadi draf di perangkat Anda. "Permintaan publikasi", yang mengirim draf sebagai Pull Request, sudah diterapkan tetapi tidak diaktifkan pada penampil publik. Untuk menerapkannya ke repositori, suntinglah dengan versi VS Code atau pada klona lokal Anda.
