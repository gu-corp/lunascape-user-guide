# Άνοιγμα αποθετηρίου GitHub

Στην έκδοση Web μπορείτε να ανοίξετε και να διαβάσετε ένα αποθετήριο GitHub απευθείας, χωρίς να το κλωνοποιήσετε. Για τα δημόσια αποθετήρια δεν χρειάζεται σύνδεση.

## Άνοιγμα από την οθόνη

1. Πατήστε [Άνοιγμα εγγράφων] (το εικονίδιο φακέλου) στη γραμμή εργαλείων. Ανοίγει η οθόνη «Άνοιγμα εγγράφων».
2. Στη στήλη αριστερά, επιλέξτε από πού θα ανοίξετε.

   | Θέση | Τι εμφανίζεται |
   |---|---|
   | Όλα | Όλα τα παρακάτω. Όσα ανοίξατε πρόσφατα εμφανίζονται πρώτα |
   | Πρόσφατα | Τα αποθετήρια και οι φάκελοι που έχετε ανοίξει |
   | Προτεινόμενα | Τα εγχειρίδια που προβάλλει ο ιστότοπος |
   | Αποθετήρια GitHub | Όταν έχετε συνδεθεί στο GitHub, τα αποθετήρια που μπορείτε να διαβάσετε |
   | Αυτός ο υπολογιστής | Οι φάκελοι αυτής της συσκευής |

3. Πατήστε [Άνοιγμα] στη γραμμή που θέλετε. Για να περιορίσετε τις γραμμές, πληκτρολογήστε στο [Φιλτράρισμα κατά όνομα εγγράφου ή αποθετηρίου] στο επάνω μέρος.

Για ένα αποθετήριο που δεν υπάρχει στη λίστα, ορίστε το από το [Άνοιγμα owner/repo] στη στήλη αριστερά.

> **Συμβουλή**
>
> - Τα αποθετήρια GitHub της λίστας είναι εκείνα στα οποία είναι εγκατεστημένη η GitHub App «Lunascape Docs» και για τα οποία έχετε δικαίωμα ανάγνωσης. Αν δεν βρίσκετε κάποιο, ζητήστε από τον κάτοχο του αποθετηρίου να προσθέσει την εφαρμογή.

## Έλεγχος της θέσης του εγγράφου

Το μικρό εικονίδιο κοντά στην αριστερή πλευρά της γραμμής εργαλείων (η ένδειξη θέσης) δείχνει πού βρίσκεται το έγγραφο που διαβάζετε.

| Εικονίδιο | Θέση |
|---|---|
| Το σήμα του GitHub | Διαβάζετε από το GitHub. Δεν αποθηκεύεται τίποτα σε αυτήν τη συσκευή |
| Φάκελος | Φάκελος σε αυτήν τη συσκευή |

Πατήστε το εικονίδιο για να δείτε τη θέση, την κατάστασή της και τις ενέργειες που μπορείτε να κάνετε από εκεί (όπως [Προβολή στο GitHub] και [Αντιγραφή συνδέσμου]).

## Άνοιγμα μέσω URL

Η διεύθυνση παραθέτει το αποθετήριο και τη θέση του εγγράφου όπως είναι. Η διαδρομή είναι η θέση μέσα στο αποθετήριο, οπότε η σειρά είναι ίδια με το URL του GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Τι ορίζετε | Μορφή |
|---|---|
| Μόνο αποθετήριο (προεπιλεγμένος κλάδος) | `/github/owner/repo` |
| Έγγραφο μέσα στο αποθετήριο | `/github/owner/repo/docs/01-product/vision.md` |
| Κλάδος ή ετικέτα | Προσθέστε `?ref=v1.2.0` στο τέλος |

Όταν μετακινείστε σε άλλη σελίδα, αλλάζει και η διεύθυνση. Πατήστε [Κοινοποίηση αυτού του εγγράφου] στη γραμμή εργαλείων για να δώσετε τον σύνδεσμο της σελίδας που διαβάζετε. Λειτουργούν επίσης τα κουμπιά [Πίσω] και [Εμπρός] του προγράμματος περιήγησης.

Η παλαιότερη μορφή `?source=` εξακολουθεί να ανοίγει. Μετά το άνοιγμα, η διεύθυνση μετατρέπεται στη νέα μορφή.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Σημείωση**
>
> - Χωρίς σύνδεση ισχύει το όριο χρήσης του GitHub API (60 αιτήματα ανά ώρα). Για αποθετήρια με πολλά έγγραφα ή για επαναλαμβανόμενη ανάγνωση, χρησιμοποιήστε το [Σύνδεση με GitHub].
> - Ονόματα κλάδων που περιέχουν `/` (όπως `feature/xxx`) ορίζονται με `?ref=` στην παραπάνω μορφή διεύθυνσης. Η μορφή `?source=` δεν μπορεί να τα εκφράσει.
> - Τα έγγραφα φορτώνονται με τα δικαιώματα GitHub του αναγνώστη. Όσοι δεν έχουν δικαίωμα ανάγνωσης δεν τα βλέπουν.

## Άνοιγμα εγγράφων από τοπικό φάκελο

Πατήστε [Άνοιγμα εγγράφων] στη γραμμή εργαλείων και, από το [Άνοιγμα εγγράφων από τοπικό φάκελο] στη στήλη αριστερά, επιλέξτε έναν φάκελο της συσκευής σας. Η επεξεργασία των αρχείων γίνεται μέσα στο πρόγραμμα περιήγησης και δεν αποστέλλονται πουθενά. Λειτουργεί σε προγράμματα περιήγησης που υποστηρίζουν την επιλογή φακέλου (Chrome, Edge κ.λπ.).
