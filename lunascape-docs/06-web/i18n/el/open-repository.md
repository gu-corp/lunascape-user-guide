# Άνοιγμα αποθετηρίου GitHub

Στην έκδοση Web ανοίγετε έγγραφα καθορίζοντας ένα αποθετήριο GitHub. Για τα δημόσια αποθετήρια δεν απαιτείται σύνδεση.

## Άνοιγμα από την οθόνη

1. Ανοίξτε τη διεύθυνση <https://docs.lunascape.org/>.
2. Πατήστε [Άνοιγμα εγγράφων] (το εικονίδιο φακέλου) στη γραμμή εργαλείων.
3. Καταχωρίστε το αποθετήριο στο [Απευθείας καταχώριση αποθετηρίου] και πατήστε [Άνοιγμα].
   Όταν έχετε συνδεθεί στο GitHub, μπορείτε επίσης να επιλέξετε από τη λίστα στο [Επιλογή από τα αναγνώσιμα αποθετήρια].

> **Συμβουλή**
>
> - Το διπλανό εικονίδιο του GitHub ανοίγει στο github.com το έγγραφο που διαβάζετε. Δεν είναι ενέργεια ανοίγματος εγγράφων.

## Άνοιγμα μέσω URL

Η διεύθυνση παραθέτει τη θέση του αποθετηρίου και του εγγράφου όπως ακριβώς είναι. Η διαδρομή είναι η θέση μέσα στο αποθετήριο, οπότε η σειρά είναι η ίδια με τη διεύθυνση URL του GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Τι καθορίζετε | Τρόπος γραφής |
|---|---|
| Μόνο το αποθετήριο (προεπιλεγμένος κλάδος) | `/github/owner/repo` |
| Έγγραφο μέσα στο αποθετήριο | `/github/owner/repo/docs/01-product/vision.md` |
| Καθορισμός κλάδου ή ετικέτας | Προσθέστε στο τέλος `?ref=v1.2.0` |

Καθώς μετακινείστε σε άλλη σελίδα, αλλάζει και η διεύθυνση. Πατήστε [Κοινοποίηση αυτού του εγγράφου] στη γραμμή εργαλείων για να δώσετε σε κάποιον τον σύνδεσμο της σελίδας που διαβάζετε. Λειτουργούν επίσης τα [Πίσω] και [Εμπρός] του προγράμματος περιήγησης.

Η παλαιότερη μορφή με `?source=` ανοίγει όπως και πριν. Μετά το άνοιγμα, μετατρέπεται στη νέα μορφή.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Σημείωση**
>
> - Χωρίς σύνδεση ισχύει το όριο χρήσης του API του GitHub (60 φορές ανά ώρα). Σε αποθετήρια με πολλά έγγραφα ή σε επαναλαμβανόμενη ανάγνωση, επιλέξτε [Σύνδεση με GitHub].
> - Τα ονόματα κλάδων που περιέχουν `/` (όπως `feature/xxx`) μπορούν να καθοριστούν με το `?ref=` της παραπάνω μορφής διεύθυνσης. Στη μορφή `?source=` δεν γράφονται.
> - Τα έγγραφα φορτώνονται με τα δικαιώματα GitHub του αναγνώστη. Σε όσους δεν έχουν δικαίωμα ανάγνωσης δεν εμφανίζονται.

## Άνοιγμα εγγράφων από τοπικό φάκελο

Πατήστε [Άνοιγμα εγγράφων] στη γραμμή εργαλείων και, από το [Άνοιγμα εγγράφων από τοπικό φάκελο] κάτω από τη λίστα, επιλέξτε έναν φάκελο στη συσκευή σας. Τα αρχεία επεξεργάζονται μέσα στο πρόγραμμα περιήγησης και δεν αποστέλλονται προς τα έξω. Λειτουργεί σε προγράμματα περιήγησης που υποστηρίζουν την επιλογή φακέλου (Chrome, Edge και άλλα).
