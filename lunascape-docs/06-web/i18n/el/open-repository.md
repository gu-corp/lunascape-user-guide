# Άνοιγμα αποθετηρίου GitHub

Στην έκδοση Web και στο Lunascape μπορείτε να ανοίξετε ένα αποθετήριο GitHub και να το διαβάσετε απευθείας, χωρίς να δημιουργήσετε αντίγραφο. Τα δημόσια αποθετήρια δεν απαιτούν σύνδεση.

## Άνοιγμα από την οθόνη

1. Στη γραμμή εργαλείων, πατήστε [Άνοιγμα εγγράφων] (το εικονίδιο φακέλου). Ανοίγει η οθόνη «Άνοιγμα εγγράφων».
2. Στην αριστερή στήλη, επιλέξτε από πού θα ανοίξετε.

   | Θέση | Τι εμφανίζεται |
   |---|---|
   | Όλα | Όλα τα παρακάτω. Όσα ανοίξατε πρόσφατα εμφανίζονται πρώτα |
   | Πρόσφατα | Τα αποθετήρια και οι φάκελοι που έχετε ανοίξει |
   | Προτεινόμενα | Τα εγχειρίδια που προτείνει ο ιστότοπος |
   | Αποθετήρια GitHub | Όταν έχετε συνδεθεί στο GitHub, τα αποθετήρια που μπορείτε να διαβάσετε |
   | Αυτός ο υπολογιστής | Φάκελοι σε αυτήν τη συσκευή. Στο Lunascape εμφανίζονται εδώ και τα αποθετήρια των οποίων έχετε δημιουργήσει αντίγραφο |

3. Πατήστε [Άνοιγμα] στη γραμμή που θέλετε. Για να περιορίσετε τις γραμμές, πληκτρολογήστε στο πεδίο [Φιλτράρισμα κατά όνομα εγγράφου ή αποθετηρίου] στο επάνω μέρος.

Για ένα αποθετήριο που δεν υπάρχει στη λίστα, χρησιμοποιήστε το [Εισαγωγή owner/repo και άνοιγμα] στην αριστερή στήλη.

> **Συμβουλή**
>
> - Η λίστα δείχνει τα αποθετήρια GitHub στα οποία είναι εγκατεστημένη η εφαρμογή GitHub «Lunascape Docs» και για τα οποία έχετε δικαίωμα ανάγνωσης. Αν δεν βρίσκετε κάποιο αποθετήριο, ζητήστε από τον κάτοχό του να προσθέσει την εφαρμογή.

## Έλεγχος της θέσης του εγγράφου

Το μικρό εικονίδιο στο αριστερό μέρος της γραμμής εργαλείων (η ένδειξη θέσης) δείχνει πού βρίσκεται το έγγραφο που διαβάζετε.

| Εικονίδιο | Θέση |
|---|---|
| Το σήμα του GitHub | Διαβάζετε από το GitHub. Δεν αποθηκεύεται τίποτα σε αυτήν τη συσκευή |
| Φορητός υπολογιστής | Φάκελος σε αυτήν τη συσκευή που διαχειρίζεται το Lunascape. Εμφανίζονται επίσης το όνομα του κλάδου Git και ο αριθμός των αρχείων που έχουν αλλάξει |
| Φάκελος | Φάκελος σε αυτήν τη συσκευή |

Πατήστε το εικονίδιο για να δείτε τη θέση, την κατάστασή της και τις ενέργειες που μπορείτε να κάνετε από εκεί, όπως [Προβολή στο GitHub] και [Αντιγραφή συνδέσμου].

## Δημιουργία αντιγράφου αποθετηρίου στο Lunascape

Στο Lunascape μπορείτε να δημιουργήσετε αντίγραφο ενός αποθετηρίου GitHub σε αυτήν τη συσκευή. Στη συνέχεια, μπορείτε να το επεξεργαστείτε και να υποβάλετε αλλαγές με το Git.

- Στην οθόνη «Άνοιγμα εγγράφων», πατήστε [Δημιουργία αντιγράφου] στη γραμμή του αποθετηρίου.
- Αν διαβάζετε ένα αποθετήριο που ανοίξατε από το GitHub, πατήστε την ένδειξη θέσης και έπειτα [Δημιουργία αντιγράφου σε αυτόν τον υπολογιστή]. Όταν ολοκληρωθεί η δημιουργία του αντιγράφου, το ίδιο έγγραφο ανοίγει από το αντίγραφο αυτής της συσκευής.

Όταν έχετε δημιουργήσει αντίγραφο ενός αποθετηρίου, η λίστα το δείχνει με την ένδειξη «Σε αυτόν τον υπολογιστή» και το [Άνοιγμα σε αυτόν τον υπολογιστή] εμφανίζεται πρώτο.

## Άνοιγμα με URL

Η διεύθυνση περιέχει το αποθετήριο και τη θέση του εγγράφου με τη σειρά. Η διαδρομή είναι η θέση του εγγράφου μέσα στο αποθετήριο, γι' αυτό η σειρά είναι ίδια με εκείνη του URL στο GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Τι καθορίζετε | Μορφή |
|---|---|
| Μόνο το αποθετήριο (προεπιλεγμένος κλάδος) | `/github/owner/repo` |
| Έγγραφο μέσα στο αποθετήριο | `/github/owner/repo/docs/01-product/vision.md` |
| Κλάδος ή ετικέτα | Προσθέστε `?ref=v1.2.0` στο τέλος |

Η διεύθυνση αλλάζει όταν πηγαίνετε σε άλλη σελίδα. Για να στείλετε σε κάποιον τον σύνδεσμο της σελίδας που διαβάζετε, πατήστε [Κοινοποίηση αυτού του εγγράφου] στη γραμμή εργαλείων. Λειτουργούν επίσης τα κουμπιά [Πίσω] και [Εμπρός] του προγράμματος περιήγησης.

Η παλαιότερη μορφή `?source=` εξακολουθεί να λειτουργεί. Όταν ανοίξει η σελίδα, η διεύθυνση αλλάζει στη νέα μορφή.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Σημείωση**
>
> - Χωρίς σύνδεση, ισχύει το όριο χρήσης του GitHub API (60 αιτήματα την ώρα). Αν το αποθετήριο έχει πολλά έγγραφα ή αν το διαβάζετε συχνά, πατήστε [Σύνδεση με GitHub].
> - Ονόματα κλάδων που περιέχουν `/` (όπως `feature/xxx`) μπορούν να οριστούν με `?ref=` στη μορφή διεύθυνσης που περιγράφεται παραπάνω. Η μορφή `?source=` δεν τα υποστηρίζει.
> - Τα έγγραφα φορτώνονται με τα δικαιώματα GitHub του αναγνώστη. Όσοι δεν έχουν δικαίωμα ανάγνωσης δεν τα βλέπουν.

## Άνοιγμα εγγράφων από τοπικό φάκελο

Πατήστε [Άνοιγμα εγγράφων] στη γραμμή εργαλείων. Έπειτα πατήστε [Άνοιγμα εγγράφων από τοπικό φάκελο] στην αριστερή στήλη και επιλέξτε έναν φάκελο στη συσκευή σας. Τα αρχεία επεξεργάζονται μέσα στο πρόγραμμα περιήγησης και δεν αποστέλλονται πουθενά. Η λειτουργία είναι διαθέσιμη σε προγράμματα περιήγησης που υποστηρίζουν την επιλογή φακέλου (Chrome, Edge κ.λπ.).
