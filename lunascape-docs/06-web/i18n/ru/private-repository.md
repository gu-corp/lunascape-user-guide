# Просмотр закрытого репозитория

Документы закрытых репозиториев можно просматривать после входа через GitHub — только в тех репозиториях, к которым у вас есть доступ на чтение. У Lunascape Docs нет собственных учетных записей или прав.

## Вход и открытие

1. Откройте <https://docs.lunascape.org/>.
   Если вы указали закрытый документ или еще не вошли, появляется экран входа.
2. Нажмите [Войти через GitHub].
   Экран авторизации GitHub открывается во всплывающем окне.
3. После входа нажмите [Открыть документы] на панели инструментов и выберите нужный репозиторий в [Выбрать из доступных репозиториев].

> **Совет**
>
> - Имя учетной записи, под которой выполнен вход, отображается на панели инструментов. Отсюда же можно [Выйти] или [Войти с другой учетной записью].
> - В списке показываются репозитории тех учетных записей (организаций или пользователей), где установлено приложение GitHub «Lunascape Docs», — только те, к которым у вас есть доступ на чтение.

## Настройка со стороны владельца репозитория

Если нужного репозитория нет в списке, владелец репозитория или администратор организации должен установить приложение GitHub «Lunascape Docs».

- Запрашиваемые права — Contents (чтение и запись) и Pull requests (чтение и запись). Чтение нужно для просмотра, запись — для запроса на публикацию из Web (Pull Request). Содержимое документов Lunascape Docs не сохраняет.
- Приложение устанавливается на учетную запись (организацию или пользователя). Выберите, охватить ли все репозитории — «All repositories» (в том числе автоматически те, что будут созданы позже) — или только выбранные.

| Ситуация | Порядок действий |
|---|---|
| Впервые установить в организации или личной учетной записи | Выполните через [страницу установки](https://github.com/apps/lunascape-docs/installations/new) |
| Добавить репозитории в организации, где приложение уже установлено | Настройте в Settings организации → GitHub Apps → Lunascape Docs → Configure → Repository access |

Даже если приложение установлено на всю организацию, каждый участник может просматривать только те репозитории, к которым у него есть доступ на чтение. Отправлять запрос на публикацию можно только в те репозитории, к которым у него есть доступ на запись.

> **Совет**
> - При новой установке запрашиваемые права перечислены на экране установки, и нажатие «Install» означает их согласование. Дополнительных действий не требуется.
> - Организации, установившей приложение до того, как добавилось новое право, приходит письмо администраторам, а вверху страницы Settings организации → GitHub Apps → Lunascape Docs → Configure появляется кнопка согласования. Пока согласование не выполнено, в этой организации доступен только просмотр, а при отправке запроса на публикацию показывается сообщение «Требуется предоставить право на запись».
> - С какими правами приложение установлено сейчас, можно проверить на той же странице Configure. Для личной учетной записи это Settings → Applications → Installed GitHub Apps.
> - Если нужный репозиторий был случайно исключен или приложение удалено, все вернется, если установить заново со [страницы установки](https://github.com/apps/lunascape-docs/installations/new). В сообщении об отклонении запроса на публикацию есть ссылка на экран для исправления.
> - Если со стороны репозитория запросы на публикацию принимать не нужно, укажите в `lunascape-docs.json` строку `"publish": { "enabled": false }`. Просмотр при этом остается доступным.
