# Возможности веб-версии

Веб-версия Lunascape Docs опубликована по адресу <https://docs.lunascape.org/>. Без установки вы читаете документы на GitHub так же, как обычный веб-сайт.

## Возможности

| Функция | Описание |
|---|---|
| Просмотр открытых репозиториев | Открывает документы открытого репозитория GitHub без входа |
| Просмотр закрытых репозиториев | После входа через GitHub открывает репозитории, к которым у вас есть доступ на чтение |
| Просмотр локальных папок | [Открыть документы] → [Открыть документы из локальной папки] открывает папку на вашем устройстве (только в поддерживаемых браузерах) |
| Функции просмотра | INDEX, ссылки, история, фильтрация, оглавление страницы, переключение языка и темы. Так же, как в версии для VS Code |
| Схемы и формулы | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, формулы KaTeX |
| Черновики | Правьте документы и сохраняйте изменения как черновики на устройстве. В репозиторий ничего не записывается |
| Прямые ссылки на страницу | В URL можно указать репозиторий и страницу и открыть нужную страницу напрямую |

## Отличия от версии для VS Code

- Проверки документов, создание по шаблону, подготовка перевода и упорядочивание из INDEX в веб-версии недоступны.
- Схемы TikZ не отображаются.
- Правки не записываются в репозиторий, а становятся черновиками на устройстве. «Запрос на публикацию», отправляющий черновики как Pull Request, реализован, но в открытом просмотрщике не включен. Чтобы изменения попали в репозиторий, правьте документы в версии для VS Code или в локальной копии.
