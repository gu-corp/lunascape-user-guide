# Открытие репозитория GitHub

В веб-версии документы открываются по указанию репозитория GitHub. Для публичных репозиториев вход не требуется.

## Открытие с экрана

1. Откройте <https://docs.lunascape.org/>.
2. Нажмите [Открыть документы] (значок папки) на панели инструментов.
3. Введите репозиторий в поле [Указать репозиторий] и нажмите [Открыть].
   Если вы вошли в GitHub, можно также выбрать репозиторий из списка [Выбрать из доступных репозиториев].

> **Совет**
>
> - Значок GitHub рядом открывает читаемый сейчас документ на github.com. Это не команда открытия документов.

## Открытие по URL

Адрес составляется из репозитория и пути к документу в том же порядке, что и в самом репозитории. Путь указывается относительно репозитория, поэтому адрес совпадает по строению с URL на GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Что указывается | Как записывается |
|---|---|
| Только репозиторий (ветка по умолчанию) | `/github/owner/repo` |
| Документ внутри репозитория | `/github/owner/repo/docs/01-product/vision.md` |
| Ветка или тег | в конце добавляется `?ref=v1.2.0` |

При переходе по страницам адрес меняется. Нажмите [Поделиться этим документом] на панели инструментов, чтобы передать ссылку на читаемую сейчас страницу. Кнопки браузера [Назад] и [Вперед] тоже работают.

Прежняя форма с `?source=` открывается по-прежнему. После открытия адрес переписывается в новую форму.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Примечание**
>
> - Без входа действует ограничение GitHub API (60 запросов в час). Для репозиториев с большим числом документов и при частом чтении выполните [Войти через GitHub].
> - Имена веток с символом `/` (например, `feature/xxx`) указываются через `?ref=` в адресе описанного выше вида. В форме `?source=` их записать нельзя.
> - Документы загружаются с правами GitHub самого читателя. Тем, у кого нет прав на чтение, они не показываются.

## Открытие документов из локальной папки

Нажмите [Открыть документы] на панели инструментов, затем [Открыть документы из локальной папки] под списком и выберите папку на устройстве. Файлы обрабатываются внутри браузера и никуда не передаются. Это работает в браузерах с поддержкой выбора папки (Chrome, Edge и других).
