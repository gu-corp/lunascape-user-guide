# Открытие репозитория GitHub

В веб-версии и в Lunascape репозиторий GitHub можно открыть и читать как есть, без клонирования. Для публичных репозиториев вход не нужен.

## Открытие с экрана

1. Нажмите [Открыть документы] (значок папки) на панели инструментов. Откроется экран «Открыть документы».
2. В левой колонке выберите, где искать.

   | Место | Что в нем показано |
   |---|---|
   | Все | Все перечисленное ниже. Недавно открытое показано первым |
   | Недавние | Репозитории и папки, которые вы уже открывали |
   | Рекомендуемые | Руководства, которые предлагает сайт |
   | Репозитории GitHub | Если вы вошли в GitHub, — репозитории, которые вы можете читать |
   | Этот компьютер | Папки на этом устройстве. В Lunascape здесь также показаны клонированные репозитории |

3. Нажмите [Открыть] в нужной строке. Чтобы сократить список, введите текст в поле [Фильтр по имени документа или репозитория] вверху.

Если репозитория нет в списке, укажите его с помощью [Ввести owner/repo и открыть] в левой колонке.

> **Совет**
>
> - В списке показаны репозитории GitHub, в которых установлено GitHub App «Lunascape Docs» и к которым у вас есть доступ на чтение. Если нужного репозитория нет, попросите его владельца добавить это приложение.

## Где находится документ

Небольшой значок в левой части панели инструментов (индикатор расположения) показывает, где находится документ, который вы читаете.

| Значок | Расположение |
|---|---|
| Логотип GitHub | Документ читается с GitHub. На этом устройстве он не сохранен |
| Компьютер | Папка на этом устройстве, которой управляет Lunascape. Также показаны имя ветки Git и число измененных файлов |
| Папка | Папка на этом устройстве |

Нажмите значок, чтобы увидеть расположение, состояние и доступные действия ([Посмотреть на GitHub], [Копировать ссылку] и т. д.).

## Клонирование репозитория в Lunascape

В Lunascape репозиторий GitHub можно клонировать на это устройство, а затем редактировать файлы и делать коммиты в Git.

- На экране «Открыть документы» нажмите [Дублировать] в строке репозитория.
- Если вы читаете репозиторий, открытый с GitHub, нажмите индикатор расположения, затем [Клонировать на этот компьютер]. Когда клонирование завершится, тот же документ откроется из копии на этом устройстве.

Клонированный репозиторий отмечен в списке надписью «На этом компьютере», а первой в его строке стоит кнопка [Открыть на этом компьютере].

## Открытие по URL

Адрес состоит из имени репозитория и пути к документу. Путь — это расположение внутри репозитория, поэтому части адреса идут в том же порядке, что и в URL на GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Что указать | Как записать |
|---|---|
| Только репозиторий (ветка по умолчанию) | `/github/owner/repo` |
| Документ внутри репозитория | `/github/owner/repo/docs/01-product/vision.md` |
| Ветка или тег | Добавьте в конец `?ref=v1.2.0` |

При переходе между страницами адрес тоже меняется. Чтобы передать ссылку на страницу, которую вы читаете, нажмите [Поделиться этим документом] на панели инструментов. Кнопки браузера [Назад] и [Вперед] тоже работают.

Прежний формат `?source=` по-прежнему открывается. После открытия адрес заменяется новым форматом.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Примечание**
>
> - Без входа действует ограничение GitHub API (60 запросов в час). Для репозиториев с большим числом документов или при частом просмотре нажмите [Войти через GitHub].
> - Имя ветки с символом `/` (например, `feature/xxx`) можно указать через `?ref=` в формате адреса, описанном выше. В формате `?source=` такое имя записать нельзя.
> - Документы загружаются с правами GitHub самого читателя. Тем, у кого нет доступа на чтение, они не показываются.

## Открытие документов из локальной папки

Нажмите [Открыть документы] на панели инструментов, затем в левой колонке нажмите [Открыть документы из локальной папки] и выберите папку на устройстве. Файлы обрабатываются в браузере и никуда не отправляются. Функция работает в браузерах, которые поддерживают выбор папки (Chrome, Edge и др.).
