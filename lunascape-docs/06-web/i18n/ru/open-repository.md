# Открытие репозитория GitHub

В веб-версии репозиторий GitHub можно открыть и читать как есть, без клонирования. Для публичных репозиториев вход не требуется.

## Открытие с экрана

1. Нажмите [Открыть документы] (значок папки) на панели инструментов. Откроется экран «Открыть документы».
2. В левой колонке выберите, где искать.

   | Место | Что отображается |
   |---|---|
   | Все | Все, что ниже. Недавно открытые отображаются в начале списка |
   | Недавно открытые | Репозитории и папки, которые вы открывали |
   | Рекомендуемые | Руководства, которые представлены на сайте |
   | Репозитории GitHub | Если вы вошли через GitHub, — репозитории, которые вам доступны для чтения |
   | Этот компьютер | Папки на этом устройстве |

3. Нажмите [Открыть] в нужной строке. Чтобы сузить список, введите текст в поле [Фильтр по имени документа или репозитория] вверху.

Репозиторий, которого нет в списке, укажите с помощью [Ввести owner/repo и открыть] в левой колонке.

> **Совет**
>
> - В списке показаны репозитории GitHub, в которых установлено приложение GitHub App «Lunascape Docs» и к которым у вас есть доступ на чтение. Если нужного репозитория нет, попросите его владельца добавить это приложение.

## Проверка расположения документа

Небольшой значок в левой части панели инструментов (метка расположения) показывает, где находится документ, который вы читаете.

| Значок | Расположение |
|---|---|
| Логотип GitHub | Документ читается с GitHub. На этом устройстве он не сохранен |
| Папка | Папка на этом устройстве |

Нажмите значок, чтобы увидеть расположение, состояние и доступные действия ([Посмотреть на GitHub], [Копировать ссылку] и др.).

## Открытие по URL

Адрес состоит из имени репозитория и пути к документу. Путь указывает расположение внутри репозитория, поэтому части адреса идут в том же порядке, что и в URL на GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Что указать | Как записать |
|---|---|
| Только репозиторий (ветка по умолчанию) | `/github/owner/repo` |
| Документ в репозитории | `/github/owner/repo/docs/01-product/vision.md` |
| Ветка или тег | Добавьте в конце `?ref=v1.2.0` |

При переходе на другую страницу адрес тоже меняется. Чтобы передать ссылку на страницу, которую вы читаете, нажмите [Поделиться этим документом] на панели инструментов. Кнопки браузера [Назад] и [Вперед] тоже работают.

Адреса в прежнем формате `?source=` по-прежнему открываются. После открытия адрес заменяется на новый формат.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Внимание**
>
> - Без входа действует ограничение GitHub API (60 запросов в час). Для репозиториев с большим количеством документов и при частом просмотре нажмите [Войти через GitHub].
> - Имена веток, содержащие `/` (например, `feature/xxx`), можно указать через `?ref=` в формате адреса, описанном выше. В формате `?source=` их записать нельзя.
> - Документы загружаются с правами GitHub того, кто их читает. Пользователи без доступа на чтение их не увидят.

## Открытие документов из локальной папки

Нажмите [Открыть документы] на панели инструментов, затем в левой колонке нажмите [Открыть документы из локальной папки] и выберите папку на устройстве. Файлы обрабатываются в браузере и никуда не передаются. Функция доступна в браузерах, которые поддерживают выбор папки (Chrome, Edge и др.).
