# Публикация ваших документов в Интернете

Документы вашего репозитория можно опубликовать как веб-сайт на GitHub Pages или на любом статическом хостинге. Есть два способа. Эти шаги предназначены для разработчиков, которые могут клонировать репозиторий Lunascape Docs и работать с `npm`.

## Способ 1: разместить два файла средства просмотра

Разместите только средство просмотра (`index.html` и `lsdoc.js`), а документы оно загрузит с GitHub. Сами документы не входят в состав сайта, поэтому способ безопасен и для закрытых репозиториев (читатели входят через GitHub).

1. Выполните в репозитории Lunascape Docs следующую команду.

   ```sh
   npm run build:viewer
   ```

   В папке `dist/viewer/` будут созданы `index.html` и `lsdoc.js`.
2. Поместите оба файла в папку `docs/` того репозитория, который вы хотите опубликовать.
3. Включите GitHub Pages.

Корень документации для отображения определяется в следующем порядке.

1. Параметр `source` внутри `index.html`
2. Значение `repository` в файле `lunascape-docs.json` в той же папке
3. Определение по URL-адресу `*.github.io` и структуре веток

## Способ 2: выгрузить статический сайт вместе с документами

Выгрузите средство просмотра вместе с файлами документов и разместите результат как есть.

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

Выгружаются файлы средства просмотра, документы из папки `docs/`, файл списка `lunascape-docs-manifest.json` и `.nojekyll`. Разместите результат на S3 или GitHub Pages, чтобы опубликовать его. Пример автоматической публикации через GitHub Actions см. в файле `examples/workflows/publish-docs-pages.yml` в репозитории.

> **Примечание**
>
> - **Не выгружайте документы закрытого репозитория на GitHub Pages.** За пределами Enterprise Cloud страницы GitHub Pages доступны для просмотра всем. Если нужна ограниченная публикация, используйте способ 1 и предложите читателям войти через GitHub.
> - Открыть `index.html` напрямую по протоколу `file://` не получится: браузер запрещает загрузку соседних файлов и выполнение модулей ES. Для локальной проверки используйте версию для VS Code или HTTP-сервер.
> - Библиотеки отрисовки для TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob и Penrose загружаются при отображении. Вместе с выгруженным сайтом разместите и папку `vendor/`.
