# Сохранение черновика

Когда вы редактируете документ в веб-версии, изменения не записываются в репозиторий, а сохраняются внутри браузера как «черновик».

## Создание черновика

1. Откройте документ и нажмите [Редактировать] в правом нижнем углу.
2. Внесите изменения и нажмите [Сохранить].
   Появится сообщение «Сохранено как черновик», и изменения будут сохранены в браузере.

- У документов с черновиком в INDEX появляется значок. Над текстом выводится сообщение «Этот документ — черновик на данном устройстве (не опубликован)».
- Кнопка [Черновики] на панели инструментов показывает количество черновиков; при нажатии открывается их список.

## Удаление черновика

- Чтобы удалить черновик отдельного документа, нажмите [Удалить черновик] над текстом.
- Чтобы удалить все черновики, воспользуйтесь списком черновиков.

## Перенос изменений в репозиторий

Запрос на публикацию, который отправляет черновики в виде Pull Request, реализован, но в публичной версии просмотра не включён. Чтобы внести изменения в репозиторий, редактируйте документ в версии для VS Code или в локальной копии репозитория.

> **Примечание**
>
> - Черновики хранятся в браузере (IndexedDB). Они не переносятся в другой браузер или на другое устройство. Если очистить данные сайта в браузере, черновики также будут удалены.
> - Если после создания черновика документ в репозитории был изменён, выводится сообщение «Исходная версия обновлена». Просмотрите содержимое и решите, удалить черновик или продолжить работу с ним.
> - Если вы открыли локальную папку через [Открыть документы] и редактируете её, изменения записываются прямо в файл — при условии, что браузер это поддерживает. В браузерах без такой поддержки изменения сохраняются только на время текущего сеанса.
