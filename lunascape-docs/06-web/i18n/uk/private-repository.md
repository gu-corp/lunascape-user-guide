# Перегляд приватного репозиторію

Документи приватних репозиторіїв можна переглядати після входу через GitHub — лише ті репозиторії, до яких у вас є право читання. Lunascape Docs не має власних облікових записів чи прав доступу.

## Вхід і відкриття

1. Відкрийте <https://docs.lunascape.org/>.
   Якщо ви вказали приватний документ або ще не увійшли, з’явиться екран входу.
2. Натисніть [Увійти через GitHub].
   У спливному вікні відкриється екран авторизації GitHub.
3. Після входу натисніть [Відкрити документи] на панелі інструментів і виберіть потрібний репозиторій у [Вибрати з доступних для читання репозиторіїв].

> **Порада**
>
> - Ім’я облікового запису, під яким виконано вхід, показується на панелі інструментів. Звідси також можна [Вийти] або [Увійти з іншим обліковим записом].
> - У списку показуються ті репозиторії облікових записів (організацій або особистих), де встановлено GitHub App «Lunascape Docs», до яких у вас є право читання.

## Налаштування, які виконує власник репозиторію

Якщо потрібного репозиторію немає в списку, власник репозиторію або адміністратор організації має встановити GitHub App «Lunascape Docs».

- Запитувані права — Contents (читання й запис) та Pull requests (читання й запис). Читання потрібне для перегляду, запис — для запиту на публікацію з вебу (Pull Request). Lunascape Docs не зберігає вмісту документів.
- Одиниця встановлення — обліковий запис (організація або особистий). Налаштовується, чи охоплювати «All repositories» (включно з репозиторіями, створеними надалі), чи лише вибрані репозиторії.

| Ситуація | Кроки |
|---|---|
| Нове встановлення в організації або особистому обліковому записі | Виконайте зі [сторінки встановлення](https://github.com/apps/lunascape-docs/installations/new) |
| Додавання репозиторіїв в організації, де вже встановлено | Налаштуйте у Settings організації → GitHub Apps → Lunascape Docs → Configure → Repository access |

Навіть якщо застосунок встановлено для всієї організації, кожен учасник може переглядати лише ті репозиторії, до яких має право читання. Надіслати запит на публікацію можна лише до тих репозиторіїв, до яких у нього є право запису.

> **Порада**
> - Під час нового встановлення запитувані права показуються списком на екрані встановлення, і натискання «Install» означає їх схвалення. Додаткових дій не потрібно.
> - Організація, яка встановила застосунок до того, як права було розширено, отримує лист адміністраторам, а вгорі Settings організації → GitHub Apps → Lunascape Docs → Configure з’являється кнопка схвалення. Доки схвалення немає, у цій організації доступний лише перегляд, а надсилання запиту на публікацію показує «Потрібно надати право запису».
> - Які саме права наразі надано, видно на тому самому екрані Configure. Для особистого облікового запису це Settings → Applications → Installed GitHub Apps.
> - Якщо потрібний репозиторій випадково прибрали або застосунок видалили, повернути все можна, встановивши знову зі [сторінки встановлення](https://github.com/apps/lunascape-docs/installations/new). Повідомлення про відхилений запит на публікацію містить посилання на екран для виправлення.
> - Якщо на боці репозиторію не потрібно приймати запити на публікацію, впишіть у `lunascape-docs.json` рядок `"publish": { "enabled": false }`. Перегляд працюватиме як і раніше.
