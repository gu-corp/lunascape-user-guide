# Відкриття репозиторію GitHub

У вебверсії документи відкриваються через зазначення репозиторію GitHub. Для відкритих репозиторіїв вхід не потрібен.

## Відкриття з екрана

1. Відкрийте <https://docs.lunascape.org/>.
2. Натисніть [Відкрити документи] (значок папки) на панелі інструментів.
3. Введіть репозиторій у полі [Вказати репозиторій] і натисніть [Відкрити].
   Якщо ви ввійшли до GitHub, можна також вибрати зі списку в розділі [Вибрати з доступних для читання репозиторіїв].

> **Порада**
>
> - Значок GitHub поруч відкриває документ, який ви зараз читаєте, на github.com. Це не дія відкриття документів.

## Відкриття за URL

Адреса складається з репозиторію та розташування документа, записаних поспіль. Шлях — це розташування всередині репозиторію, тому порядок такий самий, як в URL GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Що вказати | Як записати |
|---|---|
| Лише репозиторій (гілка за замовчуванням) | `/github/owner/repo` |
| Документ усередині репозиторію | `/github/owner/repo/docs/01-product/vision.md` |
| Гілка або тег | у кінці додайте `?ref=v1.2.0` |

Під час переходу між сторінками адреса змінюється. Натисніть [Поділитися цим документом] на панелі інструментів, щоб передати посилання на сторінку, яку ви читаєте. Кнопки браузера [Назад] і [Вперед] також працюють.

Попередній формат `?source=` відкривається, як і раніше. Після відкриття він переписується на новий.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Примітка**
>
> - Без входу діє обмеження GitHub API (60 запитів на годину). Для репозиторіїв із великою кількістю документів або для повторного перегляду скористайтеся [Увійти через GitHub].
> - Назви гілок із символом `/` (наприклад, `feature/xxx`) можна вказати через `?ref=` у наведеному вище форматі адреси. У форматі `?source=` їх записати не можна.
> - Документи завантажуються з правами GitHub самого читача. Людям без права на читання вони не відображаються.

## Відкриття документів із локальної папки

Натисніть [Відкрити документи] на панелі інструментів, а потім [Відкрити документи з локальної папки] під списком і виберіть папку на своєму пристрої. Файли обробляються всередині браузера й нікуди не надсилаються. Це працює у браузерах із підтримкою вибору папки (Chrome, Edge тощо).
