# Відкриття репозиторію GitHub

У веб-версії та в Lunascape репозиторій GitHub можна відкрити й читати безпосередньо, не клонуючи його. Для публічних репозиторіїв входити не потрібно.

## Відкриття з екрана

1. Натисніть [Відкрити документи] (значок папки) на панелі інструментів. Відкриється екран «Відкрити документи».
2. У стовпці ліворуч виберіть, де шукати.

   | Місце | Що відображається |
   |---|---|
   | Усі | Усе, що нижче. Нещодавно відкриті елементи йдуть першими |
   | Нещодавно відкриті | Репозиторії та папки, які ви вже відкривали |
   | Рекомендовані | Посібники, які рекомендує сайт |
   | Репозиторії GitHub | Якщо ви ввійшли через GitHub, тут відображаються репозиторії, які ви можете читати |
   | Цей комп’ютер | Папки на цьому пристрої. У Lunascape тут також відображаються клоновані репозиторії |

3. Натисніть [Відкрити] у потрібному рядку. Щоб відфільтрувати рядки, введіть текст у поле [Фільтр за назвою документа або репозиторію] вгорі.

Якщо репозиторію немає у списку, вкажіть його через [Ввести owner/repo і відкрити] у стовпці ліворуч.

> **Порада**
>
> - У списку відображаються репозиторії GitHub, у яких установлено GitHub App «Lunascape Docs» і до яких ви маєте доступ на читання. Якщо потрібного репозиторію немає, попросіть власника репозиторію додати App.

## Визначення розташування документа

Невеликий значок ліворуч на панелі інструментів (чип розташування) показує, де зберігається документ, який ви зараз читаєте.

| Значок | Розташування |
|---|---|
| Логотип GitHub | Документ читається з GitHub. На цьому пристрої його не збережено |
| Комп’ютер | Папка на цьому пристрої, якою керує Lunascape. Також відображаються назва гілки Git і кількість змінених файлів |
| Папка | Папка на цьому пристрої |

Натисніть значок, щоб побачити розташування, стан і доступні дії, як-от [Переглянути на GitHub] і [Копіювати посилання].

## Клонування репозиторію в Lunascape

У Lunascape можна клонувати репозиторій GitHub на цей пристрій, а потім редагувати файли й створювати коміти за допомогою Git.

- На екрані «Відкрити документи» натисніть [Дублювати] у рядку репозиторію.
- Якщо ви читаєте репозиторій, відкритий із GitHub, натисніть чип розташування, а потім [Клонувати на цей комп’ютер]. Після завершення клонування той самий документ відкриється з копії на цьому пристрої.

Клоновані репозиторії позначено у списку як «Є на цьому комп’ютері», а дія [Відкрити на цьому комп’ютері] стоїть першою.

## Відкриття за URL-адресою

Адреса складається з назви репозиторію та розташування документа в ньому. Шлях вказує розташування в репозиторії, тому частини йдуть у тому самому порядку, що й в URL-адресі GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Що вказати | Як записати |
|---|---|
| Лише репозиторій (гілка за замовчуванням) | `/github/owner/repo` |
| Документ у репозиторії | `/github/owner/repo/docs/01-product/vision.md` |
| Гілка або тег | Додайте в кінці `?ref=v1.2.0` |

Під час переходу між сторінками адреса також змінюється. Щоб передати посилання на сторінку, яку ви зараз читаєте, натисніть [Поділитися цим документом] на панелі інструментів. Також працюють кнопки браузера [Назад] і [Вперед].

Старий формат `?source=` теж відкривається, як і раніше. Після відкриття адресу буде замінено на новий формат.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Увага**
>
> - Без входу діє обмеження GitHub API (60 запитів на годину). Якщо в репозиторії багато документів або ви переглядаєте його часто, натисніть [Увійти через GitHub].
> - Назви гілок, що містять `/` (наприклад, `feature/xxx`), можна вказати через `?ref=` у форматі адреси, описаному вище. У форматі `?source=` їх записати не можна.
> - Документи завантажуються з правами GitHub того, хто їх переглядає. Користувачі без доступу на читання їх не бачать.

## Відкриття документів із локальної папки

Натисніть [Відкрити документи] на панелі інструментів, потім у стовпці ліворуч натисніть [Відкрити документи з локальної папки] і виберіть папку на пристрої. Файли обробляються в браузері й нікуди не надсилаються. Ця функція працює в браузерах, які підтримують вибір папки (Chrome, Edge тощо).
