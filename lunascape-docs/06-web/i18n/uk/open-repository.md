# Відкриття репозиторію GitHub

У вебверсії можна відкрити й читати репозиторій GitHub безпосередньо, не клонуючи його. Для загальнодоступних репозиторіїв вхід не потрібен.

## Відкриття з екрана

1. Натисніть [Відкрити документи] (значок папки) на панелі інструментів. Відкриється екран «Відкрити документи».
2. На лівій панелі виберіть місце, звідки відкривати.

   | Місце | Що відображається |
   |---|---|
   | Усі | Усе, що нижче. Нещодавно відкрите відображається першим |
   | Нещодавно відкриті | Репозиторії та папки, які ви вже відкривали |
   | Рекомендовані | Посібники, які пропонує сайт |
   | Репозиторії GitHub | Якщо ви ввійшли через GitHub — репозиторії, які ви можете читати |
   | Цей комп’ютер | Папки на цьому пристрої |

3. Натисніть [Відкрити] у потрібному рядку. Щоб відфільтрувати рядки, введіть текст у поле [Фільтр за назвою документа або репозиторію] угорі.

Репозиторій, якого немає в списку, вкажіть за допомогою [Ввести owner/repo і відкрити] на лівій панелі.

> **Порада**
>
> - У списку відображаються репозиторії GitHub, у яких установлено GitHub App «Lunascape Docs» і до яких у вас є доступ на читання. Якщо потрібного репозиторію немає, попросіть його власника додати App.

## Перевірка розташування документа

Невеликий значок у лівій частині панелі інструментів (чип розташування) показує, де зберігається документ, який ви зараз читаєте.

| Значок | Розташування |
|---|---|
| Логотип GitHub | Документ читається з GitHub. На цьому пристрої він не зберігається |
| Папка | Папка на цьому пристрої |

Натисніть значок, щоб побачити розташування, стан і доступні дії ([Переглянути на GitHub], [Копіювати посилання] тощо).

## Відкриття за URL-адресою

Адреса складається з назви репозиторію та розташування документа. Шлях — це розташування всередині репозиторію, тому порядок такий самий, як в URL-адресі GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Що вказати | Як записати |
|---|---|
| Лише репозиторій (гілка за замовчуванням) | `/github/owner/repo` |
| Документ у репозиторії | `/github/owner/repo/docs/01-product/vision.md` |
| Гілка або тег | Додайте в кінці `?ref=v1.2.0` |

Під час переходу між сторінками адреса також змінюється. Щоб передати посилання на сторінку, яку ви читаєте, натисніть [Поділитися цим документом] на панелі інструментів. Кнопки браузера [Назад] і [Вперед] також працюють.

Адреси в попередньому форматі `?source=` відкриваються, як і раніше. Після відкриття адресу буде замінено на новий формат.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Увага**
>
> - Без входу діє обмеження GitHub API (60 запитів на годину). Для репозиторіїв із великою кількістю документів або для частого перегляду натисніть [Увійти через GitHub].
> - Назву гілки, що містить `/` (наприклад, `feature/xxx`), можна вказати за допомогою `?ref=` у наведеному вище форматі адреси. У форматі `?source=` її записати не можна.
> - Документи завантажуються з правами GitHub того, хто їх читає. Користувачі без доступу на читання їх не бачать.

## Відкриття документів із локальної папки

Натисніть [Відкрити документи] на панелі інструментів, потім на лівій панелі — [Відкрити документи з локальної папки] і виберіть папку на пристрої. Файли обробляються в браузері й нікуди не надсилаються. Ця функція працює в браузерах, що підтримують вибір папок (Chrome, Edge тощо).
