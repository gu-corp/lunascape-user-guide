# Що вміє вебверсія

Вебверсія Lunascape Docs доступна за адресою <https://docs.lunascape.org/>. Без жодного встановлення ви читаєте документи на GitHub так, ніби це вебсайт.

## Можливості

| Можливість | Опис |
|---|---|
| Перегляд публічних репозиторіїв | Відкриває документи публічного репозиторію GitHub без входу |
| Перегляд приватних репозиторіїв | Після входу через GitHub відкриває репозиторії, до яких ви маєте доступ на читання |
| Перегляд локальних папок | [Відкрити документи], далі [Відкрити документи з локальної папки] — відкриває папку на вашому пристрої (лише в підтримуваних браузерах) |
| Читання | INDEX, посилання, історія, фільтрування, зміст сторінки, перемикання мови та теми. Так само, як у версії для VS Code |
| Діаграми та формули | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, формули KaTeX |
| Чернетки | Редагує документи та зберігає зміни як чернетки на вашому пристрої. У репозиторій нічого не записується |
| Прямі посилання на сторінку | URL може вказувати репозиторій і сторінку, тож певну сторінку можна відкрити напряму |

## Відмінності від версії для VS Code

- Перевірки документів, створення з шаблонів, складання пропозицій перекладу та впорядкування з панелі INDEX у вебверсії відсутні.
- Діаграми TikZ не відображаються.
- Зміни не записуються в репозиторій, а стають чернетками на вашому пристрої. «Запит на публікацію», який надсилає чернетки як Pull Request, реалізовано, але в публічному переглядачі він не ввімкнений. Щоб внести зміни до репозиторію, редагуйте у версії для VS Code або у локальному клоні.
