# Web sürümünün yapabildikleri

Lunascape Docs'un Web tarayıcı sürümü <https://docs.lunascape.org/> adresinde yayımlanmaktadır. Hiçbir kurulum yapmadan, GitHub üzerindeki belgeleri bir web sitesi gibi okuyabilirsiniz.

## Yapabilecekleriniz

| Özellik | İçerik |
|---|---|
| Herkese açık depoları görüntüleme | Oturum açmadan, GitHub'daki herkese açık depoların belgelerini açar |
| Özel depoları görüntüleme | GitHub ile oturum açtığınızda, okuma yetkiniz olan depoları açabilirsiniz |
| Yerel klasörleri görüntüleme | [Belgeleri aç] içindeki [Yerel klasördeki belgeleri aç] ile cihazınızdaki bir klasörü açar (yalnızca desteklenen tarayıcılarda) |
| Görüntüleme özellikleri | INDEX, bağlantılar, geçmiş, süzme, sayfa içi içindekiler, dil değiştirme, tema değiştirme. VS Code sürümüyle aynıdır |
| Diyagram ve matematik | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, KaTeX matematik ifadeleri |
| Taslak | Belgeleri düzenler ve değişiklikleri cihazınızda taslak olarak saklar. Depoya yazmaz |
| Sayfaya doğrudan bağlantı | URL ile depoyu ve sayfayı belirterek belirli bir sayfayı doğrudan açabilirsiniz |

## VS Code sürümünden farkları

- Belge denetimi, şablondan oluşturma, çeviri önerisi üretme ve INDEX üzerinden düzenleme Web sürümünde yoktur.
- TikZ diyagramları çizilmez.
- Düzenlemeler depoya yazılmaz, cihazınızda taslak olarak kalır. Taslakları pull request olarak gönderen "yayımlama isteği" uygulanmıştır, ancak herkese açık görüntüleyicide etkin değildir. Depoya yansıtmak için VS Code sürümüyle veya yerel bir kopya üzerinde düzenleyin.
