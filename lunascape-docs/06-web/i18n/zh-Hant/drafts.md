# 儲存草稿

在 Web 版中編輯文件時，變更不會寫入存放庫，而是以「草稿」的形式儲存在瀏覽器內。

## 建立草稿

1. 開啟文件，按下右下角的 [編輯]。
2. 編輯後按下 [儲存]。
   畫面會顯示「已儲存為草稿」，變更即儲存在瀏覽器內。

- 有草稿的文件會在 INDEX 上顯示標記。內文上方會顯示「本文件是此裝置上的草稿（未發布）」。
- 工具列的 [草稿] 會顯示件數，按下後會開啟草稿清單。

## 捨棄草稿

- 要逐份文件捨棄時，請按下內文上方的 [捨棄草稿]。
- 要全部捨棄時，請從草稿清單操作。

## 套用到存放庫

將草稿以 Pull Request 送出的「發布請求」雖已實作，但在公開檢視器中並未啟用。若要套用到存放庫，請使用 VS Code 版或在本機複本中編輯。

> **注意**
>
> - 草稿儲存在瀏覽器（IndexedDB）中，不會沿用到其他瀏覽器或其他裝置。清除瀏覽器的網站資料後，草稿也會一併消失。
> - 建立草稿後，若存放庫端的文件有所更新，畫面會顯示「上游已更新」。請確認內容後，再判斷要捨棄草稿還是繼續使用。
> - 若是從 [開啟文件] 開啟本機資料夾進行編輯，在瀏覽器支援的情況下會直接儲存到檔案。在不支援的瀏覽器中，僅於該工作階段期間保留。
