# 開啟 GitHub 儲存庫

在 Web 版中，不必複製 GitHub 儲存庫，即可直接開啟並閱讀。公開儲存庫不需要登入。

## 從畫面開啟

1. 按下工具列中的 [開啟文件]（資料夾圖示）。「開啟文件」畫面隨即開啟。
2. 在左側欄位中，選擇要開啟的位置。

   | 位置 | 列出的項目 |
   |---|---|
   | 全部 | 以下所有項目。最近開啟的項目排在最前面 |
   | 最近開啟 | 先前開啟過的儲存庫與資料夾 |
   | 推薦 | 網站介紹的使用手冊 |
   | GitHub 儲存庫 | 使用 GitHub 登入時，您可讀取的儲存庫 |
   | 本機 | 此裝置上的資料夾 |

3. 在要開啟的那一列按下 [開啟]。在上方的 [依文件名稱或儲存庫名稱篩選] 中輸入文字，即可篩選列出的項目。

清單中沒有的儲存庫，請從左側欄位的 [輸入 owner/repo 以開啟] 指定。

> **提示**
>
> - 清單中列出的 GitHub 儲存庫，是已安裝 GitHub App「Lunascape Docs」且您具有讀取權限的儲存庫。若找不到，請向儲存庫的擁有者要求新增此 App。

## 確認文件的位置

工具列左側的小圖示（位置標籤）會顯示目前閱讀的文件位於何處。

| 圖示 | 位置 |
|---|---|
| GitHub 標誌 | 正從 GitHub 讀取。並未儲存在此裝置上 |
| 資料夾 | 此裝置上的資料夾 |

按下圖示，即會顯示位置與狀態，以及可從該處執行的操作（[在 GitHub 上檢視]、[複製連結] 等）。

## 以 URL 開啟

網址的形式是依序列出儲存庫與文件的位置。路徑是在儲存庫中的位置，因此排列方式與 GitHub 的 URL 相同。

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 指定內容 | 寫法 |
|---|---|
| 僅儲存庫（預設分支） | `/github/owner/repo` |
| 儲存庫中的文件 | `/github/owner/repo/docs/01-product/vision.md` |
| 指定分支或標籤 | 在結尾加上 `?ref=v1.2.0` |

切換頁面時，網址也會隨之變更。按下工具列的 [分享此文件]，即可分享目前閱讀頁面的連結。也可使用瀏覽器的 [返回] [前進]。

舊的 `?source=` 形式也與以往一樣可以開啟。開啟後會改寫為新的形式。

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **注意**
>
> - 未登入時，會受到 GitHub API 的使用限制（每小時 60 次）。若儲存庫中的文件很多，或需要重複閱覽，請 [使用 GitHub 登入]。
> - 含有 `/` 的分支名稱（例如 `feature/xxx`），可使用上述網址形式的 `?ref=` 指定。`?source=` 形式無法寫出這類名稱。
> - 文件會以閱覽者的 GitHub 權限載入。沒有讀取權限的人無法看到。

## 開啟本機資料夾中的文件

按下工具列的 [開啟文件]，再從左側欄位中的 [開啟本機資料夾中的文件] 選擇裝置中的資料夾。檔案會在瀏覽器中處理，不會傳送到外部。可在支援選擇資料夾的瀏覽器（Chrome、Edge 等）中使用。
