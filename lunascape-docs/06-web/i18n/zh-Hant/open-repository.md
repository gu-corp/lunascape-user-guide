# 開啟 GitHub 儲存庫

在 Web 版和 Lunascape 中，可以直接開啟並閱讀 GitHub 的儲存庫，不必先複製。公開儲存庫不需要登入。

## 從畫面開啟

1. 按工具列上的 [開啟文件]（資料夾圖示）。「開啟文件」畫面隨即開啟。
2. 在左側欄位中，選擇要開啟的位置。

   | 位置 | 列出的項目 |
   |---|---|
   | 全部 | 以下所有項目。最近開啟的項目排在最前面 |
   | 最近開啟 | 曾經開啟過的儲存庫和資料夾 |
   | 推薦 | 網站介紹的手冊 |
   | GitHub 儲存庫 | 已使用 GitHub 登入時，您可以閱讀的儲存庫 |
   | 這台電腦 | 本裝置上的資料夾。在 Lunascape 中，已複製的儲存庫也會列在這裡 |

3. 按要開啟的那一列的 [開啟]。在上方的 [依文件名稱或儲存庫名稱篩選] 中輸入文字，即可篩選列出的項目。

不在清單中的儲存庫，請從左側欄位的 [輸入 owner/repo 並開啟] 指定。

> **提示**
>
> - 清單中顯示的 GitHub 儲存庫，是已安裝 GitHub App「Lunascape Docs」且您具有讀取權限的儲存庫。找不到時，請向儲存庫擁有者要求新增此 App。

## 確認文件的位置

工具列左側的小圖示（位置標籤）會顯示目前閱讀的文件位於何處。

| 圖示 | 位置 |
|---|---|
| GitHub 標誌 | 正在從 GitHub 讀取。並未儲存在本裝置上 |
| 電腦 | 由 Lunascape 管理的本裝置資料夾。也會顯示 Git 的分支名稱和已變更的檔案數 |
| 資料夾 | 本裝置上的資料夾 |

按下圖示，會顯示位置與狀態，以及可從該處執行的操作（[在 GitHub 上檢視]、[複製連結] 等）。

## 在 Lunascape 中複製儲存庫

在 Lunascape 中，可以將 GitHub 的儲存庫複製到本裝置，並使用 Git 進行編輯與提交。

- 在「開啟文件」畫面中，按儲存庫那一列的 [建立複本]。
- 正在閱讀從 GitHub 開啟的儲存庫時，按位置標籤，再按 [在這台電腦上建立複本]。複製完成後，同一份文件會以本裝置上的版本開啟。

已複製的儲存庫在清單中會標示「已在這台電腦上」，[在這台電腦上開啟] 會排在前面。

## 使用 URL 開啟

網址是依序排列儲存庫與文件位置的形式。路徑是文件在儲存庫中的位置，因此排列方式與 GitHub 的 URL 相同。

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 指定內容 | 寫法 |
|---|---|
| 僅儲存庫（預設分支） | `/github/owner/repo` |
| 儲存庫中的文件 | `/github/owner/repo/docs/01-product/vision.md` |
| 指定分支或標籤 | 在結尾加上 `?ref=v1.2.0` |

切換頁面時，網址也會跟著改變。按工具列上的 [分享此文件]，即可分享目前閱讀頁面的連結。也可以使用瀏覽器的 [返回] [前進]。

以前的 `?source=` 形式也能照常開啟。開啟後，網址會改寫為新的形式。

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **注意**
>
> - 未登入時，會受到 GitHub API 的使用限制（每小時 60 次）。若儲存庫中的文件較多，或需要反覆閱讀，請按 [使用 GitHub 登入]。
> - 包含 `/` 的分支名稱（例如 `feature/xxx`），可以用上述網址形式的 `?ref=` 指定。`?source=` 形式無法指定。
> - 文件會以閱讀者的 GitHub 權限載入。沒有讀取權限的人無法看到。

## 開啟本機資料夾中的文件

按工具列上的 [開啟文件]，再從左側欄位的 [開啟本機資料夾中的文件] 選擇裝置中的資料夾。檔案會在瀏覽器內處理，不會傳送到外部。可在支援選擇資料夾的瀏覽器（Chrome、Edge 等）中使用。
