# قراءة مستودع خاص

بعد تسجيل الدخول عبر GitHub، يمكنك قراءة مستندات المستودعات الخاصة، مقتصرةً على تلك التي لديك صلاحية القراءة عليها. لا تمتلك Lunascape Docs أي حسابات أو صلاحيات خاصة بها.

## تسجيل الدخول والفتح

1. افتح <https://docs.lunascape.org/>.
   عند تحديد مستند خاص أو عندما لا تكون قد سجّلت الدخول بعد، تظهر شاشة تسجيل الدخول.
2. اضغط [تسجيل الدخول عبر GitHub].
   تُفتح شاشة المصادقة الخاصة بـ GitHub في نافذة منبثقة.
3. بعد تسجيل الدخول، اضغط [فتح المستندات] في شريط الأدوات، واختر المستودع الذي تريد فتحه من [الاختيار من المستودعات القابلة للقراءة].

> **ملاحظة**
>
> - يظهر اسم الحساب المسجّل دخوله في شريط الأدوات. ومن هنا أيضًا يمكنك [تسجيل الخروج] أو [تسجيل الدخول بحساب آخر].
> - تعرض القائمة مستودعات الحسابات (المؤسسات أو الأفراد) التي جرى تثبيت GitHub App «Lunascape Docs» عليها، مقتصرةً على تلك التي لديك صلاحية قراءتها.

## الإعدادات التي يقوم بها مالك المستودع

إذا لم يظهر المستودع المطلوب في القائمة، فيجب على مالك المستودع أو مسؤول المؤسسة تثبيت GitHub App «Lunascape Docs».

- الصلاحيات المطلوبة هي Contents (قراءة وكتابة) وPull requests (قراءة وكتابة). القراءة للاطّلاع، والكتابة لإرسال طلب نشر (Pull Request) من الويب. لا تحفظ Lunascape Docs محتوى المستندات إطلاقًا.
- يجري التثبيت على مستوى الحساب (مؤسسة أو فرد). حدّد ما إذا كان النطاق «All repositories» (ويشمل تلقائيًا المستودعات التي تُنشأ لاحقًا) أم المستودعات المختارة فقط.

| الحالة | الخطوات |
|---|---|
| التثبيت على مؤسسة أو حساب فردي جديد | نفّذ ذلك من [صفحة التثبيت](https://github.com/apps/lunascape-docs/installations/new) |
| إضافة مستودعات في مؤسسة سبق تثبيته فيها | اضبط ذلك من Settings الخاص بالمؤسسة ← GitHub Apps ← Lunascape Docs ← Configure ← Repository access |

حتى عند التثبيت على مستوى المؤسسة بأكملها، لا يرى كل عضو سوى المستودعات التي لديه صلاحية قراءتها، ولا يمكنه إرسال طلب نشر إلا إلى المستودعات التي لديه صلاحية الكتابة عليها.

> **ملاحظة**
> - في حالة التثبيت الجديد، تُعرض الصلاحيات المطلوبة في قائمة على شاشة التثبيت، ويُعدّ الضغط على «Install» موافقةً عليها. ولا يلزم أي إجراء إضافي.
> - المؤسسة التي كانت قد ثبّتت التطبيق قبل إضافة صلاحية جديدة يصل إلى مسؤوليها بريد للتأكيد، ويظهر زر الموافقة في أعلى Settings الخاص بالمؤسسة ← GitHub Apps ← Lunascape Docs ← Configure. وإلى أن تجري الموافقة، يمكن في تلك المؤسسة الاطّلاع فقط، وعند إرسال طلب نشر يظهر «يلزم منح صلاحية الكتابة».
> - يمكنك التحقق من الصلاحيات النافذة حاليًا من شاشة Configure نفسها. وفي حالة الحساب الفردي يكون ذلك من Settings ← Applications ← Installed GitHub Apps.
> - إذا استُبعد المستودع المطلوب عن طريق الخطأ أو أُلغي تثبيت التطبيق، فيمكن استعادة الحالة بإعادة التثبيت من [صفحة التثبيت](https://github.com/apps/lunascape-docs/installations/new). وتتضمن رسالة رفض طلب النشر رابطًا إلى شاشة الإصلاح.
> - إذا كنت لا ترغب في استقبال طلبات النشر على مستوى المستودع، فاكتب `"publish": { "enabled": false }` في `lunascape-docs.json`. تبقى القراءة متاحة كما هي.
