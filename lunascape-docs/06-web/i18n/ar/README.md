# ما يمكن فعله في نسخة الويب

تتوفّر نسخة الويب من Lunascape Docs على <https://docs.lunascape.org/>. يمكنك قراءة المستندات الموجودة على GitHub كأنها موقع ويب، دون تثبيت أي شيء.

## ما يمكن فعله

| الميزة | المحتوى |
|---|---|
| عرض المستودعات العامة | يفتح مستندات مستودع عام على GitHub دون تسجيل الدخول |
| عرض المستودعات الخاصة | بعد تسجيل الدخول عبر GitHub، يفتح المستودعات التي لديك صلاحية قراءتها |
| عرض المجلدات المحلية | من [فتح المستندات] ثم [فتح مستندات من مجلد محلي]، يفتح مجلدًا داخل جهازك (في المتصفحات المدعومة فقط) |
| ميزات العرض | INDEX والروابط والسجلّ والتصفية وفهرس الصفحة وتبديل اللغة وتبديل السمة، وهي نفسها في نسخة VS Code |
| الرسوم التخطيطية والمعادلات | Mermaid وVega-Lite وMarkmap وWaveDrom وSvgbob وPenrose ومعادلات KaTeX |
| المسودات | حرِّر المستندات واحتفظ بالتغييرات كمسودات داخل جهازك. لا يُكتب شيء في المستودع |
| الروابط المباشرة إلى الصفحات | يمكن تحديد المستودع والصفحة في عنوان URL لفتح صفحة معيّنة مباشرة |

## الفروق عن نسخة VS Code

- فحص المستندات والإنشاء من قالب وتوليد مقترحات الترجمة والتنظيم من INDEX غير متوفّرة في نسخة الويب.
- لا تُرسم رسوم TikZ التخطيطية.
- لا تُكتب التعديلات في المستودع، بل تصبح مسودات داخل جهازك. «طلب النشر» الذي يرسل المسودات على هيئة Pull Request مُنفَّذ، لكنه غير مُفعَّل في العارض العام. لتطبيق التغييرات على المستودع، حرِّر باستخدام نسخة VS Code أو في نسخة مستنسخة لديك.
