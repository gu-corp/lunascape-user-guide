# Публикуване на вашите документи в Уеб

Можете да публикувате документите на собственото си хранилище като уебсайт в GitHub Pages или на произволен статичен хостинг. Има два начина. Тези стъпки са за разработчици, които могат да клонират хранилището на Lunascape Docs и да използват `npm`.

## Начин 1: поставяне на двата файла на визуализатора

Разполагате само визуализатора (`index.html` и `lsdoc.js`), а документите се зареждат от GitHub. Самите документи не са част от сайта, затова този начин е безопасен и за частни хранилища (читателите влизат с GitHub).

1. Изпълнете следната команда в хранилището на Lunascape Docs.

   ```sh
   npm run build:viewer
   ```

   В `dist/viewer/` се създават `index.html` и `lsdoc.js`.
2. Поставете двата файла в `docs/` на хранилището, което искате да публикувате.
3. Включете GitHub Pages.

Коренната папка на документацията, която се показва, се определя в следния ред.

1. Настройката `source` в `index.html`
2. `repository` в `lunascape-docs.json` в същата папка
3. Заключение от адреса `*.github.io` и устройството на клоните

## Начин 2: изнасяне на статичен сайт заедно с документите

Изнасяте визуализатора заедно с файловете на документите и хоствате резултата както е.

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

Резултатът съдържа визуализатора, документите под `docs/`, файла със списъка `lunascape-docs-manifest.json` и `.nojekyll`. Поставете изнесената папка в S3 или GitHub Pages, за да я публикувате. За пример за автоматично публикуване с GitHub Actions вижте `examples/workflows/publish-docs-pages.yml` в хранилището.

> **Внимание**
>
> - **Не изнасяйте документите на частно хранилище към GitHub Pages.** Извън Enterprise Cloud GitHub Pages е достъпен за всички. Ако е нужно ограничено публикуване, използвайте начин 1 и оставете читателите да влязат с GitHub.
> - Отварянето на `index.html` директно чрез `file://` не работи, защото браузърът забранява зареждането на съседни файлове и изпълнението на ES модули по този начин. За проверка на място използвайте версията за VS Code или HTTP сървър.
> - Библиотеките за изчертаване на TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob и Penrose се зареждат при показване. В изнесения сайт поставете и папката `vendor/`.
