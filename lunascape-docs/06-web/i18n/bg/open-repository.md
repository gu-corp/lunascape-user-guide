# Отваряне на хранилище в GitHub

В уеб версията можете да отворите хранилище в GitHub и да го четете направо, без да го клонирате. За публичните хранилища не е нужно да влизате.

## Отваряне от екрана

1. Натиснете [Отваряне на документи] (иконата с папка) в лентата с инструменти. Отваря се екранът „Отваряне на документи“.
2. В лявата колона изберете откъде да отворите.

   | Място | Какво се показва |
   |---|---|
   | Всички | Всичко по-долу. Наскоро отворените са най-отгоре |
   | Наскоро отваряни | Хранилищата и папките, които сте отваряли |
   | Препоръчани | Ръководствата, които сайтът препоръчва |
   | Хранилища в GitHub | Когато сте влезли в GitHub — хранилищата, които можете да четете |
   | Този компютър | Папки на това устройство |

3. Натиснете [Отваряне] на реда, който искате. Въведете текст в [Филтриране по име на документ или хранилище] най-горе, за да филтрирате редовете.

За хранилище, което не е в списъка, използвайте [Въвеждане на owner/repo и отваряне] в лявата колона.

> **Съвет**
>
> - В списъка се показват хранилищата в GitHub, в които е инсталирано приложението GitHub App „Lunascape Docs“ и за които имате права за четене. Ако дадено хранилище липсва, помолете собственика му да добави приложението.

## Проверка на местоположението на документа

Малката икона в лявата част на лентата с инструменти (индикаторът за местоположение) показва къде се намира документът, който четете.

| Икона | Местоположение |
|---|---|
| Знакът на GitHub | Четете от GitHub. На това устройство не е съхранено нищо |
| Папка | Папка на това устройство |

Натиснете иконата, за да видите местоположението, състоянието и действията, които можете да извършите оттам ([Преглед в GitHub], [Копиране на връзката] и др.).

## Отваряне чрез URL

Адресът изрежда хранилището и мястото на документа в него. Пътят е мястото в хранилището, затова редът е същият като в URL адреса в GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| Какво се посочва | Как се записва |
|---|---|
| Само хранилище (клон по подразбиране) | `/github/owner/repo` |
| Документ в хранилището | `/github/owner/repo/docs/01-product/vision.md` |
| Клон или етикет | Добавете `?ref=v1.2.0` в края |

При преминаване към друга страница адресът също се променя. Натиснете [Споделяне на този документ] в лентата с инструменти, за да изпратите връзка към страницата, която четете. Бутоните [Назад] и [Напред] на браузъра също работят.

По-старият формат с `?source=` също се отваря както досега. След отварянето адресът се преобразува в новия формат.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **Внимание**
>
> - Без вход се прилага ограничението на GitHub API (60 заявки на час). За хранилища с много документи или при многократно четене използвайте [Вход с GitHub].
> - Имена на клонове, съдържащи `/` (например `feature/xxx`), могат да се посочат с `?ref=` в горния формат на адреса. Във формата с `?source=` това не е възможно.
> - Документите се зареждат с правата в GitHub на читателя. Хора без права за четене не ги виждат.

## Отваряне на документи от локална папка

Натиснете [Отваряне на документи] в лентата с инструменти, после [Отваряне на документи от локална папка] в лявата колона и изберете папка на устройството. Файловете се обработват в браузъра и не се изпращат никъде. Работи в браузъри, които поддържат избор на папка (Chrome, Edge и др.).
