# Какво може уеб версията

Уеб версията на Lunascape Docs е достъпна на <https://docs.lunascape.org/>. Без да инсталирате нищо, четете документите в GitHub като уеб сайт.

## Какво може

| Функция | Описание |
|---|---|
| Преглед на публични хранилища | Отваря документите на публично хранилище в GitHub без вход |
| Преглед на непублични хранилища | След вход с GitHub отваряте хранилищата, за които имате права за четене |
| Преглед на локална папка | С [Отваряне на документи] и след това [Отваряне на документи от локална папка] отваряте папка на устройството си (само в поддържани браузъри) |
| Функции за четене | INDEX, връзки, история, филтриране, съдържание на страницата, смяна на езика и смяна на темата. Същите като във версията за VS Code |
| Диаграми и формули | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, формули на KaTeX |
| Чернови | Редактирате документ и запазвате промените като чернова на устройството. В хранилището не се записва нищо |
| Пряка връзка към страница | С URL посочвате хранилището и страницата и отваряте определена страница直接 |

## Разлики спрямо версията за VS Code

- Проверката на документи, създаването от шаблон, изготвянето на предложения за превод и подреждането от INDEX липсват в уеб версията.
- Диаграмите TikZ не се изчертават.
- Редакциите не се записват в хранилището, а стават чернови на устройството. „Заявка за публикуване“, която изпраща черновите като Pull Request, е реализирана, но не е включена в публичния преглед. За да отразите промените в хранилището, редактирайте във версията за VS Code или в локално копие.
