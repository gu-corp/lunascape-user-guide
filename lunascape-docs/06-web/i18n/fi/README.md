# Mitä Web-versiossa voi tehdä

Lunascape Docsin Web-selainversio on julkaistu osoitteessa <https://docs.lunascape.org/>. Ilman asennusta voit lukea GitHubissa olevia dokumentteja kuin verkkosivustoa.

## Mitä voit tehdä

| Toiminto | Sisältö |
|---|---|
| Julkisten säilöjen selaaminen | Avaa GitHubin julkisen säilön dokumentit ilman kirjautumista |
| Yksityisten säilöjen selaaminen | Kun kirjaudut sisään GitHubilla, voit avata säilöt, joihin sinulla on lukuoikeus |
| Paikallisten kansioiden selaaminen | [Avaa dokumentteja] ja sitten [Avaa dokumentteja paikallisesta kansiosta] avaa laitteessasi olevan kansion (vain tuetuissa selaimissa) |
| Lukutoiminnot | INDEX, linkit, historia, rajaus, sivun sisällysluettelo, kielen vaihto ja teeman vaihto. Samat kuin VS Code -versiossa |
| Kaaviot ja matematiikka | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose ja KaTeX-matematiikka |
| Luonnokset | Muokkaa dokumentteja ja säilytä muutokset luonnoksina laitteessasi. Säilöön ei kirjoiteta mitään |
| Suorat linkit sivulle | URL-osoitteessa voi määrittää säilön ja sivun, jolloin tietty sivu avautuu suoraan |

## Erot VS Code -versioon

- Dokumenttien tarkistus, luonti mallista, käännösehdotusten luonti ja järjestely INDEX-paneelista eivät ole käytettävissä Web-versiossa.
- TikZ-kuvia ei piirretä.
- Muokkauksia ei kirjoiteta säilöön, vaan niistä tulee luonnoksia laitteeseesi. Luonnosten lähettäminen pull requestina eli ”julkaisupyyntö” on toteutettu, mutta sitä ei ole otettu käyttöön julkisessa katseluohjelmassa. Jos haluat viedä muutokset säilöön, muokkaa VS Code -versiossa tai paikallisessa kloonissa.
