# খসড়া সংরক্ষণ করা

Web সংস্করণে কোনো নথি সম্পাদনা করলে পরিবর্তনগুলি রিপোজিটরিতে লেখা হয় না, ব্রাউজারের ভিতরে "খসড়া" হিসেবে সংরক্ষিত হয়।

## খসড়া তৈরি করা

1. নথিটি খুলুন এবং নিচে ডান দিকের [সম্পাদনা] চাপুন।
2. সম্পাদনা করে [সংরক্ষণ] চাপুন।
   "খসড়া হিসেবে সংরক্ষণ করা হয়েছে" দেখানো হয় এবং পরিবর্তনটি ব্রাউজারের ভিতরে সংরক্ষিত হয়।

- যে নথিতে খসড়া আছে, INDEX-এ তার সঙ্গে একটি ব্যাজ যুক্ত হয়। মূল লেখার উপরে "এই নথিটি এই যন্ত্রের ভিতরের একটি খসড়া (অপ্রকাশিত)" দেখানো হয়।
- টুলবারের [খসড়া]-এ সংখ্যা দেখানো হয়, চাপলে খসড়ার তালিকা খোলে।

## খসড়া বাতিল করা

- নথি ধরে ধরে বাতিল করতে, মূল লেখার উপরের [খসড়া বাতিল করুন] চাপুন।
- সবগুলি বাতিল করতে, খসড়ার তালিকা থেকে কাজটি করুন।

## রিপোজিটরিতে প্রতিফলিত করা

খসড়াকে Pull Request হিসেবে পাঠানোর "প্রকাশের অনুরোধ" বাস্তবায়িত হয়েছে, তবে সর্বজনীন ভিউয়ারে এটি সক্রিয় নয়। রিপোজিটরিতে প্রতিফলিত করতে VS Code সংস্করণে বা হাতের কাছের ক্লোনে সম্পাদনা করুন।

> **সতর্কতা**
>
> - খসড়া ব্রাউজারে (IndexedDB) সংরক্ষিত হয়। অন্য ব্রাউজার বা অন্য যন্ত্রে তা যায় না। ব্রাউজারের সাইট ডেটা মুছে ফেললে খসড়াও মুছে যায়।
> - খসড়া তৈরির পরে রিপোজিটরির দিকের নথিটি হালনাগাদ হলে "উজানে হালনাগাদ হয়েছে" দেখানো হয়। বিষয়বস্তু দেখে নিয়ে খসড়াটি বাতিল করবেন, নাকি সেভাবেই ব্যবহার করবেন, তা ঠিক করুন।
> - [নথি খুলুন] থেকে স্থানীয় ফোল্ডার খুলে সম্পাদনা করলে, ব্রাউজার সমর্থন করলে সরাসরি ফাইলে সংরক্ষিত হয়। যে ব্রাউজার সমর্থন করে না, সেখানে কেবল ওই সেশনের সময়টুকুই তা থাকে।
