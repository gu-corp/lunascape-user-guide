# একটি ব্যক্তিগত রিপোজিটরি দেখা

ব্যক্তিগত রিপোজিটরির নথি GitHub দিয়ে সাইন ইন করলে দেখা যায়, তবে শুধু সেই রিপোজিটরিগুলোই যেগুলোতে আপনার পড়ার অনুমতি আছে। Lunascape Docs-এর কখনো নিজস্ব অ্যাকাউন্ট বা অনুমতি থাকে না।

## সাইন ইন করে খুলুন

1. <https://docs.lunascape.org/> খুলুন।
   কোনো ব্যক্তিগত নথি নির্দিষ্ট করলে, অথবা এখনো সাইন ইন না করে থাকলে, সাইন ইন স্ক্রিন প্রদর্শিত হয়।
2. [GitHub দিয়ে সাইন ইন] চাপুন।
   GitHub-এর অনুমোদন স্ক্রিন একটি পপ-আপে খোলে।
3. সাইন ইন শেষ হলে, টুলবারে [নথি খুলুন] চাপুন এবং [পড়া যায় এমন রিপোজিটরি থেকে বেছে নিন] থেকে যে রিপোজিটরি খুলতে চান তা বেছে নিন।

> **ইঙ্গিত**
>
> - সাইন ইন করা অ্যাকাউন্টের নাম টুলবারে প্রদর্শিত হয়। [সাইন আউট] বা [অন্য অ্যাকাউন্ট দিয়ে সাইন ইন]-ও এখান থেকে করা যায়।
> - তালিকায় সেই অ্যাকাউন্টগুলোর (সংগঠন বা ব্যক্তি) রিপোজিটরি প্রদর্শিত হয় যেখানে GitHub App "Lunascape Docs" ইনস্টল করা আছে, তবে শুধু সেগুলোই যেগুলো আপনি পড়তে পারেন।

## রিপোজিটরির মালিক যে সেটিং করবেন

তালিকায় কাঙ্ক্ষিত রিপোজিটরি প্রদর্শিত না হলে, রিপোজিটরির মালিক বা সংগঠনের প্রশাসককে GitHub App "Lunascape Docs" ইনস্টল করতে হবে।

- অনুরোধ করা অনুমতিগুলো হলো Contents (পড়া ও লেখা) এবং Pull requests (পড়া ও লেখা)। পড়া হলো দেখার জন্য, আর লেখা হলো Web থেকে প্রকাশের অনুরোধ (Pull Request) পাঠানোর জন্য। Lunascape Docs কখনো নথির বিষয়বস্তু সংরক্ষণ করে না।
- ইনস্টলের একক হলো অ্যাকাউন্ট (সংগঠন বা ব্যক্তি)। লক্ষ্যকে "All repositories" (পরবর্তীতে তৈরি হওয়া রিপোজিটরিও স্বয়ংক্রিয়ভাবে অন্তর্ভুক্ত করে) করবেন, নাকি শুধু বেছে নেওয়া রিপোজিটরিতে সীমাবদ্ধ রাখবেন, তা সেট করুন।

| পরিস্থিতি | পদক্ষেপ |
|---|---|
| নতুন করে সংগঠন বা ব্যক্তিগত অ্যাকাউন্টে যুক্ত করা | [ইনস্টল পৃষ্ঠা](https://github.com/apps/lunascape-docs/installations/new) থেকে সম্পন্ন করুন |
| ইতিমধ্যে যুক্ত করা সংগঠনে কাঙ্ক্ষিত রিপোজিটরি যোগ করা | সংগঠনের Settings → GitHub Apps → Lunascape Docs → Configure → Repository access-এ সেট করুন |

সম্পূর্ণ সংগঠনে ইনস্টল করলেও, প্রতিটি সদস্য শুধু সেই রিপোজিটরিগুলোই দেখতে পারেন যেগুলোতে তার নিজের পড়ার অনুমতি আছে। প্রকাশের অনুরোধও শুধু সেই রিপোজিটরিতে পাঠানো যায় যেগুলোতে তার নিজের লেখার অনুমতি আছে।

> **ইঙ্গিত**
> - নতুন করে ইনস্টল করার সময়, অনুরোধ করা অনুমতিগুলো ইনস্টল স্ক্রিনে তালিকা আকারে প্রদর্শিত হয়, এবং "Install" চাপার মুহূর্তেই সেগুলো অনুমোদন করা হয়। বাড়তি কোনো পদক্ষেপ নেই।
> - অনুমতি বাড়ার আগে থেকে যে সংগঠন ইনস্টল করেছিল, তার প্রশাসকের কাছে নিশ্চিতকরণের একটি ইমেইল পৌঁছায় এবং সংগঠনের Settings → GitHub Apps → Lunascape Docs → Configure-এর উপরের দিকে একটি অনুমোদন বোতাম প্রদর্শিত হয়। অনুমোদন না করা পর্যন্ত সেই সংগঠনে শুধু দেখা যায়, আর প্রকাশের অনুরোধ পাঠালে "লেখার অনুমতি দেওয়া প্রয়োজন" প্রদর্শিত হয়।
> - এখন কোন অনুমতি নিয়ে যুক্ত আছে তা একই Configure স্ক্রিনে দেখা যায়। ব্যক্তিগত অ্যাকাউন্টের ক্ষেত্রে তা Settings → Applications → Installed GitHub Apps।
> - কাঙ্ক্ষিত রিপোজিটরি ভুলবশত বাদ দিলে বা আনইনস্টল করলে, [ইনস্টল পৃষ্ঠা](https://github.com/apps/lunascape-docs/installations/new) থেকে পুনরায় যুক্ত করলে তা আগের অবস্থায় ফিরে আসে। প্রকাশের অনুরোধ প্রত্যাখ্যানের বার্তায় সংশোধনের স্ক্রিনের একটি লিঙ্ক থাকে।
> - রিপোজিটরির দিক থেকে প্রকাশের অনুরোধ গ্রহণ করতে না চাইলে, `lunascape-docs.json`-এ `"publish": { "enabled": false }` লিখুন। দেখা তেমনই থাকে।
