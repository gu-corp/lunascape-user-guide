# ওয়েব সংস্করণে যা করা যায়

ওয়েব ব্রাউজার সংস্করণের Lunascape Docs <https://docs.lunascape.org/> ঠিকানায় প্রকাশিত। কিছু ইনস্টল না করেই GitHub-এর নথিগুলি একটি ওয়েবসাইটের মতো পড়া যায়।

## যা করা যায়

| সুবিধা | বিবরণ |
|---|---|
| পাবলিক রিপোজিটরি দেখা | সাইন ইন ছাড়াই GitHub-এর পাবলিক রিপোজিটরির নথি খোলে |
| প্রাইভেট রিপোজিটরি দেখা | GitHub দিয়ে সাইন ইন করলে, যেসব রিপোজিটরিতে আপনার পড়ার অনুমতি আছে সেগুলি খোলা যায় |
| লোকাল ফোল্ডার দেখা | [নথি খুলুন]-এর [লোকাল ফোল্ডারের নথি খুলুন] দিয়ে আপনার যন্ত্রের ভিতরের একটি ফোল্ডার খোলে (কেবল সমর্থিত ব্রাউজারে) |
| পাঠের সুবিধা | INDEX, লিঙ্ক, ইতিহাস, ছাঁকনি, পৃষ্ঠার সূচি, ভাষা পরিবর্তন, থিম পরিবর্তন। VS Code সংস্করণের মতোই |
| চিত্র ও গাণিতিক সূত্র | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, KaTeX গাণিতিক সূত্র |
| খসড়া | নথি সম্পাদনা করে পরিবর্তনগুলি যন্ত্রের ভিতরে খসড়া হিসেবে রাখে। রিপোজিটরিতে কিছু লেখা হয় না |
| পৃষ্ঠায় সরাসরি লিঙ্ক | URL-এ রিপোজিটরি ও পৃষ্ঠা উল্লেখ করে নির্দিষ্ট একটি পৃষ্ঠা সরাসরি খোলা যায় |

## VS Code সংস্করণের সঙ্গে পার্থক্য

- নথি পরীক্ষা, টেমপ্লেট থেকে তৈরি করা, অনুবাদের খসড়া তৈরি এবং INDEX থেকে গুছিয়ে নেওয়া ওয়েব সংস্করণে নেই।
- TikZ চিত্র আঁকা হয় না।
- সম্পাদনার বিষয়বস্তু রিপোজিটরিতে লেখা হয় না, যন্ত্রের ভিতরে খসড়া হয়ে থাকে। খসড়াকে পুল রিকোয়েস্ট হিসেবে পাঠানোর "প্রকাশের অনুরোধ" তৈরি করা আছে, তবে পাবলিক ভিউয়ারে তা চালু নেই। রিপোজিটরিতে প্রতিফলিত করতে VS Code সংস্করণে বা হাতের কাছের ক্লোনে সম্পাদনা করুন।
