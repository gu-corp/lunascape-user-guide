# GitHub রিপোজিটরি খোলা

Web সংস্করণে GitHub রিপোজিটরি উল্লেখ করে নথি খোলা হয়। পাবলিক রিপোজিটরি হলে সাইন ইন করার প্রয়োজন নেই।

## স্ক্রিন থেকে খোলা

1. <https://docs.lunascape.org/> খুলুন।
2. টুলবারের [নথি খুলুন] (ফোল্ডারের আইকন) চাপুন।
3. [রিপোজিটরি সরাসরি উল্লেখ করুন]-এ রিপোজিটরি লিখুন এবং [খুলুন] চাপুন।
   GitHub-এ সাইন ইন করা থাকলে, [পড়া যায় এমন রিপোজিটরি থেকে বেছে নিন] দিয়ে তালিকা থেকেও বেছে নেওয়া যায়।

> **ইঙ্গিত**
>
> - পাশের GitHub আইকনটি আপনি এখন যে নথি পড়ছেন সেটি github.com-এ খোলে। এটি নথি খোলার কাজ নয়।

## URL দিয়ে খোলা

ঠিকানাটি রিপোজিটরি ও নথির অবস্থান যেমন আছে তেমনই পাশাপাশি সাজিয়ে লেখা হয়। পাথটি রিপোজিটরির ভিতরের অবস্থান, তাই GitHub-এর URL-এর মতোই একই ক্রমে থাকে।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| উল্লেখ | লেখার নিয়ম |
|---|---|
| শুধু রিপোজিটরি (ডিফল্ট ব্রাঞ্চ) | `/github/owner/repo` |
| রিপোজিটরির ভিতরের নথি | `/github/owner/repo/docs/01-product/vision.md` |
| ব্রাঞ্চ বা ট্যাগ উল্লেখ | শেষে `?ref=v1.2.0` যোগ করুন |

পৃষ্ঠা বদলালে ঠিকানাও বদলায়। টুলবারের [এই নথি শেয়ার করুন] চাপলে আপনি এখন যে পৃষ্ঠা পড়ছেন তার লিঙ্ক দেওয়া যায়। ব্রাউজারের [পিছনে] [সামনে]-ও ব্যবহার করা যায়।

আগের `?source=` রূপটিও আগের মতোই খোলা যায়। খোলার পরে তা নতুন রূপে লেখা হয়ে যায়।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **দ্রষ্টব্য**
>
> - সাইন ইন না করা অবস্থায় GitHub API-এর ব্যবহারের সীমা (ঘণ্টায় ৬০ বার) প্রযোজ্য। অনেক নথি আছে এমন রিপোজিটরি বা বারবার পড়ার ক্ষেত্রে [GitHub দিয়ে সাইন ইন] করুন।
> - `/` আছে এমন ব্রাঞ্চের নাম (যেমন `feature/xxx`) উপরের ঠিকানা-রূপের `?ref=` দিয়ে উল্লেখ করা যায়। `?source=` রূপে তা লেখা যায় না।
> - নথিগুলি পাঠকের নিজের GitHub অনুমতি দিয়ে লোড হয়। পড়ার অনুমতি নেই এমন ব্যক্তির কাছে সেগুলি দেখা যায় না।

## লোকাল ফোল্ডারের নথি খোলা

টুলবারের [নথি খুলুন] চাপুন, তারপর তালিকার নিচের [লোকাল ফোল্ডারের নথি খুলুন] থেকে ডিভাইসের ভিতরের একটি ফোল্ডার বেছে নিন। ফাইলগুলি ব্রাউজারের ভিতরেই প্রক্রিয়া করা হয়, বাইরে পাঠানো হয় না। ফোল্ডার নির্বাচন সমর্থন করে এমন ব্রাউজারে (Chrome, Edge প্রভৃতি) এটি ব্যবহার করা যায়।
