# GitHub রিপোজিটরি খোলা

ওয়েব সংস্করণে এবং Lunascape-এ GitHub রিপোজিটরির প্রতিলিপি না করেই সেটি সরাসরি খুলে পড়া যায়। পাবলিক রিপোজিটরির জন্য সাইন ইন করতে হয় না।

## স্ক্রিন থেকে খোলা

1. টুলবারের [নথি খুলুন] (ফোল্ডারের আইকন) চাপুন। “নথি খুলুন” স্ক্রিন খুলবে।
2. বাঁ দিকের কলামে কোথা থেকে খুলবেন তা বেছে নিন।

   | স্থান | যা দেখানো হয় |
   |---|---|
   | সব | নিচের সবকিছু। সম্প্রতি খোলা আইটেম সবার আগে থাকে |
   | সম্প্রতি খোলা | আগে খোলা রিপোজিটরি ও ফোল্ডার |
   | প্রস্তাবিত | সাইটে পরিচয় করিয়ে দেওয়া ম্যানুয়াল |
   | GitHub রিপোজিটরি | GitHub-এ সাইন ইন করা থাকলে, যে রিপোজিটরিগুলো আপনি পড়তে পারেন |
   | এই কম্পিউটার | এই ডিভাইসের ফোল্ডার। Lunascape-এ প্রতিলিপি করা রিপোজিটরিও এখানে দেখানো হয় |

3. যে সারিটি খুলতে চান, তার [খুলুন] চাপুন। ওপরের [নথি বা রিপোজিটরির নাম দিয়ে ফিল্টার করুন]-এ লিখে সারিগুলো ফিল্টার করা যায়।

তালিকায় নেই এমন রিপোজিটরি খুলতে, বাঁ দিকের কলামের [owner/repo লিখে খুলুন] ব্যবহার করুন।

> **পরামর্শ**
>
> - তালিকায় শুধু সেই GitHub রিপোজিটরিগুলো দেখানো হয়, যেগুলোতে GitHub App “Lunascape Docs” ইনস্টল করা আছে এবং যেগুলো পড়ার অনুমতি আপনার আছে। কোনো রিপোজিটরি খুঁজে না পেলে, সেটির মালিককে App-টি যোগ করতে বলুন।

## নথির অবস্থান দেখা

টুলবারের বাঁ দিকের কাছে একটি ছোট আইকন (অবস্থান চিপ) আছে। আপনি এখন যে নথি পড়ছেন, সেটি কোথায় আছে তা এই আইকন দেখায়।

| আইকন | অবস্থান |
|---|---|
| GitHub-এর চিহ্ন | নথিটি GitHub থেকে পড়া হচ্ছে। এই ডিভাইসে সংরক্ষিত নেই |
| কম্পিউটার | এই ডিভাইসের এমন একটি ফোল্ডার, যা Lunascape পরিচালনা করে। Git ব্রাঞ্চের নাম এবং পরিবর্তিত ফাইলের সংখ্যাও দেখানো হয় |
| ফোল্ডার | এই ডিভাইসের একটি ফোল্ডার |

আইকনটি চাপলে অবস্থান, অবস্থা এবং সেখান থেকে করা যায় এমন কাজ ([GitHub-এ দেখুন], [লিঙ্ক কপি করুন] ইত্যাদি) দেখানো হয়।

## Lunascape-এ রিপোজিটরির প্রতিলিপি করা

Lunascape-এ GitHub রিপোজিটরির প্রতিলিপি এই ডিভাইসে রাখা যায়। এরপর Git দিয়ে সম্পাদনা ও কমিট করা যায়।

- “নথি খুলুন” স্ক্রিনে রিপোজিটরির সারিতে [প্রতিলিপি] চাপুন।
- GitHub থেকে খোলা রিপোজিটরি পড়ার সময় অবস্থান চিপ চাপুন, তারপর [এই কম্পিউটারে প্রতিলিপি] চাপুন। প্রতিলিপি শেষ হলে একই নথি এই ডিভাইসের কপি থেকে খুলবে।

প্রতিলিপি করা রিপোজিটরির পাশে তালিকায় “এই কম্পিউটারে আছে” লেখা থাকে। সেই সারিতে [এই কম্পিউটারে খুলুন] প্রথমে দেখানো হয়।

## URL দিয়ে খোলা

ঠিকানায় রিপোজিটরির নাম এবং তার ভেতরে নথির পাথ পরপর লেখা থাকে। পাথটি রিপোজিটরির ভেতরে নথির অবস্থান নির্দেশ করে, তাই ঠিকানাটি একই ফাইলের GitHub URL-এর মতো একই ক্রমে লেখা হয়।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| যা নির্দিষ্ট করবেন | লেখার ধরন |
|---|---|
| শুধু রিপোজিটরি (ডিফল্ট ব্রাঞ্চ) | `/github/owner/repo` |
| রিপোজিটরির ভেতরের নথি | `/github/owner/repo/docs/01-product/vision.md` |
| ব্রাঞ্চ বা ট্যাগ | শেষে `?ref=v1.2.0` যোগ করুন |

অন্য পৃষ্ঠায় গেলে ঠিকানাও বদলে যায়। এখন যে পৃষ্ঠা পড়ছেন তার লিঙ্ক অন্য কাউকে দিতে, টুলবারের [এই নথি শেয়ার করুন] চাপুন। ব্রাউজারের [পিছনে] ও [সামনে] বোতামও কাজ করে।

পুরোনো `?source=` ধরনের ঠিকানাও আগের মতোই খোলে। খোলার পরে ঠিকানাটি নতুন ধরনে বদলে যায়।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **দ্রষ্টব্য**
>
> - সাইন ইন না করলে GitHub API-এর ব্যবহারসীমা (প্রতি ঘণ্টায় ৬০টি অনুরোধ) প্রযোজ্য হয়। অনেক নথি আছে এমন রিপোজিটরি পড়তে বা বারবার পড়তে হলে [GitHub দিয়ে সাইন ইন] করুন।
> - যে ব্রাঞ্চের নামে `/` আছে (যেমন `feature/xxx`), সেটি ওপরের ঠিকানার ধরনে `?ref=` দিয়ে নির্দিষ্ট করা যায়। `?source=` ধরনে এমন ব্রাঞ্চের নাম লেখা যায় না।
> - নথি পাঠকের নিজের GitHub অনুমতি দিয়ে লোড হয়। যাঁদের পড়ার অনুমতি নেই, তাঁরা নথিগুলো দেখতে পান না।

## লোকাল ফোল্ডারের নথি খোলা

টুলবারের [নথি খুলুন] চাপুন। এরপর বাঁ দিকের কলামে [লোকাল ফোল্ডারের নথি খুলুন] চাপুন এবং ডিভাইসের একটি ফোল্ডার বেছে নিন। ফাইলগুলো ব্রাউজারের ভেতরেই প্রক্রিয়া করা হয় এবং বাইরে কোথাও পাঠানো হয় না। এটি সেইসব ব্রাউজারে কাজ করে, যেগুলোতে ফোল্ডার বেছে নেওয়া যায় (Chrome, Edge ইত্যাদি)।
