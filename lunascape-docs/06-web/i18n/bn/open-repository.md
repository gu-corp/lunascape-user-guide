# GitHub-এর রিপোজিটরি খোলা

ওয়েব সংস্করণে GitHub-এর রিপোজিটরি ক্লোন না করেই সরাসরি খুলে পড়তে পারেন। পাবলিক রিপোজিটরির জন্য সাইন ইন প্রয়োজন হয় না।

## স্ক্রিন থেকে খোলা

1. টুলবারের [নথি খুলুন] (ফোল্ডারের আইকন) চাপুন। “নথি খুলুন” স্ক্রিন খুলবে।
2. কোথা থেকে খুলবেন, তা বাঁ দিকের তালিকা থেকে বেছে নিন।

   | স্থান | যা দেখায় |
   |---|---|
   | সব | নিচের সবকিছু। সম্প্রতি খোলাগুলো সবার আগে থাকে |
   | সম্প্রতি খোলা | এ পর্যন্ত খোলা রিপোজিটরি ও ফোল্ডার |
   | প্রস্তাবিত | সাইটে পরিচয় করিয়ে দেওয়া ম্যানুয়াল |
   | GitHub-এর রিপোজিটরি | GitHub-এ সাইন ইন থাকলে যেসব রিপোজিটরি আপনি পড়তে পারেন |
   | এই কম্পিউটার | এই ডিভাইসের ফোল্ডার |

3. যে সারিটি খুলতে চান, তার [খুলুন] চাপুন। উপরের [নথি বা রিপোজিটরির নাম দিয়ে ফিল্টার করুন]-এ লিখলে সারিগুলো ফিল্টার করা যায়।

তালিকায় নেই এমন রিপোজিটরি বাঁ দিকের [owner/repo লিখে খুলুন] থেকে নির্দিষ্ট করুন।

> **পরামর্শ**
>
> - তালিকায় যে GitHub রিপোজিটরিগুলো দেখা যায়, সেগুলোতে GitHub App “Lunascape Docs” ইনস্টল করা আছে এবং সেগুলো পড়ার অনুমতি আপনার আছে। খুঁজে না পেলে রিপোজিটরির মালিককে App যোগ করতে বলুন।

## নথির অবস্থান যাচাই করা

টুলবারের বাঁ দিকের ছোট আইকনটি (অবস্থান চিপ) দেখায়, এখন যে নথি পড়ছেন সেটি কোথায় আছে।

| আইকন | অবস্থান |
|---|---|
| GitHub-এর চিহ্ন | GitHub থেকে পড়ছেন। এই ডিভাইসে সংরক্ষিত নয় |
| ফোল্ডার | এই ডিভাইসের ফোল্ডার |

আইকনটি চাপলে অবস্থান ও অবস্থা, এবং সেখান থেকে করা যায় এমন কাজ ([GitHub-এ দেখুন], [লিঙ্ক কপি করুন] ইত্যাদি) দেখা যায়।

## URL দিয়ে খোলা

ঠিকানায় রিপোজিটরি ও নথির অবস্থান হুবহু পরপর সাজানো থাকে। পাথটি রিপোজিটরির ভেতরের অবস্থান, তাই এর ক্রম GitHub-এর URL-এর মতোই।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| যা নির্দিষ্ট করবেন | লেখার ধরন |
|---|---|
| শুধু রিপোজিটরি (ডিফল্ট ব্রাঞ্চ) | `/github/owner/repo` |
| রিপোজিটরির ভেতরের নথি | `/github/owner/repo/docs/01-product/vision.md` |
| ব্রাঞ্চ বা ট্যাগ নির্দিষ্ট করা | শেষে `?ref=v1.2.0` যোগ করুন |

পৃষ্ঠা বদলালে ঠিকানাও বদলায়। টুলবারের [এই নথি শেয়ার করুন] চাপলে এখন যে পৃষ্ঠা পড়ছেন, তার লিঙ্ক অন্যকে দিতে পারেন। ব্রাউজারের [পিছনে] ও [সামনে]-ও ব্যবহার করা যায়।

আগের `?source=` ধরনের ঠিকানাও আগের মতোই খোলে। খোলার পর এটি নতুন ধরনে বদলে যায়।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **দ্রষ্টব্য**
>
> - সাইন ইন না করা অবস্থায় GitHub API-এর ব্যবহারসীমা (প্রতি ঘণ্টায় ৬০ বার) প্রযোজ্য। বেশি নথি থাকা রিপোজিটরি বা বারবার পড়ার ক্ষেত্রে [GitHub দিয়ে সাইন ইন] করুন।
> - `/` থাকা ব্রাঞ্চের নাম (`feature/xxx` ইত্যাদি) উপরের ঠিকানার ধরনে `?ref=` দিয়ে নির্দিষ্ট করা যায়। `?source=` ধরনে এগুলো লেখা যায় না।
> - নথি পাঠকের নিজের GitHub অনুমতি দিয়ে লোড হয়। যাঁদের পড়ার অনুমতি নেই, তাঁরা এটি দেখতে পান না।

## লোকাল ফোল্ডারের নথি খোলা

টুলবারের [নথি খুলুন] চাপুন, তারপর বাঁ দিকের [লোকাল ফোল্ডারের নথি খুলুন] থেকে ডিভাইসের ফোল্ডার বেছে নিন। ফাইলগুলো ব্রাউজারের ভেতরেই প্রক্রিয়া করা হয় এবং কোথাও পাঠানো হয় না। ফোল্ডার বেছে নেওয়া সমর্থন করে এমন ব্রাউজারে (Chrome, Edge ইত্যাদি) এটি ব্যবহার করা যায়।
