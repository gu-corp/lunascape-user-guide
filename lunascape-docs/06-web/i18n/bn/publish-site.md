# আপনার নথি Web-এ প্রকাশ করা

আপনার নিজের রিপোজিটরির নথিগুলো GitHub Pages বা যেকোনো স্ট্যাটিক হোস্টিংয়ে একটি ওয়েবসাইট হিসেবে প্রকাশ করা যায়। প্রকাশ করার উপায় দুটি। এই ধাপগুলো সেইসব ডেভেলপারের জন্য, যাঁরা Lunascape Docs-এর রিপোজিটরি clone করে `npm` ব্যবহার করতে পারেন।

## উপায় ১: ভিউয়ারের দুটি ফাইল রাখা

শুধু ভিউয়ারটি (`index.html` এবং `lsdoc.js`) রেখে দিয়ে নথিগুলো GitHub থেকে লোড করার পদ্ধতি। নথিগুলো নিজে সাইটের অংশ নয়, তাই ব্যক্তিগত রিপোজিটরির ক্ষেত্রেও এটি নিরাপদ (পাঠক GitHub দিয়ে সাইন ইন করেন)।

1. Lunascape Docs-এর রিপোজিটরিতে নিচের কমান্ডটি চালান।

   ```sh
   npm run build:viewer
   ```

   `dist/viewer/`-এ `index.html` ও `lsdoc.js` তৈরি হয়।
2. ফাইল দুটি, যে রিপোজিটরি প্রকাশ করতে চান তার `docs/`-এ রাখুন।
3. GitHub Pages চালু করুন।

কোন ডকুমেন্টেশন রুট দেখানো হবে তা নিচের ক্রমে নির্ধারিত হয়।

1. `index.html`-এর ভেতরের `source` সেটিং
2. একই ফোল্ডারের `lunascape-docs.json`-এ লেখা `repository`
3. `*.github.io`-এর URL ও ব্রাঞ্চের গঠন থেকে অনুমান

## উপায় ২: নথিসহ স্ট্যাটিক সাইট রপ্তানি করা

ভিউয়ার ও নথির ফাইলগুলো একসঙ্গে রপ্তানি করে সেটিকে সরাসরি হোস্ট করার পদ্ধতি।

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

ভিউয়ারের সম্পূর্ণ সেট, `docs/`-এর নিচের নথিগুলো, তালিকা ফাইল `lunascape-docs-manifest.json` এবং `.nojekyll` আউটপুট হিসেবে তৈরি হয়। আউটপুটটি S3 বা GitHub Pages-এ রাখলেই প্রকাশ করা যায়। GitHub Actions দিয়ে স্বয়ংক্রিয়ভাবে প্রকাশের উদাহরণের জন্য রিপোজিটরির `examples/workflows/publish-docs-pages.yml` দেখুন।

> **সতর্কতা**
>
> - **ব্যক্তিগত রিপোজিটরির নথি রপ্তানি করে GitHub Pages-এ রাখবেন না।** Enterprise Cloud ছাড়া GitHub Pages যে কেউ দেখতে পারে। সীমিত প্রকাশের প্রয়োজন হলে উপায় ১ ব্যবহার করুন এবং পাঠককে GitHub দিয়ে সাইন ইন করান।
> - `index.html` সরাসরি `file://` দিয়ে খুললে কাজ করবে না। কারণ ব্রাউজার পাশের ফাইল লোড করা ও ES মডিউল চালানো নিষিদ্ধ করে। নিজের কাছে পরীক্ষা করার সময় VS Code সংস্করণ বা একটি HTTP সার্ভার ব্যবহার করুন।
> - TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose-এর রেন্ডারিং লাইব্রেরিগুলো প্রদর্শনের সময় লোড হয়। রপ্তানি করা সাইটে `vendor/` ফোল্ডারটিও একসঙ্গে রাখুন।
