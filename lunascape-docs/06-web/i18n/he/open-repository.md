# פתיחת מאגר GitHub

בגרסת האינטרנט אפשר לפתוח מאגר GitHub ולקרוא אותו ישירות, בלי לשכפל אותו. במאגר ציבורי אין צורך להתחבר.

## פתיחה מהמסך

1. לחצו על [פתיחת מסמכים] (סמל התיקייה) בסרגל הכלים. ייפתח המסך "פתיחת מסמכים".
2. בעמודה השמאלית, בחרו מאיפה לפתוח.

   | מיקום | מה מופיע |
   |---|---|
   | הכול | כל מה שמופיע למטה. מה שנפתח לאחרונה מופיע ראשון |
   | נפתחו לאחרונה | המאגרים והתיקיות שפתחתם עד כה |
   | מומלצים | המדריכים שהאתר ממליץ עליהם |
   | מאגרי GitHub | כשאתם מחוברים ל-GitHub, המאגרים שיש לכם הרשאה לקרוא |
   | המחשב הזה | תיקיות במכשיר הזה |

3. לחצו על [פתיחה] בשורה הרצויה. כדי לצמצם את השורות, הקלידו בשדה [סינון לפי שם מסמך או שם מאגר] שלמעלה.

כדי לפתוח מאגר שאינו ברשימה, השתמשו ב-[הזנת owner/repo ופתיחה] בעמודה השמאלית.

> **טיפ**
>
> - מאגרי GitHub שמופיעים ברשימה הם מאגרים שבהם מותקנת אפליקציית GitHub בשם "Lunascape Docs", ושיש לכם הרשאת קריאה אליהם. אם מאגר חסר, בקשו מהבעלים של המאגר להוסיף את האפליקציה.

## בדיקת מיקום המסמך

הסמל הקטן בצד שמאל של סרגל הכלים (תג המיקום) מראה איפה נמצא המסמך שאתם קוראים.

| סמל | מיקום |
|---|---|
| הסמל של GitHub | המסמך נקרא מ-GitHub. הוא לא נשמר במכשיר הזה |
| תיקייה | תיקייה במכשיר הזה |

לחצו על הסמל כדי לראות את המיקום, את המצב ואת הפעולות שאפשר לבצע משם, כמו [הצג ב-GitHub] ו-[העתקת הקישור].

## פתיחה לפי כתובת URL

הכתובת מורכבת מהמאגר וממיקום המסמך, זה אחר זה. הנתיב הוא המיקום בתוך המאגר, ולכן הסדר זהה לסדר בכתובת ה-URL של GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| מה לציין | צורת הכתיבה |
|---|---|
| המאגר בלבד (ענף ברירת המחדל) | `/github/owner/repo` |
| מסמך בתוך המאגר | `/github/owner/repo/docs/01-product/vision.md` |
| ענף או תג מסוים | מוסיפים בסוף `?ref=v1.2.0` |

כשעוברים בין דפים, גם הכתובת משתנה. לחצו על [שיתוף המסמך הזה] בסרגל הכלים כדי להעביר קישור לדף שאתם קוראים. אפשר גם להשתמש בלחצנים [חזרה] ו-[קדימה] של הדפדפן.

גם הצורה הישנה `?source=` עדיין נפתחת כרגיל. אחרי הפתיחה, הכתובת משתנה לצורה החדשה.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **שימו לב**
>
> - כשאינכם מחוברים, חלה מגבלת השימוש של GitHub API (60 בקשות בשעה). במאגר עם מסמכים רבים או בקריאה חוזרת, לחצו על [כניסה עם GitHub].
> - שם ענף שמכיל `/` (כמו `feature/xxx`) אפשר לציין באמצעות `?ref=` בצורת הכתובת שלמעלה. בצורה `?source=` אי אפשר לכתוב אותו.
> - המסמכים נטענים לפי הרשאות GitHub של הקורא. אנשים ללא הרשאת קריאה לא יראו אותם.

## פתיחת מסמכים מתיקייה מקומית

לחצו על [פתיחת מסמכים] בסרגל הכלים, ואז על [פתיחת מסמכים מתיקייה מקומית] בעמודה השמאלית, ובחרו תיקייה במכשיר. הקבצים מעובדים בתוך הדפדפן ואינם נשלחים החוצה. האפשרות זמינה בדפדפנים שתומכים בבחירת תיקייה (Chrome, Edge ועוד).
