# פתיחת מאגר GitHub

בגרסת ה-Web וב-Lunascape אפשר לפתוח מאגר GitHub ולקרוא אותו ישירות, בלי לשכפל אותו. במאגר ציבורי אין צורך בהתחברות.

## פתיחה מהמסך

1. לחצו על [פתיחת מסמכים] (סמל התיקייה) בסרגל הכלים. נפתח המסך "פתיחת מסמכים".
2. בעמודה השמאלית, בחרו את המקום שממנו תפתחו.

   | מקום | מה מופיע בו |
   |---|---|
   | הכול | כל המקומות שלמטה. מה שנפתח לאחרונה מופיע ראשון |
   | נפתחו לאחרונה | המאגרים והתיקיות שפתחתם עד כה |
   | מומלצים | המדריכים שהאתר ממליץ עליהם |
   | מאגרי GitHub | כשאתם מחוברים ל-GitHub, המאגרים שאתם יכולים לקרוא |
   | המחשב הזה | תיקיות במכשיר הזה. ב-Lunascape מופיעים כאן גם מאגרים ששכפלתם |

3. לחצו על [פתיחה] בשורה שאתם רוצים לפתוח. אפשר לצמצם את השורות בהקלדה בשדה [סינון לפי שם מסמך או שם מאגר] שלמעלה.

מאגר שאינו מופיע ברשימה אפשר לציין דרך [הזנת owner/repo ופתיחה] בעמודה השמאלית.

> **עצה**
>
> - מאגרי GitHub שמופיעים ברשימה הם מאגרים שמותקנת בהם אפליקציית GitHub בשם "Lunascape Docs" ושיש לכם הרשאת קריאה בהם. אם מאגר אינו מופיע, בקשו מבעלי המאגר להוסיף את האפליקציה.

## בדיקת מיקום המסמך

הסמל הקטן בצד שמאל של סרגל הכלים (תווית המיקום) מראה איפה נמצא המסמך שאתם קוראים כעת.

| סמל | מיקום |
|---|---|
| הסמל של GitHub | המסמך נקרא מ-GitHub. הוא לא נשמר במכשיר הזה |
| מחשב | תיקייה במכשיר הזה שמנוהלת על ידי Lunascape. מוצגים גם שם הענף ב-Git ומספר הקבצים ששיניתם |
| תיקייה | תיקייה במכשיר הזה |

לחיצה על הסמל מציגה את המיקום, את המצב ואת הפעולות שאפשר לבצע משם (כמו [הצג ב-GitHub] ו-[העתקת הקישור]).

## שכפול מאגר ב-Lunascape

ב-Lunascape אפשר לשכפל מאגר GitHub למכשיר הזה, ולערוך ולבצע commit באמצעות Git.

- במסך "פתיחת מסמכים", לחצו על [שכפול] בשורה של המאגר.
- כשאתם קוראים מאגר שנפתח מ-GitHub, לחצו על תווית המיקום ואז על [שכפול למחשב הזה]. בסיום השכפול, אותו מסמך נפתח בגרסה שבמכשיר הזה.

ליד מאגר ששוכפל מוצג ברשימה "נמצא במחשב הזה", ו-[פתח במחשב הזה] מופיע ראשון.

## פתיחה לפי כתובת URL

הכתובת בנויה ממיקום המאגר וממיקום המסמך, זה אחר זה. הנתיב הוא המיקום בתוך המאגר, ולכן הסדר זהה לסדר בכתובת ה-URL של GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| מה מציינים | צורת הכתיבה |
|---|---|
| המאגר בלבד (ענף ברירת המחדל) | `/github/owner/repo` |
| מסמך בתוך המאגר | `/github/owner/repo/docs/01-product/vision.md` |
| ענף או תג מסוים | מוסיפים בסוף `?ref=v1.2.0` |

כשעוברים בין דפים, גם הכתובת משתנה. לחיצה על [שיתוף המסמך הזה] בסרגל הכלים מאפשרת לשלוח קישור לדף שאתם קוראים כעת. אפשר להשתמש גם בלחצנים [חזרה] ו-[קדימה] של הדפדפן.

הצורה הישנה `?source=` עדיין נפתחת כרגיל. אחרי הפתיחה, הכתובת נכתבת מחדש בצורה החדשה.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **שימו לב**
>
> - כשאינכם מחוברים, חלה מגבלת השימוש ב-GitHub API (‏60 בקשות בשעה). במאגרים עם מסמכים רבים או בקריאה חוזרת, התחברו באמצעות [כניסה עם GitHub].
> - שמות ענפים שמכילים `/` (כמו `feature/xxx`) אפשר לציין באמצעות `?ref=` בצורת הכתובת שלמעלה. בצורה `?source=` אי אפשר לכתוב אותם.
> - המסמכים נטענים עם הרשאות GitHub של הקורא. אנשים ללא הרשאת קריאה לא יראו אותם.

## פתיחת מסמכים מתיקייה מקומית

לחצו על [פתיחת מסמכים] בסרגל הכלים, ובחרו תיקייה במכשיר דרך [פתיחת מסמכים מתיקייה מקומית] בעמודה השמאלית. הקבצים מעובדים בתוך הדפדפן ואינם נשלחים החוצה. האפשרות זמינה בדפדפנים שתומכים בבחירת תיקייה (Chrome, Edge ועוד).
