# פתיחת מאגר של GitHub

בגרסת הרשת פותחים מסמכים על ידי ציון מאגר של GitHub. במאגר ציבורי אין צורך בהתחברות.

## פתיחה מהמסך

1. פתחו את <https://docs.lunascape.org/>.
2. לחצו על [פתיחת מסמכים] (סמל התיקייה) בסרגל הכלים.
3. הזינו את המאגר תחת [ציון מאגר ישירות] ולחצו על [פתיחה].
   כשאתם מחוברים ל‑GitHub, אפשר גם לבחור מתוך רשימה תחת [בחירה מתוך מאגרים שניתן לקרוא].

> **טיפ**
>
> - סמל GitHub שלצידו פותח את המסמך שאתם קוראים כעת ב‑github.com. אין זו פעולה של פתיחת מסמכים.

## פתיחה באמצעות כתובת

הכתובת מציבה את המאגר ואת מיקום המסמך זה אחר זה. הנתיב הוא המיקום בתוך המאגר, ולכן סדרו זהה לזה של כתובת GitHub.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| מה מציינים | צורת הכתיבה |
|---|---|
| מאגר בלבד (ענף ברירת המחדל) | `/github/owner/repo` |
| מסמך בתוך המאגר | `/github/owner/repo/docs/01-product/vision.md` |
| ציון ענף או תג | הוסיפו בסוף `?ref=v1.2.0` |

כשעוברים בין דפים, גם הכתובת משתנה. לחיצה על [שיתוף המסמך הזה] בסרגל הכלים מאפשרת למסור קישור לדף שאתם קוראים כעת. אפשר להשתמש גם ב‑[חזרה] ו‑[קדימה] של הדפדפן.

גם הצורה הקודמת `?source=` נפתחת כמו קודם. לאחר הפתיחה היא נכתבת מחדש בצורה החדשה.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **שימו לב**
>
> - במצב שאינכם מחוברים חלה מגבלת השימוש של ‎GitHub API‏ (60 פעמים בשעה). במאגרים עם מסמכים רבים או בעיון חוזר, בצעו [כניסה עם GitHub].
> - שמות ענף הכוללים `/` (כגון `feature/xxx`) ניתנים לציון באמצעות `?ref=` בצורת הכתובת שלמעלה. בצורת `?source=` אי אפשר לכתוב אותם.
> - המסמכים נטענים בהרשאות ה‑GitHub של הקורא. מי שאין לו הרשאת קריאה לא יראה אותם.

## פתיחת מסמכים מתיקייה מקומית

לחצו על [פתיחת מסמכים] בסרגל הכלים, ומתוך [פתיחת מסמכים מתיקייה מקומית] שמתחת לרשימה בחרו תיקייה שבמחשב. הקבצים מעובדים בתוך הדפדפן ואינם נשלחים החוצה. אפשר להשתמש בכך בדפדפנים התומכים בבחירת תיקייה (Chrome,‏ Edge ואחרים).
