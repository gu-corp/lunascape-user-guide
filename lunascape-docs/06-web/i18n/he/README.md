# מה אפשר לעשות בגרסת הרשת

גרסת דפדפן הרשת של Lunascape Docs זמינה בכתובת <https://docs.lunascape.org/>. בלי התקנה, אפשר לקרוא מסמכים שנמצאים ב‑GitHub כמו אתר אינטרנט.

## מה אפשר לעשות

| תכונה | תיאור |
|---|---|
| עיון במאגרים ציבוריים | פותח את המסמכים של מאגר ציבורי ב‑GitHub בלי התחברות |
| עיון במאגרים פרטיים | לאחר התחברות ב‑GitHub אפשר לפתוח מאגרים שיש לך הרשאת קריאה אליהם |
| עיון בתיקייה מקומית | [פתיחת מסמכים] ואחריו [פתיחת מסמכים מתיקייה מקומית] פותחים תיקייה שבמכשיר (בדפדפנים נתמכים בלבד) |
| תכונות קריאה | INDEX, קישורים, היסטוריה, סינון, תוכן העניינים בדף, החלפת שפה והחלפת ערכת נושא. זהה לגרסת VS Code |
| תרשימים ונוסחאות | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose ונוסחאות KaTeX |
| טיוטות | עריכת מסמכים ושמירת השינויים כטיוטה במכשיר. שום דבר לא נכתב אל המאגר |
| קישור ישיר לדף | כתובת URL יכולה לציין את המאגר ואת הדף, כך שאפשר לפתוח דף מסוים ישירות |

## הבדלים מגרסת VS Code

- בדיקת מסמכים, יצירה מתבנית, הפקת הצעות תרגום וארגון מתוך INDEX אינם קיימים בגרסת הרשת.
- תרשימי TikZ אינם מוצגים.
- תוכן העריכה אינו נכתב אל המאגר אלא הופך לטיוטה במכשיר. "בקשת פרסום", השולחת טיוטה כ‑Pull Request, ממומשת אך אינה מופעלת במציג הציבורי. כדי להחיל שינויים על המאגר, ערוך בגרסת VS Code או בעותק מקומי.
