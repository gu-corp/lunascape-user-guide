# פרסום המסמכים שלך באינטרנט

אפשר לפרסם את המסמכים שבמאגר שלך כאתר אינטרנט ב‑GitHub Pages או בכל אחסון סטטי אחר. יש שתי דרכים לעשות זאת. השלבים האלה מיועדים למפתחים שיכולים לשכפל את המאגר של Lunascape Docs ולהשתמש ב‑`npm`.

## דרך 1: הצבת שני קובצי המציג

בדרך זו מציבים רק את המציג עצמו (`index.html` ו‑`lsdoc.js`), והמסמכים נטענים מ‑GitHub. המסמכים עצמם אינם חלק מהאתר, ולכן הדרך הזו בטוחה גם למאגרים פרטיים (הקוראים מתחברים דרך GitHub).

1. הריצו את הפקודה הבאה במאגר של Lunascape Docs.

   ```sh
   npm run build:viewer
   ```

   הקבצים `index.html` ו‑`lsdoc.js` נוצרים בתיקייה `dist/viewer/`.
2. הציבו את שני הקבצים בתיקייה `docs/` של המאגר שברצונכם לפרסם.
3. הפעילו את GitHub Pages.

שורש התיעוד שיוצג נקבע לפי הסדר הזה.

1. ההגדרה `source` שבתוך `index.html`
2. הערך `repository` שבקובץ `lunascape-docs.json` באותה תיקייה
3. הסקה מתוך הכתובת `*.github.io` ומבנה הענפים

## דרך 2: ייצוא אתר סטטי הכולל את המסמכים

בדרך זו מייצאים את המציג יחד עם קובצי המסמכים ומאחסנים את התוצאה כמות שהיא.

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

הפלט כולל את המציג על כל חלקיו, את המסמכים שתחת `docs/`, את קובץ הרשימה `lunascape-docs-manifest.json` ואת `.nojekyll`. הציבו את הפלט ב‑S3 או ב‑GitHub Pages כדי לפרסם אותו. דוגמה לפרסום אוטומטי באמצעות GitHub Actions מופיעה בקובץ `examples/workflows/publish-docs-pages.yml` שבמאגר.

> **שימו לב**
>
> - **אין לייצא מסמכים ממאגר פרטי ולהציב אותם ב‑GitHub Pages.** GitHub Pages מחוץ ל‑Enterprise Cloud פתוח לצפייה לכולם. אם נדרש פרסום מוגבל, השתמשו בדרך 1 ובקשו מהקוראים להתחבר דרך GitHub.
> - פתיחת `index.html` ישירות באמצעות `file://` אינה פועלת, משום שהדפדפן חוסם טעינת קבצים סמוכים והרצת מודולי ES בדרך זו. לבדיקה מקומית השתמשו בגרסת VS Code או בשרת HTTP.
> - ספריות הציור של TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob ו‑Penrose נטענות בעת ההצגה. באתר המיוצא הציבו גם את התיקייה `vendor/`.
