# צפייה במאגר פרטי

את המסמכים שבמאגרים פרטיים אפשר לקרוא לאחר כניסה עם GitHub, ורק במאגרים שיש לך בהם הרשאת קריאה. ל־Lunascape Docs אין חשבונות או הרשאות משלו.

## התחברות ופתיחה

1. פתח את <https://docs.lunascape.org/>.
   כאשר מצוין מסמך פרטי, או כאשר עדיין לא התחברת, מופיע מסך ההתחברות.
2. לחץ על [כניסה עם GitHub].
   מסך האימות של GitHub נפתח בחלון קופץ.
3. לאחר ההתחברות, לחץ על [פתיחת מסמכים] בסרגל הכלים ובחר את המאגר שברצונך לפתוח תחת [בחירה מתוך מאגרים שניתן לקרוא].

> **טיפ**
>
> - שם החשבון המחובר מוצג בסרגל הכלים. גם [יציאה] וגם [כניסה עם חשבון אחר] מתבצעות מכאן.
> - ברשימה מופיעים המאגרים של החשבונות (ארגונים או יחידים) שבהם מותקן ה־GitHub App‏ „Lunascape Docs”, מבין אלה שיש לך בהם הרשאת קריאה.

## הגדרות שמבצע בעל המאגר

אם המאגר המבוקש אינו מופיע ברשימה, על בעל המאגר או על מנהל הארגון להתקין את ה־GitHub App‏ „Lunascape Docs”.

- ההרשאות הנדרשות הן Contents (קריאה וכתיבה) ו־Pull requests (קריאה וכתיבה). הקריאה משמשת לצפייה; הכתיבה משמשת לבקשת פרסום מהאינטרנט (Pull Request). Lunascape Docs אינו שומר את תוכן המסמכים.
- יחידת ההתקנה היא החשבון (ארגון או יחיד). קובעים אם היעד יהיה „All repositories” (הכולל אוטומטית גם מאגרים שייווצרו בהמשך) או רק המאגרים שנבחרו.

| מצב | שלבים |
|---|---|
| התקנה חדשה בחשבון ארגון או יחיד | מתבצעת מ[דף ההתקנה](https://github.com/apps/lunascape-docs/installations/new) |
| הוספת מאגר בארגון שבו כבר הותקן | מגדירים ב־Settings של הארגון → GitHub Apps → Lunascape Docs → Configure → Repository access |

גם כאשר מתקינים לארגון כולו, כל חבר יכול לצפות רק במאגרים שיש לו בהם הרשאת קריאה. בקשת פרסום ניתן לשלוח רק למאגרים שיש לו בהם הרשאת כתיבה.

> **טיפ**
> - בהתקנה חדשה, ההרשאות הנדרשות מוצגות כרשימה במסך ההתקנה, ולחיצה על „Install” משמעה אישורן. אין צורך בפעולה נוספת.
> - ארגון שהתקין את היישום עוד לפני הוספת הרשאה יקבל דוא״ל לאישור אצל המנהלים, וכפתור אישור יופיע בראש Settings של הארגון → GitHub Apps → Lunascape Docs → Configure. עד לאישור, בארגון זה אפשר רק לצפות, ושליחת בקשת פרסום מציגה „נדרשת הענקת הרשאת כתיבה”.
> - את ההרשאות הפעילות כרגע אפשר לבדוק באותו מסך Configure. בחשבון אישי הנתיב הוא Settings → Applications → Installed GitHub Apps.
> - אם הוסר בטעות מאגר מהיעד או שהיישום הוסר לגמרי, התקנה מחדש מ[דף ההתקנה](https://github.com/apps/lunascape-docs/installations/new) תחזיר את המצב לקדמותו. הודעת הדחייה של בקשת פרסום כוללת קישור למסך שבו מתקנים זאת.
> - אם אין רצון שהמאגר יקבל בקשות פרסום, כותבים ב־`lunascape-docs.json` את `"publish": { "enabled": false }`. הצפייה נשארת זמינה כרגיל.
