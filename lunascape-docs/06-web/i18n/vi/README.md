# Những gì bản Web làm được

Bản Web của Lunascape Docs được cung cấp tại <https://docs.lunascape.org/>. Bạn có thể đọc tài liệu trên GitHub như một trang web mà không cần cài đặt gì.

## Các tính năng

| Tính năng | Nội dung |
|---|---|
| Xem kho lưu trữ công khai | Mở tài liệu của kho lưu trữ công khai trên GitHub mà không cần đăng nhập |
| Xem kho lưu trữ riêng tư | Sau khi đăng nhập bằng GitHub, mở được các kho lưu trữ mà bạn có quyền đọc |
| Xem thư mục trên máy | Chọn [Mở tài liệu] rồi [Mở tài liệu từ thư mục trên máy] để mở một thư mục trên thiết bị (chỉ với trình duyệt hỗ trợ) |
| Tính năng đọc | INDEX, liên kết, lịch sử, lọc, mục lục trong trang, chuyển ngôn ngữ, chuyển giao diện. Giống với bản VS Code |
| Sơ đồ và công thức toán | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, công thức toán KaTeX |
| Bản nháp | Chỉnh sửa tài liệu và giữ các thay đổi dưới dạng bản nháp trên thiết bị. Không ghi vào kho lưu trữ |
| Liên kết trực tiếp đến trang | Chỉ định kho lưu trữ và trang bằng URL để mở trực tiếp một trang cụ thể |

## Khác biệt so với bản VS Code

- Bản Web không có kiểm tra tài liệu, tạo từ mẫu, tạo bản dịch đề xuất và sắp xếp từ INDEX.
- Sơ đồ TikZ không được vẽ.
- Nội dung chỉnh sửa không được ghi vào kho lưu trữ mà trở thành bản nháp trên thiết bị. "Yêu cầu xuất bản", tức gửi bản nháp dưới dạng Pull Request, đã được cài đặt nhưng chưa bật trên trình xem công khai. Để phản ánh vào kho lưu trữ, hãy chỉnh sửa bằng bản VS Code hoặc trong bản sao trên máy.
