# 保存草稿

在 Web 版中编辑文档时，更改不会写入仓库，而是作为"草稿"保存在浏览器中。

## 创建草稿

1. 打开文档，按右下角的 [编辑]。
2. 编辑后按 [保存]。
   界面会显示"已保存为草稿"，更改保存在浏览器中。

- 有草稿的文档会在 INDEX 中带有标记。正文上方会显示"此文档是本设备内的草稿（未发布）"。
- 工具栏的 [草稿] 会显示件数，按下后打开草稿列表。

## 丢弃草稿

- 要逐个文档丢弃，请按正文上方的 [丢弃草稿]。
- 要全部丢弃，请在草稿列表中操作。

## 反映到仓库

将草稿作为 Pull Request 发送的"发布请求"功能已实现，但在公开查看器中未启用。若要反映到仓库，请使用 VS Code 版或在本地克隆中编辑。

> **注意**
>
> - 草稿保存在浏览器中（IndexedDB）。不会转移到其他浏览器或其他设备。清除浏览器的站点数据后，草稿也会消失。
> - 创建草稿后，如果仓库中的文档有更新，界面会显示"上游已更新"。请确认内容后，再判断是丢弃草稿还是继续使用。
> - 如果是通过 [打开文档] 打开本地文件夹进行编辑，在浏览器支持的情况下会直接保存到文件。在不支持的浏览器中，仅在该会话期间保留。
