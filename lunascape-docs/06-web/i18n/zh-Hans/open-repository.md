# 打开 GitHub 仓库

在 Web 版和 Lunascape 中，无需复制 GitHub 仓库，即可直接打开阅读。公开仓库无需登录。

## 从界面打开

1. 点击工具栏中的 [打开文档]（文件夹图标）。随即打开“打开文档”界面。
2. 在左栏中选择要打开的位置。

   | 位置 | 列出的内容 |
   |---|---|
   | 全部 | 下列所有内容。最近打开的排在最前 |
   | 最近打开 | 以往打开过的仓库和文件夹 |
   | 推荐 | 本网站介绍的手册 |
   | GitHub 仓库 | 已使用 GitHub 登录时，您可以阅读的仓库 |
   | 本机 | 此设备上的文件夹。在 Lunascape 中，已复制的仓库也会列在这里 |

3. 点击要打开的行中的 [打开]。在上方的 [按文档名或仓库名筛选] 中输入内容，可以筛选行。

列表中没有的仓库，可通过左栏的 [输入 owner/repo 打开] 指定。

> **提示**
>
> - 列表中显示的 GitHub 仓库，是已安装 GitHub App“Lunascape Docs”且您拥有读取权限的仓库。如果找不到，请联系仓库所有者添加该 App。

## 确认文档的位置

工具栏左侧的小图标（位置标签）显示当前阅读的文档所在的位置。

| 图标 | 位置 |
|---|---|
| GitHub 标志 | 从 GitHub 读取。未保存在此设备上 |
| 电脑 | 由 Lunascape 管理的此设备上的文件夹。还会显示 Git 分支名和已更改的文件数 |
| 文件夹 | 此设备上的文件夹 |

点击图标，会显示位置、状态以及可从此处执行的操作（[在 GitHub 上查看]、[复制链接] 等）。

## 在 Lunascape 中复制仓库

在 Lunascape 中，可以将 GitHub 仓库复制到此设备，并使用 Git 进行编辑和提交。

- 在“打开文档”界面中，点击仓库所在行的 [创建副本]。
- 从 GitHub 打开阅读时，点击位置标签，然后点击 [复制到本机]。复制完成后，同一文档会以此设备上的版本打开。

已复制的仓库在列表中标注为“已在本机”，并且 [在本机打开] 排在前面。

## 通过 URL 打开

地址由仓库和文档的位置依次排列而成。路径是文档在仓库中的位置，因此与 GitHub 的 URL 排列方式相同。

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 指定内容 | 写法 |
|---|---|
| 仅仓库（默认分支） | `/github/owner/repo` |
| 仓库中的文档 | `/github/owner/repo/docs/01-product/vision.md` |
| 指定分支或标签 | 在末尾加上 `?ref=v1.2.0` |

切换页面时，地址也会随之改变。点击工具栏中的 [分享此文档]，可以将当前阅读页面的链接发给他人。也可以使用浏览器的 [返回] [前进]。

旧的 `?source=` 形式仍可照常打开。打开后会改写为新形式。

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **注意**
>
> - 未登录时，会受到 GitHub API 的使用限制（每小时 60 次）。对于文档较多的仓库或需要反复浏览时，请点击 [使用 GitHub 登录]。
> - 包含 `/` 的分支名（如 `feature/xxx`），可以通过上述地址形式中的 `?ref=` 指定。`?source=` 形式无法表示。
> - 文档会以阅读者的 GitHub 权限加载。没有读取权限的人无法看到。

## 打开本地文件夹中的文档

点击工具栏中的 [打开文档]，然后在左栏中点击 [打开本地文件夹中的文档]，选择此设备中的文件夹。文件在浏览器内处理，不会发送到外部。可在支持选择文件夹的浏览器（Chrome、Edge 等）中使用。
