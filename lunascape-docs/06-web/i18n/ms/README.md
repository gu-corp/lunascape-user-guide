# Apa yang boleh dilakukan oleh pemapar Web

Lunascape Docs versi pelayar Web tersedia di <https://docs.lunascape.org/>. Tanpa memasang apa-apa, anda boleh membaca dokumen di GitHub seperti sebuah tapak web.

## Ciri

| Ciri | Kandungan |
|---|---|
| Melihat repositori awam | Membuka dokumen repositori awam GitHub tanpa log masuk |
| Melihat repositori persendirian | Selepas log masuk dengan GitHub, membuka repositori yang anda mempunyai kebenaran baca |
| Melihat folder setempat | Dengan [Buka dokumen] kemudian [Buka dokumen daripada folder setempat], membuka folder dalam peranti anda (pelayar yang disokong sahaja) |
| Fungsi bacaan | INDEX, pautan, sejarah, penapisan, senarai kandungan dalam halaman, penukaran bahasa dan penukaran tema. Sama seperti versi VS Code |
| Rajah dan rumus matematik | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, rumus matematik KaTeX |
| Draf | Menyunting dokumen dan menyimpan perubahan sebagai draf dalam peranti anda. Tiada apa-apa ditulis ke repositori |
| Pautan terus ke halaman | URL boleh menyatakan repositori dan halaman, jadi halaman tertentu boleh dibuka terus |

## Perbezaan daripada versi VS Code

- Semakan dokumen, penciptaan daripada templat, penjanaan cadangan terjemahan dan penyusunan daripada INDEX tiada dalam pemapar Web.
- Rajah TikZ tidak dilukis.
- Suntingan tidak ditulis ke repositori; ia menjadi draf dalam peranti anda. "Permintaan penerbitan", yang menghantar draf sebagai Pull Request, telah dilaksanakan tetapi tidak diaktifkan pada pemapar awam. Untuk menyalurkannya ke repositori, sunting dengan versi VS Code atau dalam klon setempat anda.
