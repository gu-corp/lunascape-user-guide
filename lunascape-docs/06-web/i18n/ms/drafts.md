# Menyimpan draf

Apabila anda mengedit dokumen dalam versi Web, perubahan tidak ditulis ke repositori, tetapi disimpan di dalam pelayar sebagai "draf".

## Membuat draf

1. Buka dokumen dan tekan [Edit] di bahagian kanan bawah.
2. Edit dan tekan [Simpan].
   "Disimpan sebagai draf" akan dipaparkan dan perubahan disimpan di dalam pelayar.

- Dokumen yang mempunyai draf akan mempunyai lencana dalam INDEX. Di atas teks, "Dokumen ini ialah draf dalam peranti (belum diterbitkan)" akan dipaparkan.
- [Draf] pada bar alat memaparkan bilangannya, dan menekannya akan membuka senarai draf.

## Membuang draf

- Untuk membuang draf bagi satu dokumen, tekan [Buang draf] di atas teks.
- Untuk membuang semuanya, lakukan dari senarai draf.

## Menerapkan pada repositori

"Permintaan penerbitan", yang menghantar draf sebagai Pull Request, telah dilaksanakan tetapi tidak diaktifkan pada pemapar awam. Untuk menerapkan perubahan pada repositori, sila edit dengan versi VS Code atau dalam klon setempat.

> **Perhatian**
>
> - Draf disimpan dalam pelayar (IndexedDB). Draf tidak dibawa ke pelayar lain atau peranti lain. Jika anda memadamkan data tapak pelayar, draf juga akan hilang.
> - Jika dokumen di pihak repositori dikemas kini selepas anda membuat draf, "Hulu telah dikemas kini" akan dipaparkan. Semak kandungannya, kemudian tentukan sama ada hendak membuang draf atau terus menggunakannya.
> - Jika anda membuka folder setempat daripada [Buka dokumen] dan mengeditnya, perubahan akan disimpan terus ke fail jika pelayar menyokongnya. Pada pelayar yang tidak menyokongnya, perubahan hanya disimpan sepanjang sesi tersebut.
