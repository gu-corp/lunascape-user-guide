# Ce poate face versiunea Web

Versiunea pentru browser Web a Lunascape Docs este publicată la <https://docs.lunascape.org/>. Fără nicio instalare, puteți citi documentele de pe GitHub ca pe un site Web.

## Ce puteți face

| Funcție | Descriere |
|---|---|
| Consultarea depozitelor publice | Deschide documentele unui depozit public de pe GitHub, fără conectare |
| Consultarea depozitelor private | După conectarea cu GitHub, puteți deschide depozitele la care aveți drept de citire |
| Consultarea unui folder local | Cu [Deschide documente], apoi [Deschide documente dintr-un folder local], deschideți un folder de pe dispozitiv (numai în browserele compatibile) |
| Funcții de citire | INDEX, linkuri, istoric, filtrare, cuprinsul paginii, schimbarea limbii și schimbarea temei. La fel ca în versiunea VS Code |
| Diagrame și formule matematice | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, formule matematice KaTeX |
| Ciorne | Editați documentele și păstrați modificările ca ciorne pe dispozitiv. Nu se scrie nimic în depozit |
| Linkuri directe către pagini | URL-ul poate indica depozitul și pagina, astfel încât o anumită pagină se deschide direct |

## Diferențe față de versiunea VS Code

- Verificarea documentelor, crearea dintr-un șablon, generarea propunerilor de traducere și organizarea din INDEX nu există în versiunea Web.
- Diagramele TikZ nu sunt redate.
- Modificările nu se scriu în depozit, ci devin ciorne pe dispozitiv. „Cererea de publicare”, care trimite ciornele sub formă de pull request, este implementată, dar nu este activată în vizualizatorul public. Pentru a modifica depozitul, editați cu versiunea VS Code sau într-o clonă locală.
