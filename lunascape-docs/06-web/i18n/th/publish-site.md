# เผยแพร่เอกสารของคุณบนเว็บ

คุณสามารถเผยแพร่เอกสารในที่เก็บของคุณเป็นเว็บไซต์ได้ด้วย GitHub Pages หรือโฮสติงแบบสแตติกใดก็ได้ วิธีเผยแพร่มี 2 วิธี ขั้นตอนเหล่านี้สำหรับนักพัฒนาที่ clone ที่เก็บของ Lunascape Docs และใช้ `npm` ได้

## วิธีที่ 1: วางไฟล์ของตัวแสดงผล 2 ไฟล์

วางเฉพาะตัวแสดงผล (`index.html` และ `lsdoc.js`) แล้วให้โหลดเอกสารจาก GitHub เอกสารไม่ได้รวมอยู่ในเว็บไซต์ จึงปลอดภัยแม้กับที่เก็บแบบไม่เปิดเผย (ผู้อ่านจะลงชื่อเข้าใช้ด้วย GitHub)

1. เรียกใช้คำสั่งต่อไปนี้ในที่เก็บของ Lunascape Docs

   ```sh
   npm run build:viewer
   ```

   ระบบจะสร้าง `index.html` และ `lsdoc.js` ไว้ใน `dist/viewer/`
2. วางไฟล์ทั้ง 2 ไฟล์ไว้ใน `docs/` ของที่เก็บที่คุณต้องการเผยแพร่
3. เปิดใช้งาน GitHub Pages

รากเอกสารที่จะแสดงถูกกำหนดตามลำดับต่อไปนี้

1. การตั้งค่า `source` ภายใน `index.html`
2. `repository` ที่ระบุไว้ใน `lunascape-docs.json` ในโฟลเดอร์เดียวกัน
3. การอนุมานจาก URL ของ `*.github.io` และโครงสร้างของสาขา

## วิธีที่ 2: ส่งออกเว็บไซต์แบบสแตติกที่รวมเอกสารไว้ด้วย

ส่งออกตัวแสดงผลพร้อมกับไฟล์เอกสาร แล้วนำผลลัพธ์ไปโฮสต์ได้ทันที

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

ผลลัพธ์ประกอบด้วยชุดตัวแสดงผล เอกสารที่อยู่ใต้ `docs/` ไฟล์รายการ `lunascape-docs-manifest.json` และ `.nojekyll` วางผลลัพธ์ไว้บน S3 หรือ GitHub Pages เพื่อเผยแพร่ ดูตัวอย่างการเผยแพร่อัตโนมัติด้วย GitHub Actions ได้ที่ `examples/workflows/publish-docs-pages.yml` ในที่เก็บ

> **ข้อควรระวัง**
>
> - **อย่าส่งออกเอกสารของที่เก็บแบบไม่เปิดเผยไปวางบน GitHub Pages** GitHub Pages ที่ไม่ใช่ Enterprise Cloud นั้นใครก็อ่านได้ หากต้องการเผยแพร่แบบจำกัด ให้ใช้วิธีที่ 1 และให้ผู้อ่านลงชื่อเข้าใช้ด้วย GitHub
> - การเปิด `index.html` โดยตรงด้วย `file://` จะไม่ทำงาน เพราะเบราว์เซอร์ห้ามโหลดไฟล์ข้างเคียงและห้ามเรียกใช้ ES module ด้วยวิธีนั้น เมื่อต้องการตรวจสอบในเครื่อง ให้ใช้เวอร์ชัน VS Code หรือเซิร์ฟเวอร์ HTTP
> - ไลบรารีการวาดของ TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob และ Penrose จะถูกโหลดเมื่อแสดงผล สำหรับเว็บไซต์ที่ส่งออก ให้วางโฟลเดอร์ `vendor/` ไว้ด้วย
