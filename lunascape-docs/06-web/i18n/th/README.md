# สิ่งที่ทำได้ในเวอร์ชันเว็บ

Lunascape Docs เวอร์ชันเว็บเบราว์เซอร์เผยแพร่อยู่ที่ <https://docs.lunascape.org/> คุณอ่านเอกสารบน GitHub ได้เหมือนเว็บไซต์ โดยไม่ต้องติดตั้งอะไรเลย

## สิ่งที่ทำได้

| ความสามารถ | รายละเอียด |
|---|---|
| การอ่านที่เก็บสาธารณะ | เปิดเอกสารในที่เก็บสาธารณะของ GitHub ได้โดยไม่ต้องลงชื่อเข้าใช้ |
| การอ่านที่เก็บส่วนตัว | เมื่อลงชื่อเข้าใช้ด้วย GitHub จะเปิดที่เก็บที่คุณมีสิทธิ์อ่านได้ |
| การอ่านโฟลเดอร์ในเครื่อง | เปิดโฟลเดอร์ในเครื่องได้จาก [เปิดเอกสาร] แล้วเลือก [เปิดเอกสารจากโฟลเดอร์ในเครื่อง] (เฉพาะเบราว์เซอร์ที่รองรับ) |
| ความสามารถในการอ่าน | INDEX ลิงก์ ประวัติ การกรอง สารบัญในหน้า การสลับภาษา และการสลับธีม เหมือนกับเวอร์ชัน VS Code |
| แผนภาพและสูตรคณิตศาสตร์ | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose และสูตรคณิตศาสตร์ KaTeX |
| ฉบับร่าง | แก้ไขเอกสารและเก็บการเปลี่ยนแปลงเป็นฉบับร่างในเครื่อง โดยไม่เขียนลงในที่เก็บ |
| ลิงก์ตรงไปยังหน้า | ระบุที่เก็บและหน้าใน URL เพื่อเปิดหน้าที่ต้องการได้โดยตรง |

## ความแตกต่างจากเวอร์ชัน VS Code

- การตรวจสอบเอกสาร การสร้างจากเทมเพลต การสร้างคำแปลที่เสนอ และการจัดระเบียบจาก INDEX ไม่มีในเวอร์ชันเว็บ
- แผนภาพ TikZ จะไม่ถูกวาด
- เนื้อหาที่แก้ไขจะไม่ถูกเขียนลงในที่เก็บ แต่จะกลายเป็นฉบับร่างในเครื่อง "คำขอเผยแพร่" ซึ่งส่งฉบับร่างเป็น Pull Request นั้นมีอยู่แล้ว แต่ยังไม่ได้เปิดใช้งานในโปรแกรมดูสาธารณะ หากต้องการให้มีผลกับที่เก็บ ให้แก้ไขด้วยเวอร์ชัน VS Code หรือในสำเนาที่โคลนไว้ในเครื่อง
