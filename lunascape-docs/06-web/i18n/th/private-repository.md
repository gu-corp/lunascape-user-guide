# การเปิดดูที่เก็บส่วนตัว

เอกสารในที่เก็บส่วนตัวนั้น เมื่อคุณลงชื่อเข้าใช้ด้วย GitHub แล้ว จะเปิดดูได้เฉพาะที่เก็บที่คุณมีสิทธิ์อ่านเท่านั้น Lunascape Docs ไม่มีบัญชีหรือสิทธิ์ของตนเองแต่อย่างใด

## ลงชื่อเข้าใช้แล้วเปิด

1. เปิด <https://docs.lunascape.org/>
   เมื่อคุณระบุเอกสารส่วนตัว หรือเมื่อยังไม่ได้ลงชื่อเข้าใช้ หน้าจอลงชื่อเข้าใช้จะปรากฏขึ้น
2. กด [ลงชื่อเข้าใช้ด้วย GitHub]
   หน้าจอการรับรองตัวตนของ GitHub จะเปิดขึ้นเป็นป็อปอัป
3. เมื่อลงชื่อเข้าใช้เสร็จแล้ว ให้กด [เปิดเอกสาร] บนแถบเครื่องมือ แล้วเลือกที่เก็บที่ต้องการเปิดใน [เลือกจากที่เก็บที่อ่านได้]

> **เคล็ดลับ**
>
> - ชื่อบัญชีที่กำลังลงชื่อเข้าใช้จะแสดงบนแถบเครื่องมือ คุณสามารถ [ออกจากระบบ] หรือ [ลงชื่อเข้าใช้ด้วยบัญชีอื่น] ได้จากที่นี่เช่นกัน
> - รายการที่แสดงคือที่เก็บของบัญชี (องค์กรหรือส่วนบุคคล) ที่ติดตั้ง GitHub App "Lunascape Docs" ไว้ โดยจำกัดเฉพาะที่เก็บที่คุณมีสิทธิ์อ่าน

## การตั้งค่าที่เจ้าของที่เก็บต้องทำ

หากที่เก็บที่ต้องการไม่ปรากฏในรายการ เจ้าของที่เก็บหรือผู้ดูแลองค์กรจำเป็นต้องติดตั้ง GitHub App "Lunascape Docs"

- สิทธิ์ที่ร้องขอคือ Contents (อ่านและเขียน) และ Pull requests (อ่านและเขียน) การอ่านมีไว้เพื่อการเปิดดู ส่วนการเขียนมีไว้เพื่อคำขอเผยแพร่ (Pull Request) จากเว็บ Lunascape Docs ไม่เก็บเนื้อหาของเอกสารแต่อย่างใด
- หน่วยของการติดตั้งคือบัญชี (องค์กรหรือส่วนบุคคล) คุณสามารถตั้งค่าให้เป็น "All repositories" (รวมถึงที่เก็บที่จะสร้างขึ้นในภายหลังโดยอัตโนมัติด้วย) หรือเฉพาะที่เก็บที่เลือกไว้เท่านั้น

| สถานการณ์ | ขั้นตอน |
|---|---|
| ติดตั้งใหม่ในบัญชีองค์กรหรือส่วนบุคคล | ดำเนินการจาก[หน้าติดตั้ง](https://github.com/apps/lunascape-docs/installations/new) |
| เพิ่มที่เก็บเป้าหมายในองค์กรที่ติดตั้งไว้แล้ว | ตั้งค่าที่ Settings ขององค์กร → GitHub Apps → Lunascape Docs → Configure → Repository access |

แม้จะติดตั้งให้ทั้งองค์กร แต่ละสมาชิกก็จะเปิดดูได้เฉพาะที่เก็บที่ตนเองมีสิทธิ์อ่านเท่านั้น และจะส่งคำขอเผยแพร่ได้เฉพาะที่เก็บที่ตนเองมีสิทธิ์เขียนเท่านั้น

> **เคล็ดลับ**
> - เมื่อติดตั้งใหม่ สิทธิ์ที่ร้องขอจะแสดงเป็นรายการบนหน้าจอการติดตั้ง และเมื่อกด "Install" ก็ถือว่าได้อนุมัติแล้ว ไม่มีขั้นตอนเพิ่มเติมอีก
> - สำหรับองค์กรที่ติดตั้งไว้ตั้งแต่ก่อนที่สิทธิ์จะเพิ่มขึ้น จะมีอีเมลแจ้งยืนยันไปยังผู้ดูแล และปุ่มอนุมัติจะแสดงอยู่ด้านบนของ Settings ขององค์กร → GitHub Apps → Lunascape Docs → Configure จนกว่าจะอนุมัติ องค์กรนั้นจะเปิดดูได้อย่างเดียว และเมื่อส่งคำขอเผยแพร่จะแสดงข้อความว่า "จำเป็นต้องได้รับการมอบสิทธิ์เขียน"
> - คุณสามารถตรวจสอบได้ว่าขณะนี้เข้าใช้ด้วยสิทธิ์ใดที่หน้า Configure เดียวกันนี้ สำหรับบัญชีส่วนบุคคลคือ Settings → Applications → Installed GitHub Apps
> - หากเผลอเอาที่เก็บเป้าหมายออกหรือถอนการติดตั้ง สามารถติดตั้งใหม่จาก[หน้าติดตั้ง](https://github.com/apps/lunascape-docs/installations/new)ได้เพื่อให้กลับมาเป็นเหมือนเดิม ข้อความปฏิเสธคำขอเผยแพร่จะมีลิงก์ไปยังหน้าจอสำหรับแก้ไขแนบมาด้วย
> - หากไม่ต้องการรับคำขอเผยแพร่ทางฝั่งที่เก็บ ให้เขียน `"publish": { "enabled": false }` ลงใน `lunascape-docs.json` การเปิดดูยังใช้งานได้ตามปกติ
