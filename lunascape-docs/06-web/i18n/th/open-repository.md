# เปิดที่เก็บ GitHub

ในเวอร์ชันเว็บ คุณสามารถเปิดและอ่านที่เก็บ GitHub ได้โดยตรงโดยไม่ต้องทำสำเนา ที่เก็บสาธารณะไม่ต้องลงชื่อเข้าใช้

## เปิดจากหน้าจอ

1. กด [เปิดเอกสาร] (ไอคอนโฟลเดอร์) บนแถบเครื่องมือ หน้าจอ “เปิดเอกสาร” จะเปิดขึ้น
2. เลือกตำแหน่งที่จะเปิดในช่องด้านซ้าย

   | ตำแหน่ง | สิ่งที่แสดง |
   |---|---|
   | ทั้งหมด | ทุกรายการด้านล่าง โดยรายการที่เปิดล่าสุดจะแสดงก่อน |
   | เปิดล่าสุด | ที่เก็บและโฟลเดอร์ที่คุณเคยเปิด |
   | แนะนำ | คู่มือที่เว็บไซต์แนะนำ |
   | ที่เก็บ GitHub | เมื่อลงชื่อเข้าใช้ด้วย GitHub แล้ว จะแสดงที่เก็บที่คุณอ่านได้ |
   | คอมพิวเตอร์เครื่องนี้ | โฟลเดอร์ในอุปกรณ์นี้ |

3. กด [เปิด] ในแถวที่ต้องการ พิมพ์ใน [กรองตามชื่อเอกสารหรือชื่อที่เก็บ] ที่ด้านบนเพื่อกรองแถว

สำหรับที่เก็บที่ไม่อยู่ในรายการ ให้ระบุจาก [ป้อน owner/repo เพื่อเปิด] ในช่องด้านซ้าย

> **เคล็ดลับ**
>
> - ที่เก็บ GitHub ที่แสดงในรายการคือที่เก็บที่ติดตั้ง GitHub App “Lunascape Docs” ไว้ และคุณมีสิทธิ์อ่าน หากไม่พบที่เก็บที่ต้องการ ให้ขอให้เจ้าของที่เก็บเพิ่ม App นี้

## ตรวจสอบตำแหน่งของเอกสาร

ไอคอนเล็ก ๆ ทางด้านซ้ายของแถบเครื่องมือ (ชิปตำแหน่ง) แสดงว่าเอกสารที่คุณกำลังอ่านอยู่ที่ใด

| ไอคอน | ตำแหน่ง |
|---|---|
| เครื่องหมาย GitHub | กำลังอ่านจาก GitHub ไม่ได้บันทึกไว้ในอุปกรณ์นี้ |
| โฟลเดอร์ | โฟลเดอร์ในอุปกรณ์นี้ |

กดไอคอนเพื่อดูตำแหน่ง สถานะ และการดำเนินการที่ทำได้จากตำแหน่งนั้น (เช่น [ดูบน GitHub] และ [คัดลอกลิงก์])

## เปิดด้วย URL

ที่อยู่ประกอบด้วยที่เก็บและตำแหน่งของเอกสารเรียงต่อกัน เส้นทางคือตำแหน่งภายในที่เก็บ จึงเรียงลำดับเหมือนกับ URL ของ GitHub

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| สิ่งที่ระบุ | วิธีเขียน |
|---|---|
| เฉพาะที่เก็บ (แบรนช์เริ่มต้น) | `/github/owner/repo` |
| เอกสารภายในที่เก็บ | `/github/owner/repo/docs/01-product/vision.md` |
| ระบุแบรนช์หรือแท็ก | ต่อท้ายด้วย `?ref=v1.2.0` |

เมื่อย้ายไปหน้าอื่น ที่อยู่ก็จะเปลี่ยนตาม กด [แชร์เอกสารนี้] บนแถบเครื่องมือเพื่อส่งลิงก์ของหน้าที่กำลังอ่านอยู่ ใช้ [ย้อนกลับ] และ [ไปข้างหน้า] ของเบราว์เซอร์ได้เช่นกัน

รูปแบบ `?source=` แบบเดิมยังคงเปิดได้เหมือนเดิม หลังจากเปิดแล้ว ที่อยู่จะถูกเปลี่ยนเป็นรูปแบบใหม่

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ข้อควรระวัง**
>
> - เมื่อยังไม่ได้ลงชื่อเข้าใช้ จะมีข้อจำกัดการใช้ GitHub API (60 ครั้งต่อชั่วโมง) สำหรับที่เก็บที่มีเอกสารจำนวนมากหรือการเปิดอ่านซ้ำ ๆ ให้กด [ลงชื่อเข้าใช้ด้วย GitHub]
> - ชื่อแบรนช์ที่มี `/` (เช่น `feature/xxx`) ระบุได้ด้วย `?ref=` ในรูปแบบที่อยู่ด้านบน แต่เขียนในรูปแบบ `?source=` ไม่ได้
> - เอกสารจะถูกโหลดด้วยสิทธิ์ GitHub ของผู้อ่าน ผู้ที่ไม่มีสิทธิ์อ่านจะไม่เห็นเอกสาร

## เปิดเอกสารจากโฟลเดอร์ในเครื่อง

กด [เปิดเอกสาร] บนแถบเครื่องมือ แล้วเลือกโฟลเดอร์ในอุปกรณ์จาก [เปิดเอกสารจากโฟลเดอร์ในเครื่อง] ในช่องด้านซ้าย ไฟล์จะถูกประมวลผลภายในเบราว์เซอร์และไม่ถูกส่งออกไปภายนอก ใช้ได้ในเบราว์เซอร์ที่รองรับการเลือกโฟลเดอร์ (เช่น Chrome และ Edge)
