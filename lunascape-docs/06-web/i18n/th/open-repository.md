# การเปิดที่เก็บของ GitHub

ในเวอร์ชันเว็บ คุณเปิดเอกสารโดยระบุที่เก็บของ GitHub หากเป็นที่เก็บสาธารณะก็ไม่จำเป็นต้องลงชื่อเข้าใช้

## การเปิดจากหน้าจอ

1. เปิด <https://docs.lunascape.org/>
2. กด [เปิดเอกสาร] (ไอคอนรูปโฟลเดอร์) บนแถบเครื่องมือ
3. ป้อนที่เก็บใน [ระบุที่เก็บโดยตรง] แล้วกด [เปิด]
   เมื่อคุณลงชื่อเข้าใช้ GitHub อยู่ คุณยังเลือกจากรายการใน [เลือกจากที่เก็บที่อ่านได้] ได้ด้วย

> **คำแนะนำ**
>
> - ไอคอน GitHub ที่อยู่ข้าง ๆ จะเปิดเอกสารที่คุณกำลังอ่านอยู่บน github.com ไม่ใช่การเปิดเอกสารที่นี่

## การเปิดด้วย URL

ที่อยู่นี้เรียงชื่อที่เก็บและตำแหน่งของเอกสารตามลำดับเดิม เนื่องจากพาธคือตำแหน่งภายในที่เก็บ ลำดับจึงเหมือนกับ URL ของ GitHub

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| สิ่งที่ระบุ | วิธีเขียน |
|---|---|
| เฉพาะที่เก็บ (สาขาเริ่มต้น) | `/github/owner/repo` |
| เอกสารภายในที่เก็บ | `/github/owner/repo/docs/01-product/vision.md` |
| ระบุสาขาหรือแท็ก | ต่อท้ายด้วย `?ref=v1.2.0` |

เมื่อคุณย้ายหน้า ที่อยู่ก็จะเปลี่ยนตามไปด้วย กด [แชร์เอกสารนี้] บนแถบเครื่องมือเพื่อส่งลิงก์ของหน้าที่คุณกำลังอ่านอยู่ให้ผู้อื่น ปุ่ม [ย้อนกลับ] และ [ไปข้างหน้า] ของเบราว์เซอร์ก็ใช้ได้เช่นกัน

รูปแบบ `?source=` เดิมยังคงเปิดได้เหมือนเดิม และหลังจากเปิดแล้วจะถูกเขียนใหม่เป็นรูปแบบใหม่

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ข้อควรระวัง**
>
> - ในสถานะที่ยังไม่ได้ลงชื่อเข้าใช้ จะมีขีดจำกัดการใช้งาน GitHub API (60 ครั้งต่อชั่วโมง) สำหรับที่เก็บที่มีเอกสารจำนวนมากหรือการอ่านซ้ำ ๆ โปรด [ลงชื่อเข้าใช้ด้วย GitHub]
> - ชื่อสาขาที่มี `/` (เช่น `feature/xxx`) ระบุได้ด้วย `?ref=` ในรูปแบบที่อยู่ข้างต้น รูปแบบ `?source=` เขียนแบบนั้นไม่ได้
> - เอกสารจะถูกโหลดด้วยสิทธิ์ GitHub ของผู้อ่านเอง ผู้ที่ไม่มีสิทธิ์อ่านจะไม่เห็นเอกสารนั้น

## การเปิดเอกสารจากโฟลเดอร์ในเครื่อง

กด [เปิดเอกสาร] บนแถบเครื่องมือ แล้วเลือกโฟลเดอร์ในอุปกรณ์จาก [เปิดเอกสารจากโฟลเดอร์ในเครื่อง] ที่อยู่ใต้รายการ ไฟล์จะถูกประมวลผลภายในเบราว์เซอร์และไม่ถูกส่งออกไปภายนอก ใช้ได้กับเบราว์เซอร์ที่รองรับการเลือกโฟลเดอร์ (Chrome, Edge และอื่น ๆ)
