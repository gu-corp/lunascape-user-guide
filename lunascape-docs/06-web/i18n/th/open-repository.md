# เปิดที่เก็บ GitHub

ในเวอร์ชันเว็บและใน Lunascape คุณเปิดที่เก็บ GitHub และอ่านได้ทันทีโดยไม่ต้องทำสำเนา ที่เก็บสาธารณะไม่ต้องลงชื่อเข้าใช้

## เปิดจากหน้าจอ

1. กด [เปิดเอกสาร] (ไอคอนโฟลเดอร์) บนแถบเครื่องมือ หน้าจอ “เปิดเอกสาร” จะเปิดขึ้น
2. เลือกตำแหน่งที่จะเปิดในคอลัมน์ด้านซ้าย

   | ตำแหน่ง | สิ่งที่แสดง |
   |---|---|
   | ทั้งหมด | ทุกรายการด้านล่าง โดยรายการที่เปิดล่าสุดจะอยู่บนสุด |
   | เปิดล่าสุด | ที่เก็บและโฟลเดอร์ที่คุณเคยเปิด |
   | แนะนำ | คู่มือที่เว็บไซต์แนะนำ |
   | ที่เก็บ GitHub | ที่เก็บที่คุณอ่านได้ เมื่อลงชื่อเข้าใช้ GitHub อยู่ |
   | คอมพิวเตอร์เครื่องนี้ | โฟลเดอร์ในอุปกรณ์นี้ ใน Lunascape ที่เก็บที่ทำสำเนาไว้จะแสดงที่นี่ด้วย |

3. กด [เปิด] ในแถวที่ต้องการ พิมพ์ใน [กรองตามชื่อเอกสารหรือชื่อที่เก็บ] ที่ด้านบนเพื่อกรองแถว

สำหรับที่เก็บที่ไม่อยู่ในรายการ ให้ระบุจาก [ป้อน owner/repo เพื่อเปิด] ในคอลัมน์ด้านซ้าย

> **เคล็ดลับ**
>
> - ที่เก็บ GitHub ที่แสดงในรายการคือที่เก็บที่ติดตั้ง GitHub App “Lunascape Docs” ไว้และคุณมีสิทธิ์อ่าน หากไม่พบที่เก็บที่ต้องการ ให้ขอให้เจ้าของที่เก็บเพิ่ม App นี้

## ตรวจสอบตำแหน่งของเอกสาร

ไอคอนขนาดเล็กทางด้านซ้ายของแถบเครื่องมือ (ชิปตำแหน่ง) แสดงว่าเอกสารที่คุณกำลังอ่านอยู่ที่ใด

| ไอคอน | ตำแหน่ง |
|---|---|
| เครื่องหมาย GitHub | กำลังอ่านจาก GitHub ไม่ได้บันทึกไว้ในอุปกรณ์นี้ |
| คอมพิวเตอร์ | โฟลเดอร์ในอุปกรณ์นี้ที่ Lunascape จัดการ แสดงชื่อแบรนช์ Git และจำนวนไฟล์ที่เปลี่ยนแปลงด้วย |
| โฟลเดอร์ | โฟลเดอร์ในอุปกรณ์นี้ |

กดไอคอนเพื่อดูตำแหน่ง สถานะ และการดำเนินการที่ทำได้จากตำแหน่งนั้น (เช่น [ดูบน GitHub] และ [คัดลอกลิงก์])

## ทำสำเนาที่เก็บใน Lunascape

ใน Lunascape คุณทำสำเนาที่เก็บ GitHub มายังอุปกรณ์นี้ แล้วแก้ไขและคอมมิตด้วย Git ได้

- ในหน้าจอ “เปิดเอกสาร” ให้กด [ทำสำเนา] ในแถวของที่เก็บ
- ขณะอ่านที่เก็บที่เปิดจาก GitHub ให้กดชิปตำแหน่ง แล้วกด [ทำสำเนาไปยังคอมพิวเตอร์เครื่องนี้] เมื่อทำสำเนาเสร็จ เอกสารเดียวกันจะเปิดจากสำเนาในอุปกรณ์นี้

ที่เก็บที่ทำสำเนาแล้วจะแสดง “มีในคอมพิวเตอร์เครื่องนี้” ในรายการ และ [เปิดบนคอมพิวเตอร์เครื่องนี้] จะแสดงเป็นอันดับแรก

## เปิดด้วย URL

ที่อยู่ประกอบด้วยที่เก็บและตำแหน่งของเอกสารเรียงต่อกันตามจริง เส้นทางคือตำแหน่งภายในที่เก็บ จึงเรียงเหมือนกับ URL ของ GitHub

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| สิ่งที่ระบุ | รูปแบบ |
|---|---|
| ที่เก็บเท่านั้น (แบรนช์เริ่มต้น) | `/github/owner/repo` |
| เอกสารภายในที่เก็บ | `/github/owner/repo/docs/01-product/vision.md` |
| ระบุแบรนช์หรือแท็ก | เติม `?ref=v1.2.0` ต่อท้าย |

เมื่อย้ายไปหน้าอื่น ที่อยู่ก็จะเปลี่ยนตาม กด [แชร์เอกสารนี้] บนแถบเครื่องมือเพื่อส่งลิงก์ของหน้าที่กำลังอ่านอยู่ให้ผู้อื่น ใช้ปุ่ม [ย้อนกลับ] [ไปข้างหน้า] ของเบราว์เซอร์ได้ด้วย

รูปแบบ `?source=` แบบเดิมยังเปิดได้ตามปกติ หลังจากเปิดแล้ว ที่อยู่จะเปลี่ยนเป็นรูปแบบใหม่

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **หมายเหตุ**
>
> - เมื่อยังไม่ได้ลงชื่อเข้าใช้ จะมีขีดจำกัดการใช้ GitHub API (60 ครั้งต่อชั่วโมง) สำหรับที่เก็บที่มีเอกสารจำนวนมากหรือการอ่านซ้ำหลายครั้ง ให้กด [ลงชื่อเข้าใช้ด้วย GitHub]
> - ชื่อแบรนช์ที่มี `/` (เช่น `feature/xxx`) ระบุได้ด้วย `?ref=` ในรูปแบบที่อยู่ข้างต้น รูปแบบ `?source=` ระบุชื่อแบบนี้ไม่ได้
> - เอกสารจะโหลดด้วยสิทธิ์ GitHub ของผู้อ่าน ผู้ที่ไม่มีสิทธิ์อ่านจะไม่เห็นเอกสาร

## เปิดเอกสารจากโฟลเดอร์ในเครื่อง

กด [เปิดเอกสาร] บนแถบเครื่องมือ แล้วเลือกโฟลเดอร์ในอุปกรณ์จาก [เปิดเอกสารจากโฟลเดอร์ในเครื่อง] ในคอลัมน์ด้านซ้าย ไฟล์จะได้รับการประมวลผลภายในเบราว์เซอร์และไม่ถูกส่งออกไปภายนอก ใช้ได้ในเบราว์เซอร์ที่รองรับการเลือกโฟลเดอร์ (เช่น Chrome และ Edge)
