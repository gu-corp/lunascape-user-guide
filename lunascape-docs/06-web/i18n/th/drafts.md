# บันทึกฉบับร่าง

เมื่อคุณแก้ไขเอกสารในเวอร์ชันเว็บ การเปลี่ยนแปลงจะไม่ถูกเขียนลงในที่เก็บ แต่จะถูกบันทึกไว้ในเบราว์เซอร์ในรูปของ "ฉบับร่าง"

## สร้างฉบับร่าง

1. เปิดเอกสาร แล้วกด [แก้ไข] ที่มุมขวาล่าง
2. แก้ไขแล้วกด [บันทึก]
   ระบบจะแสดงข้อความ "บันทึกเป็นฉบับร่างแล้ว" และบันทึกการเปลี่ยนแปลงไว้ในเบราว์เซอร์

- เอกสารที่มีฉบับร่างจะมีป้ายกำกับปรากฏใน INDEX และเหนือเนื้อหาจะแสดงข้อความ "เอกสารนี้เป็นฉบับร่างในเครื่อง (ยังไม่เผยแพร่)"
- [ฉบับร่าง] บนแถบเครื่องมือจะแสดงจำนวนรายการ เมื่อกดจะเปิดรายการฉบับร่าง

## ทิ้งฉบับร่าง

- หากต้องการทิ้งฉบับร่างของเอกสารแต่ละรายการ ให้กด [ทิ้งฉบับร่าง] เหนือเนื้อหา
- หากต้องการทิ้งทั้งหมด ให้ดำเนินการจากรายการฉบับร่าง

## นำไปใช้กับที่เก็บ

"คำขอเผยแพร่" ซึ่งส่งฉบับร่างเป็น Pull Request นั้นมีอยู่แล้ว แต่ยังไม่ได้เปิดใช้งานในโปรแกรมดูสาธารณะ หากต้องการนำไปใช้กับที่เก็บ ให้แก้ไขด้วยเวอร์ชัน VS Code หรือในโคลนบนเครื่องของคุณ

> **ข้อควรระวัง**
>
> - ฉบับร่างจะถูกบันทึกไว้ในเบราว์เซอร์ (IndexedDB) จึงไม่ถูกส่งต่อไปยังเบราว์เซอร์อื่นหรือเครื่องอื่น และหากลบข้อมูลเว็บไซต์ของเบราว์เซอร์ ฉบับร่างก็จะหายไปด้วย
> - หากเอกสารฝั่งที่เก็บถูกอัปเดตหลังจากที่คุณสร้างฉบับร่างแล้ว ระบบจะแสดงข้อความ "ต้นทางมีการอัปเดต" โปรดตรวจสอบเนื้อหาก่อน แล้วจึงตัดสินใจว่าจะทิ้งฉบับร่างหรือใช้ต่อไป
> - หากคุณเปิดโฟลเดอร์ในเครื่องจาก [เปิดเอกสาร] แล้วแก้ไข การเปลี่ยนแปลงจะถูกบันทึกลงในไฟล์โดยตรงหากเบราว์เซอร์รองรับ ส่วนเบราว์เซอร์ที่ไม่รองรับจะเก็บไว้เฉพาะในเซสชันนั้นเท่านั้น
