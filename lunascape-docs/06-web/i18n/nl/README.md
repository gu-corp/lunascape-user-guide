# Wat de webversie kan

De webbrowserversie van Lunascape Docs is beschikbaar op <https://docs.lunascape.org/>. Zonder iets te installeren leest u documenten op GitHub alsof het een website is.

## Mogelijkheden

| Functie | Inhoud |
|---|---|
| Openbare repository's bekijken | Opent de documenten van een openbare GitHub-repository zonder aanmelden |
| Niet-openbare repository's bekijken | Na aanmelden met GitHub opent u de repository's waarvoor u leesrechten hebt |
| Lokale mappen bekijken | Met [Documenten openen] en vervolgens [Documenten uit een lokale map openen] opent u een map op uw apparaat (alleen in ondersteunde browsers) |
| Leesfuncties | INDEX, koppelingen, geschiedenis, filteren, inhoudsopgave van de pagina, taalwisseling en themawisseling. Gelijk aan de VS Code-versie |
| Diagrammen en formules | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose en KaTeX-formules |
| Concepten | U bewerkt documenten en de wijzigingen blijven als concept op uw apparaat bewaard. Er wordt niets naar de repository geschreven |
| Directe koppeling naar een pagina | Een URL kan de repository en de pagina aanwijzen, zodat een bepaalde pagina rechtstreeks wordt geopend |

## Verschillen met de VS Code-versie

- Documentcontroles, aanmaken op basis van een sjabloon, het genereren van vertaalvoorstellen en ordenen vanuit de INDEX zijn er niet in de webversie.
- TikZ-diagrammen worden niet weergegeven.
- Bewerkingen worden niet naar de repository geschreven, maar worden concepten op uw apparaat. Het publicatieverzoek, dat concepten als pull request verstuurt, is wel geïmplementeerd maar staat niet aan in de openbare viewer. Bewerk met de VS Code-versie of in een lokale kloon om de repository bij te werken.
