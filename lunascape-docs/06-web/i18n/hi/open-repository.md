# GitHub रिपॉज़िटरी खोलना

वेब संस्करण में आप GitHub की रिपॉज़िटरी को क्लोन किए बिना सीधे खोलकर पढ़ सकते हैं। सार्वजनिक रिपॉज़िटरी के लिए साइन इन करना ज़रूरी नहीं है।

## स्क्रीन से खोलना

1. टूलबार में [दस्तावेज़ खोलें] (फ़ोल्डर आइकन) दबाएँ। “दस्तावेज़ खोलें” स्क्रीन खुलती है।
2. बाईं ओर के कॉलम में वह स्थान चुनें जहाँ से खोलना है।

   | स्थान | क्या दिखता है |
   |---|---|
   | सभी | नीचे दिए गए सभी। हाल ही में खोले गए सबसे ऊपर दिखते हैं |
   | हाल ही में खोले गए | अब तक खोली गई रिपॉज़िटरी और फ़ोल्डर |
   | अनुशंसित | साइट द्वारा सुझाए गए मैनुअल |
   | GitHub रिपॉज़िटरी | GitHub में साइन इन होने पर, वे रिपॉज़िटरी जिन्हें आप पढ़ सकते हैं |
   | यह कंप्यूटर | इस डिवाइस के फ़ोल्डर |

3. जिस पंक्ति को खोलना है, उसमें [खोलें] दबाएँ। ऊपर [दस्तावेज़ या रिपॉज़िटरी के नाम से फ़िल्टर करें] में टाइप करके पंक्तियाँ सीमित की जा सकती हैं।

जो रिपॉज़िटरी सूची में नहीं है, उसे बाईं ओर के कॉलम में [owner/repo दर्ज करके खोलें] से निर्दिष्ट करें।

> **सुझाव**
>
> - सूची में वे GitHub रिपॉज़िटरी दिखती हैं जिन पर GitHub App “Lunascape Docs” इंस्टॉल है और जिन्हें पढ़ने की अनुमति आपके पास है। कोई रिपॉज़िटरी न दिखे, तो उसके स्वामी से App जोड़ने का अनुरोध करें।

## दस्तावेज़ का स्थान देखना

टूलबार के बाईं ओर स्थित छोटा आइकन (स्थान चिप) बताता है कि आप जो दस्तावेज़ पढ़ रहे हैं, वह कहाँ है।

| आइकन | स्थान |
|---|---|
| GitHub का चिह्न | GitHub से पढ़ा जा रहा है। यह इस डिवाइस पर सहेजा नहीं गया है |
| फ़ोल्डर | इस डिवाइस का फ़ोल्डर |

आइकन दबाने पर स्थान, उसकी स्थिति और वहाँ से किए जा सकने वाले काम ([GitHub पर देखें], [लिंक कॉपी करें] आदि) दिखते हैं।

## URL से खोलना

पते में रिपॉज़िटरी और दस्तावेज़ का स्थान उसी क्रम में लिखा जाता है। पथ रिपॉज़िटरी के भीतर का स्थान है, इसलिए इसका क्रम GitHub के URL जैसा ही होता है।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| क्या निर्दिष्ट करें | कैसे लिखें |
|---|---|
| केवल रिपॉज़िटरी (डिफ़ॉल्ट ब्रांच) | `/github/owner/repo` |
| रिपॉज़िटरी के भीतर का दस्तावेज़ | `/github/owner/repo/docs/01-product/vision.md` |
| ब्रांच या टैग निर्दिष्ट करना | अंत में `?ref=v1.2.0` जोड़ें |

पृष्ठ बदलने पर पता भी बदल जाता है। टूलबार में [यह दस्तावेज़ साझा करें] दबाकर आप वर्तमान पृष्ठ का लिंक दूसरों को दे सकते हैं। ब्राउज़र के [वापस] और [आगे] भी काम करते हैं।

पुराना `?source=` वाला रूप भी पहले की तरह खुलता है। खुलने के बाद पता नए रूप में बदल जाता है।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ध्यान दें**
>
> - साइन इन न होने पर GitHub API की उपयोग-सीमा (प्रति घंटा 60 अनुरोध) लागू होती है। अधिक दस्तावेज़ों वाली रिपॉज़िटरी या बार-बार पढ़ने के लिए [GitHub से साइन इन करें] दबाएँ।
> - `/` वाले ब्रांच नाम (जैसे `feature/xxx`) ऊपर दिए गए पते के रूप में `?ref=` से निर्दिष्ट किए जा सकते हैं। `?source=` वाले रूप में इन्हें नहीं लिखा जा सकता।
> - दस्तावेज़ पढ़ने वाले व्यक्ति की अपनी GitHub अनुमतियों से लोड होते हैं। जिनके पास पढ़ने की अनुमति नहीं है, उन्हें ये नहीं दिखते।

## स्थानीय फ़ोल्डर से दस्तावेज़ खोलना

टूलबार में [दस्तावेज़ खोलें] दबाएँ और बाईं ओर के कॉलम में [स्थानीय फ़ोल्डर से दस्तावेज़ खोलें] से डिवाइस का कोई फ़ोल्डर चुनें। फ़ाइलें ब्राउज़र के भीतर ही संसाधित होती हैं और कहीं बाहर नहीं भेजी जातीं। यह सुविधा फ़ोल्डर चुनने का समर्थन करने वाले ब्राउज़रों (Chrome, Edge आदि) में उपलब्ध है।
