# GitHub रिपॉज़िटरी खोलें

वेब संस्करण और Lunascape में, GitHub की रिपॉज़िटरी की प्रतिलिपि बनाए बिना उसे सीधे खोलकर पढ़ा जा सकता है। सार्वजनिक रिपॉज़िटरी के लिए साइन इन करना ज़रूरी नहीं है।

## स्क्रीन से खोलें

1. टूलबार में [दस्तावेज़ खोलें] (फ़ोल्डर आइकन) दबाएँ। “दस्तावेज़ खोलें” स्क्रीन खुलती है।
2. बाएँ कॉलम में चुनें कि कहाँ से खोलना है।

   | स्थान | सूची में क्या दिखता है |
   |---|---|
   | सभी | नीचे दिए गए सभी स्थानों की चीज़ें। हाल में खोली गई चीज़ें सबसे ऊपर दिखती हैं |
   | हाल ही में खोले गए | अब तक खोली गई रिपॉज़िटरी और फ़ोल्डर |
   | अनुशंसित | साइट द्वारा सुझाए गए मैनुअल |
   | GitHub रिपॉज़िटरी | GitHub में साइन इन होने पर, वे रिपॉज़िटरी जिन्हें आप पढ़ सकते हैं |
   | यह कंप्यूटर | इस डिवाइस के फ़ोल्डर। Lunascape में, जिन रिपॉज़िटरी की प्रतिलिपि बनाई गई है, वे भी यहाँ दिखती हैं |

3. जिस पंक्ति को खोलना है, उसमें [खोलें] दबाएँ। ऊपर [दस्तावेज़ या रिपॉज़िटरी के नाम से फ़िल्टर करें] में टाइप करके पंक्तियों को फ़िल्टर किया जा सकता है।

जो रिपॉज़िटरी सूची में नहीं है, उसे बाएँ कॉलम में [owner/repo दर्ज करके खोलें] से खोलें।

> **सुझाव**
>
> - सूची में वही GitHub रिपॉज़िटरी दिखती हैं जिन पर GitHub App “Lunascape Docs” इंस्टॉल है और जिन्हें पढ़ने की अनुमति आपके पास है। कोई रिपॉज़िटरी न दिखे, तो उसके स्वामी से App जोड़ने के लिए कहें।

## दस्तावेज़ का स्थान जाँचें

टूलबार में बाईं ओर का छोटा आइकन (स्थान चिप) दिखाता है कि अभी पढ़ा जा रहा दस्तावेज़ कहाँ है।

| आइकन | स्थान |
|---|---|
| GitHub का चिह्न | दस्तावेज़ GitHub से पढ़ा जा रहा है। यह इस डिवाइस पर सहेजा नहीं गया है |
| कंप्यूटर | इस डिवाइस का वह फ़ोल्डर जिसे Lunascape प्रबंधित करता है। Git ब्रांच का नाम और बदली गई फ़ाइलों की संख्या भी दिखती है |
| फ़ोल्डर | इस डिवाइस का फ़ोल्डर |

आइकन दबाने पर स्थान, उसकी स्थिति और वहाँ से किए जा सकने वाले काम ([GitHub पर देखें], [लिंक कॉपी करें] आदि) दिखते हैं।

## Lunascape में रिपॉज़िटरी की प्रतिलिपि बनाएँ

Lunascape में, GitHub की रिपॉज़िटरी की इस डिवाइस पर प्रतिलिपि बनाकर उसमें Git से संपादन और कमिट किया जा सकता है।

- “दस्तावेज़ खोलें” स्क्रीन पर, रिपॉज़िटरी की पंक्ति में [प्रतिलिपि बनाएँ] दबाएँ।
- GitHub से खोला गया दस्तावेज़ पढ़ते समय, स्थान चिप दबाएँ और [इस कंप्यूटर पर प्रतिलिपि बनाएँ] दबाएँ। प्रतिलिपि बन जाने पर वही दस्तावेज़ इस डिवाइस वाले संस्करण में खुलता है।

जिस रिपॉज़िटरी की प्रतिलिपि बन चुकी है, उसके आगे सूची में “इस कंप्यूटर पर है” लिखा दिखता है और [इस कंप्यूटर पर खोलें] सबसे पहले दिखता है।

## URL से खोलें

पते में रिपॉज़िटरी और दस्तावेज़ का स्थान सीधे क्रम से लिखा जाता है। पथ रिपॉज़िटरी के भीतर का स्थान है, इसलिए पता GitHub के URL जैसे ही क्रम में होता है।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| क्या खोलना है | कैसे लिखें |
|---|---|
| केवल रिपॉज़िटरी (डिफ़ॉल्ट ब्रांच) | `/github/owner/repo` |
| रिपॉज़िटरी के भीतर का दस्तावेज़ | `/github/owner/repo/docs/01-product/vision.md` |
| कोई ब्रांच या टैग | अंत में `?ref=v1.2.0` जोड़ें |

दूसरे पृष्ठ पर जाने पर पता भी बदल जाता है। अभी पढ़े जा रहे पृष्ठ का लिंक किसी को देने के लिए, टूलबार में [यह दस्तावेज़ साझा करें] दबाएँ। ब्राउज़र के [वापस] और [आगे] भी काम करते हैं।

पुराने `?source=` रूप वाले पते भी पहले की तरह खुलते हैं। खुलने के बाद पता नए रूप में बदल जाता है।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ध्यान दें**
>
> - साइन इन न होने पर GitHub API की उपयोग सीमा (प्रति घंटे 60 अनुरोध) लागू होती है। ज़्यादा दस्तावेज़ों वाली रिपॉज़िटरी पढ़नी हो या बार-बार पढ़ना हो, तो [GitHub से साइन इन करें] दबाएँ।
> - जिन ब्रांच नामों में `/` हो (जैसे `feature/xxx`), उन्हें ऊपर दिए गए पते में `?ref=` से लिखा जा सकता है। `?source=` रूप में उन्हें नहीं लिखा जा सकता।
> - दस्तावेज़ पढ़ने वाले व्यक्ति की अपनी GitHub अनुमतियों से लोड होते हैं। जिनके पास पढ़ने की अनुमति नहीं है, उन्हें ये नहीं दिखते।

## स्थानीय फ़ोल्डर से दस्तावेज़ खोलें

टूलबार में [दस्तावेज़ खोलें] दबाएँ। फिर बाएँ कॉलम में [स्थानीय फ़ोल्डर से दस्तावेज़ खोलें] दबाकर इस डिवाइस का कोई फ़ोल्डर चुनें। फ़ाइलें ब्राउज़र के भीतर ही प्रोसेस होती हैं और कहीं बाहर नहीं भेजी जातीं। यह सुविधा उन ब्राउज़र में काम करती है जिनमें फ़ोल्डर चुना जा सकता है (Chrome, Edge आदि)।
