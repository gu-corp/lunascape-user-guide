# GitHub की रिपॉज़िटरी खोलना

Web संस्करण में, GitHub की रिपॉज़िटरी बताकर दस्तावेज़ खोले जाते हैं। सार्वजनिक रिपॉज़िटरी के लिए साइन इन करने की आवश्यकता नहीं है।

## स्क्रीन से खोलना

1. <https://docs.lunascape.org/> खोलें।
2. टूलबार में [दस्तावेज़ खोलें] (फ़ोल्डर का चिह्न) दबाएँ।
3. [रिपॉज़िटरी सीधे बताएँ] में रिपॉज़िटरी दर्ज करें और [खोलें] दबाएँ।
   GitHub में साइन इन होने पर, [पढ़ी जा सकने वाली रिपॉज़िटरी में से चुनें] से सूची में से भी चुना जा सकता है।

> **संकेत**
>
> - उसके बगल में मौजूद GitHub का चिह्न, अभी पढ़े जा रहे दस्तावेज़ को github.com पर खोलता है। यह दस्तावेज़ खोलने की क्रिया नहीं है।

## URL से खोलना

पता, रिपॉज़िटरी और दस्तावेज़ की स्थिति को उसी क्रम में रखता है। पथ रिपॉज़िटरी के भीतर की स्थिति है, इसलिए यह GitHub के URL जैसा ही क्रम बनाता है।

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| निर्दिष्ट करना | लिखने का तरीका |
|---|---|
| केवल रिपॉज़िटरी (डिफ़ॉल्ट ब्रांच) | `/github/owner/repo` |
| रिपॉज़िटरी के भीतर का दस्तावेज़ | `/github/owner/repo/docs/01-product/vision.md` |
| ब्रांच या टैग बताना | अंत में `?ref=v1.2.0` जोड़ें |

पृष्ठ बदलने पर पता भी बदलता है। टूलबार में [यह दस्तावेज़ साझा करें] दबाने पर, अभी पढ़े जा रहे पृष्ठ की लिंक किसी को दी जा सकती है। ब्राउज़र के [वापस] और [आगे] भी काम करते हैं।

पहले वाला `?source=` रूप भी पहले की तरह खुलता है। खुलने के बाद वह नए रूप में बदल जाता है।

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ध्यान दें**
>
> - साइन इन न होने की स्थिति में, GitHub API की उपयोग सीमा (प्रति घंटा 60 बार) लागू होती है। अधिक दस्तावेज़ों वाली रिपॉज़िटरी या बार-बार पढ़ने के लिए, [GitHub से साइन इन करें] दबाएँ।
> - `/` वाले ब्रांच नाम (जैसे `feature/xxx`) ऊपर दिए पते के रूप में `?ref=` से बताए जा सकते हैं। `?source=` रूप में उन्हें नहीं लिखा जा सकता।
> - दस्तावेज़ पढ़ने वाले की अपनी GitHub अनुमतियों से लोड होते हैं। जिनके पास पढ़ने की अनुमति नहीं है, उन्हें वे नहीं दिखते।

## स्थानीय फ़ोल्डर के दस्तावेज़ खोलना

टूलबार में [दस्तावेज़ खोलें] दबाएँ और सूची के नीचे मौजूद [स्थानीय फ़ोल्डर से दस्तावेज़ खोलें] से, अपने उपकरण का फ़ोल्डर चुनें। फ़ाइलें ब्राउज़र के भीतर ही संसाधित होती हैं और बाहर नहीं भेजी जातीं। यह फ़ोल्डर चयन का समर्थन करने वाले ब्राउज़र (Chrome, Edge आदि) में काम करता है।
