# निजी रिपॉज़िटरी देखना

निजी रिपॉज़िटरी के दस्तावेज़, GitHub से साइन इन करने के बाद, केवल उन्हीं रिपॉज़िटरी तक सीमित रहते हुए देखे जा सकते हैं जिन पर आपको पढ़ने का अधिकार है। Lunascape Docs के पास अपना कोई खाता या अधिकार नहीं होता।

## साइन इन करके खोलें

1. <https://docs.lunascape.org/> खोलें।
   जब आप किसी निजी दस्तावेज़ को निर्दिष्ट करते हैं या अभी तक साइन इन नहीं किया है, तो साइन इन स्क्रीन दिखाई देती है।
2. [GitHub से साइन इन करें] दबाएँ।
   GitHub की प्रमाणीकरण स्क्रीन एक पॉप-अप में खुलती है।
3. साइन इन पूरा होने के बाद, टूलबार में [दस्तावेज़ खोलें] दबाएँ और [पढ़ी जा सकने वाली रिपॉज़िटरी में से चुनें] से वह रिपॉज़िटरी चुनें जिसे आप खोलना चाहते हैं।

> **संकेत**
>
> - साइन इन किए हुए खाते का नाम टूलबार में दिखाई देता है। [साइन आउट करें] या [किसी अन्य खाते से साइन इन करें] भी यहीं से किया जा सकता है।
> - सूची में वे रिपॉज़िटरी दिखाई देती हैं जिन पर आपको पढ़ने का अधिकार है — उन खातों (संगठन या व्यक्ति) की, जहाँ GitHub App "Lunascape Docs" इंस्टॉल की गई है।

## रिपॉज़िटरी के मालिक द्वारा की जाने वाली सेटिंग

यदि सूची में लक्षित रिपॉज़िटरी दिखाई नहीं देती, तो रिपॉज़िटरी के मालिक या संगठन के प्रशासक को GitHub App "Lunascape Docs" इंस्टॉल करनी होगी।

- माँगे जाने वाले अधिकार हैं Contents (पढ़ना और लिखना) और Pull requests (पढ़ना और लिखना)। पढ़ना देखने के लिए है, और लिखना Web से प्रकाशन अनुरोध (Pull Request) भेजने के लिए है। Lunascape Docs दस्तावेज़ की सामग्री को कभी संग्रहीत नहीं करता।
- इंस्टॉल की इकाई खाता (संगठन या व्यक्ति) है। लक्ष्य को "All repositories" (बाद में बनाई जाने वाली रिपॉज़िटरी भी स्वतः शामिल) रखना है या केवल चुनी हुई रिपॉज़िटरी तक सीमित रखना है, यह सेट करें।

| स्थिति | प्रक्रिया |
|---|---|
| किसी नए संगठन या व्यक्तिगत खाते पर पहली बार लगाना | [इंस्टॉलेशन पृष्ठ](https://github.com/apps/lunascape-docs/installations/new) से करें |
| जिस संगठन में पहले से लगी है, वहाँ लक्षित रिपॉज़िटरी जोड़ना | संगठन के Settings → GitHub Apps → Lunascape Docs → Configure → Repository access में सेट करें |

पूरे संगठन के लिए इंस्टॉल करने पर भी, प्रत्येक सदस्य केवल वही रिपॉज़िटरी देख सकता है जिन पर उसे पढ़ने का अधिकार है। प्रकाशन अनुरोध भी वही भेज सकता है जिन पर उसे लिखने का अधिकार है।

> **संकेत**
> - नई इंस्टॉलेशन के समय, माँगे जाने वाले अधिकार इंस्टॉल स्क्रीन पर सूची में दिखाए जाते हैं, और "Install" दबाते ही उन्हें स्वीकृत मान लिया जाता है। कोई अतिरिक्त कार्रवाई नहीं है।
> - जिस संगठन ने अधिकार बढ़ने से पहले इंस्टॉल किया था, उसके प्रशासकों को एक पुष्टिकरण ईमेल मिलता है, और संगठन के Settings → GitHub Apps → Lunascape Docs → Configure के ऊपरी भाग में एक स्वीकृति बटन दिखाई देता है। स्वीकृति देने तक, उस संगठन में केवल देखा जा सकता है, और प्रकाशन अनुरोध भेजने पर "लिखने के अधिकार की आवश्यकता है" दिखाई देता है।
> - इस समय किन अधिकारों के साथ इंस्टॉल है, यह उसी Configure स्क्रीन पर देखा जा सकता है। व्यक्तिगत खाते के लिए यह Settings → Applications → Installed GitHub Apps है।
> - यदि लक्षित रिपॉज़िटरी गलती से हटा दी गई हो या ऐप अनइंस्टॉल कर दी गई हो, तो [इंस्टॉलेशन पृष्ठ](https://github.com/apps/lunascape-docs/installations/new) से दोबारा लगाने पर वह पहले जैसी हो जाती है। प्रकाशन अनुरोध के अस्वीकार संदेश में उसे ठीक करने वाली स्क्रीन का लिंक होता है।
> - यदि रिपॉज़िटरी की ओर से प्रकाशन अनुरोध स्वीकार नहीं करना है, तो `lunascape-docs.json` में `"publish": { "enabled": false }` लिखें। देखना पहले की तरह चलता रहता है।
