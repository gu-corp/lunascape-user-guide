# अपने दस्तावेज़ों को वेब पर प्रकाशित करें

आप अपनी रिपॉज़िटरी के दस्तावेज़ों को GitHub Pages या किसी भी स्थैतिक होस्टिंग पर वेबसाइट के रूप में प्रकाशित कर सकते हैं। प्रकाशित करने के दो तरीके हैं। ये चरण उन डेवलपर के लिए हैं जो Lunascape Docs की रिपॉज़िटरी clone करके `npm` का उपयोग कर सकते हैं।

## तरीका 1: व्यूअर की दो फ़ाइलें रखें

केवल व्यूअर (`index.html` और `lsdoc.js`) रखें और दस्तावेज़ GitHub से लोड करवाएँ। दस्तावेज़ स्वयं साइट में शामिल नहीं होते, इसलिए यह निजी रिपॉज़िटरी के लिए भी सुरक्षित है (पाठक GitHub से साइन इन करते हैं)।

1. Lunascape Docs की रिपॉज़िटरी में निम्नलिखित कमांड चलाएँ।

   ```sh
   npm run build:viewer
   ```

   `dist/viewer/` में `index.html` और `lsdoc.js` बनते हैं।
2. दोनों फ़ाइलों को उस रिपॉज़िटरी के `docs/` में रखें जिसे आप प्रकाशित करना चाहते हैं।
3. GitHub Pages सक्षम करें।

दिखाया जाने वाला दस्तावेज़ रूट इस क्रम में तय होता है।

1. `index.html` के भीतर की सेटिंग `source`
2. उसी फ़ोल्डर के `lunascape-docs.json` में लिखा `repository`
3. `*.github.io` के URL और ब्रांच संरचना से अनुमान

## तरीका 2: दस्तावेज़ों सहित स्थैतिक साइट निर्यात करें

व्यूअर और दस्तावेज़ फ़ाइलों को एक साथ निर्यात करें और उसी रूप में होस्ट करें।

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

आउटपुट में व्यूअर का पूरा सेट, `docs/` के नीचे के दस्तावेज़, सूची फ़ाइल `lunascape-docs-manifest.json` और `.nojekyll` शामिल होते हैं। आउटपुट को S3 या GitHub Pages पर रखकर प्रकाशित किया जा सकता है। GitHub Actions से अपने आप प्रकाशित करने का उदाहरण रिपॉज़िटरी के `examples/workflows/publish-docs-pages.yml` में देखें।

> **ध्यान दें**
>
> - **निजी रिपॉज़िटरी के दस्तावेज़ों को निर्यात करके GitHub Pages पर न रखें।** Enterprise Cloud के अलावा GitHub Pages को कोई भी पढ़ सकता है। सीमित प्रकाशन आवश्यक हो तो तरीका 1 का उपयोग करें और पाठकों से GitHub पर साइन इन करवाएँ।
> - `index.html` को `file://` से सीधे खोलने पर यह काम नहीं करता, क्योंकि ब्राउज़र पड़ोसी फ़ाइलों को लोड करने और ES मॉड्यूल चलाने पर रोक लगाते हैं। स्थानीय रूप से जाँचने के लिए VS Code संस्करण या कोई HTTP सर्वर उपयोग करें।
> - TikZ, Vega-Lite, Markmap, WaveDrom, Svgbob और Penrose की रेंडरिंग लाइब्रेरी प्रदर्शन के समय लोड होती हैं। निर्यात की गई साइट में `vendor/` फ़ोल्डर भी साथ रखें।
