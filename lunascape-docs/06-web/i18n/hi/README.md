# वेब संस्करण में क्या किया जा सकता है

Lunascape Docs का वेब ब्राउज़र संस्करण <https://docs.lunascape.org/> पर उपलब्ध है। बिना कुछ इंस्टॉल किए, GitHub पर मौजूद दस्तावेज़ों को वेबसाइट की तरह पढ़ा जा सकता है।

## क्या किया जा सकता है

| सुविधा | विवरण |
|---|---|
| सार्वजनिक रिपॉज़िटरी देखना | साइन इन किए बिना, GitHub की सार्वजनिक रिपॉज़िटरी के दस्तावेज़ खोलता है |
| निजी रिपॉज़िटरी देखना | GitHub से साइन इन करने पर, जिन रिपॉज़िटरी पर आपको पढ़ने की अनुमति है, उन्हें खोला जा सकता है |
| स्थानीय फ़ोल्डर देखना | [दस्तावेज़ खोलें] के [स्थानीय फ़ोल्डर से दस्तावेज़ खोलें] से, अपने डिवाइस का फ़ोल्डर खोलता है (केवल समर्थित ब्राउज़र में) |
| पढ़ने की सुविधाएँ | INDEX, लिंक, इतिहास, छँटाई, पृष्ठ की विषय-सूची, भाषा बदलना, थीम बदलना। VS Code संस्करण जैसा ही है |
| आरेख और गणितीय सूत्र | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, KaTeX गणितीय सूत्र |
| मसौदा | दस्तावेज़ संपादित करके, बदलावों को अपने डिवाइस में मसौदे के रूप में रखता है। रिपॉज़िटरी में कुछ नहीं लिखा जाता |
| पृष्ठ का सीधा लिंक | URL में रिपॉज़िटरी और पृष्ठ बताकर, किसी विशेष पृष्ठ को सीधे खोला जा सकता है |

## VS Code संस्करण से अंतर

- दस्तावेज़ की जाँच, टेम्पलेट से निर्माण, अनुवाद प्रस्ताव तैयार करना और INDEX से व्यवस्थित करना — ये वेब संस्करण में नहीं हैं।
- TikZ आरेख नहीं बनाए जाते।
- संपादन रिपॉज़िटरी में नहीं लिखा जाता, बल्कि आपके डिवाइस में मसौदा बन जाता है। मसौदे को Pull Request के रूप में भेजने वाला "प्रकाशन अनुरोध" लागू तो है, पर सार्वजनिक व्यूअर में सक्षम नहीं है। रिपॉज़िटरी में बदलाव लाने के लिए, VS Code संस्करण से या अपने पास की क्लोन में संपादन करें।
