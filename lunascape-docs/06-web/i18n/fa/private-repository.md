# مرور یک مخزن خصوصی

پس از ورود با GitHub، می‌توانید اسناد مخزن‌های خصوصی را مرور کنید، البته تنها آن‌هایی که برای‌شان دسترسی خواندن دارید. Lunascape Docs هرگز حساب یا مجوزی از آنِ خود ندارد.

## ورود و گشودن

1. نشانی <https://docs.lunascape.org/> را باز کنید.
   هنگامی که سندی خصوصی را مشخص کنید یا هنوز وارد نشده باشید، صفحهٔ ورود نمایش داده می‌شود.
2. [ورود با GitHub] را بزنید.
   صفحهٔ احراز هویت GitHub در یک پنجرهٔ بازشو گشوده می‌شود.
3. پس از ورود، در نوار ابزار [گشودن اسناد] را بزنید و از [انتخاب از مخزن‌های خواندنی] مخزنی را که می‌خواهید بگشایید انتخاب کنید.

> **نکته**
>
> - نام حسابی که با آن وارد شده‌اید در نوار ابزار نمایش داده می‌شود. [خروج] و [ورود با حسابی دیگر] را هم می‌توانید از همین‌جا انجام دهید.
> - در فهرست، مخزن‌هایی از حساب‌هایی (سازمان یا شخص) نمایش داده می‌شوند که GitHub App «Lunascape Docs» روی آن‌ها نصب شده است، و تنها آن‌هایی که شما دسترسی خواندن دارید.

## تنظیماتی که مالک مخزن انجام می‌دهد

اگر مخزن موردنظر در فهرست نمایش داده نشد، مالک مخزن یا مدیر سازمان باید GitHub App «Lunascape Docs» را نصب کند.

- مجوزهای درخواستی Contents (خواندن و نوشتن) و Pull requests (خواندن و نوشتن) هستند. خواندن برای مرور است و نوشتن برای درخواست انتشار از وب (Pull Request). Lunascape Docs هرگز محتوای اسناد را ذخیره نمی‌کند.
- واحد نصب، حساب (سازمان یا شخص) است. تعیین می‌کنید که مقصد «All repositories» باشد (که مخزن‌هایی را که بعداً ساخته می‌شوند نیز به‌طور خودکار در بر می‌گیرد) یا فقط مخزن‌های انتخاب‌شده.

| موقعیت | مراحل |
|---|---|
| نصب تازه روی یک حساب سازمانی یا شخصی | از [صفحهٔ نصب](https://github.com/apps/lunascape-docs/installations/new) انجام دهید |
| افزودن مخزن هدف در سازمانی که پیش‌تر نصب شده است | در Organization Settings → GitHub Apps → Lunascape Docs → Configure → Repository access تنظیم کنید |

حتی اگر برنامه برای کل سازمان نصب شود، هر عضو تنها مخزن‌هایی را می‌بیند که خودش دسترسی خواندن دارد. درخواست انتشار را نیز فقط برای مخزن‌هایی می‌تواند بفرستد که خودش دسترسی نوشتن دارد.

> **نکته**
> - در نصب تازه، مجوزهای درخواستی در صفحهٔ نصب به‌صورت فهرست نمایش داده می‌شوند و با زدن «Install» آن‌ها را تأیید کرده‌اید. کار دیگری لازم نیست.
> - سازمانی که پیش از افزوده‌شدن یک مجوز، برنامه را نصب کرده بود، ایمیلی تأییدی به مدیرانش می‌رسد و دکمهٔ تأیید در بالای Organization Settings → GitHub Apps → Lunascape Docs → Configure نمایش داده می‌شود. تا زمانی که تأیید نشود، در آن سازمان تنها می‌توان مرور کرد و اگر درخواست انتشار بفرستید، پیام «اعطای دسترسی نوشتن لازم است» نمایش داده می‌شود.
> - اینکه اکنون با چه مجوزی وارد شده‌اید را در همان صفحهٔ Configure می‌توانید ببینید. برای حساب شخصی این بخش Settings → Applications → Installed GitHub Apps است.
> - اگر مخزن هدف را به‌اشتباه حذف کردید یا برنامه را حذف نصب کردید، با نصب دوبارهٔ آن از [صفحهٔ نصب](https://github.com/apps/lunascape-docs/installations/new) به حالت پیشین باز می‌گردد. پیام رد درخواست انتشار، پیوندی به صفحهٔ اصلاح دارد.
> - اگر در سمت مخزن نمی‌خواهید درخواست انتشار بپذیرید، در `lunascape-docs.json` بنویسید `"publish": { "enabled": false }`. مرور همچنان کار می‌کند.
