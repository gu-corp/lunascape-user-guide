# باز کردن مخزن GitHub

در نسخهٔ وب و در Lunascape می‌توانید مخزن GitHub را بدون تکثیر، مستقیماً باز کنید و بخوانید. برای مخزن‌های عمومی نیازی به ورود نیست.

## باز کردن از صفحه

1. در نوار ابزار، [گشودن اسناد] (نماد پوشه) را بزنید. صفحهٔ «گشودن اسناد» باز می‌شود.
2. در ستون سمت چپ، محلی را که می‌خواهید از آن باز کنید انتخاب کنید.

   | محل | موارد فهرست‌شده |
   |---|---|
   | همه | همهٔ موارد زیر. مواردی که اخیراً باز کرده‌اید در ابتدا قرار می‌گیرند |
   | اخیراً باز شده | مخزن‌ها و پوشه‌هایی که تاکنون باز کرده‌اید |
   | پیشنهادی | راهنماهایی که سایت معرفی می‌کند |
   | مخزن‌های GitHub | وقتی با GitHub وارد شده‌اید، مخزن‌هایی که می‌توانید بخوانید |
   | این رایانه | پوشه‌های این دستگاه. در Lunascape، مخزن‌های تکثیرشده نیز اینجا فهرست می‌شوند |

3. در ردیف موردنظر، [باز کردن] را بزنید. با تایپ در [فیلتر بر اساس نام سند یا نام مخزن] در بالا، می‌توانید ردیف‌ها را محدود کنید.

مخزنی را که در فهرست نیست، از [باز کردن با وارد کردن owner/repo] در ستون سمت چپ مشخص کنید.

> **نکته**
>
> - مخزن‌های GitHub که در فهرست نمایش داده می‌شوند، مخزن‌هایی هستند که GitHub App «Lunascape Docs» روی آن‌ها نصب شده است و شما به آن‌ها دسترسی خواندن دارید. اگر مخزنی را نمی‌یابید، از مالک مخزن بخواهید این App را اضافه کند.

## تشخیص محل سند

نماد کوچکی که در سمت چپ نوار ابزار قرار دارد (نشانگر محل)، نشان می‌دهد سندی که اکنون می‌خوانید کجاست.

| نماد | محل |
|---|---|
| نشان GitHub | از GitHub خوانده می‌شود. در این دستگاه ذخیره نشده است |
| رایانه | پوشه‌ای در این دستگاه که Lunascape آن را مدیریت می‌کند. نام شاخهٔ Git و تعداد فایل‌های تغییریافته نیز نمایش داده می‌شود |
| پوشه | پوشه‌ای در این دستگاه |

با زدن نماد، محل، وضعیت و کارهایی که از آنجا می‌توان انجام داد ([مشاهده در GitHub]، [کپی پیوند] و غیره) نمایش داده می‌شود.

## تکثیر مخزن در Lunascape

در Lunascape می‌توانید مخزن GitHub را در این دستگاه تکثیر کنید و با Git آن را ویرایش و کامیت کنید.

- در صفحهٔ «گشودن اسناد»، در ردیف مخزن، [تکثیر] را بزنید.
- وقتی مخزنی را که از GitHub باز کرده‌اید می‌خوانید، نشانگر محل را بزنید و سپس [تکثیر در این رایانه] را بزنید. پس از پایان تکثیر، همان سند از نسخهٔ این دستگاه باز می‌شود.

مخزن تکثیرشده در فهرست با «موجود در این رایانه» مشخص می‌شود و [باز کردن در این رایانه] در ابتدا قرار می‌گیرد.

## باز کردن با URL

نشانی، مخزن و محل سند را به همان ترتیب کنار هم می‌آورد. مسیر، محل سند درون مخزن است؛ بنابراین ترتیب آن با URL در GitHub یکسان است.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| مورد | شکل نوشتن |
|---|---|
| فقط مخزن (شاخهٔ پیش‌فرض) | `/github/owner/repo` |
| سندی درون مخزن | `/github/owner/repo/docs/01-product/vision.md` |
| تعیین شاخه یا تگ | `?ref=v1.2.0` را به انتهای نشانی اضافه کنید |

با جابه‌جایی بین صفحه‌ها، نشانی نیز تغییر می‌کند. با زدن [هم‌رسانی این سند] در نوار ابزار، می‌توانید پیوند صفحه‌ای را که اکنون می‌خوانید به دیگران بدهید. دکمه‌های [بازگشت] و [جلو] مرورگر نیز کار می‌کنند.

شکل قدیمی `?source=` نیز مانند گذشته باز می‌شود. پس از باز شدن، نشانی به شکل جدید بازنویسی می‌شود.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **توجه**
>
> - بدون ورود، محدودیت استفاده از GitHub API (۶۰ درخواست در ساعت) اعمال می‌شود. برای مخزن‌هایی با اسناد زیاد یا مطالعهٔ مکرر، [ورود با GitHub] را بزنید.
> - نام شاخه‌هایی که `/` دارند (مانند `feature/xxx`) را می‌توان با `?ref=` در شکل نشانی بالا مشخص کرد. در شکل `?source=` نمی‌توان آن‌ها را نوشت.
> - اسناد با مجوزهای GitHub خودِ خواننده بارگذاری می‌شوند. کسانی که مجوز خواندن ندارند، آن‌ها را نمی‌بینند.

## گشودن اسناد از یک پوشهٔ محلی

در نوار ابزار [گشودن اسناد] را بزنید، سپس از [گشودن اسناد از یک پوشهٔ محلی] در ستون سمت چپ، پوشه‌ای را در دستگاه انتخاب کنید. فایل‌ها درون مرورگر پردازش می‌شوند و به بیرون فرستاده نمی‌شوند. این قابلیت در مرورگرهایی کار می‌کند که از انتخاب پوشه پشتیبانی می‌کنند (Chrome، Edge و غیره).
