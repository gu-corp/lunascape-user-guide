# گشودن مخزن GitHub

در نسخهٔ وب، با تعیین یک مخزن GitHub اسناد را می‌گشایید. برای مخزن‌های عمومی نیازی به ورود نیست.

## گشودن از صفحه

1. نشانی <https://docs.lunascape.org/> را باز کنید.
2. در نوار ابزار [گشودن اسناد] (نشان پوشه) را فشار دهید.
3. در [تعیین مستقیم مخزن] نام مخزن را وارد کنید و [گشودن] را فشار دهید.
   هنگامی که به GitHub وارد شده‌اید، می‌توانید با [انتخاب از مخزن‌های خواندنی] نیز از فهرست انتخاب کنید.

> **نکته**
>
> - نشان GitHub در کنار آن، سندی را که می‌خوانید در github.com باز می‌کند. این کار برای گشودن اسناد نیست.

## گشودن با نشانی اینترنتی

نشانی، مخزن و جایگاه سند را همان‌گونه که هستند پشت سر هم می‌آورد. مسیر، جایگاه سند در درون مخزن است؛ بنابراین ترتیب آن با نشانی GitHub یکسان می‌شود.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| آنچه تعیین می‌کنید | شیوهٔ نوشتن |
|---|---|
| فقط مخزن (شاخهٔ پیش‌فرض) | `/github/owner/repo` |
| سندی درون مخزن | `/github/owner/repo/docs/01-product/vision.md` |
| تعیین یک شاخه یا برچسب | در پایان `?ref=v1.2.0` را بیفزایید |

با جابه‌جایی میان صفحه‌ها، نشانی نیز تغییر می‌کند. با فشردن [هم‌رسانی این سند] در نوار ابزار، می‌توانید پیوند صفحه‌ای را که می‌خوانید به دیگری بدهید. دکمه‌های [بازگشت] و [جلو] مرورگر نیز کار می‌کنند.

شکل پیشین `?source=` نیز مانند گذشته باز می‌شود. پس از گشوده‌شدن، به شکل تازه بازنویسی می‌شود.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **توجه**
>
> - در حالتی که وارد نشده‌اید، محدودیت استفاده از GitHub API (۶۰ بار در هر ساعت) اعمال می‌شود. برای مخزن‌هایی با اسناد فراوان یا خواندن‌های مکرر، [ورود با GitHub] را انجام دهید.
> - نام شاخه‌هایی که `/` دارند (مانند `feature/xxx`) را می‌توان با `?ref=` در شکل نشانی بالا تعیین کرد. در شکل `?source=` نمی‌توان آن‌ها را نوشت.
> - اسناد با دسترسی GitHub خودِ خواننده بارگذاری می‌شوند. کسانی که اجازهٔ خواندن ندارند، آن‌ها را نمی‌بینند.

## گشودن اسناد یک پوشهٔ محلی

در نوار ابزار [گشودن اسناد] را فشار دهید و از [گشودن اسناد از یک پوشهٔ محلی] در پایین فهرست، پوشه‌ای را در دستگاه خود برگزینید. پرونده‌ها درون مرورگر پردازش می‌شوند و به بیرون فرستاده نمی‌شوند. این کار در مرورگرهایی که انتخاب پوشه را پشتیبانی می‌کنند (Chrome، Edge و مانند آن‌ها) در دسترس است.
