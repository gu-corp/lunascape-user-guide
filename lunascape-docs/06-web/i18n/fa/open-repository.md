# باز کردن مخزن GitHub

در نسخهٔ وب می‌توانید مخزن GitHub را بدون کلون کردن، مستقیماً باز کنید و بخوانید. برای مخزن‌های عمومی نیازی به ورود نیست.

## باز کردن از صفحه

1. در نوار ابزار، [گشودن اسناد] (نماد پوشه) را بزنید. صفحهٔ «گشودن اسناد» باز می‌شود.
2. در ستون سمت چپ، محلی را که می‌خواهید از آن باز کنید انتخاب کنید.

   | محل | آنچه نمایش داده می‌شود |
   |---|---|
   | همه | همهٔ موارد زیر. مواردی که اخیراً باز کرده‌اید در ابتدا قرار می‌گیرند |
   | اخیراً باز شده | مخزن‌ها و پوشه‌هایی که تاکنون باز کرده‌اید |
   | پیشنهادی | راهنماهایی که سایت معرفی می‌کند |
   | مخزن‌های GitHub | هنگامی که با GitHub وارد شده‌اید، مخزن‌هایی که می‌توانید بخوانید |
   | این رایانه | پوشه‌های این دستگاه |

3. در ردیف مورد نظر، [باز کردن] را بزنید. با تایپ در [فیلتر بر اساس نام سند یا نام مخزن] در بالا، می‌توانید ردیف‌ها را محدود کنید.

مخزنی را که در فهرست نیست، از [وارد کردن owner/repo و باز کردن] در ستون سمت چپ مشخص کنید.

> **نکته**
>
> - مخزن‌های GitHub که در فهرست نمایش داده می‌شوند، آن‌هایی هستند که برنامهٔ GitHub با نام «Lunascape Docs» روی آن‌ها نصب شده است و شما مجوز خواندنشان را دارید. اگر مخزنی را پیدا نکردید، از مالک آن مخزن بخواهید این برنامه را اضافه کند.

## بررسی محل سند

نماد کوچکی که نزدیک سمت چپ نوار ابزار قرار دارد (تراشهٔ محل)، نشان می‌دهد سندی که اکنون می‌خوانید کجا قرار دارد.

| نماد | محل |
|---|---|
| نشان GitHub | از GitHub خوانده می‌شود. در این دستگاه ذخیره نشده است |
| پوشه | پوشه‌ای در این دستگاه |

با زدن نماد، محل و وضعیت آن و کارهایی که از آنجا می‌توانید انجام دهید ([مشاهده در GitHub]، [کپی پیوند] و غیره) نمایش داده می‌شوند.

## باز کردن با URL

نشانی، مخزن و محل سند را به همان ترتیب پشت سر هم می‌آورد. مسیر، محل سند درون مخزن است؛ بنابراین ترتیب آن همانند URL در GitHub است.

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| آنچه مشخص می‌کنید | شیوهٔ نوشتن |
|---|---|
| فقط مخزن (شاخهٔ پیش‌فرض) | `/github/owner/repo` |
| سندی درون مخزن | `/github/owner/repo/docs/01-product/vision.md` |
| تعیین شاخه یا برچسب | `?ref=v1.2.0` را به انتهای آن اضافه کنید |

با جابه‌جایی بین صفحه‌ها، نشانی نیز تغییر می‌کند. با زدن [هم‌رسانی این سند] در نوار ابزار، می‌توانید پیوند صفحه‌ای را که اکنون می‌خوانید به دیگران بدهید. دکمه‌های [بازگشت] و [جلو] مرورگر نیز کار می‌کنند.

شکل قدیمی `?source=` نیز مانند گذشته باز می‌شود. پس از باز شدن، نشانی به شکل جدید بازنویسی می‌شود.

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **توجه**
>
> - تا زمانی که وارد نشده‌اید، محدودیت استفاده از GitHub API (۶۰ درخواست در ساعت) اعمال می‌شود. برای مخزن‌هایی با اسناد زیاد یا مشاهدهٔ مکرر، [ورود با GitHub] را بزنید.
> - نام شاخه‌هایی که `/` دارند (مانند `feature/xxx`) را می‌توان با `?ref=` در قالب نشانی بالا مشخص کرد. در شکل `?source=` نمی‌توان آن‌ها را نوشت.
> - اسناد با مجوزهای GitHub خودِ خواننده بارگذاری می‌شوند. برای کسانی که مجوز خواندن ندارند نمایش داده نمی‌شوند.

## گشودن اسناد از یک پوشهٔ محلی

در نوار ابزار، [گشودن اسناد] را بزنید و از [گشودن اسناد از یک پوشهٔ محلی] در ستون سمت چپ، پوشه‌ای را در دستگاه خود انتخاب کنید. فایل‌ها درون مرورگر پردازش می‌شوند و به هیچ جای بیرونی فرستاده نمی‌شوند. این قابلیت در مرورگرهایی که از انتخاب پوشه پشتیبانی می‌کنند (Chrome، Edge و مانند آن‌ها) در دسترس است.
