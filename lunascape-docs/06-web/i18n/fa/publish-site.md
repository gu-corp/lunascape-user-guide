# انتشار سندهای خود در وب

می‌توانید سندهای مخزن خود را به صورت یک وب‌سایت روی GitHub Pages یا هر میزبانی ایستای دیگری منتشر کنید. دو راه برای انتشار وجود دارد. این مراحل برای توسعه‌دهندگانی است که می‌توانند مخزن Lunascape Docs را clone کنند و از `npm` استفاده کنند.

## راه ۱: قرار دادن دو فایل نمایشگر

در این راه فقط خودِ نمایشگر (`index.html` و `lsdoc.js`) را قرار می‌دهید و سندها از GitHub بارگذاری می‌شوند. خودِ سندها بخشی از سایت نیستند، پس این راه برای مخزن‌های خصوصی هم امن است (خواننده با GitHub وارد می‌شود).

۱. در مخزن Lunascape Docs فرمان زیر را اجرا کنید.

   ```sh
   npm run build:viewer
   ```

   فایل‌های `index.html` و `lsdoc.js` در `dist/viewer/` ساخته می‌شوند.
۲. این دو فایل را در پوشهٔ `docs/` مخزنی که می‌خواهید منتشر کنید قرار دهید.
۳. GitHub Pages را فعال کنید.

ریشهٔ مستنداتی که نمایش داده می‌شود، به این ترتیب تعیین می‌شود.

۱. تنظیم `source` داخل `index.html`
۲. مقدار `repository` در `lunascape-docs.json` در همان پوشه
۳. حدس از روی نشانی `*.github.io` و ساختار شاخه‌ها

## راه ۲: خروجی گرفتن از یک سایت ایستا همراه با سندها

در این راه نمایشگر و فایل‌های سند را با هم خروجی می‌گیرید و همان را میزبانی می‌کنید.

```sh
npm run export:web -- --root ./docs --out ./dist-site
```

خروجی شامل مجموعهٔ نمایشگر، سندهای زیر `docs/`، فایل فهرست `lunascape-docs-manifest.json` و `.nojekyll` است. با قرار دادن مقصد خروجی روی S3 یا GitHub Pages می‌توانید آن را منتشر کنید. برای نمونه‌ای از انتشار خودکار با GitHub Actions، به `examples/workflows/publish-docs-pages.yml` در مخزن مراجعه کنید.

> **توجه**
>
> - **سندهای یک مخزن خصوصی را خروجی نگیرید و روی GitHub Pages نگذارید.** GitHub Pages بیرون از Enterprise Cloud برای همه قابل مشاهده است. اگر انتشار محدود لازم دارید، از راه ۱ استفاده کنید و خواننده را با GitHub وارد کنید.
> - باز کردن مستقیم `index.html` با `file://` کار نمی‌کند، چون مرورگر بارگذاری فایل‌های مجاور و اجرای ماژول‌های ES را به این شکل منع می‌کند. برای بررسی در رایانهٔ خود، از نسخهٔ VS Code یا یک سرور HTTP استفاده کنید.
> - کتابخانه‌های ترسیم TikZ، Vega-Lite، Markmap، WaveDrom، Svgbob و Penrose هنگام نمایش بارگذاری می‌شوند. در سایت خروجی‌گرفته‌شده، پوشهٔ `vendor/` را هم همراه آن قرار دهید.
