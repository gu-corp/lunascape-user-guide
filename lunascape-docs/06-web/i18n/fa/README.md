# آنچه نسخهٔ وب انجام می‌دهد

نسخهٔ وب Lunascape Docs در نشانی <https://docs.lunascape.org/> منتشر شده است. بدون نصب چیزی، می‌توانید اسناد موجود در GitHub را مانند یک وب‌سایت بخوانید.

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| مشاهدهٔ مخزن‌های عمومی | اسناد یک مخزن عمومی GitHub را بدون ورود باز می‌کند |
| مشاهدهٔ مخزن‌های خصوصی | پس از ورود با GitHub، مخزن‌هایی را که دسترسی خواندن آن‌ها را دارید باز می‌کند |
| مشاهدهٔ پوشهٔ محلی | با [گشودن اسناد] و سپس [گشودن اسناد از یک پوشهٔ محلی]، پوشه‌ای را در دستگاه خود باز می‌کند (فقط در مرورگرهای پشتیبانی‌شده) |
| قابلیت‌های مطالعه | INDEX، پیوندها، تاریخچه، پالایش، فهرست درون‌صفحه، تغییر زبان و تغییر پوسته. همانند نسخهٔ VS Code است |
| نمودار و فرمول ریاضی | Mermaid، Vega-Lite، Markmap، WaveDrom، Svgbob، Penrose و فرمول‌های ریاضی KaTeX |
| پیش‌نویس | سند را ویرایش می‌کنید و تغییرها را به صورت پیش‌نویس در دستگاه نگه می‌دارد. چیزی در مخزن نوشته نمی‌شود |
| پیوند مستقیم به صفحه | نشانی اینترنتی می‌تواند مخزن و صفحه را مشخص کند تا صفحه‌ای معیّن مستقیماً باز شود |

## تفاوت‌ها با نسخهٔ VS Code

- بررسی سند، ساخت از الگو، تولید پیشنهاد ترجمه و سازمان‌دهی از INDEX در نسخهٔ وب وجود ندارد.
- نمودارهای TikZ ترسیم نمی‌شوند.
- محتوای ویرایش‌شده در مخزن نوشته نمی‌شود و به پیش‌نویسی در دستگاه شما تبدیل می‌شود. «درخواست انتشار» که پیش‌نویس‌ها را به صورت Pull Request می‌فرستد پیاده‌سازی شده است، اما در نمایشگر عمومی فعال نیست. برای اعمال تغییر در مخزن، با نسخهٔ VS Code یا در یک نسخهٔ محلی (clone) ویرایش کنید.
