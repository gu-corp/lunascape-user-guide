# Što omogućuje web-verzija

Web-verzija programa Lunascape Docs objavljena je na <https://docs.lunascape.org/>. Bez instalacije možete čitati dokumente na GitHubu kao da su web-mjesto.

## Mogućnosti

| Mogućnost | Opis |
|---|---|
| Pregled javnih repozitorija | Otvara dokumente javnog repozitorija na GitHubu bez prijave |
| Pregled privatnih repozitorija | Nakon prijave putem GitHuba otvara repozitorije za koje imate pravo čitanja |
| Pregled lokalnih mapa | [Otvori dokumente], zatim [Otvori dokumente iz lokalne mape], otvara mapu na vašem uređaju (samo u podržanim preglednicima) |
| Čitanje | INDEX, poveznice, povijest, filtriranje, sadržaj stranice, promjena jezika i promjena teme. Jednako kao u verziji za VS Code |
| Dijagrami i matematički izrazi | Mermaid, Vega-Lite, Markmap, WaveDrom, Svgbob, Penrose, matematički izrazi u KaTeX-u |
| Nacrti | Uređujete dokumente, a promjene se čuvaju kao nacrti na vašem uređaju. U repozitorij se ne zapisuje ništa |
| Izravne poveznice na stranicu | URL može navesti repozitorij i stranicu, pa možete izravno otvoriti određenu stranicu |

## Razlike u odnosu na verziju za VS Code

- Provjera dokumenata, izrada iz predloška, izrada prijedloga prijevoda i sređivanje iz INDEX-a nisu dostupni u web-verziji.
- TikZ dijagrami se ne prikazuju.
- Izmjene se ne zapisuju u repozitorij, nego postaju nacrti na vašem uređaju. „Zahtjev za objavu”, kojim se nacrti šalju kao Pull Request, izveden je, ali nije uključen u javnom pregledniku. Za promjene u repozitoriju uređujte dokumente u verziji za VS Code ili u lokalnom klonu.
