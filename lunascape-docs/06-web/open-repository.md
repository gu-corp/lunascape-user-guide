# GitHub のリポジトリを開く

Web 版では、GitHub のリポジトリを複製せずに、そのまま開いて読めます。公開リポジトリならログインは不要です。

## 画面から開く

1. ツールバーの [文書を開く]（フォルダのアイコン）を押します。「文書を開く」画面が開きます。
2. 左の欄で、開く場所を選びます。

   | 場所 | 並ぶもの |
   |---|---|
   | すべて | 下のすべて。最近開いたものが先頭に並びます |
   | 最近開いた | これまでに開いたリポジトリとフォルダ |
   | おすすめ | サイトが紹介しているマニュアル |
   | GitHub のリポジトリ | GitHub でログインしているとき、あなたが読めるリポジトリ |
   | このパソコン | この端末のフォルダ |

3. 開きたい行の [開く] を押します。上の [文書名・リポジトリ名で絞り込み] に入力すると、行を絞り込めます。

一覧にないリポジトリは、左の欄の [owner/repo を入力して開く] から指定します。

> **ヒント**
>
> - 一覧に出る GitHub のリポジトリは、GitHub App「Lunascape Docs」が入っていて、あなたに読み取り権限があるものです。見当たらないときは、リポジトリのオーナーに App の追加を頼んでください。

## 文書の場所を確かめる

ツールバーの左寄りにある小さなアイコン（場所チップ）は、いま読んでいる文書がどこにあるかを示します。

| アイコン | 場所 |
|---|---|
| GitHub のマーク | GitHub から読んでいます。この端末には保存されていません |
| フォルダ | この端末のフォルダです |

アイコンを押すと、場所と状態、そこからできる操作（[GitHub で見る]、[リンクをコピー] など）が表示されます。

## URL で開く

アドレスは、リポジトリと文書の位置をそのまま並べた形です。パスはリポジトリの中での位置なので、GitHub の URL と同じ並びになります。

```text
https://docs.lunascape.org/github/owner/repo/docs/01-product/vision.md
```

| 指定 | 書きかた |
|---|---|
| リポジトリのみ（既定ブランチ） | `/github/owner/repo` |
| リポジトリの中の文書 | `/github/owner/repo/docs/01-product/vision.md` |
| ブランチまたはタグを指定 | 末尾に `?ref=v1.2.0` を付けます |

ページを移動するとアドレスも変わります。ツールバーの [この文書を共有] を押すと、いま読んでいるページのリンクを渡せます。ブラウザの [戻る] [進む] も使えます。

以前の `?source=` の形も、これまでどおり開けます。開いたあとは新しい形に書き換わります。

```text
https://docs.lunascape.org/?source=github:owner/repo@main/docs#/01-product/vision.md
```

> **ご注意**
>
> - ログインしていない状態では、GitHub API の利用制限（1 時間あたり 60 回）があります。文書が多いリポジトリや繰り返しの閲覧では、[GitHub でログイン] してください。
> - `/` を含むブランチ名（`feature/xxx` など）は、上のアドレス形式の `?ref=` で指定できます。`?source=` の形では書けません。
> - 文書は閲覧者の GitHub 権限で読み込まれます。読み取り権限のない人には表示されません。

## ローカルフォルダの文書を開く

ツールバーの [文書を開く] を押し、左の欄にある [ローカルフォルダの文書を開く] から、端末内のフォルダを選びます。ファイルはブラウザの中で処理され、外部へ送られることはありません。フォルダの選択に対応したブラウザ（Chrome、Edge など）で使えます。
