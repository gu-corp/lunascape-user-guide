# 下書きを保存する

Web 版で文書を編集すると、変更はリポジトリには書き込まれず、ブラウザの中に「下書き」として保存されます。

## 下書きを作る

1. 文書を開き、右下の [編集] を押します。
2. 編集して [保存] を押します。
   「下書きとして保存しました」と表示され、変更がブラウザ内に保存されます。

- 下書きのある文書には、INDEX にバッジが付きます。本文の上には「この文書は端末内の下書きです（未公開）」と表示されます。
- ツールバーの [下書き] には件数が表示され、押すと下書きの一覧が開きます。

## 下書きを破棄する

- 文書ごとに破棄するには、本文の上の [下書きを破棄] を押します。
- すべて破棄するには、下書きの一覧から操作します。

## リポジトリに反映する

下書きを Pull Request として送る「公開依頼」は実装されていますが、公開ビューアーでは有効になっていません。リポジトリに反映するには、VS Code 版または手元のクローンで編集してください。

> **ご注意**
>
> - 下書きはブラウザ（IndexedDB）に保存されます。別のブラウザや別の端末には引き継がれません。ブラウザのサイトデータを消すと、下書きも消えます。
> - 下書きを作ったあとにリポジトリ側の文書が更新されると、「上流が更新されています」と表示されます。内容を確認してから、下書きを破棄するか、そのまま使うかを判断してください。
> - [文書を開く] からローカルフォルダを開いて編集した場合は、ブラウザが対応していればファイルに直接保存されます。対応していないブラウザでは、そのセッションの間だけ保持されます。
