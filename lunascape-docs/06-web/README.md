# Web 版でできること

Web ブラウザ版の Lunascape Docs は、<https://docs.lunascape.org/> で公開されています。インストールなしで、GitHub 上の文書を Web サイトのように読めます。

## できること

| 機能 | 内容 |
|---|---|
| 公開リポジトリの閲覧 | ログインなしで、GitHub の公開リポジトリの文書を開きます |
| 非公開リポジトリの閲覧 | GitHub でログインすると、自分に読み取り権限のあるリポジトリを開けます |
| ローカルフォルダの閲覧 | [ローカルフォルダの文書を開く] で、端末内のフォルダを開きます（対応ブラウザのみ） |
| 閲覧機能 | INDEX、リンク、履歴、絞り込み、ページ内目次、言語切り替え、テーマ切り替え。VS Code 版と同じです |
| 図と数式 | Mermaid、Vega-Lite、Markmap、WaveDrom、Svgbob、Penrose、KaTeX 数式 |
| 下書き | 文書を編集し、変更を端末内の下書きとして保持します。リポジトリには書き込みません |
| ページへの直接リンク | URL でリポジトリとページを指定して、特定のページを直接開けます |

## VS Code 版との違い

- 文書チェック、テンプレートからの作成、翻訳案の生成、INDEX からの整理は、Web 版にはありません。
- TikZ 図は描画されません。
- 編集内容はリポジトリに書き込まれず、端末内の下書きになります。下書きを Pull Request として送る「公開依頼」は実装されていますが、公開ビューアーでは有効になっていません。リポジトリに反映するには、VS Code 版か手元のクローンで編集してください。
