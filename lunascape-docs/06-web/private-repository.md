# 非公開リポジトリを閲覧する

非公開リポジトリの文書は、GitHub でログインすると、自分に読み取り権限のあるリポジトリに限って閲覧できます。Lunascape Docs が独自のアカウントや権限を持つことはありません。

## ログインして開く

1. <https://docs.lunascape.org/> を開きます。
   非公開の文書を指定した場合や、まだログインしていない場合は、サインイン画面が表示されます。
2. [GitHub でログイン] を押します。
   GitHub の認証画面がポップアップで開きます。
3. ログインが終わったら、ツールバーの [文書を開く] を押し、[読めるリポジトリから選ぶ] で開きたいリポジトリを選びます。

> **ヒント**
>
> - ログイン中のアカウント名はツールバーに表示されます。[ログアウト] や [別のアカウントでログイン] もここから行えます。
> - 一覧に表示されるのは、GitHub App「Lunascape Docs」がインストールされたアカウント（組織または個人）のリポジトリのうち、自分に読み取り権限があるものです。

## リポジトリのオーナーが行う設定

一覧に対象のリポジトリが表示されない場合は、リポジトリのオーナーまたは組織の管理者が、GitHub App「Lunascape Docs」をインストールする必要があります。

- 要求する権限は Contents（読み書き）と Pull requests（読み書き）です。読み取りは閲覧のため、書き込みは Web からの公開依頼（Pull Request）のためです。文書の内容を Lunascape Docs が保存することはありません。
- インストール単位はアカウント（組織または個人）です。対象を「All repositories」（以後作成されるリポジトリも自動的に含む）にするか、選んだリポジトリだけにするかを設定します。

| 場面 | 手順 |
|---|---|
| 新しく組織または個人アカウントに導入する | [インストールページ](https://github.com/apps/lunascape-docs/installations/new) から実施します |
| 導入済みの組織で対象リポジトリを追加する | 組織の Settings → GitHub Apps → Lunascape Docs → Configure → Repository access で設定します |

組織全体にインストールしても、各メンバーが閲覧できるのは本人が読み取り権限を持つリポジトリだけです。公開依頼を送れるのも、本人が書き込み権限を持つリポジトリだけです。

> **ヒント**
> - 新しくインストールする場合、要求する権限はインストール画面に一覧で表示され、「Install」を押した時点で承認したことになります。追加の操作はありません。
> - 権限が増える前からインストールしていた組織には、管理者に確認のメールが届き、組織の Settings → GitHub Apps → Lunascape Docs → Configure の上部に承認ボタンが表示されます。承認するまで、その組織では閲覧だけができ、公開依頼を送ると「書き込み権限の付与が必要です」と表示されます。
> - 今どの権限で入っているかは、同じ Configure 画面で確認できます。個人アカウントの場合は Settings → Applications → Installed GitHub Apps です。
> - 対象リポジトリを誤って外したりアンインストールした場合は、[インストールページ](https://github.com/apps/lunascape-docs/installations/new)から入れ直せば元に戻ります。公開依頼の拒否メッセージには、直す画面へのリンクが付きます。
> - リポジトリ側で公開依頼を受け付けたくない場合は、`lunascape-docs.json` に `"publish": { "enabled": false }` と書きます。閲覧はそのまま使えます。
