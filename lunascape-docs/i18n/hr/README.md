# Vodič za pomoć za Lunascape Docs

Lunascape Docs radni je prostor za dokumentaciju u kojem Markdown dokumente iz repozitorija čitate, pišete i provjeravate kao da su web-mjesto, bez izgradnje i bez posebnog poslužitelja. Izvornik dokumenta uvijek ostaje Markdown datoteka, a spremanje i predaja u repozitorij nikada se ne obavljaju umjesto vas.

Ovaj vodič za pomoć prije svega opisuje uporabu VS Code proširenja „Lunascape Docs”, a uz to i uporabu inačice za web preglednik.

## Kako se služiti ovim vodičem

- Odaberite temu u INDEX-u slijeva ili slijedite poveznice u tekstu.
- Upišite riječ u [Suzi popis dokumenata] iznad INDEX-a da biste prikazali samo teme koje joj odgovaraju.
- „Na ovoj stranici” zdesna prikazuje naslove trenutačne stranice.
- Nazivi stavki na zaslonu pišu se u uglatim zagradama, primjerice [Uredi]. Pritisci tipki pišu se ovako: `Alt`+`←`.
- Da biste zatvorili pomoć i vratili se na svoj dokument, ponovno pritisnite [Pomoć] na alatnoj traci ili [×] desno od te stavke.
