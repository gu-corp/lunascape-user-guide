# Guida di Lunascape Docs

Lunascape Docs è uno spazio di lavoro documentale che permette di leggere, scrivere e verificare i documenti Markdown contenuti in un repository come se fossero un sito Web, senza compilazione né server dedicato. Il documento canonico resta sempre il file Markdown e nulla viene salvato o sottoposto a commit di propria iniziativa.

Questa guida illustra soprattutto l'uso dell'estensione per VS Code «Lunascape Docs» e descrive anche l'uso della versione per browser Web.

## Come usare questa guida

- Scegliere una voce nell'INDEX a sinistra oppure seguire i collegamenti nel testo.
- Digitare una parola in [Filtra i documenti], sopra l'INDEX, per visualizzare solo le voci corrispondenti.
- In «In questa pagina», a destra, sono elencati i titoli della pagina visualizzata.
- I nomi delle voci visualizzate sullo schermo sono indicati fra parentesi quadre, per esempio [Modifica]. Le combinazioni di tasti sono indicate così: `Alt`+`←`.
- Per chiudere la guida e tornare al documento, premere di nuovo [Guida] nella barra degli strumenti oppure la [×] alla sua destra.
