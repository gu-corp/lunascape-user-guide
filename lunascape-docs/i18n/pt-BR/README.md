# Guia de ajuda do Lunascape Docs

O Lunascape Docs é um espaço de trabalho de documentação para ler, escrever e verificar os documentos Markdown que estão dentro de um repositório como se fossem um site, sem etapa de compilação e sem servidor dedicado. O documento canônico continua sendo sempre o arquivo Markdown, e nada é salvo nem enviado em commit por conta própria.

Este guia de ajuda explica principalmente como usar a extensão do VS Code "Lunascape Docs" e também como usar a versão para navegador Web.

## Como usar este guia de ajuda

- Escolha um item no INDEX à esquerda ou siga os links do texto.
- Digite uma palavra em [Filtrar documentos], acima do INDEX, para exibir somente os itens correspondentes.
- Em "Nesta página", à direita, ficam listados os títulos da página exibida.
- Os nomes dos itens mostrados na tela são indicados entre colchetes, como [Editar]. As teclas são indicadas assim: `Alt`+`←`.
- Para fechar a ajuda e voltar ao documento anterior, pressione [Ajuda] na barra de ferramentas novamente ou pressione o [×] à direita dela.
