# Hjälpguide för Lunascape Docs

Lunascape Docs är en dokumentarbetsyta där du kan läsa, skriva och kontrollera Markdown-dokumenten i en lagringsplats som om de vore en webbplats, utan byggsteg och utan en egen server. Originalet är alltid Markdown-filen, och ingenting sparas eller checkas in åt dig.

Den här hjälpguiden handlar i första hand om hur du använder VS Code-tillägget ”Lunascape Docs” och beskriver även hur webbläsarversionen används.

## Så använder du den här hjälpguiden

- Välj ett ämne i INDEX till vänster eller följ länkarna i texten.
- Skriv ett ord i [Filtrera dokument] ovanför INDEX för att bara visa de ämnen som stämmer.
- ”På den här sidan” till höger visar rubrikerna på sidan du läser.
- Namn som visas på skärmen skrivs inom hakparenteser, till exempel [Redigera]. Tangenttryckningar skrivs som `Alt`+`←`.
- Stäng hjälpen och gå tillbaka till ditt dokument genom att trycka på [Hjälp] i verktygsfältet en gång till, eller på [×] till höger om den.
