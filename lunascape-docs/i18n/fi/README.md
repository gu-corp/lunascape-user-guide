# Lunascape Docs -ohjeopas

Lunascape Docs on dokumenttityötila, jossa säilön sisällä olevia Markdown-dokumentteja luetaan, kirjoitetaan ja tarkistetaan kuin verkkosivustoa – ilman käännösvaihetta tai erillistä palvelinta. Dokumentin alkuperäisversio pysyy aina Markdown-tiedostona, eikä mitään tallenneta tai commitoida puolestasi.

Tämä ohjeopas käsittelee ennen kaikkea VS Code -laajennuksen "Lunascape Docs" käyttöä ja lisäksi selainversion käyttöä.

## Ohjeoppaan käyttäminen

- Valitse aihe vasemmalla olevasta INDEX-paneelista tai seuraa tekstissä olevia linkkejä.
- Kun kirjoitat sanan INDEX-paneelin yläpuolella olevaan kenttään [Rajaa dokumentteja], näkyviin jäävät vain vastaavat aiheet.
- Oikealla oleva "Tällä sivulla" luettelee näkyvissä olevan sivun otsikot.
- Näytöllä näkyvät kohteet merkitään hakasulkeisiin, esimerkiksi [Muokkaa]. Näppäintoiminnot merkitään muodossa `Alt`+`←`.
- Kun haluat sulkea ohjeen ja palata dokumenttiin, paina työkalurivin painiketta [Ohje] uudelleen tai sen vieressä olevaa painiketta [×].
