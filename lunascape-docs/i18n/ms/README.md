# Panduan Bantuan Lunascape Docs

Lunascape Docs ialah ruang kerja dokumentasi untuk membaca, menulis dan menyemak dokumen Markdown di dalam repositori seperti sebuah laman web, tanpa langkah binaan atau pelayan khusus. Dokumen kanonik sentiasa kekal sebagai fail Markdown, dan tiada apa-apa yang disimpan atau dikomit bagi pihak anda.

Panduan bantuan ini menumpukan cara menggunakan sambungan VS Code "Lunascape Docs", dan turut menerangkan cara menggunakan versi pelayar web.

## Cara menggunakan panduan bantuan ini

- Pilih topik dalam INDEX di sebelah kiri, atau ikut pautan di dalam teks.
- Taipkan perkataan ke dalam [Tapis dokumen] di atas INDEX untuk memaparkan topik yang sepadan sahaja.
- "Pada halaman ini" di sebelah kanan menyenaraikan tajuk halaman yang sedang dipaparkan.
- Nama item pada skrin ditulis dalam kurungan siku, contohnya [Edit]. Kekunis ditulis seperti `Alt`+`←`.
- Untuk menutup bantuan dan kembali ke dokumen asal, tekan [Bantuan] pada bar alat sekali lagi, atau tekan [×] di sebelah kanannya.
