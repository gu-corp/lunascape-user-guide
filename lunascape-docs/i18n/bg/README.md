# Ръководство за помощ на Lunascape Docs

Lunascape Docs е работно пространство за документация, което ви позволява да четете, пишете и проверявате Markdown документите в едно хранилище така, както бихте разглеждали уебсайт — без стъпка на компилиране и без специален сървър. Изходният вид на документа винаги остава самият Markdown файл и нищо не се записва или подава като комит вместо вас.

Това ръководство описва преди всичко работата с разширението за VS Code „Lunascape Docs“, а също и работата с версията за уеб браузър.

## Как да използвате това ръководство

- Изберете тема в INDEX отляво или следвайте връзките в текста.
- Въведете дума в [Филтриране на документите] над INDEX, за да се покажат само съответстващите теми.
- „В тази страница“ отдясно изброява заглавията на текущата страница.
- Имената на елементите на екрана са дадени в скоби, например [Редактиране]. Клавишните операции са означени така: `Alt`+`←`.
- За да затворите помощта и да се върнете към документа си, натиснете отново [Помощ] в лентата с инструменти или [×] вдясно от него.
