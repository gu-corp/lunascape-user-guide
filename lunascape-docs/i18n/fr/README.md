# Guide d'aide de Lunascape Docs

Lunascape Docs est un espace de travail documentaire qui permet de lire, d'écrire et de vérifier les documents Markdown d'un dépôt comme s'il s'agissait d'un site web, sans étape de compilation ni serveur dédié. Le document de référence reste toujours le fichier Markdown lui-même, et rien n'est enregistré ni validé à votre place.

Ce guide d'aide décrit principalement l'utilisation de l'extension VS Code « Lunascape Docs », ainsi que celle de la version pour navigateur web.

## Utilisation de ce guide d'aide

- Choisissez une rubrique dans l'INDEX à gauche, ou suivez les liens présents dans le texte.
- Saisissez un mot dans [Filtrer les documents], au-dessus de l'INDEX, pour n'afficher que les rubriques correspondantes.
- « Sur cette page », à droite, présente la liste des titres de la page affichée.
- Les éléments affichés à l'écran sont indiqués entre crochets, par exemple [Modifier]. Les touches sont indiquées sous la forme `Alt`+`←`.
- Pour fermer l'aide et revenir à votre document, appuyez de nouveau sur [Aide] dans la barre d'outils, ou sur le [×] situé à sa droite.
