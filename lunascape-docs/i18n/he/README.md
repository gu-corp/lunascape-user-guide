# מדריך העזרה של Lunascape Docs

‏Lunascape Docs היא סביבת עבודה לתיעוד, שבה אפשר לקרוא, לכתוב ולבדוק מסמכי Markdown שנמצאים בתוך מאגר כאילו היו אתר אינטרנט, בלי שלב בנייה ובלי שרת ייעודי. מסמך המקור נשאר תמיד קובץ Markdown, ושום דבר אינו נשמר או נמסר כ־commit מאחורי גבך.

מדריך עזרה זה מתמקד בשימוש בתוסף VS Code ‏«Lunascape Docs», ומסביר גם את השימוש בגרסת דפדפן האינטרנט.

## איך להשתמש במדריך העזרה הזה

- בוחרים נושא ב־INDEX שמימין, או עוקבים אחר הקישורים שבגוף הטקסט.
- מקלידים מילה בשדה [סינון מסמכים] שמעל ה־INDEX כדי להציג רק את הנושאים המתאימים.
- באזור «בדף זה» שמשמאל מופיעות הכותרות של הדף המוצג.
- שמות הפריטים שמופיעים על המסך מסומנים בסוגריים מרובעים, למשל [עריכה]. הקשות מקשים מסומנות כך: `Alt`+`←`.
- כדי לסגור את העזרה ולחזור למסמך, לוחצים שוב על [עזרה] בסרגל הכלים, או על ה־[×] שלידו.
