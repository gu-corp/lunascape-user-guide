# Hướng dẫn trợ giúp Lunascape Docs

Lunascape Docs là không gian làm việc tài liệu giúp bạn đọc, viết và kiểm tra các tài liệu Markdown nằm trong kho lưu trữ như một trang web, mà không cần bước build hay máy chủ riêng. Bản gốc của tài liệu luôn là tập tin Markdown, và phần mềm không tự ý lưu hay commit thay bạn.

Hướng dẫn trợ giúp này tập trung vào cách dùng tiện ích mở rộng VS Code "Lunascape Docs", đồng thời cũng giới thiệu cách dùng bản trình duyệt web.

## Cách dùng hướng dẫn trợ giúp này

- Chọn một mục trong INDEX ở bên trái, hoặc theo các liên kết trong phần nội dung để đọc tiếp.
- Nhập một từ vào [Lọc tài liệu] phía trên INDEX để chỉ hiển thị những mục phù hợp.
- "Trên trang này" ở bên phải liệt kê các tiêu đề của trang đang xem.
- Tên các mục hiển thị trên màn hình được ghi trong dấu [ ], ví dụ [Chỉnh sửa]. Thao tác phím được ghi như `Alt`+`←`.
- Để đóng trợ giúp và quay lại tài liệu ban đầu, nhấn lại [Trợ giúp] trên thanh công cụ, hoặc nhấn [×] ở bên phải nút đó.
