# Lunascape Docs सहायता गाइड

Lunascape Docs एक दस्तावेज़ कार्यस्थान है, जिससे आप रिपॉज़िटरी के अंदर मौजूद Markdown दस्तावेज़ों को बिल्ड या अलग सर्वर के बिना वेबसाइट की तरह पढ़, लिख और जाँच सकते हैं। दस्तावेज़ का प्रामाणिक रूप हमेशा Markdown फ़ाइल ही रहता है, और आपकी ओर से अपने आप कोई सहेजना या कमिट नहीं किया जाता।

यह सहायता गाइड मुख्य रूप से VS Code एक्सटेंशन "Lunascape Docs" के उपयोग की व्याख्या करती है, और साथ ही वेब ब्राउज़र संस्करण का उपयोग भी बताती है।

## इस सहायता गाइड का उपयोग कैसे करें

- बाईं ओर के INDEX में कोई विषय चुनें, या पाठ में दी गई कड़ियों का अनुसरण करें।
- INDEX के ऊपर [दस्तावेज़ फ़िल्टर करें] में कोई शब्द लिखने पर केवल मेल खाने वाले विषय दिखते हैं।
- दाईं ओर "इस पृष्ठ पर" में, दिखाए जा रहे पृष्ठ के शीर्षक क्रम से दिखते हैं।
- स्क्रीन पर दिखने वाले आइटम के नाम [संपादित करें] की तरह [ ] में लिखे जाते हैं। कुंजी संचालन `Alt`+`←` की तरह लिखे जाते हैं।
- सहायता बंद करके अपने दस्तावेज़ पर लौटने के लिए, टूलबार में [सहायता] फिर से दबाएँ, या उसके दाईं ओर के [×] को दबाएँ।
