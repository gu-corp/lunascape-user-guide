# Справка по Lunascape Docs

Lunascape Docs — это рабочая среда для документации: она позволяет читать, писать и проверять документы Markdown внутри репозитория так, как если бы это был веб-сайт, без сборки и отдельного сервера. Исходным документом всегда остается сам файл Markdown, и ничего не сохраняется и не фиксируется без вашего участия.

Эта справка посвящена прежде всего работе с расширением «Lunascape Docs» для VS Code, а также описывает версию для веб-браузера.

## Как пользоваться этой справкой

- Выберите раздел в INDEX слева или переходите по ссылкам в тексте.
- Введите слово в поле [Фильтр документов] над INDEX, чтобы показать только подходящие разделы.
- Справа, в области «На этой странице», перечислены заголовки открытой страницы.
- Названия элементов на экране приводятся в квадратных скобках, например [Редактировать]. Нажатия клавиш записываются так: `Alt`+`←`.
- Чтобы закрыть справку и вернуться к документу, снова нажмите [Справка] на панели инструментов или [×] справа от нее.
