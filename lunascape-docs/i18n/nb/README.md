# Lunascape Docs hjelpeveiledning

Lunascape Docs er et dokumentarbeidsområde for å lese, skrive og kontrollere Markdown-dokumentene inne i et repositorium som om de var et nettsted, uten et byggetrinn eller en dedikert server. Markdown-filene forblir alltid kilden til sannhet, og ingenting lagres eller commites på dine vegne.

Denne hjelpeveiledningen tar først og fremst for seg VS Code-utvidelsen «Lunascape Docs», og dekker også nettleserversjonen.

## Slik bruker du denne hjelpeveiledningen

- Velg et emne i INDEX til venstre, eller følg lenkene i teksten.
- Skriv inn et ord i [Filtrer dokumenter] over INDEX for å vise bare de emnene som passer.
- «På denne siden» til høyre viser overskriftene på den siden som vises.
- Elementer som vises på skjermen, angis med [ ], for eksempel [Rediger]. Tastetrykk angis som `Alt`+`←`.
- For å lukke hjelpen og gå tilbake til dokumentet ditt trykker du på [Hjelp] i verktøylinjen en gang til, eller på [×] til høyre for den.
