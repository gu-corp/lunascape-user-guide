# Lunascape Docs Yardım Kılavuzu

Lunascape Docs, bir deponun içindeki Markdown belgelerini derleme adımı ya da özel bir sunucu olmadan bir web sitesi gibi okumak, yazmak ve denetlemek için kullanılan bir belge çalışma alanıdır. Belgenin aslı her zaman Markdown dosyasının kendisidir; sizin yerinize kaydetme veya işleme (commit) yapılmaz.

Bu yardım kılavuzu, ağırlıklı olarak VS Code eklentisi "Lunascape Docs"un kullanımını, bunun yanında web tarayıcısı sürümünün kullanımını anlatır.

## Bu yardım kılavuzunu kullanma

- Soldaki INDEX bölümünden bir konu seçin ya da metindeki bağlantıları izleyin.
- INDEX'in üzerindeki [Belgeleri filtrele] alanına bir sözcük yazarak yalnızca eşleşen konuları görüntüleyebilirsiniz.
- Sağdaki "Bu sayfada" bölümünde, görüntülenen sayfanın başlıkları sıralanır.
- Ekranda görünen öğeler [Düzenle] gibi köşeli ayraç içinde gösterilir. Tuş işlemleri `Alt`+`←` biçiminde yazılır.
- Yardımı kapatıp belgenize dönmek için araç çubuğundaki [Yardım] düğmesine yeniden basın ya da yanındaki [×] düğmesine basın.
