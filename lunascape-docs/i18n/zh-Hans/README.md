# Lunascape Docs 帮助指南

Lunascape Docs 是一个文档工作区，无需构建或专用服务器，即可像网站一样阅读、编写和检查仓库中的 Markdown 文档。文档的正本始终是 Markdown 文件本身，不会擅自保存或提交。

本帮助指南以 VS Code 扩展「Lunascape Docs」的用法为中心，同时也介绍 Web 浏览器版的用法。

## 本帮助指南的使用方法

- 在左侧的 INDEX 中选择项目，或沿着正文中的链接继续阅读。
- 在 INDEX 上方的 [筛选文档] 中输入词语，即可只显示符合条件的项目。
- 右侧的「本页目录」中列出当前页面的标题。
- 屏幕上显示的项目名称用 [ ] 表示，例如 [编辑]。按键操作写作 `Alt`+`←`。
- 要关闭帮助并返回原文档，请再次按工具栏中的 [帮助]，或按其右侧的 [×]。
