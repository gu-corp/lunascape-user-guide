# Przewodnik pomocy Lunascape Docs

Lunascape Docs to obszar roboczy dokumentacji, w którym można czytać, pisać i sprawdzać dokumenty Markdown znajdujące się w repozytorium tak, jakby były witryną internetową — bez etapu budowania i bez dedykowanego serwera. Źródłem dokumentu zawsze pozostają pliki Markdown, a nic nie jest zapisywane ani zatwierdzane bez Twojego udziału.

Ten przewodnik pomocy opisuje przede wszystkim korzystanie z rozszerzenia VS Code „Lunascape Docs”, a także pracę w wersji przeglądarkowej.

## Jak korzystać z tego przewodnika

- Wybierz temat w panelu INDEX po lewej stronie albo podążaj za odnośnikami w tekście.
- Wpisz słowo w polu [Filtruj dokumenty] nad panelem INDEX, aby wyświetlić tylko pasujące tematy.
- Panel „Na tej stronie” po prawej stronie zawiera listę nagłówków wyświetlanej strony.
- Nazwy elementów widocznych na ekranie zapisujemy w nawiasach kwadratowych, na przykład [Edytuj]. Skróty klawiszowe zapisujemy w postaci `Alt`+`←`.
- Aby zamknąć pomoc i wrócić do dokumentu, naciśnij ponownie [Pomoc] na pasku narzędzi albo znajdujący się obok przycisk [×].
