# Lunascape Docs সহায়তা নির্দেশিকা

Lunascape Docs হলো একটি নথি ওয়ার্কস্পেস, যা রিপোজিটরির ভিতরে থাকা Markdown নথিগুলোকে বিল্ড বা আলাদা সার্ভার ছাড়াই একটি ওয়েবসাইটের মতো পড়তে, লিখতে ও যাচাই করতে দেয়। নথির মূল রূপ সবসময় Markdown ফাইলই থাকে, এবং আপনার হয়ে নিজে থেকে সংরক্ষণ বা কমিট করা হয় না।

এই সহায়তা নির্দেশিকায় মূলত VS Code এক্সটেনশন "Lunascape Docs"-এর ব্যবহার, সেই সঙ্গে ওয়েব ব্রাউজার সংস্করণের ব্যবহারও ব্যাখ্যা করা হয়েছে।

## এই সহায়তা নির্দেশিকার ব্যবহার

- বাঁ দিকের INDEX থেকে কোনো বিষয় বেছে নিন, অথবা লেখার ভিতরের লিংক ধরে পড়তে থাকুন।
- INDEX-এর উপরে থাকা [নথি ফিল্টার করুন]-এ কোনো শব্দ লিখলে শুধু সংশ্লিষ্ট বিষয়গুলো দেখানো যায়।
- ডান দিকের "এই পৃষ্ঠায়"-তে বর্তমান পৃষ্ঠার শিরোনামগুলো সাজানো থাকে।
- পর্দায় দেখানো নামগুলো [সম্পাদনা]-র মতো [ ] দিয়ে লেখা হয়। কী-অপারেশন `Alt`+`←`-এর মতো করে লেখা হয়।
- সহায়তা বন্ধ করে মূল নথিতে ফিরতে টুলবারের [সহায়তা] আবার চাপুন, অথবা তার ডান পাশের [×] চাপুন।
