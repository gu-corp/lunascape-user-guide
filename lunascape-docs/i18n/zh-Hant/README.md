# Lunascape Docs 說明指南

Lunascape Docs 是一個文件工作區，讓您不需建置程序或專用伺服器，就能像瀏覽網站一樣閱讀、撰寫及確認存放庫中的 Markdown 文件。文件的正本始終是 Markdown 檔案本身，本產品不會擅自儲存或提交。

本說明指南以 VS Code 擴充功能「Lunascape Docs」的使用方式為主，同時一併說明網頁瀏覽器版的使用方式。

## 本說明指南的使用方式

- 在左側的 INDEX 中選擇項目，或依循內文中的連結繼續閱讀。
- 在 INDEX 上方的 [篩選文件] 中輸入文字，即可只顯示符合的項目。
- 右側的「本頁內容」會列出目前頁面的標題。
- 畫面上顯示的項目名稱以 [編輯] 這樣的 [ ] 標示。按鍵操作則以 `Alt`+`←` 這樣的方式標示。
- 若要關閉說明並返回原本的文件，請再按一次工具列的 [說明]，或按其右側的 [×]。
