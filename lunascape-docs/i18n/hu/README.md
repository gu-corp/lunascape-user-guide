# Lunascape Docs súgó

A Lunascape Docs olyan dokumentum-munkaterület, amelyben az adattárban lévő Markdown dokumentumokat build és külön kiszolgáló nélkül, weboldalként olvashatja, írhatja és ellenőrizheti. A dokumentumok hiteles változata mindig maga a Markdown fájl marad, és a program semmit nem ment el és nem véglegesít a felhasználó helyett.

Ez a súgó elsősorban a „Lunascape Docs” VS Code-bővítmény használatát mutatja be, de kitér a webböngészős változat használatára is.

## A súgó használata

- Válasszon egy témakört a bal oldali INDEX panelen, vagy kövesse a szövegben lévő hivatkozásokat.
- Ha az INDEX fölötti [Dokumentumok szűrése] mezőbe beír egy szót, csak a találatok jelennek meg.
- A jobb oldali „Ezen az oldalon” részen a megjelenített oldal címsorai sorakoznak.
- A képernyőn megjelenő elemek nevét szögletes zárójel jelöli, például [Szerkesztés]. A billentyűkombinációkat így jelöljük: `Alt`+`←`.
- A súgó bezárásához és a dokumentumhoz való visszatéréshez nyomja meg újra az eszköztár [Súgó] gombját, vagy a tőle jobbra lévő [×] gombot.
