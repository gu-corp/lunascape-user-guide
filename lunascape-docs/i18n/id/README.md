# Panduan Bantuan Lunascape Docs

Lunascape Docs adalah ruang kerja dokumentasi untuk membaca, menulis, dan memeriksa dokumen Markdown di dalam repositori seperti sebuah situs web, tanpa proses build maupun server khusus. Dokumen kanonik selalu tetap berupa berkas Markdown, dan tidak ada penyimpanan atau komit yang dilakukan tanpa sepengetahuan Anda.

Panduan bantuan ini terutama menjelaskan cara menggunakan ekstensi VS Code "Lunascape Docs", sekaligus menjelaskan cara menggunakan versi peramban web.

## Cara menggunakan panduan bantuan ini

- Pilih topik pada INDEX di sebelah kiri, atau ikuti tautan di dalam teks.
- Ketikkan kata pada [Saring dokumen] di atas INDEX untuk menampilkan hanya topik yang sesuai.
- "Di halaman ini" di sebelah kanan memuat daftar judul dari halaman yang sedang ditampilkan.
- Nama item yang tampil di layar ditulis dengan tanda [ ], misalnya [Edit]. Penekanan tombol ditulis seperti `Alt`+`←`.
- Untuk menutup bantuan dan kembali ke dokumen semula, tekan [Bantuan] pada bilah alat sekali lagi, atau tekan [×] di sebelah kanannya.
