# Lunascape Docs Helpgids

Lunascape Docs is een documentwerkruimte waarmee u de Markdown-documenten in een repository als een website leest, schrijft en controleert, zonder buildstap of aparte server. De Markdown-bestanden blijven altijd het brondocument, en er wordt niets zonder uw toedoen opgeslagen of vastgelegd.

Deze helpgids beschrijft vooral het gebruik van de VS Code-extensie "Lunascape Docs" en behandelt daarnaast de webversie.

## Deze helpgids gebruiken

- Kies een onderwerp in de INDEX aan de linkerkant of volg de koppelingen in de tekst.
- Typ een woord in [Documenten filteren] boven de INDEX om alleen de bijbehorende onderwerpen te tonen.
- In "Op deze pagina" rechts staan de koppen van de huidige pagina.
- Namen van items op het scherm staan tussen blokhaken, bijvoorbeeld [Bewerken]. Toetsaanslagen worden weergegeven als `Alt`+`←`.
- Druk nogmaals op [Help] in de werkbalk of op de [×] ernaast om de help te sluiten en naar uw document terug te keren.
