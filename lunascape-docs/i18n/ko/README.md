# Lunascape Docs 도움말 가이드

Lunascape Docs는 리포지토리 안에 있는 Markdown 문서를 빌드나 전용 서버 없이 웹 사이트처럼 읽고, 쓰고, 확인하기 위한 문서 워크스페이스입니다. 문서의 정본은 언제나 Markdown 파일 그대로이며, 저장이나 커밋을 임의로 수행하지 않습니다.

이 도움말 가이드는 VS Code 확장 기능 "Lunascape Docs"의 사용법을 중심으로, 웹 브라우저 버전의 사용법도 함께 설명합니다.

## 이 도움말 가이드 사용법

- 왼쪽 INDEX에서 항목을 선택하거나, 본문 안의 링크를 따라가며 읽습니다.
- INDEX 위에 있는 [문서 필터링]에 단어를 입력하면 해당하는 항목만 표시할 수 있습니다.
- 오른쪽 "이 페이지"에는 표시 중인 페이지의 제목이 나열됩니다.
- 화면에 표시되는 항목 이름은 [편집]과 같이 [ ]로 표시합니다. 키 조작은 `Alt`+`←`와 같이 표시합니다.
- 도움말을 닫고 원래 문서로 돌아가려면 도구 모음의 [도움말]을 다시 누르거나, 그 오른쪽에 있는 [×]를 누릅니다.
