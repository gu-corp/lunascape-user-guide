# راهنمای Lunascape Docs

Lunascape Docs یک فضای کاری برای مستندات است که با آن می‌توانید اسناد Markdown داخل یک مخزن را بدون ساخت (build) و بدون سرور اختصاصی، مانند یک وب‌سایت بخوانید، بنویسید و بررسی کنید. مرجع اصلی سند همیشه همان فایل Markdown است و هیچ ذخیره یا کامیتی بدون خواست شما انجام نمی‌شود.

این راهنما بیشتر بر نحوهٔ استفاده از افزونهٔ VS Code با نام «Lunascape Docs» تمرکز دارد و نحوهٔ استفاده از نسخهٔ مرورگر وب را نیز شرح می‌دهد.

## نحوهٔ استفاده از این راهنما

- از INDEX در سمت راست یک موضوع را انتخاب کنید یا پیوندهای داخل متن را دنبال کنید.
- با نوشتن یک واژه در [محدود کردن اسناد] در بالای INDEX، تنها موضوع‌های مرتبط نمایش داده می‌شوند.
- در «در این صفحه» در سمت چپ، عنوان‌های صفحهٔ جاری فهرست می‌شوند.
- نام گزینه‌های روی صفحه با علامت [ ] نشان داده می‌شود، مانند [ویرایش]. کلیدها به این شکل نوشته می‌شوند: `Alt`+`←`.
- برای بستن راهنما و بازگشت به سند خود، دوبارهٔ [راهنما] را در نوار ابزار فشار دهید یا [×] کنار آن را بزنید.
