# دليل مساعدة Lunascape Docs

Lunascape Docs هو مساحة عمل للتوثيق تتيح قراءة مستندات Markdown الموجودة داخل مستودع وكتابتها والتحقق منها كما لو كانت موقع ويب، دون خطوة بناء أو خادم مخصص. تبقى ملفات Markdown دائمًا هي النسخة الأصلية، ولا يُحفظ أو يُودَع أي شيء نيابةً عنك.

يركّز دليل المساعدة هذا على كيفية استخدام إضافة VS Code «Lunascape Docs»، ويشرح كذلك كيفية استخدام نسخة متصفح الويب.

## كيفية استخدام دليل المساعدة هذا

- اختر بندًا من INDEX على اليسار، أو تابع القراءة باتّباع الروابط الواردة في النص.
- اكتب كلمة في [تصفية المستندات] أعلى INDEX لعرض البنود المطابقة فقط.
- يسرد «في هذه الصفحة» على اليمين عناوين الصفحة المعروضة.
- تُكتب أسماء العناصر الظاهرة على الشاشة بين قوسين معقوفين، مثل [تحرير]. وتُكتب مفاتيح لوحة المفاتيح على هذا النحو: `Alt`+`←`.
- لإغلاق المساعدة والعودة إلى مستندك، اضغط [مساعدة] في شريط الأدوات مرة أخرى، أو اضغط [×] المجاور له.
