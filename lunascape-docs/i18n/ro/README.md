# Ghidul de ajutor Lunascape Docs

Lunascape Docs este un spațiu de lucru pentru documentație, care vă permite să citiți, să scrieți și să verificați documentele Markdown dintr-un depozit ca și cum ar fi un site web, fără pas de compilare și fără server dedicat. Fișierele Markdown rămân întotdeauna documentul canonic, iar nimic nu se salvează și nu se comite în locul dumneavoastră.

Acest ghid de ajutor explică în principal utilizarea extensiei VS Code „Lunascape Docs”, precum și utilizarea versiunii pentru browserul web.

## Cum se folosește acest ghid de ajutor

- Alegeți un subiect din INDEX, în stânga, sau urmați legăturile din text.
- Tastați un cuvânt în [Filtrează documentele], deasupra INDEX, pentru a afișa numai subiectele care se potrivesc.
- În dreapta, „Pe această pagină” enumeră titlurile paginii afișate.
- Denumirile elementelor de pe ecran se scriu între paranteze drepte, de exemplu [Editează]. Tastele se scriu astfel: `Alt`+`←`.
- Pentru a închide ajutorul și a reveni la document, apăsați din nou [Ajutor] în bara de instrumente sau apăsați [×] din dreapta acestuia.
