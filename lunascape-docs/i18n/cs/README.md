# Nápověda k Lunascape Docs

Lunascape Docs je dokumentační pracovní prostor, ve kterém můžete číst, psát a ověřovat dokumenty ve formátu Markdown uložené v úložišti jako na webové stránce, bez sestavení a bez zvláštního serveru. Originálem dokumentu vždy zůstává soubor Markdown a nic se neukládá ani neodesílá do úložiště za vás.

Tato nápověda popisuje především používání rozšíření „Lunascape Docs“ pro VS Code a spolu s tím i používání webové verze.

## Jak tuto nápovědu používat

- Vyberte položku v panelu INDEX vlevo nebo pokračujte podle odkazů v textu.
- Když do pole [Filtrovat dokumenty] nad panelem INDEX zadáte slovo, zobrazí se pouze odpovídající položky.
- V části „Na této stránce“ vpravo jsou uvedeny nadpisy zobrazené stránky.
- Názvy položek na obrazovce jsou uvedeny v hranatých závorkách, například [Upravit]. Klávesy jsou zapsány například jako `Alt`+`←`.
- Chcete-li nápovědu zavřít a vrátit se k původnímu dokumentu, stiskněte znovu [Nápověda] na panelu nástrojů nebo [×] napravo od tohoto tlačítka.
