# คู่มือวิธีใช้ Lunascape Docs

Lunascape Docs คือพื้นที่ทำงานเอกสารสำหรับอ่าน เขียน และตรวจสอบเอกสาร Markdown ที่อยู่ในที่เก็บ ให้เหมือนกับเว็บไซต์ โดยไม่ต้องสร้างบิลด์หรือใช้เซิร์ฟเวอร์เฉพาะ ตัวจริงของเอกสารยังคงเป็นไฟล์ Markdown เสมอ และจะไม่มีการบันทึกหรือคอมมิตแทนคุณ

คู่มือวิธีใช้นี้อธิบายวิธีใช้ส่วนขยาย VS Code "Lunascape Docs" เป็นหลัก พร้อมทั้งวิธีใช้เวอร์ชันเว็บเบราว์เซอร์ด้วย

## วิธีใช้คู่มือนี้

- เลือกหัวข้อจาก INDEX ทางด้านซ้าย หรือคลิกลิงก์ในเนื้อหาเพื่ออ่านต่อ
- พิมพ์คำลงใน [กรองเอกสาร] ที่อยู่เหนือ INDEX เพื่อแสดงเฉพาะหัวข้อที่ตรงกัน
- "ในหน้านี้" ทางด้านขวาจะแสดงรายการหัวเรื่องของหน้าที่กำลังแสดงอยู่
- ชื่อรายการที่ปรากฏบนหน้าจอเขียนไว้ในวงเล็บเหลี่ยม เช่น [แก้ไข] การกดแป้นเขียนในรูปแบบ `Alt`+`←`
- หากต้องการปิดวิธีใช้และกลับไปยังเอกสารเดิม ให้กด [วิธีใช้] บนแถบเครื่องมืออีกครั้ง หรือกด [×] ที่อยู่ถัดไปทางขวา
