# Lunascape Docs Hilfeleitfaden

Lunascape Docs ist ein Dokumenten-Arbeitsbereich, mit dem Sie die Markdown-Dokumente in einem Repository wie eine Website lesen, schreiben und prüfen können – ohne Build-Schritt und ohne eigenen Server. Die Markdown-Dateien bleiben stets das Original, und nichts wird ohne Ihr Zutun gespeichert oder committet.

Dieser Hilfeleitfaden behandelt in erster Linie die Verwendung der VS-Code-Erweiterung „Lunascape Docs“ und geht daneben auch auf die Web-Version im Browser ein.

## So verwenden Sie diesen Hilfeleitfaden

- Wählen Sie im INDEX links einen Eintrag aus oder folgen Sie den Links im Text.
- Geben Sie in das Feld [Dokumente filtern] über dem INDEX ein Wort ein, um nur die passenden Einträge anzuzeigen.
- „Auf dieser Seite“ rechts listet die Überschriften der angezeigten Seite auf.
- Auf dem Bildschirm angezeigte Bezeichnungen werden wie [Bearbeiten] in [ ] dargestellt. Tastenbedienungen werden wie `Alt`+`←` angegeben.
- Um die Hilfe zu schließen und zu Ihrem Dokument zurückzukehren, drücken Sie in der Symbolleiste erneut [Hilfe] oder das [×] rechts daneben.
