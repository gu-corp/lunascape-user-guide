# Довідковий посібник Lunascape Docs

Lunascape Docs — це робоча область документації, яка дає змогу читати, писати та перевіряти документи Markdown усередині репозиторію так, ніби це вебсайт, без збирання та без окремого сервера. Оригіналом документа завжди залишається сам файл Markdown, і програма нічого не зберігає й не фіксує у Git без вашої участі.

Цей довідковий посібник присвячений насамперед роботі з розширенням «Lunascape Docs» для VS Code, а також описує роботу у веббраузері.

## Як користуватися цим посібником

- Вибирайте розділ в INDEX ліворуч або переходьте за посиланнями в тексті.
- Введіть слово в поле [Фільтрувати документи] над INDEX, щоб показати лише відповідні розділи.
- Праворуч, на панелі «На цій сторінці», перелічено заголовки поточної сторінки.
- Назви екранних елементів подано у квадратних дужках, наприклад [Редагувати]. Натискання клавіш подано так: `Alt`+`←`.
- Щоб закрити довідку й повернутися до свого документа, натисніть [Довідка] на панелі інструментів ще раз або [×] праворуч від неї.
