# Guía de ayuda de Lunascape Docs

Lunascape Docs es un espacio de trabajo de documentación para leer, escribir y comprobar los documentos Markdown que están dentro de un repositorio como si fueran un sitio web, sin compilación ni servidor dedicado. Los archivos Markdown siguen siendo siempre el documento original, y no se guarda ni se confirma nada por su cuenta.

Esta guía de ayuda explica sobre todo cómo usar la extensión de VS Code «Lunascape Docs» y también cómo usar la versión para navegador web.

## Cómo usar esta guía de ayuda

- Elija un tema en el INDEX de la izquierda o siga los enlaces del texto.
- Escriba una palabra en [Filtrar documentos], encima del INDEX, para mostrar solo los temas que coincidan.
- «En esta página», a la derecha, muestra los títulos de la página actual.
- Los nombres que aparecen en pantalla se indican entre corchetes, por ejemplo [Editar]. Las teclas se indican así: `Alt`+`←`.
- Para cerrar la ayuda y volver a su documento, vuelva a pulsar [Ayuda] en la barra de herramientas o pulse la [×] que está a su derecha.
