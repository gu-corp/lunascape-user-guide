# Hjælpeguide til Lunascape Docs

Lunascape Docs er et dokumentarbejdsrum, hvor du kan læse, skrive og kontrollere Markdown-dokumenterne i et lager, som var de et websted — uden byggetrin og uden en dedikeret server. Markdown-filerne er altid originalen, og intet bliver gemt eller committet på dine vegne.

Denne hjælpeguide handler først og fremmest om VS Code-udvidelsen "Lunascape Docs" og beskriver desuden brugen i webbrowseren.

## Sådan bruger du denne hjælpeguide

- Vælg et emne i INDEX til venstre, eller følg linkene i teksten.
- Skriv et ord i [Filtrér dokumenter] over INDEX for kun at vise de emner, der passer.
- "På denne side" til højre viser overskrifterne på den side, du har åben.
- Navne på det, der vises på skærmen, skrives i kantede parenteser, for eksempel [Rediger]. Tastetryk skrives som `Alt`+`←`.
- Luk hjælpen og vend tilbage til dit dokument ved at trykke på [Hjælp] i værktøjslinjen igen eller på [×] til højre for den.
