# Lunascape Docs Help Guide

Lunascape Docs is a documentation workspace for reading, writing and checking the Markdown documents inside a repository as if they were a website, without a build step or a dedicated server. The Markdown files always remain the source of truth, and nothing is saved or committed on your behalf.

This help guide focuses on the VS Code extension "Lunascape Docs" and also covers the Web viewer.

## How to use this help guide

- Choose a topic in the INDEX on the left, or follow the links in the text.
- Type a word into [文書を絞り込み] (Filter documents) above the INDEX to show only matching topics.
- "このページ" (This page) on the right lists the headings of the current page.
- On-screen items are written in brackets, for example [編集] (Edit). The Japanese label is the one shown on screen; the English meaning follows in parentheses. Key presses are written like `Alt`+`←`.
- To close the help and return to your document, press [ヘルプ] (Help) in the toolbar again, or the [×] next to it.
