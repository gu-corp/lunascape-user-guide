# 安全性與寫入邊界

Lunascape Docs 為了保護您的文件與裝置所設下的邊界。

## 顯示

- 由 Markdown 產生的 HTML，以及由圖表產生的 SVG，都會先以 DOMPurify 3.4.14 淨化後才顯示。
- MDX 中包含的任意指令碼一律不執行。
- KaTeX 以 `trust: false`、`maxSize: 50`、`maxExpand: 1000` 執行，不信任外部 HTML，也不信任任意命令。
- Markmap、WaveDrom、Svgbob、Vega-Lite、Penrose 的繪圖程式庫，只有在有對應的區塊時，才會在裝置內載入固定的版本。不允許參照外部資源、原始 HTML 與可執行的語法，並會從產生的 SVG 中移除指令碼、外部圖片、`link`、`style` 與 `foreignObject`。
- TikZ 的繪製不會啟動主機的 LaTeX，而是在具備記憶體內檔案系統的 WebAssembly TeX 工作程序中逐一執行。輸入、佇列、記憶體、執行時間（15 秒）與 SVG 輸出皆有上限，並會拒絕檔案 I/O 指令。

## 文件與檔案的存取

- 文件的連結與檔案操作無法跨出文件根目錄。
- 從 INDEX 進行的建立、重新命名、移動與刪除，會在擴充功能端重新確認文件根目錄、INDEX 的版本、正本的路徑、對象的種類、符號連結的邊界，以及未儲存的文件之後才套用。來自過時選單或其他文件根目錄的操作要求不會套用。
- 編輯文件期間，或正在套用其他 INDEX 操作期間，INDEX 的變更操作會停用。
- 從範本建立時，會在預覽之後重新確認工作區的信任狀態、文件根目錄的實體、INDEX 的版本、Standard Pack 與產生的內容、儲存位置，以及符號連結的邊界。不會覆寫既有檔案，也不會建立與預覽不同的內容或超過 4 MiB 的展開結果。
- 設定檔的儲存會在儲存前確認版本，偵測到外部變更時即中止。

## 對外傳送

- 不會為了閱覽、編輯與檢查而將文件送往外部。文件檢查會在裝置內以確定性的方式執行。
- 只有翻譯（本頁的翻譯、批次翻譯）會事先顯示傳送目的地與傳送範圍，並在獲得明確許可時才將文件傳送至語言模型。 <!-- ai-only -->
- 翻譯提案會以差異呈現，並在重新確認正本與翻譯目標的版本後，只有在人員明確儲存時才套用。 <!-- ai-only -->
- 供 AI 代理程式使用的規格工具不會傳回文件的內文、工作區名稱與本機路徑。 <!-- ai-only -->

## Git

- 儲存只會寫入檔案。任何功能都不會自動進行 Git 的暫存或提交。
- 不會在無聲的情況下刪除或變更 `_meta.json` 等既有檔案。孤立的翻譯版本也不會自動刪除或移動。
