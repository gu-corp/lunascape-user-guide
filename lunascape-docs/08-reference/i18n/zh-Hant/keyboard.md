# 鍵盤操作一覽

## 檢視器

| 操作 | 按鍵 |
|---|---|
| 返回 | `Alt`+`←` |
| 前進 | `Alt`+`→` |
| 關閉 INDEX 覆蓋層、選單或對話方塊 | `Esc` |

## INDEX

| 操作 | 按鍵 |
|---|---|
| 將項目上移／下移一層（重新排序） | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| 在項目選單中移動 | `↑` / `↓` |
| 移至項目選單的開頭／結尾 | `Home` / `End` |
| 關閉項目選單（將焦點移回原處） | `Esc` |
| 離開項目選單 | `Tab` |

## VS Code

| 操作 | 按鍵 |
|---|---|
| 命令選擇區 | `⇧⌘P` / `Ctrl+Shift+P` |
| 擴充功能檢視 | `⇧⌘X` / `Ctrl+Shift+X` |
| 設定 | `⌘,` / `Ctrl+,` |

## 網頁瀏覽器版

可使用瀏覽器的 [返回] [前進] 瀏覽歷程記錄。
