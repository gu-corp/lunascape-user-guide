# Hurtigtaster

## Viser

| Handling | Taster |
|---|---|
| Tilbake | `Alt`+`←` |
| Fram | `Alt`+`→` |
| Lukk INDEX-overlegget, en meny eller en dialog | `Esc` |

## INDEX

| Handling | Taster |
|---|---|
| Flytt et element opp eller ned (endre rekkefølge) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Flytt deg innenfor en elementmeny | `↑` / `↓` |
| Hopp til det første eller siste menyelementet | `Home` / `End` |
| Lukk en elementmeny (flytter fokus tilbake dit den ble åpnet) | `Esc` |
| Gå ut av en elementmeny | `Tab` |

## VS Code

| Handling | Taster |
|---|---|
| Kommandopalett | `⇧⌘P` / `Ctrl+Shift+P` |
| Utvidelsesvisning | `⇧⌘X` / `Ctrl+Shift+X` |
| Innstillinger | `⌘,` / `Ctrl+,` |

## Nettleserversjon

Med nettleserens [Tilbake] og [Fram] kan du bla gjennom nettleserloggen.
