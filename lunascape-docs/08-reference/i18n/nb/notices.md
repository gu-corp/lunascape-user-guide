# Varemerker og lisenser

## Lisens

Lunascape Docs leveres gratis av G.U.Corp under «Lunascape Docs bruksvilkår»: personlig og kommersiell bruk er tillatt; videredistribusjon, endring og omvendt utvikling er ikke tillatt. Den fullstendige teksten følger med utvidelsen som `LICENSE`. Medfølgende tredjepartsprogramvare leveres under sine egne lisenser.

## Varemerker

«Lunascape» og tilknyttet merkevare er varemerker som tilhører sin respektive eier. Andre produkt- og firmanavn er varemerker eller registrerte varemerker som tilhører sine respektive innehavere.

## Medfølgende programvare

Utvidelsen inkluderer følgende åpen kildekode-programvare. De fullstendige lisenstekstene og de genererte merknadene ligger i utvidelsens `vendor/`-mappe og i `THIRD-PARTY-NOTICES.md`.

- Marked
- DOMPurify 3.4.14
- Mermaid
- KaTeX
- Turndown og Turndown Plugin GFM
- docs-lint (Editor-kjøretid)
- @lunascape/tikz-renderer (MIT)
- Vega og Vega-Lite
- Markmap
- WaveDrom
- Svgbob
- Penrose Core (eksperimentell)

node-tikzjax og DVI-konvertereren, TeX-ressursene og skriftene som trengs for TikZ-gjengivelse, er kun for utvikling og er ikke inkludert i den distribuerte versjonen.
