# Sneltoetsen

## Viewer

| Handeling | Toetsen |
|---|---|
| Terug | `Alt`+`←` |
| Vooruit | `Alt`+`→` |
| De INDEX-overlay, een menu of een dialoogvenster sluiten | `Esc` |

## INDEX

| Handeling | Toetsen |
|---|---|
| Een item één plaats omhoog of omlaag verplaatsen (volgorde wijzigen) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Binnen een itemmenu navigeren | `↑` / `↓` |
| Naar het eerste of laatste menu-item springen | `Home` / `End` |
| Een itemmenu sluiten (de focus keert terug naar de oorspronkelijke plaats) | `Esc` |
| Een itemmenu verlaten | `Tab` |

## VS Code

| Handeling | Toetsen |
|---|---|
| Opdrachtenpalet | `⇧⌘P` / `Ctrl+Shift+P` |
| Extensies-weergave | `⇧⌘X` / `Ctrl+Shift+X` |
| Instellingen | `⌘,` / `Ctrl+,` |

## Webbrowserversie

Met [Terug] en [Vooruit] in de browser doorloopt u de browsergeschiedenis.
