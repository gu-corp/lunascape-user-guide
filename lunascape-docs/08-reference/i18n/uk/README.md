# Основні характеристики

## Системні вимоги

| Середовище | Вимоги |
|---|---|
| Розширення VS Code | VS Code 1.90 або новішої версії. Функції, що записують файли, працюють у надійній робочій області |
| Веброгляд | Свіжі версії Chrome, Edge, Safari, Firefox. Для перегляду локальної папки потрібен браузер із підтримкою вибору папки (File System Access API) |
| Розширення Chromium | Manifest V3. Дозволи для хостів не запитуються |

## Підтримувані документи

| Пункт | Зміст |
|---|---|
| Файли | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (таблиці, списки завдань, блоки коду, закреслення), локальні зображення, YAML front matter |
| MDX | Показуються лише дозволені компоненти. Довільні скрипти не виконуються |
| HTML | Показується після знешкодження за допомогою DOMPurify 3.4.14 |

## Діаграми та формули

| Вид | Назва мови | Примітки |
|---|---|---|
| Формули | `$...$`, `$$...$$`, `\(...\)`, `\[...\]` | KaTeX. `trust: false`, `maxSize: 50`, `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | Лише вбудовані дані. Зовнішні URL та позначки зображень не підтримуються |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | Лише строгий JSON |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | У розповсюджуваній збірці джерело показується згорнутим. Обмеження: 64 KiB на вході, 15 секунд, 2 MiB SVG |
| Penrose (експериментально) | `penrose` | Лише набір `set-theory` |

## Обмеження

| Пункт | Значення |
|---|---|
| Результат розгортання шаблону | 4 MiB |
| Контекст-джерело для перекладу | Типово 49 152 символи, максимум 1 048 576 символів |
| Кількість документів за один пакетний переклад | 1 000 документів |
| Довільна ширина зображення | 16–4096 px |
