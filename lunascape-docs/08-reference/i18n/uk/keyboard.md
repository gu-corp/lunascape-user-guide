# Клавіатурні скорочення

## Переглядач

| Дія | Клавіші |
|---|---|
| Назад | `Alt`+`←` |
| Вперед | `Alt`+`→` |
| Закрити накладку INDEX, меню або діалогове вікно | `Esc` |

## INDEX

| Дія | Клавіші |
|---|---|
| Перемістити елемент на один вгору або вниз (зміна порядку) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Переміщення в меню елемента | `↑` / `↓` |
| Перейти до першого або останнього пункту меню | `Home` / `End` |
| Закрити меню елемента (фокус повертається на попереднє місце) | `Esc` |
| Вийти з меню елемента | `Tab` |

## VS Code

| Дія | Клавіші |
|---|---|
| Палітра команд | `⇧⌘P` / `Ctrl+Shift+P` |
| Подання розширень | `⇧⌘X` / `Ctrl+Shift+X` |
| Параметри | `⌘,` / `Ctrl+,` |

## Версія для веббраузера

Кнопки браузера [Назад] і [Вперед] дають змогу переміщатися історією перегляду.
