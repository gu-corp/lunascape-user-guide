# Використання з AI-агентів

Розширення реєструє у VS Code Language Model Tool `lunascape_getDocsSpecification`, доступний лише для читання. Коли сумісного агента VS Code запитують про можливості, налаштування або правила оформлення документів Lunascape Docs, він може отримати через цей інструмент вміст цієї довідки (загальну специфікацію).

## Як користуватися

Поставте запитання в чаті VS Code з `#lunascapeDocs` або просто запитайте про налаштування чи структуру документів Lunascape Docs.

```text
#lunascapeDocs Як увімкнути англійський переклад у lunascape-docs.json?
```

## Аргументи інструмента

| Аргумент | Опис |
|---|---|
| `topic` | Розділ, який потрібно отримати: `all`, `usage` (основні дії), `structure` (корінь документації та правила для файлів), `editing` (редагування документа), `configuration` (налаштування проєкту), `security` (безпека та межі запису), `ai` (використання з AI-агентів) |
| `locale` | Мова довідки (тег мови вбудованої довідки, наприклад `ja` або `en`). Якщо не вказано, використовується мова інтерфейсу VS Code, а за її відсутності повертається довідка японською |

> **Примітка**
>
> - Інструмент не надсилає вміст документів назовні.
> - Інструмент не повертає назви робочих областей і локальні шляхи.
> - Інструмент не змінює файли.
> - Він працює із сумісними агентами VS Code і без `AGENTS.md`. Іншим AI-клієнтам, які не використовують API інструментів розширення, він автоматично не передається.
