# Danh sách phím tắt

## Trình xem

| Thao tác | Phím |
|---|---|
| Quay lại | `Alt`+`←` |
| Tiến tới | `Alt`+`→` |
| Đóng lớp phủ INDEX, menu hoặc hộp thoại | `Esc` |

## INDEX

| Thao tác | Phím |
|---|---|
| Di chuyển một mục lên／xuống một vị trí (sắp xếp lại) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Di chuyển trong menu của mục | `↑` / `↓` |
| Đến mục đầu／cuối của menu | `Home` / `End` |
| Đóng menu của mục (đưa tiêu điểm về vị trí ban đầu) | `Esc` |
| Thoát khỏi menu của mục | `Tab` |

## VS Code

| Thao tác | Phím |
|---|---|
| Bảng lệnh | `⇧⌘P` / `Ctrl+Shift+P` |
| Khung xem tiện ích mở rộng | `⇧⌘X` / `Ctrl+Shift+X` |
| Cài đặt | `⌘,` / `Ctrl+,` |

## Bản trình duyệt Web

Dùng [Quay lại] và [Tiến tới] của trình duyệt để đi theo lịch sử duyệt xem.
