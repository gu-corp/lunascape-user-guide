# Daftar pintasan keyboard

## Penampil

| Tindakan | Tombol |
|---|---|
| Kembali | `Alt`+`←` |
| Maju | `Alt`+`→` |
| Menutup hamparan INDEX, menu, atau dialog | `Esc` |

## INDEX

| Tindakan | Tombol |
|---|---|
| Memindahkan item satu tingkat ke atas/bawah (mengubah urutan) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Berpindah di dalam menu item | `↑` / `↓` |
| Ke awal/akhir menu item | `Home` / `End` |
| Menutup menu item (fokus kembali ke posisi semula) | `Esc` |
| Keluar dari menu item | `Tab` |

## VS Code

| Tindakan | Tombol |
|---|---|
| Palet Perintah | `⇧⌘P` / `Ctrl+Shift+P` |
| Tampilan Ekstensi | `⇧⌘X` / `Ctrl+Shift+X` |
| Pengaturan | `⌘,` / `Ctrl+,` |

## Versi peramban web

Dengan tombol [Kembali] dan [Maju] pada peramban, Anda dapat menelusuri riwayat penjelajahan.
