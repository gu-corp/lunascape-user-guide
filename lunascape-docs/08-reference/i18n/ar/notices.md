# العلامات التجارية والتراخيص

## الترخيص

تقدّم G.U.Corp تطبيق Lunascape Docs مجانًا بموجب «شروط استخدام Lunascape Docs». يجوز استخدامه للأغراض الشخصية والتجارية، أما إعادة التوزيع والتعديل والهندسة العكسية فغير مسموح بها. يوجد النص الكامل في ملف `LICENSE` المرفق مع الامتداد. وتخضع البرمجيات الخارجية المرفقة لتراخيصها الخاصة.

## العلامات التجارية

«Lunascape» والعلامات التجارية ذات الصلة هي علامات تجارية مملوكة لأصحابها. وأسماء المنتجات والشركات الأخرى علامات تجارية أو علامات تجارية مسجّلة تعود إلى أصحابها.

## البرمجيات المرفقة

يتضمّن الامتداد البرمجيات مفتوحة المصدر التالية. وتوجد النصوص الكاملة لكل ترخيص والإشعارات المُولَّدة في مجلد `vendor/` داخل الامتداد وفي ملف `THIRD-PARTY-NOTICES.md`.

- Marked
- DOMPurify 3.4.14
- Mermaid
- KaTeX
- Turndown و Turndown Plugin GFM
- docs-lint (بيئة تشغيل المحرّر)
- ‎@lunascape/tikz-renderer‎ (MIT)
- Vega و Vega-Lite
- Markmap
- WaveDrom
- Svgbob
- Penrose Core (تجريبي)

أما node-tikzjax ومحوّل DVI وموارد TeX والخطوط اللازمة لرسم TikZ فهي مخصّصة للتطوير فقط وغير مضمّنة في الإصدار الموزَّع.
