# اختصارات لوحة المفاتيح

## العارض

| الإجراء | المفاتيح |
|---|---|
| رجوع | `Alt`+`←` |
| تقدّم | `Alt`+`→` |
| إغلاق طبقة INDEX أو قائمة أو مربع حوار | `Esc` |

## INDEX

| الإجراء | المفاتيح |
|---|---|
| نقل عنصر لأعلى أو لأسفل (إعادة الترتيب) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| التنقل داخل قائمة العنصر | `↑` / `↓` |
| الانتقال إلى أول عنصر في القائمة أو آخره | `Home` / `End` |
| إغلاق قائمة العنصر (مع إعادة التركيز إلى موضعه السابق) | `Esc` |
| الخروج من قائمة العنصر | `Tab` |

## VS Code

| الإجراء | المفاتيح |
|---|---|
| لوحة الأوامر | `⇧⌘P` / `Ctrl+Shift+P` |
| عرض الامتدادات | `⇧⌘X` / `Ctrl+Shift+X` |
| الإعدادات | `⌘,` / `Ctrl+,` |

## إصدار متصفح الويب

يمكنك تتبّع سجل التصفح باستخدام زرَّي [رجوع] و[تقدّم] في المتصفح.
