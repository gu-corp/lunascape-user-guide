# الاستخدام من وكلاء الذكاء الاصطناعي

يسجّل الامتداد في VS Code أداة نموذج لغوي للقراءة فقط باسم `lunascape_getDocsSpecification`. وعندما يُسأل وكيل متوافق في VS Code عن ميزات Lunascape Docs أو إعداداتها أو أعراف المستندات، يمكنه عبر هذه الأداة جلب محتوى هذه المساعدة (المواصفات العامة).

## طريقة الاستخدام

اطرح سؤالك في محادثة VS Code مع إضافة `#lunascapeDocs`، أو اسأل مباشرة عن إعدادات Lunascape Docs أو بنية المستندات.

```text
#lunascapeDocs كيف أُفعّل الترجمة الإنجليزية في lunascape-docs.json؟
```

## وسائط الأداة

| الوسيط | المحتوى |
|---|---|
| `topic` | الفصل المراد جلبه: `all` أو `usage` (العمليات الأساسية) أو `structure` (جذر التوثيق وأعراف الملفات) أو `editing` (تحرير مستند) أو `configuration` (إعدادات المشروع) أو `security` (الأمان وحدود الحفظ) أو `ai` (الاستخدام من وكلاء الذكاء الاصطناعي) |
| `locale` | لغة المساعدة (وسم لغة من لغات المساعدة المضمّنة، مثل `ja` أو `en`). عند الحذف تُستخدم لغة واجهة VS Code، وإن تعذّر ذلك تُعاد المساعدة باليابانية |

> **ملاحظة**
>
> - لا ترسل الأداة محتوى المستندات إلى أي جهة خارجية.
> - لا تُعيد الأداة أسماء مساحات العمل ولا المسارات المحلية.
> - لا تُعدّل الأداة الملفات.
> - يمكن استخدامها من الوكلاء المتوافقين في VS Code حتى بغياب ملف `AGENTS.md`. ولا تُشارَك تلقائيًا مع عملاء ذكاء اصطناعي آخرين لا يستخدمون واجهة أدوات الامتداد.
