# المواصفات الرئيسية

## بيئة التشغيل

| البيئة | المتطلبات |
|---|---|
| امتداد VS Code | VS Code 1.90 أو أحدث. الميزات التي تكتب الملفات تعمل في مساحة عمل موثوقة |
| نسخة متصفح الويب | إصدار حديث من Chrome أو Edge أو Safari أو Firefox. يتطلب فتح مجلد محلي متصفحًا يدعم اختيار المجلدات (File System Access API) |
| امتداد Chromium | Manifest V3. لا تُطلب أي أذونات للمضيفين |

## المستندات المدعومة

| العنصر | التفاصيل |
|---|---|
| الملفات | `.md`، `.markdown`، `.mdx` |
| Markdown | GitHub Flavored Markdown (الجداول، قوائم المهام، كتل التعليمات البرمجية، الشطب)، الصور المحلية، YAML front matter |
| MDX | تُعرض المكوّنات المسموح بها فقط. لا تُنفَّذ أي نصوص برمجية عشوائية |
| HTML | يُعرض بعد تنقيته باستخدام DOMPurify 3.4.14 |

## الرسوم التخطيطية والمعادلات

| النوع | اسم اللغة | ملاحظات |
|---|---|---|
| المعادلات | `$...$`، `$$...$$`، `\(...\)`، `\[...\]` | KaTeX. ‏`trust: false`، `maxSize: 50`، `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | البيانات المضمّنة فقط. لا تُدعم عناوين URL الخارجية ولا علامات الصور |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | JSON صارم فقط |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | تُعرض المصادر مطوية في النسخة الموزّعة. الحدود: 64 كيبي بايت للإدخال، 15 ثانية، 2 ميبي بايت لملف SVG |
| Penrose (تجريبي) | `penrose` | الإعداد المسبق `set-theory` فقط |

## الحدود القصوى

| العنصر | القيمة |
|---|---|
| حجم نتيجة عرض القالب | 2 ميبي بايت ‏×‏ 2 = 4 ميبي بايت |
| سياق المرجع في الترجمة | 49,152 حرفًا افتراضيًا، و1,048,576 حرفًا كحد أقصى |
| عدد المستندات في تشغيل الترجمة الدفعية الواحد | 1,000 مستند |
| العرض المخصص للصور | 16–4096 بكسل |
