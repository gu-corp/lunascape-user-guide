# 보안과 저장 경계

Lunascape Docs가 문서와 단말을 보호하기 위해 두고 있는 경계입니다.

## 표시

- Markdown에서 생성한 HTML과 다이어그램에서 생성한 SVG는 DOMPurify 3.4.14로 무해화한 뒤에 표시합니다.
- MDX에 포함된 임의의 스크립트는 실행하지 않습니다.
- KaTeX는 `trust: false`, `maxSize: 50`, `maxExpand: 1000`으로 실행하며, 외부 HTML이나 임의의 명령을 신뢰하지 않습니다.
- Markmap, WaveDrom, Svgbob, Vega-Lite, Penrose의 렌더링 라이브러리는 해당하는 블록이 있을 때만 고정된 버전을 단말 안에서 불러옵니다. 외부 리소스 참조, 원시 HTML, 실행 가능한 표기는 허용하지 않으며, 생성된 SVG에서 스크립트, 외부 이미지, `link`, `style`, `foreignObject`를 제거합니다.
- TikZ 렌더링은 호스트의 LaTeX를 실행하지 않고, 메모리 내 파일 시스템을 갖춘 WebAssembly TeX 워커에서 순차적으로 실행합니다. 입력, 대기열, 메모리, 실행 시간(15초), SVG 출력에 상한이 있으며, 파일 I/O 명령은 거부합니다.

## 문서와 파일에 대한 접근

- 문서의 링크와 파일 조작은 문서 루트 밖으로 나갈 수 없습니다.
- INDEX에서의 생성, 이름 변경, 이동, 삭제는 문서 루트, INDEX의 버전, 정본 문서의 경로, 대상의 종류, 심볼릭 링크의 경계, 저장하지 않은 문서를 확장 기능 쪽에서 다시 확인한 뒤에 적용합니다. 오래된 메뉴나 다른 문서 루트에서 온 조작 요청은 적용하지 않습니다.
- 문서를 편집하는 중이거나 다른 INDEX 조작을 적용하는 중에는 INDEX의 변경 조작을 비활성화합니다.
- 템플릿에서의 생성은 작업 영역의 신뢰, 문서 루트의 실체, INDEX의 버전, Standard Pack과 생성 내용, 저장 위치, 심볼릭 링크의 경계를 미리 보기 후에 다시 확인합니다. 기존 파일을 덮어쓰지 않으며, 미리 보기와 다른 내용이나 4 MiB를 넘는 전개 결과를 만들지 않습니다.
- 설정 파일의 저장은 저장 직전에 버전을 확인하고, 외부의 변경을 감지한 경우에는 중지합니다.

## 외부로의 전송

- 열람, 편집, 검사를 위해 문서를 외부로 보내는 일은 없습니다. 문서 검사는 단말 안에서 결정적으로 실행합니다.
- 번역(이 페이지의 번역, 일괄 번역)만이 전송 대상과 전송 범위를 미리 표시하고, 명시적으로 승인된 경우에 문서를 언어 모델로 전송합니다. <!-- ai-only -->
- 번역안은 차이를 제시하고, 정본 문서와 번역 대상의 버전을 다시 확인한 뒤, 사람이 명시적으로 저장한 경우에만 적용합니다. <!-- ai-only -->
- AI 에이전트용 사양 도구는 문서의 본문, 작업 영역 이름, 로컬 경로를 반환하지 않습니다. <!-- ai-only -->

## Git

- 저장은 파일에 쓰기만 합니다. Git의 스테이징이나 커밋은 어떤 기능에서도 자동으로 하지 않습니다.
- `_meta.json` 등의 기존 파일을 말없이 삭제하거나 변경하는 일은 없습니다. 고립된 번역본도 자동으로 삭제하거나 이동하지 않습니다.
