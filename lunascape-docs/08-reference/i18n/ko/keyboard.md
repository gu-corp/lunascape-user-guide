# 키보드 단축키

## 뷰어

| 동작 | 키 |
|---|---|
| 뒤로 | `Alt`+`←` |
| 앞으로 | `Alt`+`→` |
| INDEX 오버레이, 메뉴, 대화 상자 닫기 | `Esc` |

## INDEX

| 동작 | 키 |
|---|---|
| 항목을 한 칸 위／아래로 옮기기(정렬 순서 변경) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| 항목 메뉴 안에서 이동하기 | `↑` / `↓` |
| 항목 메뉴의 처음／끝으로 이동하기 | `Home` / `End` |
| 항목 메뉴 닫기(원래 위치로 초점 되돌리기) | `Esc` |
| 항목 메뉴에서 빠져나가기 | `Tab` |

## VS Code

| 동작 | 키 |
|---|---|
| 명령 팔레트 | `⇧⌘P` / `Ctrl+Shift+P` |
| 확장 보기 | `⇧⌘X` / `Ctrl+Shift+X` |
| 설정 | `⌘,` / `Ctrl+,` |

## 웹 브라우저 버전

브라우저의 [뒤로] [앞으로]로 열람 기록을 따라 이동할 수 있습니다.
