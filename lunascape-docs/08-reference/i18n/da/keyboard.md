# Tastaturgenveje

## Fremviser

| Handling | Taster |
|---|---|
| Tilbage | `Alt`+`←` |
| Frem | `Alt`+`→` |
| Luk INDEX-overlejringen, en menu eller en dialog | `Esc` |

## INDEX

| Handling | Taster |
|---|---|
| Flyt et element op eller ned (ændr rækkefølge) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Flyt rundt i en elementmenu | `↑` / `↓` |
| Spring til det første eller sidste menupunkt | `Home` / `End` |
| Luk en elementmenu (fokus vender tilbage til det sted, den blev åbnet) | `Esc` |
| Forlad en elementmenu | `Tab` |

## VS Code

| Handling | Taster |
|---|---|
| Kommandopalet | `⇧⌘P` / `Ctrl+Shift+P` |
| Udvidelsesvisning | `⇧⌘X` / `Ctrl+Shift+X` |
| Indstillinger | `⌘,` / `Ctrl+,` |
