# Χρήση από AI

Η επέκταση καταχωρεί στο VS Code το Language Model Tool `lunascape_getDocsSpecification`, το οποίο είναι μόνο για ανάγνωση. Όταν ένας συμβατός πράκτορας του VS Code δέχεται ερώτηση για τις λειτουργίες, τις ρυθμίσεις ή τις συμβάσεις εγγράφων του Lunascape Docs, μπορεί να ανακτήσει με αυτό το εργαλείο το περιεχόμενο αυτής της βοήθειας (τις γενικές προδιαγραφές).

## Τρόπος χρήσης

Στη συνομιλία του VS Code, κάντε την ερώτησή σας προσθέτοντας `#lunascapeDocs` ή ρωτήστε απευθείας για τις ρυθμίσεις ή τη δομή εγγράφων του Lunascape Docs.

```text
#lunascapeDocs Πώς ενεργοποιώ την αγγλική μετάφραση στο lunascape-docs.json;
```

## Ορίσματα του εργαλείου

| Όρισμα | Περιεχόμενο |
|---|---|
| `topic` | Το κεφάλαιο που ανακτάται: `all`, `usage` (Βασικοί χειρισμοί), `structure` (Ρίζα τεκμηρίωσης και συμβάσεις αρχείων), `editing` (Επεξεργασία εγγράφου), `configuration` (Ρυθμίσεις έργου), `security` (Ασφάλεια και όρια εγγραφής), `ai` (Χρήση από AI) |
| `locale` | Η γλώσσα της βοήθειας (ετικέτα γλώσσας της ενσωματωμένης βοήθειας, όπως `ja` ή `en`). Αν παραλειφθεί, χρησιμοποιείται η γλώσσα εμφάνισης του VS Code και, αν δεν υπάρχει, επιστρέφεται η βοήθεια στα Ιαπωνικά |

> **Σημείωση**
>
> - Το εργαλείο δεν στέλνει το περιεχόμενο των εγγράφων προς τα έξω.
> - Το εργαλείο δεν επιστρέφει ονόματα χώρων εργασίας ούτε τοπικές διαδρομές.
> - Το εργαλείο δεν τροποποιεί αρχεία.
> - Λειτουργεί από συμβατούς πράκτορες του VS Code ακόμη και χωρίς `AGENTS.md`. Δεν κοινοποιείται αυτόματα σε άλλα προγράμματα-πελάτες AI που δεν χρησιμοποιούν το API εργαλείων της επέκτασης.
