# Συντομεύσεις πληκτρολογίου

## Πρόγραμμα προβολής

| Ενέργεια | Πλήκτρα |
|---|---|
| Πίσω | `Alt`+`←` |
| Εμπρός | `Alt`+`→` |
| Κλείσιμο της επικάλυψης του INDEX, ενός μενού ή ενός παραθύρου διαλόγου | `Esc` |

## INDEX

| Ενέργεια | Πλήκτρα |
|---|---|
| Μετακίνηση ενός στοιχείου μία θέση επάνω ή κάτω (αλλαγή σειράς) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Μετακίνηση μέσα στο μενού ενός στοιχείου | `↑` / `↓` |
| Μετάβαση στο πρώτο ή στο τελευταίο στοιχείο του μενού | `Home` / `End` |
| Κλείσιμο του μενού ενός στοιχείου (η εστίαση επιστρέφει στην αρχική θέση) | `Esc` |
| Έξοδος από το μενού ενός στοιχείου | `Tab` |

## VS Code

| Ενέργεια | Πλήκτρα |
|---|---|
| Παλέτα εντολών | `⇧⌘P` / `Ctrl+Shift+P` |
| Προβολή επεκτάσεων | `⇧⌘X` / `Ctrl+Shift+X` |
| Ρυθμίσεις | `⌘,` / `Ctrl+,` |

## Έκδοση για πρόγραμμα περιήγησης

Με τα [Πίσω] και [Εμπρός] του προγράμματος περιήγησης μπορείτε να μετακινηθείτε στο ιστορικό προβολής.
