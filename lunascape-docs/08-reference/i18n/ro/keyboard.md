# Comenzi rapide de la tastatură

## Vizualizator

| Acțiune | Taste |
|---|---|
| Înapoi | `Alt`+`←` |
| Înainte | `Alt`+`→` |
| Închiderea suprapunerii INDEX, a unui meniu sau a unei ferestre de dialog | `Esc` |

## INDEX

| Acțiune | Taste |
|---|---|
| Mutarea unui element mai sus sau mai jos (reordonare) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Deplasarea în meniul unui element | `↑` / `↓` |
| Deplasarea la primul sau la ultimul element din meniu | `Home` / `End` |
| Închiderea meniului unui element (focalizarea revine la poziția inițială) | `Esc` |
| Ieșirea din meniul unui element | `Tab` |

## VS Code

| Acțiune | Taste |
|---|---|
| Paleta de comenzi | `⇧⌘P` / `Ctrl+Shift+P` |
| Vizualizarea extensiilor | `⇧⌘X` / `Ctrl+Shift+X` |
| Setări | `⌘,` / `Ctrl+,` |

## Versiunea pentru browser web

Cu butoanele [Înapoi] și [Înainte] ale browserului parcurgeți istoricul de navigare.
