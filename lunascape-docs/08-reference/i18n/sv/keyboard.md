# Kortkommandon

## Visningsprogram

| Åtgärd | Tangenter |
|---|---|
| Tillbaka | `Alt`+`←` |
| Framåt | `Alt`+`→` |
| Stäng INDEX-överlägget, en meny eller en dialogruta | `Esc` |

## INDEX

| Åtgärd | Tangenter |
|---|---|
| Flytta ett objekt ett steg upp eller ned (ändra ordning) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Flytta inom en objektmeny | `↑` / `↓` |
| Gå till menyns första eller sista objekt | `Home` / `End` |
| Stäng en objektmeny (fokus återgår till utgångspunkten) | `Esc` |
| Lämna en objektmeny | `Tab` |

## VS Code

| Åtgärd | Tangenter |
|---|---|
| Kommandopaletten | `⇧⌘P` / `Ctrl+Shift+P` |
| Vyn Tillägg | `⇧⌘X` / `Ctrl+Shift+X` |
| Inställningar | `⌘,` / `Ctrl+,` |
