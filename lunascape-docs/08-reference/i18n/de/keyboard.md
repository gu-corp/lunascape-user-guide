# Tastenkürzel

## Viewer

| Aktion | Tasten |
|---|---|
| Zurück | `Alt`+`←` |
| Vor | `Alt`+`→` |
| INDEX-Overlay, Menü oder Dialog schließen | `Esc` |

## INDEX

| Aktion | Tasten |
|---|---|
| Eintrag eine Position nach oben/unten verschieben (umsortieren) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Innerhalb eines Eintragsmenüs bewegen | `↑` / `↓` |
| Zum ersten/letzten Menüeintrag springen | `Home` / `End` |
| Eintragsmenü schließen (Fokus kehrt an die Ausgangsstelle zurück) | `Esc` |
| Eintragsmenü verlassen | `Tab` |

## VS Code

| Aktion | Tasten |
|---|---|
| Befehlspalette | `⇧⌘P` / `Ctrl+Shift+P` |
| Erweiterungsansicht | `⇧⌘X` / `Ctrl+Shift+X` |
| Einstellungen | `⌘,` / `Ctrl+,` |
