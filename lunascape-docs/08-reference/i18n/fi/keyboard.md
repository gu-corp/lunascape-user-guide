# Näppäinkomennot

## Katselin

| Toiminto | Näppäimet |
|---|---|
| Takaisin | `Alt`+`←` |
| Eteenpäin | `Alt`+`→` |
| Sulje INDEX-peitto, valikko tai valintaikkuna | `Esc` |

## INDEX

| Toiminto | Näppäimet |
|---|---|
| Siirrä kohdetta yksi askel ylös tai alas (järjestäminen) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Siirry kohteen valikossa | `↑` / `↓` |
| Siirry valikon ensimmäiseen tai viimeiseen kohtaan | `Home` / `End` |
| Sulje kohteen valikko (kohdistus palaa alkuperäiseen paikkaan) | `Esc` |
| Poistu kohteen valikosta | `Tab` |

## VS Code

| Toiminto | Näppäimet |
|---|---|
| Komentopaletti | `⇧⌘P` / `Ctrl+Shift+P` |
| Laajennusnäkymä | `⇧⌘X` / `Ctrl+Shift+X` |
| Asetukset | `⌘,` / `Ctrl+,` |

## Selainversio

Selaimen painikkeilla [Takaisin] ja [Eteenpäin] voit selata selaushistoriaa.
