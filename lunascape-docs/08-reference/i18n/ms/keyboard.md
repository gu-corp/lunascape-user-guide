# Senarai pintasan papan kekunci

## Pemapar

| Tindakan | Kekunci |
|---|---|
| Kembali | `Alt`+`←` |
| Ke hadapan | `Alt`+`→` |
| Tutup lapisan tindanan INDEX, menu atau dialog | `Esc` |

## INDEX

| Tindakan | Kekunci |
|---|---|
| Alihkan item satu kedudukan ke atas/bawah (susun semula) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Bergerak dalam menu item | `↑` / `↓` |
| Ke awal/akhir menu item | `Home` / `End` |
| Tutup menu item (fokus kembali ke kedudukan asal) | `Esc` |
| Keluar dari menu item | `Tab` |

## VS Code

| Tindakan | Kekunci |
|---|---|
| Palet arahan | `⇧⌘P` / `Ctrl+Shift+P` |
| Paparan sambungan | `⇧⌘X` / `Ctrl+Shift+X` |
| Tetapan | `⌘,` / `Ctrl+,` |
