# Klavye kısayolları

## Görüntüleyici

| İşlem | Tuşlar |
|---|---|
| Geri | `Alt`+`←` |
| İleri | `Alt`+`→` |
| INDEX yer paylaşımını, menüyü veya iletişim kutusunu kapatma | `Esc` |

## INDEX

| İşlem | Tuşlar |
|---|---|
| Bir öğeyi bir sıra yukarı/aşağı taşıma (yeniden sıralama) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Öğe menüsü içinde gezinme | `↑` / `↓` |
| Öğe menüsünün başına/sonuna gitme | `Home` / `End` |
| Öğe menüsünü kapatma (odağı açıldığı yere geri döndürür) | `Esc` |
| Öğe menüsünden çıkma | `Tab` |

## VS Code

| İşlem | Tuşlar |
|---|---|
| Komut Paleti | `⇧⌘P` / `Ctrl+Shift+P` |
| Uzantılar görünümü | `⇧⌘X` / `Ctrl+Shift+X` |
| Ayarlar | `⌘,` / `Ctrl+,` |

## Web tarayıcısı sürümü

Tarayıcının [Geri] ve [İleri] düğmeleriyle tarama geçmişinde gezinebilirsiniz.
