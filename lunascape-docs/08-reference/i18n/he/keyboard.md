# קיצורי מקלדת

## מציג

| פעולה | מקשים |
|---|---|
| חזרה | `Alt`+`←` |
| קדימה | `Alt`+`→` |
| סגירת שכבת ה־INDEX, תפריט או תיבת דו־שיח | `Esc` |

## INDEX

| פעולה | מקשים |
|---|---|
| הזזת פריט שורה אחת למעלה או למטה (שינוי הסדר) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| מעבר בתוך תפריט הפריט | `↑` / `↓` |
| מעבר לתחילת התפריט או לסופו | `Home` / `End` |
| סגירת תפריט הפריט (החזרת המיקוד למקומו הקודם) | `Esc` |
| יציאה מתפריט הפריט | `Tab` |

## VS Code

| פעולה | מקשים |
|---|---|
| לוח הפקודות | `⇧⌘P` / `Ctrl+Shift+P` |
| תצוגת ההרחבות | `⇧⌘X` / `Ctrl+Shift+X` |
| הגדרות | `⌘,` / `Ctrl+,` |
