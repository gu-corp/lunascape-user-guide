# סימנים מסחריים ורישיונות

## רישיון

‏Lunascape Docs ניתן ללא תשלום על ידי G.U.Corp במסגרת "תנאי השימוש של Lunascape Docs". מותר להשתמש בו לשימוש אישי ומסחרי, אך אין להפיץ אותו מחדש, לשנות אותו או לבצע בו הנדסה לאחור. הנוסח המלא מצורף להרחבה בקובץ `LICENSE`. על תוכנת צד שלישי המצורפת חלים הרישיונות שלה.

## סימנים מסחריים

‏"Lunascape" והמותגים הקשורים אליו הם סימנים מסחריים של בעלי הזכויות בהם. שמות מוצרים ושמות חברות אחרים הם סימנים מסחריים או סימנים מסחריים רשומים של בעליהם.

## תוכנה מצורפת

ההרחבה כוללת את תוכנות הקוד הפתוח הבאות. הנוסח המלא של כל רישיון וההודעות שנוצרו נמצאים בתיקיית `vendor/` של ההרחבה ובקובץ `THIRD-PARTY-NOTICES.md`.

- Marked
- DOMPurify 3.4.14
- Mermaid
- KaTeX
- ‏Turndown ו-Turndown Plugin GFM
- ‏docs-lint (סביבת ההרצה של Editor)
- ‏@lunascape/tikz-renderer (MIT)
- ‏Vega ו-Vega-Lite
- Markmap
- WaveDrom
- Svgbob
- ‏Penrose Core (ניסיוני)

‏node-tikzjax וממיר ה-DVI, משאבי TeX והגופנים הדרושים לציור TikZ מיועדים לפיתוח בלבד ואינם נכללים בגרסה המופצת.
