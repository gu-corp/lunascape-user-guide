# אבטחה וגבולות השמירה

הגבולות ש‑Lunascape Docs מציב כדי להגן על המסמכים ועל המכשיר.

## תצוגה

- ה‑HTML שנוצר מ‑Markdown וה‑SVG שנוצר מתרשימים עוברים ניקוי באמצעות DOMPurify 3.4.14 לפני ההצגה.
- סקריptים שרירותיים שב‑MDX אינם מורצים.
- KaTeX פועל עם `trust: false`, `maxSize: 50` ו‑`maxExpand: 1000`, ואינו נותן אמון ב‑HTML חיצוני או בפקודות שרירותיות.
- ספריות הציור Markmap, WaveDrom, Svgbob, Vega-Lite ו‑Penrose נטענות במכשיר עצמו, בגרסאות מקובעות, רק כאשר קיימת בלוק מתאים. הפניות למשאבים חיצוניים, HTML גולמי וסימונים הניתנים להרצה אינם מותרים, ומתוך ה‑SVG שנוצר מוסרים סקריפטים, תמונות חיצוניות, `link`, `style` ו‑`foreignObject`.
- ציור TikZ אינו מפעיל את ה‑LaTeX של המארח. הוא רץ בזה אחר זה בעובד TeX מבוסס WebAssembly עם מערכת קבצים בזיכרון, עם מגבלות על הקלט, על תור ההמתנה, על הזיכרון, על זמן הריצה (15 שניות) ועל פלט ה‑SVG, ופקודות קלט/פלט לקבצים נדחות.

## גישה למסמכים ולקבצים

- קישורי המסמכים ופעולות הקבצים אינם יכולים לצאת אל מחוץ לשורש התיעוד.
- יצירה, שינוי שם, העברה ומחיקה מתוך INDEX נבדקות מחדש בצד ההרחבה — שורש התיעוד, גרסת ה‑INDEX, נתיב מסמך המקור, סוג היעד, גבולות הקישורים הסימבוליים ומסמכים שלא נשמרו — לפני שהן מוחלות. בקשות מתפריט ישן או משורש תיעוד אחר אינן מוחלות.
- פעולות השינוי ב‑INDEX מושבתות בזמן עריכת מסמך או בזמן החלה של פעולת INDEX אחרת.
- יצירה מתוך תבנית בודקת מחדש לאחר התצוגה המקדימה את מהימנות סביבת העבודה, את זהות שורש התיעוד, את גרסת ה‑INDEX, את Standard Pack ואת התוכן שנוצר, את יעד השמירה ואת גבולות הקישורים הסימבוליים. היא אינה דורסת קובץ קיים ואינה יוצרת תוכן השונה מהתצוגה המקדימה או תוצאת פריסה החורגת מ‑4 MiB.
- שמירת קובץ הגדרות בודקת את גרסתו רגע לפני השמירה, ונעצרת כאשר מזוהה שינוי חיצוני.

## שליחה החוצה

- מסמכים אינם נשלחים החוצה לצורך צפייה, עריכה או בדיקה. בדיקת המסמכים מתבצעת במכשיר עצמו ובאופן דטרמיניסטי.
- רק תרגום (תרגום הדף הזה, תרגום מרוכז) שולח מסמכים אל מודל שפה, לאחר הצגה מראש של היעד ושל היקף השליחה ורק באישור מפורש. <!-- ai-only -->
- הצעות התרגום מוצגות כהפרש, גרסאות מסמך המקור ושפת היעד נבדקות מחדש, וההצעה מוחלת רק כאשר אדם שומר אותה במפורש. <!-- ai-only -->
- כלי המפרט המיועד לסוכני AI אינו מחזיר את תוכן המסמכים, שמות סביבות עבודה או נתיבים מקומיים. <!-- ai-only -->

## Git

- השמירה רק כותבת אל הקובץ. אף יכולת אינה מבצעת staging או commit ב‑Git באופן אוטומטי.
- קבצים קיימים כגון `_meta.json` אינם נמחקים או משתנים בשקט. גם גרסאות תרגום יתומות אינן נמחקות או מועברות אוטומטית.
