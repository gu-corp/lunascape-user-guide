# מפרט עיקרי

## דרישות מערכת

| סביבה | דרישות |
|---|---|
| הרחבת VS Code | VS Code 1.90 ומעלה. תכונות הכותבות קבצים פועלות בסביבת עבודה מהימנה |
| גרסת דפדפן | Chrome,‏ Edge,‏ Safari או Firefox בגרסאות עדכניות. עיון בתיקייה מקומית מחייב דפדפן התומך בבחירת תיקייה (File System Access API) |
| הרחבת Chromium | Manifest V3. אין בקשה להרשאות מארח |

## מסמכים נתמכים

| פריט | תוכן |
|---|---|
| קבצים | `.md`,‏ `.markdown`,‏ `.mdx` |
| Markdown | GitHub Flavored Markdown (טבלאות, רשימות משימות, בלוקי קוד, קו חוצה), תמונות מקומיות, YAML front matter |
| MDX | רק רכיבים מורשים מוצגים. סקריפטים שרירותיים אינם מורצים |
| HTML | מוצג לאחר חיטוי באמצעות DOMPurify 3.4.14 |
