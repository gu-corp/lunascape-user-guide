# שימוש מצד סוכני AI

התוסף רושם ב‑VS Code כלי Language Model Tool לקריאה בלבד בשם `lunascape_getDocsSpecification`. כאשר סוכן VS Code תואם נשאל על היכולות, ההגדרות או מוסכמות המסמכים של Lunascape Docs, הוא יכול לקבל באמצעות הכלי הזה את תוכן העזרה הזו (המפרט הכללי).

## אופן השימוש

שאלו בצ'אט של VS Code בתוספת `#lunascapeDocs`, או שאלו על ההגדרות של Lunascape Docs או על מבנה המסמכים.

```text
#lunascapeDocs איך מפעילים תרגום לאנגלית ב-lunascape-docs.json?
```

## ארגומנטים של הכלי

| ארגומנט | תוכן |
|---|---|
| `topic` | הפרק שיש לקבל: `all`, ‏`usage` (פעולות בסיסיות), ‏`structure` (שורש התיעוד ומוסכמות הקבצים), ‏`editing` (עריכת מסמך), ‏`configuration` (הגדרות הפרויקט), ‏`security` (אבטחה וגבולות שמירה), ‏`ai` (שימוש מצד סוכני AI) |
| `locale` | שפת העזרה (תג שפה של העזרה המצורפת, כגון `ja` או `en`). אם הושמט, נעשה שימוש בשפת התצוגה של VS Code, ובהיעדרה מוחזרת העזרה ביפנית |

> **הערה**
>
> - הכלי אינו שולח את תוכן המסמכים לגורם חיצוני.
> - הכלי אינו מחזיר שמות של סביבות עבודה או נתיבים מקומיים.
> - הכלי אינו משנה קבצים.
> - אפשר להשתמש בו מסוכני VS Code תואמים גם ללא `AGENTS.md`. הוא אינו משותף אוטומטית עם לקוחות AI אחרים שאינם משתמשים ב‑API הכלים של התוסף.
