# Atajos de teclado

## Visor

| Acción | Teclas |
|---|---|
| Atrás | `Alt`+`←` |
| Adelante | `Alt`+`→` |
| Cerrar la superposición de INDEX, un menú o un cuadro de diálogo | `Esc` |

## INDEX

| Acción | Teclas |
|---|---|
| Mover un elemento una posición hacia arriba o hacia abajo (reordenar) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Desplazarse dentro del menú de un elemento | `↑` / `↓` |
| Ir al primer o al último elemento del menú | `Home` / `End` |
| Cerrar el menú de un elemento (devuelve el foco a su posición original) | `Esc` |
| Salir del menú de un elemento | `Tab` |

## VS Code

| Acción | Teclas |
|---|---|
| Paleta de comandos | `⇧⌘P` / `Ctrl+Shift+P` |
| Vista de extensiones | `⇧⌘X` / `Ctrl+Shift+X` |
| Configuración | `⌘,` / `Ctrl+,` |

## Versión para navegador web

Con los botones [Atrás] y [Adelante] del navegador puede recorrer el historial de navegación.
