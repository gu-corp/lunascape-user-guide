# مشخصات اصلی

## محیط اجرا

| محیط | الزامات |
|---|---|
| افزونهٔ VS Code | VS Code نسخهٔ ۱٫۹۰ یا بالاتر. قابلیت‌هایی که فایل می‌نویسند در فضای کاری مورد اعتماد کار می‌کنند |
| نسخهٔ مرورگر وب | نسخه‌های اخیر Chrome، Edge، Safari و Firefox. مشاهدهٔ پوشهٔ محلی به مرورگری نیاز دارد که از انتخاب پوشه (File System Access API) پشتیبانی کند |
| افزونهٔ Chromium | Manifest V3. هیچ مجوز میزبانی درخواست نمی‌شود |

## سندهای پشتیبانی‌شده

| مورد | محتوا |
|---|---|
| فایل | `.md`، `.markdown`، `.mdx` |
| Markdown | GitHub Flavored Markdown (جدول، فهرست کارها، بلوک کد، خط خورده)، تصویر محلی، YAML front matter |
| MDX | فقط مؤلفه‌های مجاز نمایش داده می‌شوند. هیچ اسکریپت دلخواهی اجرا نمی‌شود |
| HTML | پیش از نمایش با DOMPurify 3.4.14 پاک‌سازی می‌شود |

## نمودار و فرمول ریاضی

| نوع | نام زبان | توضیحات |
|---|---|---|
| فرمول ریاضی | `$...$`، `$$...$$`، `\(...\)`، `\[...\]` | KaTeX با `trust: false`، `maxSize: 50`، `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | فقط دادهٔ درون‌خطی. نشانی اینترنتی بیرونی و نشانگر تصویر مجاز نیست |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | فقط JSON دقیق |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | در نسخهٔ توزیع‌شده، متن مبدأ به‌صورت جمع‌شده نمایش داده می‌شود. حد ورودی ۶۴ KiB، ۱۵ ثانیه، SVG تا ۲ MiB |
| Penrose (آزمایشی) | `penrose` | فقط پیش‌تنظیم `set-theory` |
