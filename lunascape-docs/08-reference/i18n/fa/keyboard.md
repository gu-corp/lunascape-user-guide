# فهرست میان‌برهای صفحه‌کلید

## نمایشگر

| عملیات | کلید |
|---|---|
| بازگشت | `Alt`+`←` |
| جلو | `Alt`+`→` |
| بستن پوشش INDEX، منو یا کادر گفتگو | `Esc` |

## INDEX

| عملیات | کلید |
|---|---|
| جابه‌جایی یک مورد به بالا یا پایین (تغییر ترتیب) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| جابه‌جایی درون منوی مورد | `↑` / `↓` |
| رفتن به ابتدا یا انتهای منوی مورد | `Home` / `End` |
| بستن منوی مورد (بازگرداندن تمرکز به جای قبلی) | `Esc` |
| خروج از منوی مورد | `Tab` |

## VS Code

| عملیات | کلید |
|---|---|
| پنل فرمان | `⇧⌘P` / `Ctrl+Shift+P` |
| نمای افزونه‌ها | `⇧⌘X` / `Ctrl+Shift+X` |
| تنظیمات | `⌘,` / `Ctrl+,` |

## نسخهٔ مرورگر وب

با دکمه‌های [بازگشت] و [جلو] مرورگر می‌توانید در تاریخچهٔ مرور جابه‌جا شوید.
