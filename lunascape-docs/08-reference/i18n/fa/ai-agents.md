# استفاده از طریق AI

این افزونه ابزار مدل زبانی فقط‌خواندنی `lunascape_getDocsSpecification` را در VS Code ثبت می‌کند. وقتی از یک عامل سازگار VS Code دربارهٔ قابلیت‌ها، تنظیمات یا قواعد سند Lunascape Docs پرسیده شود، می‌تواند محتوای این راهنما (مشخصات فنی عمومی) را با این ابزار دریافت کند.

## نحوهٔ استفاده

در گفت‌وگوی VS Code پرسش خود را با `#lunascapeDocs` بپرسید، یا دربارهٔ تنظیمات یا ساختار سند Lunascape Docs بپرسید.

```text
#lunascapeDocs چگونه در lunascape-docs.json ترجمهٔ انگلیسی را فعال کنم؟
```

## آرگومان‌های ابزار

| آرگومان | محتوا |
|---|---|
| `topic` | بخشی که دریافت می‌شود: `all`، `usage` (عملیات پایه)، `structure` (ریشهٔ مستندات و قواعد فایل)، `editing` (ویرایش سند)، `configuration` (تنظیمات پروژه)، `security` (امنیت و مرزهای ذخیره‌سازی)، `ai` (استفاده از طریق AI) |
| `locale` | زبان راهنما است (برچسب زبان راهنمای همراه، مانند `ja` یا `en`). اگر حذف شود، زبان نمایش VS Code و در نبود آن راهنمای ژاپنی بازگردانده می‌شود |

> **توجه**
>
> - این ابزار متن سند را به بیرون ارسال نمی‌کند.
> - این ابزار نام فضای کاری یا مسیرهای محلی را بازنمی‌گرداند.
> - این ابزار فایل‌ها را تغییر نمی‌دهد.
> - بدون وجود `AGENTS.md` نیز از عامل‌های سازگار VS Code قابل استفاده است. با دیگر کلاینت‌های AI که از API ابزار این افزونه استفاده نمی‌کنند، به‌صورت خودکار به اشتراک گذاشته نمی‌شود.
