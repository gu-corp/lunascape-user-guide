# รายการการใช้งานแป้นพิมพ์

## โปรแกรมดูเอกสาร

| การทำงาน | แป้น |
|---|---|
| ย้อนกลับ | `Alt`+`←` |
| ไปข้างหน้า | `Alt`+`→` |
| ปิดโอเวอร์เลย์ของ INDEX เมนู หรือกล่องโต้ตอบ | `Esc` |

## INDEX

| การทำงาน | แป้น |
|---|---|
| ย้ายรายการขึ้นหรือลงหนึ่งตำแหน่ง (จัดลำดับใหม่) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| ย้ายตำแหน่งภายในเมนูของรายการ | `↑` / `↓` |
| ไปยังรายการแรกหรือรายการสุดท้ายของเมนู | `Home` / `End` |
| ปิดเมนูของรายการ (คืนโฟกัสไปยังตำแหน่งเดิม) | `Esc` |
| ออกจากเมนูของรายการ | `Tab` |

## VS Code

| การทำงาน | แป้น |
|---|---|
| แผงคำสั่ง | `⇧⌘P` / `Ctrl+Shift+P` |
| มุมมองส่วนขยาย | `⇧⌘X` / `Ctrl+Shift+X` |
| การตั้งค่า | `⌘,` / `Ctrl+,` |

## เวอร์ชันเว็บเบราว์เซอร์

ใช้ [ย้อนกลับ] และ [ไปข้างหน้า] ของเบราว์เซอร์เพื่อย้อนดูประวัติการเข้าชมได้
