# ข้อกำหนดหลัก

## สภาพแวดล้อมการทำงาน

| สภาพแวดล้อม | ข้อกำหนด |
|---|---|
| ส่วนขยาย VS Code | VS Code 1.90 ขึ้นไป ฟังก์ชันที่มีการเขียนไฟล์ทำงานในพื้นที่ทำงานที่เชื่อถือได้ |
| เว็บเบราว์เซอร์ | Chrome, Edge, Safari, Firefox รุ่นใหม่ การเปิดดูโฟลเดอร์ในเครื่องต้องใช้เบราว์เซอร์ที่รองรับการเลือกโฟลเดอร์ (File System Access API) |
| ส่วนขยาย Chromium | Manifest V3 ไม่ขอสิทธิ์เข้าถึงโฮสต์ |

## เอกสารที่รองรับ

| รายการ | รายละเอียด |
|---|---|
| ไฟล์ | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (ตาราง, รายการงาน, บล็อกโค้ด, ขีดฆ่า), รูปภาพในเครื่อง, YAML front matter |
| MDX | แสดงเฉพาะคอมโพเนนต์ที่อนุญาตไว้ ไม่เรียกใช้สคริปต์ใด ๆ |
| HTML | แสดงผลหลังทำให้ปลอดภัยด้วย DOMPurify 3.4.14 |

## แผนภาพและสูตรคณิตศาสตร์

| ชนิด | ชื่อภาษา | หมายเหตุ |
|---|---|---|
| สูตรคณิตศาสตร์ | `$...$`, `$$...$$`, `\(...\)`, `\[...\]` | KaTeX โดย `trust: false`, `maxSize: 50`, `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | เฉพาะข้อมูลที่ฝังไว้ ใช้ URL ภายนอกและ image mark ไม่ได้ |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | เฉพาะ JSON แบบเข้มงวดเท่านั้น |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | รุ่นที่แจกจ่ายจะแสดงซอร์สแบบพับเก็บ ขีดจำกัด: อินพุต 64 KiB, 15 วินาที, SVG 2 MiB |
| Penrose (ทดลอง) | `penrose` | เฉพาะพรีเซ็ต `set-theory` |

## ค่าขีดจำกัด

| รายการ | ค่า |
|---|---|
| ผลการขยายเทมเพลต | 4 MiB |
| บริบทอ้างอิงของคำแปล | ค่าเริ่มต้น 49,152 อักขระ สูงสุด 1,048,576 อักขระ |
| จำนวนเอกสารต่อการแปลเป็นชุด 1 ครั้ง | 1,000 เอกสาร |
| ความกว้างรูปภาพที่กำหนดเอง | 16–4096px |

## ไฟล์

| ไฟล์ | บทบาท | อยู่ใน Git |
|---|---|---|
| `lunascape-docs.json` | การตั้งค่าของรากเอกสาร | มี |
| `docs-lint.config.json` | การตั้งค่ากฎการตรวจสอบ | มี |
| `.lunascape-docs/translation-freshness.json` | บันทึกความสดใหม่ของคำแปล (เฉพาะพาธ ภาษา แฮช และวันเวลา) | มี |
| การตั้งค่าและสถานะพื้นที่ทำงานของ VS Code | การตั้งค่าการแสดงผลส่วนบุคคล การเลือกผู้ให้บริการ สถานะเปิดปิดของ INDEX | ไม่มี |
