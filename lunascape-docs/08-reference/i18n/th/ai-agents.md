# การใช้งานจาก AI

ส่วนขยายจะลงทะเบียน Language Model Tool แบบอ่านอย่างเดียว `lunascape_getDocsSpecification` ไว้กับ VS Code เมื่อมีการถามเอเจนต์ของ VS Code ที่รองรับเกี่ยวกับความสามารถ การตั้งค่า หรือข้อกำหนดของเอกสารใน Lunascape Docs เอเจนต์จะดึงเนื้อหาของวิธีใช้นี้ (ข้อกำหนดทั่วไป) ผ่านเครื่องมือนี้ได้

## วิธีใช้งาน

ถามในแชทของ VS Code โดยใส่ `#lunascapeDocs` หรือถามเกี่ยวกับการตั้งค่าหรือโครงสร้างเอกสารของ Lunascape Docs

```text
#lunascapeDocs จะเปิดใช้คำแปลภาษาอังกฤษใน lunascape-docs.json ได้อย่างไร
```

## อาร์กิวเมนต์ของเครื่องมือ

| อาร์กิวเมนต์ | ความหมาย |
|---|---|
| `topic` | บทที่จะดึงมา ได้แก่ `all`, `usage` (การใช้งานพื้นฐาน), `structure` (รากเอกสารและข้อกำหนดของไฟล์), `editing` (การแก้ไขเอกสาร), `configuration` (การตั้งค่าโครงการ), `security` (ความปลอดภัยและขอบเขตการบันทึก), `ai` (การใช้งานจาก AI) |
| `locale` | ภาษาของวิธีใช้ (แท็กภาษาของวิธีใช้ที่มาพร้อมกัน เช่น `ja` หรือ `en`) หากไม่ระบุ จะใช้ภาษาที่แสดงของ VS Code และหากไม่มี จะคืนวิธีใช้ภาษาญี่ปุ่น |

> **ข้อควรทราบ**
>
> - เครื่องมือนี้จะไม่ส่งเนื้อหาของเอกสารออกไปภายนอก
> - เครื่องมือนี้จะไม่คืนชื่อพื้นที่ทำงานหรือเส้นทางในเครื่อง
> - เครื่องมือนี้จะไม่แก้ไขไฟล์
> - แม้ไม่มี `AGENTS.md` ก็ใช้งานจากเอเจนต์ของ VS Code ที่รองรับได้ แต่จะไม่แชร์ให้ไคลเอนต์ AI อื่นที่ไม่ได้ใช้ tool API ของส่วนขยายโดยอัตโนมัติ
