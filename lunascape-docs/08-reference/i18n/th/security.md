# ความปลอดภัยและขอบเขตการบันทึก

ขอบเขตที่ Lunascape Docs กำหนดไว้เพื่อปกป้องเอกสารและเครื่องของคุณ

## การแสดงผล

- HTML ที่สร้างจาก Markdown และ SVG ที่สร้างจากแผนภาพ จะถูกล้างให้ปลอดภัยด้วย DOMPurify 3.4.14 ก่อนแสดงผล
- สคริปต์ใด ๆ ที่อยู่ใน MDX จะไม่ถูกเรียกใช้งาน
- KaTeX ทำงานด้วย `trust: false`, `maxSize: 50` และ `maxExpand: 1000` และไม่เชื่อถือทั้ง HTML ภายนอกและคำสั่งใด ๆ
- ไลบรารีวาดภาพของ Markmap, WaveDrom, Svgbob, Vega-Lite และ Penrose จะถูกโหลดภายในเครื่องด้วยรุ่นที่ตรึงไว้ เฉพาะเมื่อมีบล็อกที่เกี่ยวข้องเท่านั้น ไม่อนุญาตให้อ้างอิงทรัพยากรภายนอก HTML ดิบ และรูปแบบที่เรียกใช้งานได้ ทั้งยังลบสคริปต์ รูปภาพภายนอก `link`, `style` และ `foreignObject` ออกจาก SVG ที่สร้างขึ้น
- การวาดภาพของ TikZ จะไม่เรียกใช้ LaTeX ของเครื่อง แต่ทำงานตามลำดับใน TeX worker แบบ WebAssembly ที่มีระบบไฟล์อยู่ในหน่วยความจำ โดยมีขีดจำกัดของข้อมูลนำเข้า คิวงาน หน่วยความจำ เวลาทำงาน (15 วินาที) และผลลัพธ์ SVG อีกทั้งปฏิเสธคำสั่ง I/O ของไฟล์

## การเข้าถึงเอกสารและไฟล์

- ลิงก์ของเอกสารและการดำเนินการกับไฟล์ไม่สามารถออกนอกรากเอกสารได้
- การสร้าง เปลี่ยนชื่อ ย้าย และลบจาก INDEX จะได้รับการตรวจสอบซ้ำที่ฝั่งส่วนขยาย ทั้งรากเอกสาร รุ่นของ INDEX เส้นทางของเอกสารต้นฉบับ ชนิดของเป้าหมาย ขอบเขตของ symbolic link และเอกสารที่ยังไม่ได้บันทึก ก่อนจะนำไปใช้จริง คำขอจากเมนูเก่าหรือจากรากเอกสารอื่นจะไม่ถูกนำไปใช้
- ระหว่างที่กำลังแก้ไขเอกสาร หรือกำลังดำเนินการ INDEX รายการอื่นอยู่ การแก้ไข INDEX จะถูกปิดใช้งาน
- การสร้างจากเทมเพลตจะตรวจสอบซ้ำหลังจากดูตัวอย่างแล้ว ทั้งความเชื่อถือของพื้นที่ทำงาน ตัวตนของรากเอกสาร รุ่นของ INDEX, Standard Pack และเนื้อหาที่สร้างขึ้น ปลายทางที่บันทึก และขอบเขตของ symbolic link โดยจะไม่เขียนทับไฟล์ที่มีอยู่ และไม่สร้างเนื้อหาที่ต่างจากตัวอย่าง หรือผลลัพธ์ที่ขยายแล้วเกิน 4 MiB
- การบันทึกไฟล์การตั้งค่าจะตรวจสอบรุ่นทันทีก่อนบันทึก และจะยกเลิกเมื่อพบการเปลี่ยนแปลงจากภายนอก

## การส่งออกสู่ภายนอก

- จะไม่มีการส่งเอกสารออกไปภายนอกเพื่อการอ่าน แก้ไข หรือการตรวจสอบ การตรวจสอบเอกสารทำงานภายในเครื่องอย่างมีผลลัพธ์แน่นอน
- มีเพียงคำแปล (คำแปลของหน้านี้ และการแปลทั้งชุด) เท่านั้นที่ส่งเอกสารไปยังโมเดลภาษา โดยแสดงปลายทางและขอบเขตการส่งไว้ล่วงหน้า และส่งเมื่อได้รับการอนุมัติอย่างชัดแจ้งเท่านั้น <!-- ai-only -->
- ข้อเสนอคำแปลจะแสดงเป็นส่วนต่าง และจะนำไปใช้เมื่อบุคคลบันทึกอย่างชัดแจ้งเท่านั้น หลังจากตรวจสอบรุ่นของเอกสารต้นฉบับและปลายทางของคำแปลซ้ำแล้ว <!-- ai-only -->
- เครื่องมือข้อกำหนดสำหรับ AI เอเจนต์จะไม่ส่งคืนเนื้อหาของเอกสาร ชื่อพื้นที่ทำงาน หรือเส้นทางในเครื่อง <!-- ai-only -->

## Git

- การบันทึกจะเขียนลงไฟล์เท่านั้น ไม่มีฟังก์ชันใดที่ทำการ stage หรือ commit ใน Git โดยอัตโนมัติ
- จะไม่ลบหรือแก้ไขไฟล์ที่มีอยู่ เช่น `_meta.json` โดยไม่แจ้งให้ทราบ และจะไม่ลบหรือย้ายคำแปลที่ขาดต้นฉบับโดยอัตโนมัติ
