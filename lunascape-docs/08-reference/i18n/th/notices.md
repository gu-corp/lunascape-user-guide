# เครื่องหมายการค้าและสัญญาอนุญาต

## สัญญาอนุญาต

Lunascape Docs ให้บริการโดยไม่มีค่าใช้จ่ายจาก G.U.Corp ภายใต้ "ข้อกำหนดการใช้งาน Lunascape Docs" ใช้ได้ทั้งส่วนบุคคลและเชิงพาณิชย์ แต่ไม่อนุญาตให้เผยแพร่ซ้ำ ดัดแปลง หรือทำวิศวกรรมย้อนกลับ ข้อความฉบับเต็มอยู่ในไฟล์ `LICENSE` ที่มาพร้อมกับส่วนขยาย ซอฟต์แวร์ของบุคคลที่สามที่มาพร้อมกันนั้นอยู่ภายใต้สัญญาอนุญาตของแต่ละราย

## เครื่องหมายการค้า

"Lunascape" และแบรนด์ที่เกี่ยวข้องเป็นเครื่องหมายการค้าของเจ้าของสิทธิ์แต่ละราย ชื่อผลิตภัณฑ์และชื่อบริษัทอื่น ๆ เป็นเครื่องหมายการค้าหรือเครื่องหมายการค้าจดทะเบียนของแต่ละบริษัท

## ซอฟต์แวร์ที่มาพร้อมกัน

ส่วนขยายนี้มีซอฟต์แวร์โอเพนซอร์สต่อไปนี้มาพร้อมกัน ข้อความสัญญาอนุญาตฉบับเต็มและประกาศที่สร้างขึ้นอยู่ในโฟลเดอร์ `vendor/` ของส่วนขยาย และในไฟล์ `THIRD-PARTY-NOTICES.md`

- Marked
- DOMPurify 3.4.14
- Mermaid
- KaTeX
- Turndown และ Turndown Plugin GFM
- docs-lint (รันไทม์ของ Editor)
- @lunascape/tikz-renderer (MIT)
- Vega และ Vega-Lite
- Markmap
- WaveDrom
- Svgbob
- Penrose Core (ทดลอง)

node-tikzjax ตัวแปลง DVI ทรัพยากร TeX และฟอนต์ที่จำเป็นสำหรับการวาด TikZ ใช้สำหรับการพัฒนาเท่านั้น และไม่รวมอยู่ในเวอร์ชันที่แจกจ่าย
