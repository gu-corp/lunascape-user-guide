# Безопасность и границы записи

Границы, которые Lunascape Docs устанавливает для защиты ваших документов и устройства.

## Отображение

- HTML, созданный из Markdown, и SVG, созданный из схем, очищаются с помощью DOMPurify 3.4.14 перед отображением.
- Произвольные скрипты в MDX не выполняются.
- KaTeX работает с параметрами `trust: false`, `maxSize: 50` и `maxExpand: 1000` и не доверяет ни внешнему HTML, ни произвольным командам.
- Библиотеки отрисовки Markmap, WaveDrom, Svgbob, Vega-Lite и Penrose загружаются на устройстве, в фиксированных версиях, только при наличии соответствующего блока. Ссылки на внешние ресурсы, необработанный HTML и исполняемые конструкции не допускаются, а из созданного SVG удаляются скрипты, внешние изображения, `link`, `style` и `foreignObject`.
- Отрисовка TikZ не запускает LaTeX на хосте. Она выполняется последовательно в WebAssembly-воркере TeX с файловой системой в памяти, с ограничениями на ввод, очередь, память, время выполнения (15 секунд) и вывод SVG, и отклоняет инструкции файлового ввода-вывода.

## Доступ к документам и файлам

- Ссылки в документах и операции с файлами не могут выйти за пределы корня документации.
- Создание, переименование, перемещение и удаление из INDEX повторно проверяются на стороне расширения — корень документации, версия INDEX, путь исходного документа, тип объекта, границы символических ссылок и несохраненные документы — прежде чем они применяются. Запросы из устаревшего меню или из другого корня документации не применяются.
- Изменение INDEX отключается во время редактирования документа или применения другой операции с INDEX.
- Создание из шаблона после предварительного просмотра повторно проверяет доверие к рабочей области, реальность корня документации, версию INDEX, Standard Pack и создаваемое содержимое, место сохранения и границы символических ссылок. Существующий файл не перезаписывается, а содержимое, отличающееся от предварительного просмотра или превышающее 4 МиБ, не создается.
- При сохранении файла настроек непосредственно перед записью проверяется его версия, и при обнаружении внешних изменений сохранение прерывается.

## Передача вовне

- Документы никогда не передаются вовне для просмотра, редактирования или проверки. Проверка документов выполняется на устройстве и детерминированно.
- Только перевод (перевод этой страницы, пакетный перевод) передает документы языковой модели — предварительно показав адрес и объем передачи и только при явном согласии. <!-- ai-only -->
- Варианты перевода показываются в виде различий; версии исходного документа и перевода проверяются повторно, и вариант применяется, только если человек сохранил его явно. <!-- ai-only -->
- Инструмент спецификаций для AI-агентов не возвращает текст документов, имена рабочих областей и локальные пути. <!-- ai-only -->

## Git

- Сохранение только записывает файл. Ни одна функция не выполняет индексацию и фиксацию в Git автоматически.
- Существующие файлы, такие как `_meta.json`, не удаляются и не изменяются без уведомления. Осиротевшие переводы также не удаляются и не перемещаются автоматически.
