# Сочетания клавиш

## Просмотр

| Действие | Клавиши |
|---|---|
| Назад | `Alt`+`←` |
| Вперед | `Alt`+`→` |
| Закрыть оверлей INDEX, меню или диалоговое окно | `Esc` |

## INDEX

| Действие | Клавиши |
|---|---|
| Переместить элемент на одну позицию вверх или вниз (изменить порядок) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Перемещение внутри меню элемента | `↑` / `↓` |
| Перейти к первому или последнему пункту меню | `Home` / `End` |
| Закрыть меню элемента (фокус возвращается на прежнее место) | `Esc` |
| Выйти из меню элемента | `Tab` |

## VS Code

| Действие | Клавиши |
|---|---|
| Палитра команд | `⇧⌘P` / `Ctrl+Shift+P` |
| Представление расширений | `⇧⌘X` / `Ctrl+Shift+X` |
| Параметры | `⌘,` / `Ctrl+,` |

## Версия для веб-браузера

Кнопки браузера [Назад] и [Вперед] позволяют перемещаться по истории просмотра.
