# Основные характеристики

## Требования к среде

| Среда | Требования |
|---|---|
| Расширение VS Code | VS Code 1.90 или новее. Функции, записывающие файлы, работают в надежной рабочей области |
| Веб-версия | Актуальные Chrome, Edge, Safari, Firefox. Для просмотра локальной папки нужен браузер с поддержкой выбора папки (File System Access API) |
| Расширение Chromium | Manifest V3. Разрешения на доступ к сайтам не запрашиваются |

## Поддерживаемые документы

| Пункт | Содержание |
|---|---|
| Файлы | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (таблицы, списки задач, блоки кода, зачеркивание), локальные изображения, YAML front matter |
| MDX | Отображаются только разрешенные компоненты. Произвольные сценарии не выполняются |
| HTML | Перед отображением очищается с помощью DOMPurify 3.4.14 |

## Схемы и формулы

| Вид | Название языка | Примечания |
|---|---|---|
| Формулы | `$...$`, `$$...$$`, `\(...\)`, `\[...\]` | KaTeX. `trust: false`, `maxSize: 50`, `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | Только встроенные данные. Внешние URL и графические метки недопустимы |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | Только строгий JSON |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | В поставляемой сборке исходный код свернут. Ограничения: 64 KiB на входе, 15 секунд, 2 MiB для SVG |
| Penrose (экспериментально) | `penrose` | Только пресет `set-theory` |

## Предельные значения

| Пункт | Значение |
|---|---|
| Результат развертывания шаблона | 4 MiB |
| Контекст для перевода | 49 152 символа по умолчанию, не более 1 048 576 |
| Документов за один пакетный перевод | 1000 |
| Произвольная ширина изображения | 16–4096 px |
