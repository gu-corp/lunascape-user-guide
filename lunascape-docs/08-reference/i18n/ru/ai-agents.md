# Использование из ИИ-агентов

Расширение регистрирует в VS Code доступный только для чтения инструмент языковой модели `lunascape_getDocsSpecification`. Когда совместимый агент VS Code получает вопрос о функциях, настройках или соглашениях по документам Lunascape Docs, он может получить через этот инструмент содержимое данной справки (общую спецификацию).

## Как пользоваться

Задайте вопрос в чате VS Code, добавив `#lunascapeDocs`, или просто спросите о настройках либо структуре документов Lunascape Docs.

```text
#lunascapeDocs Как включить английский перевод в lunascape-docs.json?
```

## Аргументы инструмента

| Аргумент | Содержание |
|---|---|
| `topic` | Раздел, который нужно получить: `all`, `usage` (основные операции), `structure` (корни документации и соглашения по файлам), `editing` (редактирование документа), `configuration` (настройки проекта), `security` (безопасность и границы записи) или `ai` (использование из ИИ-агентов) |
| `locale` | Язык справки (тег языка встроенной справки, например `ja` или `en`). Если не указан, используется язык интерфейса VS Code, а при его отсутствии возвращается справка на японском |

> **Примечание**
>
> - Инструмент не отправляет содержимое документов куда-либо вовне.
> - Инструмент не возвращает имена рабочих областей и локальные пути.
> - Инструмент не изменяет файлы.
> - Он работает из совместимых агентов VS Code даже без `AGENTS.md`. Он не передается автоматически другим ИИ-клиентам, которые не используют API инструментов расширения.
