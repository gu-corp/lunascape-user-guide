# Tipkovni prečaci

## Preglednik

| Radnja | Tipke |
|---|---|
| Natrag | `Alt`+`←` |
| Naprijed | `Alt`+`→` |
| Zatvaranje prekrivnog prikaza INDEX, izbornika ili dijaloga | `Esc` |

## INDEX

| Radnja | Tipke |
|---|---|
| Pomicanje stavke za jedno mjesto gore ili dolje (promjena redoslijeda) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Kretanje unutar izbornika stavke | `↑` / `↓` |
| Prijelaz na prvu ili zadnju stavku izbornika | `Home` / `End` |
| Zatvaranje izbornika stavke (fokus se vraća na mjesto s kojeg je otvoren) | `Esc` |
| Izlazak iz izbornika stavke | `Tab` |

## VS Code

| Radnja | Tipke |
|---|---|
| Paleta naredbi | `⇧⌘P` / `Ctrl+Shift+P` |
| Prikaz proširenja | `⇧⌘X` / `Ctrl+Shift+X` |
| Postavke | `⌘,` / `Ctrl+,` |

## Web-preglednik

Gumbima [Natrag] i [Naprijed] u pregledniku krećete se kroz povijest pregledavanja.
