# Scorciatoie da tastiera

## Visualizzatore

| Azione | Tasti |
|---|---|
| Indietro | `Alt`+`←` |
| Avanti | `Alt`+`→` |
| Chiudere la sovrapposizione INDEX, un menu o una finestra di dialogo | `Esc` |

## INDEX

| Azione | Tasti |
|---|---|
| Spostare una voce in alto o in basso (riordino) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Spostarsi all'interno del menu di una voce | `↑` / `↓` |
| Passare alla prima o all'ultima voce del menu | `Home` / `End` |
| Chiudere il menu di una voce (lo stato attivo torna al punto di partenza) | `Esc` |
| Uscire dal menu di una voce | `Tab` |

## VS Code

| Azione | Tasti |
|---|---|
| Riquadro comandi | `⇧⌘P` / `Ctrl+Shift+P` |
| Vista Estensioni | `⇧⌘X` / `Ctrl+Shift+X` |
| Impostazioni | `⌘,` / `Ctrl+,` |

## Versione per browser Web

Con i pulsanti [Indietro] e [Avanti] del browser si percorre la cronologia di navigazione.
