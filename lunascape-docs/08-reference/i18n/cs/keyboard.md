# Klávesové zkratky

## Prohlížeč

| Akce | Klávesy |
|---|---|
| Zpět | `Alt`+`←` |
| Vpřed | `Alt`+`→` |
| Zavřít překryvné okno INDEX, nabídku nebo dialog | `Esc` |

## INDEX

| Akce | Klávesy |
|---|---|
| Přesunout položku o jednu nahoru nebo dolů (změna pořadí) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Pohyb v nabídce položky | `↑` / `↓` |
| Přejít na první nebo poslední položku nabídky | `Home` / `End` |
| Zavřít nabídku položky (fokus se vrátí na původní místo) | `Esc` |
| Opustit nabídku položky | `Tab` |

## VS Code

| Akce | Klávesy |
|---|---|
| Paleta příkazů | `⇧⌘P` / `Ctrl+Shift+P` |
| Zobrazení rozšíření | `⇧⌘X` / `Ctrl+Shift+X` |
| Nastavení | `⌘,` / `Ctrl+,` |

## Webový prohlížeč

Tlačítky [Zpět] a [Vpřed] v prohlížeči se pohybujete v historii prohlížení.
