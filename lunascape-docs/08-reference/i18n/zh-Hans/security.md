# 安全与写入边界

Lunascape Docs 为保护你的文档和设备而设置的边界。

## 显示

- 由 Markdown 生成的 HTML 和由图生成的 SVG，都会先经 DOMPurify 3.4.14 净化再显示。
- 不执行 MDX 中的任意脚本。
- KaTeX 以 `trust: false`、`maxSize: 50`、`maxExpand: 1000` 运行，不信任外部 HTML，也不信任任意命令。
- Markmap、WaveDrom、Svgbob、Vega-Lite、Penrose 的绘制库，仅在存在相应代码块时才在本机加载固定版本。不允许引用外部资源、原始 HTML 和可执行记法，并从生成的 SVG 中移除脚本、外部图片、`link`、`style`、`foreignObject`。
- TikZ 的绘制不会启动主机上的 LaTeX，而是在带有内存文件系统的 WebAssembly TeX 工作器中逐个执行。输入、队列、内存、执行时间（15 秒）和 SVG 输出均有上限，并拒绝文件 I/O 指令。

## 对文档和文件的访问

- 文档链接和文件操作不会越出文档根目录。
- 从 INDEX 进行的创建、重命名、移动和删除，会由扩展端再次确认文档根目录、INDEX 的版本、正本文档的路径、对象的类型、符号链接的边界以及未保存的文档后才应用。来自过期菜单或其他文档根目录的操作请求不予应用。
- 在编辑文档期间，或正在应用其他 INDEX 操作期间，INDEX 的修改操作会被禁用。
- 从模板创建时，会在预览之后再次确认工作区的信任状态、文档根目录的实体、INDEX 的版本、Standard Pack 与生成内容、保存位置以及符号链接的边界。不会覆盖已有文件，也不会创建与预览不同的内容或超过 4 MiB 的展开结果。
- 保存设置文件时，会在保存前确认版本，检测到外部更改时中止保存。

## 向外部发送

- 不会为了阅读、编辑和检查而把文档发送到外部。文档检查在本机确定性地执行。
- 只有翻译（本页翻译、批量翻译）会事先显示发送目标和发送范围，并在获得明确许可时才把文档发送给语言模型。 <!-- ai-only -->
- 翻译方案会以差异形式呈现，并在再次确认正本文档和翻译目标的版本后，仅在有人明确保存时才应用。 <!-- ai-only -->
- 面向 AI 代理的规格书工具不会返回文档正文、工作区名称和本地路径。 <!-- ai-only -->

## Git

- 保存只执行对文件的写入。任何功能都不会自动执行 Git 的暂存或提交。
- 不会静默删除或修改 `_meta.json` 等已有文件。也不会自动删除或移动孤立的译文版本。
