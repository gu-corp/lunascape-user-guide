# 键盘操作一览

## 查看器

| 操作 | 按键 |
|---|---|
| 返回 | `Alt`+`←` |
| 前进 | `Alt`+`→` |
| 关闭 INDEX 浮层、菜单或对话框 | `Esc` |

## INDEX

| 操作 | 按键 |
|---|---|
| 将项目上移／下移一位（排序） | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| 在项目菜单中移动 | `↑` / `↓` |
| 移到项目菜单的开头／末尾 | `Home` / `End` |
| 关闭项目菜单（焦点返回原位置） | `Esc` |
| 退出项目菜单 | `Tab` |

## VS Code

| 操作 | 按键 |
|---|---|
| 命令面板 | `⇧⌘P` / `Ctrl+Shift+P` |
| 扩展视图 | `⇧⌘X` / `Ctrl+Shift+X` |
| 设置 | `⌘,` / `Ctrl+,` |

## Web 浏览器版

使用浏览器的 [返回] [前进] 可以浏览历史记录。
