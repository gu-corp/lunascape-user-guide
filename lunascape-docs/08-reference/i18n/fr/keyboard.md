# Liste des raccourcis clavier

## Visionneuse

| Action | Touches |
|---|---|
| Précédent | `Alt`+`←` |
| Suivant | `Alt`+`→` |
| Fermer la superposition INDEX, un menu ou une boîte de dialogue | `Esc` |

## INDEX

| Action | Touches |
|---|---|
| Déplacer un élément d'un rang vers le haut ou vers le bas (réorganiser) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Se déplacer dans le menu d'un élément | `↑` / `↓` |
| Aller au début ou à la fin du menu d'un élément | `Home` / `End` |
| Fermer le menu d'un élément (le focus revient à sa position d'origine) | `Esc` |
| Quitter le menu d'un élément | `Tab` |

## VS Code

| Action | Touches |
|---|---|
| Palette de commandes | `⇧⌘P` / `Ctrl+Shift+P` |
| Vue Extensions | `⇧⌘X` / `Ctrl+Shift+X` |
| Paramètres | `⌘,` / `Ctrl+,` |

## Version navigateur web

Les boutons [Précédent] et [Suivant] du navigateur permettent de parcourir l'historique de navigation.
