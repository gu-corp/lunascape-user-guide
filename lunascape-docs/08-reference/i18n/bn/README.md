# প্রধান স্পেসিফিকেশন

## চালানোর পরিবেশ

| পরিবেশ | প্রয়োজনীয়তা |
|---|---|
| VS Code এক্সটেনশন | VS Code 1.90 বা তার পরের সংস্করণ। ফাইলে লেখা হয় এমন সুবিধাগুলি বিশ্বস্ত ওয়ার্কস্পেসে কাজ করে |
| ওয়েব ব্রাউজার সংস্করণ | সাম্প্রতিক Chrome, Edge, Safari বা Firefox। স্থানীয় ফোল্ডার দেখার জন্য ফোল্ডার নির্বাচন (File System Access API) সমর্থন করে এমন ব্রাউজার প্রয়োজন |
| Chromium এক্সটেনশন | Manifest V3। কোনো হোস্ট অনুমতি চাওয়া হয় না |

## সমর্থিত নথি

| বিষয় | বিবরণ |
|---|---|
| ফাইল | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (টেবিল, কাজের তালিকা, কোড ব্লক, কাটা দাগ), স্থানীয় ছবি, YAML front matter |
| MDX | কেবল অনুমোদিত কম্পোনেন্ট দেখানো হয়। যেকোনো স্ক্রিপ্ট চালানো হয় না |
| HTML | DOMPurify 3.4.14 দিয়ে নিরাপদ করে দেখানো হয় |

| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | কেবল কড়া JSON |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | বিতরণ সংস্করণে সোর্স ভাঁজ করা অবস্থায় দেখানো হয়। ইনপুট ৬৪ KiB, ১৫ সেকেন্ড, SVG ২ MiB-এর সীমা |
| Penrose (পরীক্ষামূলক) | `penrose` | কেবল `set-theory` প্রিসেট |
