# AI থেকে ব্যবহার

এক্সটেনশনটি VS Code-এ কেবল-পঠনযোগ্য Language Model Tool `lunascape_getDocsSpecification` নিবন্ধন করে। সামঞ্জস্যপূর্ণ VS Code এজেন্টকে যখন Lunascape Docs-এর বৈশিষ্ট্য, সেটিংস বা নথির রীতি সম্পর্কে জিজ্ঞাসা করা হয়, তখন সেটি এই সরঞ্জামের মাধ্যমে এই সহায়তার বিষয়বস্তু (সাধারণ স্পেসিফিকেশন) নিতে পারে।

## ব্যবহারের পদ্ধতি

VS Code-এর চ্যাটে `#lunascapeDocs` যোগ করে জিজ্ঞাসা করুন, অথবা Lunascape Docs-এর সেটিংস বা নথির গঠন সম্পর্কে জিজ্ঞাসা করুন।

```text
#lunascapeDocs lunascape-docs.json এ ইংরেজি অনুবাদ সক্রিয় করব কীভাবে?
```

## সরঞ্জামের আর্গুমেন্ট

| আর্গুমেন্ট | বিষয়বস্তু |
|---|---|
| `topic` | যে অধ্যায়টি নেওয়া হবে। `all`, `usage`（মৌলিক ব্যবহার）, `structure`（ডকুমেন্টেশন রুট ও ফাইলের রীতি）, `editing`（নথি সম্পাদনা করা）, `configuration`（প্রকল্পের সেটিংস）, `security`（নিরাপত্তা ও সংরক্ষণের সীমানা）, `ai`（AI থেকে ব্যবহার） |
| `locale` | সহায়তার ভাষা（`ja`, `en` প্রভৃতি, সঙ্গে দেওয়া সহায়তার ভাষা ট্যাগ）। বাদ দিলে VS Code-এর প্রদর্শন ভাষা, তা না থাকলে জাপানি সহায়তা ফেরত দেওয়া হয় |

> **দ্রষ্টব্য**
>
> - সরঞ্জামটি নথির মূল লেখা বাইরে পাঠায় না।
> - সরঞ্জামটি ওয়ার্কস্পেসের নাম বা স্থানীয় পাথ ফেরত দেয় না।
> - সরঞ্জামটি ফাইল পরিবর্তন করে না।
> - `AGENTS.md` না থাকলেও VS Code-এর সামঞ্জস্যপূর্ণ এজেন্ট থেকে এটি ব্যবহার করা যায়। এক্সটেনশনের সরঞ্জাম API ব্যবহার করে না এমন অন্য AI ক্লায়েন্টের সঙ্গে এটি স্বয়ংক্রিয়ভাবে ভাগ করা হয় না।
