# কীবোর্ড শর্টকাট

## ভিউয়ার

| কাজ | কী |
|---|---|
| পিছনে | `Alt`+`←` |
| সামনে | `Alt`+`→` |
| INDEX-এর ওভারলে, মেনু বা ডায়ালগ বন্ধ করা | `Esc` |

## INDEX

| কাজ | কী |
|---|---|
| একটি আইটেম এক ধাপ উপরে/নিচে সরানো (ক্রম পরিবর্তন) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| আইটেম মেনুর ভিতরে চলাচল করা | `↑` / `↓` |
| আইটেম মেনুর প্রথম/শেষ আইটেমে যাওয়া | `Home` / `End` |
| আইটেম মেনু বন্ধ করা (যেখান থেকে খোলা হয়েছিল সেখানে ফোকাস ফিরিয়ে দেয়) | `Esc` |
| আইটেম মেনু থেকে বেরিয়ে আসা | `Tab` |

## VS Code

| কাজ | কী |
|---|---|
| কমান্ড প্যালেট | `⇧⌘P` / `Ctrl+Shift+P` |
| এক্সটেনশন ভিউ | `⇧⌘X` / `Ctrl+Shift+X` |
| সেটিংস | `⌘,` / `Ctrl+,` |

## ওয়েব ব্রাউজার সংস্করণ

ব্রাউজারের [পিছনে] [সামনে] দিয়ে ব্রাউজিং ইতিহাসে চলাচল করা যায়।
