# मुख्य विनिर्देश

## चलाने की आवश्यकताएँ

| परिवेश | आवश्यकताएँ |
|---|---|
| VS Code एक्सटेंशन | VS Code 1.90 या बाद का। लिखने वाली सुविधाएँ विश्वसनीय कार्यस्थान में काम करती हैं |
| वेब ब्राउज़र संस्करण | हाल का Chrome, Edge, Safari या Firefox। स्थानीय फ़ोल्डर देखने के लिए ऐसा ब्राउज़र चाहिए जो फ़ोल्डर चयन (File System Access API) का समर्थन करता हो |
| Chromium एक्सटेंशन | Manifest V3। होस्ट अनुमतियाँ नहीं माँगी जातीं |

## समर्थित दस्तावेज़

| मद | विवरण |
|---|---|
| फ़ाइलें | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (तालिकाएँ, कार्य सूचियाँ, कोड ब्लॉक, काट कर लिखा पाठ), स्थानीय चित्र, YAML front matter |
| MDX | केवल अनुमत घटक ही दिखाए जाते हैं। कोई भी मनमानी स्क्रिप्ट नहीं चलाई जाती |
| HTML | DOMPurify 3.4.14 से निरापद बनाकर दिखाया जाता है |

## आरेख और गणितीय सूत्र

| प्रकार | भाषा का नाम | टिप्पणी |
|---|---|---|
| गणितीय सूत्र | `$...$`, `$$...$$`, `\(...\)`, `\[...\]` | KaTeX। `trust: false`, `maxSize: 50`, `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | केवल अंतर्निहित डेटा। बाहरी URL और image mark नहीं चलेंगे |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | केवल कड़ा JSON |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | वितरित संस्करण में स्रोत मुड़ा हुआ दिखता है। सीमाएँ: इनपुट 64 KiB, 15 सेकंड, SVG 2 MiB |
| Penrose (प्रयोगात्मक) | `penrose` | केवल `set-theory` प्रीसेट |

## अधिकतम सीमाएँ

| मद | मान |
|---|---|
| टेम्पलेट के विस्तार का परिणाम | 4 MiB |
| अनुवाद का संदर्भ प्रसंग | डिफ़ॉल्ट 49,152 अक्षर, अधिकतम 1,048,576 अक्षर |
| एक बार के सामूहिक अनुवाद में दस्तावेज़ | 1,000 दस्तावेज़ |
| चित्र की वैकल्पिक चौड़ाई | 16–4096px |
