# कीबोर्ड शॉर्टकट

## व्यूअर

| क्रिया | कुंजियाँ |
|---|---|
| वापस जाएँ | `Alt`+`←` |
| आगे जाएँ | `Alt`+`→` |
| INDEX का ओवरले, मेनू या डायलॉग बंद करें | `Esc` |

## INDEX

| क्रिया | कुंजियाँ |
|---|---|
| किसी आइटम को एक स्थान ऊपर／नीचे ले जाएँ (क्रम बदलना) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| आइटम मेनू के भीतर जाएँ | `↑` / `↓` |
| आइटम मेनू के पहले／अंतिम आइटम पर जाएँ | `Home` / `End` |
| आइटम मेनू बंद करें (फ़ोकस वापस पिछली जगह पर) | `Esc` |
| आइटम मेनू से बाहर निकलें | `Tab` |

## VS Code

| क्रिया | कुंजियाँ |
|---|---|
| कमांड पैलेट | `⇧⌘P` / `Ctrl+Shift+P` |
| एक्सटेंशन दृश्य | `⇧⌘X` / `Ctrl+Shift+X` |
| सेटिंग्स | `⌘,` / `Ctrl+,` |

## वेब ब्राउज़र संस्करण

ब्राउज़र के [वापस] [आगे] बटन से ब्राउज़िंग इतिहास में आगे-पीछे जा सकते हैं।
