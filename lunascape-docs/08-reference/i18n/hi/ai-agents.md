# AI से उपयोग

यह एक्सटेंशन केवल-पढ़ने योग्य Language Model Tool `lunascape_getDocsSpecification` को VS Code में पंजीकृत करता है। जब VS Code के किसी संगत एजेंट से Lunascape Docs की सुविधाओं, सेटिंग्स या दस्तावेज़ नियमों के बारे में पूछा जाता है, तो वह इस टूल के ज़रिए इस सहायता की सामग्री (सामान्य विनिर्देश) प्राप्त कर सकता है।

## उपयोग कैसे करें

VS Code की चैट में `#lunascapeDocs` लगाकर प्रश्न पूछें, या Lunascape Docs की सेटिंग्स या दस्तावेज़ संरचना के बारे में पूछें।

```text
#lunascapeDocs lunascape-docs.json में अंग्रेज़ी अनुवाद कैसे सक्षम करें?
```

## टूल के आर्ग्युमेंट

| आर्ग्युमेंट | विवरण |
|---|---|
| `topic` | प्राप्त किया जाने वाला अध्याय: `all`, `usage` (बुनियादी संचालन), `structure` (दस्तावेज़ रूट और फ़ाइल नियम), `editing` (दस्तावेज़ संपादित करना), `configuration` (प्रोजेक्ट सेटिंग्स), `security` (सुरक्षा और लेखन सीमाएँ), `ai` (AI से उपयोग) |
| `locale` | सहायता की भाषा (`ja`, `en` जैसे, साथ दी गई सहायता का भाषा टैग)। छोड़ने पर VS Code की प्रदर्शन भाषा, और वह न हो तो जापानी सहायता लौटाई जाती है |

> **ध्यान दें**
>
> - टूल दस्तावेज़ की सामग्री बाहर नहीं भेजता।
> - टूल कार्यस्थान का नाम या स्थानीय पथ नहीं लौटाता।
> - टूल फ़ाइलों में बदलाव नहीं करता।
> - `AGENTS.md` न होने पर भी VS Code के संगत एजेंट से इसका उपयोग किया जा सकता है। जो अन्य AI क्लाइंट एक्सटेंशन का टूल API उपयोग नहीं करते, उनके साथ यह अपने आप साझा नहीं होता।
