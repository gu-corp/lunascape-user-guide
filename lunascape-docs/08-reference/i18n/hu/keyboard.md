# Billentyűparancsok

## Megjelenítő

| Művelet | Billentyűk |
|---|---|
| Vissza | `Alt`+`←` |
| Előre | `Alt`+`→` |
| Az INDEX rétege, egy menü vagy egy párbeszédablak bezárása | `Esc` |

## INDEX

| Művelet | Billentyűk |
|---|---|
| Elem mozgatása egy hellyel feljebb vagy lejjebb (átrendezés) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Mozgás az elem menüjén belül | `↑` / `↓` |
| Ugrás a menü első, illetve utolsó elemére | `Home` / `End` |
| Az elem menüjének bezárása (a fókusz visszatér a kiindulási helyre) | `Esc` |
| Kilépés az elem menüjéből | `Tab` |

## VS Code

| Művelet | Billentyűk |
|---|---|
| Parancskatalógus | `⇧⌘P` / `Ctrl+Shift+P` |
| Bővítmények nézet | `⇧⌘X` / `Ctrl+Shift+X` |
| Beállítások | `⌘,` / `Ctrl+,` |

## Webböngészős változat

A böngésző [Vissza] és [Előre] gombjával a böngészési előzmények között lépkedhet.
