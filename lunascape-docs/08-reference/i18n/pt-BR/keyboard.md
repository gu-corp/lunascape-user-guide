# Atalhos de teclado

## Visualizador

| Ação | Teclas |
|---|---|
| Voltar | `Alt`+`←` |
| Avançar | `Alt`+`→` |
| Fechar a sobreposição do INDEX, um menu ou uma caixa de diálogo | `Esc` |

## INDEX

| Ação | Teclas |
|---|---|
| Mover um item uma posição para cima ou para baixo (reordenar) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Mover-se dentro do menu do item | `↑` / `↓` |
| Ir para o início ou o fim do menu do item | `Home` / `End` |
| Fechar o menu do item (devolvendo o foco ao ponto de origem) | `Esc` |
| Sair do menu do item | `Tab` |

## VS Code

| Ação | Teclas |
|---|---|
| Paleta de Comandos | `⇧⌘P` / `Ctrl+Shift+P` |
| Exibição de extensões | `⇧⌘X` / `Ctrl+Shift+X` |
| Configurações | `⌘,` / `Ctrl+,` |

## Versão para navegador

Use [Voltar] e [Avançar] do navegador para percorrer o histórico de navegação.
