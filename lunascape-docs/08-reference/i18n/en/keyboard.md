# Keyboard shortcuts

## Viewer

| Action | Keys |
|---|---|
| Back | `Alt`+`←` |
| Forward | `Alt`+`→` |
| Close the INDEX overlay, a menu or a dialog | `Esc` |

## INDEX

| Action | Keys |
|---|---|
| Move an item up or down (reorder) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Move within an item menu | `↑` / `↓` |
| Jump to the first or last menu item | `Home` / `End` |
| Close an item menu (returning focus to where it was opened) | `Esc` |
| Leave an item menu | `Tab` |

## VS Code

| Action | Keys |
|---|---|
| Command Palette | `⇧⌘P` / `Ctrl+Shift+P` |
| Extensions view | `⇧⌘X` / `Ctrl+Shift+X` |
| Settings | `⌘,` / `Ctrl+,` |

## Web viewer

The browser's Back and Forward buttons move through the browsing history.
