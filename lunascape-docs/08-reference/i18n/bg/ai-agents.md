# Използване от AI

Разширението регистрира във VS Code инструмента Language Model Tool `lunascape_getDocsSpecification`, който е само за четене. Когато съвместим агент на VS Code бъде попитан за функциите, настройките или правилата за документи на Lunascape Docs, той може да получи съдържанието на тази помощ (общата спецификация) чрез този инструмент.

## Как се използва

Задайте въпрос в чата на VS Code с `#lunascapeDocs` или просто попитайте за настройките или структурата на документите на Lunascape Docs.

```text
#lunascapeDocs Как да включа превода на английски в lunascape-docs.json?
```

## Аргументи на инструмента

| Аргумент | Съдържание |
|---|---|
| `topic` | Разделът, който да се получи: `all`, `usage` (Основни операции), `structure` (Коренна папка на документацията и правила за файловете), `editing` (Редактиране на документ), `configuration` (Настройки на проекта), `security` (Сигурност и граници на записа), `ai` (Използване от AI) |
| `locale` | Езикът на помощта (езиков таг на вградената помощ, например `ja` или `en`). Ако е пропуснат, се използва езикът на интерфейса на VS Code, а при липса — помощта на японски |

> **Забележка**
>
> - Инструментът не изпраща съдържанието на документите навън.
> - Инструментът не връща имена на работни пространства или локални пътища.
> - Инструментът не променя файлове.
> - Работи от съвместими агенти на VS Code и без `AGENTS.md`. Не се споделя автоматично с други AI клиенти, които не използват API на инструментите на разширението.
