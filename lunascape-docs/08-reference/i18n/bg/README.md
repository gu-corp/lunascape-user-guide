# Основни спецификации

## Работна среда

| Среда | Изисквания |
|---|---|
| Разширение за VS Code | VS Code 1.90 или по-нова версия. Функциите, които записват файлове, работят в надеждно работно пространство |
| Версия за уеб браузър | Скорошна версия на Chrome, Edge, Safari или Firefox. За разглеждане на локална папка е необходим браузър, който поддържа избор на папка (File System Access API) |
| Разширение за Chromium | Manifest V3. Не се изискват разрешения за хостове |

## Поддържани документи

| Елемент | Съдържание |
|---|---|
| Файлове | `.md`, `.markdown`, `.mdx` |
| Markdown | GitHub Flavored Markdown (таблици, списъци със задачи, блокове с код, зачертан текст), локални изображения, YAML front matter |
| MDX | Показват се само разрешените компоненти. Произволни скриптове не се изпълняват |
| HTML | Показва се след обезвреждане с DOMPurify 3.4.14 |

## Диаграми и формули

| Вид | Име на езика | Бележки |
|---|---|---|
| Формули | `$...$`, `$$...$$`, `\(...\)`, `\[...\]` | KaTeX. `trust: false`, `maxSize: 50`, `maxExpand: 1000` |
| Mermaid | `mermaid` | |
| Vega-Lite | `vega-lite` | Само вградени данни. Външни URL адреси и знаци за изображения не се допускат |
| Markmap | `markmap` | |
| WaveDrom | `wavedrom` | Само строг JSON |
| Svgbob | `svgbob` | |
| TikZ | `tikz` | В разпространяваната версия изходният код се показва свит. Ограничения: 64 KiB вход, 15 секунди, 2 MiB SVG |
| Penrose (експериментално) | `penrose` | Само предварителната настройка `set-theory` |

## Максимални стойности

| Елемент | Стойност |
|---|---|
| Резултат от разгръщането на шаблон | 4 MiB |
| Справочен контекст за превода | по подразбиране 49 152 знака, най-много 1 048 576 знака |
| Документи в едно пакетно изпълнение на превода | 1000 документа |
| Произволна ширина на изображение | 16–4096 px |

## Файлове

| Файл | Роля | В Git |
|---|---|---|
| `lunascape-docs.json` | Настройки на коренната папка на документацията | Да |
| `docs-lint.config.json` | Настройки на правилата за проверка | Да |
| `.lunascape-docs/translation-freshness.json` | Записи за актуалността на превода (само пътища, езици, хешове и дата и час) | Да |
| Настройки на VS Code и състояние на работното пространство | Лични настройки на изгледа, избор на доставчик, състояние на разгъването на INDEX | Не |
