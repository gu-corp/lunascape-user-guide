# Клавишни комбинации

## Визуализатор

| Действие | Клавиши |
|---|---|
| Назад | `Alt`+`←` |
| Напред | `Alt`+`→` |
| Затваряне на наслагването на INDEX, меню или диалогов прозорец | `Esc` |

## INDEX

| Действие | Клавиши |
|---|---|
| Преместване на елемент с една позиция нагоре/надолу (преподреждане) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Придвижване в менюто на елемент | `↑` / `↓` |
| Към началото/края на менюто на елемент | `Home` / `End` |
| Затваряне на менюто на елемент (фокусът се връща на предишното място) | `Esc` |
| Излизане от менюто на елемент | `Tab` |

## VS Code

| Действие | Клавиши |
|---|---|
| Палитра с команди | `⇧⌘P` / `Ctrl+Shift+P` |
| Изглед с разширения | `⇧⌘X` / `Ctrl+Shift+X` |
| Настройки | `⌘,` / `Ctrl+,` |

## Версия за уеб браузър

С бутоните [Назад] и [Напред] на браузъра се придвижвате по историята на разглеждането.
