# Skróty klawiaturowe

## Przeglądarka dokumentów

| Czynność | Klawisze |
|---|---|
| Wstecz | `Alt`+`←` |
| Dalej | `Alt`+`→` |
| Zamknięcie nakładki INDEX, menu lub okna dialogowego | `Esc` |

## INDEX

| Czynność | Klawisze |
|---|---|
| Przeniesienie pozycji o jedno miejsce w górę lub w dół (zmiana kolejności) | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| Poruszanie się w menu pozycji | `↑` / `↓` |
| Przejście na początek lub koniec menu pozycji | `Home` / `End` |
| Zamknięcie menu pozycji (fokus wraca w poprzednie miejsce) | `Esc` |
| Wyjście z menu pozycji | `Tab` |

## VS Code

| Czynność | Klawisze |
|---|---|
| Paleta poleceń | `⇧⌘P` / `Ctrl+Shift+P` |
| Widok rozszerzeń | `⇧⌘X` / `Ctrl+Shift+X` |
| Ustawienia | `⌘,` / `Ctrl+,` |

Przyciskami [Wstecz] i [Dalej] w przeglądarce przechodzisz przez historię przeglądania.
