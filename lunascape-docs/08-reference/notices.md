Lunascape Docs は G.U.Corp が「Lunascape Docs 利用規約」のもとで無償で提供しています。個人でも商用でも使えますが、再配布、改変、リバースエンジニアリングはできません。全文は拡張機能に同梱の `LICENSE` にあります。同梱の第三者ソフトウェアには、それぞれのライセンスが適用されます。

## 商標

「Lunascape」および関連するブランドは、それぞれの権利者の商標です。その他の製品名、社名は各社の商標または登録商標です。
