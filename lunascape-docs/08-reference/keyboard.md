# キーボード操作一覧

## ビューアー

| 操作 | キー |
|---|---|
| 戻る | `Alt`+`←` |
| 進む | `Alt`+`→` |
| INDEX のオーバーレイ、メニュー、ダイアログを閉じる | `Esc` |

## INDEX

| 操作 | キー |
|---|---|
| 項目を 1 つ上／下へ移動する（並び替え） | `Alt`+`Shift`+`↑` / `Alt`+`Shift`+`↓` |
| 項目メニュー内で移動する | `↑` / `↓` |
| 項目メニューの先頭／末尾へ | `Home` / `End` |
| 項目メニューを閉じる（元の位置へフォーカスを戻す） | `Esc` |
| 項目メニューを抜ける | `Tab` |

## VS Code

| 操作 | キー |
|---|---|
| コマンドパレット | `⇧⌘P` / `Ctrl+Shift+P` |
| 拡張機能ビュー | `⇧⌘X` / `Ctrl+Shift+X` |
| 設定 | `⌘,` / `Ctrl+,` |

## Web ブラウザ版

ブラウザの [戻る] [進む] で、閲覧履歴をたどれます。
