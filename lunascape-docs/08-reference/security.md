# セキュリティと保存境界

Lunascape Docs が文書と端末を守るために設けている境界です。

## 表示

- Markdown から生成した HTML と、図から生成した SVG は、DOMPurify 3.4.14 で無害化してから表示します。
- MDX に含まれる任意のスクリプトは実行しません。
- KaTeX は `trust: false`、`maxSize: 50`、`maxExpand: 1000` で実行し、外部 HTML や任意のコマンドを信頼しません。
- Markmap、WaveDrom、Svgbob、Vega-Lite、Penrose の描画ライブラリは、対応するブロックがあるときにだけ、固定した版を端末内で読み込みます。外部リソースへの参照、生の HTML、実行可能な記法は許可せず、生成 SVG からスクリプト、外部画像、`link`、`style`、`foreignObject` を除去します。
- TikZ の描画は、ホストの LaTeX を起動せず、メモリ内ファイルシステムを持つ WebAssembly の TeX ワーカーで逐次実行します。入力、待ち行列、メモリ、実行時間（15 秒）、SVG 出力に上限があり、ファイル I/O 命令は拒否します。

## 文書とファイルへのアクセス

- 文書のリンクとファイル操作は、文書ルートの外へ出られません。
- INDEX からの作成、名前変更、移動、削除は、文書ルート、INDEX の版、正本のパス、対象の種類、シンボリックリンクの境界、未保存の文書を拡張機能側で再確認してから適用します。古いメニューや別の文書ルートからの操作要求は適用しません。
- 文書の編集中や、別の INDEX 操作の適用中は、INDEX の変更操作を無効にします。
- テンプレートからの作成は、ワークスペースの信頼、文書ルートの実体、INDEX の版、Standard Pack と生成内容、保存先、シンボリックリンクの境界をプレビュー後に再確認します。既存ファイルを上書きせず、プレビューと異なる内容や 4 MiB を超える展開結果を作成しません。
- 設定ファイルの保存は、保存の直前に版を確認し、外部の変更を検出した場合は中止します。

## 外部への送信

- 閲覧、編集、チェックのために文書を外部へ送ることはありません。文書チェックは端末内で決定的に実行します。
- 翻訳（このページの翻訳、一括翻訳）だけが、送信先と送信範囲を事前に表示し、明示的に承認された場合に文書を言語モデルへ送信します。 <!-- ai-only -->
- 翻訳案は差分を提示し、正本と翻訳先の版を再確認してから、人が明示的に保存した場合にだけ適用します。 <!-- ai-only -->
- AI エージェント向けの仕様ツールは、文書の本文、ワークスペース名、ローカルパスを返しません。 <!-- ai-only -->

## Git

- 保存はファイルへの書き込みだけを行います。Git のステージングやコミットは、どの機能でも自動では行いません。
- `_meta.json` などの既存ファイルを黙って削除・変更することはありません。孤立した翻訳版も自動では削除・移動しません。
